Use **Docker Hub** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 25 typed API operations
- 10 synced entities (`images`, `invites`, `orgAccessTokens`, `organizations`, `orgMembers`, `repositories`, and 4 more) for fast `.search()` / `.list()`

## Add the plugin

```ts title="corsair.ts"
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { dockerhub } from '@corsair-dev/dockerhub';

export const corsair = createCorsair({
	plugins: [
		dockerhub(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

## Connect a tenant

Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'dockerhub',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

## Example API calls

**`images.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.dockerhub.api.images.get({});
```


**`organizations.addMember`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.dockerhub.api.organizations.addMember({});
```


See the full list on the [API](/plugins/dockerhub/api) page.

## Query synced data

Synced entities support `tenant.dockerhub.db.<entity>.search()` and `.list()`: `images`, `invites`, `orgAccessTokens`, `organizations`, `orgMembers`, `repositories`, `tags`, `teamMembers`, `teams`, `users`.

See [Database](/plugins/dockerhub/database) for filters and operators.
