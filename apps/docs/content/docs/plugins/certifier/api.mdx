## Attributes

### list

`attributes.list`

List attribute definitions available for credentials, with pagination.

**Risk:** `read`

```ts
await corsair.certifier.api.attributes.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | — |
| `cursor` | `string` | No | — |




**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `pagination` | `object` | No | — |


<Accordions>
<Accordion title="data full type">

```ts

  id?: string,
  tag?: string,
  name?: string,
  type?: string

</Accordion>

}
```
