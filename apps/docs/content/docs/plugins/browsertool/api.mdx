## Files

### get

`files.get`

Get a download URL for a task output file

**Risk:** `read`

```ts
await corsair.browsertool.api.files.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `fileId` | `string` | Yes | — |
| `taskId` | `string` | Yes | — |




**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `data` | `any` | Yes | — |
| `error` | `string` | No | — |
| `successful` | `boolean` | Yes | — |
| `session_info` | `any` | No | — |
| `log_id` | `string` | No | — |
