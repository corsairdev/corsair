Use **Pushbullet** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 15 typed API operations
- 2 synced entities (`devices`, `pushes`) for fast `.search()` / `.list()`

## Add the plugin

```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { pushbullet } from '@corsair-dev/pushbullet';

export const corsair = createCorsair({
	plugins: [
		pushbullet(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

## Choose authentication

<Tabs items={["API Key (Recommended)", "OAuth 2.0"]}>
<Tab value="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
pushbullet()
```

More: [API Key](/concepts/api-key)

</Tab>
<Tab value="OAuth 2.0">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Pushbullet OAuth app.

```ts
pushbullet({
	authType: 'oauth_2',
})
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>

## Connect a tenant

Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'pushbullet',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

## Example API calls

**`chats.list`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.pushbullet.api.chats.list({});
```


**`chats.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.pushbullet.api.chats.create({});
```


See the full list on the [API](/plugins/pushbullet/api) page.

## Query synced data

Synced entities support `tenant.pushbullet.db.<entity>.search()` and `.list()`: `devices`, `pushes`.

See [Database](/plugins/pushbullet/database) for filters and operators.
