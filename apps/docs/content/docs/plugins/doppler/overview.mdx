Use **Doppler** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 62 typed API operations
- 5 synced entities (`configs`, `environments`, `projects`, `webhooks`, `workplace`) for fast `.search()` / `.list()`

## Add the plugin

```ts title="corsair.ts"
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { doppler } from '@corsair-dev/doppler';

export const corsair = createCorsair({
	plugins: [
		doppler(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

## Connect a tenant

Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'doppler',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

## Example API calls

**`activityLogs.list`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.doppler.api.activityLogs.list({});
```


**`configLogs.rollback`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.doppler.api.configLogs.rollback({});
```


See the full list on the [API](/plugins/doppler/api) page.

## Query synced data

Synced entities support `tenant.doppler.db.<entity>.search()` and `.list()`: `configs`, `environments`, `projects`, `webhooks`, `workplace`.

See [Database](/plugins/doppler/database) for filters and operators.
