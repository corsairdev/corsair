Use **Bookingmood** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 132 typed API operations
- 9 synced entities (`bookings`, `calendar_events`, `contacts`, `invoices`, `members`, `organizations`, and 3 more) for fast `.search()` / `.list()`

## Add the plugin

```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { bookingmood } from '@corsair-dev/bookingmood';

export const corsair = createCorsair({
	plugins: [
		bookingmood(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

## Connect a tenant

Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'bookingmood',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

## Example API calls

**`attributeOptions.list`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.bookingmood.api.attributeOptions.list({});
```


**`attributeOptions.update`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.bookingmood.api.attributeOptions.update({});
```


See the full list on the [API](/plugins/bookingmood/api) page.

## Query synced data

Synced entities support `tenant.bookingmood.db.<entity>.search()` and `.list()`: `bookings`, `calendar_events`, `contacts`, `invoices`, `members`, `organizations`, `payments`, `products`, `widgets`.

See [Database](/plugins/bookingmood/database) for filters and operators.
