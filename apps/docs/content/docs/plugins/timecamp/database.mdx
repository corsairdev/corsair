The TimeCamp plugin syncs data locally. Use `corsair.timecamp.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Callout type="info">
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Callout>

## Projects

Path: `timecamp.db.projects.search`

```ts
const rows = await corsair.timecamp.db.projects.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `name` | `string` | equals, contains, startsWith, endsWith, in |
| `archived` | `boolean` | equals |
| `color` | `string` | equals, contains, startsWith, endsWith, in |
| `billable` | `boolean` | equals |
| `budgeted` | `number` | equals, gt, gte, lt, lte, in |
| `budget_unit` | `string` | equals, contains, startsWith, endsWith, in |
| `root_group_id` | `string` | equals, contains, startsWith, endsWith, in |
| `createdAt` | `date` | equals, before, after, between |


_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
