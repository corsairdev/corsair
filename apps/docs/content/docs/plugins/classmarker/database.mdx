The Classmarker plugin syncs data locally. Use `corsair.classmarker.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Callout type="info">
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Callout>

## Results

Path: `classmarker.db.results.search`

```ts
const rows = await corsair.classmarker.db.results.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `external_id` | `string` | equals, contains, startsWith, endsWith, in |
| `created_at` | `date` | equals, before, after, between |


_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
