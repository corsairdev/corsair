The Reducto plugin syncs data locally. Use `corsair.reducto.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Callout type="info">
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Callout>

## Jobs

Path: `reducto.db.jobs.search`

```ts
const rows = await corsair.reducto.db.jobs.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `jobId` | `string` | equals, contains, startsWith, endsWith, in |
| `numPages` | `number` | equals, gt, gte, lt, lte, in |
| `totalPages` | `number` | equals, gt, gte, lt, lte, in |
| `duration` | `number` | equals, gt, gte, lt, lte, in |
| `providerCreatedAt` | `string` | equals, contains, startsWith, endsWith, in |
| `studioLink` | `string` | equals, contains, startsWith, endsWith, in |
| `updatedAt` | `date` | equals, before, after, between |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
