## Delete Person

### delete

`deletePerson.delete`

Delete a person record by their unique identifier.

**Risk:** `destructive`

```ts
await corsair.timelink.api.deletePerson.delete({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |




**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |
| `data` | `object` | Yes | — |
