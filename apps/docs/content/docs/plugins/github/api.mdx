## Comments

### delete

`comments.delete`

Delete a comment

**Risk:** `write`

```ts
await corsair.github.api.comments.delete({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `owner` | `string` | Yes | — |
| `repo` | `string` | Yes | — |
| `commentId` | `number` | Yes | — |




**Output:** `void`
