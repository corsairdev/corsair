Use **Altoviz** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 67 typed API operations
- 8 synced entities (`classifications`, `contacts`, `customerFamilies`, `customers`, `productFamilies`, `products`, and 2 more) for fast `.search()` / `.list()`

## Add the plugin

```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { altoviz } from '@corsair-dev/altoviz';

export const corsair = createCorsair({
	plugins: [
		altoviz(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

## Connect a tenant

Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'altoviz',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

## Example API calls

**`account.getClassifications`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.altoviz.api.account.getClassifications({});
```


**`colleagues.delete`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.altoviz.api.colleagues.delete({});
```


See the full list on the [API](/plugins/altoviz/api) page.

## Query synced data

Synced entities support `tenant.altoviz.db.<entity>.search()` and `.list()`: `classifications`, `contacts`, `customerFamilies`, `customers`, `productFamilies`, `products`, `units`, `vats`.

See [Database](/plugins/altoviz/database) for filters and operators.
