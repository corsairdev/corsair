## Session

### create

`session.create`

Create a new Devin session to start working on a task

**Risk:** `write`

```ts
await corsair.devinmcp.api.session.create({});
```

| `org_id` | `string` | Yes | — |
| `prompt` | `string` | Yes | — |
| `create_as_user_id` | `string` | No | — |
| `playbook_id` | `string` | No | — |
| `title` | `string` | No | — |
| `tags` | `string[]` | No | — |
| `knowledge_ids` | `string[]` | No | — |
