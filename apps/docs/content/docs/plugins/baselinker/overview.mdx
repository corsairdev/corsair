Use **BaseLinker** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 106 typed API operations
- 16 synced entities (`categories`, `connectIntegrations`, `couriers`, `externalStorages`, `inventories`, `inventoryExtraFields`, and 10 more) for fast `.search()` / `.list()`

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { baselinker } from '@corsair-dev/baselinker';

export const corsair = createCorsair({
	plugins: [
		baselinker(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs items={["API Key (Recommended)"]}>
<Tab value="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
baselinker()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'baselinker',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`connect.getConnectIntegrationContractors`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.baselinker.api.connect.getConnectIntegrationContractors({});
```


**`couriers.createPackageManual`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.baselinker.api.couriers.createPackageManual({});
```


See the full list on the [API](/plugins/baselinker/api) page.

## Query synced data

Synced entities support `tenant.baselinker.db.<entity>.search()` and `.list()`: `categories`, `connectIntegrations`, `couriers`, `externalStorages`, `inventories`, `inventoryExtraFields`, `manufacturers`, `orderStatuses`, `payers`, `priceGroups`, `returnProductStatuses`, `returnReasons`, `returnStatuses`, `suppliers`, `tags`, `warehouses`.

See [Database](/plugins/baselinker/database) for filters and operators.
