Use **Figma** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 50 typed API operations
- 5 synced entities (`comments`, `components`, `fileMetadata`, `versions`, `webhookConfigs`) for fast `.search()` / `.list()`
- 6 incoming webhook event types

## Add the plugin

```ts title="corsair.ts"
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { figma } from '@corsair-dev/figma';

export const corsair = createCorsair({
	plugins: [
		figma(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

## Connect a tenant

Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'figma',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

## Example API calls

**Get file metadata**

```ts
const tenant = corsair.withTenant('acme');
await tenant.figma.api.files.getMetadata({ file_key: 'abcDEF123' });
```


**Add a comment**

```ts
const tenant = corsair.withTenant('acme');
await tenant.figma.api.comments.add({ file_key: 'abcDEF123', message: 'Hello from Corsair' });
```


See the full list on the [API](/plugins/figma/api) page.

## Query synced data

Search synced file metadata without hitting Figma.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.figma.db.fileMetadata.search({
	data: {},
	limit: 50,
});
```

Synced entities: `comments`, `components`, `fileMetadata`, `versions`, `webhookConfigs`. See [Database](/plugins/figma/database) for filters and operators.

## Webhooks

Fires when a Figma file is updated. Do not use ping.ping.

```ts
figma({
    webhookHooks: {
        files: {
            fileUpdate: {
                after: async (ctx, result) => {
                    console.log('Figma file updated:', result.data);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/figma/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
