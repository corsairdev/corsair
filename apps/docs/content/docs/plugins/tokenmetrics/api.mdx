## Market

### getPrice

`market.getPrice`

Retrieve token price, volume, and market-cap data

**Risk:** `read`

```ts
await corsair.tokenmetrics.api.market.getPrice({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `token_id` | `string \| number` | No | — |
| `symbol` | `string` | No | — |
| `interval` | `string` | No | — |
| `startDate` | `string` | No | — |
| `endDate` | `string` | No | — |
| `limit` | `number` | No | — |
| `page` | `number` | No | — |




**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `success` | `boolean` | No | — |
| `message` | `string` | No | — |


<Accordions>
<Accordion title="data full type">

```ts
{
  token_id?: string | number,
  symbol?: string,
  name?: string,
  price?: number,
  market_cap?: number,
  volume_24h?: number | null,
  number_of_holders?: number | null,
  token_creation_date?: string
}[]
```
</Accordion>
</Accordions>
