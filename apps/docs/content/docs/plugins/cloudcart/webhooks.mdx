The Cloudcart plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/cloudcart/overview) for setup context and the exact URL shape).

<Callout type="info">
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Callout>

## Webhook map

- `customer`
  - `created` (`customer.created`)
- `order`
  - `created` (`order.created`)
- `product`
  - `created` (`product.created`)

## HTTP handler setup

```ts title="app/api/webhook/route.ts"
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    const body = await request.json();
    const result = await processWebhook(corsair, headers, body);
    return result.response;
}
```

## Events

## Customer

### Created

`customer.created`

Customer created webhook event

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| number` | Yes | — |
| `email` | `any` | Yes | — |




<Accordions>
<Accordion title="Response data full type">

```ts
{
  id: string | number,
  email: any
}
```
</Accordion>
</Accordions>

**`webhookHooks` example**

```ts
cloudcart({
    webhookHooks: {
        customer: {
            created: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
