## List

### templates

`list.templates`

List all available document templates in FlexiSign

**Risk:** `read`

```ts
await corsair.flexisign.api.list.templates({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | — |
| `limit` | `number` | No | — |




**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string` | Yes | — |
| `code` | `number` | Yes | — |
| `data` | `object` | Yes | — |
| `message` | `string` | Yes | — |
