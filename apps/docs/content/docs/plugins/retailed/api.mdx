## Goat

### prices

`goat.prices`

Get GOAT product prices

**Risk:** `read`

```ts
await corsair.retailed.api.goat.prices({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | `string` | Yes | — |
| `country` | `string` | No | — |




**Output:** `object[]`

<Accordions>
<Accordion title="Output full type">

```ts
{
  sizeOption: {
    value: number,
    presentation: string
  },
  stockStatus: string,
  boxCondition: string,
  shoeCondition: string,
  lowestPriceCents: {
    currency: string
  },
  lastSoldPriceCents: {
    amount?: number,
    currency: string,
    amountUsdCents?: number
  },
  instantShipLowestPriceCents: {
    currency: string
  }
}[]
```
</Accordion>
</Accordions>
