Use **Bugsnag** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 61 typed API operations
- 4 synced entities (`collaborators`, `organizations`, `projects`, `teams`) for fast `.search()` / `.list()`

## Add the plugin

```ts title="corsair.ts"
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { bugsnag } from '@corsair-dev/bugsnag';

export const corsair = createCorsair({
	plugins: [
		bugsnag(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

## Connect a tenant

Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'bugsnag',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

## Example API calls

**`collaborators.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.bugsnag.api.collaborators.get({});
```


**`collaborators.delete`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.bugsnag.api.collaborators.delete({});
```


See the full list on the [API](/plugins/bugsnag/api) page.

## Query synced data

Synced entities support `tenant.bugsnag.db.<entity>.search()` and `.list()`: `collaborators`, `organizations`, `projects`, `teams`.

See [Database](/plugins/bugsnag/database) for filters and operators.
