Use **Salesforce** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 225 typed API operations
- 14 synced entities (`account`, `campaign`, `campaignMember`, `contact`, `contentDocument`, `emailMessage`, and 8 more) for fast `.search()` / `.list()`
- 7 incoming webhook event types

## Add the plugin

```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { salesforce } from '@corsair-dev/salesforce';

export const corsair = createCorsair({
	plugins: [
		salesforce(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

## Connect a tenant

Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'salesforce',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

## Example API calls

**`accounts.fetchAccountByIdWithQuery`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.salesforce.api.accounts.fetchAccountByIdWithQuery({});
```


**`accounts.accountCreationWithContentTypeOption`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.salesforce.api.accounts.accountCreationWithContentTypeOption({});
```


See the full list on the [API](/plugins/salesforce/api) page.

## Query synced data

Synced entities support `tenant.salesforce.db.<entity>.search()` and `.list()`: `account`, `campaign`, `campaignMember`, `contact`, `contentDocument`, `emailMessage`, `lead`, `note`, `opportunity`, `opportunityLineItem`, `pricebook`, `pricebookEntry`, `task`, `user`.

See [Database](/plugins/salesforce/database) for filters and operators.

## Webhooks

This plugin registers **7** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/salesforce/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
