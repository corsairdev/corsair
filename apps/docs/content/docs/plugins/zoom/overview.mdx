Use **Zoom** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 17 typed API operations
- 6 synced entities (`archiveFiles`, `devices`, `meetings`, `participants`, `recordings`, `webinars`) for fast `.search()` / `.list()`
- 8 incoming webhook event types

## Add the plugin

```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { zoom } from '@corsair-dev/zoom';

export const corsair = createCorsair({
	plugins: [
		zoom(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

## Connect a tenant

Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'zoom',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

## Example API calls

**List meetings**

```ts
const tenant = corsair.withTenant('acme');
await tenant.zoom.api.meetings.list({});
```


**Create a meeting**

```ts
const tenant = corsair.withTenant('acme');
await tenant.zoom.api.meetings.create({ topic: 'Corsair standup', duration: 30 });
```


See the full list on the [API](/plugins/zoom/api) page.

## Query synced data

Search synced meetings without hitting Zoom.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.zoom.db.meetings.search({
	data: {},
	limit: 50,
});
```

Synced entities: `archiveFiles`, `devices`, `meetings`, `participants`, `recordings`, `webinars`. See [Database](/plugins/zoom/database) for filters and operators.

## Webhooks

Fires when a Zoom meeting is created.

```ts
zoom({
    webhookHooks: {
        meetings: {
            created: {
                after: async (ctx, result) => {
                    console.log('Zoom meeting created:', result.data);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/zoom/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
