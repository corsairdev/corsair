## Documents

### list

`documents.list`

Retrieve a list of documents from a Boloforms workspace, with optional filtering and pagination

**Risk:** `read`

```ts
await corsair.boloforms.api.documents.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `workspaceId` | `string` | Yes | — |
| `query` | `string` | No | — |
| `sortOrder` | `string` | No | — |
| `limit` | `string` | No | — |
| `documentId` | `string` | No | — |
| `dateTo` | `string` | No | — |
| `dateFrom` | `string` | No | — |
| `page` | `string` | No | — |
| `sortBy` | `string` | No | — |
| `filter` | `string` | No | — |




**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|

| Parameter | Type | Required | Description |
| --- | --- | --- | --- |
| `documents` | `object[]` | Yes | — |
| `message` | `string` | No | — |
| `formCount` | `number` | No | — |
| `documentsCount` | `number` | No | — |
| `pagination` | `object` | No | — |
