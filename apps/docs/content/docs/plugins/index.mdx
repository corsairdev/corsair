## What each plugin documents

| Page | Contents |
| --- | --- |
| Overview | What the integration covers, install snippet, operation and entity counts |
| API | Every typed operation, its arguments, and its return shape |
| Database | The entities Corsair syncs into your database and their columns |
| Webhooks | Incoming event types and their payloads |
| Get credentials | Where to create the OAuth app or API key on the provider's side |
