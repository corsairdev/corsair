Corsair is an open-source integration layer for apps and agents. Connect to GitHub, Slack, Gmail, and the rest of the catalog through one syntax. Corsair handles OAuth, token refresh, webhooks, multi-tenancy, and rate limits.

You run it inside your own app. Credentials stay encrypted in your database. [Hub](/hub/overview) hosts connect pages and OAuth callbacks so you do not build those public URLs yourself.

## How it works

<Steps>

<Step>

### Wire once

Install `@corsair-dev/<plugin>` packages and pass your database connection:

```ts title="corsair.ts"
import { createCorsair } from 'corsair';
import { github } from '@corsair-dev/github';
import { slack } from '@corsair-dev/slack';

export const corsair = createCorsair({
  plugins: [github(), slack()],
  database: db,
  kek: process.env.CORSAIR_KEK!,
  hub: {
    projectApiKey: process.env.CORSAIR_API_KEY!,
    signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
  },
});
```

</Step>

<Step>

### Call the provider

Every plugin shares the same shape: `corsair.[plugin].api.[resource].[action]()`.

```ts title="route.ts"
await corsair.github.api.issues.create({
  owner: 'acme',
  repo: 'app',
  title: 'Bug',
});

await corsair.slack.api.messages.post({
  channel: 'C123',
  text: 'On it.',
});
```

</Step>

<Step>

### Read from `.db`

API calls and webhooks keep `corsair_entities` current. Scope to a tenant and query your database instead of fanning out to GitHub on every page load:

```ts title="route.ts"
const tenant = corsair.withTenant('user_abc123');

const issues = await tenant.github.db.issues.search({
  data: { state: 'open' },
});
```

See [Database](/concepts/database) for the table layout and sync behavior.

</Step>

</Steps>

## For agents

Corsair fits agentic workflows: expose your instance over MCP (`list_operations`, `get_schema`, `run_script`), or point a coding agent at [llms.txt](https://docs.corsair.dev/llms.txt) and the [docs MCP](https://mcp.corsair.dev/mcp). Start with [Set up with your agent](/getting-started/set-up-with-your-agent) or the [MCP adapters](/mcp-adapters/mcp-adapters) guide.
