Developer guidance

  • Configure local development with apipie({ key: process.env.APIPIE_API_KEY }).
  • The plugin does not load environment variables implicitly; the application passes the value explicitly.
  • Without an inline key, Corsair resolves api_key from its encrypted credential store.
  • HTTP 429 responses honor Retry-After; billable POST requests are not automatically replayed after errors.
  • APIpie exposes no webhook operations or incoming webhook handlers.
