Corsair is an open-source integration layer. Every service is a plugin: install it, get a typed client in your code and a tool your agent can call. One pattern whether you have one integration or fifty.

It's built on a REST API, so the same layer works for agents, backend services, and dashboards your customers use.

## Hub

OAuth callbacks, connect pages, and approval screens need a public URL. [Hub](/hub/overview) hosts them. Same SDK, one config block. Tokens pass through and land encrypted in your database. Hub stores none.

## Developer experience

**Local dev.** A built-in dev tunnel gives your local handler a scoped public URL. OAuth and webhooks behave like production, without ngrok.

**Go live.** Swap dev Hub keys for production keys and register your delivery URL. Same code, same credentials. See [Development and Production](/hub/environments).

## Your users' experience

When an action needs a connection they haven't made yet, Corsair mints an auth link on the fly. They sign into Gmail when they first need Gmail, not upfront on a settings page with a dozen OAuth buttons.

See [Connect / OAuth](/management/connect) for `createLink()`.
