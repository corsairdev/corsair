## SDK: corsair 0.1.185

Also released: `@corsair-dev/cli` 0.1.53, `@corsair-dev/langchain` 0.1.28, `@corsair-dev/llamaindex` 0.1.28, `@corsair-dev/mastra` 0.1.28, `@corsair-dev/mcp` 0.1.56, `@corsair-dev/studio` 0.1.37, `@corsair-dev/ui` 0.1.33.

- Retry a 401 for every OAuth plugin and tell a revoked grant from a broken app ([#2324](https://github.com/corsairdev/corsair/pull/2324))
- Plugin error handlers first, kek check before the call, honest webhook results ([#2335](https://github.com/corsairdev/corsair/pull/2335))
- Keep the error body on failed calls and redact more key names ([#2320](https://github.com/corsairdev/corsair/pull/2320))
- Let endpoints refresh an OAuth token after a 401 ([#2319](https://github.com/corsairdev/corsair/pull/2319))
- Render catalog and docs types as the schemas declare them ([#2090](https://github.com/corsairdev/corsair/pull/2090))
- Let an operation declare the long job it starts ([#2053](https://github.com/corsairdev/corsair/pull/2053))
- **studio:** Typed client for the Corsair Cloud management API ([#1894](https://github.com/corsairdev/corsair/pull/1894))
- **studio:** Remove duplicate aria-label props on ScriptPage ([#1798](https://github.com/corsairdev/corsair/pull/1798))
- **cli:** Validate --port in the ui command ([#1824](https://github.com/corsairdev/corsair/pull/1824))
