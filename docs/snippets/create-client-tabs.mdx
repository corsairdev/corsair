  <Tab title="Vanilla JS">

```ts corsair-client.ts
import { createCorsairClient } from "corsair";

export const client = createCorsairClient({ baseURL: "/api/corsair" });

// every route is typed
await client.connectionStatus.get({ tenantId: "acme" });
```

Works from any JS runtime — Svelte, Vue, a worker, a CLI. See the [Vanilla Client](/adapters/client) reference.
