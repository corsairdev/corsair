Hono is built on the Web `Request`/`Response` standard, and so is Corsair — so the adapter is a direct fit with nothing to bridge. Corsair serves several paths under its base (delivery, connect, tenants), so one wildcard route with `app.all` catches them all.

## Install

The adapter ships in core `corsair` — no per-runtime package. Add a plugin package per service you integrate (`@corsair-dev/github`, and so on).

## Mount the handler

```ts index.ts
import { Hono } from 'hono';
import { toHonoHandler } from 'corsair';
import { corsair } from './corsair';

const app = new Hono();

app.all('/api/corsair/*', toHonoHandler(corsair, { basePath: '/api/corsair' }));

export default app;
```

`./corsair` is your `createCorsair({ ... })` instance — see [Getting Started](/getting-started/quick-start) if you haven't built it yet. Keep the `/*` wildcard and `basePath` matching the mount path.

<Note>Because it's Web-standard the whole way down, this same file deploys to Cloudflare Workers, Bun, Deno, and Node with no per-runtime change.</Note>

## Resolve the tenant

You bring your own auth. An auth middleware puts the user on the context with `c.set('user', ...)`; read it back with `c.get('user')` and scope Corsair to that id per request:

```ts
const tenant = corsair.withTenant(await getTenantId(c));
```

## Read and write

Corsair calls are the same on every runtime. In a route handler, read from `.db` — your own database, so no network hop and no rate limit — and write through `.api`, which upserts the response so the next read reflects it:

```ts routes.ts
import { corsair } from './corsair';

app.get('/issues', async (c) => {
    const tenant = corsair.withTenant(await getTenantId(c));
    const issues = await tenant.github.db.issues.search({
        data: { state: 'open' },
        limit: 50,
    });
    // .data holds the entity fields, camelCase and typed
    return c.json(issues.map((i) => i.data.title));
});

app.post('/issues', async (c) => {
    const tenant = corsair.withTenant(await getTenantId(c));
    const { title } = await c.req.json();
    await tenant.github.api.issues.create({ owner: 'acme', repo: 'app', title });
    return c.body(null, 201);
});
```

## Go green

Start the app on your runtime of choice — `npm run dev` with `@hono/node-server`, `bun run index.ts`, or `wrangler dev` on Workers. The first request to `/api/corsair` registers your delivery URL with Hub and turns the **App sync** dot in the dashboard header green.

## Deploy

The same file deploys to Cloudflare Workers, Bun, Deno, or Node with no per-runtime change. Wherever it lands, the mounted `/api/corsair` route at your public origin becomes the delivery URL Hub calls.
