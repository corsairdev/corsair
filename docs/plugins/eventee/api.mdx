## Attendee Invite

### put

`attendeeInvite.put`

Invite attendees by email with optional profile details and tickets

**Risk:** `destructive`

```ts
await corsair.eventee.api.attendeeInvite.put({ users: [{ email: 'jane.doe@example.com', first_name: 'Jane', send_email: false }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `users` | `object[]` | Yes | — |

The first 25 users are processed immediately and the rest in the background. Eventee skips event admins/moderators and entries it rejects. Every email is validated locally first, so one malformed address fails the whole call before anything is sent. `send_email: true` makes Eventee email each person an invitation; leave it unset or false for a silent import.

<Accordion title="users full type">

```ts

  linked_in_link?: string,
  group_id?: number,
  send_email?: boolean,
  tickets?: {
    number: string,
```

### patch

`hall.patch`

Update a hall and its live stream assignment

**Risk:** `write`

```ts
await corsair.eventee.api.hall.patch({ hall_id: 1, name: 'Main Stage', order: 0 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `hall_id` | `number` | Yes | — |
| `name` | `string` | Yes | — |
| `order` | `number` | No | — |
| `stream` | `string` | No | — |

`name` is required and an omitted `order` is kept, but an omitted `stream` removes the hall's live stream. Pass the current `stream` code to keep it.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | — |
| `name` | `string` | No | — |
| `order` | `number` | No | — |
| `event_id` | `number` | No | — |
| `created_at` | `string` | No | — |
| `updated_at` | `string` | No | — |
| `stream` | `string \| null` | No | — |
