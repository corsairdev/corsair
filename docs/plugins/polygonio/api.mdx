## Aggregates

### bars

`aggregates.bars`

Read historical OHLC and volume bars for a ticker over a custom range and window size, with `next_url` paging

**Risk:** `read`

```ts
await corsair.polygonio.api.aggregates.bars({ ticker: 'AAPL', multiplier: 1, timespan: 'day', from: '2026-01-02', to: '2026-01-09' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `nextUrl` | `string` | No | The previous answer's `next_url`. When set, the other parameters are ignored and that exact page is fetched. |
| `ticker` | `string` | Yes | A case-sensitive ticker, such as AAPL. |
| `multiplier` | `number` | Yes | The size of each window, such as 5 for a 5-minute bar. |
| `timespan` | `minute \| hour \| day \| week \| month \| quarter \| year` | Yes | The unit of the window. |
| `from` | `string` | Yes | Start of the range, as YYYY-MM-DD or a millisecond timestamp. |
| `to` | `string` | Yes | End of the range, inclusive, as YYYY-MM-DD or a millisecond timestamp. |
| `adjusted` | `boolean` | No | Whether prices are adjusted for splits. The API adjusts by default. |
| `sort` | `asc \| desc` | No | Order by timestamp. The API defaults to ascending. |
| `limit` | `number` | No | How many base aggregates to read. Defaults to 5000, and the maximum is 50000. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ticker` | `string \| null` | No | — |
| `adjusted` | `boolean \| null` | No | — |
| `queryCount` | `number \| null` | No | — |
| `resultsCount` | `number \| null` | No | — |
| `status` | `string \| null` | No | `OK`, `DELAYED` when the plan delays data, or `ERROR`. |
| `request_id` | `string \| null` | No | — |
| `count` | `number \| null` | No | The total number of matching rows. |
| `next_url` | `string \| null` | No | Present while another page exists; pass it to the matching `nextPage`. |
| `results` | `object[]` | Yes | — |

}[]

## Tickers

### list

`tickers.list`

List ticker symbols filtered by type, market, exchange, CUSIP, CIK or name, with `next_url` paging

**Risk:** `read`

```ts
await corsair.polygonio.api.tickers.list({ market: 'stocks', active: true, limit: 50 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `nextUrl` | `string` | No | The previous answer's `next_url`. When set, the other parameters are ignored and that exact page is fetched. |
| `ticker` | `string` | No | One exact ticker symbol. |
| `type` | `string` | No | A ticker type code, as `tickerTypes.list` reports them. |
| `market` | `string` | No | A market, such as `stocks`, `crypto`, `fx` or `otc`. |
| `exchange` | `string` | No | An ISO 10383 Market Identifier Code, such as XNYS. |
| `cusip` | `string` | No | A CUSIP. The API accepts it but never returns it. |
| `cik` | `string` | No | An SEC Central Index Key. |
| `date` | `string` | No | Tickers as they were on this date. Defaults to the latest. |
| `search` | `string` | No | Matches within the ticker and the company name. |
| `active` | `boolean` | No | Whether to return only actively traded tickers. Defaults to true. |
| `tickerGte` | `string` | No | Ticker at or after this value. |
| `tickerGt` | `string` | No | Ticker after this value. |
| `tickerLte` | `string` | No | Ticker at or before this value. |
| `tickerLt` | `string` | No | Ticker before this value. |
| `order` | `asc \| desc` | No | Order by the `sort` field. |
| `sort` | `string` | No | The field to sort on, such as `ticker`. |
| `limit` | `number` | No | Page size. Defaults to 100, and the maximum is 1000. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string \| null` | No | `OK`, `DELAYED` when the plan delays data, or `ERROR`. |
| `request_id` | `string \| null` | No | — |
| `count` | `number \| null` | No | The total number of matching rows. |
| `next_url` | `string \| null` | No | Present while another page exists; pass it to the matching `nextPage`. |
| `results` | `object[]` | Yes | — |
