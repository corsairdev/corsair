Use **Polygon.io** through Corsair: one client, typed API calls.

Polygon.io publishes its site at polygon.io and its docs as Massive, and both names serve the same API on `api.polygon.io` and `api.massive.com`. Create a key in the dashboard and paste it into the plugin; it travels as the documented `apiKey` query parameter.

What to know before you query:

- **Plans gate the data, not the routes.** A free key reaches market status, ticker reference and end-of-day bars, while real-time snapshots need a paid plan. When a plan does not include a dataset the API answers 403 rather than an empty result, and the plugin reports that as a permission error instead of retrying.
- **`status` is not always `OK`.** A plan with delayed data answers `DELAYED`, so the field stays a string rather than an enum a future value could break.
- **Paging.** The list routes return `next_url` while another page exists. It already carries the cursor and your filters, so pass it to the same operation as `nextUrl` and the other arguments are ignored. Any `apiKey` the URL echoes is dropped, because the plugin adds the caller's own.
- **A missing bar is not an error.** `aggregates.bars` omits `results` when no qualifying trades happened in the window, so the plugin reads that as an empty page rather than a failed call. It does not mean the market was closed: an open session with no trades produces the same answer. Use `market.status` when you need the current market state.
- **Rates.** The free tier allows a small number of calls a minute. A 429 is retried by the transport three times, honouring any `Retry-After` the API sends; the plugin adds no retries of its own, so the budget is not multiplied.
- **Webhooks.** The API sends none, so the plugin receives none.

**What you get:**

- 12 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/polygonio better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/polygonio better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/polygonio better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/polygonio better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { polygonio } from '@corsair-dev/polygonio';

export const corsair = createCorsair({
	plugins: [
		polygonio(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Polygon.io API key before the first call: `pnpm corsair setup --plugin=polygonio --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
polygonio()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'polygonio',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List actively traded US stocks**

```ts
const tenant = corsair.withTenant('acme');
await tenant.polygonio.api.tickers.list({ market: 'stocks', active: true });
```


**Read a ticker's latest snapshot**

```ts
const tenant = corsair.withTenant('acme');
await tenant.polygonio.api.snapshots.snapshot({ ticker: 'AAPL' });
```
