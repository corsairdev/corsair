## Bookings

### create

`bookings.create`

Book an appointment. A resource schedule needs start and finish, a capacity schedule needs a slot id, and the two are not interchangeable

**Risk:** `write`

```ts
await corsair.supersaas.api.bookings.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `schedule_id` | `number` | Yes | — |
| `start` | `string` | No | A local wall-clock value, as YYYY-MM-DD or YYYY-MM-DD HH:MM:SS. SuperSaaS applies the schedule timezone. |
| `finish` | `string` | No | A local wall-clock value, as YYYY-MM-DD or YYYY-MM-DD HH:MM:SS. SuperSaaS applies the schedule timezone. |
| `slot_id` | `string` | No | — |
| `resource_id` | `string` | No | — |
| `full_name` | `string \| null` | No | — |
| `email` | `string \| null` | No | — |
| `address` | `string \| null` | No | — |
| `mobile` | `string \| null` | No | — |
| `phone` | `string \| null` | No | — |
| `country` | `string \| null` | No | — |
| `field_1` | `string \| null` | No | — |
| `field_2` | `string \| null` | No | — |
| `field_1_r` | `string \| null` | No | — |
| `field_2_r` | `string \| null` | No | — |
| `super_field` | `string \| null` | No | — |
| `form_id` | `string \| null` | No | — |
| `webhook` | `boolean` | No | — |
| `user_id` | `string` | No | Create the booking on behalf of this user. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `created` | `true` | Yes | — |
| `key` | `string` | Yes | — |
| `id` | `string` | No | Present only when SuperSaaS answered a body; the id otherwise arrives in a Location header this client cannot read. |

## Users

### create

`users.create`

Create a user. The name is the login name and is the only required field; SuperSaaS assigns the id and returns it in a Location header

**Risk:** `write`

```ts
await corsair.supersaas.api.users.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | The login name, max 50 characters. It must be a valid email address when the account uses email as the login name. |
| `email` | `string \| null` | No | — |
| `password` | `string \| null` | No | — |
| `full_name` | `string \| null` | No | — |
| `address` | `string \| null` | No | — |
| `mobile` | `string \| null` | No | — |
| `phone` | `string \| null` | No | — |
| `country` | `string \| null` | No | A two-letter ISO 3166-1 code. |
| `timezone` | `string \| null` | No | An IANA TZ identifier. |
| `field_1` | `string \| null` | No | — |
| `field_2` | `string \| null` | No | — |
| `super_field` | `string \| null` | No | — |
| `credit` | `string \| null` | No | A credit level; the format is set on the Payment Setup screen. |
| `role` | `3 \| 4 \| -1` | No | 3 regular, 4 superuser, -1 blocked. |
| `group` | `string \| null` | No | A group id, never the group name. |
| `webhook` | `boolean` | No | Trigger the account webhooks as part of the write. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `created` | `true` | Yes | — |
| `key` | `string` | Yes | — |
| `id` | `string` | No | Present only when SuperSaaS answered a body; the id otherwise arrives in a Location header this client cannot read. |
