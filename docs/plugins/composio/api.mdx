## Connections

### create

`connections.create`

Create a connected-account auth link

**Risk:** `write`

```ts
await corsair.composio.api.connections.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `auth_config_id` | `string` | Yes | — |
| `user_id` | `string` | Yes | — |

| `callback_url` | `string` | No | — |



**Output**

| `redirect_url` | `string` | Yes | — |
| `expires_at` | `string` | Yes | — |
| `connected_account_id` | `string` | Yes | — |
