## Contacts

### createContact

`contacts.createContact`

Create a new contact in a contact list.

**Risk:** `write`

```ts
await corsair.campayn.api.contacts.createContact({
  listId: '123',
  email: 'person@example.com'
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `listId` | `string \| number` | Yes | — |
| `email` | `string` | Yes | — |
| `first_name` | `string` | No | — |
| `last_name` | `string` | No | — |
| `title` | `string` | No | — |
| `address` | `string` | No | — |
| `city` | `string` | No | — |
| `state` | `string` | No | — |
| `zip` | `string` | No | — |
| `company` | `string` | No | — |
| `country` | `string` | No | — |
| `phones` | `object[]` | No | — |
| `sites` | `object[]` | No | — |
| `social` | `object[]` | No | — |
| `custom_fields` | `object[]` | No | — |
| `failOnDuplicate` | `boolean` | No | — |

<AccordionGroup>

}[]
```

```

## Signup

### signup

`signup.signup`

Sign up a new Campayn user account. This endpoint requires API-key authorization for signup action.

**Risk:** `write`

```ts
await corsair.campayn.api.signup.signup({
  email: 'new.user@example.com',
  first_name: 'New',
  last_name: 'User',
  password: 'secure-password-123'
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | — |
| `first_name` | `string` | Yes | — |
| `last_name` | `string` | Yes | — |
| `password` | `string` | Yes | — |
| `subdomain` | `string` | No | — |
| `site` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `number \| boolean` | Yes | — |
| `msg` | `string` | Yes | — |
| `errorCode` | `string` | No | — |
