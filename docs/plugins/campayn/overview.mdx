Use **Campayn** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 15 typed API operations
- 5 synced entities (`contacts`, `lists`, `messages`, `reports`, `webforms`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/campayn better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/campayn better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/campayn better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/campayn better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { campayn } from '@corsair-dev/campayn';

export const corsair = createCorsair({
	plugins: [
		campayn(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Campayn API key before the first call: `pnpm corsair setup --plugin=campayn --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
campayn()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'campayn',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List contact lists**

```ts
const tenant = corsair.withTenant('acme');
await tenant.campayn.api.lists.getLists({});
```


**Create a contact**

```ts
const tenant = corsair.withTenant('acme');
await tenant.campayn.api.contacts.createContact({
	listId: '12345',
	email: 'you@example.com',
	first_name: 'Octo',
	last_name: 'Cat',
});
```


See the full list on the [API](/plugins/campayn/api) page.

## Query synced data

These tables exist, but Campayn calls don't fill them yet. This returns only rows you have written yourself.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.campayn.db.contacts.search({
	data: {},
	limit: 50,
});
```

Synced entities: `contacts`, `lists`, `messages`, `reports`, `webforms`. See [Database](/plugins/campayn/database) for filters and operators.
