Use **Campayn** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 15 typed API operations
- 5 synced entities (`contacts`, `lists`, `messages`, `reports`, `webforms`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/campayn better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/campayn better-sqlite3
```
```bash pnpm
pnpm add corsair @corsair-dev/campayn better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/campayn better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { campayn } from '@corsair-dev/campayn';

export const corsair = createCorsair({
	plugins: [
		campayn(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
campayn()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'campayn',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`contacts.getContact`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.campayn.api.contacts.getContact({ contactId: '12345' });
```


**`contacts.createContact`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.campayn.api.contacts.createContact({
	listId: '987',
	email: 'person@example.com',
});
```


See the full list on the [API](/plugins/campayn/api) page.

## Query synced data

Synced entities support `tenant.campayn.db.<entity>.search()` and `.list()`: `contacts`, `lists`, `messages`, `reports`, `webforms`.

See [Database](/plugins/campayn/database) for filters and operators.
