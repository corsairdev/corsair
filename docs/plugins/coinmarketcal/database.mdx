---
title: Database
description: "CoinMarketCal has no locally synced entities. All data is fetched live from the API."
---

The CoinMarketCal plugin does not sync any entities locally, so `corsair.coinmarketcal.db` has nothing to search. Call the [API endpoints](/plugins/coinmarketcal/api) to read coins, events, and categories directly from CoinMarketCal.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
