## Categories

### list

`categories.list`

List event categories from CoinMarketCal

**Risk:** `read`

```ts
await corsair.coinmarketcal.api.categories.list({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  id: string | number,
  name?: string,
  slug?: string
}[]
```
</Accordion>
</AccordionGroup>

## Coins

### get

`coins.get`

Get a cryptocurrency by slug from CoinMarketCal

**Risk:** `read`

```ts
await corsair.coinmarketcal.api.coins.get({ slug: 'bitcoin' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `slug` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `slug` | `string` | Yes | — |
| `symbol` | `string` | No | — |
| `name` | `string` | No | — |
| `rank` | `number` | No | — |
| `tracked` | `boolean` | No | — |
| `iconUrl` | `string` | No | — |
| `upcomingCount` | `number` | No | — |
| `majorCount` | `number` | No | — |
| `peakImpact` | `number` | No | — |

**Output**

### list

`events.list`

List cryptocurrency events from CoinMarketCal

**Risk:** `read`

```ts
await corsair.coinmarketcal.api.events.list({
	coins: 'bitcoin,ethereum',
	from: '2026-01-01',
	to: '2026-03-31',
	limit: 20,
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `coins` | `string` | No | — |
| `categories` | `string` | No | — |
| `from` | `string` | No | — |
| `to` | `string` | No | — |
| `keyword` | `string` | No | — |
| `impactMin` | `number` | No | — |
| `sortBy` | `date_asc \| date_desc \| created_desc \| created_desc_and_updated_desc \| impact_desc` | No | — |
| `limit` | `number` | No | — |
| `cursor` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | No | — |
| `meta` | `object` | No | — |
