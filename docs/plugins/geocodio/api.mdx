## Distance

### fromOrigin

`distance.fromOrigin`

Measure driving or straight-line distance and duration from one origin to many destinations, optionally filtering and sorting by either

**Risk:** `read`

```ts
await corsair.geocodio.api.distance.fromOrigin({ origin: '1109 N Highland St, Arlington, VA 22201', destinations: ['1600 Pennsylvania Ave NW, Washington, DC 20500'], mode: 'driving' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `origin` | `string` | Yes | The starting address or `lat,lng` pair |
| `destinations` | `string[]` | Yes | The addresses or `lat,lng` pairs to measure from the origin |
| `mode` | `driving \| haversine \| straightline` | No | `driving` follows roads and gives a duration; `haversine` and `straightline` are the as-the-crow-flies distance |
| `units` | `miles \| km` | No | Which distance figure to use |
| `max_results` | `number` | No | Caps the destinations returned |
| `max_distance` | `number` | No | Drops destinations farther than this |
| `max_duration` | `number` | No | Drops destinations slower than this |
| `min_distance` | `number` | No | Drops destinations nearer than this |
| `min_duration` | `number` | No | Drops destinations faster than this |
| `order_by` | `distance \| duration` | No | Which figure to sort by |
| `sort_order` | `asc \| desc` | No | Sort direction |
| `country` | `string` | No | Restricts and formats the lookup as `US`, `CA`, `MX`, `GB`, `AU` or `NZ`, which also changes how an address is parsed |
| `enterprise` | `boolean` | No | Uses the enterprise host |

The route accepts `driving`, `haversine` and `straightline`; only `driving` returns a duration.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `origin` | `Record<string, any>` | No | — |
| `mode` | `string` | No | — |
| `destinations` | `object[]` | Yes | — |
| `_warnings` | `string[]` | No | — |

<AccordionGroup>
<Accordion title="destinations full type">

```ts
{
  query?: string,
  location?: number[],
  id?: string,
  distance_miles?: number,
  distance_km?: number,
  duration_seconds?: number
}[]
```
</Accordion>
</AccordionGroup>

### matrix

`distance.matrix`

Measure every origin against every destination, or pair each origin with one destination, in a single request

**Risk:** `read`

```ts
await corsair.geocodio.api.distance.matrix({ origins: ['38.886665,-77.094733'], destinations: ['38.8977,-77.0365'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `origins` | `string[]` | Yes | The starting addresses or `lat,lng` pairs, one row each |
| `destinations` | `string[]` | Yes | The addresses or `lat,lng` pairs, one column each |
| `calculation_type` | `matrix \| one-to-one` | No | `matrix` measures every origin against every destination; `one-to-one` pairs each origin with one destination |
| `mode` | `driving \| straightline` | No | `driving` follows roads and gives a duration; `straightline` is the as-the-crow-flies distance |
| `units` | `miles \| km` | No | Which distance figure to order and filter by |
| `max_results` | `number` | No | Caps the cells returned |
| `max_distance` | `number` | No | Drops cells farther than this |
| `max_duration` | `number` | No | Drops cells slower than this |
| `min_distance` | `number` | No | Drops cells nearer than this |
| `min_duration` | `number` | No | Drops cells faster than this |
| `order_by` | `distance \| duration` | No | Which figure to sort by |
| `sort_order` | `asc \| desc` | No | Sort direction |
| `country` | `string` | No | Restricts and formats the lookup as `US`, `CA`, `MX`, `GB`, `AU` or `NZ`, which also changes how an address is parsed |

`calculation_type: one-to-one` pairs each origin with one destination instead of crossing them.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `mode` | `string` | No | — |
| `results` | `object[]` | Yes | — |
| `_warnings` | `string[]` | No | — |

<AccordionGroup>
<Accordion title="results full type">

```ts
{
  origin?: Record<string, any>,
  destinations: {
    query?: string,
    location?: number[],
    id?: string,
    distance_miles?: number,
    distance_km?: number,
    duration_seconds?: number
  }[]
}[]
```
</Accordion>
</AccordionGroup>

## Geocode

### batch

**Risk:** `read`


### forward

`geocode.forward`

Turn an address into coordinates, with a confidence score, the accuracy type that says how the match was made, and the parsed components. Data appends such as timezone or congressional district come back under `fields`

**Risk:** `read`

```ts
await corsair.geocodio.api.geocode.forward({ q: '1109 N Highland St, Arlington, VA 22201', fields: ['timezone'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | No | A single-line address, such as `1109 N Highland St, Arlington, VA 22201` |
| `street` | `string` | No | The street line, without the city |
| `street2` | `string` | No | The unit, suite or floor |
| `city` | `string` | No | The city |
| `county` | `string` | No | The county |
| `state_province` | `string` | No | The state or province |
| `postal_code` | `string` | No | The ZIP or postal code |
| `country` | `string` | No | Restricts and formats the lookup as `US`, `CA`, `MX`, `GB`, `AU` or `NZ`, which also changes how an address is parsed |
| `limit` | `number` | No | How many matches to return, at most 100 |
| `fields` | `string[]` | No | Data appends to add to each result, such as `timezone`, `congressional_district`, `stateleg`, `school`, `census`, `zip4`, or a Census ACS name |
| `enterprise` | `boolean` | No | Uses api.enterprise.geocod.io, for accounts that have one |

Send either `q` or the components; `fields` appends data such as `timezone` under `fields`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `results` | `object[]` | Yes | — |
| `_warnings` | `string[]` | No | — |
