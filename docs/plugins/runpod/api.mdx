## Account

### myself

`account.myself`

Get the authenticated RunPod user id, email, MFA, and SSH public key

**Risk:** `read`

```ts
await corsair.runpod.api.account.myself({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `email` | `string` | No | — |
| `multiFactorEnabled` | `boolean` | No | — |
| `pubKey` | `string` | No | — |



---
