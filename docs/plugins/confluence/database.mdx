---
title: "Confluence database"
sidebarTitle: "Database"
description: "The Confluence plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Confluence. To read its data, call the [API operations](/plugins/confluence/api), which return what Confluence has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
