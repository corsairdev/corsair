---
title: "Minerstat database"
sidebarTitle: "Database"
description: "The Minerstat plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Minerstat. To read its data, call the [API operations](/plugins/minerstat/api), which return what Minerstat has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
