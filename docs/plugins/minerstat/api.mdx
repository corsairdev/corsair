## Algorithms

### get

`algorithms.get`

Get algorithms

**Risk:** `read`

```ts
await corsair.minerstat.api.algorithms.get({ slug: 'sha-256' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `slug` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `algorithm` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="algorithm full type">

```ts
{
  slug: string,
  name: string,
  unit: string,
  coins: {
    slug: string,
    symbol: string,
    name?: string,
    algorithm?: string,
    networkHashrate?: number | null,
    difficulty?: number | null,
    blockReward?: number | null,
    blockTimeSeconds?: number | null,
    priceUsd?: number | null,
    marketCapUsd?: number | null,
    volume24hUsd?: number | null,
    confidence?: number | null,
    dataUpdatedAt?: string | null
  }[],
  hardware: {
    slug: string,
    name: string,
    type: ASIC | GPU | CPU | FPGA,
    hashrateHs: number,
    powerWatts: number | null
  }[]
}
```
</Accordion>
</AccordionGroup>

## Profitability

### rank

`profitability.rank`

Rank profitability

**Risk:** `read`

```ts
await corsair.minerstat.api.profitability.rank({ hardware: 'nvidia-geforce-rtx-4090', electricity: 0.1 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `hardware` | `string` | No | — |
| `hashrate` | `number` | No | — |
| `algorithm` | `string` | No | — |
| `power` | `number` | No | — |
| `quantity` | `number` | No | — |
| `electricity` | `number` | No | — |
| `poolFee` | `number` | No | — |
| `verifiedOnly` | `boolean` | No | — |
| `limit` | `number` | No | — |
| `window` | `current \| 6h \| 24h \| 3d` | No | — |

Requires the Enterprise plan. Use hardware for preset mode, or hashrate and algorithm for manual mode.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `hardware` | `object \| null` | Yes | — |
| `electricityPrice` | `number` | Yes | — |
| `currency` | `string` | Yes | — |
| `results` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="hardware full type">

```ts
{
  slug: string,
  name: string
} | null
```
</Accordion>

<Accordion title="results full type">

```ts
{
  coin: {
    slug: string,
    symbol: string,
    name?: string,
    algorithm: string
  },
  coinsPerDay: number,
  revenuePerDay: number,
  electricityPerDay: number,
  profitPerDay: number,
  profitMargin: number | null,
  breakEvenElectricityPrice: number | null,

```

</AccordionGroup>
