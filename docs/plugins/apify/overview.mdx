Use **Apify** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 121 typed API operations
- 11 synced entities (`actorBuilds`, `actorOutputs`, `actorRuns`, `actors`, `actorTasks`, `datasets`, and 5 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/apify
```
```bash yarn
yarn add corsair @corsair-dev/apify
```
```bash pnpm
pnpm install corsair @corsair-dev/apify
```
```bash bun
bun add corsair @corsair-dev/apify
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { apify } from '@corsair-dev/apify';

export const corsair = createCorsair({
	plugins: [
		apify(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
apify()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'apify',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`actorBuilds.getActorBuild`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.apify.api.actorBuilds.getActorBuild({});
```


**`actorBuilds.abortActorBuild`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.apify.api.actorBuilds.abortActorBuild({});
```


See the full list on the [API](/plugins/apify/api) page.

## Query synced data

Synced entities support `tenant.apify.db.<entity>.search()` and `.list()`: `actorBuilds`, `actorOutputs`, `actorRuns`, `actors`, `actorTasks`, `datasets`, `keyValueStores`, `requestQueues`, `schedules`, `users`, `webhooks`.

See [Database](/plugins/apify/database) for filters and operators.
