## Agents

### listCases

`agents.listCases`

List cases for an external agent case type with pagination

**Risk:** `read`

```ts
await corsair.docsumo.api.agents.listCases({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `casetype_id` | `string` | Yes | — |
| `limit` | `number` | No | — |
| `offset` | `number` | No | — |
| `sort_by` | `created_date.asc \| created_date.desc \| modified_date.asc \| modified_date.desc` | No | — |
| `stage_id` | `string[]` | No | — |
| `assigned_to` | `string[]` | No | — |
| `workflow_state` | `string[]` | No | — |
| `created_date_from` | `string` | No | — |
| `created_date_to` | `string` | No | — |
| `modified_date_from` | `string` | No | — |
| `modified_date_to` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string` | No | — |
| `status_code` | `number` | No | — |
| `message` | `string` | No | — |
| `error` | `string` | No | — |
| `error_code` | `string` | No | — |
| `data` | `object` | No | — |
