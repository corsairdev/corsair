Use **BlazeMeter** through Corsair: one client, typed API calls, optional local DB sync.

**What you get:**

- 92 typed API operations
- 8 database entities synced for fast `.search()` / `.list()` queries

## Setup

<Steps>

<Step title="Install">
```bash
pnpm install @corsair-dev/blazemeter
```

</Step>

<Step title="Add the plugin">
<Tabs>
<Tab title="Solo">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { blazemeter } from '@corsair-dev/blazemeter';

export const corsair = createCorsair({
	// ... other config options,
	multiTenancy: false,
    plugins: [blazemeter()],
});
```
</Tab>
<Tab title="Multi-Tenant">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { blazemeter } from '@corsair-dev/blazemeter';

export const corsair = createCorsair({
	// ... other config options,
    multiTenancy: true,
    plugins: [blazemeter()],
});
```

See [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Tab>
</Tabs>

</Step>

<Step title="Get credentials">
Follow [Get Credentials](/plugins/blazemeter/get-credentials) if you need help getting keys.

</Step>

<Step title="Store credentials">
<Tabs>
<Tab title="Solo">
```bash
pnpm corsair setup --plugin=blazemeter
```

Use the key names documented in [Get Credentials](/plugins/blazemeter/get-credentials) (for example `api_key=`, `bot_token=`, or OAuth client fields).
</Tab>
<Tab title="Multi-Tenant">
```bash
pnpm corsair setup --plugin=blazemeter --tenant=<tenantId>
```

Store per-tenant secrets after you create the tenant record. See [Multi-tenancy](/concepts/multi-tenancy).
</Tab>
</Tabs>

</Step>

</Steps>

## Authentication

Each tab shows how to register the plugin for that authentication method. The default `authType` from the plugin does not need to appear in the factory call.

<Tabs>
<Tab title="API Key (Default)">

```ts corsair.ts
blazemeter()
```

Store credentials with `pnpm corsair setup --plugin=blazemeter` (see [Get Credentials](/plugins/blazemeter/get-credentials) for field names). For OAuth, you typically store integration keys at the provider level and tokens per account or tenant.

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>


## Query synced data

Synced entities support `corsair.blazemeter.db.<entity>.search()` and `.list()`. See [Database](/plugins/blazemeter/database) for filters and operators.


## Example API calls

**Read-style (read):** `accounts.list`

```ts
await corsair.blazemeter.api.accounts.list({});
```


**Write-style (write):** `assetDependencies.create`

```ts
await corsair.blazemeter.api.assetDependencies.create({});
```


See the full list on the [API](/plugins/blazemeter/api) page. Use `pnpm corsair list --plugin=blazemeter` and `pnpm corsair schema <path>` locally to inspect schemas.
