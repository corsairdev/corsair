The Waboxapp plugin syncs data locally. Use `corsair.waboxapp.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Accounts

Path: `waboxapp.db.accounts.search`

```ts
const rows = await corsair.waboxapp.db.accounts.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `success` | `boolean` | equals |
| `uid` | `string` | equals, contains, startsWith, endsWith, in |
| `hook_url` | `string` | equals, contains, startsWith, endsWith, in |
| `alias` | `string` | equals, contains, startsWith, endsWith, in |
| `platform` | `string` | equals, contains, startsWith, endsWith, in |
| `battery` | `string` | equals, contains, startsWith, endsWith, in |
| `plugged` | `string` | equals, contains, startsWith, endsWith, in |
| `locale` | `string` | equals, contains, startsWith, endsWith, in |
| `error` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
