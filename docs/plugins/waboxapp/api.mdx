## Accounts

### getStatus

`accounts.getStatus`

Get WhatsApp session status

**Risk:** `read`

```ts
await corsair.waboxapp.api.accounts.getStatus({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `uid` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |
| `uid` | `string` | No | — |
| `hook_url` | `string` | No | — |
| `alias` | `string` | No | — |
| `platform` | `string` | No | — |
| `battery` | `string` | No | — |
| `plugged` | `string` | No | — |
| `locale` | `string` | No | — |
| `error` | `string` | No | — |
