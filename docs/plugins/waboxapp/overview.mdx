Use **Waboxapp** through Corsair: one client, typed API calls, and incoming webhooks.

**What you get:**

- 5 typed API operations
- 2 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/waboxapp
```
```bash yarn
yarn add corsair @corsair-dev/waboxapp
```
```bash pnpm
pnpm install corsair @corsair-dev/waboxapp
```
```bash bun
bun add corsair @corsair-dev/waboxapp
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { waboxapp } from '@corsair-dev/waboxapp';

export const corsair = createCorsair({
	plugins: [
		waboxapp(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
waboxapp()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'waboxapp',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Get session status**

```ts
const tenant = corsair.withTenant('acme');
await tenant.waboxapp.api.accounts.getStatus({});
```


**Send a text message**

```ts
const tenant = corsair.withTenant('acme');
await tenant.waboxapp.api.messages.sendChat({ to: '34666789123', text: 'Hello from Corsair' });
```


See the full list on the [API](/plugins/waboxapp/api) page.

## Webhooks

Fires when a WhatsApp message arrives.

```ts
waboxapp({
    webhookHooks: {
        message: {
            received: {
                after: async (ctx, result) => {
                    console.log('Waboxapp message:', result.data?.uid, result.data?.contact?.uid);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/waboxapp/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
