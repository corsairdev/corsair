The Waboxapp plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/waboxapp/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `message`
  - `ack` (`message.ack`)
  - `received` (`message.received`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    const body = await request.json();
    const result = await processWebhook(corsair, headers, body);
    return result.response;
}
```

## Events

## Message

### Ack

`message.ack`

A WhatsApp message acknowledgement

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event` | `ack` | Yes | — |
| `token` | `string` | Yes | — |
| `uid` | `string` | Yes | — |
| `contact` | `object` | No | — |
| `message` | `object` | No | — |
| `muid` | `string` | No | — |
| `cuid` | `string` | No | — |
| `ack` | `string` | No | — |

**`webhookHooks` example**

```ts
waboxapp({
    webhookHooks: {
        message: {
            ack: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
