## Automation Mails

### create

`automationMails.create`

Create an automation mail without starting its automation.

**Risk:** `write`

```ts
await corsair.mailcoach.api.automationMails.create({ name: 'Welcome email', subject: 'Welcome aboard', html: '<p>Welcome</p>' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `subject` | `string` | No | — |
| `html` | `string` | No | — |
| `template_uuid` | `string` | No | — |
| `fields` | `Record<string, JsonValue>` | No | — |
| `utm_tags` | `boolean` | No | — |
| `add_subscriber_tags` | `boolean` | No | — |
| `add_subscriber_link_tags` | `boolean` | No | — |

Creates a reusable automation email and does not start an automation or send to subscribers.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  uuid: string,
  name?: string,
  subject?: string | null,
  html?: string | null,
  template_uuid?: string | null,
  structured_html?: JsonValue | null
}
```
</Accordion>
</AccordionGroup>

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignUuid` | `string` | Yes | — |
| `body` | `object` | Yes | — |

This is not a sparse patch: omitted content, segment, or scheduling values can reset. Resend the full intended draft settings. schedule_at uses UTC in YYYY-MM-DD HH:mm:ss form.
