### create

**Risk:** `write`


| Name | Type | Required | Description |
|------|------|----------|-------------|
| `stormId` | `number` | Yes | — |
| `message` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `message` | `object` | Yes | — |

Create an idea on a Storm

```ts
await corsair.stormboard.api.ideas.create({ stormid: 49999, data: 'This is an idea. Like it?' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|

| `type` | `string` | No | — |
| `data` | `string` | Yes | — |
| `name` | `string` | No | — |
| `color` | `string` | No | — |
| `shape` | `string` | No | — |

| `x` | `number` | No | — |
| `y` | `number` | No | — |
| `lock` | `0 \| 1` | No | — |

**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `message` | `string \| number` | Yes | — |
| `id` | `number \| string \| null` | No | — |
