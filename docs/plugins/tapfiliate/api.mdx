### create

`affiliates.create`

Create an affiliate and run the Affiliate created triggers; the new affiliate joins no program until you add it to one

**Risk:** `write`

```ts
await corsair.tapfiliate.api.affiliates.create({ email: 'jane@example-blog.inc', firstname: 'Jane', lastname: 'Jameson' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | The affiliate's email. |
| `password` | `string` | No | The account password. Tapfiliate generates one and returns it when this is omitted. |
| `firstname` | `string` | No | The affiliate's first name. |
| `lastname` | `string` | No | The affiliate's last name. |
| `company` | `object` | No | The affiliate's company. |
| `address` | `object` | No | The address. `address`, `postal_code`, `city` and `country.code` are required together, because Tapfiliate drops a partial address without an error. |
| `custom_fields` | `Record<string, string>` | No | Custom field values keyed by the field ID from `affiliates.customFields`. |

The reference documents a 200 with no body; then the plugin reports `{ created: true, email }` and the id (derived from the first and last name) comes from affiliates.list. An address is kept only when address, postal_code, city and country.code are all sent.

## Clicks

### create

`clicks.create`

Record a click and return its ID for use as click_id when creating a conversion

**Risk:** `write`

```ts
await corsair.tapfiliate.api.clicks.create({ referral_code: 'janejameson' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `referral_code` | `string` | No | An affiliate's referral code, the `ref=` value in their link. |
| `tracking_id` | `string` | No | The tracking ID from the Tapfiliate JavaScript library. |
| `click_id` | `string` | No | A click ID from `clicks.create`. |
| `coupon` | `string` | No | A coupon code to attribute by. |
| `asset_id` | `string` | No | The tracking asset ID. |
| `source_id` | `string` | No | The click source ID. Pair it with `asset_id`; on a click it can also override the source of a `referral_code`. |
| `ip` | `string` | No | Stored as sent. |
| `user_agent` | `string` | No | Stored as sent. |
| `referrer` | `string` | No | Stored as sent. |
| `landing_page` | `string` | No | Stored as sent. |

Returns `{ id }` for use as click_id in conversions.create. Name the affiliate with referral_code (a source_id then overrides its source) or with asset_id and source_id. ip, user_agent, referrer and landing_page are stored as sent.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |

## Conversions

### create

`conversions.create`

Track a conversion and create its commissions, attributed through a coupon, click, referral code, asset or tracking ID

**Risk:** `destructive`

```ts
await corsair.tapfiliate.api.conversions.create({ click_id: '1-abc', amount: 30.55, currency: 'USD', external_id: 'order-100' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `referral_code` | `string` | No | An affiliate's referral code, the `ref=` value in their link. |
| `tracking_id` | `string` | No | The tracking ID from the Tapfiliate JavaScript library. |
| `click_id` | `string` | No | A click ID from `clicks.create`. |
| `coupon` | `string` | No | A coupon code to attribute by. |
| `asset_id` | `string` | No | The tracking asset ID. |
| `source_id` | `string` | No | The click source ID. Pair it with `asset_id`; on a click it can also override the source of a `referral_code`. |
| `amount` | `number` | Yes | The conversion amount. |
