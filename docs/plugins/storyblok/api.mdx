## Assets

### bulkDelete

`assets.bulkDelete`

Delete several assets in one call, with the same effect as deleting each

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.storyblok.api.assets.bulkDelete({ ids: [900, 901] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ids` | `number[]` | Yes | The asset ids to delete. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deleted` | `number \| null` | No | — |
| `message` | `string \| null` | No | — |

### update

`components.update`

Replace a component's field schema. Existing content is not migrated: a removed field's values stay in stories, hidden, until a migration removes them

**Risk:** `write`

```ts
await corsair.storyblok.api.components.update({ component_id: 12345, name: 'page', schema: { title: { type: 'text' }, subtitle: { type: 'text' } } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `component_id` | `number` | Yes | A Storyblok numeric id. |
| `name` | `string` | Yes | The technical name, which content uses as its component key. |
| `display_name` | `string \| null` | No | — |
| `schema` | `Record<string, any>` | Yes | Field name to its definition, such as &#123; title: &#123; type: "text" &#125; &#125;. |
| `is_root` | `boolean` | No | — |
| `is_nestable` | `boolean` | No | — |
| `preview_field` | `string \| null` | No | — |
| `preview_tmpl` | `string \| null` | No | — |
| `icon` | `string \| null` | No | — |
| `color` | `string \| null` | No | — |
| `component_group_uuid` | `string \| null` | No | — |

Replacing a component's schema changes the shape every story of that type is parsed against, and a removed field's values stay in existing stories, hidden from the editor, until a migration removes them.
