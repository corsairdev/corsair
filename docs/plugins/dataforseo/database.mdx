The DataForSeo plugin syncs data locally. Use `corsair.dataforseo.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Amazon Products

Path: `dataforseo.db.amazonProducts.search`

```ts
const rows = await corsair.dataforseo.db.amazonProducts.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `asin` | `string` | equals, contains, startsWith, endsWith, in |
| `seDomain` | `string` | equals, contains, startsWith, endsWith, in |
| `locationCode` | `number` | equals, gt, gte, lt, lte, in |
| `languageCode` | `string` | equals, contains, startsWith, endsWith, in |
| `title` | `string` | equals, contains, startsWith, endsWith, in |
| `priceFrom` | `number` | equals, gt, gte, lt, lte, in |
| `currency` | `string` | equals, contains, startsWith, endsWith, in |
| `rating` | `number` | equals, gt, gte, lt, lte, in |
| `ratingCount` | `number` | equals, gt, gte, lt, lte, in |
| `isAvailable` | `boolean` | equals |
| `updatedAt` | `date` | equals, before, after, between |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
