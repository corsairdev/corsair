The DocuSign plugin syncs data locally. Use `corsair.docusign.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Accounts

Path: `docusign.db.accounts.search`

```ts
const rows = await corsair.docusign.db.accounts.search({
    data: { /* filters below */ },
```
