Use **Docusign** through Corsair: one client, typed API calls.

**What you get:**

- 340 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/docusign
```
```bash yarn
yarn add corsair @corsair-dev/docusign
```
```bash pnpm
pnpm install corsair @corsair-dev/docusign
```
```bash bun
bun add corsair @corsair-dev/docusign
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { docusign } from '@corsair-dev/docusign';

export const corsair = createCorsair({
	plugins: [
		docusign({
			authType: 'oauth_2',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="OAuth 2.0 (Recommended)">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Docusign OAuth app.

```ts
docusign({
	authType: 'oauth_2',
})
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'docusign',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`deprecatedEndpointForTabBlob`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.docusign.api.deprecatedEndpointForTabBlob({});
```


**`addContactsToContactsList`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.docusign.api.addContactsToContactsList({});
```
