Use **Jira** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 32 typed API operations
- 6 synced entities (`boards`, `comments`, `issues`, `projects`, `sprints`, `users`) for fast `.search()` / `.list()`
- 3 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/jira
```
```bash yarn
yarn add corsair @corsair-dev/jira
```
```bash pnpm
pnpm install corsair @corsair-dev/jira
```
```bash bun
bun add corsair @corsair-dev/jira
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { jira } from '@corsair-dev/jira';

export const corsair = createCorsair({
	plugins: [
		jira(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

Provider walkthrough: [Get Credentials](/plugins/jira/get-credentials).

```ts
jira()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'jira',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`comments.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.jira.api.comments.get({});
```


**`comments.add`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.jira.api.comments.add({});
```


See the full list on the [API](/plugins/jira/api) page.

## Query synced data

Synced entities support `tenant.jira.db.<entity>.search()` and `.list()`: `boards`, `comments`, `issues`, `projects`, `sprints`, `users`.

See [Database](/plugins/jira/database) for filters and operators.

## Webhooks

This plugin registers **3** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/jira/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
