Every `clickhouse.*` operation is listed below with parameter shapes and
return types from the plugin Zod schemas. The ClickHouse plugin is
read-only: all operations are `read` risk-level and never mutate the
database.

<Info>
**New to Corsair?** See [API access](/concepts/api),
[authentication](/concepts/auth), and
[error handling](/concepts/error-handling).
</Info>

## Query

### query.execute

`query.execute`

Execute a SQL query against the tenant ClickHouse instance and return the
result rows. The plugin appends `LIMIT n` when `limit` is set and the
provided SQL has no `LIMIT` clause.

**Risk:** `read`

```ts
await corsair.clickhouse.query.execute({
	sql: 'SELECT name, count() FROM system.tables GROUP BY name',
	database: 'analytics',
	limit: 100,
});
```

**Input**

| Name       | Type     | Required | Description                                                            |
| ---------- | -------- | -------- | ---------------------------------------------------------------------- |
| `sql`      | `string` | Yes      | SQL query to execute against ClickHouse                                |
| `database` | `string` | No       | Default database context (sent as `?database=`)                        |
| `limit`    | `number` | No       | Maximum rows to return; appended as `LIMIT` when not present in SQL    |

**Output**

```ts
{
	rows: Record<string, unknown>[];
	rowCount: number;
}
```

### query.listDatabases

`query.listDatabases`

List all databases on the tenant ClickHouse instance.

**Risk:** `read`

```ts
await corsair.clickhouse.query.listDatabases({});
```

**Input:** none.

**Output**

```ts
{
	databases: { name: string; engine: string }[];
}
```

### query.listTables

`query.listTables`

List tables in a ClickHouse database with their engine and approximate
size.

**Risk:** `read`

```ts
await corsair.clickhouse.query.listTables({ database: 'analytics', limit: 50 });
```

**Input**

| Name       | Type     | Required | Description                            |
| ---------- | -------- | -------- | -------------------------------------- |
| `database` | `string` | Yes      | Database to list tables from           |
| `limit`    | `number` | No       | Maximum tables to return (default 1000) |
| `offset`   | `number` | No       | Tables to skip before returning rows   |

**Output**

```ts
{
	database: string;
	tables: {
		name: string;
		engine: string;
		totalRows?: number | string;
		totalBytes?: number | string;
	}[];
	count: number;
}
```

## Schema

### schema.getDatabase

`schema.getDatabase`

Get a schema overview for a ClickHouse database; optionally include
column definitions for each table.

**Risk:** `read`

```ts
await corsair.clickhouse.schema.getDatabase({
	database: 'analytics',
	includeColumns: true,
});
```

**Input**

| Name             | Type      | Required | Description                                                        |
| ---------------- | --------- | -------- | ------------------------------------------------------------------ |
| `database`       | `string`  | Yes      | Database to introspect                                             |
| `includeColumns` | `boolean` | No       | When `true`, also fetch column definitions for each table          |
| `limit`          | `number`  | No       | Maximum tables to return                                           |
| `offset`         | `number`  | No       | Tables to skip before returning rows                               |

**Output**

```ts
{
	database: string;
	tables: {
		name: string;
		engine?: string;
		totalRows?: number | string;
		totalBytes?: number | string;
		columns?: {
			name: string;
			type: string;
			position?: number | string;
			comment?: string;
			defaultExpression?: string;
		}[];
	}[];
	count: number;
}
```

### schema.getTable

`schema.getTable`

Get column-level schema for a ClickHouse table, optionally with sample
rows.

**Risk:** `read`

```ts
await corsair.clickhouse.schema.getTable({
	database: 'analytics',
	table: 'events',
	includeSample: true,
	sampleSize: 5,
});
```

**Input**

| Name            | Type      | Required | Description                                                              |
| --------------- | --------- | -------- | ------------------------------------------------------------------------ |
| `database`      | `string`  | Yes      | Database the table belongs to                                            |
| `table`         | `string`  | Yes      | Table to introspect                                                       |
| `includeSample` | `boolean` | No       | When `true`, include up to `sampleSize` rows from the table               |
| `sampleSize`    | `number`  | No       | Sample row count when `includeSample` is true; defaults to 5, max 1000    |

**Output**

```ts
{
	database: string;
	table: string;
	engine?: string;
	totalRows?: number | string;
	columns: {
		name: string;
		type: string;
		position?: number | string;
		comment?: string;
		defaultExpression?: string;
	}[];
	sampleRows?: Record<string, unknown>[];
}
```

## Play

### play.get

`play.get`

Fetch the ClickHouse Play web UI HTML (Monaco editor + query UI). The
response is capped at 5 MB.

**Risk:** `read`

```ts
await corsair.clickhouse.play.get({});
```

**Input:** none.

**Output**

```ts
{
	url: string;
	html: string;
	sizeBytes: number;
}
```
