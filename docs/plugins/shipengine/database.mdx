---
title: "ShipStation API (formerly ShipEngine) database"
sidebarTitle: "Database"
description: "The ShipStation API (formerly ShipEngine) plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for ShipStation API (formerly ShipEngine). To read its data, call the [API operations](/plugins/shipengine/api), which return what ShipStation API (formerly ShipEngine) has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
