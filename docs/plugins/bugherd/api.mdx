## Columns

### create

`columns.create`

Add a custom column at the end of a project board.

**Risk:** `write`

```ts
await corsair.bugherd.api.columns.create({ project_id: 552668, name: 'In Review' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project_id` | `number` | Yes | BugHerd project id. |
| `name` | `string` | Yes | Column name. It is added at the end of the board. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `column` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="column full type">

```ts
{
  id: number,
  name?: string | null,
  project_id?: number | null,
  position?: number | null,
  tasks_count?: number | null,
  created_at?: string | null,
  updated_at?: string | null
}
```
</Accordion>
</AccordionGroup>
