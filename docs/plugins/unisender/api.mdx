## Campaigns

### create

`campaigns.create`

Start or schedule a campaign from a message; omitting start_time sends it immediately

**Risk:** `write`

```ts
await corsair.unisender.api.campaigns.create({ message_id: 98765, start_time: '2026-12-01 09:00:00', timezone: 'Europe/Berlin' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `message_id` | `number` | Yes | The message from messages.createEmail. |
| `start_time` | `string` | No | YYYY-MM-DD hh:mm:ss in the given timezone. Omit it to start immediately. |
| `timezone` | `string` | No | The timezone start_time is in. |
| `track_read` | `0 \| 1` | No | — |
| `track_links` | `0 \| 1` | No | — |
| `contacts` | `string` | No | A comma-separated address list, as an alternative to the message's list. |
| `track_ga` | `0 \| 1` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `result` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="result full type">

```ts
{
  campaign_id?: number | null,
  status?: string | null
}
```
</Accordion>
</AccordionGroup>

### list

`campaigns.list`

List campaigns whose start time falls in a window, up to 10,000 a page

**Risk:** `read`

```ts

```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `from` | `string` | Yes | YYYY-MM-DD hh:mm:ss in UTC; the earliest start to include. |
| `to` | `string` | No | YYYY-MM-DD hh:mm:ss in UTC; the latest start to include. |
| `limit` | `number` | No | At most 10,000 a call. |
| `offset` | `number` | No | Zero-based position of the first record. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `result` | `object[]` | Yes | — |

### exclude

`contacts.exclude`

Remove a contact from lists without marking them unsubscribed, so they can be re-added later

**Risk:** `write`

```ts
await corsair.unisender.api.contacts.exclude({ email: 'jordan@acme-logistics.com', list_ids: [1] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | — |
| `contact_type` | `email` | No | email is the documented value; it is sent explicitly. |
| `list_ids` | `number[]` | No | The lists to unsubscribe from. Omit it to unsubscribe from every list the contact is in. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `result` | `Record<string, any>` | Yes | — |

### import

`contacts.import`

Import up to 500 contacts from columnar data; role addresses such as sales@ are skipped on purpose

**Risk:** `write`

```ts
await corsair.unisender.api.contacts.import({ list_ids: [1], field_names: ['email', 'Name'], data: [['jordan@acme-logistics.com', 'Jordan']] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `list_ids` | `number[]` | Yes | The lists to add every imported contact to. |
| `field_names` | `string[]` | Yes | The column names, which must include email. `tags` is a comma-separated tag list and `delete` set to 1 removes the contact. |
| `data` | `(string \| number \| boolean)[][]` | Yes | Rows, each with a value per field_names entry and in the same order. At most 500 contacts per call. |
| `overwrite_tags` | `0 \| 1` | No | — |
| `overwrite_lists` | `0 \| 1` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `result` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="result full type">

```ts
Record<string, {
  created?: number | null,
  updated?: number | null,
  deleted?: number | null,
  skipped?: number | null,
  new_emails?: number | null,
  invalid?: number | null,
  errors?: string[] | null
}>
```
</Accordion>
</AccordionGroup>

### subscribe

`contacts.subscribe`

Add or update a contact in one or more lists, choosing whether to send a confirmation email; the resulting status says whether the address can be mailed yet

**Risk:** `write`

```ts
await corsair.unisender.api.contacts.subscribe({ list_ids: [1], email: 'jordan@acme-logistics.com', fields: { Name: 'Jordan' }, double_optin: 1 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `list_ids` | `number[]` | Yes | The lists to add the contact to. |
| `email` | `string` | Yes | — |
| `fields` | `Record<string, string \| number \| boolean>` | No | Custom field name to value, sent as fields[&lt;name&gt;]=value. |
| `double_optin` | `0 \| 1 \| 3` | No | 0 adds without a confirmation email, 1 sends one, 3 adds without any email. Defaults to Unisender's own choice. |
| `overwrite` | `0 \| 1` | No | 1 overwrites the contact's existing field values. |
| `tags` | `string[]` | No | Up to 10 tags to add. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `result` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="result full type">

```ts
{
  person?: Record<string, any> | null,
  email?: {
    email?: string | null,
    status?: string | null
  } | null
}
```
</Accordion>
</AccordionGroup>

### sendEmail

`messages.sendEmail`

Send one transactional email to a single recipient; capped at 60 calls a minute and with no field substitution beyond the unsubscribe URL

**Risk:** `write`

```ts
await corsair.unisender.api.messages.sendEmail({ email: 'jordan@acme-logistics.com', sender_name: 'Acme', sender_email: 'hello@acme.example', subject: 'Your receipt', body: '<p>Thanks.</p>', list_id: 1 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | The recipient, optionally as `Name <address>`. |
| `sender_name` | `string` | Yes | The From display name. |
| `sender_email` | `string` | Yes | The From address, which must be verified. |
| `subject` | `string` | Yes | — |
| `body` | `string` | Yes | The HTML body, up to 1 MB. |
| `list_id` | `number` | Yes | The list the message is associated with, for unsubscribe handling. |
| `track_read` | `0 \| 1` | No | — |
| `track_links` | `0 \| 1` | No | — |
| `cc` | `string` | No | A carbon-copy address. |
| `metadata` | `Record<string, string \| number>` | No | Your own keys, echoed back by checkEmail. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `result` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="result full type">

```ts
{
  email_id?: number | null,
  email?: string | null,
  message_id?: number | null,
  message?: string | null
}[]
```
</Accordion>
</AccordionGroup>
