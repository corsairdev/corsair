## Actions

### list

`actions.list`

List actions / issues

**Risk:** `read`

```ts
await corsair.safetyculture.api.actions.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `IN PROGRESS \| DONE \| OVERDUE \| NONE \| CLOSED` | No | — |
| `assignee` | `string` | No | — |
| `created_after` | `string` | No | — |
| `created_before` | `string` | No | — |
| `modified_after` | `string` | No | — |
| `due_after` | `string` | No | — |
| `due_before` | `string` | No | — |
| `limit` | `number` | No | — |
| `offset` | `number` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `count` | `number` | No | — |
| `total` | `number` | No | — |
| `actions` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="actions full type">

```ts
{
  action_id: string,
  title?: string,
  description?: string,
  status?: string,
  priority?: string | null,
  assignee_id?: string | null,
  assignee_name?: string | null,
  creator_id?: string | null,
  creator_name?: string | null,
  audit_id?: string | null,
  audit_title?: string | null,
  template_id?: string | null,
  due_at?: string | null,
  created_at?: string,
  modified_at?: string,
  completed_at?: string | null,
  site_id?: string | null
}[]
```
</Accordion>
</AccordionGroup>
