## Accounts

### create

`accounts.create`

Create an account with a type and an opening balance, given in milliunits

**Risk:** `write`

```ts
await corsair.ynab.api.accounts.create({ budgetId: 'last-used', name: 'Checking', type: 'checking', balance: 1234560 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `budgetId` | `string` | Yes | The budget id, or `last-used` for the one most recently opened. |
| `name` | `string` | Yes | — |
| `type` | `checking \| savings \| cash \| creditCard \| otherAsset \| otherLiability` | Yes | — |
| `balance` | `number` | Yes | An amount in milliunits: the currency value times 1,000. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  account?: {
    id?: string | null,
    name?: string | null,
    type?: string | null,
    on_budget?: boolean | null,
    closed?: boolean | null,
    note?: string | null,
    balance?: number | null,
    cleared_balance?: number | null,
    uncleared_balance?: number | null,
    transfer_payee_id?: string | null,
    deleted?: boolean | null
  } | null
}
```
</Accordion>
</AccordionGroup>
