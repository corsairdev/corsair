Use **Retell AI** through Corsair: one client, typed API calls, local DB sync.

- **Lists are summaries.** `calls.list` and `chats.list` omit transcripts; call `calls.get` or `chats.get` for the transcript, recording and analysis. Only the `get` operations save records locally.
- **Paging.** Pass the returned `pagination_key` back as `paginationKey` while `has_more` is true. Set `includeTotal: true` to get `total` (Retell runs an extra count query for it).

**What you get:**

- 4 typed API operations
- 2 synced entities (`calls`, `chats`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/retellai better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/retellai better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/retellai better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/retellai better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { retellai } from '@corsair-dev/retellai';

export const corsair = createCorsair({
	plugins: [
		retellai(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Retell AI API key before the first call: `pnpm corsair setup --plugin=retellai --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
retellai()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'retellai',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List ended calls**

```ts
const tenant = corsair.withTenant('acme');
await tenant.retellai.api.calls.list({
	limit: 50,
	filterCriteria: {
		call_status: {
			type: 'enum',
			op: 'in',
			value: ['ended'],
		},
	},
});
```

## Query synced data

Calls fetched with `calls.get` are kept locally.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.retellai.db.calls.search({
	data: { call_status: 'ended' },
	limit: 20,
});
```

Synced entities: `calls`, `chats`. See [Database](/plugins/retellai/database) for filters and operators.
