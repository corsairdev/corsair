## Calls

### get

`calls.get`

Retrieve a call with its transcript, recording, and post-call analysis.

**Risk:** `read`

```ts
await corsair.retellai.api.calls.get({ id: 'call-id' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | - |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `call_id` | `string` | Yes | - |
| `call_type` | `string` | No | - |
| `agent_id` | `string` | No | - |
| `call_status` | `string` | No | - |
| `start_timestamp` | `number` | No | - |
| `end_timestamp` | `number` | No | - |
| `direction` | `string` | No | - |
| `from_number` | `string` | No | - |
| `to_number` | `string` | No | - |
| `disconnection_reason` | `string` | No | - |
| `metadata` | `object` | No | - |
| `transcript` | `string` | No | - |
| `transcript_object` | `object[]` | No | - |
| `transcript_with_tool_calls` | `object[]` | No | - |
| `scrubbed_transcript_with_tool_calls` | `object[]` | No | - |
| `recording_url` | `string` | No | - |
| `call_analysis` | `object` | No | - |
| `retell_llm_dynamic_variables` | `object` | No | - |

### list

`calls.list`

List Retell calls with filters and cursor pagination.

**Risk:** `read`

```ts
await corsair.retellai.api.calls.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `filterCriteria` | `object` | No | - |
| `limit` | `number` | No | - |
| `paginationKey` | `string` | No | - |
| `sortOrder` | `ascending \| descending` | No | - |
| `enableTotal` | `boolean` | No | - |
