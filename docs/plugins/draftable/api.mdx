## Comparisons

### create

`comparisons.create`

Compare two documents given by URL (PDF, Word, PowerPoint, RTF or text). Uses one comparison from the plan quota.

**Risk:** `destructive`

```ts
await corsair.draftable.api.comparisons.create({ identifier: 'contract-v1-v2', left: { source_url: 'https://example.com/contract-v1.pdf', file_type: 'pdf', display_name: 'v1' }, right: { source_url: 'https://example.com/contract-v2.docx', file_type: 'docx' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `left` | `object` | Yes | The original document. |
| `right` | `object` | Yes | The new document. |
| `identifier` | `string` | No | Your own unique id for the comparison. Draftable makes one when omitted. |
| `public` | `boolean` | No | Let anyone with the viewer link see it. Default false (signed links only). |
| `expiry_time` | `string` | No | ISO-8601 time after which Draftable deletes the comparison. |

### delete

`comparisons.delete`

Delete a comparison and its documents from Draftable.

**Risk:** `destructive`

```ts
await corsair.draftable.api.comparisons.delete({ identifier: 'contract-v1-v2' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `identifier` | `string` | Yes | Comparison identifier from comparisons.list or comparisons.create. |

Draftable answers a successful delete with an empty 204; the operation then returns `{ identifier, deleted: true }`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `identifier` | `string` | Yes | — |
| `deleted` | `true` | Yes | — |

### getViewerUrl

`comparisons.getViewerUrl`

Get a link to view a comparison in the Draftable viewer, signed for a limited time unless the comparison is public.

**Risk:** `read`

```ts
await corsair.draftable.api.comparisons.getViewerUrl({ identifier: 'contract-v1-v2', valid_for_minutes: 60 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `identifier` | `string` | Yes | Comparison identifier from comparisons.list or comparisons.create. |
| `valid_for_minutes` | `number` | No | How long a signed link stays valid. Default 30 minutes. Ignored for public comparisons. |
| `wait` | `boolean` | No | Show a loading page until the comparison is ready instead of an error. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `identifier` | `string` | Yes | — |
| `url` | `string` | Yes | — |
| `signed` | `boolean` | Yes | — |
| `valid_until` | `string \| null` | Yes | — |

## Exports

### create

`exports.create`

Start a PDF export of a comparison. Poll exports.get until ready, then download its url.

**Risk:** `write`

```ts
await corsair.draftable.api.exports.create({ comparison: 'contract-v1-v2', kind: 'combined', include_cover_page: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `comparison` | `string` | Yes | Comparison identifier from comparisons.list or comparisons.create. |
| `kind` | `single_page \| combined \| left \| right` | Yes | single_page: both documents on one page; combined: the comparison with change details; left or right: one document with its changes highlighted. |
| `include_cover_page` | `boolean` | No | Add a summary cover page (combined exports). |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `identifier` | `string` | Yes | — |
| `comparison` | `string \| null` | No | — |
| `kind` | `string \| null` | No | — |
| `ready` | `boolean \| null` | No | — |
| `failed` | `boolean \| null` | No | — |
| `url` | `string \| null` | No | — |
| `error_message` | `string \| null` | No | — |
| `include_cover_page` | `boolean \| null` | No | — |
