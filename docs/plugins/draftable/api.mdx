## Comparisons

### list

`comparisons.list`

Paginated list of document comparisons.

**Risk:** `read`

```ts
await corsair.draftable.api.comparisons.list({ limit: 20, offset: 0 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | Page size. |
| `offset` | `number` | No | Number of comparisons to skip. |

Omit limit or offset to take the service default. The call does not create a comparison.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `count` | `number` | Yes | — |
| `results` | `object[]` | Yes | — |
