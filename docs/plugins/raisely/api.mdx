### list

`campaigns.list`

List the organisation’s campaigns with path, mode and status filters plus offset paging

**Risk:** `read`

```ts
await corsair.raisely.api.campaigns.list({ status: 'ACTIVE', limit: 100, sort: 'createdAt', order: 'desc' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | Records per page. Raisely applies its own default when omitted. |
| `offset` | `number` | No | Records to skip. Pass the `next_offset` from the previous page rather than computing it. |
| `q` | `string` | No | A search phrase. |
| `sort` | `string` | No | The attribute to sort on, used with `order`. |
| `order` | `asc \| desc` | No | The sort direction; only applied when `sort` is also set. |
| `private` | `boolean` | No | Return the full record. Only meaningful with a token that can see private fields. |
| `path` | `string` | No | Only the campaign with this path. |
| `mode` | `string` | No | The campaign mode. |
| `status` | `string` | No | The campaign status. |
| `prune_config` | `boolean` | No | Drop `config` from each record to shrink the response. |
| `include_tags` | `boolean` | No | — |

`order` is only sent when `sort` is also set, because Raisely ignores it alone.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaigns` | `object[]` | Yes | — |
| `pagination` | `object \| null` | No | — |
| `next_offset` | `number \| null` | Yes | Pass as `offset` to read the next page; null on the last. |
| `total` | `number \| null` | Yes | — |

## Donations

### create

`donations.create`

Record a donation for a campaign, with the donor details and the gateway it came through

**Risk:** `write`

```ts
await corsair.raisely.api.donations.create({ amount: 2500, currency: 'USD', email: 'jordan@example.com', method: 'CREDIT_CARD', type: 'OFFLINE', campaign_uuid: 'aaaaaaaa-aaaa-aaaa-aaaa-aaaaaaaaaaaa' });
```

| `method` | `string` | Yes | The payment gateway, such as `CREDIT_CARD`, `PAYPAL` or `APPLE_PAY`. |

| `campaign_uuid` | `string` | No | The campaign the donation belongs to. |

| `firstName` | `string` | No | — |
| `lastName` | `string` | No | — |
| `fullName` | `string` | No | — |
| `preferredName` | `string` | No | — |
| `message` | `string` | No | — |
| `anonymous` | `boolean` | No | — |
| `date` | `string` | No | An ISO 8601 timestamp. |
| `country` | `string` | No | — |

| `address1` | `string` | No | — |
| `address2` | `string` | No | — |
| `phoneNumber` | `string` | No | — |
| `mode` | `LIVE \| TEST` | No | — |
| `designation` | `string` | No | The designation uuid to attribute the donation to. |
| `public` | `Record<string, string \| number \| boolean \| Record<string, string \| number \| boolean \| null> \| null> \| null` | No | — |
| `private` | `Record<string, string \| number \| boolean \| Record<string, string \| number \| boolean \| null> \| null> \| null` | No | — |
