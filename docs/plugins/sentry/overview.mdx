Use **Sentry** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 25 typed API operations
- 7 synced entities (`comments`, `events`, `issues`, `organizations`, `projects`, `releases`, and 1 more) for fast `.search()` / `.list()`
- 9 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/sentry
```
```bash yarn
yarn add corsair @corsair-dev/sentry
```
```bash pnpm
pnpm install corsair @corsair-dev/sentry
```
```bash bun
bun add corsair @corsair-dev/sentry
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { sentry } from '@corsair-dev/sentry';

export const corsair = createCorsair({
	plugins: [
		sentry(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

Provider walkthrough: [Get Credentials](/plugins/sentry/get-credentials).

```ts
sentry()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'sentry',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`events.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.sentry.api.events.get({});
```


**`issues.delete`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.sentry.api.issues.delete({});
```


See the full list on the [API](/plugins/sentry/api) page.

## Query synced data

Synced entities support `tenant.sentry.db.<entity>.search()` and `.list()`: `comments`, `events`, `issues`, `organizations`, `projects`, `releases`, `teams`.

See [Database](/plugins/sentry/database) for filters and operators.

## Webhooks

This plugin registers **9** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/sentry/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
