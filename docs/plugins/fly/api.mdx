## Apps

### create

`apps.create`

Create an app in an organization. The app costs nothing until it has Machines or volumes.

**Risk:** `write`

```ts
await corsair.fly.api.apps.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Globally unique app name |
| `org_slug` | `string` | Yes | Organization slug, or 'personal' for your personal organization |
| `network` | `string` | No | Private network to attach the app to; defaults to the org default |
| `enable_subdomains` | `boolean` | No | — |
| `idempotency_key` | `string` | No | Makes a retry of the same create return the same app |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `created_at` | `number \| null` | No | — |
