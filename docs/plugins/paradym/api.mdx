## Credential Templates

### archive

`credentialTemplates.archive`

Archive an SD-JWT VC credential template

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.paradym.api.credentialTemplates.archive({ credentialTemplateId: "tmpl_1" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `credentialTemplateId` | `string` | Yes | Template id |

Archived templates can be restored with credentialTemplates.unarchive.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Archived template id |
| `success` | `boolean` | Yes | Whether the archive succeeded |

### create

`credentialTemplates.create`

Create an SD-JWT VC credential template with its attributes

**Risk:** `write`

```ts
await corsair.paradym.api.credentialTemplates.create({ type: "urn:eudi:pid:1", name: "PID", attributes: { given_name: { name: "given_name", required: true } }, revocable: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `string` | Yes | Credential type identifier, e.g. urn:eudi:pid:1 |
| `name` | `string` | Yes | Template name |
| `attributes` | `object` | Yes | Credential attributes keyed by attribute name |
| `revocable` | `boolean` | No | Enable revocation for credentials from this template |
| `validFrom` | `string \| object` | No | A date, e.g. 2026-11-21, or &#123; future: &#123; days, months, years &#125; &#125; |
| `validUntil` | `string \| object` | No | A date, or &#123; start: issuance \| validFrom, future: &#123; days, months, years &#125; &#125; |

The attributes object is keyed by attribute name; Paradym validates its contents, including the credential type identifier.

<AccordionGroup>
<Accordion title="attributes full type">

```ts
Record<string, {
}>
```
</Accordion>

<Accordion title="validFrom full type">

```ts
string | {
  future: {
    days?: number,
    months?: number,
    years?: number
  }
}
```
</Accordion>

<Accordion title="validUntil full type">

```ts
string | {
  start: issuance | validFrom,
  future: {
    days?: number,
    months?: number,
    years?: number
  }
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Template id |
| `walletId` | `string \| null` | No | Wallet the template belongs to |
| `name` | `string \| null` | No | Template name |
| `description` | `string \| null` | No | Template description |
| `format` | `string \| null` | No | Credential format |
| `revocable` | `boolean \| null` | No | Whether credentials from this template can be revoked |
| `archived` | `boolean \| null` | No | Whether the template is archived |
| `createdAt` | `string \| null` | No | Creation timestamp |
| `updatedAt` | `string \| null` | No | Last modification timestamp |

## Issuance

### createOffer

`issuance.createOffer`

Create a credential offer a holder wallet can accept

**Risk:** `write`

```ts
await corsair.paradym.api.issuance.createOffer({ credentials: [{ credentialTemplateId: "tmpl_1", attributes: { given_name: "Jane" } }], expirationInMinutes: 15 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `credentials` | `object[]` | Yes | The credentials to be issued in this offer |
| `expirationInMinutes` | `number` | No | Minutes until the offer expires |

The answer carries the offer URI, QR image and deep link a holder wallet opens; the session stays open until the wallet completes it.

<AccordionGroup>
<Accordion title="credentials full type">

```ts
{
  credentialTemplateId: string,
  attributes?: Record<string, any>
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Issuance session id |
| `status` | `string` | Yes | Session status, e.g. offered, completed, failed, expired |
| `offerUri` | `string \| null` | No | Credential offer URI a wallet opens |
| `offerQrUri` | `string \| null` | No | QR image of the offer |
| `offerDeeplinkUri` | `string \| null` | No | Deep link of the offer |
| `offerDeeplinkQrUri` | `string \| null` | No | QR image of the deep link |
| `expiresAt` | `string \| null` | No | When the offer expires |
| `createdAt` | `string \| null` | No | Creation timestamp |
| `updatedAt` | `string \| null` | No | Last modification timestamp |
