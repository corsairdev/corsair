Use **All Images AI** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 7 typed API operations
- 3 synced entities (`downloadedImages`, `imageGenerations`, `webhooks`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/allimagesai
```
```bash yarn
yarn add corsair @corsair-dev/allimagesai
```
```bash pnpm
pnpm install corsair @corsair-dev/allimagesai
```
```bash bun
bun add corsair @corsair-dev/allimagesai
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { allimagesai } from '@corsair-dev/allimagesai';

export const corsair = createCorsair({
	plugins: [
		allimagesai(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
allimagesai()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'allimagesai',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`apiKeys.check`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.allimagesai.api.apiKeys.check({});
```


**`imageGenerations.delete`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.allimagesai.api.imageGenerations.delete({});
```


See the full list on the [API](/plugins/allimagesai/api) page.

## Query synced data

Synced entities support `tenant.allimagesai.db.<entity>.search()` and `.list()`: `downloadedImages`, `imageGenerations`, `webhooks`.

See [Database](/plugins/allimagesai/database) for filters and operators.
