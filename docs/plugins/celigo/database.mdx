The Celigo plugin syncs data locally. Use `corsair.celigo.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Connections

Path: `celigo.db.connections.search`

```ts
const rows = await corsair.celigo.db.connections.search({
    data: { /* filters below */ },
```
