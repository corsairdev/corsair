### tokens.create

`account.tokens.create`

Create an API token, optionally restricted to one billing account

**Risk:** `write`

```ts
await corsair.pilvio.api.account.tokens.create({ description: "ci token", billingAccountId: 6, restricted: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `description` | `string` | No | Token description |
| `billingAccountId` | `number` | No | Binds the token to one billing account (restricted) |
| `restricted` | `boolean` | No | Restrict the token to billingAccountId |

Set restricted with billingAccountId to bind the token to one billing account; the token value is answered once and never logged by the plugin.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number \| null` | No | Token id |
| `token` | `string \| null` | No | The API token value |
| `description` | `string \| null` | No | Token description |
| `restricted` | `boolean \| null` | No | Whether the token is bound to one billing account |
| `billing_account_id` | `number \| null` | No | Billing account a restricted token is bound to |
| `user_id` | `number \| null` | No | Owner user id |
| `consumer_id` | `string \| null` | No | Gateway consumer id |
| `kong_id` | `string \| null` | No | Gateway token id |
| `created_at` | `string \| null` | No | Creation timestamp |
| `updated_at` | `string \| null` | No | Last update timestamp |

## Network

### firewalls.create

`network.firewalls.create`

Create a firewall with rules

**Risk:** `write`

```ts
await corsair.pilvio.api.network.firewalls.create({ displayName: "Database Firewall", rules: [{ protocol: "tcp", direction: "inbound", portStart: 3306, portEnd: 3306, endpointSpecType: "ip_prefixes", endpointSpec: ["10.0.0.0/24"] }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `displayName` | `string` | Yes | Firewall name |
| `billingAccountId` | `number` | No | Billing account |
| `rules` | `object[]` | Yes | The firewall rules |

Rules take protocol tcp/udp/icmp, direction inbound/outbound, a port range and endpointSpecType ip_prefixes (with CIDR list) or any.

<AccordionGroup>
<Accordion title="rules full type">

```ts
{
  protocol: tcp | udp | icmp,
  direction: inbound | outbound,
  portStart?: number,
  portEnd?: number,
  endpointSpecType: ip_prefixes | any,
  endpointSpec?: string[]
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `uuid` | `string \| null` | No | Firewall UUID |
| `display_name` | `string \| null` | No | Firewall name |
| `billing_account_id` | `number \| null` | No | Billing account id |
| `rules` | `object[] \| null` | No | Firewall rules |
| `resources_assigned` | `any[] \| null` | No | Resources the firewall is assigned to |
| `user_id` | `number \| null` | No | Owner user id |
| `created_at` | `string \| null` | No | Creation timestamp |
| `deleted_at` | `string \| null` | No | Deletion timestamp |

<AccordionGroup>
<Accordion title="rules full type">

```ts
{
  uuid?: string | null,
  protocol?: tcp | udp | icmp | null,
  direction?: inbound | outbound | null,
  port_start?: number | null,
  port_end?: number | null,
  endpoint_spec_type?: ip_prefixes | any | null,
  endpoint_spec?: string[] | null
```

### disks.create

`storage.disks.create`

Create a disk from empty, an OS image, a disk or a snapshot

**Risk:** `write`

```ts
await corsair.pilvio.api.storage.disks.create({ sizeGb: 50, sourceImageType: "EMPTY", displayName: "DB data" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
