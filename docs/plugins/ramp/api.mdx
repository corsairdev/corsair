### list

`bills.list`

List bills with filters for vendor, status, approval, payment and date ranges, plus cursor paging

**Risk:** `read`

```ts
await corsair.ramp.api.bills.list({ status_summaries: ['AWAITING_PAYMENT'], from_due_date: '2026-05-01T00:00:00Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `vendor_id` | `string` | No | — |
| `entity_id` | `string` | No | — |
| `invoice_number` | `string` | No | — |
| `status_summaries` | `(APPROVAL_PENDING \| APPROVAL_REJECTED \| ARCHIVED \| AWAITING_PAYMENT \| AWAITING_RELEASE \| BLOCKED \| HELD_BY_PROVIDER \| ON_HOLD \| PAYMENT_COMPLETED \| PAYMENT_DETAILS_MISSING \| PAYMENT_ERROR \| PAYMENT_NOT_INSTRUCTED \| PAYMENT_PROCESSING \| PAYMENT_READY \| PAYMENT_SCHEDULED \| PENDING_VENDOR_APPROVAL \| WAITING_FOR_TRANSACTION_MATCH \| WAITING_FOR_TRANSFER_MATCH \| WAITING_FOR_VENDOR)[]` | No | Sent as a comma-separated list. |
| `approval_status` | `APPROVED \| INITIALIZED \| PENDING \| REJECTED \| TERMINATED` | No | — |
| `payment_status` | `OPEN \| PAID` | No | — |
| `sync_status` | `BILL_AND_PAYMENT_SYNCED \| BILL_SYNCED \| NOT_SYNCED` | No | — |
| `is_archived` | `boolean` | No | Show archived bills instead of active ones. |
| `sync_ready` | `boolean` | No | — |
| `payment_details_missing` | `boolean` | No | — |
| `from_created_at` | `string` | No | — |
| `to_created_at` | `string` | No | — |
| `from_due_date` | `string` | No | — |
| `to_due_date` | `string` | No | — |
| `from_paid_at` | `string` | No | — |
| `to_paid_at` | `string` | No | — |
| `min_amount` | `string \| number` | No | A decimal amount, as a string or a number. |
| `max_amount` | `string \| number` | No | A decimal amount, as a string or a number. |
| `start` | `string` | No | The id of the last record on the previous page. Read it from `next_cursor`, and keep the same filters: the id is only meaningful for the query that produced it. |
| `page_size` | `number` | No | Results per page, 2 to 100. Defaults to 20 when omitted. |

`status_summaries` is sent as a comma-separated list; Ramp rejects a value outside the documented set.



**Output**

| Name | Type | Required | Description |

| `next_cursor` | `string \| null` | Yes | Pass as `start` to read the next page. Null once `page.next` is null. |
| `next_page_url` | `string \| null` | Yes | The absolute `page.next` URL, for callers that prefer it. |
| `total_count` | `number \| null` | No | — |
| `total_count_capped` | `boolean \| null` | No | — |
