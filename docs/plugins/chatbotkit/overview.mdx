Use **ChatBotKit** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 43 typed API operations
- 8 synced entities (`blueprints`, `bots`, `conversations`, `datasets`, `files`, `secrets`, and 2 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/chatbotkit
```
```bash yarn
yarn add corsair @corsair-dev/chatbotkit
```
```bash pnpm
pnpm install corsair @corsair-dev/chatbotkit
```
```bash bun
bun add corsair @corsair-dev/chatbotkit
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { chatbotkit } from '@corsair-dev/chatbotkit';

export const corsair = createCorsair({
	plugins: [
		chatbotkit(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
chatbotkit()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'chatbotkit',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`blueprints.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.chatbotkit.api.blueprints.get({});
```


**`blueprints.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.chatbotkit.api.blueprints.create({});
```


See the full list on the [API](/plugins/chatbotkit/api) page.

## Query synced data

Synced entities support `tenant.chatbotkit.db.<entity>.search()` and `.list()`: `blueprints`, `bots`, `conversations`, `datasets`, `files`, `secrets`, `skillsets`, `tasks`.

See [Database](/plugins/chatbotkit/database) for filters and operators.
