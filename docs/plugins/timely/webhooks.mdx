The Timely plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/timely/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `projects`
  - `created` (`projects.created`)
  - `deleted` (`projects.deleted`)
  - `updated` (`projects.updated`)
- `tags`
  - `created` (`tags.created`)
  - `deleted` (`tags.deleted`)
  - `updated` (`tags.updated`)
- `tasks`
  - `created` (`tasks.created`)
  - `deleted` (`tasks.deleted`)
  - `updated` (`tasks.updated`)
- `timeEntries`
  - `created` (`timeEntries.created`)
  - `deleted` (`timeEntries.deleted`)
  - `updated` (`timeEntries.updated`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

### Created

`projects.created`

A project was created

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event` | `string` | Yes | — |
| `payload` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="payload full type">

```ts
{
  entity_id: number | string,
  entity_type: string,
  entity_path?: string | null,
  entity_external_id?: string | null,
  updated_from?: string | null,
  updated_at?: string | null,
  status?: string | null,
  date?: string | null
}
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  event: string,
  payload: {
    entity_id: number | string,
    entity_type: string,
    entity_path?: string | null,
    entity_external_id?: string | null,
    updated_from?: string | null,
    updated_at?: string | null,
    status?: string | null,
    date?: string | null
  }
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
timely({
    webhookHooks: {
        projects: {
            created: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
