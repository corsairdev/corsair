## Cryptocurrency

### info

`cryptocurrency.info`

Static metadata for a cryptocurrency, such as its description, logo, website and social links, by CMC ID, slug, ticker or contract address

**Risk:** `read`

```ts
await corsair.coinmarketcap.api.cryptocurrency.info({ id: ['1'], aux: 'description,logo,urls' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string[]` | No | CoinMarketCap IDs, such as ["1", "1027"]. |
| `slug` | `string[]` | No | Slugs, such as ["bitcoin"]. |
| `symbol` | `string[]` | No | Tickers, such as ["BTC"]. |
| `address` | `string` | No | A contract address, when the asset is a token. |
| `skip_invalid` | `boolean` | No | Skip unknown identifiers instead of failing the whole call. |
| `aux` | `string` | No | Comma-separated supplemental fields: urls, logo, description, tags, platform, date_added, notice, status. |

Pass exactly one of `id`, `slug`, `symbol` or `address`. A token's `platform.id` is a string on this route and a number on the others.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `cryptocurrencies` | `object[]` | Yes | — |
| `status` | `object` | No | — |

### listings

`cryptocurrency.listings`

Rank every active cryptocurrency by market cap, price, volume or a percent change, with price, market cap and volume filters, paging and up to 120 quote currencies

**Risk:** `read`

```ts
await corsair.coinmarketcap.api.cryptocurrency.listings({ limit: 10, sort: 'market_cap', sort_dir: 'desc' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `start` | `number` | No | 1-based index of the first result. Defaults to 1. |
| `limit` | `number` | No | How many results to return. Defaults to 100; the maximum is 5000. Each 250 results costs one credit. |
| `price_min` | `number` | No | Minimum USD price. |
| `price_max` | `number` | No | Maximum USD price. |
| `market_cap_min` | `number` | No | Minimum market cap in USD. |
| `market_cap_max` | `number` | No | Maximum market cap in USD. |
| `volume_24h_min` | `number` | No | Minimum rolling 24 hour USD volume. |
| `volume_24h_max` | `number` | No | Maximum rolling 24 hour USD volume. |
| `circulating_supply_min` | `number` | No | — |
| `circulating_supply_max` | `number` | No | — |
| `percent_change_24h_min` | `number` | No | Minimum 24 hour percent change, so -50 for a 50% drop. |
| `percent_change_24h_max` | `number` | No | — |
| `convert` | `string[]` | No | Quote currencies by symbol, such as ["USD"] or ["USD", "EUR"]. Each one past the first costs an extra credit, and a plan may cap how many it allows. |
| `convert_id` | `string[]` | No | Quote currencies by CMC ID instead of symbol. Cannot be combined with `convert`. |
| `sort` | `market_cap \| market_cap_strict \| name \| symbol \| date_added \| price \| circulating_supply \| total_supply \| max_supply \| num_market_pairs \| market_cap_by_total_supply_strict \| volume_24h \| volume_7d \| volume_30d \| percent_change_1h \| percent_change_24h \| percent_change_7d` | No | Field to sort by. Defaults to market_cap. |
| `sort_dir` | `asc \| desc` | No | Sort direction. Defaults to desc. |
| `cryptocurrency_type` | `all \| coins \| tokens` | No | Limit the result to coins, tokens or both. Defaults to all. |
| `tag` | `string` | No | Only assets carrying this tag, such as "defi" or "layer-2". |
| `aux` | `string` | No | Comma-separated supplemental fields, for example "platform,first_historical_data". |



**Output**

### map

`cryptocurrency.map`

Resolve tickers, or a page of the full asset list, to the stable CoinMarketCap IDs, names and slugs that every other call takes; it has no slug filter

**Risk:** `read`

```ts
await corsair.coinmarketcap.api.cryptocurrency.map({ symbol: ['BTC', 'ETH'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `listing_status` | `(active \| inactive \| untracked)[]` | No | Which listing statuses to include. Defaults to active. |
| `start` | `number` | No | 1-based index of the first result. Defaults to 1. |
| `limit` | `number` | No | How many results to return. Defaults to every match; the maximum is 5000. |
| `sort` | `cmc_rank \| id` | No | Field to sort by. Defaults to id. |
| `symbol` | `string[]` | No | Tickers to resolve to CMC IDs, such as ["BTC", "ETH"]. When set, the API ignores every other option except `aux`. |
| `aux` | `string` | No | Comma-separated supplemental fields: platform, first_historical_data, last_historical_data, is_active, status. |

When `symbol` is set, CoinMarketCap ignores `listing_status`, `start`, `limit` and `sort`, so this operation rejects those combinations rather than sending a request that would silently return the wrong rows. `aux` still applies with `symbol`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `cryptocurrencies` | `object[]` | Yes | — |
| `status` | `object` | No | — |

## Tools

### priceConversion

`tools.priceConversion`

Convert an amount of one currency into another, optionally at a past timestamp; a ticker shared by several assets returns one result per asset

**Risk:** `read`

```ts
await corsair.coinmarketcap.api.tools.priceConversion({ amount: 10.43, symbol: 'BTC', convert: ['USD'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `amount` | `number` | Yes | How much of the source currency to convert, such as 1.5. |
| `id` | `number` | No | The source currency CMC ID. CoinMarketCap takes exactly one ID here, not a list. |
| `symbol` | `string` | No | The source currency ticker. When several assets share it, one result per asset is returned. |
| `time` | `string` | No | A Unix or ISO 8601 timestamp to convert at. Defaults to now. |
| `convert` | `string[]` | No | Target currencies by symbol, such as ["USD"]. |
| `convert_id` | `string[]` | No | Target currencies by CMC ID. Cannot be combined with `convert`. |

Pass exactly one of `id` or `symbol`, and pass `id` as a single number: the route refuses a comma-separated list here even though the quote routes accept one. A `symbol` lookup returns every asset sharing the ticker, and `price` is null for one CoinMarketCap has no price for.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `conversions` | `object[]` | Yes | — |
