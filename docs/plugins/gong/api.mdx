## Accounts Enrich

**Risk:** `read`

```ts
await corsair.gong.api.accountsEnrich.getResults({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `jobId` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `requestId` | `string` | Yes | — |
| `accounts` | `object[]` | Yes | — |
| `summary` | `Record<string, any>` | Yes | — |

<AccordionGroup>
<Accordion title="accounts full type">

```ts
{
  id: string,
  matched: boolean,
  dataCategories?: {
    dataCategory?: string,
    status?: string,
    enriched?: boolean,
    data?: Record<string, any> | null

}[]
```
</Accordion>
</AccordionGroup>
