## Attachments

### create

`attachments.create`

Create a contest or a social unlock

**Risk:** `write`


## Campaigns

### create

`campaigns.create`

Create an ad campaign on Facebook or Google; creating one can start spend, so review the body before calling

**Risk:** `write`

```ts
await corsair.toneden.api.campaigns.create({ title: 'Spring tour', target_type: 'link', target: 'https://toneden.io/ada/new-single' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `title` | `string` | No | — |
| `status` | `string` | No | — |
| `target_type` | `string` | No | — |
| `target` | `string` | No | — |

Creates a real campaign on Facebook or Google. ToneDen documents no required field, so pass the targeting and creative fields the campaign type needs.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ad_campaign` | `object` | Yes | — |
