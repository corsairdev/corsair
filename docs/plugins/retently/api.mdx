
| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | 1-based, defaults to 1. |

| `sort` | `string` | No | Field to sort by; prefix with - for descending, such as -createdDate. |

| `attributes` | `object[]` | No | Property filters. The operators allowed depend on the property type. |
| `match` | `all \| any` | No | How to combine several attributes: all (AND, default) or any (OR). |
