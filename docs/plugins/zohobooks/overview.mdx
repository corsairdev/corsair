Use **Zoho Books** through Corsair: one client, typed API calls.

Zoho Books uses regional data centers. Supported region values are us (default), eu, in, au, jp, ca, sa, ae, and cn. API calls go to www.zohoapis.&lt;domain&gt;/books/v3 and sign-in to the matching accounts host (accounts.zohocloud.ca for Canada, accounts.zoho.com.cn for China, as the Books OAuth guide's domain table lists). Each plugin instance has one supported region, so configure the Zoho OAuth client for that data center or use shared client credentials with Zoho multi-DC enabled. Access tokens use Authorization: Zoho-oauthtoken &lt;token&gt;, expire after one hour, and offline consent provides a refresh token. The plugin requests all 81 OAuth scopes present in the included operation contracts. A connection granted only a subset may receive 403 responses for operations outside those scopes.

Most resource operations require query.organization_id; discover IDs with organizations.listOrganizations. Operations whose route contains &#123;organization_id&#125; take it in pathParams. Organization discovery/creation and user organization lookup routes are unscoped. Pass page and per_page as documented; the plugin makes one request per call and does not auto-follow pages. Zoho documents 200 records as the generic pagination default, while operation-specific OpenAPI defaults may differ.

Zoho documents 100 API calls per minute per organization, plus plan-specific daily quotas and concurrent-call limits. Recoverable HTTP 429 responses are retried once with Retry-After; daily-quota code 45 is not retried.

Binary downloads return &#123; kind: binary, contentType, base64, byteLength &#125;; responses over 10 MiB are rejected. Binary upload inputs accept &#123; filename, contentType, base64 &#125;. Fields that Zoho lists under Query Parameters are removed from the URL and transmitted as multipart form-data parts. When a JSON request accompanies a file, its non-file fields are sent in the JSONString form-data part; multipart boundaries are generated by fetch. The official OpenAPI bundle documents 885 REST operations; 884 are implemented. The all_tag_options route is excluded because its path has a numeric regex segment while tag_id is defined only as a query parameter and no matching path parameter is documented. Region and edition availability annotations are retained but are not enforced locally. No webhook handlers are registered.

**What you get:**

- 884 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/zohobooks better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/zohobooks better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/zohobooks better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/zohobooks better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { zohobooks } from '@corsair-dev/zohobooks';

export const corsair = createCorsair({
	plugins: [
		zohobooks(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="OAuth 2.0 (Recommended)">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Zoho Books OAuth app.

```ts
zohobooks()
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'zohobooks',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`bankAccounts.getBankAccount`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.zohobooks.api.bankAccounts.getBankAccount({});
```


**`bankAccounts.addBankReconciliationAttachment`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.zohobooks.api.bankAccounts.addBankReconciliationAttachment({});
```
