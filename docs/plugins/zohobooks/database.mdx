---
title: "Zoho Books database"
sidebarTitle: "Database"
description: "The Zoho Books plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Zoho Books. To read its data, call the [API operations](/plugins/zohobooks/api), which return what Zoho Books has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
