The Updown.io plugin syncs data locally. Use `corsair.updownio.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Check Domain

Path: `updownio.db.checkDomain.search`

```ts
const rows = await corsair.updownio.db.checkDomain.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `tested_at` | `string` | equals, contains, startsWith, endsWith, in |
| `expires_at` | `string` | equals, contains, startsWith, endsWith, in |
| `remaining_days` | `number` | equals, gt, gte, lt, lte, in |
| `source` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
