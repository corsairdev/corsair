## Accounts

### get

`accounts.get`

Read one account, optionally expanding its environments with their region and primary flag

**Risk:** `read`

```ts
await corsair.userflow.api.accounts.get({ id: '3f2a4b56-7c8d-9e0f-1a2b-3c4d5e6f7a8b', expand: 'environments' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `expand` | `string` | No | Relationships to expand, e.g. `memberships.group`. Dot-separated, at most four levels. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `object` | `account \| null` | No | — |
| `name` | `string \| null` | No | — |
| `slug` | `string \| null` | No | — |
| `created_at` | `string \| null` | No | — |
| `is_2fa_enforced` | `boolean \| null` | No | — |
| `environments` | `object[] \| null` | No | — |

## Events

### track

`events.track`

Record an event against a user, a group or both, optionally with attributes and a past timestamp

**Risk:** `write`

```ts
await corsair.userflow.api.events.track({ name: 'subscription_activated', user_id: '2a845972-4cde-4cb4-ba14-5cb2fc15ec4c', attributes: { plan_name: 'plus', plan_price: 199 } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | The event name, such as `subscription_activated`. Letters, digits, underscores, dashes, dots, parentheses and spaces only. |
| `user_id` | `string` | No | The user who did it. At least one of user_id and group_id is required. |
| `group_id` | `string` | No | The group it happened in. At least one of user_id and group_id is required. |
| `attributes` | `Record<string, string \| number \| boolean \| Record<string, any> \| string[] \| null>` | No | Attributes of the event itself, such as a plan name or price. |
| `time` | `string` | No | ISO 8601 when it happened, for importing historic events. Defaults to now. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `object` | `event \| null` | No | — |
| `attributes` | `Record<string, any> \| null` | No | — |
| `created_at` | `string \| null` | No | — |
| `group_id` | `string \| null` | No | — |
| `user_id` | `string \| null` | No | — |
