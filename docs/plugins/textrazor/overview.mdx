Use **TextRazor** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 17 typed API operations
- 5 synced entities (`accounts`, `categories`, `dictionaries`, `dictionaryEntries`, `entities`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/textrazor
```
```bash yarn
yarn add corsair @corsair-dev/textrazor
```
```bash pnpm
pnpm install corsair @corsair-dev/textrazor
```
```bash bun
bun add corsair @corsair-dev/textrazor
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { textrazor } from '@corsair-dev/textrazor';

export const corsair = createCorsair({
	plugins: [
		textrazor(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
textrazor()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'textrazor',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`account.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.textrazor.api.account.get({});
```


**`classifiers.delete`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.textrazor.api.classifiers.delete({});
```


See the full list on the [API](/plugins/textrazor/api) page.

## Query synced data

Synced entities support `tenant.textrazor.db.<entity>.search()` and `.list()`: `accounts`, `categories`, `dictionaries`, `dictionaryEntries`, `entities`.

See [Database](/plugins/textrazor/database) for filters and operators.
