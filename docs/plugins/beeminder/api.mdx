## Charges

### create

`charges.create`

Create a charge against a Beeminder user. Use dryrun to preview.

**Risk:** `write`

```ts
const tenant = corsair.withTenant('acme');
await tenant.beeminder.api.charges.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `user_id` | `string` | Yes | — |
| `amount` | `number` | Yes | — |
| `note` | `string` | No | — |
| `dryrun` | `boolean` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `amount` | `number` | Yes | — |
| `note` | `string` | No | — |
| `username` | `string` | Yes | — |

## User

const tenant = corsair.withTenant('acme');

| `emaciated` | `boolean` | No | — |
| `datapoints_count` | `number` | No | — |
