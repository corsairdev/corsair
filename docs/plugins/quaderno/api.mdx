## Authorization

### authorization

`authorization`

Which account this key belongs to: `identity.href` is that account’s base URL, so this is how a caller finds the subdomain to pass as `account`. Also returns the default API version.

**Risk:** `read`

```ts
await corsair.quaderno.api.authorization({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `identity` | `object` | Yes | — |

```ts
  id?: number | string | null,

  email?: string | null,
  publishable_key?: string | null,
  href?: string | null,
  default_api_version?: number | null
}
```
</Accordion>

## Contacts

### create

`contacts.create`

Adds a customer. `first_name` is required, and holds the company name for a `company`. Give an `email` if documents will be delivered to this contact.

**Risk:** `write`

```ts
await corsair.quaderno.api.contacts.create({ first_name: "Amelia", last_name: "Chen", email: "amelia.chen@example.com", country: "US" });
```

| `last_name` | `string` | No | — |

### delete

`contacts.delete`

Removes a customer. Quaderno refuses with 422 while the contact still has documents attached, so invoices must be voided first. Answers 204 with no body.

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.quaderno.api.contacts.delete({ id: 78395726 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | The contact to delete. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deleted` | `true` | Yes | — |

## Credits

### create

`credits.create`

Issues a credit note against an existing invoice, by `invoice_id`, and records the refund. It credits the whole invoice unless `credited_amount` is given. It consumes a document number and cannot be deleted, only voided.

**Risk:** `write`

```ts
await corsair.quaderno.api.credits.create({ invoice_id: 181235103 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `invoice_id` | `number` | Yes | The invoice being credited. |
| `payment_method` | `credit_card \| cash \| wire_transfer \| direct_debit \| check \| iou \| paypal \| other` | No | How the credited amount is refunded. |
| `credited_amount` | `number` | No | Amount to credit in major units, at most the invoice total. Only works for an invoice with a single line. Defaults to the full invoice total. |

A credit note is issued against an invoice: pass `invoice_id`. It credits the full invoice unless `credited_amount` is set, which only works for an invoice with one line.

## Invoices

### create

`invoices.create`

Issues an invoice and **allocates a document number**, which is not recoverable: invoices cannot be deleted, only voided. Passing `payment_method` records a full payment immediately and marks it paid. Needs a `contact` id and at least one line item.

**Risk:** `write`

```ts
await corsair.quaderno.api.invoices.create({ contact: { id: 78395726 }, items: [{ description: "Consulting hour", unit_price: 150 }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contact` | `object` | Yes | The contact being billed, by id. Create one with contacts.create first. |
| `items` | `object[]` | Yes | Line items. Quaderno caps a document at 200 lines. |
| `currency` | `string` | No | — |
