Use **Bright Data** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 10 typed API operations
- 9 synced entities (`cities`, `countries`, `datasets`, `serpResults`, `snapshotProgress`, `snapshotRefs`, and 3 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/brightdata better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/brightdata better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/brightdata better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/brightdata better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { brightdata } from '@corsair-dev/brightdata';

export const corsair = createCorsair({
	plugins: [
		brightdata(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Bright Data API key before the first call: `pnpm corsair setup --plugin=brightdata --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
brightdata()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'brightdata',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`getAvailableCities`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.brightdata.api.getAvailableCities({});
```


**`crawlApi`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.brightdata.api.crawlApi({});
```


See the full list on the [API](/plugins/brightdata/api) page.

## Query synced data

Synced entities support `tenant.brightdata.db.<entity>.search()` and `.list()`: `cities`, `countries`, `datasets`, `serpResults`, `snapshotProgress`, `snapshotRefs`, `snapshotResults`, `unlockerResults`, `zones`.

See [Database](/plugins/brightdata/database) for filters and operators.
