Use **Inkbox** through Corsair: one client, typed API calls, and incoming webhooks.

Connect with an Inkbox API key (inkbox.ai/console → API keys). An organization admin key reaches every identity; a key scoped to one identity reaches only that identity (some routes, such as avatars, need the identity key). Phone numbers, more identities and custom domains need a paid Inkbox plan. For webhook events, give the plugin the identity's signing key (identities.signingKey.createOrRotate returns it once) as webhookSecret, and subscribe a URL with webhooks.subscriptions.create. Vault secrets are encrypted on the client with the vault key: the API stores and returns ciphertext only.

**What you get:**

- 455 typed API operations
- 8 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/inkbox better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/inkbox better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/inkbox better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/inkbox better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { inkbox } from '@corsair-dev/inkbox';

export const corsair = createCorsair({
	plugins: [
		inkbox(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Inkbox API key before the first call: `pnpm corsair setup --plugin=inkbox --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
inkbox()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'inkbox',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List the latest emails in an agent's inbox**

```ts
const tenant = corsair.withTenant('acme');
await tenant.inkbox.api.mail.messages.list({ email_address: 'support-agent@inkboxmail.com', limit: 20 });
```


**Send an email from an agent identity**

```ts
const tenant = corsair.withTenant('acme');
await tenant.inkbox.api.mail.messages.send({
	email_address: 'support-agent@inkboxmail.com',
	recipients: {
		to: ['ada@example.com'],
	},
	subject: 'Your order has shipped',
	body_text: 'Hi Ada, your order shipped today. Tracking: 1Z999AA10123456784.',
});
```


See the full list on the [API](/plugins/inkbox/api) page.

## Webhooks

This plugin registers **8** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/inkbox/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
