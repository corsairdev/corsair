---

Use **Parsera** through Corsair: one client, typed API calls.

Authenticate with an API key from the Parsera app; the plugin sends it in the `X-API-KEY` header. One-shot extraction charges credits per call, so extractor.extract and extractor.parse are marked as writes.
Agent extractions and async scraper runs answer 202 with an id: poll agent.getTask (statuses pending, running, completed, failed, stopped) or scrapers.getRun (running, completed, completed_partial, failed), and stop a running extraction with agent.stopTask. The plugin declares these as jobs, so the agent can follow them with get_job.
Every extraction result is an open record: its keys are the attribute names you sent, or whatever structure the prompt produced. The docs publish no fixed result schema, so the plugin does not invent one.
Every operation is described in the official docs: https://parsera.org/docs/api

**What you get:**

- 15 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/parsera better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/parsera better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/parsera better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/parsera better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { parsera } from '@corsair-dev/parsera';

export const corsair = createCorsair({
	plugins: [
		parsera(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Parsera API key before the first call: `pnpm corsair setup --plugin=parsera --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
parsera()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'parsera',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read an extraction task**

```ts
const tenant = corsair.withTenant('acme');
await tenant.parsera.api.agent.getTask({ taskId: 'agent-extract-abc123' });
```


**Extract attributes from a page**

```ts
const tenant = corsair.withTenant('acme');
await tenant.parsera.api.extractor.extract({
	url: 'https://news.ycombinator.com/',
	attributes: [{ name: 'title', description: 'News title' }, { name: 'points', description: 'Number of points' }],
});
```


See the full list on the [API](/plugins/parsera/api) page.
