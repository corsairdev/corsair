## Passes

### activeHistory

`passes.activeHistory`

Read the history of active and inactive passes of a template

**Risk:** `read`

```ts
await corsair.passcreator.api.passes.activeHistory({ templateUid: "6d03a4a9-cf92-4e36-80b4-a8994546e2f", day: "2025-01-15" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `templateUid` | `string` | Yes | Pass-template UID |
| `day` | `string` | No | History up to this date; omit for the current state |



**Output:** _empty object_

### create

`passes.create`

Create a pass from a pass template with personalised properties

**Risk:** `write`

```ts
await corsair.passcreator.api.passes.create({ passtemplate: "6d03a4a9-cf92-4e36-80b4-a8994546e2f", properties: { firstname: "John" } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `passtemplate` | `string` | Yes | Pass-template UID the pass is created from |
| `properties` | `Record<string, unknown>` | Yes | Additional properties keyed by property name or ID |

Property keys are the template's property names or property IDs; templates.fields lists both. The answer is the created pass.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `passId` | `string \| null` | No | Pass id |
| `identifier` | `string \| null` | No | Pass identifier (UUID, barcode value or user-provided ID) |
| `uniqueIdentifier` | `string \| null` | No | Pass UID |
| `barcodeValue` | `string \| null` | No | Barcode value |
| `linkToPassPage` | `string \| null` | No | Link to the pass page in the wallet app |
| `passTemplate` | `string \| null` | No | Template name |
| `passTemplateGuid` | `string \| null` | No | Template UID |
| `createdOn` | `string \| null` | No | Creation timestamp |
| `voided` | `boolean \| null` | No | Whether the pass is voided |

### list

`passes.list`

List the passes of a pass template, paged by cursor and date

**Risk:** `read`

```ts
await corsair.passcreator.api.passes.list({ templateUid: "6d03a4a9-cf92-4e36-80b4-a8994546e2f", start: 0, pageSize: 100 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `templateUid` | `string` | Yes | Pass-template UID to list passes of |
| `start` | `number` | No | Offset of the first pass to return |
| `pageSize` | `number` | No | Number of passes per page |
| `lastIdOfPriorPage` | `string` | No | Identifier of the last pass of the prior page, for cursor paging |
| `lastCreatedOnOfPriorPage` | `string` | No | createdOn of the last pass of the prior page, for cursor paging |
| `createdSince` | `string` | No | Only passes created after this date, e.g. "2021-07-01 15:30" |
| `modifiedSince` | `string` | No | Only passes modified after this date, e.g. "2021-07-01 15:30" |

Cursor paging: pass lastIdOfPriorPage and lastCreatedOnOfPriorPage from the prior page along with start and pageSize.



**Output:** `object[]`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  passId?: string | null,
  identifier?: string | null,
  uniqueIdentifier?: string | null,
  barcodeValue?: string | null,
  linkToPassPage?: string | null,
  passTemplate?: string | null,
  passTemplateGuid?: string | null,
  createdOn?: string | null,
  voided?: boolean | null
}[]
```
</Accordion>
</AccordionGroup>

## Webhooks

### subscribe

`webhooks.subscribe`

Subscribe a URL to a webhook event, optionally scoped to one template

**Risk:** `write`

```ts
await corsair.passcreator.api.webhooks.subscribe({ target_url: "https://example.com/webhooks/passcreator", event: "pass_created" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `target_url` | `string` | Yes | Endpoint deliveries are posted to |
| `event` | `string` | Yes | Event to subscribe to, e.g. pass_created, pass_updated, pass_deleted, pass_scanned, pass_template_created, pass_template_updated, appscan_created |
| `pass_template` | `string` | No | Scope the subscription to one pass-template UID |

Events include pass_created, pass_updated, pass_deleted, pass_scanned and the template, appscan and message hooks; pass_template scopes the subscription to one template.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `subscription_url` | `string \| null` | No | Subscription resource URL |
| `target_url` | `string \| null` | No | Endpoint deliveries are posted to |
| `event` | `string \| null` | No | Event the subscription delivers |
| `pass_template` | `string \| null` | No | Template the subscription is scoped to |
| `pull_mode` | `boolean \| null` | No | Whether the subscription is pull-mode |
