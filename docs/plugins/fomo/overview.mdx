Use **Fomo** through Corsair: one client, typed API calls.

Fomo authenticates API requests using an Auth Token passed in the `Authorization: Token <token>` header.
To find your token, log into Fomo, navigate to **Settings > Site**, and copy the Auth Token located near the bottom of the page.
Each website connected to Fomo has its own unique application token.

**What you get:**

- 14 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/fomo better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/fomo better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/fomo better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/fomo better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { fomo } from '@corsair-dev/fomo';

export const corsair = createCorsair({
	plugins: [
		fomo(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Fomo API key before the first call: `pnpm corsair setup --plugin=fomo --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
fomo()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'fomo',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List recent notification events**

```ts
const tenant = corsair.withTenant('acme');
await tenant.fomo.api.events.list({ per: 10, page: 1 });
```


**Create a new notification event**

```ts
const tenant = corsair.withTenant('acme');
await tenant.fomo.api.events.create({
	event_type_id: 123,
	first_name: 'John',
	city: 'New York',
	title: 'Annual Subscription',
	url: 'https://example.com/product',
});
```


See the full list on the [API](/plugins/fomo/api) page.
