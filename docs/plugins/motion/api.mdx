## Comments

### create

`comments.create`

Create a comment on a task.

**Risk:** `destructive`

```ts
await corsair.motion.api.comments.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `taskId` | `string` | Yes | The task on which to place a comment. |
| `content` | `string` | No | Github Flavored Markdown representing the comment. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `taskId` | `string \| null` | No | — |
| `content` | `string \| null` | No | — |
| `createdAt` | `string \| null` | No | — |
| `creator` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="creator full type">

```ts
} | null
```
</Accordion>
</AccordionGroup>

## Projects

### create

`projects.create`

Create a project.

**Risk:** `write`

```ts
await corsair.motion.api.projects.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | The name of the project. |
| `workspaceId` | `string` | Yes | The workspace to which the project belongs. |
| `dueDate` | `string` | No | ISO 8601 due date on the project. |
| `description` | `string` | No | The description of the project. HTML input accepted. |
| `labels` | `string[]` | No | The list of labels by name the project should have. |
| `priority` | `ASAP \| HIGH \| MEDIUM \| LOW` | No | Defaults to MEDIUM. Options are ASAP, HIGH, MEDIUM, and LOW. |
| `projectDefinitionId` | `string` | No | Optional ID of the project definition (template) to use. If provided, stages must also be included. |
| `stages` | `object[]` | No | Optional array of stage objects, required if projectDefinitionId is provided. |

## Recurring Tasks

### create

`recurringTasks.create`

Create a recurring task.

**Risk:** `write`

```ts
await corsair.motion.api.recurringTasks.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | The name of the recurring task. |
| `workspaceId` | `string` | Yes | The workspace in which to create the recurring task. |
| `frequency` | `string` | Yes | Frequency in which the task should be scheduled. |
| `assigneeId` | `string` | Yes | To whom the recurring task should be assigned. |
| `deadlineType` | `HARD \| SOFT` | No | "HARD" or "SOFT" are the two values allowed. |
| `duration` | `REMINDER \| number` | No | An integer greater than 0 or "REMINDER" for a reminder task. |
| `startingOn` | `string` | No | ISO 8601 date trimmed to the start of the day passed, like 2024-03-12 or 2024-03-12T06:00:00.000Z. |
| `idealTime` | `string` | No | If possible, schedule at the ideal time if free (HH:mm). |
| `schedule` | `string` | No | Schedule the task must adhere to (defaults to "Work Hours"). |
| `description` | `string` | No | The description of the task. |
| `priority` | `HIGH \| MEDIUM` | No | "HIGH" or "MEDIUM" (which is the default). |



**Output**

|------|------|----------|-------------|
| `id` | `string` | Yes | — |

| `creator` | `object \| null` | No | — |
