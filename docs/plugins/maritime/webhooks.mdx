The Maritime plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/maritime/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `agent`
  - `deployed` (`agent.deployed`)
  - `error` (`agent.error`)
  - `llmLimitReached` (`agent.llmLimitReached`)
  - `restarted` (`agent.restarted`)
  - `sleeping` (`agent.sleeping`)
  - `stopped` (`agent.stopped`)
  - `woken` (`agent.woken`)
- `endUser`
  - `created` (`endUser.created`)
  - `deleted` (`endUser.deleted`)
  - `resumed` (`endUser.resumed`)
  - `suspended` (`endUser.suspended`)
- `exec`
  - `finished` (`exec.finished`)

  - `created` (`sandbox.created`)

  - `pauseFailed` (`sandbox.pauseFailed`)

  - `running` (`sandbox.running`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Events

## Agent

### Deployed

`agent.deployed`

The agent finished deploying and is ready (X-Maritime-Event agent.deployed)

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event` | `string` | Yes | The event name, such as agent.error. |
| `agent_id` | `string \| null` | No | The agent the event is about. |
| `external_id` | `string \| null` | No | The agent's external_id: your own customer's id. |
| `end_user` | `object \| null` | No | The end user the agent belongs to, or null. |
| `timestamp` | `string \| null` | No | When it happened (ISO 8601). |
| `data` | `Record<string, any> \| null` | No | Event fields: failure_kind on agent.error; execution_id, status, exit_code on exec.finished. |

<AccordionGroup>
<Accordion title="end_user full type">

```ts
{
} | null
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  event: string,
  agent_id?: string | null,
  external_id?: string | null,
  end_user?: {
  } | null,
  timestamp?: string | null,
  data?: Record<string, any> | null
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
maritime({
    webhookHooks: {
        agent: {
            deployed: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
