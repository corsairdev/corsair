## Activity

### list

`activity.list`

Get what happened across the account's agents and computers (creates, boots, starts, sleeps, wakes, takeovers, deletes, errors, triggers), newest first

**Risk:** `read`

```ts
await corsair.maritime.api.activity.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | — |
| `type` | `(lifecycle \| error \| trigger_fired)[]` | No | Only these types (repeat for several). Default: all three. |
| `before` | `string` | No | Only entries strictly older than this ISO timestamp (pagination cursor). |
| `since` | `string` | No | Only entries at or after this ISO timestamp. |
| `until` | `string` | No | Only entries at or before this ISO timestamp. |
| `agent_id` | `string` | No | Only the events of this agent or computer. |
| `external_id` | `string` | No | Only the events of the machines of this end user (the external id). |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `events` | `object[] \| null` | No | — |
| `nextBefore` | `string \| null \| null` | No | — |

### chat.send

`agents.chat.send`

Send a message to an agent and wait for its reply; a sleeping agent wakes first

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.maritime.api.agents.chat.send({ agent_id: 'ag_3k9x2m7q', message: 'Summarize today', conversation_id: 'customer-481:c_9' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `agent_id` | `string` | Yes | — |
| `idempotency_key` | `string` | No | Idempotency-Key header: a retry with the same key returns what this key already did instead of doing it again. Leave it out and the plugin sends a new random key. |
| `chat_result` | `string` | No | X-Maritime-Chat-Result header. 'turns-v1' answers with a turn receipt (pending, reply or failure) instead of the legacy reply; read a pending turn with agents.chat.getTurn. |
| `message` | `string` | Yes | — |
| `conversation_id` | `string \| null` | No | — |
| `context` | `Record<string, string> \| null` | No | String key-value pairs delivered to the agent's container with this message only, for example the sender's user id and a short-lived token for your own tools. Maritime does not store or log them and does not show them to the model. |



**Output:** `any`
