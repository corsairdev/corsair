## Archives

### list

`archives.list`

List archived message or flow-run data.

**Risk:** `read`

```ts
await corsair.textit.api.archives.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `cursor` | `string` | No | — |
| `before` | `string` | No | — |
| `after` | `string` | No | — |
| `type` | `message \| run` | No | — |
| `period` | `daily \| monthly` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `next` | `string \| null` | Yes | — |
| `previous` | `string \| null` | Yes | — |
| `results` | `object[]` | Yes | — |
