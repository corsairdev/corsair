---
title: "Help Scout database"
sidebarTitle: "Database"
description: "The Help Scout plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Help Scout. To read its data, call the [API operations](/plugins/helpscout/api), which return what Help Scout has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
