## Conversations

### create

`conversations.create`

Create a new conversation with initial thread

**Risk:** `destructive`

```ts
await corsair.helpscout.api.conversations.create({ subject: 'Support request', type: 'email', mailboxId: 100, customer: { email: 'customer@example.com' }, threads: [{ type: 'customer', text: 'Need assistance' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `subject` | `string` | Yes | — |
| `type` | `email \| chat \| phone` | Yes | — |
| `mailboxId` | `number` | Yes | — |
| `customer` | `object` | Yes | — |
| `status` | `active \| pending \| closed \| spam` | No | — |
| `assignTo` | `number` | No | — |
| `createdAt` | `string` | No | — |
| `threads` | `object[]` | Yes | — |
| `tags` | `string[]` | No | — |
| `fields` | `object[]` | No | — |

<AccordionGroup>
<Accordion title="customer full type">

```ts
{
  id?: number,
  email?: string,
  firstName?: string,
  lastName?: string
}
```
</Accordion>

<Accordion title="threads full type">

```ts
{
  type: customer | reply | note | phone | chat,
  text: string,
  customer?: {
    id?: number,
    email?: string
  },
  user?: number,
  draft?: boolean,
  attachments?: {
    fileName: string,
    mimeType: string,
    data: string
  }[]
}[]
```
</Accordion>

<Accordion title="fields full type">

```ts
{
  id: number,
  value: string
}[]
```
</Accordion>
</AccordionGroup>



**Output:** `Record<string, any>`
