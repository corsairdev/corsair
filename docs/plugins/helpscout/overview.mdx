Use **Help Scout** through Corsair: one client, typed API calls.

**Authentication.** Help Scout Mailbox API 2.0 authenticates via OAuth 2 Bearer tokens. Pass your token as `key` in plugin options or configure it via Corsair tenant credentials. All requests send the `Authorization: Bearer <token>` header.

**Rate Limiting.** The Mailbox API enforces rate limits per tenant. The underlying HTTP transport automatically retries 429 responses with exponential backoff honoring the `Retry-After` header.

**Resource Identification.** Help Scout numeric IDs are integers or digit strings. Path parameters accept both numbers and numeric strings.

**What you get:**

- 55 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/helpscout better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/helpscout better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/helpscout better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/helpscout better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { helpscout } from '@corsair-dev/helpscout';

export const corsair = createCorsair({
	plugins: [
		helpscout(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Help Scout API key before the first call: `pnpm corsair setup --plugin=helpscout --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
helpscout()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'helpscout',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List mailboxes**

```ts
const tenant = corsair.withTenant('acme');
await tenant.helpscout.api.mailboxes.list({});
```


**Delete a conversation**

```ts
const tenant = corsair.withTenant('acme');
await tenant.helpscout.api.conversations.delete({ conversationId: 1000 });
```


See the full list on the [API](/plugins/helpscout/api) page.
