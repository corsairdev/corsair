Use **Help Scout** through Corsair: one client, typed API calls.

**Authentication.** Help Scout has no API keys. Create an app under Your Profile > My Apps and connect each Help Scout account with OAuth 2: Corsair refreshes the 2-day access token with the stored refresh token, and on a read it refreshes once more and retries after a 401 (writes are not retried: a write that gets a 401 fails, and running it again reuses the stored token until that token expires or a read's 401 retry replaces it). For a single Help Scout account, `clientCredentials: true` in plugin options mints tokens from the app's own id and secret instead (Help Scout's client-credentials grant), so no connect step is needed; leave it off when tenants connect their own accounts, because those tokens reach the account that owns the app. Passing `key` in plugin options sends that token as is, with no refresh.

**Rate Limiting.** The Mailbox API enforces rate limits per tenant. Corsair's HTTP transport retries a 429 up to three times, honoring `Retry-After`.

**Resource Identification.** Help Scout numeric IDs are integers or digit strings. Path parameters accept both numbers and numeric strings.

**What you get:**

- 55 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/helpscout better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/helpscout better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/helpscout better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/helpscout better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { helpscout } from '@corsair-dev/helpscout';

export const corsair = createCorsair({
	plugins: [
		helpscout(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="OAuth 2.0 (Recommended)">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Help Scout OAuth app.

```ts
helpscout()
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'helpscout',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List mailboxes**

```ts
const tenant = corsair.withTenant('acme');
await tenant.helpscout.api.mailboxes.list({});
```


**Delete a conversation**

```ts
const tenant = corsair.withTenant('acme');
await tenant.helpscout.api.conversations.delete({ conversationId: 1000 });
```


See the full list on the [API](/plugins/helpscout/api) page.
