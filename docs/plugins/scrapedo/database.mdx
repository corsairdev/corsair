---
title: "Scrape.do database"
sidebarTitle: "Database"
description: "The Scrape.do plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Scrape.do. To read its data, call the [API operations](/plugins/scrapedo/api), which return what Scrape.do has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
