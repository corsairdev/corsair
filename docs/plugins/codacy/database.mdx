The Codacy plugin syncs data locally. Use `corsair.codacy.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Accounts

Path: `codacy.db.accounts.search`

```ts
const rows = await corsair.codacy.db.accounts.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `number` | equals, gt, gte, lt, lte, in |
| `name` | `string` | equals, contains, startsWith, endsWith, in |
| `mainEmail` | `string` | equals, contains, startsWith, endsWith, in |
| `isAdmin` | `boolean` | equals |
| `isActive` | `boolean` | equals |
| `created` | `string` | equals, contains, startsWith, endsWith, in |
| `intercomHash` | `string` | equals, contains, startsWith, endsWith, in |
| `zendeskHash` | `string` | equals, contains, startsWith, endsWith, in |
| `pylonHash` | `string` | equals, contains, startsWith, endsWith, in |
| `shouldDoClientQualification` | `boolean` | equals |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
