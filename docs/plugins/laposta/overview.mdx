Use **Laposta** through Corsair: one client, typed API calls.

Laposta uses HTTP Basic authentication with the API key as the username and an empty password. The plugin resolves the key through Corsair and sends it only in the Authorization header.

Laposta's documented webhook management endpoints are included. Incoming webhook delivery is a separate callback workflow and is not registered as a Corsair webhook receiver by this plugin.

**What you get:**

- 41 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/laposta better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/laposta better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/laposta better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/laposta better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { laposta } from '@corsair-dev/laposta';

export const corsair = createCorsair({
	plugins: [
		laposta(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Laposta API key before the first call: `pnpm corsair setup --plugin=laposta --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
laposta()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'laposta',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List active subscribers**

```ts
const tenant = corsair.withTenant('acme');
await tenant.laposta.api.members.list({ list_id: 'list-1', limit: 100 });
```


**Create a mailing list**

```ts
const tenant = corsair.withTenant('acme');
await tenant.laposta.api.lists.create({ name: 'Newsletter' });
```


See the full list on the [API](/plugins/laposta/api) page.
