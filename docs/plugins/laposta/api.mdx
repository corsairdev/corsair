## Campaigns

### create

`campaigns.create`

Create a regular email campaign

**Risk:** `write`

```ts
await corsair.laposta.api.campaigns.create({ type: 'regular', name: 'Monthly news', subject: 'Updates', from: { name: 'Example', email: 'sender@example.net' }, list_ids: ['list-1'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `regular` | Yes | — |
| `name` | `string` | Yes | — |
| `subject` | `string` | Yes | — |
| `previewtext` | `string` | No | — |
| `from` | `object` | Yes | — |
| `reply_to` | `string` | No | — |
| `list_ids` | `string[]` | Yes | — |
| `stats` | `object` | No | — |

<AccordionGroup>
<Accordion title="from full type">

```ts
{
  name: string,
  email: string
}
```
</Accordion>

```ts
}
```
</Accordion>
</AccordionGroup>



**Output**

|------|------|----------|-------------|
| `campaign` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="campaign full type">

```ts
  created?: string,
```

### history

`campaigns.history`

Retrieve paginated events for a campaign

**Risk:** `read`

```ts
await corsair.laposta.api.campaigns.history({ campaign_id: 'campaign-1', limit: 100 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaign_id` | `string` | Yes | — |
| `event_date_from` | `string \| string` | No | — |
| `event_date_to` | `string \| string` | No | — |
| `limit` | `number` | No | — |
| `cursor` | `string` | No | — |
| `order_by` | `event_date` | No | — |
| `order` | `desc \| asc` | No | — |

Campaign history uses cursor pagination with a default limit of 100 and maximum of 1000. Keep the same filters and ordering when sending the next cursor.

|------|------|----------|-------------|
| `pagination` | `object` | Yes | — |
| `order` | `object` | Yes | — |
| `filters` | `Record<string, string \| null>` | Yes | — |
| `data` | `object[]` | Yes | — |

Create a segment for a mailing list

**Risk:** `write`

```ts
await corsair.laposta.api.segments.create({ list_id: "list-1", name: "Local members", definition: "\"city\" = 'Utrecht'" });
```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `list_id` | `string` | Yes | — |
| `name` | `string` | Yes | — |
| `definition` | `string` | Yes | — |

Laposta recommends creating a segment in its application first and retrieving it through `segments.get` before composing a definition string.

## Webhooks

### create

`webhooks.create`

Create a webhook subscription for a mailing list

**Risk:** `write`

```ts
await corsair.laposta.api.webhooks.create({ list_id: 'list-1', event: 'modified', url: 'https://example.net/hook', blocked: false });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `list_id` | `string` | Yes | — |
| `event` | `subscribed \| modified \| deactivated` | Yes | — |
| `url` | `string` | Yes | — |
| `blocked` | `boolean` | Yes | — |

Creates a Laposta subscription that POSTs member events to the configured URL. This operation manages the subscription; it does not install an incoming request handler.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `webhook` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="webhook full type">

```ts
  webhook_id: string,

  timezone?: string,
  created?: string,
  created_iso?: string,
  modified?: string | null,
  modified_iso?: string | null,
  state: active | deleted,
  event: subscribed | modified | deactivated,
  url: string,
  blocked: boolean,

}
```
