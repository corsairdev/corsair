## Campaigns

### get

`campaigns.get`

Retrieve a specific campaign by ID

**Risk:** `read`

```ts
await corsair.laposta.api.campaigns.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaign_id` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaign` | `Record<string, any>` | Yes | — |
