The Akta plugin syncs data locally. Use `corsair.akta.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Companies

Path: `akta.db.companies.search`

```ts
const rows = await corsair.akta.db.companies.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `uuid` | `string` | equals, contains, startsWith, endsWith, in |
| `name` | `string` | equals, contains, startsWith, endsWith, in |
| `website` | `string` | equals, contains, startsWith, endsWith, in |
| `productCategory` | `string` | equals, contains, startsWith, endsWith, in |
| `parentCompanyUuid` | `string` | equals, contains, startsWith, endsWith, in |
| `foundedYear` | `number` | equals, gt, gte, lt, lte, in |
| `headcountRange` | `string` | equals, contains, startsWith, endsWith, in |
| `descriptionShort` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
