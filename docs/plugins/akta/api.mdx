## Company

### employeeReviews

`company.employeeReviews`

Get employee review ratings and individual reviews for a company

**Risk:** `read`

```ts
await corsair.akta.api.company.employeeReviews({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `company` | `string` | Yes | Company website (https://canva.com) or Akta uuid from company.search |
| `limit` | `number` | No | — |
| `offset` | `number` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |
| `limit` | `number` | Yes | — |
| `offset` | `number` | Yes | — |
| `credits_consumed` | `number` | Yes | — |
