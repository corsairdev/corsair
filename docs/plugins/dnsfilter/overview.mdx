Use **DNSFilter** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 248 typed API operations
- 10 synced entities (`ipAddresses`, `macAddresses`, `networks`, `organizations`, `policies`, `scheduledReports`, and 4 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/dnsfilter
```
```bash yarn
yarn add corsair @corsair-dev/dnsfilter
```
```bash pnpm
pnpm install corsair @corsair-dev/dnsfilter
```
```bash bun
bun add corsair @corsair-dev/dnsfilter
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { dnsfilter } from '@corsair-dev/dnsfilter';

export const corsair = createCorsair({
	plugins: [
		dnsfilter(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
dnsfilter()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'dnsfilter',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`agentLocalUserBulkDeletes.counts`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.dnsfilter.api.agentLocalUserBulkDeletes.counts({});
```


**`agentLocalUserBulkDeletes.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.dnsfilter.api.agentLocalUserBulkDeletes.create({});
```


See the full list on the [API](/plugins/dnsfilter/api) page.

## Query synced data

Synced entities support `tenant.dnsfilter.db.<entity>.search()` and `.list()`: `ipAddresses`, `macAddresses`, `networks`, `organizations`, `policies`, `scheduledReports`, `subnets`, `unblockRequests`, `userAgents`, `users`.

See [Database](/plugins/dnsfilter/database) for filters and operators.
