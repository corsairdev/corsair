## Account

### credits

`account.credits`

Get the credit balance, cards left and price per card.

**Risk:** `read`

```ts
await corsair.echtpost.api.account.credits({});
```

**Input:** _empty object_

Balance in EUR, cards left at the regular and foreign price, and the price per card.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `credits_eur` | `string \| null` | No | — |
| `cards_regular` | `number \| null` | No | — |
| `cards_foreign` | `number \| null` | No | — |
| `currency` | `string \| null` | No | — |
| `price_per_card_eur` | `string \| null` | No | — |
| `price_per_foreign_card_eur` | `string \| null` | No | — |

## Cards

### cancel

`cards.cancel`

Cancel a card that has not been printed yet; it cannot be restored.

**Risk:** `destructive`

```ts
await corsair.echtpost.api.cards.cancel({ id: '0b9e3c1e-2a4f-4b8a-9f00-1c2d3e4f5a6b' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Card id (UUID) |

Only while `cancelable` is true; answers with the new status.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `status` | `string \| null` | No | — |
| `cancelable` | `boolean \| null` | No | — |

### create

`cards.create`

Print and post a real postcard to each recipient; the account is billed per card.

**Risk:** `destructive`

```ts
await corsair.echtpost.api.cards.create({ motive_id: 42, content: '{anrede}, thank you for your order!', recipient_ids: [101], deliver_at: 'tomorrow' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `motive_id` | `number` | Yes | — |
| `content` | `string` | No | Card text; &#123;anrede&#125; becomes each recipient salutation |
| `content_ps` | `string` | No | — |
| `content_vertical` | `string` | No | — |
| `qr_code_url` | `string` | No | — |
| `deduplicate_recipients` | `boolean` | No | — |
| `font` | `object` | No | Optional; EchtPost picks architects_daughter at a middle size |
| `notifications` | `object[]` | No | — |
| `deliver_at` | `string` | No | YYYY-MM-DD, today, asap, tomorrow or N-days-from-now; at most 90 days out |
| `move_to_next_print_date` | `boolean` | No | — |
| `recipient_ids` | `number[]` | No | — |
| `group_ids` | `number[]` | No | — |
| `recipients` | `object[]` | No | New recipients by postal address |

Prints, posts and bills a real card per recipient with a live key. `motive_id` is required; `content` is required when the motive allows text.
