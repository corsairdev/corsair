## Templates

### list

`templates.list`

List saved Echtpost postcard templates.

**Risk:** `read`

```ts
await corsair.echtpost.api.templates.list({ page: 1, per_page: 50 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | — |
| `per_page` | `number` | No | — |

GET /templates. The body is a JSON array. A row is stored only when id is a number. source is stored as a string so a new enum value does not fail the parse.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `templates` | `object[]` | Yes | — |
