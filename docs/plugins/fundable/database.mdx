---
title: "Fundable database"
sidebarTitle: "Database"
description: "The Fundable plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Fundable. To read its data, call the [API operations](/plugins/fundable/api), which return what Fundable has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
