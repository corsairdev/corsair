Use **Firecrawl** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 9 typed API operations
- 4 synced entities (`jobs`, `scrapes`, `searches`, `siteMaps`) for fast `.search()` / `.list()`
- 14 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/firecrawl
```
```bash yarn
yarn add corsair @corsair-dev/firecrawl
```
```bash pnpm
pnpm install corsair @corsair-dev/firecrawl
```
```bash bun
bun add corsair @corsair-dev/firecrawl
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { firecrawl } from '@corsair-dev/firecrawl';

export const corsair = createCorsair({
	plugins: [
		firecrawl(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
firecrawl()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'firecrawl',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`agent.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.firecrawl.api.agent.get({});
```


**`agent.cancel`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.firecrawl.api.agent.cancel({});
```


See the full list on the [API](/plugins/firecrawl/api) page.

## Query synced data

Synced entities support `tenant.firecrawl.db.<entity>.search()` and `.list()`: `jobs`, `scrapes`, `searches`, `siteMaps`.

See [Database](/plugins/firecrawl/database) for filters and operators.

## Webhooks

This plugin registers **14** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/firecrawl/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
