---
title: "Cloudlayer database"
sidebarTitle: "Database"
description: "The Cloudlayer plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Cloudlayer. To read its data, call the [API operations](/plugins/cloudlayer/api), which return what Cloudlayer has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
