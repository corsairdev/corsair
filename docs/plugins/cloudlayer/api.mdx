## Account

Read account usage, plan limits, storage use and (on usage plans) the credit balance. Docs: https://cloudlayer.io/docs/account/

**Risk:** `read`

## Template

### toImage

`template.toImage`

Render a gallery or base64 Nunjucks template with caller data to an image using JSON or multipart upload; v2 async:false returns a completed JSON job. Docs: https://cloudlayer.io/docs/template-to-image/

**Risk:** `destructive`

```ts
await corsair.cloudlayer.api.template.toImage({
	templateId: 'invoice-template',
	data: { invoiceNumber: 'INV-100' },
});
```

**Input:** `object`

V2 returns a JSON job; `async: false` waits for completion and returns the completed JSON job per the API overview. `template.toImageV1` exposes the v1 route as a base64-encoded binary artifact. For multipart input, the generated type renderer labels the `z.instanceof(Blob)` field as `custom`; callers must pass an actual `Blob` in `{ template: Blob, data: object }`, where `data` is a JSON object. Multipart requests remain in v2 job mode; only the documented `template` and `data` parts are sent. See https://cloudlayer.io/docs/template-to-image/.
