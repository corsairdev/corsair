## Apod

### get

`apod.get`

Read one day's picture by its six-digit date code, with title, explanation, image URLs and the raw HTML page

**Risk:** `read`

```ts
await corsair.nasa.api.apod.get({ date: '240115' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `date` | `string` | Yes | NASA's six-digit date code for the picture, e.g. 240115 for 2024-01-15. This is the only addressable form: the feed has no lookup by YYYY-MM-DD. |

The date is the legacy six-digit code, so 240115 means 2024-01-15.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `date` | `string \| null` | No | — |
| `post_id` | `number \| null` | No | — |
| `title` | `string \| null` | No | — |
| `permalink` | `string \| null` | No | — |
| `media_type` | `string \| null` | No | — |
| `explanation` | `string \| null` | No | — |
| `credit` | `string \| null` | No | — |
| `copyright` | `string \| null` | No | — |
| `alt` | `string \| null` | No | — |
| `url` | `string \| null` | No | — |
| `hdurl` | `string \| null` | No | — |
| `basic_html` | `string \| null` | No | — |
| `basic_html_url` | `string \| null` | No | — |

### list

`apod.list`

List Astronomy Picture of the Day entries, newest first, or a date range in the legacy YYMMDD form; NASA serves at most 25 per page

**Risk:** `read`

```ts
await corsair.nasa.api.apod.list({ per_page: 5 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | 1-based page number. |
| `per_page` | `number` | No | Entries per page. NASA caps this at 25; a larger value is served as 25. |
| `date_from` | `number` | No | Oldest day in the legacy YYMMDD form, e.g. 240115. Only honoured when date_to is also sent. |
| `date_to` | `number` | No | Newest day in the legacy YYMMDD form, e.g. 240117. Only honoured when date_from is also sent. |

NASA serves at most 25 entries per page whatever per_page says, and applies date_from and date_to only as a pair.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `entries` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="entries full type">

```ts
{
  date?: string | null,

  title?: string | null,
  permalink?: string | null,
  media_type?: string | null,
  explanation?: string | null,
  credit?: string | null,
  copyright?: string | null,
  alt?: string | null,
  url?: string | null,
  hdurl?: string | null,
  basic_html?: string | null,
  basic_html_url?: string | null
}[]
```
</Accordion>

### cmeAnalysis

`donki.cmeAnalysis`

List standalone CME analyses, filterable by speed, half angle, catalog and the provider's most-accurate flag

**Risk:** `read`

```ts
await corsair.nasa.api.donki.cmeAnalysis({ startDate: '2026-10-20', endDate: '2026-10-31', speed: 500, halfAngle: 30 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `startDate` | `string` | No | A date in YYYY-MM-DD format. |
| `endDate` | `string` | No | A date in YYYY-MM-DD format. |
| `mostAccurateOnly` | `boolean` | No | Keep only the analysis NASA marks most accurate. Defaults at the provider to true. |
| `completeEntryOnly` | `boolean` | No | Keep only complete analyses. Defaults at the provider to true. |
| `speed` | `number` | No | Lowest speed in km/s to include. Defaults to 0. |
| `halfAngle` | `number` | No | Smallest half angle in degrees to include. Defaults to 0. |
| `catalog` | `ALL \| SWRC_CATALOG \| JANG_ET_AL_CATALOG` | No | Which analysis catalog to read. Defaults to ALL. |
| `keyword` | `string` | No | Free-text filter, such as swpc_annex. |

mostAccurateOnly and completeEntryOnly default to true at the provider, so omitting them hides most analyses.



**Output**

| Name | Type | Required | Description |
