---
title: "IP2Proxy database"
sidebarTitle: "Database"
description: "The IP2Proxy plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for IP2Proxy. To read its data, call the [API operations](/plugins/ip2proxy/api), which return what IP2Proxy has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
