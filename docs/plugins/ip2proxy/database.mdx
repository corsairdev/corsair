The IP2Proxy plugin syncs data locally. Use `corsair.ip2proxy.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Checks

Path: `ip2proxy.db.checks.search`

```ts
const rows = await corsair.ip2proxy.db.checks.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `ip` | `string` | equals, contains, startsWith, endsWith, in |
| `response` | `string` | equals, contains, startsWith, endsWith, in |
| `countryCode` | `string` | equals, contains, startsWith, endsWith, in |
| `countryName` | `string` | equals, contains, startsWith, endsWith, in |
| `regionName` | `string` | equals, contains, startsWith, endsWith, in |
| `cityName` | `string` | equals, contains, startsWith, endsWith, in |
| `isp` | `string` | equals, contains, startsWith, endsWith, in |
| `domain` | `string` | equals, contains, startsWith, endsWith, in |
| `usageType` | `string` | equals, contains, startsWith, endsWith, in |
| `asn` | `string` | equals, contains, startsWith, endsWith, in |
| `as` | `string` | equals, contains, startsWith, endsWith, in |
| `lastSeen` | `number` | equals, gt, gte, lt, lte, in |
| `proxyType` | `string` | equals, contains, startsWith, endsWith, in |
| `isProxy` | `string` | equals, contains, startsWith, endsWith, in |
| `threat` | `string` | equals, contains, startsWith, endsWith, in |
| `provider` | `string` | equals, contains, startsWith, endsWith, in |
| `creditsConsumed` | `number` | equals, gt, gte, lt, lte, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
