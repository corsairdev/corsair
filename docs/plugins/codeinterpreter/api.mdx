## Code

### execute

`code.execute`

Execute code in the sandbox

**Risk:** `write`

```ts
await corsair.codeinterpreter.api.code.execute({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `code` | `string` | Yes | — |
| `language` | `string` | No | — |
| `session_id` | `string` | No | — |
| `args` | `string[]` | No | — |
| `files` | `string[]` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `exit_code` | `number` | Yes | — |
| `stdout` | `string` | No | — |
| `stderr` | `string` | No | — |
| `logs` | `string` | No | — |
| `output_files` | `object[]` | No | — |
| `session_id` | `string` | No | — |

<AccordionGroup>
<Accordion title="output_files full type">

```ts
{
  id: string,
  name: string
}[]
```
</Accordion>
</AccordionGroup>

## File

### delete

`file.delete`

Delete a file from the sandbox

**Risk:** `destructive`

```ts
await corsair.codeinterpreter.api.file.delete({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `file_id` | `string` | Yes | — |
| `session_id` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |
| `file_id` | `string` | Yes | — |
