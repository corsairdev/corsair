Use **Stack Exchange** through Corsair: one client, typed API calls.

Select a documented method with the route field. Per-site methods require a site parameter; network methods do not. OAuth connection requests the documented `read_inbox`, `write_access`, and `private_info` scopes together so every user-context method can be called. Stack Exchange requires a registered redirect URI; expiring tokens have no refresh token and must be reconnected.

**What you get:**

- 3 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/stackexchange better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/stackexchange better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/stackexchange better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/stackexchange better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { stackexchange } from '@corsair-dev/stackexchange';

export const corsair = createCorsair({
	plugins: [
		stackexchange(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Stack Exchange API key before the first call: `pnpm corsair setup --plugin=stackexchange --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
stackexchange()
```

More: [API Key](/concepts/api-key)

</Tab>
<Tab title="OAuth 2.0">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Stack Exchange OAuth app.

```ts
stackexchange({
	authType: 'oauth_2',
})
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'stackexchange',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List recent Stack Overflow questions**

```ts
const tenant = corsair.withTenant('acme');
await tenant.stackexchange.api.site.read({
	route: 'questions',
	site: 'stackoverflow',
	parameters: { pagesize: 10 },
});
```


**Preview question markdown**

```ts
const tenant = corsair.withTenant('acme');
await tenant.stackexchange.api.site.write({
	route: 'render-question',
	site: 'stackoverflow',
	parameters: { title: 'A question about API integration', body: 'Markdown body for rendering only', tags: 'api;testing' },
});
```


See the full list on the [API](/plugins/stackexchange/api) page.
