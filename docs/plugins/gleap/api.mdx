### create

**Risk:** `write`


| Name | Type | Required | Description |
|------|------|----------|-------------|

| `restrictedToUsers` | `string[]` | No | — |
| `restrictedToTeams` | `string[]` | No | — |
| `project` | `string` | No | — |

| Name | Type | Required | Description |
|------|------|----------|-------------|

| `type` | `string` | Yes | — |
| `name` | `string` | Yes | — |
