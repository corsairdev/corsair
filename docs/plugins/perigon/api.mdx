## Articles

### list

`articles.list`

Search news articles: one result per published URL, filterable by query, topic, category, source, country, language and dates

**Risk:** `read`

```ts
await corsair.perigon.api.articles.list({ q: "climate AND policy", category: "Business", source: ["reuters.com", "apnews.com"], from: "2025-11-01", sortBy: "date", size: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | No | Keyword or boolean query (AND, OR, NOT, quotes) across title, description and content |
| `from` | `string` | No | Published after this time: ISO 8601 or yyyy-mm-dd |
| `to` | `string` | No | Published before this time: ISO 8601 or yyyy-mm-dd |
| `topic` | `string \| string[]` | No | Topic, e.g. Markets, Cryptocurrency; several values are ORed |
| `category` | `string \| string[]` | No | Category, e.g. Tech, Business, Politics; several values are ORed |
| `source` | `string \| string[]` | No | Publisher domain, wildcards allowed (*.cnn.com); several values are ORed |
| `country` | `string \| string[]` | No | Country code, e.g. us; several values are ORed |
| `title` | `string` | No | Query scoped to titles |
| `language` | `string \| string[]` | No | ISO-639 language code, e.g. en; several values are ORed |
| `label` | `string \| string[]` | No | Label, e.g. Opinion, Paid News; several values are ORed |
| `excludeLabel` | `string \| string[]` | No | Label to leave out; several values are ORed |
| `showReprints` | `boolean` | No | Include syndicated reprints (Perigon default true) |
| `sortBy` | `relevance \| date \| reverseDate \| addDate \| reverseAddDate \| pubDate \| refreshDate` | No | Sort order |
| `page` | `number` | No | Page number, starting at 0 |
| `size` | `number` | No | Results per page (at most 100 on the free plan) |

One result per published article URL; showReprints: false drops syndicated copies. Content may be plan-truncated; limits.get reports articleContentTruncation.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `number \| null` | No | HTTP status Perigon echoes, 200 on success |
| `numResults` | `number \| null` | No | Total matching records across all pages |
| `articles` | `object[]` | Yes | Articles on this page |

## Stories

### list

`stories.list`

List story clusters: one narrative across many articles

**Risk:** `read`

```ts
await corsair.perigon.api.stories.list({ q: "semiconductor", minUniqueSources: 3, sortBy: "updatedAt" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | No | Keyword or boolean query (AND, OR, NOT, quotes) across title, description and content |
| `from` | `string` | No | Published after this time: ISO 8601 or yyyy-mm-dd |
| `to` | `string` | No | Published before this time: ISO 8601 or yyyy-mm-dd |
| `topic` | `string \| string[]` | No | Topic, e.g. Markets, Cryptocurrency; several values are ORed |
| `category` | `string \| string[]` | No | Category, e.g. Tech, Business, Politics; several values are ORed |
| `source` | `string \| string[]` | No | Publisher domain, wildcards allowed (*.cnn.com); several values are ORed |
| `country` | `string \| string[]` | No | Country code, e.g. us; several values are ORed |
| `name` | `string` | No | Query scoped to story names |
| `minUniqueSources` | `number` | No | Only stories covered by at least this many publishers |
| `sortBy` | `createdAt \| updatedAt \| relevance \| count \| totalCount` | No | Sort order |
| `page` | `number` | No | Page number, starting at 0 |
| `size` | `number` | No | Results per page (at most 100 on the free plan) |

Clustered narratives; use clusterId from an article to reach its story.



**Output**
