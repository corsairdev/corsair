## Articles

### list

`articles.list`

Search news articles: one result per published URL, filterable by query, topic, source, dates and sentiment

**Risk:** `read`

```ts
await corsair.perigon.api.articles.list({ q: "climate AND policy", topic: "Business", sentiment: "negative", from: "2025-11-01", size: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | No | Keyword or boolean query across titles, URLs, descriptions and body |
| `title` | `string` | No | Query scoped to titles |
| `from` | `string` | No | Published from this date (YYYY-MM-DD or ISO) |
| `to` | `string` | No | Published to this date |
| `topic` | `string` | No | Topic filter, e.g. Tech, Business |
| `source` | `string` | No | Publisher name filter |
| `sourceUrl` | `string` | No | Publisher home URL filter |
| `country` | `string` | No | Country filter (ISO code or name) |
| `language` | `string` | No | Language filter (ISO code) |
| `sentiment` | `positive \| negative \| neutral` | No | Sentiment filter |
| `removeDuplicate` | `boolean` | No | Collapse reprints and duplicates |
| `page` | `number` | No | Page number |
| `size` | `number` | No | Results per page, within the plan maxPageSize |
| `sortBy` | `date \| relevance \| source \| topic` | No | Result ordering |

One result per published article URL. Sentiment accepts positive, negative or neutral. Content may be plan-truncated; limits.get reports articleContentTruncation.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `articles` | `object[]` | Yes | Articles on this page |
| `pagination` | `object` | Yes | Pagination metadata |

## Limits

### get

`limits.get`

Read account usage and limits; free to poll and not rate-limited

**Risk:** `read`

```ts
await corsair.perigon.api.limits.get({});
```

**Input:** _empty object_

Free to poll and not rate-limited; reports requestsUsed, requestLimit (null means unlimited), maxPageSize and resetAt.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `organizationName` | `string \| null` | No | Account or organization name |
| `requestsUsed` | `number \| null` | No | Billable requests used this period |
| `requestLimit` | `number \| null` | No | Maximum billable requests; null means unlimited |
| `maxPageSize` | `number \| null` | No | Largest page size the plan allows |
| `paginationLimit` | `number \| null` | No | Maximum results you can page through |
| `articleContentTruncation` | `number \| null` | No | Character limit applied to article content; null means no truncation |
| `since` | `string \| null` | No | Start of the current usage period |
| `lastMadeAt` | `string \| null` | No | Timestamp of the most recent billable request |
| `resetAt` | `string \| null` | No | When the request counter resets |
