Use **Perigon** through Corsair: one client, typed API calls.

Authenticate with the API key from the Developers section of your Perigon account; the plugin sends it in the x-api-key header (the docs also allow a query parameter and a Bearer header — the header keeps the key out of URLs). Every route here is a GET.
Articles API returns one result per published article URL; Stories API returns clustered narratives. The limits endpoint is free to poll — it does not count against your quota — and reports requestsUsed, requestLimit and resetAt. Article body text may be truncated on some plans; check articleContentTruncation in limits.get.
Filters are documented across the Search & Filtering pages (query logic, dates, sources, topics, sentiment, deduplication); this plugin exposes the common family. Monitors, Social (X, Reddit, LinkedIn), vector search and the summarizer are documented by Perigon but not part of this plugin.
Every operation is described in the official docs: https://perigon.io/docs/api/authentication

**What you get:**

- 6 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/perigon better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/perigon better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/perigon better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/perigon better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { perigon } from '@corsair-dev/perigon';

export const corsair = createCorsair({
	plugins: [
		perigon(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Perigon API key before the first call: `pnpm corsair setup --plugin=perigon --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
perigon()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'perigon',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Search articles**

```ts
const tenant = corsair.withTenant('acme');
await tenant.perigon.api.articles.list({ q: 'climate AND policy', from: '2025-11-01', size: 25 });
```
