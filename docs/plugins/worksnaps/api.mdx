## Projects

### create

`projects.create`

Create a project with a name and description

**Risk:** `write`

```ts
await corsair.worksnaps.api.projects.create({ name: 'Acme storefront', description: 'Front-end work' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `description` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="project full type">

```ts
{
  id?: number | string | null,
  name?: string | null,
  description?: string | null,
  status?: string | null

```
</Accordion>
</AccordionGroup>

## Reports

### project

`reports.project`

Read time per user and task in one project over at most 30 days

**Risk:** `read`

```ts
await corsair.worksnaps.api.reports.project({ project_id: 3456, user_ids: [12], from_timestamp: 1717232400, to_timestamp: 1717318800 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project_id` | `number` | Yes | — |
| `name` | `time_summary \| time_entries` | No | time_summary (the default) totals time per user and task; time_entries lists each entry. |
| `user_ids` | `number[]` | Yes | The users to report on. |
| `from_timestamp` | `number` | Yes | Start of the range in Unix seconds, on a 10-minute boundary (a multiple of 600). |
| `to_timestamp` | `number` | Yes | End of the range in Unix seconds, on a 10-minute boundary. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `time_summary` | `object[] \| object \| ""` | No | — |
| `time_entries` | `object[] \| object \| ""` | No | — |

### summary

`reports.summary`

Read time by user, project, task and day across the projects you manage, over at most 30 days

**Risk:** `read`

```ts
await corsair.worksnaps.api.reports.summary({ from_date: '2024-06-01', to_date: '2024-06-07' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `from_date` | `string` | Yes | First day, YYYY-MM-DD. |
| `to_date` | `string` | Yes | Last day, YYYY-MM-DD; at most 30 days after from_date. |
| `timezone_offset` | `number` | No | Hours from UTC for the day boundaries, e.g. -8 or 5.5; defaults to the user timezone. |
| `project_ids` | `number[]` | No | Defaults to every project you manage. |
| `user_ids` | `number[]` | No | Defaults to every user in those projects. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `manager_report` | `object[] \| object \| ""` | Yes | — |

<AccordionGroup>
<Accordion title="manager_report full type">

```ts
{
  user_id?: number | string | null,
  user_name?: string | null,
  project_id?: number | string | null,
  project_name?: string | null,
  date?: string | null,
  task_id?: number | string | null,
  task_name?: string | null,
  type?: string | null,
  duration_in_minutes?: number | string | null
}[] | {
} | ""
```
</Accordion>
</AccordionGroup>
