## Chains

### list

`chains.list`

The chains OpenSea indexes, with each one’s symbol and block explorer. No input; the list is a closed set and is the valid source for every `chain` argument elsewhere.

**Risk:** `read`

```ts
await corsair.opensea.api.chains.list({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chains` | `object[]` | Yes | — |

<Accordion title="chains full type">

```ts
{
  chain: string,
  name: string,
  symbol?: string | null,
  supports_swaps?: boolean | null,
  block_explorer?: string | null,
  block_explorer_url?: string | null
}[]
```
</Accordion>
</AccordionGroup>

| `limit` | `number` | No | Page size. |
| `next` | `string` | No | The `next` cursor. |

### list

`collections.list`

Collections, paged with the returned `next` cursor. Filter by chain, creator or hidden status, and sort with `order_by`. OpenSea defaults the page size to 50.

**Risk:** `read`

```ts
await corsair.opensea.api.collections.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chain` | `base \| ethereum \| zora \| arbitrum \| sei \| avalanche \| polygon \| optimism \| ape_chain \| flow \| soneium \| ronin \| bera_chain \| solana \| shape \| unichain \| gunzilla \| abstract \| animechain \| hyperevm \| somnia \| monad \| hyperliquid \| megaeth \| ink \| robinhood` | No | The chain slug, such as `ethereum` or `base`. Values outside the enum are rejected by the API. |
| `creator_username` | `string` | No | Only collections made by this OpenSea account. |
| `include_hidden` | `boolean` | No | Include collections hidden from search and browse. |
| `order_by` | `string` | No | Field to sort by. The spec types this as a free string and names no values. |
| `limit` | `number` | No | How many to return. The API defaults to 50. |
| `next` | `string` | No | The `next` cursor from a previous page. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `collections` | `object[]` | Yes | — |
| `next` | `string \| null` | No | Cursor for the next page; null on the last one. |
