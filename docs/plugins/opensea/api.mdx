## Accounts

### get

`accounts.get`

One OpenSea profile by wallet address or username, with its display name, bio, follower counts and verification flag. `is_agent` is a self-declaration, not a check by OpenSea.

**Risk:** `read`

```ts
await corsair.opensea.api.accounts.get({ address_or_username: 'boredapeyachtclub' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `address_or_username` | `string` | Yes | A wallet address or an OpenSea username. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `address` | `string` | Yes | — |
| `username` | `string \| null` | No | — |
| `display_name` | `string \| null` | No | — |
| `bio` | `string \| null` | No | — |
| `ens_name` | `string \| null` | No | — |
| `banner_image_url` | `string \| null` | No | — |
| `profile_image_url` | `string \| null` | No | — |
| `follower_count` | `number \| null` | No | — |
| `following_count` | `number \| null` | No | — |
| `is_verified` | `boolean \| null` | No | — |
| `is_agent` | `boolean \| null` | No | — |
| `joined_date` | `string \| null` | No | — |

### portfolio

`accounts.portfolio`

USD value of one wallet’s NFTs and tokens, with profit and loss over a timeframe. Every figure is a string. `pnl_absolute` and `pnl_percentage` are absent, not zero, when the account has no history.

**Risk:** `read`

```ts
await corsair.opensea.api.accounts.portfolio({ address: "0xaba7161a7fb69c88e16ed9f455ce62b8cc0b4d3c", timeframe: "WEEK" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `address` | `string` | Yes | The wallet address to value. |
| `timeframe` | `string` | No | Window for the P&L figures: `HOUR`, `DAY`, `WEEK` or `MONTH`. The API defaults to `DAY`. |
| `chains` | `string[]` | No | Only value assets on these chains. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `total_value_usd` | `string \| null` | No | — |
| `nft_value_usd` | `string \| null` | No | — |
| `token_value_usd` | `string \| null` | No | — |
| `pnl_absolute` | `string \| null` | No | — |
| `pnl_percentage` | `string \| null` | No | — |
| `timeframe` | `string \| null` | No | — |
