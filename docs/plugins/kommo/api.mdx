## Account

### get

`account.get`

The account itself: its name, subdomain, currency and country

**Risk:** `read`

```ts
await corsair.kommo.api.account.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | — |
| `name` | `string \| null` | No | — |
| `subdomain` | `string \| null` | No | — |
| `currency` | `string \| null` | No | — |
| `country` | `string \| null` | No | — |
| `created_at` | `number \| null` | No | — |
| `_embedded` | `Record<string, any> \| null` | No | — |
