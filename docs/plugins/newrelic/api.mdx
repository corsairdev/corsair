## Accounts

### list

`accounts.list`

List the accounts this key can reach, with the ids NRQL and issues take

**Risk:** `read`

```ts
await corsair.newrelic.api.accounts.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `region` | `us \| eu` | No | Which data centre to call. Defaults to us; an EU account must pass eu, because a key is only valid in its own region. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `accounts` | `object[]` | Yes | — |

## Metrics

### get

`metrics.get`

Read metric timeslices for an application over a time window, or one averaged value per metric with summarize

**Risk:** `read`

```ts
await corsair.newrelic.api.metrics.get({ applicationId: 1129082, names: ['Apdex', 'Errors/all'], summarize: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `region` | `us \| eu` | No | Which data centre to call. Defaults to us; an EU account must pass eu, because a key is only valid in its own region. |
| `applicationId` | `number` | Yes | The application id, from applications.list. |
| `names` | `string[]` | Yes | Metric names, sent as repeated `names[]` parameters, e.g. Apdex, Errors/all, WebTransaction. |
| `from` | `string` | No | Start of the window. New Relic defaults to the last 30 minutes. |
| `to` | `string` | No | End of the window. Defaults to now. |
| `period` | `number` | No | Seconds per data point. |
| `summarize` | `boolean` | No | Return one averaged value for the window rather than the series. |
| `values` | `string[]` | No | Only these value fields, e.g. average_value, call_count. |

Without from, New Relic returns the last 30 minutes. summarize collapses the window into one value per metric.

## Query

### nrql

`query.nrql`

Run a NRQL query against one account through NerdGraph and return its rows and the time window New Relic actually ran over

**Risk:** `read`

```ts
await corsair.newrelic.api.query.nrql({ accountId: 1234567, query: 'SELECT count(*) FROM Transaction SINCE 1 hour ago' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `region` | `us \| eu` | No | Which data centre to call. Defaults to us; an EU account must pass eu, because a key is only valid in its own region. |
| `accountId` | `number` | Yes | The New Relic account the query runs against. |
| `query` | `string` | Yes | A NRQL statement, e.g. SELECT count(*) FROM Transaction SINCE 1 hour ago. |

Runs through NerdGraph, so accountId is required. A bad query answers 200 with an errors array, which the plugin throws.
