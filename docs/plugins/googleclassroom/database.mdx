---
title: "Google Classroom database"
sidebarTitle: "Database"
description: "The Google Classroom plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Google Classroom. To read its data, call the [API operations](/plugins/googleclassroom/api), which return what Google Classroom has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
