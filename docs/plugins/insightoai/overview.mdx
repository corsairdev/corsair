Use **Insighto.ai** through Corsair: one client, typed API calls, optional local DB sync.

**What you get:**

- 66 typed API operations

## Setup

<Steps>

<Step title="Install">
```bash
pnpm install @corsair-dev/insightoai
```

</Step>

<Step title="Add the plugin">
<Tabs>
<Tab title="Solo">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { insightoai } from '@corsair-dev/insightoai';

export const corsair = createCorsair({
	// ... other config options,
	multiTenancy: false,
    plugins: [insightoai()],
});
```
</Tab>
<Tab title="Multi-Tenant">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { insightoai } from '@corsair-dev/insightoai';

export const corsair = createCorsair({
	// ... other config options,
    multiTenancy: true,
    plugins: [insightoai()],
});
```

See [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Tab>
</Tabs>

</Step>

<Step title="Get credentials">
Follow [Get Credentials](/plugins/insightoai/get-credentials) if you need help getting keys.

</Step>

<Step title="Store credentials">
<Tabs>
<Tab title="Solo">
```bash
pnpm corsair setup --plugin=insightoai
```

Use the key names documented in [Get Credentials](/plugins/insightoai/get-credentials) (for example `api_key=`, `bot_token=`, or OAuth client fields).
</Tab>
<Tab title="Multi-Tenant">
```bash
pnpm corsair setup --plugin=insightoai --tenant=<tenantId>
```

Store per-tenant secrets after you create the tenant record. See [Multi-tenancy](/concepts/multi-tenancy).
</Tab>
</Tabs>

</Step>

</Steps>

## Authentication

Each tab shows how to register the plugin for that authentication method. The default `authType` from the plugin does not need to appear in the factory call.

<Tabs>
<Tab title="API Key (Default)">

```ts corsair.ts
insightoai()
```

Store credentials with `pnpm corsair setup --plugin=insightoai` (see [Get Credentials](/plugins/insightoai/get-credentials) for field names). For OAuth, you typically store integration keys at the provider level and tokens per account or tenant.

More: [API Key](/concepts/api-key)

</Tab>
<Tab title="OAuth 2.0">

```ts corsair.ts
insightoai({
    authType: 'oauth_2',
})
```

Store credentials with `pnpm corsair setup --plugin=insightoai` (see [Get Credentials](/plugins/insightoai/get-credentials) for field names). For OAuth, you typically store integration keys at the provider level and tokens per account or tenant.

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>



## Example API calls

**Read-style (read):** `agency.getAgencyBillingPlan`

```ts
await corsair.insightoai.api.agency.getAgencyBillingPlan({});
```


**Write-style (write):** `agency.createAgency`

```ts
await corsair.insightoai.api.agency.createAgency({});
```


See the full list on the [API](/plugins/insightoai/api) page. Use `pnpm corsair list --plugin=insightoai` and `pnpm corsair schema <path>` locally to inspect schemas.
