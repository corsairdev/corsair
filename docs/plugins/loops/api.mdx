## Campaigns

### create

`campaigns.create`

Create a new draft campaign. An empty email message is created automatically and its `emailMessageId` is returned. Use the `/email-messages/{emailMessageId}` endpoint to set subject, sender, preview text, and LMX content. Passing scheduling &#123; method: "now" &#125; sends the campaign to its whole audience right away.

**Risk:** `destructive`

```ts
await corsair.loops.api.campaigns.create({ name: 'Spring announcement', mailingListId: 'clm2k8j4h6g0f8d6s4a2b0z8' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | The campaign name. |
| `campaignGroupId` | `string` | No | The ID of the group to add this campaign to. Defaults to the team's Unsorted group when omitted. |
| `mailingListId` | `string \| null` | No | The ID of the mailing list to send to. |
| `audienceSegmentId` | `string \| null` | No | The ID of an audience segment. Setting this without also providing `audienceFilter` clears any existing `audienceFilter`. If both are provided, the filter is applied on top of the segment's filter. |
| `audienceFilter` | `object \| null` | No | A tree of audience conditions combined with `match`. Setting this without also providing `audienceSegmentId` clears any existing `audienceSegmentId`. When both are provided, this filter is applied on top of the segment's filter. |
| `scheduling` | `object` | No | When the campaign should send. `timestamp` is required and must be in the future when `method` is `schedule`, and must be omitted when `method` is `now`. |

Creates a draft and its empty email message (emailMessageId); set subject and content with emailMessages.update. scheduling &#123; method: now &#125; sends at once.
