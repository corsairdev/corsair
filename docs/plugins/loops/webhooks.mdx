The Loops plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/loops/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `campaign`
  - `emailSent` (`campaign.emailSent`)
- `contact`
  - `created` (`contact.created`)
  - `deleted` (`contact.deleted`)
  - `mailingListSubscribed` (`contact.mailingListSubscribed`)
  - `mailingListUnsubscribed` (`contact.mailingListUnsubscribed`)
  - `unsubscribed` (`contact.unsubscribed`)
- `email`
  - `clicked` (`email.clicked`)
  - `delivered` (`email.delivered`)
  - `hardBounced` (`email.hardBounced`)
  - `opened` (`email.opened`)
  - `resubscribed` (`email.resubscribed`)
  - `softBounced` (`email.softBounced`)
  - `spamReported` (`email.spamReported`)
  - `unsubscribed` (`email.unsubscribed`)
- `loop`
  - `emailSent` (`loop.emailSent`)
- `testing`
  - `testEvent` (`testing.testEvent`)
- `transactional`
  - `emailSent` (`transactional.emailSent`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Campaign

### Email Sent

`campaign.emailSent`

Campaign email sent. Sent when a campaign email is sent to a contact. This event fires for every campaign send (for example, sending to 1,000 contacts produces 1,000 events).

**Payload:** `object`
