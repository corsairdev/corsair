## Account

### identity

`account.identity`

Read the identity behind the credential: user, organization and current scopes (needs an OAuth token with account.read).

**Risk:** `read`

```ts
await corsair.vpndetection.api.account.identity({});
```

**Input:** _empty object_


**Output**

|------|------|----------|-------------|

| `user` | `object` | No | — |
| `org` | `object` | No | — |
| `credential` | `object` | No | — |
| `scopes` | `string[]` | No | — |

## Api Keys

### create

`apiKeys.create`

Create an API key and return its secret once (needs an OAuth token with apikeys.manage).

**Risk:** `write`

```ts
await corsair.vpndetection.api.apiKeys.create({ name: 'ci', allowedScopes: ['ip.lookup'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | A name for the key, shown in the console. |
| `allowedScopes` | `(ip.lookup \| db.download)[]` | No | What the key may do. Omit for both. |

Needs an OAuth token with `apikeys.manage`. The answer carries the new secret once; read it back later with `apiKeys.reveal`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `rc` | `string` | Yes | — |
| `id` | `string` | Yes | — |
| `name` | `string` | No | — |
| `key` | `string` | Yes | — |
| `key_prefix` | `string` | No | — |
| `allowed_cidrs` | `string[]` | No | — |
| `allowed_scopes` | `string[]` | No | — |

### download

`databases.download`

Get a time-limited download link for one database version and format, or one build by name; the file itself is not fetched.

**Risk:** `read`

```ts
await corsair.vpndetection.api.databases.download({ id: 'tor_ip_v1', format: 'mmdb' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | A versioned database ID from databases.list `versions[].id`, e.g. `tor_ip_v1`. |
| `format` | `csvgz \| mmdb` | Yes | `csvgz` or `mmdb`. The `_provider` catalogs come as `csvgz` only. |
| `build` | `string` | No | One build by the name a database.updated webhook gives it (kept 7 days). Omit for the live build. |

Returns `{ url }`: the time-limited object-storage link the API redirects to. The redirect is not followed, so no file is downloaded; fetch `url` yourself. A database the organization holds no license for answers 403 `NOT_LICENSED`; a format a database is not built in answers 400 `INVALID_FORMAT`; a `build` older than 7 days answers 410 `BUILD_GONE`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | Time-limited link to the file on object storage; it only has to be valid when the download starts. |

## Ip

### batch

`ip.batch`

Classify up to 1000 IP addresses in one call (a paid plan; a free key answers a batch of one); per-address failures come back in errors.

**Risk:** `read`

```ts
await corsair.vpndetection.api.ip.batch({ ips: ['185.65.135.230', '185.220.101.1'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ips` | `string[]` | Yes | 1 to 1000 addresses. Each distinct string is one lookup; a string that is not an address comes back in `errors` as a 400. |
| `userAgents` | `Record<string, string>` | No | Each address's User-Agent, keyed by the string as it appears in `ips`. Never kept. |

Up to 1000 strings in `ips`; each distinct string costs what one lookup costs. Both maps in the answer are keyed by the string as sent: `results` holds the answers, `errors` the strings that could not be answered (a non-address is a 400 there). Each answer is saved to `lookups` like a single lookup. The free plan answers a batch of one address and refuses anything larger with 402.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `results` | `object` | Yes | — |
| `errors` | `object` | Yes | — |

### lookup

`ip.lookup`

Check whether an IP address is a VPN, a Tor node or a privacy relay, with its country and ASN; omit ip for the caller's own address.

**Risk:** `read`

```ts
await corsair.vpndetection.api.ip.lookup({ ip: '185.65.135.230' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ip` | `string \| string` | No | IPv4 or IPv6 address. Omit it and the service looks up the caller address. |
| `userAgent` | `string` | No | The visitor's User-Agent. With every field, the answer then carries `user_agent` with a verdict on it. Never kept. |

Omit `ip` and the service looks up the caller address. Only `ip` and `is_vpn` are always present. A keyless or free-plan answer usually also carries `is_tor`, `is_relay`, `is_bogon`, `is_anycast`, `tor`, `relay`, `location`, `asn` and `hostname`, and a paid plan or a trial adds the other `is_*` flags and their detail objects; any field the plan does not include is absent, so test for presence. A lookup with an explicit `ip` is saved to the `lookups` table under that address, replacing the previous row for it; a lookup without `ip` is returned but not saved, and a failed save does not fail the lookup. Anything but an IPv4 or IPv6 address in `ip` is refused before the request. `userAgent` adds a verdict on the visitor's User-Agent and is never kept.
