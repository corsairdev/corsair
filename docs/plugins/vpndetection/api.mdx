## Ip

### lookup

`ip.lookup`

Check whether an IP address is a VPN, a Tor node or a privacy relay, with its country and ASN.

**Risk:** `read`

```ts
await corsair.vpndetection.api.ip.lookup({ ip: '185.65.135.230' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ip` | `string` | No | IPv4 or IPv6 address. Omit it and the service looks up the caller address. |

Omit `ip` and the service looks up the caller address. Every answer carries `ip`, `is_vpn`, `is_tor`, `is_relay`, `is_bogon`, `is_anycast`, `tor`, `relay`, `location`, `asn` and `hostname`. A lookup with an explicit `ip` is saved to the `lookups` table under that address, replacing the previous row for it; a lookup without `ip` is returned but not saved, and a failed save does not fail the lookup. An address that does not parse comes back as HTTP 400.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ip` | `string` | Yes | — |
| `is_vpn` | `boolean` | Yes | — |
| `is_tor` | `boolean` | No | — |
| `is_relay` | `boolean` | No | — |
| `is_bogon` | `boolean` | No | — |
| `is_anycast` | `boolean` | No | — |
| `tor` | `object` | No | — |
| `relay` | `object` | No | — |
| `location` | `object` | No | — |
| `asn` | `object` | No | — |
| `hostname` | `string` | No | — |
