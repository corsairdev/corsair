The VPNDetection plugin syncs data locally. Use `corsair.vpndetection.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Lookups

Path: `vpndetection.db.lookups.search`

```ts
const rows = await corsair.vpndetection.db.lookups.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `ip` | `string` | equals, contains, startsWith, endsWith, in |
| `is_vpn` | `boolean` | equals |
| `is_tor` | `boolean` | equals |
| `is_relay` | `boolean` | equals |
| `is_bogon` | `boolean` | equals |
| `is_anycast` | `boolean` | equals |
| `tor_provider` | `string` | equals, contains, startsWith, endsWith, in |
| `relay_provider` | `string` | equals, contains, startsWith, endsWith, in |
| `country` | `string` | equals, contains, startsWith, endsWith, in |
| `asn` | `number` | equals, gt, gte, lt, lte, in |
| `asn_name` | `string` | equals, contains, startsWith, endsWith, in |
| `asn_type` | `string` | equals, contains, startsWith, endsWith, in |
| `hostname` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
