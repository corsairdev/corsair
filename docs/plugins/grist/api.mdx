## Attachments

### get

`attachments.get`

Get metadata for a specific attachment in a document

**Risk:** `read`

```ts
await corsair.grist.api.attachments.get({ docId: 'doc123example', attachmentId: 1 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `docId` | `string` | Yes | — |
| `attachmentId` | `string \| number` | Yes | — |

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string` | No | — |
| `fileSize` | `number` | No | — |
| `timeUploaded` | `string` | No | — |
