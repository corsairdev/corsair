Use **Best Buy** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 8 typed API operations
- 4 synced entities (`categories`, `products`, `reviews`, `stores`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/bestbuy
```
```bash yarn
yarn add corsair @corsair-dev/bestbuy
```
```bash pnpm
pnpm install corsair @corsair-dev/bestbuy
```
```bash bun
bun add corsair @corsair-dev/bestbuy
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { bestbuy } from '@corsair-dev/bestbuy';

export const corsair = createCorsair({
	plugins: [
		bestbuy(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
bestbuy()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'bestbuy',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List products**

```ts
const tenant = corsair.withTenant('acme');
await tenant.bestbuy.api.products.list({});
```


**Get a product**

```ts
const tenant = corsair.withTenant('acme');
await tenant.bestbuy.api.products.get({ sku: '6428324' });
```


See the full list on the [API](/plugins/bestbuy/api) page.

## Query synced data

These tables exist, but Best Buy calls don't fill them yet. This returns only rows you have written yourself.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.bestbuy.db.products.search({
	data: {},
	limit: 50,
});
```

Synced entities: `categories`, `products`, `reviews`, `stores`. See [Database](/plugins/bestbuy/database) for filters and operators.
