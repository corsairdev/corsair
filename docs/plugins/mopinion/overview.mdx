Use **Mopinion** through Corsair: one client, typed API calls.

Create a Feedback API credential set in Mopinion under Settings &gt; Feedback
API (classic interface) or Integrations &gt; Feedback API (Raspberry
interface); the package must include API access (the 14-day trial does).
Connect with the signature token as the API key and the public key as the
account's `public_key` field. Every request is signed with an HMAC-based
`x-auth-token` header computed over the resource path and body.

- **Pinned to the 2.5 API.** The client sends `version: 2.5.0`, which
Mopinion serves as its current stable release (2.5.5 on 2026-11-24). The
3.0.0 line is an alpha: on 2026-11-24 it answered 500 for every feedback
route and for a deployment read.
- **Read-only.** The data API only exposes GET endpoints, so every
operation here is a read; there is nothing to send or delete.
- **Response shapes.** A single resource (account, dataset, report,
deployment) comes back as its fields next to `_meta`. Lists (fields,
feedback, deployments) and a single feedback item come back as
`{ data: [...], _meta }`.
- **Paging and metadata.** Lists take `page` (default 1) and `limit`
(default 10, max 1000); feedback lists also take `sort` (created |
datetime) and `order` (asc | desc). `_meta` carries has_more, next,
previous, count and total.
- **Filters.** Feedback lists accept Mopinion filter expressions as a
`filters` record, e.g. `{"<<nps": 5}` or `{"date_from": "2026-01-01"}`;
keys are date, rating, nps, ces, ces_inverse, gcr and tags, with the
modifiers !, &lt;, &lt;&lt;, &gt; and &gt;&gt;. Ignored filters are reported in
`_meta.warnings`.
- **Errors.** Failures are RFC 7807 problem documents
(`{status, error_code, title, type}`); the error message carries the
status, the `error_code` (18 is invalid credentials) and the title.
- **Known server issue.** `GET /deployments` answered Mopinion's own 500
"Server error" on every API version for the trial account on 2026-11-24;
reading one deployment by its key works.

**What you get:**

- 11 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/mopinion better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/mopinion better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/mopinion better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/mopinion better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { mopinion } from '@corsair-dev/mopinion';

export const corsair = createCorsair({
	plugins: [
		mopinion(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Mopinion API key before the first call: `pnpm corsair setup --plugin=mopinion --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
mopinion()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'mopinion',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>
