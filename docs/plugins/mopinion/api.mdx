## Account

### get

`account.get`

Read the account data behind the signed credentials

**Risk:** `read`

```ts
await corsair.mopinion.api.account.get({});
```

**Input:** _empty object_

`GET /account`. Returns the account data behind the signed credentials.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `_meta` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="_meta full type">

```ts
{
  code?: number | null,
  message?: string | null,
  has_more?: boolean | null,
  previous?: string | boolean | null,
  next?: string | boolean | null,
  count?: number | null,
  total?: number | null,
  warnings?: any[] | null,
  changed?: number | null,
  previous_attributes?: Record<string, any> | null
} | null
```
</Accordion>
</AccordionGroup>

## Datasets

### feedback

`datasets.feedback`

List the feedback items of a dataset, one page at a time, with Mopinion filter expressions for date, rating, NPS, CES, GCR and tags

**Risk:** `read`

```ts
await corsair.mopinion.api.datasets.feedback({ datasetId: '12345', page: 1, limit: 100, filters: { '<<nps': 5, date_from: '2026-01-01' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | Defaults to 1. |
| `limit` | `number` | No | Defaults to 10, at most 1000. |
| `sort` | `created \| datetime` | No | — |
| `order` | `asc \| desc` | No | Defaults to desc. |
| `datasetId` | `string` | Yes | — |
| `filters` | `Record<string, string \| number>` | No | — |

`GET /datasets/{datasetId}/feedback` with page, limit (max 1000), sort
(created | datetime), order (asc | desc) and `filters`. Pagination state
arrives in `_meta` (has_more, next, previous, count, total).



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `_meta` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="_meta full type">

```ts
{
  code?: number | null,
  message?: string | null,
  has_more?: boolean | null,
  previous?: string | boolean | null,
  next?: string | boolean | null,
  count?: number | null,
  total?: number | null,
  warnings?: any[] | null,
  changed?: number | null,
  previous_attributes?: Record<string, any> | null
} | null
```
</Accordion>
</AccordionGroup>
