---
title: "Mopinion database"
sidebarTitle: "Database"
description: "The Mopinion plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Mopinion. To read its data, call the [API operations](/plugins/mopinion/api), which return what Mopinion has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
