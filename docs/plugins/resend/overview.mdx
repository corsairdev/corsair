Use **Resend** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 15 typed API operations
- 3 synced entities (`contacts`, `domains`, `emails`) for fast `.search()` / `.list()`
- 16 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/resend better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/resend better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/resend better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/resend better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { resend } from '@corsair-dev/resend';

export const corsair = createCorsair({
	plugins: [
		resend(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Resend API key before the first call: `pnpm corsair setup --plugin=resend --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

Provider walkthrough: [Get Credentials](/plugins/resend/get-credentials).

```ts
resend()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'resend',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List emails**

```ts
const tenant = corsair.withTenant('acme');
await tenant.resend.api.emails.list({});
```


**Send an email**

```ts
const tenant = corsair.withTenant('acme');
await tenant.resend.api.emails.send({
	from: 'corsair@example.com',
	to: 'you@example.com',
	subject: 'Hello from Corsair',
	text: 'Hello from Corsair',
});
```


See the full list on the [API](/plugins/resend/api) page.

## Query synced data

Search synced emails without hitting Resend.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.resend.db.emails.search({
	data: {},
	limit: 50,
});
```

Synced entities: `contacts`, `domains`, `emails`. See [Database](/plugins/resend/database) for filters and operators.

## Webhooks

Fires when Resend accepts an outbound email.

```ts
resend({
    webhookHooks: {
        emails: {
            sent: {
                after: async (ctx, result) => {
                    console.log('Email sent:', result.data);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/resend/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
