## Contacts

### create

`contacts.create`

Create a new contact

**Risk:** `write`

```ts
const tenant = corsair.withTenant('acme');
await tenant.resend.api.contacts.create({});
```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | — |
| `first_name` | `string` | No | — |
| `last_name` | `string` | No | — |
| `unsubscribed` | `boolean` | No | — |
| `properties` | `object` | No | — |
| `segments` | `object[]` | No | — |
| `topics` | `object[]` | No | — |
