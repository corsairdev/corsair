## Account

### get

`account.get`

Read the account plan and the remaining search, verification and count credits for this usage window

**Risk:** `read`

```ts
await corsair.tomba.api.account.get({});
```

**Input:** _empty object_

The /me body also carries the account `secret_token` and an `intercom_user_jwt`; the endpoint drops both before returning.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
  first_name?: string | null,

  email?: string | null,
  country?: string | null,
```

### search

`company.search`

Search the company database with a plain-language query or structured filters, 50 per page

**Risk:** `read`

```ts
await corsair.tomba.api.company.search({ query: 'Fintech companies in France' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | No | Plain-language query; filters are generated from it and any `filters` sent are ignored |
| `filters` | `object` | No | Structured filters, keyed by field such as industry or location_city |
| `page` | `number` | No | 50 companies per page |

Sending `query` makes Tomba generate the filters and ignore any `filters` you send. The generated filters come back in `meta.filters` for the next page.

<AccordionGroup>
<Accordion title="filters full type">

```ts
Record<string, {

  exclude?: string[] | null
} | string | string[]>
```

</AccordionGroup>

| `data` | `object` | Yes | — |
| `meta` | `object \| null` | No | — |

### emailSources

`domain.emailSources`

List the public pages where Tomba found an email address, with first and last seen dates

**Risk:** `read`

```ts
await corsair.tomba.api.domain.emailSources({ email: 'jane.doe@stripe.com' });
```

|------|------|----------|-------------|
