## Bounces

### activate

`bounces.activate`

Reactivate an address Postmark deactivated after a bounce. A hard bounce that cannot be reactivated reports so

**Risk:** `write`

```ts
await corsair.postmark.api.bounces.activate({ id: 42 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | The bounce id whose address should be reactivated. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `Message` | `string \| null` | No | — |
| `Bounce` | `object \| null` | No | — |

## Email

### send

`email.send`

Send one transactional email. This delivers a real message and cannot be recalled once Postmark accepts it

**Risk:** `destructive`

```ts
await corsair.postmark.api.email.send({ From: 'sender@example.com', To: 'receiver@example.com', Subject: 'Password Reset', TextBody: 'Click here to reset your password.', MessageStream: 'outbound' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `From` | `string` | Yes | The sender. The address needs a confirmed Sender Signature or a verified domain. |
| `To` | `string` | Yes | Comma-separated addresses. `To`, `Cc` and `Bcc` together allow 50, and each address is at most 254 characters. |
| `Cc` | `string` | No | Comma-separated addresses. `To`, `Cc` and `Bcc` together allow 50, and each address is at most 254 characters. |
| `Bcc` | `string` | No | Comma-separated addresses. `To`, `Cc` and `Bcc` together allow 50, and each address is at most 254 characters. |
| `Subject` | `string` | No | Max 2000 characters. |
| `Tag` | `string` | No | Categorises the message for statistics. |
| `HtmlBody` | `string` | No | — |
| `TextBody` | `string` | No | — |
| `ReplyTo` | `string` | No | Comma-separated addresses. `To`, `Cc` and `Bcc` together allow 50, and each address is at most 254 characters. |
| `Headers` | `object[]` | No | Custom headers to include. |
| `TrackOpens` | `boolean` | No | — |
| `TrackLinks` | `None \| HtmlAndText \| HtmlOnly \| TextOnly` | No | Which bodies get their links rewritten for tracking. |
| `Attachments` | `object[]` | No | — |
| `Metadata` | `Record<string, string>` | No | — |
| `MessageStream` | `string` | No | Defaults to the `outbound` transactional stream. |

}[]
```
</Accordion>

  Message?: string | null

```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `Messages` | `object[]` | Yes | Up to 500 messages, which is the API limit per request. |
