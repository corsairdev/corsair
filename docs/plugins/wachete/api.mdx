## Data

### list

`data.list`

Read a monitor's check history, optionally as a diff per entry

**Risk:** `read`

```ts
await corsair.wachete.api.data.list({ id: '9f7e1ae7-9a7f-49e0-baa2-ffd8760f7b9e', returnDiff: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The monitor id. |
| `from` | `string` | No | ISO 8601 start. |
| `to` | `string` | No | ISO 8601 end. |
| `count` | `number` | No | — |
| `returnDiff` | `boolean` | No | Return a Google-style diff per entry rather than the raw value. |
| `continuationToken` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[] \| null` | No | — |
| `continuationToken` | `string \| null` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  lastCheckTimestamp?: string | null,
  valueChangedTimestamp?: string | null,
  raw?: string | null,
  error?: string | null,
  diff?: any[] | null
}[] | null
```
</Accordion>
</AccordionGroup>

### move

| `folderIds` | `string[]` | No | — |

| Name | Type | Required | Description |
|------|------|----------|-------------|

### upsert

`tasks.upsert`

Create a monitor, or update one by sending its id; sets the URL, the part of the page watched, how often to check and who to notify

**Risk:** `write`

```ts
await corsair.wachete.api.tasks.upsert({ name: 'My First Monitor', url: 'http://www.mypage.com', xPath: '/', recurrenceInSeconds: 86400, alerts: [{ type: 'Error' }, { type: 'NotEq' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | No | Omit to create, send to update that monitor. |
| `name` | `string` | Yes | — |
| `url` | `string` | Yes | — |
| `xPath` | `string` | No | The part of the page to watch. `/` is the whole page. |
| `excludeXPath` | `string` | No | A part of the page to ignore, such as a timestamp. |
| `regex` | `string` | No | — |
| `method` | `string` | No | The HTTP method to fetch with. Defaults to GET. |
| `headers` | `object[]` | No | Request headers, as `{ key, value }` pairs. |
| `body` | `string` | No | Request body, for a POST monitor. |
| `alerts` | `object[]` | No | — |
| `recurrenceInSeconds` | `number` | Yes | How often to check, in seconds. 86400 is daily. |
| `folderId` | `string` | No | — |
| `notificationEndpoints` | `object[]` | No | Who to tell. An empty list uses the default email recipients; omit it to notify every endpoint on the account. |
| `proxies` | `object[]` | No | — |
| `location` | `us \| gb \| number` | No | The location to check from. The docs name us and gb. |
| `dynamicContent` | `boolean` | No | Set when the watched content is rendered by JavaScript. |
| `scrollPage` | `boolean` | No | — |
| `ignoreInvalidPages` | `boolean` | No | — |
| `collectRawHtml` | `boolean` | No | — |
| `jobType` | `SinglePage \| Portal \| number` | No | SinglePage watches one page; Portal crawls a site. Defaults to SinglePage. |
| `crawlingDepth` | `1 \| 2 \| 3` | No | Portal only: how deep to crawl, 1 to 3. Defaults to 2. |
| `crawlBinaryContent` | `boolean` | No | — |
| `urlFilter` | `object` | No | Portal only: which crawled URLs to keep or skip. |
| `crawlPagesFromAllDomains` | `boolean` | No | — |
| `note` | `string` | No | — |
