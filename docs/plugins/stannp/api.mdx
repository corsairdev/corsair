## Account

### balance

`account.balance`

Read the account balance

**Risk:** `read`

```ts
await corsair.stannp.api.account.balance({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `balance` | `string \| number \| null` | No | Account balance, such as "214.4200". |



---

### topup

`account.topup`

Top up the account balance from the saved card; the amount is charged for real

**Risk:** `destructive`

```ts
await corsair.stannp.api.account.topup({ net: '10.00' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `net` | `string` | Yes | Amount to top up, such as "10.00". Tax may be added. |
| `idempotencyKey` | `string` | No | Sent as the X-Idempotency-Key header. A repeat call with the same key and body returns the original response with HTTP 409 instead of running again. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `receipt_pdf` | `string \| number \| null` | No | URL of the receipt. |

### book

`campaigns.book`

Book a campaign for dispatch on a date, paying from the balance; this starts a real mailing

**Risk:** `destructive`

```ts
await corsair.stannp.api.campaigns.book({ id: 123, send_date: '2026-01-22', use_balance: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | The campaign to book. |
| `send_date` | `string` | Yes | The dispatch date. |
| `next_available_date` | `boolean` | No | Defaults to true: books on the next available date when yours is taken. False returns an error instead. |
| `use_balance` | `boolean` | No | Defaults to true: pays from the balance. False schedules the campaign but nothing posts until payment. |
| `idempotencyKey` | `string` | No | Sent as the X-Idempotency-Key header. A repeat call with the same key and body returns the original response with HTTP 409 instead of running again. |



**Output:** `boolean \| number`

### create

`campaigns.create`

Create a campaign for a group from a template, copied design or uploaded artwork; nothing sends until it is booked

**Risk:** `write`

```ts
await corsair.stannp.api.campaigns.create({ name: 'My Campaign', type: 'a6-postcard', template_id: 12345, group_id: 12345 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Name of the campaign, for reference. |
| `type` | `a6-postcard \| a5-postcard \| letter \| A6-postcard \| A5-postcard` | Yes | The mailpiece this campaign sends. |
| `template_id` | `number` | No | A template to copy. 0 or omitted uses a blank template of the format. |
| `file` | `string` | No | URL of a PDF to use as the design artwork. |
| `front` | `string` | No | URL of a PDF or JPG for the front image. |
| `back` | `string` | No | URL of a PDF or JPG for the back image. |
| `size` | `string` | No | Required with file or front/back images, such as A4, A5 or A6. |
| `save` | `boolean` | No | Save the uploaded artwork as a new design template. |
| `group_id` | `number` | Yes | The group this campaign sends to. |
| `what_recipients` | `all \| valid \| not_valid \| int` | No | all is every recipient in the group, valid and not_valid are UK validated and non-validated addresses, int is international addresses. |
| `addons` | `string` | No | Addon code for the campaign. |
| `idempotencyKey` | `string` | No | Sent as the X-Idempotency-Key header. A repeat call with the same key and body returns the original response with HTTP 409 instead of running again. |



**Output:** `unknown`

## Events

### create

`events.create`

Record an event against a recipient for tracking, conversions and automation triggers

**Risk:** `write`

```ts
await corsair.stannp.api.events.create({ recipient_id: '12345', name: 'PURCHASE', value: '24.99', conversion: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `recipient_id` | `string` | Yes | The recipient id, or the ref_id stored on the recipient. |
| `name` | `string` | Yes | Event name, such as PURCHASE, SIGNUP, PAGE_VIEW, PRODUCT_VIEW, PRODUCT_TO_BASKET. |
| `value` | `string` | No | Value information, such as the purchase amount or product name. |
| `conversion` | `boolean` | No | True for a conversion event. Defaults to false. |
| `data` | `string` | No | Extended data for automation or dynamic templating. |
| `ref` | `string` | No | A campaign or mailpiece reference. Empty uses the most recent communication. |
| `idempotencyKey` | `string` | No | Sent as the X-Idempotency-Key header. A repeat call with the same key and body returns the original response with HTTP 409 instead of running again. |



**Output:** `number \| string`

### create

`letters.create`

Create and mail a letter merged from a template or PDF; test mode renders a PDF proof without posting or charging

**Risk:** `destructive`

```ts
await corsair.stannp.api.letters.create({ test: true, file: 'https://www.stannp.com/assets/samples/letter-heading.pdf', recipient: { firstname: 'John', lastname: 'Smith', address1: '123 Sample Street', city: 'Sampletown', zipcode: '12345', country: 'US' }, addons: 'FIRST_CLASS' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `test` | `boolean` | No | True produces a sample PDF without dispatching or charging. Defaults to false: the letter is posted for real. |
| `recipient` | `number \| object` | Yes | An existing recipient id, or a new recipient object. |
| `template` | `number` | No | A template set up on the platform. |
| `file` | `string` | No | URL of a PDF or DOC file to mail merge, instead of a template. Page limits apply per the docs. |
| `size` | `A4 \| US-LETTER \| US-LETTER-XL-WINDOW` | No | Defaults to A4 for EU/UK accounts, US-LETTER for US accounts. |
| `duplex` | `boolean` | No | Defaults to true. False prints front sides only. |
| `clearzone` | `boolean` | No | Defaults to true. True overlays clear zones with white. |
| `post_unverified` | `boolean` | No | Defaults to true. If false, the letter is not posted when the address could not be verified. |
| `tags` | `string` | No | Comma-separated tags for reporting. |
| `addons` | `string` | No | Comma-separated addon codes: FIRST_CLASS, C4_ENVELOPE, CONFIDENTIAL, STOCK_120. |
| `idempotencyKey` | `string` | No | Sent as the X-Idempotency-Key header. A repeat call with the same key and body returns the original response with HTTP 409 instead of running again. |

**Risk:** `destructive`


**Input**

| Name | Type | Required | Description |
