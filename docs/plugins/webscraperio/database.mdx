---
title: "Web Scraper Cloud database"
sidebarTitle: "Database"
description: "The Web Scraper Cloud plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Web Scraper Cloud. To read its data, call the [API operations](/plugins/webscraperio/api), which return what Web Scraper Cloud has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
