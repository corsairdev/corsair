Use **Web Scraper Cloud** through Corsair: one client, typed API calls.

Create an API token in the Web Scraper Cloud app under **Account → API**. It travels as an `api_token` **query parameter**, not a header, and every call is against `https://api.webscraper.io/api/v1`.

- **The token is a query parameter.** There is no bearer header; the plugin adds `api_token` to every request, so a bare request without it is refused with `401 Unauthorized, invalid api_token.`
- **The public v1 surface is small — and this plugin wraps exactly it.** The routes the API serves are `GET /sitemaps`, `GET /sitemap/{id}`, `POST /sitemap` and `GET /account`. Scraping jobs and their scraped data live behind the Cloud web app rather than these routes, so the plugin does not invent endpoints for them; if you need job data programmatically, that is not available through this API today.
- **Two error shapes, and they mean different things.** A handled failure is `{ success: false, error }` — that is what a bad token produces. An unrouted request is Laravel's own 404 `{ message: "The route ... could not be found." }`, which means the *path* is wrong. The plugin keeps them apart, so a 404 from a mistyped path is not reported as a missing sitemap.
- **A 403 is a plan problem, not a key problem.** A 401 means the token is wrong; a 403 means the token works but the plan does not include the call.
- **A sitemap is the scraping configuration.** Its `selectors` define what is extracted and its `start_urls` where the crawl begins, so reading one tells you what a scrape would do without running it.
- **`sitemaps.create` takes the export as-is.** The body is the JSON the browser extension exports — `_id`, name, `startUrl`, `selectors`, `startUrls` — and its shape belongs to the builder, so the plugin passes it through unchanged rather than pretending to model it.
- **Lists come in two shapes.** `sitemaps.list` accepts both a flat `data` array and a paginated `data.data` object, and counts either the same way.
- **`account.get` is the cheapest check.** It returns the plan and how many pages and jobs are used against the allowance, so it verifies a token and reports the quota in one call.

**What you get:**

- 4 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/webscraperio better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/webscraperio better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/webscraperio better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/webscraperio better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { webscraperio } from '@corsair-dev/webscraperio';

export const corsair = createCorsair({
	plugins: [
		webscraperio(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
webscraperio()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'webscraperio',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List sitemaps**

```ts
const tenant = corsair.withTenant('acme');
await tenant.webscraperio.api.sitemaps.list({});
```


**Create a sitemap from an export**

```ts
const tenant = corsair.withTenant('acme');
await tenant.webscraperio.api.sitemaps.create({
	sitemap: {
		_id: 'product_catalogue',
		name: 'Product catalogue',
		startUrl: 'https://acme.example/products',
		selectors: [],
	},
});
```


See the full list on the [API](/plugins/webscraperio/api) page.
