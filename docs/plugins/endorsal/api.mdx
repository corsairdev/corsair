### post

`contacts.post`

Create a contact; with campaignID, enroll it in an AutoRequest campaign that emails the contact. Destructive because that enrollment sends email

**Risk:** `destructive`

```ts
await corsair.endorsal.api.contacts.post({ contact: { email: 'jane.doe@example.com' }, campaignID: 'campaign_123' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contact` | `object` | Yes | — |
| `campaignID` | `string` | No | — |

At least one of `contact.email` or `contact.phone` is required. `campaignID` is a query parameter, not part of the JSON body. Enrolling a contact in a campaign makes Endorsal email them a review request.

### search.post

`contacts.search.post`

Search contacts with AND-combined match conditions

**Risk:** `read`

```ts
await corsair.endorsal.api.contacts.search.post({ query: [{ field: 'name', operator: 'contains', value: 'Jane' }] });
```

**Input**

`operator` accepts the TypeScript string-literal union `'=' | '>' | '>=' | '<' | '<=' | '!=' | 'contains' | 'in'`. The `in` comparison operator requires an array value. Match objects are combined with AND.
