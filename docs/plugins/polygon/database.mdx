---
title: "Polygon OMS database"
sidebarTitle: "Database"
description: "The Polygon OMS plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Polygon OMS. To read its data, call the [API operations](/plugins/polygon/api), which return what Polygon OMS has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
