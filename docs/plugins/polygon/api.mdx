## Cash Locations

### list

`cashLocations.list`

List the retail cash locations in range, nearest first, with cursor paging

**Risk:** `read`

```ts
await corsair.polygon.api.cashLocations.list({ provider: 'retail', latitude: 47.6062, longitude: -122.3321, radius: 10, flow: 'cash_in', limit: 50 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `provider` | `string` | Yes | The cash provider configuration to query, as set up for this project. |
| `latitude` | `number` | Yes | Search center latitude. |
| `longitude` | `number` | Yes | Search center longitude. |
| `radius` | `number` | No | Search radius in miles, above 0 and at most 100. |
| `flow` | `cash_in \| cash_out` | No | Only locations that take deposits (`cash_in`) or pay out (`cash_out`). |
| `customerId` | `string` | No | Scope availability to one `cst_` customer. |
| `limit` | `number` | No | Page size, an integer from 1 to 100. A value outside that range is rejected before the request is sent; when omitted, OMS applies its default page size for the resource. |
| `startingAfter` | `string` | No | The previous page's `nextCursor`. |
| `endingBefore` | `string` | No | The previous page's `previousCursor`, to page backwards. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `object` | `string \| null` | No | — |
| `limit` | `number \| null` | No | The effective page size OMS applied. |
| `hasMore` | `boolean` | Yes | True when more rows exist in the direction of travel. |
| `nextCursor` | `string \| null` | No | Pass as `startingAfter`. |
| `previousCursor` | `string \| null` | No | Pass as `endingBefore` to page backwards. |
| `data` | `object[]` | Yes | — |

## Customers

### create

`customers.create`

Create a customer. Individuals need a first and last name; businesses need a legal name and email. Identity verification follows the project policy

**Risk:** `write`

```ts
await corsair.polygon.api.customers.create({ type: 'individual', firstName: 'Jane', lastName: 'Smith', email: 'jane@example.com', nationality: 'US' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `idempotencyKey` | `string` | No | Idempotency key for this write. Send the same value again to retry the same logical attempt rather than creating a second one; one is generated when omitted. |
| `type` | `individual \| business` | Yes | Which KYC or KYB policy this customer follows. |
| `email` | `string` | No | — |
| `phone` | `string` | No | E.164 format, such as +12125551234. |
| `externalId` | `string` | No | Your own identifier, kept on the customer for cross-referencing. |
| `signedAgreement` | `boolean` | No | Whether the customer accepted the OMS terms. Defaults to false. |
| `firstName` | `string` | No | Legal first name. Individuals only. |
| `middleName` | `string` | No | Individuals only. |
| `lastName` | `string` | No | Legal last name. Individuals only. |
| `birthDate` | `string` | No | YYYY-MM-DD. Write-only: OMS never returns it. |
| `nationality` | `string` | No | ISO 3166-1 alpha-2 country code. |
| `ipAddress` | `string` | No | Used for geo-based compliance checks. Write-only. |
| `residentialAddress` | `object` | No | Write-only: OMS never returns it. Which parts it requires depends on the project's KYC policy. |
| `companyLegalName` | `string` | No | Legal business name. Businesses only, and required to create one. |
| `dbaName` | `string` | No | — |
| `formationDate` | `string` | No | — |
| `registrationCountry` | `string` | No | — |
| `registrationNumber` | `string` | No | — |
| `websiteUrl` | `string` | No | — |
| `businessDescription` | `string` | No | — |

## Quotes

### create

`quotes.create`

Price a transfer: set the amount on one side and OMS calculates the other. Nothing moves until a transaction accepts the quote

**Risk:** `write`

```ts
await corsair.polygon.api.quotes.create({ customerId: 'cst_vfa0nxw6zvyws9g237jrxn4y7k', source: { type: 'walletCrypto', details: { id: 'wlt_5h4jzzpr9xre3bamd9ca7qyghn', asset: 'usdc', network: 'polygon' }, amount: '100.00' }, destination: { type: 'bankUs', details: { id: 'ext_fky491gakzj0dd46qb6whsr2vq', asset: 'usd', network: 'ach' } } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `idempotencyKey` | `string` | No | Idempotency key for this write. Send the same value again to retry the same logical attempt rather than creating a second one; one is generated when omitted. |
| `customerId` | `string` | Yes | The `cst_` customer this quote is for. |
| `source` | `object` | Yes | What funds the transaction. |
| `destination` | `object` | Yes | The instrument that receives the funds. |
| `sponsorGas` | `boolean` | No | When true, OMS absorbs the on-chain gas for the delivery. Only true is supported today. |
| `metadata` | `Record<string, string>` | No | Free-form pairs, copied to the resulting transaction. |
