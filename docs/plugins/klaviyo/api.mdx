## Events

### create

`events.create`

Record an event against a profile by metric name; Klaviyo creates the metric on first use, and the event can trigger flows

**Risk:** `write`

```ts
await corsair.klaviyo.api.events.create({ metric: 'Placed Order', email: 'jordan@acme.com', properties: { Total: 129.5 } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `metric` | `string` | Yes | The metric name, such as "Placed Order". Klaviyo creates the metric if it is new. |
| `profileId` | `string` | No | The profile the event belongs to. Pass this or `email`. |
| `email` | `string` | No | The profile email, when the id is not known. |
| `properties` | `Record<string, any>` | Yes | Event properties, such as a cart total. Required by the spec. |
| `value` | `number` | No | A monetary value for the event. |
| `valueCurrency` | `string` | No | — |
| `time` | `string` | No | ISO 8601 UTC timestamp. Defaults to now; Klaviyo rejects a time in the future or older than its retention window. |
| `uniqueId` | `string` | No | A caller idempotency id, deduplicating a repeated send. |
| `backfill` | `boolean` | No | Mark the event as historical rather than live. |

`metric` is a name, not an id: Klaviyo creates the metric if it is new. `properties` is required by the spec, and the profile must be given by id or email.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |

## Metrics

### aggregate

`metrics.aggregate`

Aggregate a metric into time buckets, such as a daily count over a date range, optionally grouped by a dimension

**Risk:** `read`

```ts
await corsair.klaviyo.api.metrics.aggregate({ metricId: 'Mt123', measurements: ['count'], interval: 'day', filter: ['greater-or-equal(datetime,2026-01-01T00:00:00)', 'less-than(datetime,2026-02-01T00:00:00)'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `metricId` | `string` | Yes | The metric to aggregate. |
| `measurements` | `string[]` | Yes | What to compute, such as ["count"] or ["sum_value", "count"]. |
| `interval` | `hour \| day \| week \| month` | Yes | The bucket size. |
| `pageCursor` | `string` | No | — |
| `by` | `string[]` | No | Group by these dimensions, such as ["$attributed_message"]. |
| `filter` | `string[]` | Yes | Filter expressions in Klaviyo filter syntax. A date range is required, such as ["greater-or-equal(datetime,2026-01-01T00:00:00)", "less-than(datetime,2026-02-01T00:00:00)"]. |
| `timezone` | `string` | No | — |

`filter` must carry a date range, and Klaviyo rejects the call without one. `dates` in the response are the bucket start times, and each row of `data` holds its measurement arrays in the same order.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object \| null` | No | — |
| `links` | `object \| null` | No | — |
