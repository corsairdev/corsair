## Account

### credits

`account.credits`

Read the enrichment credits left on the account; costs no credits

**Risk:** `read`

```ts
await corsair.dropcontact.api.account.credits({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `credits` | `number` | Yes | Enrichment credits left on the account. |

## Enrichment

### enrich

`enrichment.enrich`

Submit up to 250 contacts for email finding, verification and company enrichment; spends one credit per contact and returns a request_id, not the results

**Risk:** `write`

```ts
await corsair.dropcontact.api.enrichment.enrich({ data: [{ first_name: 'Denis', last_name: 'Cohen', company: 'Dropcontact' }], language: 'en' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | Up to 250 contacts. Enrichment runs as a batch, so the call returns a request_id rather than results. |
| `siren` | `boolean` | No | Ask for French SIREN company data. Defaults to false. |
| `language` | `string` | No | Language for the qualifications and civility in the result, such as "en" or "fr". Defaults to "fr". |
| `custom_callback_url` | `string` | No | Where to POST the results once the batch finishes. Overrides the account default for this request only. |
| `hashed_inputs` | `boolean` | No | Ask for the hashed inputs in the response. Sent as the `hashedInputs` query parameter. |

Spends one credit per contact and has no cancel operation. Every record needs a company identifier, an email, or a LinkedIn URL.

### results

`enrichment.results`

Read the enriched contacts for a request_id: qualified emails, LinkedIn, phone and company data; reports success false with a reason while the batch is still processing

**Risk:** `read`

```ts
await corsair.dropcontact.api.enrichment.results({ request_id: 'qzmxkpvlrtdnhwa' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `request_id` | `string` | Yes | The id `enrichment.enrich` returned. |
| `force_results` | `boolean` | No | Return whatever has already been enriched instead of asking you to retry. Adds a `status` per record (`ready` or `in_progress`). |

`status` says whether the batch is done: `in_progress` while Dropcontact is still working, `ready` once it has finished. `success` only says whether this read returned usable records, so a forced partial read can be `success: true` with `status: in_progress`. A `success: false` answer with a `reason` is a normal poll result, not a failure.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `records` | `object[]` | Yes | One entry per submitted record, in the order they were sent. Empty while a batch has not produced anything yet. |
| `creditsLeft` | `number \| null` | No | — |
| `status` | `string` | Yes | `ready` once the batch has finished, `in_progress` while Dropcontact is still processing. Dropcontact sets this field only when `force_results` is passed, so it is derived from `success` otherwise. |
| `error` | `boolean \| null` | No | — |
| `success` | `boolean` | Yes | Whether this read returned usable records. It is not a completion flag: a forced partial read is successful with `status: in_progress`. A false value is a normal poll result while a batch runs, so the call returns rather than throwing. |
| `reason` | `string \| null` | No | Present when `success` is false, such as "Request not ready yet". |

## Webhook

### get

`webhook.get`

Read the default webhook callback URL used by enrichment requests that carry no custom callback of their own

**Risk:** `read`

```ts
await corsair.dropcontact.api.webhook.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `callback_url` | `string \| null` | No | The account default, or null when none is set. |
| `error` | `boolean \| null` | No | — |
| `success` | `boolean \| null` | No | — |



---

### remove

`webhook.remove`

Delete the account default webhook callback URL; afterwards only requests carrying their own custom_callback_url notify anything

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.dropcontact.api.webhook.remove({});
```

**Input:** _empty object_

Deletes the account default callback URL permanently. Only requests that carry their own `custom_callback_url` notify anything afterwards.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `detail` | `string` | Yes | Dropcontact's confirmation message. |



---

### set

`webhook.set`

Set the account default webhook callback URL, replacing any previous one; enrichment requests without their own callback POST their results there

**Risk:** `write`

```ts
await corsair.dropcontact.api.webhook.set({ callback_url: 'https://example.com/dropcontact/results' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `callback_url` | `string` | Yes | Where to POST results for every request that does not carry its own `custom_callback_url`. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `callback_url` | `string` | Yes | — |
| `error` | `boolean \| null` | No | — |
| `success` | `boolean \| null` | No | — |
