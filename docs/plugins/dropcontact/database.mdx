---
title: "Dropcontact database"
sidebarTitle: "Database"
description: "The Dropcontact plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Dropcontact. To read its data, call the [API operations](/plugins/dropcontact/api), which return what Dropcontact has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
