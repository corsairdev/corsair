---
title: "Woodpecker Co database"
sidebarTitle: "Database"
description: "The Woodpecker Co plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Woodpecker Co. To read its data, call the [API operations](/plugins/woodpeckerco/api), which return what Woodpecker Co has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
