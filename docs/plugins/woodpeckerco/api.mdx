## Campaigns

### deleteStep

`campaigns.deleteStep`

Permanently delete an unused EMAIL or LINKEDIN step that is not the first step; the campaign must be DRAFT or EDITED

**Risk:** `destructive`

```ts
await corsair.woodpeckerco.api.campaigns.deleteStep({ campaign_id: 1234567, step_id: '36c4fb2c-6f4f-45bf-aeae-4903501193hd' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaign_id` | `number` | Yes | The campaign, in DRAFT or EDITED status. |
| `step_id` | `string \| number` | Yes | The EMAIL or LINKEDIN step's `id` from the campaign's `steps`. It cannot be the first step after START or a step that has processed prospects. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | — |
| `campaign_id` | `number` | Yes | — |
| `step_id` | `string \| number` | Yes | — |
| `campaign` | `object` | No | The campaign as it stands after the deletion. |

### list

`campaigns.list`

List campaigns, optionally filtered by status or ID; asking for exactly one ID also returns its statistics

**Risk:** `read`

```ts
await corsair.woodpeckerco.api.campaigns.list({ status: ['RUNNING', 'PAUSED'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `(RUNNING \| DRAFT \| EDITED \| PAUSED \| STOPPED \| COMPLETED)[]` | No | Only campaigns in these statuses. |
| `id` | `number[]` | No | Only these campaigns. Exactly one ID also returns its `stats`; several return the plain list. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaigns` | `object[]` | Yes | — |

## Prospects

### addToCampaign

`prospects.addToCampaign`

Add up to 20,000 prospects to a campaign, also creating them in the global list; each result says if that prospect was a duplicate or rejected

**Risk:** `write`

```ts
await corsair.woodpeckerco.api.prospects.addToCampaign({ campaign: { campaign_id: 1234567 }, prospects: [{ email: 'jordan@acme-logistics.com', first_name: 'Jordan', snippet1: 'Saw your talk in Austin' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaign` | `object` | Yes | — |
| `force` | `boolean` | No | Add prospects whose global status is not ACTIVE. Use with caution: they may be contacted again even after replying elsewhere or opting out. |
| `file_name` | `string` | No | Name of the import batch, shown in the imported column. |
| `prospects` | `object[]` | Yes | — |

### listInCampaigns

`prospects.listInCampaigns`

List the prospects in one or more campaigns with their campaign status and interest level, with filters, sorting and paging

**Risk:** `read`

```ts
await corsair.woodpeckerco.api.prospects.listInCampaigns({ campaigns_id: [1234567], status: 'REPLIED', sort: '-updated', per_page: 50 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaigns_id` | `number[]` | Yes | The campaigns to read prospects from. |
| `id` | `number[]` | No | Only these prospects. |
| `status` | `ACTIVE \| BOUNCED \| TO-CHECK \| TO-REVIEW \| REPLIED \| AUTOREPLIED \| BLACKLIST \| PAUSED \| INVALID` | No | The prospect's status in the campaign. |
| `contacted` | `boolean` | No | — |
| `interested` | `INTERESTED \| MAYBE-LATER \| NOT-INTERESTED \| NOT-MARKED` | No | — |
| `activity` | `OPENED \| NOT-OPENED \| CLICKED \| NOT-CLICKED` | No | — |
| `diff` | `string` | No | Only prospects with an activity timestamp after this date, such as 2025-01-15T00:00:00+0200. The + is percent-encoded for you. |
| `sort` | `string` | No | Fields with + (ascending) or - (descending), comma-separated, such as +company,-last_contacted. |
| `page` | `number` | No | 1-based page. |
| `per_page` | `number` | No | Defaults to 100. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `prospects` | `object[]` | Yes | — |
| `page` | `number` | Yes | — |
| `per_page` | `number` | Yes | — |
| `next_page` | `number \| null` | Yes | The next page while this one is full; null once a page comes back short. A full last page leads to one empty page. |
| `message` | `string` | No | Woodpecker's note when nothing matched. |
