Use **Vapi** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 34 typed API operations
- 7 synced entities (`assistants`, `calls`, `files`, `knowledgeBases`, `phoneNumbers`, `squads`, and 1 more) for fast `.search()` / `.list()`
- 6 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/vapi better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/vapi better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/vapi better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/vapi better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { vapi } from '@corsair-dev/vapi';

export const corsair = createCorsair({
	plugins: [
		vapi(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Vapi API key before the first call: `pnpm corsair setup --plugin=vapi --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

Provider walkthrough: [Get Credentials](/plugins/vapi/get-credentials).

```ts
vapi()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'vapi',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`assistants.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.vapi.api.assistants.get({});
```


**`assistants.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.vapi.api.assistants.create({});
```


See the full list on the [API](/plugins/vapi/api) page.

## Query synced data

Synced entities support `tenant.vapi.db.<entity>.search()` and `.list()`: `assistants`, `calls`, `files`, `knowledgeBases`, `phoneNumbers`, `squads`, `tools`.

See [Database](/plugins/vapi/database) for filters and operators.

## Webhooks

This plugin registers **6** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/vapi/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
