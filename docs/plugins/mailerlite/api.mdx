## Campaigns

### activity

`campaigns.activity`

List the recipients of a sent campaign with their open and click activity

**Risk:** `read`

```ts
await corsair.mailerlite.api.campaigns.activity({ campaignId: '66200823885989563', limit: 50 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | Id of a sent campaign |
| `filterType` | `opened \| unopened \| clicked \| unsubscribed \| forwarded \| hardbounced \| softbounced \| junk \| sent \| social_interaction` | No | Only recipients with this kind of activity |
| `filterSearch` | `string` | No | Only the activity of the subscriber with this email address |
| `limit` | `10 \| 25 \| 50 \| 100` | No | Recipients per page: 10, 25, 50 or 100 |
| `sort` | `string` | No | Sort field, prefix with - for descending order |
| `page` | `number` | No | Page number to return, counting from 1 |
| `include` | `subscriber \| subscriber.groups` | No | Relations to embed in the response |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `links` | `object \| null` | No | — |
| `meta` | `object` | Yes | — |

### create

`campaigns.create`

Create a draft campaign with recipients and email content. Nothing is sent until campaigns.schedule runs

**Risk:** `write`

```ts
await corsair.mailerlite.api.campaigns.create({ name: 'October update', type: 'regular', emails: [{ subject: 'Our October update', from_name: 'Acme Logistics', from: 'news@acme-logistics.com' }], groups: ['42'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Campaign name, up to 255 characters |
| `type` | `regular \| ab \| resend \| multivariate` | Yes | Campaign kind. resend and multivariate need a paid plan |
| `language_id` | `number` | No | Language for the unsubscribe template. Defaults to English |
| `emails` | `object[]` | Yes | Exactly one email object, unless this is a multivariate campaign testing content |
| `groups` | `string[]` | No | Group ids to send to. Ignored when segments is also given |
| `segments` | `string[]` | No | Segment ids to send to. Takes precedence over groups |
| `ab_settings` | `object` | No | — |
| `resend_settings` | `object` | No | — |
| `multivariate_settings` | `object` | No | — |
| `settings` | `object` | No | — |

### schedule

`campaigns.schedule`

Schedule a ready draft, or send it now with delivery instant. This emails real recipients and an instant send cannot be unsent

**Risk:** `write`

```ts
await corsair.mailerlite.api.campaigns.schedule({ campaignId: '1', delivery: 'scheduled', schedule: { date: '2026-12-01', hours: '09', minutes: '30' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | Campaign id |
| `delivery` | `instant \| scheduled \| timezone_based \| smart_sending` | No | When to send. instant sends now and cannot be unsent; required unless the campaign type is rss, which takes no body |
| `schedule` | `object` | No | Send time, used by the scheduled, timezone_based and smart_sending deliveries |
| `resend` | `object` | No | Second-send time, for auto-resend campaigns only |
| `sending_time_test_schedule` | `object[]` | No | Send times to test, ordered soonest first. Only for campaigns testing sending time: exactly 2 entries for A/B, 2-8 for multivariate |

### upsert

`subscribers.upsert`

Create a subscriber or update an existing one matched by email. Repeating the call is safe: it never deletes fields or group membership

**Risk:** `write`

```ts
await corsair.mailerlite.api.subscribers.upsert({ email: 'jordan@acme-logistics.com', fields: { name: 'Jordan' }, groups: ['4243829086487936'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | Subscriber email address, RFC 2821 |
| `fields` | `Record<string, string \| number \| null>` | No | Custom field values keyed by field key. Unknown keys are ignored; omission never removes a value |
| `groups` | `string[]` | No | Group ids to add the subscriber to. Additive only: omission never removes membership |
| `status` | `active \| unsubscribed \| unconfirmed \| bounced \| junk` | No | Subscriber status. New subscribers default to active, or unconfirmed on double opt-in accounts |
| `subscribed_at` | `string` | No | Subscribe time, yyyy-MM-dd HH:mm:ss, at most one hour in the future |
| `ip_address` | `string` | No | Signup IP address. A value that is not a valid IP address is ignored |
| `opted_in_at` | `string` | No | Opt-in confirmation time |
| `optin_ip` | `string` | No | Confirmation IP address. A value that is not a valid IP address is ignored |
| `unsubscribed_at` | `string` | No | Unsubscribe time; only used together with status unsubscribed |
| `resubscribe` | `boolean` | No | Set true to reactivate an unsubscribed, bounced or junk subscriber. Without it, a request that omits status fails with 422 |
| `double_optin` | `boolean` | No | Whether a new subscriber starts as unconfirmed. Ignored by most API tokens |
| `notes` | `string[]` | No | Free-text notes, each up to 10000 characters. Ignored for existing subscribers |
