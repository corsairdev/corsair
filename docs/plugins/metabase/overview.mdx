Use **Metabase** through Corsair: one client, typed API calls.

Metabase's REST API is unversioned. The official latest reference currently describes Metabase 65, but available endpoints vary by the installed instance. This plugin implements the collection and collection-permissions routes whose request and response schemas are declared in that reference. An API key inherits permissions from the group assigned when the key is created. Configure the instance origin in `metabase({ baseUrl })`; every request sends `X-API-Key`, omits cookies, and refuses redirects so the key is not forwarded to another host. HTTP is accepted only for localhost development.

**What you get:**

- 18 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/metabase better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/metabase better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/metabase better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/metabase better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { metabase } from '@corsair-dev/metabase';

export const corsair = createCorsair({
	plugins: [
		metabase({
			baseUrl: 'https://metabase.invalid',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Metabase API key before the first call: `pnpm corsair setup --plugin=metabase --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

`baseUrl` is the administrator-configured origin of the Metabase instance. It cannot be supplied by an endpoint caller; use HTTPS, or HTTP only for localhost development. The API key is stored separately as Corsair tenant credentials.

```ts
metabase({
	baseUrl: 'https://metabase.invalid',
})
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'metabase',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`collectionPermissions.graph.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.metabase.api.collectionPermissions.graph.get({});
```


**`collectionPermissions.graph.update`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.metabase.api.collectionPermissions.graph.update({});
```
