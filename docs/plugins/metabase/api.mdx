### graph.update

`collectionPermissions.graph.update`

Replace collection permission graph entries

**Risk:** `destructive`

```ts
await corsair.metabase.api.collectionPermissions.graph.update({
	body: {
		groups: {
			2: { 8: 'read' },
		},
		revision: 1,
	},
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `object` | No | — |
| `body` | `object` | Yes | — |

The graph update can overwrite permission entries. Metabase documents `force=true` as persisting the supplied graph without requiring a revision, which may clobber intervening writes. This operation is marked destructive.

<AccordionGroup>
<Accordion title="query full type">

```ts
{
  force?: boolean | null,
  skip-graph?: boolean | null
}
```
</Accordion>

<Accordion title="body full type">

```ts
{
  groups: Record<string, Record<string, write | read | none>>,
  namespace?: string | null,
  revision?: number | null
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `revision` | `number \| null` | No | — |

### items.list

`collections.items.list`

List items in a collection

**Risk:** `read`

```ts
await corsair.metabase.api.collections.items.list({
	path: { id: 8 },
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `path` | `object` | Yes | — |
| `query` | `object` | No | — |

The `data` array contains heterogeneous collection items. The official OpenAPI schema intentionally leaves item properties open; the plugin preserves JSON-compatible fields instead of claiming a fixed item model. Metabase returns `limit` and `offset` where applicable, but the documented route does not expose them as request parameters.

<AccordionGroup>
<Accordion title="path full type">

```ts
{
  id: number | string
}
```
</Accordion>

<Accordion title="query full type">

```ts
{
  q?: string | null,
  pinned-state?: is_not_pinned | is_pinned | all | null,
  archived?: boolean | null,
  sort-direction?: desc | asc | null,
  show-dashboard-questions?: boolean | null,
  show-exploration-documents?: boolean | null,
  include-available-models?: boolean | null,
  models?: (dashboard | table | exploration | dataset | no_models | timeline | snippet | collection | measure | transform | document | pulse | action | metric | card)[] | null,
  official-collections-first?: boolean | null,
  sort-column?: model | name | last_edited_by | last_edited_at | description | null
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
