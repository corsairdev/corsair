## Counters

### get

`counters.get`

Read a Backendless atomic counter.

**Risk:** `read`

```ts
const tenant = corsair.withTenant('acme');
await tenant.backendless.api.counters.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `counterName` | `string` | Yes | — |



**Output:** `number`
