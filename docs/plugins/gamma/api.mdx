## Agent

### generate

`agent.generate`

Start a Gamma 5 agent generation from one brief, with a theme, template, quality preset and up to 10 source URLs. Spends credits

**Risk:** `destructive`

```ts
await corsair.gamma.api.agent.generate({ prompt: 'A deck about solar power for a finance audience', format: 'presentation', quality: 'standard', sourceUrls: ['https://acme.example/report'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `prompt` | `string` | Yes | The brief: what to generate. The only required field. |
| `title` | `string` | No | — |
| `format` | `presentation \| document \| social` | No | Defaults to `presentation`. A webpage needs `generations.create`. |
| `numCards` | `number` | No | Target cards, capped by the plan’s maximum. |
| `themeId` | `string` | No | — |
| `templateId` | `string` | No | An accessible workspace template. |
| `quality` | `lite \| standard \| max` | No | A quality preset; `max` spends more credits. |
| `additionalInstructions` | `string` | No | — |
| `exportAs` | `pdf \| pptx \| png` | No | — |
| `folderId` | `string` | No | — |
| `sourceUrls` | `string[]` | No | Up to 10 pages the agent reads as source material. |
| `disableConnectors` | `boolean` | No | Opt this run out of the workspace’s connectors. |
| `sharingOptions` | `object` | No | — |

The Gamma 5 route for a new presentation, document or social post. `prompt` is the only required field.

<AccordionGroup>
<Accordion title="sharingOptions full type">

```ts
{
  workspaceAccess?: comment | edit | fullAccess | noAccess | view,
  externalAccess?: comment | edit | noAccess | view,
  emailOptions?: {
    access?: comment | edit | fullAccess | view,
    recipients: string[]
  }
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `generationId` | `string` | Yes | — |
| `status` | `string \| null` | No | — |
| `warnings` | `object[] \| null` | No | Options Gamma ignored or could not apply. Keep them: the status read does not always repeat them. |

<AccordionGroup>
<Accordion title="warnings full type">

```ts
{
  code: string,
  message?: string | null
}[] | null
```
</Accordion>
</AccordionGroup>

### get

`agent.get`

Where an agent generation stands, with the same terminal states as a Classic one

**Risk:** `read`

```ts
await corsair.gamma.api.agent.get({ generationId: 'gen_agent1' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `generationId` | `string` | Yes | The `generationId` a create returned. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `generationId` | `string` | Yes | — |
| `status` | `string` | Yes | `pending` is not final; `completed` and `failed` are. |

| `credits` | `object \| null` | No | — |
| `updatedTime` | `string \| null` | No | — |

## Exports

### get

`exports.get`

Where an export stands. `completed` carries a download URL that works for anyone holding it, for about a week

**Risk:** `read`

```ts
await corsair.gamma.api.exports.get({ exportId: 'exp_1' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `exportId` | `string` | Yes | The `exportId` the export returned. |

`completed` carries a download URL valid about a week. A `png` export is a zip of one image per card.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `exportId` | `string \| null` | No | — |
| `gammaId` | `string \| null` | No | — |
| `exportAs` | `string \| null` | No | — |
| `status` | `string` | Yes | `pending` is not final; `completed` and `failed` are. |
| `exportUrl` | `string \| null` | No | A download link valid about a week. Anyone holding it can download the file, so treat it as a secret and do not log it. |
| `error` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="error full type">

```ts
{
  message?: string | null,
  statusCode?: number | null
} | null
```
</Accordion>
</AccordionGroup>

### start

`exports.start`

Start an export of an existing gamma to PDF, PPTX or PNG, returning an `exportId`. A PNG export is a zip of one image per card

**Risk:** `write`

```ts
await corsair.gamma.api.exports.start({ gammaId: 'gam_xyz789', format: 'pptx' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `gammaId` | `string` | Yes | The Gamma file ID, or the doc ID from a `gamma.app/docs/...` URL. |
| `format` | `pdf \| pptx \| png` | Yes | Sent as Gamma’s `exportAs`, which is required. A `png` export is a zip of one image per card. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `exportId` | `string` | Yes | — |
| `status` | `string \| null` | No | — |

## Gammas

### archive

`gammas.archive`

Archive a gamma. Idempotent, and reversible from the Gamma app, so it is not destructive

**Risk:** `write`

```ts
await corsair.gamma.api.gammas.archive({ gammaId: 'gam_xyz789' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `gammaId` | `string` | Yes | The Gamma file ID, or the doc ID from a `gamma.app/docs/...` URL. |

Idempotent and reversible, so it is a write rather than a destructive call.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | — |
| `gamma_id` | `string` | Yes | — |

### search

`gammas.search`

Full-text search over the gammas the caller can read. Needs `q` or a filter (`createdBy`, `updatedAfter`, `updatedBefore`)

**Risk:** `read`

| `updatedAfter` | `string` | No | ISO 8601. |
| `updatedBefore` | `string` | No | ISO 8601. |
| `includeArchived` | `boolean` | No | — |
| `limit` | `number` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `hits` | `object[]` | Yes | — |

## Generations

### create

`generations.create`

Start a Classic generation from text or a `pages` array, at once returning a `generationId` to poll. Spends credits. Use it for webpages and multi-page gammas; the agent route covers a single new presentation

**Risk:** `destructive`

```ts
await corsair.gamma.api.generations.create({ inputText: 'Create a presentation about renewable energy', textMode: 'generate', format: 'presentation', numCards: 12 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `inputText` | `string` | No | — |
| `pages` | `object[]` | No | A multi-page gamma. Takes precedence over the per-page fields at the top level. |
| `format` | `presentation \| document \| social \| webpage` | No | — |
| `textMode` | `generate \| condense \| preserve` | No | — |
| `cardSplit` | `auto \| inputTextBreaks` | No | — |
| `exportAs` | `pdf \| pptx \| png` | No | Export automatically once the gamma is done. A `png` export is a zip of one image per card. |
| `title` | `string` | No | — |
| `additionalInstructions` | `string` | No | — |
| `publish` | `boolean` | No | Publish a multi-page gamma as a site once every page succeeds. |
| `numCards` | `number` | No | — |
| `themeId` | `string` | No | An `id` from `themes.list`. |
| `textOptions` | `object` | No | — |
| `imageOptions` | `object` | No | — |
| `cardOptions` | `object` | No | — |
| `sharingOptions` | `object` | No | — |
| `folderId` | `string` | No | The folder to place the gamma in. |

Takes `inputText` or a `pages` array, never both. `publish` applies only to a multi-page generation.

### get

`generations.get`

Where a Classic generation stands: `pending` is not final, `completed` carries the gamma ID, URL and any export URL, `failed` carries the error

**Risk:** `read`

```ts
await corsair.gamma.api.generations.get({ generationId: 'gen_abc123' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `generationId` | `string` | Yes | The `generationId` a create returned. |

Poll until `status` is `completed` or `failed`. The `exportUrl` it may carry is a download link that works for anyone holding it, so it is never logged.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `generationId` | `string` | Yes | — |
| `status` | `string` | Yes | `pending` is not final; `completed` and `failed` are. |
| `gammaId` | `string \| null` | No | Set once the generation completes. |
| `gammaUrl` | `string \| null` | No | — |
| `error` | `object \| null` | No | — |
| `exportUrl` | `string \| null` | No | A download link for the export, valid for about a week. Anyone holding it can download the file, so treat it as a secret and do not log it. |
| `credits` | `object \| null` | No | — |
| `pages` | `object[] \| null` | No | Per-page results, only for a multi-page generation. |
