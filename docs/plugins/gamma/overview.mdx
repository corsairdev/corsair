Use **Gamma** through Corsair: one client, typed API calls.

Create an API key in Gamma under Account settings, API keys. It is sent in the `X-API-KEY` header.

Things to know before you call:

- **Two generation routes, and they are not interchangeable.** `agent.generate` runs Gamma 5 from a single brief and is the one to use for a new presentation, document or social post. `generations.create` is the Classic path: it is the only one that takes a `pages` array for a multi-page gamma or site, and the only one that publishes with `publish: true`. A Classic body carries either `inputText` or `pages`, never both, and the plugin refuses a body with neither.
- **A generation is asynchronous.** Both creates return a `generationId` at once, and a poll answers `pending` until it is `completed` or `failed` (which carries an `error`). A completed Classic generation carries `gammaId` and `gammaUrl` at the top level; an agent generation nests them under `gamma`, next to the agent's `result.summary`. Spends credits.
- **`exportUrl` is a credential.** The download link works for anyone holding it, for about a week, and Gamma's own docs say to treat it as a secret. The plugin never logs it; `generations.get` and `exports.get` report only whether one arrived.
- **`png` exports are archives.** A PNG export is a zip of one image per card, not a single file, and `pptx` and `pdf` match their own formats.
- **Archiving is not deleting.** `gammas.archive` is idempotent and reversible from the Gamma app, so it is a write rather than a destructive call. `gammas.delete` is permanent and needs a workspace admin role.
- **A 403 has several meanings.** A web app URL slug sent where a file ID belongs, a workspace below Pro on the analytics routes, a key owner without the permission, or, on the agent routes, a workspace out of credits (`code: insufficient_credits`, which the plugin reports as `isQuotaError`; Classic routes answer `402` for that). The `code` says which; `individual_analytics_required` is the analytics case.
- **A 429 can be a job cap, not a rate.** Gamma adds `code: workspace_concurrency_limit_exceeded` when a Free workspace already has too many pending jobs started with an API key, and sends `Retry-After`. The plugin retries both, honouring the header.
- **Credits are reported per generation.** A completed `generations.get` carries `credits.deducted` and `credits.remaining`, which is how you see what a run cost.
- **No webhooks.** Gamma does not push; poll the generation until it is `completed` or `failed`.

- 12 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/gamma better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/gamma better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/gamma better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/gamma better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { gamma } from '@corsair-dev/gamma';

export const corsair = createCorsair({
	plugins: [
		gamma(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Gamma API key before the first call: `pnpm corsair setup --plugin=gamma --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
gamma()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'gamma',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Search your gammas**

```ts
const tenant = corsair.withTenant('acme');
await tenant.gamma.api.gammas.search({ q: 'quarterly review', limit: 10 });
```


**Generate a presentation from a brief**

```ts
const tenant = corsair.withTenant('acme');
await tenant.gamma.api.agent.generate({ prompt: 'A ten-slide deck about renewable energy for a finance audience' });
```
