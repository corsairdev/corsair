The Faraday plugin syncs data locally. Use `corsair.faraday.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Accounts

Path: `faraday.db.accounts.search`

```ts
const rows = await corsair.faraday.db.accounts.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `name` | `string` | equals, contains, startsWith, endsWith, in |
| `resource_type` | `string` | equals, contains, startsWith, endsWith, in |
| `created_at` | `string` | equals, contains, startsWith, endsWith, in |
| `updated_at` | `string` | equals, contains, startsWith, endsWith, in |
| `archived_at` | `string` | equals, contains, startsWith, endsWith, in |
| `status_changed_at` | `string` | equals, contains, startsWith, endsWith, in |
| `status_error` | `string` | equals, contains, startsWith, endsWith, in |
| `last_read_input_at` | `string` | equals, contains, startsWith, endsWith, in |
| `last_updated_config_at` | `string` | equals, contains, startsWith, endsWith, in |
| `last_updated_output_at` | `string` | equals, contains, startsWith, endsWith, in |
| `contract_started_at` | `string` | equals, contains, startsWith, endsWith, in |
| `parent_account_id` | `string` | equals, contains, startsWith, endsWith, in |
| `stripe_customer_id` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
