Use **Ecologi** through Corsair: one client, typed API calls, local DB sync.

The reporting reads (`*.get`) are public: they send no API key and work for any Ecologi username. An unknown username returns HTTP 404. The username is the row id and is not written to the event.

The purchase operations (`*.purchase`, `trees.purchaseLocal`) spend money. They need the API key from Ecologi's Impact API page, sent as a Bearer token, and are billed to the account on the 1st of each month (minimum invoice GBP 3). Pass `test: true` to get the expected response without being charged. Send an `idempotencyKey` so a retried request is not bought twice. The `name` is shown publicly on a public profile, so don't send a customer's name without permission. A `recipientEmail` sends that person an email about the purchase.

**What you get:**

- 10 typed API operations
- 5 synced entities (`carbonOffsets`, `carbonRemovals`, `habitats`, `impacts`, `trees`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/ecologi better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/ecologi better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/ecologi better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/ecologi better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { ecologi } from '@corsair-dev/ecologi';

export const corsair = createCorsair({
	plugins: [
		ecologi(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Ecologi API key before the first call: `pnpm corsair setup --plugin=ecologi --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
ecologi()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'ecologi',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read trees**

```ts
const tenant = corsair.withTenant('acme');
await tenant.ecologi.api.trees.get({ username: 'ecologi' });
```


**`carbonOffsets.purchase`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.ecologi.api.carbonOffsets.purchase({});
```


See the full list on the [API](/plugins/ecologi/api) page.

## Query synced data

Synced entities support `tenant.ecologi.db.<entity>.search()` and `.list()`: `carbonOffsets`, `carbonRemovals`, `habitats`, `impacts`, `trees`.

See [Database](/plugins/ecologi/database) for filters and operators.
