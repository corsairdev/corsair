## Carbon Offsets

### get

`carbonOffsets.get`

Read the CO2e avoided by an Ecologi username.

**Risk:** `read`

```ts
await corsair.ecologi.api.carbonOffsets.get({ username: 'ecologi' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `username` | `string` | Yes | — |

GET /users/{username}/carbon-offset. Stored fields are total and pending.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `total` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="total full type">

```ts
{
  id: string,
  total: number,
  pending: number
}
```
</Accordion>
</AccordionGroup>

## Impacts

### get

`impacts.get`

Read the combined impact for an Ecologi username.

**Risk:** `read`

```ts
await corsair.ecologi.api.impacts.get({ username: 'ecologi' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `username` | `string` | Yes | — |

GET /users/{username}/impact. Stores the four totals and the four pending totals.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `impact` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="impact full type">

```ts
{
  id: string,
  trees: number,
  carbonOffset: number,
  carbonRemoval: number,
  habitatRestoration: number,
  pendingTrees: number,
  pendingCarbonOffset: number,
  pendingCarbonRemoval: number,
  pendingHabitatRestoration: number
}
```
</Accordion>
</AccordionGroup>
