## Carbon Offsets

### get

`carbonOffsets.get`

Read the CO2e avoided by an Ecologi username.

**Risk:** `read`

```ts
await corsair.ecologi.api.carbonOffsets.get({ username: 'ecologi' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `username` | `string` | Yes | — |

GET /users/&#123;username&#125;/carbon-offset. Stored fields are total and pending.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `total` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="total full type">

```ts
{
  id: string,
  total: number,
  pending: number
}
```
</Accordion>
</AccordionGroup>



---

### purchase

`carbonOffsets.purchase`

Buy carbon avoidance by the kg or tonne (GBP 9.45 a tonne). Billed monthly; test: true charges nothing.

**Risk:** `destructive`

```ts
await corsair.ecologi.api.carbonOffsets.purchase({ number: 10, units: 'KG', test: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `number` | `number` | Yes | Amount to buy, at least 1 kg (0.001 tonnes). |
| `units` | `KG \| Tonnes` | Yes | — |
| `name` | `string` | No | "Funded by" label on the Ecologi profile. Public if the profile is public; never send a customer name without permission. |
| `test` | `boolean` | No | true returns the expected response without charging or adding it to the profile. |
| `recipientEmail` | `string` | No | Sends this address a templated email about the purchase (not in test mode). |
| `idempotencyKey` | `string` | No | Sent as the Idempotency-Key header so a retried request is not bought twice. |

POST /impact/carbon with `units` KG or Tonnes, at least 1 kg. Funding may be split across projects.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `amount` | `number` | No | — |
| `currency` | `string` | No | — |
| `number` | `number` | No | — |
| `units` | `string` | No | — |
| `numberInTonnes` | `number` | No | — |
| `treeUrl` | `string` | No | — |
| `tileUrl` | `string` | No | — |
| `name` | `string \| null` | No | — |
| `recipientEmail` | `string` | No | — |
| `projectDetails` | `object[]` | No | — |

<AccordionGroup>
<Accordion title="projectDetails full type">

```ts
{
  name?: string,
  projectUrl?: string,
  splitPercentage?: number,
  splitAmountTrees?: number,
  splitAmountTonnes?: number,
  quantity?: number
}[]
```
</Accordion>
</AccordionGroup>
