## Bee Plugin

### suspendUser

`beePlugin.suspendUser`

Suspend or reinstate a Bee Plugin user

**Risk:** `write`

```ts
await corsair.niftyimages.api.beePlugin.suspendUser({ pluginKey: 'YOUR_PLUGIN_KEY', user: 'Test User', suspend: false });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `pluginKey` | `string` | Yes | The Bee Plugin key from the NiftyImages app. |
| `user` | `string` | Yes | The Bee Plugin user name. |
| `suspend` | `boolean` | Yes | true suspends the user, false lifts the suspension. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | — |
