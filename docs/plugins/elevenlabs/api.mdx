| Name | Type | Required | Description |

## Audio Isolation

### isolate

`audioIsolation.isolate`

Remove background noise from audio and keep the voices; spends credits by audio length. The cleaned audio comes back in the result.

**Risk:** `write`

```ts
await corsair.elevenlabs.api.audioIsolation.isolate({ fileBase64: '<base64 audio>', fileName: 'noisy.mp3', contentType: 'audio/mpeg' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileBase64` | `string` | Yes | The file, base64-encoded (at most 100 MB once decoded). |
| `fileName` | `string` | No | — |
| `contentType` | `string` | No | Media type of the file, for example audio/mpeg. |
| `fileFormat` | `pcm_s16le_16 \| other` | No | pcm_s16le_16 for raw 16-bit 16 kHz mono PCM, which is faster. Default other. |

ElevenLabs refuses audio under about 4.6 s. No history item, so the output always comes back in the result. It takes no `outputFormat`, and a clip of about 7.5 s came back as 302,018 bytes in one run, so in a script hand on anything over about 18 s instead of returning it.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contentBase64` | `string` | No | The output, base64-encoded. Missing when contentOmitted is set. |
| `contentType` | `string` | Yes | Media type of the output, for example audio/mpeg. |
| `byteLength` | `number` | Yes | Size of the output in bytes. |
| `contentOmitted` | `not_requested \| over_limit` | No | Set when contentBase64 was left out: includeContent was false, or the output was over the limit. |
| `note` | `string` | No | How to get output that was left out. |
| `songId` | `string` | No | The `song-id` header, on generated music. |
| `requestId` | `string` | No | The `request-id` header. Pass it as previousRequestIds for continuity between clips. |
| `traceId` | `string` | No | The `x-trace-id` header; quote it to ElevenLabs support. |
| `characterCost` | `number` | No | Credits charged, from the `character-cost` header. Music and stem separation don’t send it; account.usageStats has their cost. |
| `historyItemId` | `string` | No | The history item holding this audio. Read it again with history.getAudio. Only speech operations have one. |

## Dubbing

### create

`dubbing.create`

Start dubbing a video or audio file into another language; spends credits by length. Returns at once with a dubbing_id; follow it with dubbing.get until status is dubbed or failed.

**Risk:** `write`

```ts
await corsair.elevenlabs.api.dubbing.create({ sourceUrl: 'https://example.com/clip.mp4', targetLang: 'es', watermark: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileBase64` | `string` | No | The file, base64-encoded (at most 100 MB once decoded). |
| `fileName` | `string` | No | — |
| `contentType` | `string` | No | Media type of the file, for example audio/mpeg. |
| `sourceUrl` | `string` | No | URL of the video or audio, instead of fileBase64. |
| `targetLang` | `string` | Yes | Language to dub into, as an ISO 639 code. |
| `sourceLang` | `string` | No | Default auto. |
| `name` | `string` | No | — |
| `numSpeakers` | `number` | No | 0 (default) detects them. |
| `watermark` | `boolean` | No | — |
| `startTime` | `number` | No | — |
| `endTime` | `number` | No | — |
| `highestResolution` | `boolean` | No | — |
| `dropBackgroundAudio` | `boolean` | No | — |
| `useProfanityFilter` | `boolean` | No | — |
| `disableVoiceCloning` | `boolean` | No | true uses a similar voice from the library instead of cloning the speakers in the source. |

Returns at once. Follow `dubbing_id` with `dubbing.get` until `status` is `dubbed` or `failed`. By default dubbing clones the speakers it hears; set `disableVoiceCloning` true to use library voices instead.



**Output**

| `dubbing_id` | `string` | Yes | — |

### getAudio

`dubbing.getAudio`

Download a finished dub as base64 (audio or video), subject to the same size limit as other audio.

**Risk:** `read`

```ts
await corsair.elevenlabs.api.dubbing.getAudio({ dubbingId: '<dubbing id>', languageCode: 'es', maxBytes: 10000000 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `dubbingId` | `string` | Yes | The dubbing_id that dubbing.create returned. |
| `languageCode` | `string` | Yes | A target language of the dub; for transcripts also `source`. |
| `includeContent` | `boolean` | No | false returns the size and type only. Default true. |
| `maxBytes` | `number` | No | Largest audio to carry in the result, in bytes. Over it, contentBase64 is left out and contentOmitted says so. Default 700000 (about 43 s of 128 kbps mp3), so the base64 fits the 1,000,000 byte cap on a script’s result on Corsair’s cloud. At most 50 MB. |

Audio or video, per `contentType`. Subject to `maxBytes`, so raise it for anything long.



**Output**

| `contentType` | `string` | Yes | Media type of the output, for example audio/mpeg. |
| `byteLength` | `number` | Yes | Size of the output in bytes. |
| `contentOmitted` | `not_requested \| over_limit` | No | Set when contentBase64 was left out: includeContent was false, or the output was over the limit. |
| `note` | `string` | No | How to get output that was left out. |
| `songId` | `string` | No | The `song-id` header, on generated music. |
