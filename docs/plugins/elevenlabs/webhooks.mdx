The ElevenLabs plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/elevenlabs/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `conversations`
  - `callInitiationFailure` (`conversations.callInitiationFailure`)
  - `postCallAudio` (`conversations.postCallAudio`)
  - `postCallTranscription` (`conversations.postCallTranscription`)
- `speechToText`
  - `transcriptionCompleted` (`speechToText.transcriptionCompleted`)
  - `transcriptionFailed` (`speechToText.transcriptionFailed`)
- `voices`
  - `removalNotice` (`voices.removalNotice`)
  - `removalNoticeWithdrawn` (`voices.removalNoticeWithdrawn`)
  - `removed` (`voices.removed`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Events

## Conversations

### Call Initiation Failure

`conversations.callInitiationFailure`

A phone call could not be started: busy, no answer or unknown.

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `call_initiation_failure` | Yes | — |
| `event_timestamp` | `number \| string \| null` | No | When the event happened, in Unix time. |
| `data` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  agent_id?: string | null,
  conversation_id?: string | null,
  failure_reason?: string | null,
  metadata?: Record<string, any> | null
} | null
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  type: call_initiation_failure,
  event_timestamp?: number | string | null,
  data?: {
    agent_id?: string | null,
    conversation_id?: string | null,
    failure_reason?: string | null,
    metadata?: Record<string, any> | null
  } | null
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
elevenlabs({
    webhookHooks: {
        conversations: {
            callInitiationFailure: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
