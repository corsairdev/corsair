title: Webhooks
description: "ElevenLabs incoming webhooks: event paths, payloads, and response data."
---

The ElevenLabs plugin handles incoming webhooks. In ElevenLabs, create a webhook under Developers, Webhooks with HMAC auth, point it at your Corsair HTTP handler, and save the secret it shows you as the account's `webhook_signature` (see [Overview](/plugins/elevenlabs/overview) for setup). Tick the events you want; post-call events also need the webhook selected in the agent's settings. Deliveries name no account, so with several tenants add `?tenantId=<id>` to the URL. The signature covers the body but not the URL, so `?tenantId=` only picks which tenant's secret checks a delivery. When tenants share a secret, by storing the same one or through the `webhookSecret` option, anyone holding a signed delivery under 30 minutes old can resend it with another `tenantId`, and that tenant's hooks run on it. Give each tenant its own webhook secret, or check in an `after` hook that the event's ids belong to that tenant before acting on it. By then the plugin has logged the event under that tenant. A `before` hook runs ahead of the signature check, so it can receive an unsigned or forged delivery. Keep side effects in `after`. The same event can arrive more than once, from ElevenLabs' retries or from someone resending a signed delivery within 30 minutes, so make hooks safe to run twice, for example by recording the `conversation_id` or `request_id` each one acted on.

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `conversations`
  - `callInitiationFailure` (`conversations.callInitiationFailure`)
  - `postCallAudio` (`conversations.postCallAudio`)
  - `postCallTranscription` (`conversations.postCallTranscription`)
- `speechToText`
  - `transcriptionCompleted` (`speechToText.transcriptionCompleted`)
  - `transcriptionFailed` (`speechToText.transcriptionFailed`)
- `voices`
  - `removalNotice` (`voices.removalNotice`)
  - `removalNoticeWithdrawn` (`voices.removalNoticeWithdrawn`)
  - `removed` (`voices.removed`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // The raw text: ElevenLabs signs the exact bytes it sent, so don't parse it first.
    const body = await request.text();
    // Carries ?tenantId=<id>, which picks the tenant whose secret checks the signature.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    const result = await processWebhook(corsair, headers, body, query);
    // Answer non-2xx when processing failed (a bad signature, a payload that fails
    // validation, no secret stored yet), so ElevenLabs counts it and retries if retries are on.
    return Response.json(result.response ?? { success: false }, {
        status: !result.plugin ? 404 : result.response?.success === false ? 500 : 200,
    });
}
```

## Conversations

### Call Initiation Failure

`conversations.callInitiationFailure`

A phone call could not be started: busy, no answer or unknown.

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `call_initiation_failure` | Yes | — |
| `event_timestamp` | `number \| string \| null` | No | When the event happened, in Unix time. |
| `data` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  agent_id?: string | null,
  conversation_id?: string | null,
  failure_reason?: string | null,
  metadata?: Record<string, any> | null
} | null
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  type: call_initiation_failure,
  event_timestamp?: number | string | null,
  data?: {
    agent_id?: string | null,
    conversation_id?: string | null,
    failure_reason?: string | null,
    metadata?: Record<string, any> | null
  } | null
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
elevenlabs({
    webhookHooks: {
        conversations: {
            callInitiationFailure: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
