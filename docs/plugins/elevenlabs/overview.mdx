Use **ElevenLabs** through Corsair: one client, typed API calls, and incoming webhooks.

Audio comes back as base64 in `contentBase64`, with `contentType`, `byteLength` and what ElevenLabs reports in its headers: `requestId`, `traceId`, `characterCost` (credits charged) and `historyItemId` (`songId` on music). Base64 is expensive in an agent's context, so speech operations (`textToSpeech`, `textToDialogue`, `voiceChanger`) take `includeContent: false` to leave it out, and leave it out on their own above `maxBytes` (default 700000 bytes, about 40 s of 128 kbps mp3, which fits a script result on Corsair's cloud). `contentOmitted` then says why and `note` says how to get it: `history.getAudio({ historyItemId })`. The history item can take a few seconds to appear after the audio returns.

Sound effects, music, stems and isolation have no history item, so ElevenLabs keeps no copy. Their output always comes back in the result, up to 50 MB; don't return it from a script on Corsair's cloud unless it fits the script's 1 MB result, and pass it to the next operation instead. Pick a small `outputFormat` such as `mp3_22050_32` when you can.

Calls here wait for the audio. A script on Corsair's cloud has about 20 s, and only jobs outlast that, so keep generation short there: a few paragraphs of speech with a fast model, a few seconds of music. Long music, stems and isolation can run past it, and a run cut off that way may still finish and bill. `dubbing.create` is the one long operation with a job: follow it with `dubbing.get`, or let `get_job` do it. Transcripts of long files can use `speechToText.convert({ webhook: true })`.

ElevenLabs has no idempotency keys, so a repeated generation bills again. The plugin retries a generation only when ElevenLabs refused it before running it (429 `rate_limit_exceeded`, `concurrent_limit_exceeded` or `system_busy`, waiting as `Retry-After` says), never on a 5xx, a timeout or a network failure. Reads also retry on 5xx.

Not covered, on purpose: Studio and projects, professional voice training, instant voice cloning from files (consent and verification concerns), websockets, realtime and Speech Engine, streaming variants (an operation returns one value), phone numbers and outbound calls, workspace admin, SMB, and Flows.

**What you get:**

- 49 typed API operations
- 8 incoming webhook event types

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/elevenlabs better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/elevenlabs better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/elevenlabs better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/elevenlabs better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { elevenlabs } from '@corsair-dev/elevenlabs';

export const corsair = createCorsair({
	plugins: [
		elevenlabs(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'elevenlabs',
	tenantId: 'acme',
});
```

## Example API calls

**Find a voice**

```ts
const tenant = corsair.withTenant('acme');
await tenant.elevenlabs.api.voices.list({ search: 'narrator', pageSize: 5 });
```


**Speak a sentence**

```ts
const tenant = corsair.withTenant('acme');
await tenant.elevenlabs.api.textToSpeech.convert({
	voiceId: 'FGY2WhTYpPnrIDTdsKH5',
	text: 'Your order has shipped.',
	modelId: 'eleven_flash_v2_5',
	outputFormat: 'mp3_22050_32',
});
```


See the full list on the [API](/plugins/elevenlabs/api) page.

## Webhooks

Create a webhook in ElevenLabs under Developers, Webhooks, with HMAC auth, and save the secret it shows you as the account's `webhook_signature` (or pass `webhookSecret`); deliveries are refused until it is set. Tick the events you want, and select the webhook in the agent's settings for post-call events. Hand `processWebhook` the raw body text (`await request.text()`), not parsed JSON, because ElevenLabs signs the exact bytes it sent. Deliveries name no account, so with several tenants put `?tenantId=<id>` on the webhook URL.

```ts
elevenlabs({
    webhookHooks: {
        speechToText: {
            transcriptionCompleted: {
                after: async (ctx, result) => {
                    if (result.data?.type === 'speech_to_text_transcription') console.log(result.data.data?.request_id, result.data.data?.transcription?.text);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/elevenlabs/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
