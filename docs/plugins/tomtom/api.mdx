## Routing

### calculate

`routing.calculate`

Calculate a route between waypoints with travel mode, traffic and avoidance options; makes no booking

**Risk:** `read`

```ts
await corsair.tomtom.api.routing.calculate({ origins: [{ latitude: 52.37, longitude: 4.89 }], destinations: [{ latitude: 52.09, longitude: 5.12 }], travel_mode: 'car', traffic: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `origins` | `object[]` | Yes | Where the route starts |
| `destinations` | `object[]` | Yes | Where the route ends |
| `travel_mode` | `car \| truck \| taxi \| bus \| van \| motorcycle \| bicycle \| pedestrian` | No | Default car |
| `route_type` | `fastest \| shortest \| eco \| thrilling` | No | Default fastest |
| `traffic` | `boolean` | No | Use live traffic in the calculation |
| `depart_at` | `string` | No | Departure time as an ISO 8601 instant, for future-traffic routing |
| `vehicle_max_speed` | `number` | No | Kilometres per hour for the travel mode |
| `avoid` | `(tollRoads \| motorways \| ferries \| unpavedRoads \| carpools \| alreadyUsedRoads)[]` | No | Features to route around |
| `language` | `string` | No | — |

Waypoints are joined in the path, origins then destinations. `depart_at` uses future traffic when `traffic` is on.

<AccordionGroup>
<Accordion title="origins full type">

```ts

  longitude: number
}[]
```
</Accordion>

<Accordion title="destinations full type">

```ts

  latitude: number,
  longitude: number
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `formatVersion` | `string \| null` | No | — |
| `routes` | `object[]` | Yes | — |

## Search

### fuzzy

`search.fuzzy`

Search for places, addresses, streets and geography, with optional geo bias and country filters

**Risk:** `read`

```ts
await corsair.tomtom.api.search.fuzzy({ query: 'pizza', lat: 52.37, lon: 4.89, radius: 5000, limit: 5 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | What to search for, e.g. "pizza" |
| `typeahead` | `boolean` | No | Treat the query as partial input for predictive search |
| `radius` | `number` | No | Metres from the bias point; requires lat and lon |
| `limit` | `number` | No | Results per page; default 10, maximum 100 |
| `offset` | `number` | No | Default 0 |
| `country_set` | `string` | No | Comma-separated ISO country codes, e.g. "US,MX" |
| `language` | `string` | No | BCP-47 language tag, e.g. "en-GB" |
| `lat` | `number` | No | Latitude for the geo bias |
| `lon` | `number` | No | Longitude for the geo bias |

`radius` needs both `lat` and `lon`. `limit` caps at 100. `summary.totalResults` is the total match count and `summary.numResults` the size of this page.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `summary` | `object \| null` | No | — |
| `results` | `object[]` | Yes | — |

| `query` | `string` | Yes | An address to turn into coordinates |

| `country_set` | `string` | No | Comma-separated ISO country codes, e.g. "US,MX" |

| `lat` | `number` | No | Latitude for the geo bias |

### incidents

`traffic.incidents`

List live traffic incidents in a bounding box, with their delay and road numbers

**Risk:** `read`

```ts
await corsair.tomtom.api.traffic.incidents({ bbox: '4.88,52.36,4.92,52.39' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `bbox` | `string` | Yes | Bounding box as "minLon,minLat,maxLon,maxLat", at most 10,000 km² in area |
| `language` | `string` | No | Default en-GB |
| `category_filter` | `number[]` | No | Incident categories to include, such as [1, 6] for Accident and Jam; sent comma-separated |
| `time_validity_filter` | `(present \| future)[]` | No | present, future or both; default present |

The bounding box is minLon,minLat,maxLon,maxLat. The box may cover at most 10,000 km². `category_filter` is a list of category numbers, such as [1, 6] for Accident and Jam, and `time_validity_filter` takes present, future or both.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `incidents` | `object[]` | Yes | — |

### tile

`traffic.tile`

Fetch one traffic flow or incident map tile

**Risk:** `read`

```ts
await corsair.tomtom.api.traffic.tile({ layer: 'flow', style: 'relative-delay', zoom: 12, x: 2100, y: 1350 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `layer` | `flow \| incidents` | No | Default flow |
| `style` | `absolute \| relative \| relative-delay \| reduced-sensitivity` | No | Flow layer style, default relative |
| `incident_style` | `s0 \| s0-dark \| s1 \| s2 \| s3 \| night` | No | Incidents layer style, default s3 |
| `zoom` | `number` | Yes | — |
| `x` | `number` | Yes | — |
| `y` | `number` | Yes | — |

Returns the PNG as base64. The flow layer defaults to the relative style and the incidents layer to s3.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `content_type` | `string` | Yes | Usually image/png |
| `base64` | `string` | Yes | The tile image, base64-encoded |
