---
title: "TomTom database"
sidebarTitle: "Database"
description: "The TomTom plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for TomTom. To read its data, call the [API operations](/plugins/tomtom/api), which return what TomTom has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
