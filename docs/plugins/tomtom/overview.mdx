Use **TomTom** through Corsair: one client, typed API calls.

Create an API key in the TomTom developer portal at my.tomtom.com. The key travels as the `key` query parameter on every request, and it must have the Search, Routing or Traffic product enabled for the endpoints you call.

Things to know:

- **Paging is offset based.** `limit` caps at 100 and `offset` skips within the result set; `summary.numResults` is the total available, not the size of this page.
- **A search with no matches is a success.** TomTom answers 200 with an empty `results` array, so check the array rather than the status.
- **`radius` needs a point.** A radius without `lat` and `lon` is rejected before the request, because the API ignores it otherwise.
- **Routes take coordinates, not addresses.** Geocode first, then pass the resulting positions. `origins` and `destinations` each accept several waypoints, joined with colons in the path.
- **Traffic needs a bounding box.** `traffic.incidents` takes `minLon,minLat,maxLon,maxLat`; the whole world is `-180,-90,180,90`. An inverted box is rejected here rather than at the provider.
- **Tiles are images, not JSON.** `traffic.tile` returns a PNG body; the incidents layer has no style segment in its path.
- **A 403 is a plan limit.** The key is valid but does not cover the product or the region, so the plugin does not retry it.

- 7 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/tomtom better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/tomtom better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/tomtom better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/tomtom better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { tomtom } from '@corsair-dev/tomtom';

export const corsair = createCorsair({
	plugins: [
		tomtom(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the TomTom API key before the first call: `pnpm corsair setup --plugin=tomtom --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
tomtom()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'tomtom',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Search for a place with a geo bias**

```ts
const tenant = corsair.withTenant('acme');
await tenant.tomtom.api.search.fuzzy({
	query: 'pizza',
	lat: 52.37,
	lon: 4.89,
	limit: 5,
});
```


**Calculate a route between two points**

```ts
const tenant = corsair.withTenant('acme');
await tenant.tomtom.api.routing.calculate({
	origins: [{ latitude: 52.37, longitude: 4.89 }],
	destinations: [{ latitude: 52.09, longitude: 5.12 }],
	traffic: true,
});
```


See the full list on the [API](/plugins/tomtom/api) page.
