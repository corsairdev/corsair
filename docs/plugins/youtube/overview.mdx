Use **YouTube** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 51 typed API operations
- 8 synced entities (`activities`, `captions`, `channels`, `comments`, `playlistItems`, `playlists`, and 2 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/youtube
```
```bash yarn
yarn add corsair @corsair-dev/youtube
```
```bash pnpm
pnpm install corsair @corsair-dev/youtube
```
```bash bun
bun add corsair @corsair-dev/youtube
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { youtube } from '@corsair-dev/youtube';

export const corsair = createCorsair({
	plugins: [
		youtube(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="OAuth 2.0 (Recommended)">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your YouTube OAuth app.

Provider walkthrough: [Get Credentials](/plugins/youtube/get-credentials).

```ts
youtube()
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'youtube',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`captions.list`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.youtube.api.captions.list({});
```


**`captions.update`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.youtube.api.captions.update({});
```


See the full list on the [API](/plugins/youtube/api) page.

## Query synced data

Synced entities support `tenant.youtube.db.<entity>.search()` and `.list()`: `activities`, `captions`, `channels`, `comments`, `playlistItems`, `playlists`, `subscriptions`, `videos`.

See [Database](/plugins/youtube/database) for filters and operators.
