## Businesses

### create

`businesses.create`

Create a business. The body uses `businessName` and `businessType`, not the `name` and `organisationType` a read returns

**Risk:** `write`

```ts
await corsair.gatherup.api.businesses.create({ businessName: 'Peach Trees Intl.', businessType: 'Insurance Agency', city: 'Haiku', country: 'US', streetAddress: '4150 Hana Hwy', state: 'HI', zip: '96708', phone: '808-333-3334' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `businessName` | `string` | Yes | — |
| `businessType` | `string` | Yes | A Google business type, such as `Insurance Agency`; see `businesses.types`. |
| `city` | `string` | Yes | — |
| `country` | `string` | Yes | A country code or full name. |
| `streetAddress` | `string` | Yes | — |
| `state` | `string` | Yes | A state code or full name. |
| `zip` | `string` | Yes | — |
| `phone` | `string` | Yes | — |
| `websiteUrl` | `string` | No | — |
| `organisationType` | `string` | No | Defaults to `company`. |
| `legalBusinessName` | `string` | No | — |
| `publicBusinessName` | `string` | No | — |
| `language` | `string` | No | — |

Takes `businessName` and `businessType`, not the `name` and `organisationType` a read returns.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `businessId` | `number \| string \| null` | No | — |
| `errorCode` | `number \| null` | No | `0` on success. Any other value is a failure, whatever the status. |
| `errorMessage` | `string \| null` | No | — |

## Customers

### create

`customers.create`

Add a customer to a business. The body uses `customerFirstName` and `customerEmail`; an email or a phone is needed. Destructive because it can message the customer: a feedback request goes out when `sendFeedbackRequest` is true, and a business in automatic mode sends one on its own schedule

**Risk:** `destructive`

```ts
await corsair.gatherup.api.customers.create({ businessId: 34291, customerFirstName: 'John', customerLastName: 'Smith', customerEmail: 'john.smith@example.com', customerTags: 'brakes,tires' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `businessId` | `number` | Yes | The business ID, from `businesses.list`. |
| `customerFirstName` | `string` | Yes | — |
| `customerLastName` | `string` | Yes | — |
| `customerEmail` | `string` | No | Required on the basic plan. |
| `customerPhone` | `string` | No | — |
| `customerJobId` | `string` | No | — |
| `customerCustomId` | `string` | No | — |
| `customerTags` | `string` | No | Comma-separated tags, each at most 50 characters. |
| `sendFeedbackRequest` | `boolean` | No | Send a feedback request to the customer as soon as they are created. Defaults to false; a business in automatic mode still sends on its own schedule. |

Takes `customerFirstName` and `customerEmail`; an email or a phone is needed to reach the customer.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `customerId` | `string \| number \| null` | No | — |
| `feedbackRequestErrorCode` | `number \| null` | No | `0` when the requested feedback request went out. |
| `feedbackRequestErrorMessage` | `string \| null` | No | — |
| `errorCode` | `number \| null` | No | `0` on success. Any other value is a failure, whatever the status. |
| `errorMessage` | `string \| null` | No | — |
