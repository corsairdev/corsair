Use **Conversion Tools** through Corsair: one client, typed API calls.

Connect each tenant through the connect-link step below before making authenticated API calls. The API-key flow does not prompt for credentials on a tenant's first request. Base64 download operations return files up to 10 MiB; use a temporary download link for larger files.

**What you get:**

- 17 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/conversiontools better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/conversiontools better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/conversiontools better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/conversiontools better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { conversiontools } from '@corsair-dev/conversiontools';

export const corsair = createCorsair({
	plugins: [
		conversiontools(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Conversion Tools API key before the first call: `pnpm corsair setup --plugin=conversiontools --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
conversiontools()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'conversiontools',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Download a converted file**

```ts
const tenant = corsair.withTenant('acme');
await tenant.conversiontools.api.files.downloadById({ file_id: '0123456789abcdef0123456789abcdef' });
```


**Start a conversion task**

```ts
const tenant = corsair.withTenant('acme');
await tenant.conversiontools.api.tasks.create({
	type: 'convert.xml_to_json',
	options: { file_id: '0123456789abcdef0123456789abcdef' },
});
```


See the full list on the [API](/plugins/conversiontools/api) page.
