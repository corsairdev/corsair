## Account

### getConfig

`account.getConfig`

Get account-specific converter configuration. https://api.conversiontools.io/openapi.yaml

**Risk:** `read`

```ts
await corsair.conversiontools.api.account.getConfig({});
```

**Input:** _empty object_

These snippets use a single-tenant client. With `multiTenancy: true`, bind a tenant first (`const tenant = corsair.withTenant('acme')`) and replace `corsair` with `tenant` in the API calls. The converters sit under `data.conversions` in the live response. An option's `type` is `'string'`, `'boolean'`, `'enum'` or `'number'` today, and the schema also accepts a type the catalog adds later.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `error` | `string \| null` | Yes | — |
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  conversions?: {
    type: string,
    title?: string,
    options?: {
      key: string,
      title?: string,
      type?: string | boolean | enum | number | string,
      values?: {
        value: string,
        label?: string
      }[],
      default?: JsonValue,
      placeholder?: string
    }[]
  }[]
}
```
</Accordion>
</AccordionGroup>

### downloadById

`files.downloadById`

Download file bytes by file ID as base64 with response metadata. https://conversiontools.io/llms-full.txt

**Risk:** `read`

```ts
await corsair.conversiontools.api.files.downloadById({ file_id: '0123456789abcdef0123456789abcdef' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `file_id` | `string` | Yes | 32-character lowercase hexadecimal file ID |

The JSON/base64 download response is capped at 10 MiB of raw file bytes. For larger files, create a temporary download link and have the consumer GET `https://api.conversiontools.io/v1/files/{download_id}/download` directly without an Authorization header.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contentBase64` | `string` | Yes | Raw file bytes encoded as base64 for JSON-safe output; downloads are limited to 10 MiB. Use a temporary download link for larger files. |
| `contentType` | `string` | Yes | The response Content-Type |
| `contentDisposition` | `string` | No | The response Content-Disposition, when provided |
| `size` | `number` | Yes | Downloaded byte length |

## Tasks

### create

`tasks.create`

Create an asynchronous conversion task. https://conversiontools.io/api-documentation#run-conversion-task

**Risk:** `destructive`

```ts
await corsair.conversiontools.api.tasks.create({ type: 'convert.xml_to_json', options: { file_id: '0123456789abcdef0123456789abcdef' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `string` | Yes | — |
| `options` | `Record<string, JsonValue>` | Yes | — |

Provide exactly one of `file_id` or `url` inside `options`; the plugin rejects requests with both or neither. `callbackUrl` is not accepted because this plugin does not implement callbacks. The options type remains `Record<string, JsonValue>` so converter-specific options stay open-ended.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `error` | `string \| null` | Yes | — |
| `task_id` | `string` | Yes | 32-character lowercase hexadecimal task ID |
| `sandbox` | `boolean` | No | — |
| `message` | `string` | No | — |
