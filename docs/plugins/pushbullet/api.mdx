## Chats

### create

`chats.create`

Start a chat with another Pushbullet user by email

**Risk:** `write`

```ts
await corsair.pushbullet.api.chats.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `iden` | `string` | Yes | — |
| `active` | `boolean` | No | — |
| `muted` | `boolean` | No | — |
| `created` | `number` | No | — |
| `modified` | `number` | No | — |
| `with` | `object` | No | — |

<AccordionGroup>
<Accordion title="with full type">

```ts
{
  iden?: string,
  email?: string,
  name?: string,
  image_url?: string,
  type?: string
}
```
</Accordion>
</AccordionGroup>
