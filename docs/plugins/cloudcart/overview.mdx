Use **CloudCart** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 151 typed API operations
- 5 synced entities (`categories`, `customers`, `orders`, `products`, `variants`) for fast `.search()` / `.list()`
- 3 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/cloudcart better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/cloudcart better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/cloudcart better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/cloudcart better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { cloudcart } from '@corsair-dev/cloudcart';

export const corsair = createCorsair({
	plugins: [
		cloudcart(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the CloudCart API key before the first call: `pnpm corsair setup --plugin=cloudcart --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
cloudcart()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'cloudcart',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List products**

```ts
const tenant = corsair.withTenant('acme');
await tenant.cloudcart.api.products.listProducts({});
```


**Create a product**

```ts
const tenant = corsair.withTenant('acme');
await tenant.cloudcart.api.products.createProduct({
	data: {
		type: 'products',
		attributes: { name: 'Blue T-shirt' },
	},
});
```


See the full list on the [API](/plugins/cloudcart/api) page.

## Query synced data

This table exists, but Cloudcart calls don't fill it yet. This returns only rows you have written yourself.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.cloudcart.db.products.search({
	data: {},
	limit: 50,
});
```

Synced entities: `categories`, `customers`, `orders`, `products`, `variants`. See [Database](/plugins/cloudcart/database) for filters and operators.

## Webhooks

Fires when a customer places an order.

```ts
cloudcart({
    webhookHooks: {
        order: {
            created: {
                after: async (ctx, result) => {
                    console.log('Cloudcart order created:', result.data);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/cloudcart/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
