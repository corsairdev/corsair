## Company

### get

`company.get`

Read the company of the authenticated user

**Risk:** `read`

```ts
await corsair.payhere.api.company.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | The Payhere company of the authenticated user |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  id: number,
  name?: string | null,
  legal_name?: string | null,
  slug?: string | null,
  country_code?: string | null,
  currency?: string | null,
  stripe_connected?: boolean | null,
  gocardless_connected?: boolean | null
}
```
</Accordion>
</AccordionGroup>

### stats

`company.stats`

Read the payment stats of the last 30 days with comparisons

**Risk:** `read`

```ts
await corsair.payhere.api.company.stats({});
```

**Input:** _empty object_

Comparison fields cover the 30-60 days before the last 30.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `currency` | `string` | Yes | Currency the stats are reported in |
| `payments_last_30` | `number` | Yes | Payment volume of the last 30 days |
| `payments_comparison` | `number` | Yes | Payment volume of the 30-60 days before, for comparison |
| `subscribers_last_30` | `number` | Yes | New subscribers of the last 30 days |
| `subscribers_comparison` | `number` | Yes | New subscribers of the 30-60 days before, for comparison |
| `payments_all_time` | `number` | Yes | Payment volume across all time |

|------|------|----------|-------------|
| `page` | `number` | No | Page number |

## Refunds

### create

`refunds.create`

Refund a payment fully or partially; money leaves the account and the refund cannot be undone

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.payhere.api.refunds.create({ payment_id: 373, amount: 0.5, reason: "requested_by_customer" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `payment_id` | `number` | Yes | Id of the payment to refund |
| `amount` | `number` | Yes | Amount to refund, in the payment currency; decimals allowed (1.5 is $1.50 USD) |
| `reason` | `requested_by_customer \| duplicate \| fraudulent` | Yes | Reason for the refund |

Answers 204 with no body. The reason must be one of requested_by_customer, duplicate or fraudulent; the amount uses the payment currency.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `paymentId` | `number` | Yes | Refunded payment id |
| `amount` | `number` | Yes | Refunded amount |
| `success` | `boolean` | Yes | Whether the refund succeeded |
