## Deploys

### create

`deploys.create`

Record a deploy with its environment, revision and optional status and comment

**Risk:** `write`

```ts
await corsair.rollbar.api.deploys.create({ environment: 'production', revision: 'abc1234', comment: 'Ship it' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `environment` | `string` | Yes | The environment deployed to. |
| `revision` | `string` | Yes | The revision deployed, up to 40 characters. |
| `project_id` | `number` | No | — |
| `comment` | `string` | No | — |
| `local_username` | `string` | No | — |
| `rollbar_username` | `string` | No | — |
| `status` | `started \| succeeded \| failed \| timed_out` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deploy_id` | `number \| null` | No | — |
| `result` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="result full type">

```ts
{
  id?: number | null
} | null
```
</Accordion>
</AccordionGroup>

### list

`items.list`

List error items with status, level, environment and assignee filters plus page paging

**Risk:** `read`

```ts
await corsair.rollbar.api.items.list({ status: 'active', level: ['error', 'critical'], environment: 'production' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | 1-based page. Rollbar returns 20 per page unless `limit` is set. |
| `limit` | `number` | No | Records per page, up to 100. |
| `status` | `active \| resolved \| muted` | No | — |
| `level` | `(critical \| error \| warning \| info \| debug)[]` | No | Sent as a repeated parameter, so several levels can be asked for. |
| `environment` | `string` | No | — |
| `framework` | `string` | No | — |
| `query` | `string` | No | A search string. |
| `ids` | `number[]` | No | — |
| `project_ids` | `number[]` | No | Account tokens only: search these projects. |
| `assigned_user` | `string` | No | A user id or email. |
| `assigned_team` | `string` | No | — |
| `is_snoozed` | `boolean` | No | — |

`level`, `ids` and `project_ids` repeat the query parameter, so arrays send every value.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|

| `page` | `number \| null` | Yes | — |
| `total_count` | `number \| null` | Yes | Total matches, or null when the project has more than 100,000 items. |

### update

`items.update`

Update an item: its status, level, title, assignee, resolved-in version or snooze

**Risk:** `write`

```ts
await corsair.rollbar.api.items.update({ item_id: 12345, status: 'resolved', resolved_in_version: '1.2.3' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `item_id` | `number` | Yes | — |
| `status` | `active \| resolved \| muted` | No | — |
| `level` | `critical \| error \| warning \| info \| debug` | No | — |
| `title` | `string` | No | A new title, up to 255 characters. |
| `assigned_user_id` | `number` | No | — |
| `assigned_team_id` | `number` | No | — |
| `resolved_in_version` | `string` | No | The version the item is resolved in, up to 40 characters. |
| `snooze_enabled` | `boolean` | No | — |
| `snooze_expiration_in_seconds` | `number` | No | — |

A snooze needs a duration; `snooze_enabled` without `snooze_expiration_in_seconds` is rejected before the request.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `item` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="item full type">

```ts
{
  status?: string | null,
  resolved_in_version?: string | null,
  title?: string | null,
  level?: string | null,
  assigned_user_id?: number | null,
  assigned_team_id?: number | null,
  snooze_enabled?: boolean | null,
  snooze_expiration_in_seconds?: number | null
}
```
</Accordion>
</AccordionGroup>

### list

`occurrences.list`

List occurrences in a project with page paging, for a forward walk from a known id

**Risk:** `read`

```ts
await corsair.rollbar.api.occurrences.list({ page: 1, limit: 20 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | 1-based page. Rollbar returns 20 per page unless `limit` is set. |
| `limit` | `number` | No | Records per page, up to 100. |
| `project_id` | `number` | No | Account tokens only: read this project. |
| `last_id` | `number` | No | Only occurrences after this id, for a forward walk. |

This route names occurrences `instances`; the plugin returns them as `occurrences`.



**Output**

| Name | Type | Required | Description |
