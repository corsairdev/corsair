---
title: "SMS Alert database"
sidebarTitle: "Database"
description: "The SMS Alert plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for SMS Alert. To read its data, call the [API operations](/plugins/smsalert/api), which return what SMS Alert has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
