Use **Elorus** through Corsair: one client, typed API calls.

Connect an Elorus API token and the organization ID used in the required X-Elorus-Organization header. The API key is stored as the secret; the organization ID is a separate account field. List endpoints support page and page_size pagination (maximum 250). Tracking-category filters use dynamic keys such as tc_12345; unrelated query keys are rejected. API v1.1 remains in maintenance until December 31, 2026; v1.2 is the current API.

**What you get:**

- 457 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/elorus better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/elorus better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/elorus better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/elorus better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { elorus } from '@corsair-dev/elorus';

export const corsair = createCorsair({
	plugins: [
		elorus(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Elorus API key before the first call: `pnpm corsair setup --plugin=elorus --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
elorus()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'elorus',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Retrieve bill email settings**

```ts
const tenant = corsair.withTenant('acme');
await tenant.elorus.api.v12.bills_email_read({
	path: { id: 'demo' },
});
```


**Create a bill**

```ts
const tenant = corsair.withTenant('acme');
await tenant.elorus.api.v12.bills_create({
	body: {
		supplier: 'demo',
		items: [],
	},
});
```


See the full list on the [API](/plugins/elorus/api) page.
