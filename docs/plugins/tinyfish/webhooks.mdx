The TinyFish plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/tinyfish/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `run`
  - `cancelled` (`run.cancelled`)
  - `completed` (`run.completed`)
  - `failed` (`run.failed`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    const body = await request.json();
    const result = await processWebhook(corsair, headers, body);
    return result.response;
}
```

## Events

## Run

### Cancelled

`run.cancelled`

A run reached CANCELLED

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event` | `run.cancelled` | Yes | — |
| `run_id` | `string` | Yes | — |
| `status` | `string` | Yes | — |
| `data` | `object` | No | — |

<Accordion title="data full type">

```ts
{

  status?: string,

**`webhookHooks` example**

                after(ctx, response) {
                },
            },
        },
    },
})
```
