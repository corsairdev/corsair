**Risk:** `write`

```ts
await corsair.tinyfish.api.agent.cancelRun({ runId: 'run_...' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `runId` | `string` | Yes | — |



**Output**

| `status` | `CANCELLED \| COMPLETED \| FAILED` | Yes | — |
| `cancelled_at` | `string` | No | — |
