## Members

### create

`members.create`

Add an advocate to a program with their name, email and an optional referral code

**Risk:** `write`

```ts
await corsair.referralrock.api.members.create({ program_id: '86de93f6-95a8-473d-bb68-b9645f6e9880', first_name: 'Sam', last_name: 'Rivera', email: 'sam@example.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `program_id` | `string` | Yes | The program the member joins. |
| `first_name` | `string` | Yes | — |
| `email` | `string` | Yes | The member’s email address. |
| `last_name` | `string` | No | — |
| `referral_code` | `string` | No | A code the member shares; Referral Rock generates one when omitted. |
| `phone` | `string` | No | — |
| `external_identifier` | `string` | No | Your own id, for linking the member to another system. |
| `date_of_birth` | `string` | No | — |
| `address_line1` | `string` | No | — |
| `address_line2` | `string` | No | — |
| `city` | `string` | No | — |
| `region` | `string` | No | A region name or ISO 3166-2 code; requires `country`. |
| `country` | `string` | No | A country name or ISO 3166-2 code. |
| `postal_code` | `string` | No | — |
| `should_send_email` | `boolean` | No | Send the program’s confirmation email. Defaults to false. |

A refusal arrives as a 200 with a null member and the reason in `message`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `member` | `object \| null` | No | — |
| `message` | `string \| null` | No | — |

### list

`members.list`

List advocates with program, search, disabled and date filters, plus offset paging

**Risk:** `read`

```ts
await corsair.referralrock.api.members.list({ query: 'sam@example.com', offset: 0, count: 50 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `offset` | `number` | No | Records to skip, 0-based. Pass `next_offset` from the previous page. |
| `count` | `number` | No | Records to return. Referral Rock returns everything matching when this is omitted. |
| `date_from` | `string` | No | Only records created after this date. |
| `date_to` | `string` | No | Only records created before this date. |
| `program_id` | `string` | No | A program id, name or title. |
| `query` | `string` | No | A value the member must match on email, internal id, external id or referral code. |
| `show_disabled` | `boolean` | No | Include disabled members. Defaults to false. |
| `sort` | `Member_Views_Desc \| Member_Views_Asc \| Page_Views_Desc \| Page_Views_Asc \| Lead_Count_Desc \| Lead_Count_Asc \| Reward_Issued_Total_Desc \| Reward_Issued_Total_Asc \| Member_Full_Name_Desc \| Member_Full_Name_Asc \| Create_Dt_Desc \| Create_Dt_Asc` | No | — |

The sort values are case-sensitive; the API silently ignores an unrecognised one.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `members` | `object[]` | Yes | — |
| `offset` | `number \| null` | Yes | — |
| `total` | `number \| null` | Yes | — |
| `next_offset` | `number \| null` | Yes | Pass as `offset` to read the next page; null on the last. |
| `message` | `string \| null` | No | Referral Rock’s own note. On a collection it can explain why nothing matched. |

## Programs

### list

`programs.list`

List the referral programs on the account, optionally narrowed to one program id

**Risk:** `read`

```ts
await corsair.referralrock.api.programs.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `program_id` | `string` | No | A program id; when given, only that program is returned. |
| `offset` | `number` | No | Records to skip, 0-based. Pass `next_offset` from the previous page. |
| `count` | `number` | No | Records to return. Referral Rock returns everything matching when this is omitted. |

A program id, name or title narrows the result to one program.

|------|------|----------|-------------|

| `company_name` | `string` | No | — |

## Rewards

### create

`rewards.create`

Issue a reward to a member for an optional referral, with its amount and payout type

**Risk:** `write`

```ts
await corsair.referralrock.api.rewards.create({ member_id: '19548e00-1a17-42e1-b18b-b7bf140cd21d', amount: 10, payout_id: 'paypal' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `member_id` | `string` | Yes | The member the reward is for. |
| `amount` | `number` | Yes | The reward amount. |
| `payout_id` | `string` | No | The payout type to issue. |
| `description` | `string` | No | — |
| `eligibility_date` | `string` | No | When the reward becomes eligible, as ISO 8601. |
| `referral_id` | `string` | No | The referral the reward is attributed to. |

Sent as an array of reward infos, each naming its member and optional referral.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `reward` | `object \| null` | No | — |
| `message` | `string \| null` | No | — |
