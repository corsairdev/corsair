---
title: "Crawl4AI database"
sidebarTitle: "Database"
description: "The Crawl4AI plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Crawl4AI. To read its data, call the [API operations](/plugins/crawl4ai/api), which return what Crawl4AI has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
