## Cloud

### answer

`cloud.answer`

Answer a question directly from the web (optionally as JSON matching a schema), with the sources it drew on; experimental

**Risk:** `read`

```ts
await corsair.crawl4ai.api.cloud.answer({ q: 'rust web crawler' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | The question or a whole prompt (max 4,000 characters). |
| `schema` | `Record<string, any>` | No | A JSON Schema the answer must match. |
| `deep` | `boolean` | No | Read a couple of pages when needed (default true); false = only a readily available answer. |



**Output:** `unknown`

### batch

`cloud.batch`

Run one tool over many inputs: as a job (up to 10,000; follow with cloud.jobs.*) or streamed in the call (stream true, up to 50, returned as a list)

**Risk:** `read`

```ts
await corsair.crawl4ai.api.cloud.batch({
	tool: 'scrape',
	inputs: [{ url: 'https://example.com' }, { url: 'https://example.org' }],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `tool` | `string` | Yes | The tool id, e.g. scrape. |
| `inputs` | `Record<string, any>[]` | Yes | One input per page; the first one's options apply to all. |
| `stream` | `boolean` | No | Answer in the call, one result per line (up to 50). |
| `idempotency_key` | `string` | No | Send the same key again on a retry to get the first job back, billed once. |



**Output:** `unknown`

### scrape

`cloud.scrape`

Fetch one page as clean Markdown and/or HTML (cache, then HTTP, then a browser), with optional links, media, metadata and tables

**Risk:** `read`

```ts
await corsair.crawl4ai.api.cloud.scrape({ url: 'https://example.com', format: 'md' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | A public http(s) URL. |
| `format` | `both \| md \| html` | No | both (default), md or html. |
| `proxy` | `standard \| extra` | No | standard (default) or extra: rented residential addresses when ours are refused; a page served that way costs 4x. |
| `country` | `string` | No | Two-letter country to fetch from, e.g. us, gb. |
| `parse` | `any` | No | Also return page structure: true, a list (links, media, metadata, tables) or an object. |
| `engine` | `auto \| browser-light \| browser` | No | auto (default), browser-light or browser. |
| `bypass_cache` | `boolean` | No | Fetch fresh, never from the cache. |
| `timeout` | `number` | No | Answer within this many seconds (5 to 120); set it a little below your client timeout. |
| `fresh` | `boolean` | No | Skip the cache and fetch fresh (the Crawl4AI-Fresh header). |



**Output:** `unknown`

**Output**

### crawl

```ts
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
