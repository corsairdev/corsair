## Images

### get

`images.get`

Get image variant by digest

**Risk:** `read`

```ts
const tenant = corsair.withTenant('acme');
await tenant.dockerhub.api.images.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `namespace` | `string` | Yes | — |
| `name` | `string` | Yes | — |
| `digest` | `string` | Yes | — |
| `pageSize` | `number` | No | — |



**Output:** `any`


---
