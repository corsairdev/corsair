---
title: "Roam HQ database"
sidebarTitle: "Database"
description: "The Roam HQ plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Roam HQ. To read its data, call the [API operations](/plugins/roam/api), which return what Roam HQ has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
