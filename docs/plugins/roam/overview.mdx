Use **Roam HQ** through Corsair: one client, typed API calls.

Create an API client in **Roam Administration → Developer** to get your credentials. Send the key as `Authorization: Bearer <key>`. Things to know before you call:

- **The version header matters.** Every response is rendered against a dated API version, and the plugin pins `Roam-Version: 2026-08-25` on every request so a body's shape cannot change under it. Omitting the header would use the integration's default, which Roam moves between releases.
- **Errors are labelled `text/plain`.** Roam's error envelope is JSON but the response's content type makes generic clients hand it over as a raw string. The plugin parses it, so `RoamAPIError.code` is the catalog code such as `invalid_token` — not a string containing the whole body.
- **Branch on the code, not the status.** A 401 can be `not_authed`, `invalid_token` or `token_revoked`, and a 403 can be `missing_scope` or `approval_pending`. A revoked token is permanent: discard it rather than retrying. A `missing_scope` body names the scopes that would work in `needed`, any one of which is enough.
- **`chat.post` takes exactly one content type.** `text`, `items`, `asset_ids`, `blocks` or `poll` — a body with two of them is refused, and so is a body with none, so the schema rejects either before the request.
- **A post needs a destination.** One of `chat_id`, `group_id` or `user_ids`: the last one opens a direct conversation.
- **Scheduling a post returns a different shape.** Passing `send_at` returns `scheduledMessageId` instead of a live `timestamp`.
- **`chat.history` needs a target.** It reads one chat or one group, so `chat_id` or `group_id` is required; without one Roam returns an unscoped history.
- **Messages are edited, not replaced.** `chat.update` takes the chat and the message `timestamp`, and needs exactly one new content type.
- **Paging is a cursor.** Lists answer `cursor` plus `hasMore`, and the plugin returns `next_cursor`. A list with no cursor is the last page.

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/roam better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/roam better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/roam better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/roam better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { roam } from '@corsair-dev/roam';

export const corsair = createCorsair({
	plugins: [
		roam(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. A call without a saved key throws `AuthMissingError`, which may carry a `connectUrl` for connecting Roam HQ.

```ts
roam()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'roam',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read the last messages in a chat**

```ts
const tenant = corsair.withTenant('acme');
await tenant.roam.api.chat.history({ chat_id: '757dfe66-37b4-4772-baa5-8c86ec68c176', limit: 50 });
```


**Post a message to a chat**

```ts
const tenant = corsair.withTenant('acme');
await tenant.roam.api.chat.post({ chat_id: '757dfe66-37b4-4772-baa5-8c86ec68c176', text: 'Standup in five' });
```


See the full list on the [API](/plugins/roam/api) page.
