## Comments

### delete

`comments.delete`

Permanently delete a map comment

**Risk:** `destructive`

```ts
await corsair.felt.api.comments.delete({ map_id: 'a1b2c3d4e5', comment_id: 'comm_123' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `map_id` | `string` | Yes | — |
| `comment_id` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |
| `id` | `string` | No | — |

### upsert

`elements.upsert`

Create or update elements on a map using GeoJSON FeatureCollection

**Risk:** `write`

