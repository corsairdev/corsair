Use **Twilio** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 6 typed API operations
- 2 synced entities (`calls`, `messages`) for fast `.search()` / `.list()`
- 3 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/twilio
```
```bash yarn
yarn add corsair @corsair-dev/twilio
```
```bash pnpm
pnpm install corsair @corsair-dev/twilio
```
```bash bun
bun add corsair @corsair-dev/twilio
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { twilio } from '@corsair-dev/twilio';

export const corsair = createCorsair({
	plugins: [
		twilio(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_DEV_API_KEY!,
		signingSecret: process.env.CORSAIR_DEV_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
twilio()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'twilio',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List messages**

```ts
const tenant = corsair.withTenant('acme');
await tenant.twilio.api.messages.list({});
```


**Send a message**

```ts
const tenant = corsair.withTenant('acme');
await tenant.twilio.api.messages.send({ To: '+15555550100', From: '+15555550101', Body: 'Hello from Corsair' });
```


See the full list on the [API](/plugins/twilio/api) page.

## Query synced data

Search synced messages without hitting Twilio.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.twilio.db.messages.search({
	data: {},
	limit: 50,
});
```

Synced entities: `calls`, `messages`. See [Database](/plugins/twilio/database) for filters and operators.

## Webhooks

Fires when an inbound SMS arrives.

```ts
twilio({
    webhookHooks: {
        message: {
            received: {
                after: async (ctx, result) => {
                    console.log('Twilio message:', result.data);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/twilio/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
