Use **Alchemy** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 36 typed API operations
- 5 synced entities (`AlchemyNft`, `AlchemyNftContract`, `AlchemyToken`, `AlchemyTokenBalance`, `AlchemyTokenPrice`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/alchemy
```
```bash yarn
yarn add corsair @corsair-dev/alchemy
```
```bash pnpm
pnpm install corsair @corsair-dev/alchemy
```
```bash bun
bun add corsair @corsair-dev/alchemy
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { alchemy } from '@corsair-dev/alchemy';

export const corsair = createCorsair({
	plugins: [
		alchemy(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
alchemy()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'alchemy',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`nft.computeRarityV3`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.alchemy.api.nft.computeRarityV3({});
```


**`nft.invalidateContractV3`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.alchemy.api.nft.invalidateContractV3({});
```


See the full list on the [API](/plugins/alchemy/api) page.

## Query synced data

Synced entities support `tenant.alchemy.db.<entity>.search()` and `.list()`: `AlchemyNft`, `AlchemyNftContract`, `AlchemyToken`, `AlchemyTokenBalance`, `AlchemyTokenPrice`.

See [Database](/plugins/alchemy/database) for filters and operators.
