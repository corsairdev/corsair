### explorePrompt

`aiVisibility.explorePrompt`

Ask a prompt in ChatGPT, Claude, Gemini or Perplexity and see answers, citations and brand mentions

**Risk:** `read`

```ts
await corsair.openseo.api.aiVisibility.explorePrompt({
	projectId: '6f1c2a9e-3b7d-4e58-9a14-2c8b5d7e0f31',
	prompt: 'What is the best coffee subscription?',
	models: ['chat_gpt'],
	highlightBrand: 'Acme Coffee',
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `projectId` | `string` | Yes | Required. The OpenSEO project ID to scope this call to. Get one from list_projects. |
| `prompt` | `string` | Yes | The exact question to ask, up to 500 characters. Preserve the user's wording. |
| `models` | `(chat_gpt \| claude \| gemini \| perplexity)[]` | No | Models to query: chat_gpt, claude, gemini, perplexity. Defaults to ChatGPT only. Supply a list to compare selected models; each uncached model uses credits. |

| `webSearch` | `boolean` | No | Allow web search, default true. Answers report whether the model actually searched; permission does not guarantee citations. |

### export

`aiVisibility.export`

Export stored AI visibility observations as a CSV or JSON download link

**Risk:** `read`

```ts
await corsair.openseo.api.aiVisibility.export({ projectId: '6f1c2a9e-3b7d-4e58-9a14-2c8b5d7e0f31', format: 'csv', includeHistory: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `projectId` | `string` | Yes | — |
| `runId` | `string \| null` | No | Omit or null for the latest baseline/scheduled run. Reuse the returned runId for related source/answer reads. Do not use the string all. |
| `topic` | `string \| null` | No | Omit or null for all topics in the run. Filter by an exact saved topic name only when requested; do not use the string all. |
| `engines` | `(chatgpt \| gemini \| google_ai_overview \| google_ai_mode \| claude \| perplexity)[] \| null` | No | Omit or null for all engines in one call. Provide one or more engines for an explicitly requested subset, or an empty array for no engines. Do not make separate calls for each engine or use the string all. |
| `promptId` | `string \| null` | No | Omit or null for all prompts in the run. Provide an exact prompt ID only when requested; includeHistory returns that prompt's prior observations. Do not use the string all. |
| `includeHistory` | `boolean` | No | — |
| `competitorGap` | `boolean` | No | Use false for the initial review, overall sources and branded diagnostics. True restricts rows to answers where a competitor appears and your brand is absent; an empty gap subset does not mean answer details are missing. |
| `branded` | `all \| neutral \| branded` | No | — |
| `cursor` | `string \| null` | No | Omit or null for the first page. Use only a returned nextCursor for another page; do not use the string all. |
| `limit` | `number` | No | — |
| `format` | `json \| csv` | No | — |
