---
title: "OpenSEO database"
sidebarTitle: "Database"
description: "The OpenSEO plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for OpenSEO. To read its data, call the [API operations](/plugins/openseo/api), which return what OpenSEO has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
