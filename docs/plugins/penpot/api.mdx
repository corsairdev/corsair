## Access Tokens

### delete

`accessTokens.delete`

Revoke an API access token; apps using it stop working

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.penpot.api.accessTokens.delete({ id: "ef2a1c3d-4e5f-6a7b-8c9d-0e1f2a3b4c66" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Token id |

Revoking a token immediately breaks apps using it.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Revoked token id |
| `success` | `boolean` | Yes | Whether the revoke succeeded |



---

### list

`accessTokens.list`

List the API access tokens of the account (names only, never values)

**Risk:** `read`

await corsair.penpot.api.accessTokens.list({});

## Webhooks

### create

`webhooks.create`

Create a webhook for a team

**Risk:** `write`

```ts
await corsair.penpot.api.webhooks.create({ teamId: "5f2a1c3d-4e5f-6a7b-8c9d-0e1f2a3b4c5d", uri: "https://example.com/webhooks/penpot", mtype: "application/json" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `teamId` | `string` | Yes | Team the webhook belongs to |
| `uri` | `string` | Yes | Endpoint deliveries are posted to |
| `mtype` | `application/json \| application/transit+json` | Yes | Payload format of the deliveries |

mtype picks the delivery payload format: application/json or application/transit+json. Penpot calls the URI on create and refuses one that does not answer (500 webhook-validation).



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | UUID |
| `uri` | `string \| null` | No | Endpoint deliveries are posted to |
| `mtype` | `string \| null` | No | Payload format: application/json or application/transit+json |
| `isActive` | `boolean \| null` | No | Whether deliveries are active |
| `teamId` | `string \| null` | No | Team the webhook belongs to |



---
