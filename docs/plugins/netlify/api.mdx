## Accounts

### audit.list

`accounts.audit.list`

List a team's audit log events, one page at a time

**Risk:** `read`

```ts
await corsair.netlify.api.accounts.audit.list({ account_id: '5f3e9c1b7a2d4e0012ab34cd' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `account_id` | `string` | Yes | — |
| `query` | `string` | No | — |
| `log_type` | `string` | No | — |
| `page` | `number` | No | — |
| `per_page` | `number` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `items` | `object[]` | Yes | One page of results. |
| `next_page` | `number \| null` | Yes | The page to ask for next: set while a page came back full (per_page entries), null once a page comes back shorter. |

<AccordionGroup>
<Accordion title="items full type">

```ts
{
  id?: string | null,
  account_id?: string | null,
  payload?: {
    actor_id?: string | null,
    actor_name?: string | null,
    actor_email?: string | null,
    action?: string | null,
    timestamp?: string | null,
    log_type?: string | null
  } | null
}[]
```
</Accordion>
</AccordionGroup>

### cancel

`accounts.cancel`

Cancel a team: its sites and members are removed and billing stops

**Risk:** `destructive` · **Irreversible**


**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `account_id` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | Netlify accepted the call; it answered with no body. |
