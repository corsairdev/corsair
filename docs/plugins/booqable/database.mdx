---
title: "Booqable database"
sidebarTitle: "Database"
description: "The Booqable plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Booqable. To read its data, call the [API operations](/plugins/booqable/api), which return what Booqable has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
