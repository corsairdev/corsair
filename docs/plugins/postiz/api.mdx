## Analytics

### platform

`analytics.platform`

Read one channel's analytics rows for a period

**Risk:** `read`

```ts
await corsair.postiz.api.analytics.platform({ integration: 'cm4ean69r0003w8w1cdomox9n', date: 'last_30_days' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `integration` | `string` | Yes | The integration id to read analytics for. |
| `date` | `string` | Yes | The period to read, which the API takes as its own window token. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `analytics` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="analytics full type">

```ts
{
  label?: string | null,
  percentageChange?: number | null,
  data?: number[] | null
}[]
```
</Accordion>
</AccordionGroup>

## Posts

### changeStatus

`posts.changeStatus`

Move a post between draft and scheduled, without touching its content or date

**Risk:** `write`

```ts
await corsair.postiz.api.posts.changeStatus({ id: 'post-123', status: 'draft' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The post id to move. |
| `status` | `draft \| schedule` | Yes | `draft` pulls the post back to a draft, and `schedule` returns it to the queue. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `state` | `string \| null` | No | The new state, `DRAFT` or `QUEUE`. |



---

### create

`posts.create`

Create a post as a draft, scheduled, or published immediately. A schedule or an immediate post goes out to every listed channel and cannot be recalled by this plugin once published

**Risk:** `destructive`

```ts
await corsair.postiz.api.posts.create({ type: 'schedule', date: '2024-12-14T10:00:00.000Z', shortLink: false, tags: [], posts: [{ integration: { id: 'cm4ean69r0003w8w1cdomox9n' }, value: [{ content: 'Hello from the Postiz API!' }], settings: { __type: 'x', who_can_reply_post: 'everyone' } }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `draft \| schedule \| now` | Yes | `draft` saves without publishing, `schedule` queues for `date`, and `now` publishes as soon as Postiz takes it. |
| `date` | `string` | Yes | When to publish, as an ISO 8601 UTC timestamp. |
| `shortLink` | `boolean` | Yes | Whether Postiz shortens the links in the post. |
| `tags` | `object[]` | Yes | Tags to attach to the post. |
| `posts` | `object[]` | No | The per-integration posts. Required unless `type` is `draft`. |
| `inter` | `number` | No | Minutes between the parts of a thread. |

### delete

`posts.delete`

Delete a post, which also deletes every post in its group. A published post stays live on the platform

**Risk:** `destructive`

```ts
await corsair.postiz.api.posts.delete({ id: 'post-123' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The post id. Deleting one removes every post in its group. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The id that was deleted. |

### list

`posts.list`

```ts
await corsair.postiz.api.posts.list({ startDate: '2024-12-01T00:00:00.000Z', endDate: '2024-12-31T23:59:59.000Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `startDate` | `string` | Yes | Inclusive start of the window, as an ISO 8601 timestamp. |
| `endDate` | `string` | Yes | Inclusive end of the window, as an ISO 8601 timestamp. |
| `customer` | `string` | No | Only posts for this customer (group) id. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `posts` | `object[]` | Yes | — |
