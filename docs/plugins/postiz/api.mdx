## Analytics

### platform

`analytics.platform`

Read one channel's analytics rows for a period

**Risk:** `read`

```ts
await corsair.postiz.api.analytics.platform({ integration: 'cm4ean69r0003w8w1cdomox9n', date: '30' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `integration` | `string` | Yes | The integration id to read analytics for. |
| `date` | `string` | Yes | How many days to look back, such as `7`, `30` or `90`. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `analytics` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="analytics full type">

```ts
{
  label?: string | null,
  percentageChange?: number | null,
  data?: {
    total?: string | number | null,
    date?: string | null
  }[] | null
}[]
```
</Accordion>
</AccordionGroup>

### uploadFromUrl

`media.uploadFromUrl`

Copy a file from a public URL into the media library, for use as a post attachment

**Risk:** `write`

```ts
await corsair.postiz.api.media.uploadFromUrl({ url: 'https://example.com/image.png' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | A public http(s) URL Postiz downloads the file from. |
| `adjust` | `boolean` | No | Resize and re-encode the file to the platforms' limits after the upload. Runs in the background; the result's `status` is `processing` until it is done. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The uploaded media id. |
| `name` | `string \| null` | No | — |
| `path` | `string` | Yes | The hosted URL of the file. |
| `organizationId` | `string \| null` | No | — |
| `createdAt` | `string \| null` | No | — |
| `updatedAt` | `string \| null` | No | — |
| `status` | `string \| null` | No | `processing` while `adjust` runs, otherwise `ready`. |

## Posts

### changeStatus

`posts.changeStatus`

Move a post between draft and scheduled. Scheduling queues it to publish at its stored date to every channel it targets

**Risk:** `destructive`

```ts
await corsair.postiz.api.posts.changeStatus({ id: 'post-123', status: 'draft' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The post id to move. |
| `status` | `draft \| schedule` | Yes | `draft` pulls the post back to a draft, and `schedule` returns it to the queue. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `state` | `string \| null` | No | The new state, `DRAFT` or `QUEUE`. |



---

### create

`posts.create`

Create a post as a draft, scheduled, or published immediately. A schedule or an immediate post goes out to every listed channel and cannot be recalled by this plugin once published

**Risk:** `destructive`

```ts
await corsair.postiz.api.posts.create({ type: 'schedule', date: '2024-12-14T10:00:00.000Z', shortLink: false, tags: [], posts: [{ integration: { id: 'cm4ean69r0003w8w1cdomox9n' }, value: [{ content: 'Hello from the Postiz API!' }], settings: { __type: 'x', who_can_reply_post: 'everyone' } }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `draft \| schedule \| now` | Yes | `draft` saves without publishing, `schedule` queues for `date`, and `now` publishes as soon as Postiz takes it. |
| `date` | `string` | Yes | When to publish, as an ISO 8601 UTC timestamp. |
| `shortLink` | `boolean` | Yes | Whether Postiz shortens the links in the post. |
| `tags` | `object[]` | Yes | Tags to attach to the post. |
| `posts` | `object[]` | No | The per-integration posts. Required unless `type` is `draft`. |
| `inter` | `number` | No | Minutes between the parts of a thread. |

<AccordionGroup>
<Accordion title="tags full type">

```ts
{
  value: string,
  label: string
}[]
```
</Accordion>

<Accordion title="posts full type">

```ts

    id: string
  },
  value: {
    content: string,
    image?: {
      id: string,
      path: string,
      thumbnailTimestamp?: number
    }[],
    id?: string
  }[],
  group?: string,
  settings?: {
    __type?: string | null
  }
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `posts` | `object[]` | Yes | — |

### delete

`posts.delete`

Delete a post, which also deletes every post in its group. A published post stays live on the platform

**Risk:** `destructive`

```ts
await corsair.postiz.api.posts.delete({ id: 'post-123' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The post id. Deleting one removes every post in its group. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The id that was deleted. |
