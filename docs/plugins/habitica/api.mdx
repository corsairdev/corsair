## Auth

### login

`auth.login`

Exchange a password for an API token

**Risk:** `read`

```ts
const tenant = corsair.withTenant('acme');
await tenant.habitica.api.auth.login({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `username` | `string` | Yes | — |
| `password` | `string` | Yes | — |

| `id` | `string` | No | — |
| `apiToken` | `string` | No | — |
| `newUser` | `boolean` | No | — |
| `username` | `string` | No | — |
