## Accounts

### list

`accounts.list`

List connected social accounts (LinkedIn, X, Threads, Bluesky, Facebook Pages, Instagram, TikTok, YouTube, Pinterest) with status, capabilities and media requirements. Their ids are the targets for posts.create.

**Risk:** `read`

```ts
await corsair.postonce.api.accounts.list({});
```

**Input:** _empty object_

| `data` | `object[]` | Yes | — |

### create

`posts.create`

Create one post for one or more connected accounts, with text and media URLs. Without publish_at it publishes immediately and cannot be recalled once live; with publish_at it is scheduled. An idempotencyKey makes a retry return the original post.

**Risk:** `destructive`

```ts
await corsair.postonce.api.posts.create({ content: 'Launching today', targets: [{ account_id: 'ACCOUNT_ID' }], media: [{ url: 'https://example.com/launch.png', type: 'image' }], publish_at: '2026-12-01T15:00:00Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `content` | `string` | No | Post text shared by every target |
| `targets` | `object[]` | Yes | One entry per connected account to publish to |
| `media` | `object[]` | No | Images or a video, by URL |
| `publish_at` | `string \| null` | No | ISO-8601 date-time to schedule the post; omit to publish immediately |
| `external_id` | `string \| null` | No | Your own reference, returned on the post |
| `idempotencyKey` | `string` | No | Sent as the Idempotency-Key header. A repeat with the same body returns the original post instead of creating a duplicate. |

### list

`posts.list`

List the profile's posts, newest first, including dashboard and workflow posts. Page with after = meta.next_cursor.

**Risk:** `read`

```ts
await corsair.postonce.api.posts.list({ limit: 20 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | Maximum number of posts to return (1-100, default 20) |
| `after` | `string` | No | Cursor from a previous response (meta.next_cursor) |



**Output**

| Name | Type | Required | Description |
