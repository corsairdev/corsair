The InstaBox plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/instabox/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `sandbox`
  - `created` (`sandbox.created`)
  - `deleted` (`sandbox.deleted`)
  - `error` (`sandbox.error`)
  - `queued` (`sandbox.queued`)
  - `queueEnded` (`sandbox.queueEnded`)
  - `started` (`sandbox.started`)
  - `stopped` (`sandbox.stopped`)
  - `suspended` (`sandbox.suspended`)
- `snapshot`
  - `created` (`snapshot.created`)
  - `deleted` (`snapshot.deleted`)
  - `failed` (`snapshot.failed`)
- `webhook`
  - `test` (`webhook.test`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Events

## Sandbox

### Created

`sandbox.created`

A machine was accepted (state creating) (type sandbox.created)

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The event id, the same on every retry. |
| `type` | `string` | Yes | The event type, such as sandbox.suspended. |
| `createdAt` | `string \| null` | No | — |
| `orgId` | `string \| null` | No | The workspace the event is from. |
| `data` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  sandbox?: {
    id?: string | null,
    name?: string | null,
    metadata?: Record<string, any> | null
  } | null,
  previousState?: string | null,
  state?: string | null,
  reason?: string | null,
  operationId?: string | null
} | null
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  id: string,
  type: string,
  createdAt?: string | null,
  orgId?: string | null,
  data?: {
    sandbox?: {
      id?: string | null,
      name?: string | null,
      metadata?: Record<string, any> | null
    } | null,
    previousState?: string | null,
    state?: string | null,
    reason?: string | null,
    operationId?: string | null
  } | null
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
instabox({
    webhookHooks: {
        sandbox: {
            created: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
