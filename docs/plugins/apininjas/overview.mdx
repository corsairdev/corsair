Use **API Ninjas** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 129 typed API operations
- 13 synced entities (`aircraft`, `airlines`, `airports`, `animals`, `cities`, `countries`, and 7 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/apininjas
```
```bash yarn
yarn add corsair @corsair-dev/apininjas
```
```bash pnpm
pnpm install corsair @corsair-dev/apininjas
```
```bash bun
bun add corsair @corsair-dev/apininjas
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { apininjas } from '@corsair-dev/apininjas';

export const corsair = createCorsair({
	plugins: [
		apininjas(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
apininjas()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'apininjas',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`calendar.holidays`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.apininjas.api.calendar.holidays({});
```


**`utility.counter`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.apininjas.api.utility.counter({});
```


See the full list on the [API](/plugins/apininjas/api) page.

## Query synced data

Synced entities support `tenant.apininjas.db.<entity>.search()` and `.list()`: `aircraft`, `airlines`, `airports`, `animals`, `cities`, `countries`, `emoji`, `planets`, `sp500`, `stars`, `stockExchanges`, `universities`, `vehicles`.

See [Database](/plugins/apininjas/database) for filters and operators.
