---
title: "n8n database"
sidebarTitle: "Database"
description: "The n8n plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for n8n. To read its data, call the [API operations](/plugins/n8n/api), which return what n8n has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
