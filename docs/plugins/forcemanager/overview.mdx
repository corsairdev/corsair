Use **ForceManager** through Corsair: one client, typed API calls.

ForceManager issues a public and a private API key in ForceAdmin. Store the private key as the account's API key and the public key in its `public_key` field (`pnpm corsair setup --plugin=forcemanager api_key=<private key> public_key=<public key>`, or the two fields on Hub's connect page). The plugin logs in with the pair, sends the session token in X-Session-Key and logs in again when the token expires. Set environment to sandbox to target the documented sandbox host. Calendar create and update (sendNotification emails invitations), user create and update (billable adds a paid seat) and the generic bulk create and update routes are destructive. The plugin does not manage webhooks or perform the binary upload step returned by document and picture upload-initiation routes.

**What you get:**

- 294 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/forcemanager better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/forcemanager better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/forcemanager better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/forcemanager better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { forcemanager } from '@corsair-dev/forcemanager';

export const corsair = createCorsair({
	plugins: [
		forcemanager(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the ForceManager API key before the first call: `pnpm corsair setup --plugin=forcemanager --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
forcemanager()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'forcemanager',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`accountAddresses.accountAddressesSchema`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.forcemanager.api.accountAddresses.accountAddressesSchema({});
```


**Create an account address**

```ts
const tenant = corsair.withTenant('acme');
await tenant.forcemanager.api.accountAddresses.createAccountAddress({
	body: { accountId: 1, address1: 'Main office' },
});
```


See the full list on the [API](/plugins/forcemanager/api) page.
