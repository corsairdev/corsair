---
title: "Mocean database"
sidebarTitle: "Database"
description: "The Mocean plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Mocean. To read its data, call the [API operations](/plugins/mocean/api), which return what Mocean has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
