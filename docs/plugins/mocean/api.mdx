Look up a number's original and current carrier and porting status, paid from prepaid credit; synchronous without a callback URL

**Risk:** `read`

```ts
await corsair.mocean.api.lookup.request({ mocean_to: '60123456789' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `mocean_to` | `string` | Yes | The phone number to look up, with country code. |

### send

`sms.send`

Send an SMS to up to 500 receivers, charged per destination; the response has a status and msgid per receiver

**Risk:** `destructive`

```ts
await corsair.mocean.api.sms.send({ mocean_from: 'Acme', mocean_to: '60123456789 60198765432', mocean_text: 'Your order has shipped.' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `mocean_from` | `string` | Yes | The Sender ID shown on the recipient handset. |
| `mocean_to` | `string` | Yes | Receiver phone numbers with country code, separated by commas or spaces, up to 500. |
| `mocean_text` | `string` | Yes | The message content; every receiver gets the same text. |
| `mocean_udh` | `string` | No | User Data Header, e.g. 0605040B8423F0. |
| `mocean_coding` | `number` | No | DCS coding scheme: 1 for 7-bit, 2 for 8-bit, 3 for UCS2. |
| `mocean_dlr_mask` | `number` | No | Set to 1 to request delivery reports. Defaults to 0. |
| `mocean_dlr_url` | `string` | No | Required when mocean_dlr_mask is 1: the delivery report callback URL. |
| `mocean_schedule` | `string` | No | Send later, in Malaysia time (GMT+8). A wrong format is rejected by the gateway. |
| `mocean_mclass` | `number` | No | Set to 1 with mocean_alt_dcs to send a Flash SMS. |
| `mocean_alt_dcs` | `number` | No | Set to 1 with mocean_mclass to send a Flash SMS. |
| `mocean_charset` | `ISO-8859-1 \| ISO-8859-7 \| UTF-8 \| Windows-1252` | No | The character set used in mocean_text. |
| `mocean_validity` | `number` | No | How long the message stays deliverable, in seconds. |

`POST /rest/2/sms` with a form-encoded body. Mocean answers HTTP 202 with
`{ messages: [{ status, receiver, msgid }] }`; each row can fail on its own.
A request with no receiver answers HTTP 400 with the same shape.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `messages` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="messages full type">

```ts
{
  status: number | string,
  receiver?: string | null,
  msgid?: string | null,
  err_msg?: string | null
}[]
```
</Accordion>
</AccordionGroup>

### status

`sms.status`

Read a sent message's final status (success, failed, expired, pending or not found) and the credit it took

**Risk:** `read`

```ts
await corsair.mocean.api.sms.status({ mocean_msgid: 'cust20013050311050614001' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `mocean_msgid` | `string` | Yes | The msgid from the send response. |

`GET /rest/2/report/message`. `message_status` is 1 success, 2 failed,
3 expired, 4 pending, 5 not found (an unknown msgid answers 5, not an
error).



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `number \| string` | Yes | — |
| `message_status` | `number \| null` | No | — |
| `msgid` | `string \| null` | No | — |
| `credit_deducted` | `number \| string \| null` | No | — |

## Verify

### check

`verify.check`

Check the code a user gave you against a verify request; Mocean allows three wrong attempts

**Risk:** `write`

```ts
await corsair.mocean.api.verify.check({ mocean_reqid: 'moceanq5672285037', mocean_code: '123456' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `mocean_reqid` | `string` | Yes | The reqid of the verify request. |
| `mocean_code` | `string` | Yes | The PIN the user gave you. |

`POST /rest/2/verify/check`. An expired or unknown reqid answers HTTP 404
with body status 17; a wrong code is status 16.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `reqid` | `string \| null` | No | — |
| `status` | `number \| string` | Yes | — |
