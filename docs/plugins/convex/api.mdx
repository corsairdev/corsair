## Custom Domains

### delete

`customDomains.delete`

Remove a custom domain from a Convex deployment

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.convex.api.customDomains.delete({ deployment_name: 'happy-otter-123', requestDestination: 'convexSite', domain: 'api.example.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deployment_name` | `string` | Yes | — |
| `requestDestination` | `convexCloud \| convexSite` | Yes | — |
| `domain` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |
