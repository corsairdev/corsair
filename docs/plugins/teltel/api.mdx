## Calls

### create

`calls.create`

Place a click-to-call between two numbers, which bills per minute once answered

**Risk:** `destructive`

```ts
await corsair.teltel.api.calls.create({ caller_number: '37126111111', destination_number: '37126111112', destination_displayname: 'Support' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `caller_number` | `string` | Yes | The phone number or SIP device that places the call. |
| `caller_displayname` | `string` | No | — |
| `destination_number` | `string` | Yes | The number to dial. |
| `destination_displayname` | `string` | Yes | The display name shown to the destination. |

destination_displayname is required alongside both numbers.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  status?: number | null,
  message?: string | null
} | null
```
</Accordion>
</AccordionGroup>

## Campaigns

### action

`campaigns.action`

Start, pause or stop a campaign; start sends to every contact in its groups

**Risk:** `destructive`

```ts
await corsair.teltel.api.campaigns.action({ campaignId: 781, action: 'start' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `number` | Yes | The campaign to act on. |
| `action` | `start \| pause \| stop` | Yes | What to do: start sending, pause, or stop for good. |

start sends to every contact in the campaign groups, pause stops it temporarily and stop ends it.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  id?: number | null,
  action?: string | null
} | null
```
</Accordion>
</AccordionGroup>
