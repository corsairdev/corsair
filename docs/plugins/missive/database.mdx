---
title: "Missive database"
sidebarTitle: "Database"
description: "The Missive plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Missive. To read its data, call the [API operations](/plugins/missive/api), which return what Missive has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
