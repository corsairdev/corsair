## Account

### get

`account.get`

Check that the key works; the route answers 200 either way, so `authenticated` reports whether a workspace actually came back

**Risk:** `read`

```ts
await corsair.roboflow.api.account.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `welcome` | `string \| null` | No | — |
| `instructions` | `string \| null` | No | — |
| `docs` | `string \| null` | No | — |
| `workspace` | `string \| null` | No | The workspace slug the key belongs to. Absent when the request was not authenticated. |
| `workspaceId` | `string \| null` | No | — |
| `authenticated` | `boolean` | Yes | True when a workspace came back, which is the only proof the key works. |

## Images

### upload

`images.upload`

Upload one image to a project by URL or base64; a duplicate is reported as such rather than as a failure

**Risk:** `write`

```ts
await corsair.roboflow.api.images.upload({ project: 'roboflow/chess-sample-4ckfl', image: 'https://example.com/board.jpg', batch: 'may-import', tag: ['chess'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project` | `string` | Yes | The project URL slug, or a workspace/project ID whose workspace is the API key's own. |
| `image` | `string` | Yes | A publicly reachable image URL, or a base64 data URI. Up to 20MB. |
| `name` | `string` | No | The file name to record, when the image is a data URI. |
| `batch` | `string` | No | A batch name to group the upload under. |
| `tag` | `string[]` | No | Tags for the new image. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean \| null` | No | — |
| `duplicate` | `boolean \| null` | No | — |
| `id` | `string \| null` | No | The image ID, for a later annotation. |

## Infer

### infer

`infer`

Run a trained model on an image on the serverless inference host, returning predictions and their count; billed per image

**Risk:** `write`

```ts
await corsair.roboflow.api.infer({ modelId: 'chess-sample-4ckfl/3', image: 'https://example.com/board.jpg', confidence: 0.5, overlap: 0.3 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `modelId` | `string` | Yes | The model ID from models.list `url`, in the form project/version, or workspace/model for a model not tied to a version. |
| `image` | `string` | Yes | A publicly reachable image URL, a base64 string, or a data URI. Base64 is sent as `image_type=base64`. |
| `imageType` | `url \| base64` | No | url sends `image` in the query; base64 sends the raw image in the request body. HTTP URLs select url when imageType is omitted; other strings select base64. |
| `confidence` | `number` | No | The confidence threshold, 0 to 1, to filter predictions. |
| `overlap` | `number` | No | The IoU threshold above which two boxes are treated as duplicates. |
| `maxDetections` | `number` | No | The most predictions to return. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `image` | `Record<string, JsonValue> \| Record<string, JsonValue>[] \| null` | No | The input image, with its width and height. |
| `predictions` | `object[] \| Record<string, JsonValue> \| null` | No | Detection and single-label classification return arrays. Multi-label classification returns a class-keyed object; semantic segmentation returns a mask object. |
| `predicted_classes` | `string[] \| null` | No | — |
| `count` | `number \| null` | No | How many predictions came back. |
| `time` | `number \| null` | No | Inference time in seconds. |

<AccordionGroup>
<Accordion title="predictions full type">

```ts
{
  x?: number | null,
  y?: number | null,
  width?: number | null,
  height?: number | null,
  confidence?: number | null,
  class?: string | null,
  class_id?: number | null,
  detection_id?: string | null
}[] | Record<string, JsonValue> | null
```
</Accordion>
</AccordionGroup>

## Project

### create

`project.create`

Create a project of a given type in an annotation group, optionally licensed onto Universe

**Risk:** `write`

```ts
await corsair.roboflow.api.project.create({ workspace: 'roboflow', name: 'Sharks Dataset', type: 'object-detection', annotation: 'sharks', license: 'Private' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspace` | `string` | Yes | — |
| `name` | `string` | Yes | Letters, numbers, dashes, underscores and spaces only. |
| `type` | `object-detection \| single-label-classification \| multi-label-classification \| instance-segmentation \| semantic-segmentation \| keypoint-detection \| action-recognition \| anomaly-detection` | Yes | anomaly-detection needs the feature turned on and its own annotation group. |
| `annotation` | `string` | Yes | The annotation group: a noun for what you label, such as sharks. Projects in one group share classes. |
| `license` | `Private \| Public Domain \| MIT \| CC BY 4.0 \| BY-NC-SA 4.0 \| ODbL v1.0` | No | Private keeps the project private; any other value publishes it on Universe. Required on a public plan, which cannot create a private project. |
| `group` | `string` | No | A project folder ID to create it in. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | The new project ID. |
| `name` | `string \| null` | No | — |
| `type` | `string \| null` | No | — |
