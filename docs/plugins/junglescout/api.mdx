## Keywords

### byAsin

`keywords.byAsin`

Query keywords and rankings for up to 10 Amazon ASINs

**Risk:** `read`

```ts
await corsair.junglescout.api.keywords.byAsin({ marketplace: 'us', asins: ['B08RT1NF23', 'B002UXRXE6'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `marketplace` | `us \| uk \| de \| in \| ca \| fr \| it \| es \| mx \| jp` | Yes | — |
| `asins` | `string[]` | Yes | — |
| `sort` | `name \| -name \| dominant_category \| -dominant_category \| monthly_trend \| -monthly_trend \| quarterly_trend \| -quarterly_trend \| monthly_search_volume_exact \| -monthly_search_volume_exact \| monthly_search_volume_broad \| -monthly_search_volume_broad \| recommended_promotions \| -recommended_promotions \| sp_brand_ad_bid \| -sp_brand_ad_bid \| ppc_bid_broad \| -ppc_bid_broad \| ppc_bid_exact \| -ppc_bid_exact \| ease_of_ranking_score \| -ease_of_ranking_score \| relevancy_score \| -relevancy_score \| organic_product_count \| -organic_product_count` | No | — |
| `page_size` | `number` | No | — |
| `page_cursor` | `string` | No | — |
| `include_variants` | `boolean` | No | — |
| `min_monthly_search_volume_exact` | `number` | No | — |
| `max_monthly_search_volume_exact` | `number` | No | — |
| `min_monthly_search_volume_broad` | `number` | No | — |
| `max_monthly_search_volume_broad` | `number` | No | — |
| `min_word_count` | `number` | No | — |
| `max_word_count` | `number` | No | — |
| `min_organic_product_count` | `number` | No | — |
| `max_organic_product_count` | `number` | No | — |

Query up to 10 ASINs per request. Returns exact and broad search volume, PPC bids, and competitor ranking data.



**Output**

|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `links` | `object` | No | — |
| `meta` | `object` | No | — |

### byKeyword

### historicalSearchVolume

`keywords.historicalSearchVolume`

Retrieve weekly historical search volume trends for a keyword

**Risk:** `read`

```ts
await corsair.junglescout.api.keywords.historicalSearchVolume({ marketplace: 'us', keyword: 'yoga mat', start_date: '2024-01-01', end_date: '2024-06-01' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `marketplace` | `us \| uk \| de \| in \| ca \| fr \| it \| es \| mx \| jp` | Yes | — |
| `keyword` | `string` | Yes | — |
| `start_date` | `string` | Yes | — |
| `end_date` | `string` | Yes | — |

Date ranges must use YYYY-MM-DD format with start date prior to end date.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  id: string,
  type: string,
  attributes: {
    estimate_start_date: string,
    estimate_end_date: string,
    estimated_exact_search_volume: number
  }
}[]
```
</Accordion>
</AccordionGroup>

## Product Database

### query

`productDatabase.query`

Search Amazon product catalog with sales, revenue, rank, and review filters

**Risk:** `read`

```ts
await corsair.junglescout.api.productDatabase.query({ marketplace: 'us', include_keywords: ['stainless steel water bottle'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `marketplace` | `us \| uk \| de \| in \| ca \| fr \| it \| es \| mx \| jp` | Yes | — |
| `sort` | `name \| -name \| category \| -category \| revenue \| -revenue \| sales \| -sales \| price \| -price \| rank \| -rank \| reviews \| -reviews \| lqs \| -lqs \| sellers \| -sellers` | No | — |
| `page_size` | `number` | No | — |
| `page_cursor` | `string` | No | — |

| `product_tiers` | `(standard \| oversize)[]` | No | — |

| `min_price` | `number` | No | — |
| `max_price` | `number` | No | — |

| `max_net` | `number` | No | — |

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|

| `asin` | `string` | Yes | — |
| `start_date` | `string` | Yes | — |
| `end_date` | `string` | Yes | — |

End date must precede the current UTC date. Returns daily sales estimates and pricing trends.



**Output**
