## Contacts

### add

`contacts.add`

Add a contact (lead) to a GoDial list; assignmentMode or accountsId assigns it to an agent for calling

**Risk:** `write`

```ts
await corsair.godial.api.contacts.add({ listId: 'list-123', name: 'Ada Lovelace', phone: '+15555550123' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | — |
| `email` | `string` | No | — |
| `phone` | `string` | Yes | — |
| `secondPhone` | `string` | No | — |
| `companyName` | `string` | No | — |
| `note` | `string` | No | — |
| `remarks` | `string` | No | — |
| `extra` | `string` | No | — |
| `assignmentMode` | `default \| roundrobin` | No | — |
| `customFields` | `object[]` | No | — |
| `listId` | `string` | Yes | — |
| `accountsId` | `string` | No | — |
| `source` | `string` | No | — |
| `address` | `string` | No | — |
| `source_marketing` | `object` | No | — |

phone and listId are required. With assignmentMode 'roundrobin' or an accountsId the contact is assigned to an agent and joins that agent's calling queue. The reference shows only an empty example response.

```
</Accordion>

<Accordion title="source_marketing full type">

```
</Accordion>
</AccordionGroup>

## Lists

### list

`lists.list`

List the authenticated GoDial account’s lists

**Risk:** `read`

```ts
await corsair.godial.api.lists.list({});
```

**Input:** _empty object_

GoDial's reference (godial.stoplight.io) documents the route but shows only an empty example response, so the result is returned as the provider's JSON without a fixed shape.


**Output:** `object[]`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  id: string | number,
  name?: string | null,
  system?: boolean | null,
  callScript?: string | null,
  companyId?: string | number | null,
  teamsId?: string | number | null,
  indiamart?: {
    enabled?: boolean | null
  } | null
}[]
```
</Accordion>
</AccordionGroup>
