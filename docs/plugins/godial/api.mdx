## Contacts

### add

`contacts.add`

Add a contact to a GoDial list

**Risk:** `write`

```ts
await corsair.godial.api.contacts.add({ listId: 'list-123', name: 'Ada Lovelace', phone: '+15555550123' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | — |
| `email` | `string` | No | — |
| `phone` | `string` | No | — |
| `secondPhone` | `string` | No | — |
| `companyName` | `string` | No | — |
| `note` | `string` | No | — |
| `remarks` | `string` | No | — |
| `extra` | `string` | No | — |
| `assignmentMode` | `string` | No | — |
| `listId` | `string` | Yes | — |

The official overview documents this route but does not publish its response envelope or fields. Only this route and lists.list are verified; other GoDial operations are excluded until their API contract is available.



**Output:** `custom`

## Lists

### list

`lists.list`

List the authenticated GoDial account’s lists

**Risk:** `read`

```ts
await corsair.godial.api.lists.list({});
```

**Input:** _empty object_

The official overview documents this route but does not publish its response envelope or fields. Only this route and contacts.add are verified; other GoDial operations are excluded until their API contract is available.


**Output:** `custom`
