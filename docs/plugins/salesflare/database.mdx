---
title: "Salesflare database"
sidebarTitle: "Database"
description: "The Salesflare plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Salesflare. To read its data, call the [API operations](/plugins/salesflare/api), which return what Salesflare has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
