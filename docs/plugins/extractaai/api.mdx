## Classification

### create

`classification.create`

Create a document classification (EXTRACTA_AI_CREATE_CLASSIFICATION)

**Risk:** `write`

```ts
await corsair.extractaai.api.classification.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `classificationDetails` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="classificationDetails full type">

```ts
{
  name: string,
  description?: string,
  documentTypes: {
    name: string,
    description: string,
    uniqueWords: string[],
    extractionId?: string
  }[]
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `created` | Yes | — |
| `createdAt` | `number` | Yes | — |
| `classificationId` | `string` | Yes | — |
