Use **Extracta.ai** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 10 typed API operations
- 2 synced entities (`classifications`, `extractions`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/extractaai better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/extractaai better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/extractaai better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/extractaai better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { extractaai } from '@corsair-dev/extractaai';

export const corsair = createCorsair({
	plugins: [
		extractaai(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Extracta.ai API key before the first call: `pnpm corsair setup --plugin=extractaai --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
extractaai()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'extractaai',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Check remaining credits**

```ts
const tenant = corsair.withTenant('acme');
await tenant.extractaai.api.credits.get({});
```


**Create an extraction**

```ts
const tenant = corsair.withTenant('acme');
await tenant.extractaai.api.extraction.create({
	extractionDetails: {
		name: 'Invoice extraction',
		language: 'English',
		fields: [{ key: 'invoice_number', description: 'The invoice number.' }],
	},
});
```


See the full list on the [API](/plugins/extractaai/api) page.

## Query synced data

These tables exist, but Extracta.ai calls don't fill them yet. This returns only rows you have written yourself.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.extractaai.db.extractions.search({
	data: {},
	limit: 50,
});
```

Synced entities: `classifications`, `extractions`. See [Database](/plugins/extractaai/database) for filters and operators.
