## Accounts

### getBalance

`accounts.getBalance`

Retrieve the authenticated user's fund balance.

**Risk:** `read`

```ts
await corsair.daffy.api.accounts.getBalance({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `amount` | `number` | Yes | Not specified |
| `pending_deposit_balance` | `number` | Yes | Not specified |
| `portfolio_balance` | `number` | Yes | Not specified |
| `available_balance` | `number` | Yes | Not specified |
