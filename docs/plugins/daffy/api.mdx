## Accounts

### getBalance

`accounts.getBalance`

Retrieve the authenticated user's fund balance.

**Risk:** `read`

```ts
await corsair.daffy.api.accounts.getBalance({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `amount` | `number` | Yes | — |
| `pending_deposit_balance` | `number` | Yes | — |
| `portfolio_balance` | `number` | Yes | — |
| `available_balance` | `number` | Yes | — |

## Gifts

### create

`gifts.create`

Create a Daffy charitable gift for a beneficiary.

**Risk:** `write`

```ts
await corsair.daffy.api.gifts.create({ name: 'Jamie', amount: 18 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `amount` | `number` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Gift beneficiary name. |
| `amount` | `number` | Yes | Gift amount in US dollars. |
| `message` | `string` | No | Gift message. |
| `code` | `string` | Yes | Unique gift code. |
| `ein` | `string` | No | Associated nonprofit EIN. |
| `seen` | `boolean` | Yes | Whether the gift was seen. |
| `status` | `new \| accepted \| denied \| claimed` | Yes | Gift status. |
| `updated_at` | `string` | Yes | Gift status update timestamp. |
| `created_at` | `string` | Yes | Gift creation timestamp. |
| `claimed` | `boolean` | Yes | Whether the gift was claimed. |
| `url` | `string` | Yes | Shareable gift URL. |



---
