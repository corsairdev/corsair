## Fields

### create

`fields.create`

Add a field to a table: text, number, choice, date, reference and the other Ninox types

**Risk:** `write`

```ts
await corsair.ninox.api.fields.create({ workspaceId: 'abcdefghijkl', moduleName: 'CRM', tableName: 'orders', field: { name: 'tags', labels: { '': 'Tags' }, type: 'multi', options: [{ label: 'red' }, { label: 'blue' }] } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspaceId` | `string` | Yes | The workspace id, twelve lowercase letters or digits. |
| `moduleName` | `string` | Yes | The module name, as it appears in the workspace. |
| `tableName` | `string` | Yes | The table name, as it appears in the module. |
| `field` | `object` | Yes | — |

Choice and multi options are [&#123; label &#125;]; Ninox assigns the ids.

<AccordionGroup>
<Accordion title="field full type">

```ts
{
  name: string,
  labels: Record<string, string>,
  type: string | html | number | boolean | choice | dchoice | multi | dmulti | file | date | timestamp | time | appointment | reference | reverse | function | color | icon,
  required?: boolean,
  unique?: boolean,
  variant?: string,
  options?: any,
  refTableName?: string,
  expression?: string
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `field` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="field full type">

```ts
{
  name?: string | null,
  type?: string | null,
  required?: boolean | null,
  unique?: boolean | null,
  canRead?: string | null,
  canWrite?: string | null,
  binding?: string | null
}
```
</Accordion>
</AccordionGroup>

## Records

### changes

`records.changes`

Poll a table’s row-level change feed since a timestamp, which needs history tracking enabled on that table

**Risk:** `read`

```ts
await corsair.ninox.api.records.changes({ workspaceId: 'abcdefghijkl', moduleName: 'CRM', tableName: 'Contacts', since: '2026-11-16T09:00:00Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspaceId` | `string` | Yes | The workspace id, twelve lowercase letters or digits. |
| `moduleName` | `string` | Yes | The module name, as it appears in the workspace. |
| `tableName` | `string` | Yes | The table name, as it appears in the module. |
| `since` | `string` | Yes | Return changes at or after this instant. Only tables with history tracking enabled answer; others return 400. |
| `asOf` | `string` | No | The first page's meta.asOf, when paging through one poll so the window stays fixed. |
| `limit` | `number` | No | Most rows to return, 1 to 100. |
| `offset` | `number` | No | Rows to skip. Starts at 0. |

Needs history tracking on the table, which otherwise answers 400. Pass result.asOf back as since on the next poll.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `changes` | `object[]` | Yes | — |
| `asOf` | `string \| null` | No | Pass as `since` on the next poll to avoid a gap or a repeat. |
| `page_info` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="changes full type">

### update

`records.update`

Update rows in one transaction, optionally rejecting a write when a field no longer holds the value the caller read

**Risk:** `write`

```ts
await corsair.ninox.api.records.update({ workspaceId: 'abcdefghijkl', moduleName: 'CRM', tableName: 'Contacts', records: [{ id: 12, Name: 'Dana O.' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspaceId` | `string` | Yes | The workspace id, twelve lowercase letters or digits. |
| `moduleName` | `string` | Yes | The module name, as it appears in the workspace. |
| `tableName` | `string` | Yes | The table name, as it appears in the module. |
| `override` | `boolean` | No | Write the values even when one no longer matches its _expected entry, instead of answering 409. |
| `records` | `object[]` | Yes | — |

Put values you read into _expected; a mismatch answers 409 unless override is true.

<AccordionGroup>

```ts
  id: number,
  _expected?: Record<string, string | number | boolean | null | (string | number)[]>
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `updatedIds` | `string[]` | Yes | — |

### upsert

`records.upsert`

Create or update rows matched by one unique field, refusing an ambiguous match rather than picking a row

**Risk:** `write`

```ts
await corsair.ninox.api.records.upsert({ workspaceId: 'abcdefghijkl', moduleName: 'CRM', tableName: 'Contacts', matchField: 'Email', records: [{ Email: 'dana@northwind.example', Name: 'Dana Okafor' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspaceId` | `string` | Yes | The workspace id, twelve lowercase letters or digits. |
| `moduleName` | `string` | Yes | The module name, as it appears in the workspace. |
| `tableName` | `string` | Yes | The table name, as it appears in the module. |
| `matchField` | `string` | Yes | The unique field to match on. Ninox refuses a field not marked unique, and a non-unique match answers 409. |
| `records` | `Record<string, string \| number \| boolean \| null \| (string \| number)[]>[]` | Yes | — |

matchField must be a field marked unique; an ambiguous match answers 409 rather than picking a row.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `createdIds` | `string[]` | Yes | — |
| `updatedIds` | `string[]` | Yes | — |

## Scripts

### execute

`scripts.execute`

Run Ninox script in a module and return its result; a script can change or delete records

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.ninox.api.scripts.execute({ workspaceId: 'abcdefghijkl', moduleName: 'CRM', script: 'count(select Contacts)' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspaceId` | `string` | Yes | The workspace id, twelve lowercase letters or digits. |
| `moduleName` | `string` | Yes | The module the script runs in; `do as database` stays inside it. |
| `script` | `string` | Yes | Ninox script, e.g. count(select customers). |
| `tableName` | `string` | No | The table name, as it appears in the module. |
| `rowId` | `number` | No | A record the script runs against (as `this`). |
| `mode` | `wait \| background` | No | wait (default) answers the result when the script ends in time; background answers the run at once. |

A script can write and delete, so this is destructive. A long script answers &#123; run &#125; instead of &#123; result &#125;.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `result` | `any` | No | — |
| `run` | `Record<string, any>` | No | — |
