## Libraries

### create

`libraries.create`

Create a reusable library whose importName transformations import it by

**Risk:** `write`

```ts
await corsair.rudderstacktransform.api.libraries.create({ name: 'cool library', language: 'javascript', code: 'export function add(a,b) { return a+b; }', publish: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | The library name, used as the module name when imported. |
| `language` | `javascript \| pythonfaas` | Yes | javascript or pythonfaas. A resource cannot change language after it is created. |
| `code` | `string` | Yes | The library code. |
| `description` | `string` | No | — |
| `publish` | `boolean` | No | True publishes the library immediately. Defaults to false. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `versionId` | `string \| null` | No | — |
| `name` | `string \| null` | No | — |
| `description` | `string \| null` | No | — |
| `code` | `string \| null` | No | — |
| `language` | `string \| null` | No | — |
| `createdAt` | `string \| null` | No | — |
| `updatedAt` | `string \| null` | No | — |
| `importName` | `string \| null` | No | The name a transformation imports this library by. It cannot be changed after creation. |
| `isPublished` | `boolean \| null` | No | Documented on revision rows, but the live API left it out on 11-12. |


| `transformations` | `object[]` | No | — |

## Transformations

### connect

`transformations.connect`

Connect a published transformation to a destination, replacing any transformation already connected to it

**Risk:** `write`

```ts
await corsair.rudderstacktransform.api.transformations.connect({ id: '2C8Vk2wj8qkofy00YzJbvJOGeqa', destinationId: '2C8YtptB4KF2eL3KRi9mCFkY3BF' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `destinationId` | `string` | Yes | The destination to act on. |
| `id` | `string` | Yes | The transformation to connect. It must be published, or RudderStack answers 400 "Transformation is not published". |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `versionId` | `string \| null` | No | Identifies this revision; pass it to libraries.publish. |
| `name` | `string \| null` | No | — |
| `description` | `string \| null` | No | — |
| `code` | `string \| null` | No | The JavaScript or Python code. |
| `codeVersion` | `string \| null` | No | Always "1" for API calls, as RudderStack sends it. |
| `language` | `string \| null` | No | — |
| `createdAt` | `string \| null` | No | — |
| `updatedAt` | `string \| null` | No | — |
| `workspaceId` | `string \| Record<string, JsonValue> \| null` | No | A string ID or a workspace object, depending on the route. |
| `destinations` | `object[] \| null` | No | — |
