The Benzinga plugin syncs data locally. Use `corsair.benzinga.db.<entity>.search({ entity_id?, data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Conference Calls

Path: `benzinga.db.conferenceCalls.search`

```ts
const rows = await corsair.benzinga.db.conferenceCalls.search({
    entity_id: { equals: '<id>' }, // optional, top-level (not inside data)
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
```
