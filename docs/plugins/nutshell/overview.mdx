Use **Nutshell** through Corsair: one client, typed API calls.

Authenticate with the Nutshell user's email as the HTTP Basic username and that user's API key as the password. Requests use the HTTPS REST API at `https://app.nutshell.com/rest`.

This plugin implements the documented REST operations. Nutshell's legacy JSON-RPC API is not included. Its webhooks are outbound notifications configured in Nutshell, not inbound operations for this integration.

**What you get:**

- 114 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/nutshell better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/nutshell better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/nutshell better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/nutshell better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { nutshell } from '@corsair-dev/nutshell';

export const corsair = createCorsair({
	plugins: [
		nutshell(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Nutshell API key before the first call: `pnpm corsair setup --plugin=nutshell --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
nutshell()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'nutshell',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`accounts.customFieldAttributes`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.nutshell.api.accounts.customFieldAttributes({});
```


**`accounts.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.nutshell.api.accounts.create({});
```
