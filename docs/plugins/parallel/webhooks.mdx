The Parallel plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/parallel/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `findall`
  - `candidateEnriched` (`findall.candidateEnriched`)
  - `candidateGenerated` (`findall.candidateGenerated`)
  - `candidateMatched` (`findall.candidateMatched`)
  - `runCancelled` (`findall.runCancelled`)
  - `runCompleted` (`findall.runCompleted`)
  - `runFailed` (`findall.runFailed`)
- `monitor`
  - `eventDetected` (`monitor.eventDetected`)
  - `executionCompleted` (`monitor.executionCompleted`)
  - `executionFailed` (`monitor.executionFailed`)
- `taskRun`
  - `status` (`taskRun.status`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

### Candidate Enriched

`findall.candidateEnriched`

Enrichment data was extracted for a FindAll candidate

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `findall.candidate.enriched` | Yes | — |
| `timestamp` | `string` | Yes | — |
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  candidate_id: string,
  name: string,
  url: string,
  match_status: generated | matched | unmatched | discarded | string,
  description?: string | null,
  output?: Record<string, JsonValue> | null,
  basis?: {
    field: string,
    reasoning: string,
    confidence?: string | null,
    citations?: {
      url: string,
      title?: string | null,
      excerpts?: string[] | null
    }[]
  }[] | null,
  findall_id: string
}
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts

    description?: string | null,

      field: string,

      confidence?: string | null,
      citations?: {
        url: string,

```
</Accordion>
</AccordionGroup>

```ts

                after(ctx, response) {
                },
            },
        },
    },
})
```
