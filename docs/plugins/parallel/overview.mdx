Use **Parallel** through Corsair: one client, typed API calls, and incoming webhooks.

Create a key in the Parallel console (https://platform.parallel.ai) and send it as the `x-api-key` header.

Things to know before you send:

- **Search APIs.** `search.search` (web pages and excerpts), `images.search`, `places.search`, `flights.search`, `hotels.search` and `shopping.search` are synchronous and priced per request. `flights.search` takes IATA codes (`SFO`, `NYC`) and returns itineraries linked to the airline's booking page; `hotels.search` returns properties with each seller's offers; `shopping.search` returns products linked to store pages, with the market set by `advanced_settings.location` (`us` by default).
- **`fetch_policy.as_of`** asks for results as the web stood on a date. Parallel enables it per account: without access it answers 422 "as_of is not enabled".
- **Tasks, FindAll and Monitors run in the background.** `tasks.createRun`, `findall.createRun` and `monitors.create` return an id at once; read the result later or pass a `webhook`. A monitor keeps running on its schedule, and billing, until `monitors.cancel`.
- **Managed pricing.** With `authType: 'managed_pricing'` the calls run on Corsair's Parallel account and are billed in Corsair credits. Only the operations Corsair prices run that way; the rest (background runs, monitors, memory) are refused and nothing is charged.
- **Inbound webhooks.** Parallel signs every delivery the Standard Webhooks way (`webhook-id`, `webhook-timestamp`, `webhook-signature: v1,<base64>`) with your account's webhook secret from Settings → Webhooks. Set `webhookSecret`, or store it with `keys.set_webhook_signature`. Verification needs the untouched request body, and deliveries more than five minutes old are refused. Events: `taskRun.status`, `findall.candidateGenerated`, `findall.candidateMatched`, `findall.candidateEnriched`, `findall.runCompleted`, `findall.runCancelled`, `findall.runFailed`, `monitor.eventDetected`, `monitor.executionCompleted` and `monitor.executionFailed`. Subscribe a FindAll run with the `findall.*` event names, not `task_run.status`.

**What you get:**

- 38 typed API operations
- 10 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/parallel better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/parallel better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/parallel better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/parallel better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { parallel } from '@corsair-dev/parallel';

export const corsair = createCorsair({
	plugins: [
		parallel(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Parallel API key before the first call: `pnpm corsair setup --plugin=parallel --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
parallel()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'parallel',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`extract.extract`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.parallel.api.extract.extract({});
```


**`chat.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.parallel.api.chat.create({});
```


See the full list on the [API](/plugins/parallel/api) page.

## Webhooks

This plugin registers **10** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/parallel/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
