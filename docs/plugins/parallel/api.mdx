## Chat

### create

**Risk:** `destructive`

```ts

```

| `max_tokens` | `number \| null` | No | — |
| `temperature` | `number \| null` | No | — |
| `top_p` | `number \| null` | No | — |
| `n` | `number \| null` | No | — |
| `presence_penalty` | `number \| null` | No | — |
| `frequency_penalty` | `number \| null` | No | — |
