---
title: "StatusCake database"
sidebarTitle: "Database"
description: "The StatusCake plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for StatusCake. To read its data, call the [API operations](/plugins/statuscake/api), which return what StatusCake has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
