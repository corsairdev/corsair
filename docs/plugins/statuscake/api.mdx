## Contact Groups

### create

`contactGroups.create`

Create a contact group to alert when a check fails

**Risk:** `write`

```ts
await corsair.statuscake.api.contactGroups.create({ name: 'DevOps', email_addresses: ['oncall@example.com'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | Name of the contact group. |
| `email_addresses` | `string[]` | No | List of email addresses. Sending an empty array clears them. |
| `mobile_numbers` | `string[]` | No | International format mobile numbers. Sending an empty array clears them. |
| `integrations` | `string[]` | No | Integration IDs. Sending an empty array clears them. |
| `ping_url` | `string` | No | HTTP GET endpoint pushed with uptime events. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |

```ts
{
  new_id?: string | null
}
```
</Accordion>
</AccordionGroup>

## Maintenance Windows

### create

`maintenanceWindows.create`

Create a maintenance window that silences chosen uptime checks, by ID or by tags, for a time period

**Risk:** `write`

```ts
await corsair.statuscake.api.maintenanceWindows.create({ name: 'deploy window', start_at: '2026-12-01T02:00:00Z', end_at: '2026-12-01T04:00:00Z', timezone: 'Europe/London', tests: ['123456'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | Name of the maintenance window. |
| `start_at` | `string` | No | Start of the window in RFC3339 format; the UTC offset is ignored. |
| `end_at` | `string` | No | End of the window in RFC3339 format; the UTC offset is ignored. |
| `timezone` | `string` | No | Timezone of the window, from the tz database (such as Europe/London). |
| `repeat_interval` | `never \| 1d \| 1w \| 2w \| 1m` | No | How often the window repeats. Defaults to never. |
| `tests` | `string[]` | No | Uptime checks the window covers. At least one of tests and tags is required on create. |
| `tags` | `string[]` | No | List of tags. Sending an empty array clears every tag on an update. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  new_id?: string | null
}
```
</Accordion>
</AccordionGroup>

## Pagespeed

### create

`pagespeed.create`

Create a pagespeed check that runs from a chosen region and can alert on page size or load time

**Risk:** `write`

```ts
await corsair.statuscake.api.pagespeed.create({ name: 'marketing site', website_url: 'https://www.example.com', check_rate: 3600, region: 'UK', alert_slower: 3000 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | Name of the check. |
| `website_url` | `string` | No | URL, FQDN, or IP address of the website under test. |
| `check_rate` | `number \| string` | No | Seconds between checks, one of 60, 300, 600, 900, 1800, 3600, 86400. Defaults to 300 (5 minutes). |
| `region` | `AU \| CA \| DE \| FR \| IN \| JP \| NL \| SG \| UK \| US \| USW` | No | Region to run the check from, from the pagespeed locations list. |
| `alert_bigger` | `number` | No | Alert when the page is larger than this many kb. Defaults to 0 (disabled). |
| `alert_slower` | `number` | No | Alert when the page loads slower than this many ms. Defaults to 0 (disabled). |
| `alert_smaller` | `number` | No | Alert when the page is smaller than this many kb. Defaults to 0 (disabled). |
| `contact_groups` | `string[]` | No | Contact groups alerted by this check. |
| `paused` | `boolean` | No | Whether the check should be run. Defaults to false. |



**Output**

|------|------|----------|-------------|
| `data` | `object` | Yes | — |
