## Addresses

### validate

`addresses.validate`

Validate a US address and get back every match TaxJar finds, with the street and ZIP normalized

**Risk:** `read`

```ts
await corsair.taxjar.api.addresses.validate({ country: 'US', state: 'AZ', zip: '85297', city: 'Gilbert', street: '3301 South Greenfield Rd' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `country` | `string` | Yes | Two-letter ISO country code. |
| `state` | `string` | No | Two-letter ISO state code. |
| `zip` | `string` | No | A postal code, 5 digits or ZIP+4. |
| `city` | `string` | No | — |
| `street` | `string` | No | The street address, which is the part validation rewrites. |

Returns every match TaxJar finds, so read the first entry rather than assuming one.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `addresses` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="addresses full type">

```ts
{
  zip?: string | null,
  street?: string | null,
  state?: string | null,
  country?: string | null,
  city?: string | null
}[]
```
</Accordion>
</AccordionGroup>

## Customers

### create

`customers.create`

Create an exempt customer, whose exemption applies to later transactions that cite its customer_id

**Risk:** `write`

```ts
await corsair.taxjar.api.customers.create({ customer_id: '123', exemption_type: 'wholesale', name: 'Dunder Mifflin' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `exemption_type` | `wholesale \| government \| marketplace \| other \| non_exempt` | Yes | The exemption kind. |
| `exempt_regions` | `object[]` | No | The regions the exemption covers. Omit it to exempt every region. |
| `name` | `string` | No | — |
| `country` | `string` | No | — |
| `state` | `string` | No | — |
| `zip` | `string` | No | A postal code, 5 digits or ZIP+4. |
| `city` | `string` | No | — |
| `street` | `string` | No | — |
| `customer_id` | `string` | Yes | The unique customer ID you assigned. |

exemption_type is required; omitting exempt_regions exempts every region.

<AccordionGroup>
<Accordion title="exempt_regions full type">

```ts
{

  state?: string
}[]
```

**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `customer` | `object` | Yes | — |

```ts
  customer_id: string,
```

## Orders

### create

`orders.create`

Record an order transaction for tax reporting; shipping is required even when it is zero

**Risk:** `destructive`

```ts
await corsair.taxjar.api.orders.create({ transaction_id: '123', transaction_date: '2026-11-15', to_country: 'US', to_zip: '90002', to_state: 'CA', amount: 16.5, shipping: 1.5, sales_tax: 0.95 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `from_country` | `string` | No | — |
| `from_zip` | `string` | No | A postal code, 5 digits or ZIP+4. |
| `from_state` | `string` | No | — |
| `from_city` | `string` | No | — |
| `from_street` | `string` | No | — |
| `to_country` | `string` | Yes | The destination country. |
| `to_zip` | `string` | No | A postal code, 5 digits or ZIP+4. |
| `to_state` | `string` | No | — |
| `to_city` | `string` | No | — |
| `to_street` | `string` | No | — |
| `amount` | `number` | No | The total amount of the order including shipping, excluding sales tax. |
| `shipping` | `number` | Yes | The shipping charge. TaxJar requires this field, even as 0. |
| `customer_id` | `string` | No | The unique customer ID you assigned. |
| `exemption_type` | `wholesale \| government \| marketplace \| other \| non_exempt` | No | — |
| `line_items` | `object[]` | No | — |
| `transaction_id` | `string` | Yes | The unique transaction ID you assigned. |
| `transaction_date` | `string` | Yes | A date as "YYYY/MM/DD" or "YYYY-MM-DD". TaxJar documents both and accepts either. |
| `provider` | `string` | No | — |
| `sales_tax` | `number` | No | The sales tax collected. |

shipping is required even when it is 0; amounts in the response come back as decimal strings.
