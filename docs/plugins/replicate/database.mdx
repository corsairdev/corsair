---
title: "Replicate database"
sidebarTitle: "Database"
description: "The Replicate plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Replicate. To read its data, call the [API operations](/plugins/replicate/api), which return what Replicate has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
