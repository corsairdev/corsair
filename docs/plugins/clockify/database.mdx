---
title: "Clockify database"
sidebarTitle: "Database"
description: "The Clockify plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Clockify. To read its data, call the [API operations](/plugins/clockify/api), which return what Clockify has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
