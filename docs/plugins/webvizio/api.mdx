## Projects

### list

`projects.list`

List all available Webvizio projects

**Risk:** `read`

```ts
const tenant = corsair.withTenant('acme');
await tenant.webvizio.api.projects.list({});
```

**Input:** _empty object_


**Output:** `object[]`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  uuid: string,
  name: string,
  id?: number,
  externalId?: string | null,
  screenshot?: string | null,
  url?: string | null,
  createdAt?: string | null,
  updatedAt?: string | null
}[]
```
</Accordion>
</AccordionGroup>

## Webhooks

### list

`webhooks.list`

List all configured Webvizio webhook subscriptions

**Risk:** `read`

```ts
const tenant = corsair.withTenant('acme');
await tenant.webvizio.api.webhooks.list({});
```

**Input:** _empty object_


**Output:** `object[]`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  id: number,
  url: string,
  event: string
}[]
```
</Accordion>
</AccordionGroup>
