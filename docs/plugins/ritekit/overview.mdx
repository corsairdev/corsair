Use **RiteKit** through Corsair: one client, typed API calls.

Create a token in the [API Console](https://ritekit.com/developer/dashboard/) - RiteKit calls it a **Client ID**. It travels as the `client_id` query parameter on every call, which is the transport RiteKit documents for all endpoints.

Things to know before you call:

- **Credits, not requests, are the budget.** Each endpoint costs 1 or 2 credits and the monthly allowance is shared across all of them, so a `402` means the month's credits are gone: the plugin reports it as `isQuotaExhausted` and never retries, because waiting cannot refill them. The rate limit itself is 100 calls per second.
- **Two `401` messages mean different things.** A call with no Client ID gets `Endpoint is not accessible`; a Client ID RiteKit does not recognise gets `Verification failed`. Both are a `401`, and the plugin keeps RiteKit's `info` hint on the error because it usually names the fix.
- **Hashtag fields are named differently per route.** `hashtags.stats`, `hashtags.suggestions` and `hashtags.forImage` return rows under `data`; `hashtags.forUrl` returns them under `hashtags`; `hashtags.trending` returns `tags` and calls the image share `photos` where the others call it `images`. The response models follow each route rather than pretending they match.
- **The `color` number needs its legend.** A stats row's `color` is 0 unused, 1 overused, 2 good, 3 great, and `hashtags.stats` returns the labels in a `color` array beside the rows. `hashtags.trending`'s `green` filter is the same idea, and the API reads it as `1` rather than `true`.
- **`images` / `links` / `mentions` are percentages, not counts.** A value of `0.35` means 0.35% of the hashtag's tweets carry an image, which is why the fields are fractional.
- **`hashtags.stats` takes up to 100 tags in one call**, joined into a single comma-separated `tags` value. The plugin rejects a longer list rather than letting RiteKit truncate it.
- **`links.listCtas` is not wrapped.** RiteKit's demo page says it needs each user to authenticate with RiteKit itself and "cannot be shown in the Demo", so its shape is unpublished and a single Client ID cannot call it. `links.shorten` still accepts a `cta` value from the Rite.ly dashboard.
- **`images.quote` and `images.animate` return a URL.** The two samples are not published; the docs say each returns the image's URL, so `url` is the field and the rest of the envelope is the usual one.
- **`companies.logo` gives you two URLs.** `url` expires; `permanentUrl` is stable, but every view of it costs a credit, so store the permanent one and let a CDN fetch it.

**What you get:**

- 22 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/ritekit better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/ritekit better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/ritekit better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/ritekit better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { ritekit } from '@corsair-dev/ritekit';

export const corsair = createCorsair({
	plugins: [
		ritekit(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
ritekit()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'ritekit',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read stats for two hashtags**

```ts
const tenant = corsair.withTenant('acme');
await tenant.ritekit.api.hashtags.stats({
	tags: ['jobs', 'hello'],
});
```


**Shorten a link with a Link Ad**

```ts
const tenant = corsair.withTenant('acme');
await tenant.ritekit.api.links.shorten({ url: 'https://ritekit.com', cta: '6530' });
```


See the full list on the [API](/plugins/ritekit/api) page.
