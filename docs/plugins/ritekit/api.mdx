## Companies

### brandColors

`companies.brandColors`

Return a company's brand colors from its domain or name

**Risk:** `read`

```ts
await corsair.ritekit.api.companies.brandColors({ name: 'producthunt.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | A company name or a domain. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `result` | `boolean \| null` | No | True on success. A refusal is a non-2xx status, not a false here. |
| `message` | `string \| null` | No | — |
| `code` | `number \| null` | No | Repeats the HTTP status when present. |
| `name` | `string \| null` | No | — |
| `data` | `string[] \| null` | No | The site's brand colors, most prominent first. |

### logo

`companies.logo`

Return a company's logo from its domain, with square and original variants, brand colors and a stable URL

**Risk:** `read`

```ts
await corsair.ritekit.api.companies.logo({ domain: 'evernote.com', squareLogoSize: 256, squareLogoBackground: 'original' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `domain` | `string` | Yes | The company site, such as evernote.com. |
| `generateFallbackLogo` | `boolean` | No | Generate a logo from the site's brand colors when no logo is found. |
| `squareLogoSize` | `number` | No | Pixels, 1 to 512. |
| `squareLogoBackground` | `remove \| original \| add` | No | remove makes it transparent, add makes it solid. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `result` | `boolean \| null` | No | True on success. A refusal is a non-2xx status, not a false here. |
| `message` | `string \| null` | No | — |
| `code` | `number \| null` | No | Repeats the HTTP status when present. |
| `isGenerated` | `boolean \| null` | No | True when no logo was found and one was generated. |
| `domain` | `string \| null` | No | — |
| `url` | `string \| null` | No | The logo itself. |
| `permanentUrl` | `string \| null` | No | A stable URL that serves the image directly. Each view costs a credit. |
| `originalLogo` | `object \| null` | No | — |
| `squareLogo` | `object \| null` | No | — |
| `brandColors` | `string[] \| null` | No | — |

### quote

Render a quote as a PNG with chosen fonts, colors, gradient and an optional logo, returned as a data URL

**Risk:** `read`

```ts
await corsair.ritekit.api.images.quote({ text: 'If you love life, do not waste time', author: 'Bruce Lee', width: 400, height: 400, textFont: 'Lora', backgroundColor1: '#8686bd', backgroundColor2: '#1ddad6' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `text` | `string` | Yes | The quote. |
| `author` | `string` | Yes | Who said it. |
| `width` | `number` | No | Pixels, such as 400. |
| `height` | `number` | No | Pixels, such as 400. |
| `textFont` | `string` | No | A font name, such as Lora. |
| `textColor` | `string` | No | A CSS color, such as #000000 or transparent. The # is percent-encoded for you. |
| `textFontWeight` | `number` | No | Such as 400 or 700. |
| `authorFont` | `string` | No | A font name, such as Lato. |
| `authorColor` | `string` | No | A CSS color, such as #000000 or transparent. The # is percent-encoded for you. |
| `authorFontWeight` | `number` | No | — |
| `highlightEnabled` | `boolean` | No | Highlights part of the quote. |
| `highlightColor` | `string` | No | transparent leaves the text unhighlighted. |
| `backgroundColor1` | `string` | No | The gradient's first stop. |
| `backgroundColor2` | `string` | No | The gradient's second stop. |
| `logoUrl` | `string` | No | An image drawn onto the quote, such as a brand logo. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | The image as a data URL (data:&lt;type&gt;;base64,...). |
