Use **Interzoid** through Corsair: one client, typed API calls.

Interzoid provides AI and algorithmic data matching keys (SimKeys), standardization, enrichment, and validation APIs.
An Interzoid API key (license) is required for authenticated operations.
Every API call consumes credits: standard calls generally cost one credit, while premium APIs and selected AI models can cost multiple credits. Review Interzoid's pricing and model-credit documentation before choosing paid operations.

**What you get:**

- 75 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/interzoid better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/interzoid better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/interzoid better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/interzoid better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { interzoid } from '@corsair-dev/interzoid';

export const corsair = createCorsair({
	plugins: [
		interzoid(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Interzoid API key before the first call: `pnpm corsair setup --plugin=interzoid --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
interzoid()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'interzoid',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Generate company match similarity key**

```ts
const tenant = corsair.withTenant('acme');
await tenant.interzoid.api.matching.getCompanyMatchAdvanced({ company: 'IBM Corporation', algorithm: 'model-v4-wide' });
```


**Standardize a company name (Interzoid has no writes; every operation is a lookup)**

```ts
const tenant = corsair.withTenant('acme');
await tenant.interzoid.api.standardization.getOrgStandard({ org: 'ibm inc' });
```


See the full list on the [API](/plugins/interzoid/api) page.
