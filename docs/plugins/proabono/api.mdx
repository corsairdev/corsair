## Balance Lines

### create

`balanceLines.create`

Add a balance line, such as a one-off charge or credit, to a customer in cents

**Risk:** `write`

```ts
await corsair.proabono.api.balanceLines.create({ ReferenceCustomer: 'cust-42', Title: 'One-off setup', Amount: 59900 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ReferenceCustomer` | `string` | Yes | Your own identifier for the resource, unique within its kind. |
| `Title` | `string` | Yes | — |
| `Amount` | `number` | Yes | In cents. A negative value is a credit. |
| `Description` | `string` | No | — |
| `Date` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `Id` | `number \| null` | No | The ProAbono numeric id. |
| `IdCustomer` | `number \| null` | No | The ProAbono numeric id. |
| `ReferenceCustomer` | `string \| null` | No | — |
| `IdSegment` | `number \| null` | No | The ProAbono numeric id. |
| `Title` | `string \| null` | No | — |
| `Description` | `string \| null` | No | — |
| `Amount` | `number \| null` | No | In cents. |
| `Date` | `string \| null` | No | — |
| `TypeBalanceLine` | `string \| null` | No | — |

## Subscriptions

### create

`subscriptions.create`

Subscribe a customer to an offer, which starts billing when the offer is paid and the customer is billable. `TryStart: false` creates it without starting so it can be customised first

**Risk:** `destructive`

```ts
await corsair.proabono.api.subscriptions.create({ ReferenceOffer: 'premium', ReferenceCustomer: 'cust-42' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ReferenceOffer` | `string` | Yes | Your own identifier for the resource, unique within its kind. |
| `ReferenceCustomer` | `string` | Yes | The customer, which must already exist in ProAbono. |
| `ReferenceCustomerBuyer` | `string` | No | When the buyer is not the recipient. |
| `Metadata` | `Record<string, JsonValue>` | No | Your own key-value data, stored on the resource. |
| `EnsureBillable` | `boolean` | No | Check paying information even for a free offer; a customer without any answers 403. |
