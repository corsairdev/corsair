## Balance Lines

### create

`balanceLines.create`

Add a balance line, such as a one-off charge or credit in cents, to a customer's next invoice

**Risk:** `destructive`

```ts
await corsair.proabono.api.balanceLines.create({ ReferenceCustomer: 'cust-42', Label: 'One-off setup', Amount: 59900 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ReferenceCustomer` | `string` | Yes | Your own identifier for the resource, unique within its kind. |
| `IdSubscription` | `number` | No | The ProAbono numeric id. |
| `Label` | `string` | No | The line label, shown on the invoice. |
| `Amount` | `number` | Yes | In cents, before taxes. A negative value is a credit. |
| `Quantity` | `number` | No | Shown on the invoice only; it does not change the amount. |
| `EnsureBillable` | `boolean` | No | True by default on ProAbono: a customer without valid payment information answers 403. False adds the line anyway. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `IdSegment` | `number \| null` | No | The ProAbono numeric id. |
| `IdCustomer` | `number \| null` | No | The ProAbono numeric id. |
| `IdSubscription` | `number \| null` | No | The ProAbono numeric id. |
| `ReferenceSegment` | `string \| null` | No | — |
| `ReferenceCustomer` | `string \| null` | No | — |
| `LabelLocalized` | `string \| null` | No | — |
| `PricingLocalized` | `string \| null` | No | HTML. |
| `Currency` | `string \| null` | No | — |
| `AmountSubtotal` | `number \| null` | No | In cents, before taxes. |
| `AmountTotal` | `number \| null` | No | In cents, with taxes. |
| `DateMove` | `string \| null` | No | When the line is billed, for a line outside a period. |
| `QuantityReported` | `number \| null` | No | — |
| `QuantityBilled` | `number \| null` | No | — |
| `DatePeriodStart` | `string \| null` | No | — |
| `DatePeriodTerm` | `string \| null` | No | — |
