Use **ProAbono** through Corsair: one client, typed API calls.

ProAbono bills recurring subscriptions. Every account is served from its own host, `api-<account>.proabono.com`, so the plugin needs your account number as well as the two keys from MY PROFILE, INTEGRATION: the agent key and the API key. They travel as HTTP Basic, with the agent key as the username and the API key as the password.

What to know before you bill:

- **The account number.** Pass `account: '42'` to reach `api-42.proabono.com`. Without it there is no host to call, so the plugin refuses the request rather than guessing.
- **Two steps to a subscription.** A subscription is created from an offer reference and a customer reference, and it only starts billing once the customer is billable. `TryStart: false` creates it without starting, so it can be customised first; `start` then begins it.
- **Amounts are integer cents.** Every amount, such as `AmountRecurrence` and an invoice's `AmountTotal`, is in the currency's minor unit, so 9900 is 99.00.
- **Usages accumulate.** `usages.increment` adds to a feature's usage, and a negative increment subtracts, which is how a reversed action is recorded. `usages.update` sends several rows at once.
- **A 204 is not an error.** ProAbono answers a read that finds nothing with 204 and an empty body. The plugin turns that into an empty result rather than failing the parse.
- **A 422 lists the bad fields.** It carries one entry per field, which the thrown error keeps on `validationErrors`.
- **Nothing to check a subscription with.** The docs warn against using `subscriptions.get` to decide whether a user is a subscriber, and point at their own method instead.
- **Webhooks.** ProAbono notifies through its portal rather than by webhook deliveries, so this plugin receives none.

**What you get:**

- 27 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/proabono better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/proabono better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/proabono better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/proabono better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { proabono } from '@corsair-dev/proabono';

export const corsair = createCorsair({
	plugins: [
		proabono(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the ProAbono API key before the first call: `pnpm corsair setup --plugin=proabono --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
proabono()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'proabono',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List the offers in your account**

```ts
const tenant = corsair.withTenant('acme');
await tenant.proabono.api.offers.list({});
```


**Create a customer with your own reference**

```ts
const tenant = corsair.withTenant('acme');
await tenant.proabono.api.customers.create({ ReferenceCustomer: 'cust-42', Name: 'Jane Smith', Email: 'jane@example.com' });
```


See the full list on the [API](/plugins/proabono/api) page.
