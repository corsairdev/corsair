## Analytics

### retrieve

`analytics.retrieve`

Read aggregated click, lead and sale analytics, grouped by count, timeseries, country, device, link and more

**Risk:** `read`

```ts
await corsair.dub.api.analytics.retrieve({ groupBy: 'countries', interval: '7d' });
```

**Input**

| Name | Type | Required | Description |

| `tagId` | `string` | No | — |
| `folderId` | `string` | No | — |
| `partnerTagId` | `string` | No | — |
