Use **2Captcha** through Corsair: one client, typed API calls.

Copy your API key from the 2Captcha dashboard at https://2captcha.com/setting. It is 32 characters, and the API answers `ERROR_WRONG_USER_KEY` when it is not.

Things to know:

- **Every answer is an envelope.** 2Captcha returns HTTP 200 for almost everything and puts the outcome in `status`: `1` is success and `0` is failure, with the reason in `request` and a message in `error_text`. The plugin throws `TwoCaptchaAPIError` on a failure, so a resolved promise means the task or read succeeded.
- **Creating a task costs money.** `tasks.create` is billable from the call, so it is never replayed, and a failure there is reported rather than retried.
- **Not ready is not an error.** While a task is being solved, `tasks.result` answers `status: 0` with `request: "CAPCHA_NOT_READY"`. The plugin returns that state instead of throwing, so poll until `status` is `1`.
- **Report a rejected token.** `account.reportIncorrect` refunds the task and asks the workers again. `account.reportCorrect` improves the account rating. Both take the task id.
- **Two codes are worth retrying.** `ERROR_NO_SLOT_AVAILABLE` and `ERROR_TOO_MANY_REQUESTS` mean the queue is full; the plugin retries them with backoff. Every other code is permanent.
- **Captcha kinds.** `tasks.create` takes a `type` such as `RecaptchaV2TaskProxyless` and the per-kind fields inside `task`. The key field name differs by kind: `websiteKey`, `sitekey` or `websitePublicKey`.
- **No callbacks in this plugin.** 2Captcha can POST a result to a URL you give it, but this plugin does not receive that delivery; poll `tasks.result` instead.

**What you get:**

- 5 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/twocaptcha better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/twocaptcha better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/twocaptcha better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/twocaptcha better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { twocaptcha } from '@corsair-dev/twocaptcha';

export const corsair = createCorsair({
	plugins: [
		twocaptcha(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the 2Captcha API key before the first call: `pnpm corsair setup --plugin=twocaptcha --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
twocaptcha()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'twocaptcha',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read the account balance**

```ts
const tenant = corsair.withTenant('acme');
await tenant.twocaptcha.api.account.balance({});
```


**Create a captcha task for a page**

```ts
const tenant = corsair.withTenant('acme');
await tenant.twocaptcha.api.tasks.create({
	task: { websiteURL: 'https://example.com/login', websiteKey: '6LeIxAcTAAAAAJcZVRqyHh71UMIEGNQ_MXjiZKhI' },
});
```


See the full list on the [API](/plugins/twocaptcha/api) page.
