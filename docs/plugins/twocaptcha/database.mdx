---
title: "2Captcha database"
sidebarTitle: "Database"
description: "The 2Captcha plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for 2Captcha. To read its data, call the [API operations](/plugins/twocaptcha/api), which return what 2Captcha has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
