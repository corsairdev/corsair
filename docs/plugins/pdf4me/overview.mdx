This plugin merges, splits, compresses and organizes PDFs, converts them to Word and renders HTML to PDF, runs OCR, reads PDF metadata, extracts tables and form data, and polls asynchronous processing jobs. File answers come back base64-encoded."

Use **PDF4me** through Corsair: one client, typed API calls.

Authenticate with the API key from the PDF4me dashboard; the plugin sends it as the raw value of the Authorization header, without a Bearer prefix, as the API expects. File payloads go in the docContent field as base64, a pdf4meblobid:// reference or an https URL, with docName always set — the API dispatches on the extension.
PDF-producing actions answer the raw file unless isAsync is set; the plugin decodes both the binary answer and the documented JSON shape (&#123;"File Content", "File Name"&#125;) into fileContent. Pass isAsync: true to get a job and poll it with jobs.status (the plugin declares that as a job, so the agent can wait on it). Processing calls consume credits.
This plugin covers a working subset: merge, split, compress, page organization, metadata, PDF-to-Word, HTML-to-PDF, OCR, and table and form extraction. The barcode, Excel, image, Word-suite, generate and signature families are documented by PDF4me but not part of this plugin.
Every operation is described in the official docs: https://docs.pdf4me.com/pdf4me-api/

**What you get:**

- 12 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/pdf4me better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/pdf4me better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/pdf4me better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/pdf4me better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { pdf4me } from '@corsair-dev/pdf4me';

export const corsair = createCorsair({
	plugins: [
		pdf4me(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the PDF4me API key before the first call: `pnpm corsair setup --plugin=pdf4me --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
pdf4me()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'pdf4me',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read PDF metadata**

```ts
const tenant = corsair.withTenant('acme');
await tenant.pdf4me.api.pdf.getInfo({ docContent: 'JVBERi0=', docName: 'document.pdf' });
```


**Compress a PDF**

```ts
const tenant = corsair.withTenant('acme');
await tenant.pdf4me.api.pdf.compress({ docContent: 'JVBERi0=', docName: 'document.pdf', optimizeProfile: 'Web' });
```
