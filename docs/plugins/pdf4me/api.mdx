## Convert

### htmlToPdf

`convert.htmlToPdf`

Render HTML content into a PDF

**Risk:** `write`

```ts
await corsair.pdf4me.api.convert.htmlToPdf({ htmlContent: "<h1>Hello</h1>", docName: "out.pdf" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `htmlContent` | `string` | Yes | HTML content to render into a PDF |
| `docName` | `string` | Yes | Source file name including its extension; the API dispatches on it |
| `jobIdExt` | `string` | No | Your own reference for this call, stored with the API call log |
| `isAsync` | `boolean` | No | Process asynchronously and return a job to poll at jobs.status (only honoured by actions that support it) |
| `callBackUrl` | `string` | No | URL notified when an asynchronous job completes |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string \| null` | No | File name of the produced document |
| `fileContent` | `string \| null` | No | The produced document, base64-encoded |

### ocrPdf

`convert.ocrPdf`

Run OCR on a scanned PDF to make its text editable

**Risk:** `write`

```ts
await corsair.pdf4me.api.convert.ocrPdf({ docContent: "<base64>", docName: "scan.pdf", ocrWhenNeeded: true, ocrLang: "eng" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `docContent` | `string` | Yes | Source file: base64 content, a pdf4meblobid://&lt;id&gt; reference, or an https URL |
| `docName` | `string` | Yes | Source file name including its extension; the API dispatches on it |
| `ocrWhenNeeded` | `boolean` | No | Run OCR only when the document needs it (documented mixed field type) |
| `ocrLang` | `string` | No | OCR language code, e.g. eng |
| `jobIdExt` | `string` | No | Your own reference for this call, stored with the API call log |
| `isAsync` | `boolean` | No | Process asynchronously and return a job to poll at jobs.status (only honoured by actions that support it) |
| `callBackUrl` | `string` | No | URL notified when an asynchronous job completes |

ocrWhenNeeded is the documented mixed-type boolean field; ocrLang takes an OCR language code such as eng.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string \| null` | No | File name of the produced document |
| `fileContent` | `string \| null` | No | The produced document, base64-encoded |

## Jobs

### status

`jobs.status`

Poll an asynchronous processing job started with isAsync

**Risk:** `read`

```ts
await corsair.pdf4me.api.jobs.status({ jobId: "job-1" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `jobId` | `string` | Yes | Job id the async answer returned |

Poll a job started with isAsync: true. isFinished with isSuccess true means done; hasFailed true means it failed.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `jobId` | `string \| null` | No | Job id |
| `isSuccess` | `boolean \| null` | No | Whether the job finished successfully |
| `isWorking` | `boolean \| null` | No | Whether the job is still running |
| `isFinished` | `boolean \| null` | No | Whether the job reached a terminal state |
| `hasFailed` | `boolean \| null` | No | Whether the job failed |
| `jobStatusText` | `string \| null` | No | Human-readable job status |
| `blobId` | `string \| null` | No | Blob id of the result document |

## Pdf

### compress

`pdf.compress`

Compress a PDF with a documented profile (Max, Web, Print, Default)

**Risk:** `write`

```ts
await corsair.pdf4me.api.pdf.compress({ docContent: "<base64>", docName: "document.pdf", optimizeProfile: "Web" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `docContent` | `string` | Yes | Source file: base64 content, a pdf4meblobid://&lt;id&gt; reference, or an https URL |
| `docName` | `string` | Yes | Source file name including its extension; the API dispatches on it |
| `optimizeProfile` | `Max \| Web \| Print \| Default` | No | Compression profile; Default is mapped to Max server-side; an unknown value fails with 400 |
| `jobIdExt` | `string` | No | Your own reference for this call, stored with the API call log |
| `isAsync` | `boolean` | No | Process asynchronously and return a job to poll at jobs.status (only honoured by actions that support it) |
| `callBackUrl` | `string` | No | URL notified when an asynchronous job completes |

optimizeProfile values: Max, Web, Print, Default. Default is mapped to Max server-side; an unknown value fails with 400 Invalid Optimization Profile.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string \| null` | No | File name of the produced document |
| `fileContent` | `string \| null` | No | The produced document, base64-encoded |

| `pageNumbers` | `number[]` | No | Page numbers to delete |

| `isAsync` | `boolean` | No | Process asynchronously and return a job to poll at jobs.status (only honoured by actions that support it) |

### merge

`pdf.merge`

Merge multiple PDFs into one; array order is the merge order

**Risk:** `write`

```ts
await corsair.pdf4me.api.pdf.merge({ docContent: ["<base64 of first.pdf>", "<base64 of second.pdf>"], docName: "merged.pdf" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `docContent` | `string[]` | Yes | The PDFs to merge, base64-encoded; array order is the merge order |
| `docName` | `string` | Yes | Source file name including its extension; the API dispatches on it |
| `jobIdExt` | `string` | No | Your own reference for this call, stored with the API call log |
| `isAsync` | `boolean` | No | Process asynchronously and return a job to poll at jobs.status (only honoured by actions that support it) |
| `callBackUrl` | `string` | No | URL notified when an asynchronous job completes |

docContent is an array and order matters — the array order is the merge order. The answer is the merged PDF.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string \| null` | No | File name of the produced document |
| `fileContent` | `string \| null` | No | The produced document, base64-encoded |

### split

Split a PDF by pages, text separator, barcode or Swiss QR code

**Risk:** `write`

```ts
await corsair.pdf4me.api.pdf.split({ docContent: "<base64>", docName: "document.pdf", splitMode: "pages", splitPageNr: 3 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `docContent` | `string` | Yes | Source file: base64 content, a pdf4meblobid://&lt;id&gt; reference, or an https URL |
| `docName` | `string` | Yes | Source file name including its extension; the API dispatches on it |
| `splitMode` | `pages \| text \| barcode \| swissQr` | No | Splitting strategy the API applies |
| `splitPageNr` | `number` | No | Split before this page number (pages mode) |
| `textSeparator` | `string` | No | Text the API splits on (text mode) |
| `jobIdExt` | `string` | No | Your own reference for this call, stored with the API call log |
| `isAsync` | `boolean` | No | Process asynchronously and return a job to poll at jobs.status (only honoured by actions that support it) |
| `callBackUrl` | `string` | No | URL notified when an asynchronous job completes |

splitMode picks pages, text, barcode or swissQr; the answer holds the split parts.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string \| null` | No | File name of the produced document |
| `fileContent` | `string \| null` | No | The produced document, base64-encoded |
