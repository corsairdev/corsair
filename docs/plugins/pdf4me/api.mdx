## Convert

### htmlToPdf

`convert.htmlToPdf`

Render HTML content into a PDF

**Risk:** `destructive`

```ts
await corsair.pdf4me.api.convert.htmlToPdf({ htmlContent: "<h1>Hello</h1>", docName: "out.pdf" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `htmlContent` | `string` | Yes | HTML to render into a PDF; the plugin base64-encodes it |
| `docName` | `string` | Yes | Name of the HTML source including .html, e.g. page.html |
| `layout` | `Portrait \| Landscape` | No | Page layout |
| `format` | `A0 \| A1 \| A2 \| A3 \| A4 \| A5 \| A6 \| A7 \| A8 \| Legal \| Tabloid \| Statement \| Executive` | No | Page format; A4 when unset |
| `scale` | `number` | No | Render scale; 0.8 when unset |
| `topMargin` | `string` | No | CSS length, e.g. 40px |
| `bottomMargin` | `string` | No | CSS length, e.g. 40px |
| `leftMargin` | `string` | No | CSS length, e.g. 40px |
| `rightMargin` | `string` | No | CSS length, e.g. 40px |
| `printBackground` | `boolean` | No | Print CSS backgrounds; true when unset |
| `displayHeaderFooter` | `boolean` | No | Show the header and footer; false when unset |
| `jobIdExt` | `string` | No | Your own reference for this call, stored with the API call log |
| `isAsync` | `boolean` | No | Process asynchronously and return a job to poll at jobs.status (only honoured by actions that support it) |
| `callBackUrl` | `string` | No | URL notified when an asynchronous job completes |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string \| null` | No | File name of the produced document |
| `fileContent` | `string \| null` | No | The produced document, base64-encoded |
| `documents` | `object[]` | No | The produced documents, when the action makes several |
| `jobId` | `string \| null` | No | Job id; poll it with jobs.status |
| `status` | `string \| null` | No | Job state the API reports, e.g. Accepted |
| `statusUrl` | `string \| null` | No | GetActionStatus URL for this job |
| `message` | `string \| null` | No | The API message about the job |

<Accordion title="documents full type">

```ts
{
  fileName?: string | null,
  fileContent?: string | null
}[]
```
</Accordion>

### ocrPdf

`convert.ocrPdf`

Run OCR on a scanned PDF to make its text editable; the API answers a job, so poll jobs.status for the file

**Risk:** `destructive`

```ts
await corsair.pdf4me.api.convert.ocrPdf({ docContent: "<base64>", docName: "scan.pdf", ocrWhenNeeded: true, ocrLang: "eng" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `docContent` | `string` | Yes | Source file: base64 content, a pdf4meblobid://&lt;id&gt; reference, or an https URL |
| `docName` | `string` | Yes | Source file name including its extension; the API dispatches on it |
| `qualityType` | `Draft \| High` | No | OCR quality |
| `ocrWhenNeeded` | `boolean` | No | Run OCR only when the document needs it |
| `language` | `string` | No | Document language, e.g. English |
| `jobIdExt` | `string` | No | Your own reference for this call, stored with the API call log |
| `isAsync` | `boolean` | No | Process asynchronously and return a job to poll at jobs.status (only honoured by actions that support it) |
| `callBackUrl` | `string` | No | URL notified when an asynchronous job completes |

ocrWhenNeeded is the documented mixed-type boolean field; ocrLang takes an OCR language code such as eng.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string \| null` | No | File name of the produced document |
| `fileContent` | `string \| null` | No | The produced document, base64-encoded |
| `documents` | `object[]` | No | The produced documents, when the action makes several |
| `jobId` | `string \| null` | No | Job id; poll it with jobs.status |
| `status` | `string \| null` | No | Job state the API reports, e.g. Accepted |
| `statusUrl` | `string \| null` | No | GetActionStatus URL for this job |
| `message` | `string \| null` | No | The API message about the job |

## Jobs

### status

`jobs.status`

Poll a job (isAsync, or PDF-to-Word and OCR, which always run as jobs); a finished job answers its file

**Risk:** `read`

```ts
await corsair.pdf4me.api.jobs.status({ jobId: "job-1" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `jobId` | `string` | Yes | Job id the async answer returned |

Poll a job started with isAsync: true. isFinished with isSuccess true means done; hasFailed true means it failed.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `jobId` | `string \| null` | No | Job id; poll it with jobs.status |
| `status` | `string \| null` | No | Job state the API reports, e.g. Accepted |
| `statusUrl` | `string \| null` | No | GetActionStatus URL for this job |
| `message` | `string \| null` | No | The API message about the job |
| `isFinished` | `boolean \| null` | No | True once GetActionStatus answered the finished file |
| `fileName` | `string \| null` | No | File name of the result, once finished |
| `fileContent` | `string \| null` | No | The result document, base64-encoded, once finished |

**Risk:** `destructive`

splitMode picks pages, text, barcode or swissQr; the answer holds the split parts.
