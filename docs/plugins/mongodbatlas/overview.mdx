Use **MongoDB Atlas** through Corsair: one client, typed API calls.

Connect with a service account (Organization &gt; Access Manager &gt;
Applications &gt; Service Accounts): store it as `clientId:clientSecret`
(`mdb_sa_id_...:mdb_sa_sk_...`) or as the JSON `{ "clientId",
"clientSecret" }`. The plugin trades it at `/api/oauth/token` for a bearer
token (cached until a minute before it expires). A programmatic API key
works too, as `publicKey:privateKey`; Atlas wants those with HTTP Digest
authentication, which the plugin does. Add the IP addresses the calls come
from to the credential's API access list if your organization requires
one, and give it the roles the calls need (Organization Owner or Project
Owner covers most).

- **Ids.** Atlas calls a project a group: `groupId` is the project id
(`projects.listProjects`), `orgId` the organization's
(`organizations.listOrgs`). Clusters, users and indexes go by name.
- **Versions.** Every Atlas route is versioned by media type; each
operation is pinned to the newest version the spec offers and sends it as
`Accept: application/vnd.atlas.<date>+json`.
- **Lists** page with `pageNum` (1-based) and `itemsPerPage` (the plugin
sends 100 when it is left out) and return `{ results, totalCount, links }`.
- **Downloads** (database logs, invoices as CSV) come back as files.
- **Risk.** Reads are `read`. Deletes, anything that starts billed
infrastructure (clusters, search nodes, stream workspaces and processors,
data federation, private endpoints, peering, online archive, snapshots),
restores, failover and outage tests, invitations, new keys and service
accounts, and organization-level changes are `destructive`; other writes
are `write`.
- Not wrapped: the 53 operations the spec marks deprecated (each has a
newer replacement in the plugin).

**What you get:**

- 489 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/mongodbatlas better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/mongodbatlas better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/mongodbatlas better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/mongodbatlas better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { mongodbatlas } from '@corsair-dev/mongodbatlas';

export const corsair = createCorsair({
	plugins: [
		mongodbatlas(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the MongoDB Atlas API key before the first call: `pnpm corsair setup --plugin=mongodbatlas --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
mongodbatlas()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'mongodbatlas',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List the clusters in a project**

```ts
const tenant = corsair.withTenant('acme');
await tenant.mongodbatlas.api.clusters.listClusters({ groupId: '5f43e7f0a1b2c3d4e5f60718' });
```


**Allow an IP range to reach a project**

```ts
const tenant = corsair.withTenant('acme');
await tenant.mongodbatlas.api.projectIpAccessList.createAccessListEntry({
	groupId: '5f43e7f0a1b2c3d4e5f60718',
	body: [{ cidrBlock: '203.0.113.0/24', comment: 'Office' }],
});
```


See the full list on the [API](/plugins/mongodbatlas/api) page.
