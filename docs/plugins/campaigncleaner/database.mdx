The CampaignCleaner plugin syncs data locally. Use `corsair.campaigncleaner.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Campaigns

Path: `campaigncleaner.db.campaigns.search`

```ts
const rows = await corsair.campaigncleaner.db.campaigns.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `campaign_name` | `string` | equals, contains, startsWith, endsWith, in |
| `date_added` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._

## Credits

Path: `campaigncleaner.db.credits.search`

```ts
const rows = await corsair.campaigncleaner.db.credits.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `credits` | `number` | equals, gt, gte, lt, lte, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
