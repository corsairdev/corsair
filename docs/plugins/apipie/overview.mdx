title: APIpie

APIpie provides a single API for routing requests to AI models. The Corsair plugin supports model discovery, chat completions, embeddings, and image generation.

## Setup

Install the plugin and register it with Corsair:

```bash
pnpm add @corsair-dev/apipie
```

```typescript
import { apipie } from '@corsair-dev/apipie';
import { createCorsair } from 'corsair/core';

const corsair = createCorsair({
  plugins: [apipie({ key: process.env.APIPIE_API_KEY })],
});
```

For local development, set the key in your shell:

```powershell
$env:APIPIE_API_KEY = "your-api-key"
```

The plugin does not read environment variables automatically. Pass `process.env.APIPIE_API_KEY` (or another secret source) as the `key` option. For production, prefer Corsair's encrypted credential store and omit the inline key.

## Quickstart

```typescript
const models = await corsair.apipie.api.models.list({ type: 'chat' });

const completion = await corsair.apipie.api.chat.createCompletion({
  model: 'openai/gpt-4o-mini',
  messages: [{ role: 'user', content: 'Summarize the latest deployment.' }],
});
```

See [API endpoints](/plugins/apipie/api) for every supported operation and [database](/plugins/apipie/database) for cached model and image records.

## Authentication and errors

APIpie uses the `api_key` auth type. Corsair sends the key as a Bearer token. Missing credentials raise an authentication error before a request is made. APIpie authentication, validation, account-credit, permission, not-found, conflict, and server errors are classified for callers. Rate limits honor the provider's `Retry-After` value; billable POST requests are not automatically replayed.

APIpie does not expose webhook operations or incoming webhook handlers through this plugin.
