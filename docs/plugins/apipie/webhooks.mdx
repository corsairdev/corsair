---
title: APIpie Webhooks
description: Webhook support for the APIpie Corsair plugin.
---

The APIpie Corsair plugin currently exposes no webhook endpoints or incoming webhook event handlers. There is no `webhookHooks` configuration or provider signature verification surface to register.

Use the HTTP API methods under `corsair.apipie.api` for model, chat, embedding, and image-generation requests. See [API endpoints](/plugins/apipie/api) for the supported operations.
