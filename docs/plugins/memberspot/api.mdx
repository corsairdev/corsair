## Auth

### check

`auth.check`

Returns the school the API key belongs to, which is the cheapest way to confirm a key works

**Risk:** `read`

```ts
await corsair.memberspot.api.auth.check({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `schoolId` | `string \| null` | No | The school the key belongs to. |
| `name` | `string \| null` | No | The school name. |
