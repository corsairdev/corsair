Use **Workable** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 35 typed API operations
- 5 synced entities (`candidates`, `departments`, `employees`, `jobs`, `members`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/workable
```
```bash yarn
yarn add corsair @corsair-dev/workable
```
```bash pnpm
pnpm install corsair @corsair-dev/workable
```
```bash bun
bun add corsair @corsair-dev/workable
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { workable } from '@corsair-dev/workable';

export const corsair = createCorsair({
	plugins: [
		workable(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
workable()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'workable',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`accounts.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.workable.api.accounts.get({});
```


**`departments.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.workable.api.departments.create({});
```


See the full list on the [API](/plugins/workable/api) page.

## Query synced data

Synced entities support `tenant.workable.db.<entity>.search()` and `.list()`: `candidates`, `departments`, `employees`, `jobs`, `members`.

See [Database](/plugins/workable/database) for filters and operators.
