Create a lead or job with its type, lead source, brand and event date

**Risk:** `write`

```ts
await corsair.tave.api.jobs.create({ name: 'Smith wedding', stage: 'lead', eventDate: '2026-06-15', guestCount: 120 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | The job name, which overrides the generated title. |

| `jobTypeId` | `string` | No | The job type. |

### list

`jobs.list`

List jobs with their stage, balances and event dates, filtered by stage, lead status or event date range

**Risk:** `read`

```ts
await corsair.tave.api.jobs.list({ page: 1, pageSize: 50, includeClosed: false });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | Page of results, starting at 1. Defaults to 1. |
| `pageSize` | `number` | No | Results per page, from 10 to 100. The API defaults it to 100, so omit it unless you need smaller pages. |
| `sortBy` | `string` | No | A property to sort by, optionally followed by " asc" or " desc", e.g. "modified desc". |
| `includeClosed` | `boolean` | No | Include jobs that have been closed. Defaults to false. |
| `expand` | `string` | No | Entity-qualified dot paths to expand inline, comma-separated, e.g. "Job.clientContacts". |
| `stage` | `(lead \| booked \| fulfillment \| completed)[]` | No | Only jobs in these stages. |
| `leadStatusId` | `string` | No | Only jobs with this lead status. |
| `eventDateFrom` | `string` | No | Only jobs whose event date is on or after this date; jobs without an event date are excluded. |
| `eventDateTo` | `string` | No | Only jobs whose event date is on or before this date; jobs without an event date are excluded. |
| `staleBefore` | `string` | No | Only jobs whose stale date is on or before this date. |

Returns leads and jobs together; stage accepts lead, booked, fulfillment and completed, and closed jobs need includeClosed.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `string` | Yes | — |
| `items` | `object[]` | Yes | — |
| `meta` | `object \| null` | No | — |
