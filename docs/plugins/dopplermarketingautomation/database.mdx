---
title: "Doppler Marketing Automation database"
sidebarTitle: "Database"
description: "The Doppler Marketing Automation plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Doppler Marketing Automation. To read its data, call the [API operations](/plugins/dopplermarketingautomation/api), which return what Doppler Marketing Automation has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
