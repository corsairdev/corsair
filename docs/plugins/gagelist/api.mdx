## Calibrations

### certificate

`calibrations.certificate`

Render a calibration certificate PDF for a record, returned base64-encoded with its content type

**Risk:** `read`

```ts
await corsair.gagelist.api.calibrations.certificate({ id: 500 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | The GageList record ID. |

Returns the PDF base64-encoded in `certificate`, with `encoding`, `contentType` and `byteLength`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `certificate` | `string` | Yes | The certificate: base64 bytes when `encoding` is `base64`, otherwise the text GageList sent. |
| `encoding` | `base64 \| text` | Yes | — |
| `contentType` | `string` | Yes | The Content-Type GageList sent, usually `application/pdf`. |
| `byteLength` | `number` | No | Size of the decoded file. |
