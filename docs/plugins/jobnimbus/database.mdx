---
title: "JobNimbus database"
sidebarTitle: "Database"
description: "The JobNimbus plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for JobNimbus. To read its data, call the [API operations](/plugins/jobnimbus/api), which return what JobNimbus has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
