## Crawl

### create

`crawl.create`

Start an asynchronous multi-page crawl job (consumes compute credits)

**Risk:** `destructive`

```ts
await corsair.hyperbrowser.api.crawl.create({ url: 'https://example.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | — |
| `maxPages` | `number` | No | — |
| `followLinks` | `boolean` | No | — |
| `ignoreSitemap` | `boolean` | No | — |
| `excludePatterns` | `string[]` | No | — |
| `includePatterns` | `string[]` | No | — |
| `sessionOptions` | `object` | No | — |
| `scrapeOptions` | `object` | No | — |

<AccordionGroup>
<Accordion title="sessionOptions full type">

```ts
{
  useUltraStealth?: boolean,
  useStealth?: boolean,
  useProxy?: boolean,
  proxyServer?: string,
  proxyServerPassword?: string,
  proxyServerUsername?: string,
  proxyCountry?: string,
  proxyState?: string,
  proxyCity?: string | null,
  region?: string,
  operatingSystems?: string[],
  device?: string[],
  platform?: string[],
  locales?: string[],
  screen?: {
    width?: number,
    height?: number,
    deviceScaleFactor?: number
  },
  solveCaptchas?: boolean,
  solverType?: visual,
  adblock?: boolean,
  trackers?: boolean,
  annoyances?: boolean,
  enableWebRecording?: boolean,
  enableVideoWebRecording?: boolean,
  profile?: {
    id?: string,
    persistChanges?: boolean
  },
  acceptCookies?: boolean,
  staticIpId?: string,
  saveDownloads?: boolean,
  extensionIds?: string[],
  urlBlocklist?: string[],
  browserArgs?: string[],
  timeoutMinutes?: number,
  enableWindowManager?: boolean,
  enableWindowManagerTaskbar?: boolean,
  viewOnlyLiveView?: boolean,
  disablePasswordManager?: boolean,
  enableAlwaysOpenPdfExternally?: boolean,
  disablePostQuantumKeyAgreement?: boolean,
  enableWebMcp?: boolean

```
</Accordion>

<Accordion title="scrapeOptions full type">

```ts
{
  formats?: (html | links | markdown | screenshot)[],
  includeTags?: string[],
  excludeTags?: string[],
```

|------|------|----------|-------------|
| `jobId` | `string` | Yes | — |
