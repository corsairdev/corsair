## Brands

### get

`brands.get`

Get a brand by ID with its operating locations (paged by cursor) and legal entities, each location with its address, operating status and 12-month card revenue

**Risk:** `read`

```ts
await corsair.enigma.api.brands.get({ id: '5f1147ed-4d0e-4f36-a1d2-c2b3f2b1a9c4', locationsFirst: 10, locationsAfter: 'cursor-from-previous-page' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The brand ID from a brands.match call. |
| `locationsFirst` | `number` | No | Page size for the operating locations list. Defaults to 10. |
| `locationsAfter` | `string` | No | Cursor from a previous operating locations page. |
| `legalEntitiesFirst` | `number` | No | Page size for the legal entities list. Defaults to 5. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `brand` | `object \| null` | No | `null` when nothing matched. |

### match

`brands.match`

Match a business by name, website, phone number or a natural-language prompt, with an optional address and confidence threshold; returns the best-matching brand with its industries, location count and 12-month card revenue

**Risk:** `read`

```ts
await corsair.enigma.api.brands.match({ name: 'Starbucks', address: { state: 'WA' }, matchThreshold: 0.5 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | Business name to match. |
| `website` | `string` | No | Website to match, any format. |
| `phoneNumber` | `string` | No | Phone number to match, 10-digit US number. |
| `prompt` | `string` | No | Natural-language business description; cannot be combined with name, website, phoneNumber or address. |
| `address` | `object` | No | Address to narrow the match. |
| `matchThreshold` | `number` | No | Confidence threshold between 0.0 and 1.0. |

At least one of `name`, `website`, `phoneNumber` or `prompt` is required, and `prompt` cannot be combined with any of them or with `address`.

## Legal Entities

### get

`legalEntities.get`

Get a legal entity by ID or name, with its registered entities, formation dates, addresses and brands; each list returns up to three entries with a pageInfo flag when more exist

**Risk:** `read`

```ts
await corsair.enigma.api.legalEntities.get({ name: 'Starbucks Corporation' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | No | The legal entity ID. |
| `name` | `string` | No | Legal entity name to match instead of an ID. |

At least one of `id` or `name` is required. The `registeredEntities`, `addresses` and `brands` lists return their first page of up to three entries; each carries a `pageInfo` with `hasNextPage` when more exist.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `legalEntity` | `object \| null` | No | `null` when nothing matched. |

## Locations

### match

`locations.match`

Match a business location by name, address, website or phone number; returns the address, phone numbers, operating status and parent brands

**Risk:** `read`

```ts
await corsair.enigma.api.locations.match({ name: 'Bluestone Lane', address: { city: 'New York', state: 'NY' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | Business name to match. |
| `website` | `string` | No | Website to match. |
| `phoneNumber` | `string` | No | Phone number to match, 10-digit US number. |
| `address` | `object` | No | Address to match. |
| `matchThreshold` | `number` | No | Confidence threshold between 0.0 and 1.0. |

At least one of `name`, `website`, `phoneNumber` or `address` is required.
