The ActiveCampaign plugin syncs data locally. Use `corsair.activecampaign.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Account Contacts

Path: `activecampaign.db.accountContacts.search`

```ts
const rows = await corsair.activecampaign.db.accountContacts.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `contact` | `string` | equals, contains, startsWith, endsWith, in |
| `account` | `string` | equals, contains, startsWith, endsWith, in |
| `jobTitle` | `string` | equals, contains, startsWith, endsWith, in |
| `createdTimestamp` | `string` | equals, contains, startsWith, endsWith, in |
| `updatedTimestamp` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
