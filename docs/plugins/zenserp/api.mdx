## Account

### getStatus

`account.getStatus`

Return the remaining request quota for the API key

**Risk:** `read`

```ts
await corsair.zenserp.api.account.getStatus({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `remaining_requests` | `number` | Yes | — |
