Use **CallPage** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 30 typed API operations
- 6 synced entities (`calls`, `managers`, `smsMessages`, `users`, `voiceMessages`, `widgets`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/callpage
```
```bash yarn
yarn add corsair @corsair-dev/callpage
```
```bash pnpm
pnpm install corsair @corsair-dev/callpage
```
```bash bun
bun add corsair @corsair-dev/callpage
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { callpage } from '@corsair-dev/callpage';

export const corsair = createCorsair({
	plugins: [
		callpage(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
callpage()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'callpage',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`widgets.list`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.callpage.api.widgets.list({ limit: 20 });
```


**`widgets.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.callpage.api.widgets.create({ url: 'https://example.com', description: 'Landing page' });
```


See the full list on the [API](/plugins/callpage/api) page.

## Query synced data

Query synced `widgets` rows without hitting the live API.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.callpage.db.widgets.search({
	data: { enabled: true },
	limit: 20,
});
```

Synced entities: `calls`, `managers`, `smsMessages`, `users`, `voiceMessages`, `widgets`. See [Database](/plugins/callpage/database) for filters and operators.
