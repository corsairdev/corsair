## Collection

### add

`collection.add`

Add existing entities to a Fibery collection field

**Risk:** `write`

```ts
await corsair.fibery.api.collection.add({ type: 'CRM/Lead', field: 'CRM/Contacts', entityId: '019dcf9a-c5ab-7292-9bdb-8956eea1b532', itemIds: ['019dcf9a-c294-71cc-b740-ccdbd5722322'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `string` | Yes | — |
| `field` | `string` | Yes | — |
| `entityId` | `string` | Yes | — |
| `itemIds` | `string[]` | Yes | — |



**Output:** `JsonValue`

## History

### search

`history.search`

Search paginated Fibery entity change history with filters and time bounds

**Risk:** `read`

```ts
await corsair.fibery.api.history.search({ limit: 50, where: [], timeframe: { start: '2025-01-01T00:00:00.000Z', end: '2025-01-02T00:00:00.000Z' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `where` | `object[]` | No | — |
| `timeframe` | `object` | No | — |
| `limit` | `number` | Yes | — |
| `excludeAutomaticChanges` | `(automations \| integrations \| formulas \| auto-linking)[]` | No | — |
| `sinceItem` | `string` | No | — |

Pages may be shorter than limit; continue only while nextPage.hasNext, passing nextPage.sinceItem. The timeframe maximum span is one year. Field and operator values are documented string literals; the reference generator omits quotes around enum values in rendered type tables.

<AccordionGroup>
<Accordion title="where full type">

```ts
{
  field: id | action | entityPublicId | entityState | author | typeId | entityTypeId | entityName | entityId | field,
  operator: = | in | contains | not-in | empty | not-empty,
  value?: JsonValue
}[]
```
</Accordion>

<Accordion title="timeframe full type">

```ts
{
  start: string,
  end: string
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `items` | `Record<string, JsonValue>[]` | Yes | — |
| `nextPage` | `Record<string, JsonValue>` | Yes | — |
