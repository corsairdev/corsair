Use **Fibery** through Corsair: one client, typed API calls.

Set workspaceUrl to the HTTPS origin of the Fibery workspace (such as https://acme.fibery.io). Static API tokens use Authorization: Token; OAuth access tokens use Authorization: Bearer. Fibery documents limits of 3 requests per second per token and 7 per second per workspace. Register an OAuth app in the target workspace; its scopes are openid and offline, and its token endpoint uses HTTP Basic client authentication. Entity-query pagination uses the documented fibery/id cursor pattern; history uses nextPage.sinceItem. Webhook administration, API-token lifecycle endpoints, and URL-based file import are intentionally not exposed.

**What you get:**

- 31 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/fibery better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/fibery better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/fibery better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/fibery better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { fibery } from '@corsair-dev/fibery';

export const corsair = createCorsair({
	plugins: [
		fibery(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
fibery()
```

More: [API Key](/concepts/api-key)

</Tab>
<Tab title="OAuth 2.0">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Fibery OAuth app.

```ts
fibery({
	authType: 'oauth_2',
})
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'fibery',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`document.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.fibery.api.document.get({});
```


**`collection.add`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.fibery.api.collection.add({});
```
