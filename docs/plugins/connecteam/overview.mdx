Use **Connecteam** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 16 typed API operations
- 13 synced entities (`account`, `conversations`, `customFieldCategories`, `customFields`, `forms`, `jobs`, and 7 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/connecteam
```
```bash yarn
yarn add corsair @corsair-dev/connecteam
```
```bash pnpm
pnpm install corsair @corsair-dev/connecteam
```
```bash bun
bun add corsair @corsair-dev/connecteam
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { connecteam } from '@corsair-dev/connecteam';

export const corsair = createCorsair({
	plugins: [
		connecteam(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
connecteam()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'connecteam',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`chat.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.connecteam.api.chat.get({});
```


**`attachments.generateUploadUrl`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.connecteam.api.attachments.generateUploadUrl({});
```


See the full list on the [API](/plugins/connecteam/api) page.

## Query synced data

Synced entities support `tenant.connecteam.db.<entity>.search()` and `.list()`: `account`, `conversations`, `customFieldCategories`, `customFields`, `forms`, `jobs`, `performanceIndicators`, `policyTypes`, `publishers`, `schedulers`, `smartGroups`, `taskBoards`, `users`.

See [Database](/plugins/connecteam/database) for filters and operators.
