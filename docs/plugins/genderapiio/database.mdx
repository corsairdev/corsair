---
title: "GenderAPI.io database"
sidebarTitle: "Database"
description: "The GenderAPI.io plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for GenderAPI.io. To read its data, call the [API operations](/plugins/genderapiio/api), which return what GenderAPI.io has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
