## Account

### getCredits

`account.getCredits`

Retrieve current credit balance for the Bouncer account

**Risk:** `read`

```ts
await corsair.bouncer.api.account.getCredits({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `credits` | `number` | Yes | — |
