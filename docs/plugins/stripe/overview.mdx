Use **Stripe** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 20 typed API operations
- 7 synced entities (`balance`, `charges`, `coupons`, `customers`, `paymentIntents`, `prices`, and 1 more) for fast `.search()` / `.list()`
- 11 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/stripe
```
```bash yarn
yarn add corsair @corsair-dev/stripe
```
```bash pnpm
pnpm install corsair @corsair-dev/stripe
```
```bash bun
bun add corsair @corsair-dev/stripe
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { stripe } from '@corsair-dev/stripe';

export const corsair = createCorsair({
	plugins: [
		stripe(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Tabs>

</Tab>

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'stripe',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List customers**

```ts
const tenant = corsair.withTenant('acme');
await tenant.stripe.api.customers.list({});
```


**Create a payment intent**

```ts
const tenant = corsair.withTenant('acme');
await tenant.stripe.api.paymentIntents.create({ amount: 2000, currency: 'usd' });
```


See the full list on the [API](/plugins/stripe/api) page.

## Query synced data

Search synced customers without hitting Stripe.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.stripe.db.customers.search({
	data: {},
	limit: 50,
});
```

Synced entities: `balance`, `charges`, `coupons`, `customers`, `paymentIntents`, `prices`, `sources`. See [Database](/plugins/stripe/database) for filters and operators.

## Webhooks

Fires when a payment intent transitions to `succeeded`. Use this to fulfil orders.

```ts
stripe({
    webhookHooks: {
        paymentIntent: {
            succeeded: {
                after: async (ctx, result) => {
                    const intent = result.data.data.object;
                    console.log('Payment succeeded:', intent.id, intent.amount, intent.currency);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/stripe/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
