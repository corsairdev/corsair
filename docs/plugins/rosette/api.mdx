## Categories

### categories

`categories`

Classify a text into topic-taxonomy categories with confidence

**Risk:** `read`

```ts
await corsair.rosette.api.categories({ content: 'A new machine learning framework was released today.' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `content` | `string` | No | The text to analyse. Mutually exclusive with contentUri. |
| `contentUri` | `string` | No | A URL for Rosette to fetch, over http, https, ftp or ftps. Mutually exclusive with content. |
| `language` | `string` | No | An ISO 639 language code, two or three letters, such as eng or spa. |
| `profileId` | `string` | No | A saved language profile to apply. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `categories` | `object[] \| null` | No | — |

<AccordionGroup>
<Accordion title="categories full type">

```ts
{
  label?: string | null,
  score?: number | null,
  confidence?: number | null
}[] | null
```
</Accordion>
</AccordionGroup>

## Name Translation

`nameTranslation`

```ts
await corsair.rosette.api.nameTranslation({ name: 'John Smith', targetLanguage: 'rus', entityType: 'PERSON' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | The name to translate. |
| `targetLanguage` | `string` | Yes | The ISO 639 language to translate into. |
| `entityType` | `PERSON \| LOCATION \| ORGANIZATION` | No | Defaults to PERSON. |
| `sourceLanguageOfOrigin` | `string` | No | — |
| `sourceLanguageOfUse` | `string` | No | — |
| `sourceScript` | `string` | No | ISO 15924 code. |
| `targetScript` | `string` | No | ISO 15924 code. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `translation` | `string \| null` | No | — |
| `confidence` | `number \| null` | No | — |
| `targetLanguage` | `string \| null` | No | — |
| `targetScript` | `string \| null` | No | — |
| `targetScheme` | `string \| null` | No | — |
| `sourceScript` | `string \| null` | No | — |
| `sourceLanguageOfOrigin` | `string \| null` | No | — |
| `sourceLanguageOfUse` | `string \| null` | No | — |
| `extendedInformation` | `Record<string, JsonValue> \| null` | No | Extra server details, such as processedByBabel. |
