---
title: "Kit database"
sidebarTitle: "Database"
description: "The Kit plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Kit. To read its data, call the [API operations](/plugins/kit/api), which return what Kit has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
