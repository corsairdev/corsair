## Account

The account and its user: plan, primary address, timezone and the sending addresses with their verification and DMARC status

**Risk:** `read`

```ts
await corsair.kit.api.account.get({});
```

**Output**

|------|------|----------|-------------|
| `user` | `object \| null` | No | — |

### subscribe

`forms.subscribe`

Add an existing subscriber to a form, which applies the form’s incentive and records when they were added. Create the subscriber first

**Risk:** `destructive`

```ts
await corsair.kit.api.forms.subscribe({ form_id: 12, email_address: 'jordan@acme.example', referrer: 'https://acme.example/blog' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `form_id` | `number` | Yes | The form ID. |
| `email_address` | `string` | Yes | An email address. Kit normalizes its case, and returns an existing subscriber rather than creating a duplicate. |
| `referrer` | `string` | No | Where the signup came from. |

The subscriber must already exist; call `subscribers.create` first, then this to record the signup against the form, apply its incentive and set `added_at`.

## Subscribers

### create

`subscribers.create`

Create a subscriber, or return the existing one for an address already on the list. Unknown custom field keys are ignored and named in `warnings`

**Risk:** `write`

```ts
await corsair.kit.api.subscribers.create({ email_address: 'jordan@acme.example', first_name: 'Jordan', fields: { last_name: 'Lee' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email_address` | `string` | Yes | An email address. Kit normalizes its case, and returns an existing subscriber rather than creating a duplicate. |
| `first_name` | `string` | No | — |
| `state` | `active \| cancelled \| bounced \| complained \| inactive` | No | Defaults to `active`. |
| `fields` | `Record<string, string>` | No | Custom field values keyed by the field’s `key`, such as `last_name`. An unknown key is ignored and named in `warnings`. |

An address already on the list returns the existing subscriber. An unknown custom field key is ignored and named in `warnings`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `subscriber` | `object` | Yes | — |
| `warnings` | `string[] \| null` | No | Custom field keys Kit ignored because it did not recognise them. |

### list

`subscribers.list`

Subscribers by state, address or date, cursor-paged, with optional attribution, tags and location

**Risk:** `read`

```ts
await corsair.kit.api.subscribers.list({ per_page: 25, status: 'active', include: ['tags'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `after` | `string` | No | The `end_cursor` of the page before, for the next page. |
| `before` | `string` | No | The `start_cursor` of the page after, for the previous page. |
| `per_page` | `number` | No | Items per page, up to 1000. Kit’s default is 500. |
| `status` | `active \| cancelled \| bounced \| complained \| inactive \| all` | No | Defaults to `active`. `all` widens it to every state. |
| `email_address` | `string` | No | Only the subscriber with this exact address. |
| `include` | `(attribution \| tags \| location \| canceled_at)[]` | No | Embed these extra fields on each subscriber. `canceled_at` needs `status: "cancelled"`. |
| `include_total_count` | `boolean` | No | Also return the total number of matching subscribers. |
| `slim` | `boolean` | No | Omit the `fields` object for a smaller, faster response. |
| `sort_field` | `id \| created_at \| updated_at \| cancelled_at \| canceled_at \| engagement__sent \| engagement__opens \| engagement__clicks \| engagement__open_rate \| engagement__click_rate` | No | Field to order by. `cancelled_at` needs `status: "cancelled"`. An `engagement__<metric>` sort orders by the trailing 90 days and cannot be combined with `email_address`. |
| `sort_order` | `asc \| desc` | No | — |
| `created_after` | `string` | No | A date, `yyyy-mm-dd`. |
| `created_before` | `string` | No | A date, `yyyy-mm-dd`. |
| `updated_after` | `string` | No | A date, `yyyy-mm-dd`. |
| `updated_before` | `string` | No | A date, `yyyy-mm-dd`. |

Pages by cursor: pass `pagination.end_cursor` back as `after`. Only active subscribers are returned unless `status` says otherwise.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `subscribers` | `object[]` | Yes | — |
| `pagination` | `object \| null` | No | — |

### unsubscribe

`subscribers.unsubscribe`

Unsubscribe a subscriber, which stops every future send to them; re-subscribing takes their own action, not a call

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.kit.api.subscribers.unsubscribe({ subscriberId: 1001 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `subscriberId` | `number` | Yes | The subscriber ID, from `subscribers.list`. |

Stops every future send to that person. Only they can resubscribe.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | — |
| `subscriber_id` | `number` | Yes | — |
