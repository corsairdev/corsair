## Channels

### get

`channels.get`

Read one channel with its type, name and the inbox it belongs to

**Risk:** `read`

```ts
await corsair.superchat.api.channels.get({ channelId: 'mc_1aBMS9FKwvSDjljRJI1aZ' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `channelId` | `string` | Yes | The channel id, as `mc_...`. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `type` | `string \| null` | No | — |
| `name` | `string \| null` | No | — |
| `inbox_id` | `string \| null` | No | — |

## Contact Lists

### addContact

`contactLists.addContact`

Add a contact to a contact list. The list is named in the body on this route, not in the path

**Risk:** `write`

```ts
await corsair.superchat.api.contactLists.addContact({ contactId: 'ct_1aBMS9FKwvSDjljRJI1aZ', contactListId: 'cl_1aBMS9FKwvSDjljRJI1aZ' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contactId` | `string` | Yes | — |
| `contactListId` | `string` | Yes | — |

The list id goes in the body as `{ id }`, not in the path, on this route. Removing a contact takes it in the path instead.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `name` | `string` | Yes | — |
| `description` | `string \| null` | No | — |
| `url` | `string \| null` | No | — |

### update

`conversations.update`

Change a conversation's status, inbox, labels or assignees. Snoozing needs both a status of snoozed and a snoozed_until time

**Risk:** `write`

```ts
await corsair.superchat.api.conversations.update({ id: 'cv_1aBMS9FKwvSDjljRJI1aZ', status: 'snoozed', snoozed_until: '2026-03-20T09:00:00Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `status` | `string \| null` | No | — |
| `inbox_id` | `string \| null` | No | — |
| `snoozed_until` | `string \| null` | No | ISO 8601. |
| `assigned_users` | `string[] \| null` | No | — |
