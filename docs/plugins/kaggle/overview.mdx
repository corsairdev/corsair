Use **Kaggle** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 25 typed API operations
- 4 synced entities (`competitions`, `datasets`, `kernels`, `models`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/kaggle
```
```bash yarn
yarn add corsair @corsair-dev/kaggle
```
```bash pnpm
pnpm install corsair @corsair-dev/kaggle
```
```bash bun
bun add corsair @corsair-dev/kaggle
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { kaggle } from '@corsair-dev/kaggle';

export const corsair = createCorsair({
	plugins: [
		kaggle(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
kaggle()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'kaggle',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`competitions.downloadFile`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.kaggle.api.competitions.downloadFile({});
```


**`competitions.generateSubmissionUrl`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.kaggle.api.competitions.generateSubmissionUrl({});
```


See the full list on the [API](/plugins/kaggle/api) page.

## Query synced data

Synced entities support `tenant.kaggle.db.<entity>.search()` and `.list()`: `competitions`, `datasets`, `kernels`, `models`.

See [Database](/plugins/kaggle/database) for filters and operators.
