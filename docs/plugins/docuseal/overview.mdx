Use **DocuSeal** through Corsair: one client, typed API calls.

Create an API key at console.docuseal.com under API. Every DocuSeal account also gets a free sandbox with separate keys, so you can test without touching production documents. Things to know before you send:

- **Real signatures.** `submissions.create` sends the signature-request emails immediately unless you pass `send_email: false`; the same applies to the create-from-PDF, HTML and DOCX variants. `submitters.update` with `completed: true` counter-signs the document as that submitter, which cannot be undone.
- **Archive, not delete.** The hosted API has no hard delete. `templates.archive` and `submissions.archive` archive; restore either with `templates.update` or `submissions.update` and `archived: false`.
- **Signed document URLs.** `submissions.getDocuments` returns URLs of the signed documents. They act as bearer credentials, so treat the result as sensitive.
- **Paging.** The three list endpoints page by id cursor: pass `pagination.next` from one page as `after` on the next. Page size is capped at 100 (DocuSeal defaults to 10).
- **Pro plan features.** Creating templates or submissions from uploaded PDF or DOCX files, merging templates and replacing template documents may require a paid (Pro) plan; the docs no longer mark which.
- **Webhooks.** DocuSeal sends webhook deliveries for 11 event types (form, submission and template events), but they are configured per account in the DocuSeal console, not through the API, and there is no documented payload signature. Corsair does not receive them; handle deliveries with your own endpoint.
- **Hosts.** This plugin targets `api.docuseal.com`. DocuSeal also runs `api.docuseal.eu` and self-hosted installations with their own hosts, which this plugin does not switch between.

**What you get:**

- 23 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/docuseal better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/docuseal better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/docuseal better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/docuseal better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { docuseal } from '@corsair-dev/docuseal';

export const corsair = createCorsair({
	plugins: [
		docuseal(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the DocuSeal API key before the first call: `pnpm corsair setup --plugin=docuseal --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
docuseal()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'docuseal',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List templates**

```ts
const tenant = corsair.withTenant('acme');
await tenant.docuseal.api.templates.list({});
```


**Send a template for signature**

```ts
const tenant = corsair.withTenant('acme');
await tenant.docuseal.api.submissions.create({
	template_id: 123456,
	submitters: [{ role: 'First party', email: 'jordan@acme-logistics.com' }],
});
```


See the full list on the [API](/plugins/docuseal/api) page.
