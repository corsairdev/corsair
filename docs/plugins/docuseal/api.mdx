## Events

### listFormCompleted

`events.listFormCompleted`

List form.completed events (one per signer who finished), oldest first by completion time in Unix seconds; a polling alternative to webhooks

**Risk:** `read`

```ts
await corsair.docuseal.api.events.listFormCompleted({ limit: 50, after: 1764320000 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | Results per page, 1-100. DocuSeal defaults to 10. |
| `after` | `number` | No | Unix seconds: only events completed after this time. Pass `pagination.next` from the previous page. |
| `before` | `number` | No | Unix seconds: only events completed before this time. |

Pages by completion time in Unix seconds: pass `pagination.next` as `after`. Not in the published OpenAPI file.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `pagination` | `object` | Yes | — |

## Submissions

### archive

`submissions.archive`

Archive a submission; DocuSeal has no hard delete, so it can be restored with submissions.update and archived: false

**Risk:** `write`

```ts
await corsair.docuseal.api.submissions.archive({ id: 654321 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | The submission to archive. DocuSeal has no hard delete; restore it with `submissions.update` and `archived: false`. |

DocuSeal archives instead of deleting. Restore an archived submission with `submissions.update` and `archived: false`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | — |
| `archived_at` | `string \| null` | No | — |

### create

`submissions.create`

Create a submission from a template, one submitter per signing role; sends the signature-request emails unless send_email is false

**Risk:** `destructive`

```ts
await corsair.docuseal.api.submissions.create({ template_id: 123456, submitters: [{ role: 'First party', email: 'jordan@acme-logistics.com' }], send_email: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `template_id` | `number` | Yes | The template to fill. |
| `submitters` | `object[]` | Yes | One entry per signing role on the template. |
| `send_email` | `boolean` | No | DocuSeal defaults to true: signature-request emails go out on create. |
| `send_sms` | `boolean` | No | DocuSeal defaults to false. |
| `order` | `random \| preserved` | No | DocuSeal defaults to preserved. |
| `completed_redirect_url` | `string` | No | — |
| `bcc_completed` | `string` | No | Email address that receives the completed document. |
| `reply_to` | `string` | No | — |
| `expire_at` | `string` | No | Free-form datetime as DocuSeal accepts it, e.g. `2024-09-01 12:00:00 UTC`. |
| `variables` | `Record<string, any>` | No | — |
| `message` | `object` | No | — |

Sends the signature-request emails immediately unless you pass `send_email: false`. Answers a bare array, one submitter per entry.
