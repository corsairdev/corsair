## Account

### get

`account.get`

Read one account: name, credit balance, forest name and slug

**Risk:** `read`

```ts
await corsair.moretrees.api.account.get({ accountCode: 'AC1C2C' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `accountCode` | `string` | Yes | The More Trees account code, from Settings &gt; Account Settings. |



**Output:** `Record<string, any>`

## Forest

### get

`forest.get`

Read one virtual forest: branding plus planted, gifted and received tree totals and CO2 captured

**Risk:** `read`

```ts
await corsair.moretrees.api.forest.get({ forestSlugOrAccountCode: 'beachy' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `forestSlugOrAccountCode` | `string` | Yes | The forest slug or the account code, from Settings &gt; Account Settings. |



**Output:** `Record<string, any>`

## Projects

### list

`projects.list`

List every active planting project with country, supplier and the trees you can plant in it

**Risk:** `read`

```ts
await corsair.moretrees.api.projects.list({});
```

**Input:** _empty object_

`GET /projects` on the project-management service. The guide's projects
section mentions a "public validation key" without naming a header; the
plugin authenticates with the standard `X-API-KEY`.


**Output:** `Record<string, any>[]`

## Trees

### plant

`trees.plant`

Plant trees from the payment account for yourself or as gifts; spends credits unless test mode is on

**Risk:** `destructive`

```ts
await corsair.moretrees.api.trees.plant({ payment_account_code: 'AC1C2C', test: true, plant_for_others: false, quantity: 2 });
```

**Input:** `object`

`POST /plant` on the transaction-management service. With
`plant_for_others: true`, send `recipients` (each needs an
`account_code` or an `email`, plus `name` and `quantity`) and omit
`quantity`; with `plant_for_others: false`, send `quantity` and omit
`recipients`. `project_id` and `tree_id` default to More Trees' default
project and tree when omitted.

<AccordionGroup>
<Accordion title="Input full type">

```ts
{
  payment_account_code: string,
  test?: boolean,
  plant_for_others: false,
  quantity: number,
  project_id?: number,
  tree_id?: number
} | {
  payment_account_code: string,
  test?: boolean,
  plant_for_others: true,
  project_id?: number,
  tree_id?: number,
  recipients: {
    account_code?: string,
    email?: string,
    name: string,
    quantity: number
  }[]
}
```
</Accordion>
</AccordionGroup>


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `test` | `boolean \| null` | No | — |
| `plant_for_others` | `boolean \| null` | No | — |
| `credits_used` | `number \| null` | No | — |
| `credits_remaining` | `number \| null` | No | — |
| `project_id` | `number \| null` | No | — |
| `tree_id` | `number \| null` | No | — |
| `recipients` | `object[] \| null` | No | — |

<AccordionGroup>
<Accordion title="recipients full type">

```ts
{
  account_code?: string | null,
  account_name?: string | null,
  quantity?: number | null
}[] | null
```
</Accordion>
</AccordionGroup>
