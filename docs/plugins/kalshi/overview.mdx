Use **Kalshi** through Corsair: one client, typed API calls.

Kalshi needs **two credentials**: an API key ID and the matching PEM private key (RSA or Ed25519). Generate them together in your Kalshi account settings; the private key is shown only once. Demo and production use separate accounts and separate keys.

**What you get:**

- 20 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/kalshi better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/kalshi better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/kalshi better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/kalshi better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { kalshi } from '@corsair-dev/kalshi';

export const corsair = createCorsair({
	plugins: [
		kalshi({
			environment: 'demo',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

`kalshi()` defaults to the **production** environment, where order writes spend real money. Start with `environment: 'demo'` and demo credentials, then switch to production deliberately.

```ts
kalshi({
	environment: 'demo',
})
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'kalshi',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Get a market**

```ts
const tenant = corsair.withTenant('acme');
await tenant.kalshi.api.markets.get({ ticker: 'KXHIGHNY-26NOV12-T60' });
```


**Cancel a resting order (demo environment)**

```ts
const tenant = corsair.withTenant('acme');
await tenant.kalshi.api.orders.cancel({ order_id: '<order-id>', market_ticker: 'KXHIGHNY-26NOV12-T60' });
```


See the full list on the [API](/plugins/kalshi/api) page.
