## Task Lists

### delete

`taskLists.delete`

Delete a task list; assigned tasks and their source tasks may also be deleted. OAuth scope: https://www.googleapis.com/auth/tasks.

**Risk:** `destructive`

```ts
await corsair.googletasks.api.taskLists.delete({ taskListId: 'list-id' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `taskListId` | `string` | Yes | — |

The default task list cannot be deleted. Deleting a list containing assigned tasks may also delete the original tasks in Docs or Chat Spaces.



**Output:** `undefined`

## Tasks

### clear

`tasks.clear`

Hide all completed tasks in a task list. OAuth scope: https://www.googleapis.com/auth/tasks.

**Risk:** `destructive`

```ts
await corsair.googletasks.api.tasks.clear({ taskListId: '@default' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `taskListId` | `string` | Yes | — |

Clearing hides all completed tasks; it does not permanently delete them. Clear and delete methods return HTTP 204 with no response body.



**Output:** `undefined`
