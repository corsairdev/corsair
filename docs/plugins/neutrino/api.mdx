## Commerce

### binLookup

`commerce.binLookup`

Read card facts from a BIN: brand, category, type, issuing country, and whether the calling IP matches that country

**Risk:** `read`

```ts
await corsair.neutrino.api.commerce.binLookup({ binNumber: '48334884' });
```

### convert

`commerce.convert`

Convert between currencies, units and number bases using the unit codes Neutrino publishes

**Risk:** `read`

```ts
await corsair.neutrino.api.commerce.convert({ fromValue: 100, fromType: 'USD', toType: 'EUR' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fromValue` | `number` | Yes | The value to convert. |
| `fromType` | `string` | Yes | The unit or currency to convert from, e.g. USD, kg, km, c. Neutrino publishes the full list in its docs. |
| `toType` | `string` | Yes | The unit or currency to convert to. |

result is a string and result-float a number; both are returned.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `valid` | `boolean \| null` | No | — |
| `result` | `string \| null` | No | — |
| `from-value` | `string \| null` | No | — |

| `result-float` | `number \| null` | No | — |

| `from-symbol` | `string \| null` | No | — |
