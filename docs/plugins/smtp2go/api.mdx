## Activity

### search

`activity.search`

Search delivery activity events (processed, delivered, bounced, opened, clicked and more) by date, address and event type; limited to 100 returned items per call

**Risk:** `read`

```ts
await corsair.smtp2go.api.activity.search({ event_types: ['delivered', 'opened'], search_subject: 'receipt', limit: 100, region: 'eu' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `start_date` | `string` | No | — |
| `end_date` | `string` | No | — |
| `search` | `string` | No | — |
| `search_email_id` | `string` | No | — |
| `search_subject` | `string` | No | — |
| `search_sender` | `string` | No | — |
| `search_recipient` | `string` | No | — |
| `event_types` | `string[]` | No | Event types to keep: 'processed', 'soft-bounced', 'hard-bounced', 'rejected', 'spam', 'delivered', 'unsubscribed', 'resubscribed', 'opened', 'clicked'. |
| `limit` | `number` | No | Defaults to 100; the API returns at most 1000 items. |
| `continue_token` | `string` | No | — |
| `only_latest` | `boolean` | No | — |
| `include_headers` | `boolean` | No | — |
| `region` | `us \| eu \| au` | No | Read activity from one region instead of the account default. |
| `subaccounts` | `string[]` | No | Subaccount ids to include. |

Returns at most 1000 events per call; `total_events` is the full match
count. The endpoint is documented at 60 requests per minute.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `request_id` | `string` | Yes | — |
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts

}
```

## Domains

### add

`domains.add`

Add a sender domain and get the DNS records to publish; verification starts right away unless auto_verify is false

**Risk:** `write`

```ts
await corsair.smtp2go.api.domains.add({ domain: 'example.com', auto_verify: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `domain` | `string` | Yes | The sender domain to add, such as example.com. |
| `auto_verify` | `boolean` | No | Defaults to true: verification is attempted right away. |
| `requisition_ssl` | `boolean` | No | Defaults to true: an SSL requisition is created for the tracking subdomain. |
| `subaccount_id` | `string` | No | — |

The answer contains the DNS records to publish (DKIM, return-path and
CNAME). Verification starts right away unless `auto_verify` is false.

### send

`email.send`

Send one email to up to 100 recipients, with HTML or plain text, a template, attachments, custom headers, or a schedule up to 3 days out; the result counts succeeded and failed recipients at HTTP 200, so check failed, not the status

**Risk:** `write` · **Irreversible**

```ts
await corsair.smtp2go.api.email.send({ sender: 'John Smith <john@example.com>', to: ['Jane Jones <jane@example.com>'], subject: 'Your receipt', text_body: 'Thanks for your order.', custom_headers: [{ header: 'Reply-To', value: 'support@example.com' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `sender` | `string` | Yes | The sender, in `Name <name@example.com>` format. |
| `to` | `string[]` | Yes | Up to 100 recipients. Each recipient counts against the plan quota. |
| `cc` | `string[]` | No | — |
| `bcc` | `string[]` | No | — |
| `subject` | `string` | No | Optional despite the docs saying required: the server does not enforce it. |
| `html_body` | `string` | No | — |
| `text_body` | `string` | No | — |
| `custom_headers` | `object[]` | No | Content-Type, Content-Transfer-Encoding and MIME-Version cannot be overridden. |
| `attachments` | `object[]` | No | — |
| `inlines` | `object[]` | No | Inline images referenced by the HTML body via cid: URLs. |
| `template_id` | `string` | No | — |
| `template_data` | `string` | No | Template variables as a JSON-encoded string. |
| `schedule` | `string` | No | Schedule the send, in `YYYY-MM-DD HH:mm:ss +ZZZZ` format, less than 3 days out. |
| `fastaccept` | `boolean` | No | Accept the message without delivery results; defaults to false, which waits for per-recipient outcomes. |

Sends real email. The plugin requires one of `text_body`, `html_body` or
`template_id` before spending the call; SMTP2GO enforces the same rule
server-side. `subject` is optional despite the docs saying required
(verified live). Every To/CC/BCC recipient counts as one email against the
plan quota. The answer carries `succeeded` and `failed` counts at HTTP
200, plus a `failures` entry per rejected recipient, so check `failed`
rather than the status code.
