## Activity

### search

`activity.search`

Search delivery activity events (processed, delivered, bounced, opened, clicked and more) by date, address, subject or username, with equals/contains/not_* operators; 100 items by default, up to 1,000 per call, continue_token for more

**Risk:** `read`

```ts
await corsair.smtp2go.api.activity.search({ event_types: ['delivered', 'opened'], search_subject: 'receipt', limit: 100, region: 'eu' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `start_date` | `string` | No | — |
| `end_date` | `string` | No | — |
| `search` | `string` | No | — |
| `search_email_id` | `string` | No | — |
| `search_subject` | `string` | No | — |
| `search_subject_op` | `equals \| contains \| not_equals \| not_contains` | No | How search_subject compares; SMTP2GO defaults to contains. |
| `search_sender` | `string` | No | — |
| `search_sender_op` | `equals \| contains \| not_equals \| not_contains` | No | How search_sender compares; SMTP2GO defaults to contains. |
| `search_recipient` | `string` | No | — |
| `search_recipient_op` | `equals \| contains \| not_equals \| not_contains` | No | How search_recipient compares; SMTP2GO defaults to contains. |
| `search_usernames` | `string[]` | No | Only events for emails sent by these SMTP usernames. |
| `only_latest_by_sent` | `boolean` | No | Only the latest event per email, ordered by sent date (overrides only_latest). |
| `custom_headers` | `string[]` | No | Header names to parse out of each email's raw headers. |
| `event_types` | `string[]` | No | Event types to keep: 'processed', 'soft-bounced', 'hard-bounced', 'rejected', 'spam', 'delivered', 'unsubscribed', 'resubscribed', 'opened', 'clicked'. |
| `limit` | `number` | No | SMTP2GO defaults to 100 and allows up to 1000 per call. |
| `continue_token` | `string` | No | — |
| `only_latest` | `boolean` | No | — |
| `include_headers` | `boolean` | No | — |
| `region` | `us \| eu \| au` | No | Read activity from one region instead of the account default. |
| `subaccounts` | `string[]` | No | Subaccount ids to include. |

Returns at most 1000 events per call; `total_events` is the full match
count. The endpoint is documented at 60 requests per minute.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `request_id` | `string` | Yes | — |
| `data` | `object` | Yes | — |

<Accordion title="data full type">

```ts

    email_id?: string | null,

    recipient?: string | null,
    to?: string | null,
```

## Webhooks

### add

`webhooks.add`

Register a webhook URL for chosen email (or SMS) events, in form or JSON output, with optional auth headers

**Risk:** `write`

```ts
await corsair.smtp2go.api.webhooks.add({ url: 'https://example.com/smtp2go-events', events: ['delivered', 'open', 'click', 'spam', 'bounce'], output_format: 'json' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | The https URL events are posted to. |
| `events` | `string[]` | No | Email events to receive: 'delivered', 'unsubscribe', 'spam', 'bounce', 'processed', 'reject', 'click', 'open'. Defaults to all. |
| `sms_events` | `string[]` | No | — |
| `headers` | `string[]` | No | Email headers echoed to the webhook. |
| `usernames` | `string[]` | No | Restrict the webhook to these SMTP users. |
| `output_format` | `form \| json` | No | Defaults to 'form'. |
| `auth_header_type` | `string` | No | — |
| `auth_header_value` | `string` | No | — |
| `custom_headers` | `string[]` | No | Extra headers sent with every delivery. |
| `subaccount_id` | `string` | No | — |

`output_format` accepts `form` or `json` and defaults to `form`. With no
`events` list the webhook receives all email events. Set `auth_header_type`
and `auth_header_value`, and store the value as the plugin's webhook
secret: the plugin's `email.event` and `sms.event` webhooks receive the
deliveries and check that header.



**Output**

| `request_id` | `string` | Yes | — |
| `data` | `object` | Yes | — |
