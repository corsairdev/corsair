---
title: "SMTP2GO database"
sidebarTitle: "Database"
description: "The SMTP2GO plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for SMTP2GO. To read its data, call the [API operations](/plugins/smtp2go/api), which return what SMTP2GO has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
