The SMTP2GO plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/smtp2go/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `email`
  - `event` (`email.event`)
- `sms`
  - `event` (`sms.event`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Events

## Email

### Event

`email.event`

An email event: processed, delivered, open, click, bounce, spam, unsubscribe, resubscribe, reject (the "event" parameter)

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event` | `string` | Yes | — |
| `id` | `string \| number \| null` | No | — |
| `email_id` | `string \| null` | No | — |
| `message-id` | `string \| null` | No | — |
| `time` | `string \| number \| null` | No | — |
| `sendtime` | `string \| number \| null` | No | — |
| `sender` | `string \| null` | No | — |
| `from` | `string \| null` | No | — |
| `from_address` | `string \| null` | No | — |
| `from_name` | `string \| null` | No | — |
| `rcpt` | `string \| null` | No | — |
| `recipients` | `string \| string[] \| null` | No | — |
| `subject` | `string \| null` | No | — |
| `auth` | `string \| null` | No | — |
| `host` | `string \| null` | No | — |
| `message` | `string \| null` | No | — |
| `bounce` | `string \| null` | No | — |
| `user-agent` | `string \| null` | No | — |
| `read-secs` | `string \| number \| null` | No | — |
| `client` | `string \| null` | No | — |
| `client-device` | `string \| null` | No | — |
| `client-os` | `string \| null` | No | — |
| `geoip-country` | `string \| null` | No | — |
| `srchost` | `string \| null` | No | — |

**`webhookHooks` example**

```ts
smtp2go({
    webhookHooks: {
        email: {
            event: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
