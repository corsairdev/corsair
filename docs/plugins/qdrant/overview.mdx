Use **Qdrant** through Corsair: one client, typed API calls.

Works with self-hosted Qdrant and [Qdrant Cloud](https://cloud.qdrant.io). Each account stores its cluster URL as `base_url` next to its API key. The URL is never taken from endpoint input. A stored URL must use https and a public host; pin a local or private cluster such as `http://localhost:6333` or `http://qdrant:6333` with the `baseUrl` option.

**What you get:**

- 29 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/qdrant better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/qdrant better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/qdrant better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/qdrant better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { qdrant } from '@corsair-dev/qdrant';

export const corsair = createCorsair({
	plugins: [
		qdrant({
			baseUrl: 'https://xyz-example.eu-central.aws.cloud.qdrant.io:6333',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Qdrant API key before the first call: `pnpm corsair setup --plugin=qdrant --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

Pass `baseUrl` to pin one cluster for every account, or leave it out and store `base_url` per account.

```ts
qdrant({
	baseUrl: 'https://xyz-example.eu-central.aws.cloud.qdrant.io:6333',
})
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'qdrant',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Find the nearest neighbours of a vector**

```ts
const tenant = corsair.withTenant('acme');
await tenant.qdrant.api.query.points({
	collectionName: 'docs',
	query: [0.12, 0.08, 0.91, 0.33],
	filter: {
		must: [{
			key: 'lang',
			match: { value: 'en' },
		}],
	},
	limit: 5,
	with_payload: true,
});
```


**Store embeddings with their payload**

```ts
const tenant = corsair.withTenant('acme');
await tenant.qdrant.api.points.upsert({
	collectionName: 'docs',
	points: [{
		id: 1,
		vector: [0.12, 0.08, 0.91, 0.33],
		payload: { url: 'https://example.com/guide', lang: 'en' },
	}],
});
```
