### update

`aliases.update`

Atomically create, delete or rename aliases, e.g. to switch traffic to a rebuilt collection

**Risk:** `write`

```ts
await corsair.qdrant.api.aliases.update({
	actions: [{
		delete_alias: { alias_name: 'docs_live' },
	}, {
		create_alias: { collection_name: 'docs_v2', alias_name: 'docs_live' },
	}],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `actions` | `object[]` | Yes | Applied atomically |
| `timeout` | `number` | No | Request timeout in seconds |

<AccordionGroup>
<Accordion title="actions full type">

```ts
(
  {
    create_alias: {
      collection_name: string,
      alias_name: string
    }
  } | {
    delete_alias: {
      alias_name: string
    }
  } | {
    rename_alias: {
      old_alias_name: string,
      new_alias_name: string
    }
  }
)[]
```
</Accordion>
</AccordionGroup>



**Output:** `boolean`
