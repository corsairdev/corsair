---
title: Database
description: "Qdrant returns live API data and stores no local entities."
---

The Qdrant plugin returns live API data and does not sync or store entities locally. No local `.search()` operations are available. Each call logs a `qdrant.<group>.<operation>` event that records only the collection name.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
