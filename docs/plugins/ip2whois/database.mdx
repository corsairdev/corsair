---
title: "IP2WHOIS database"
sidebarTitle: "Database"
description: "The IP2WHOIS plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for IP2WHOIS. To read its data, call the [API operations](/plugins/ip2whois/api), which return what IP2WHOIS has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
