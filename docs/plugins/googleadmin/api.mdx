## Customers

### get

`customers.get`

Read the account's customer record, including its primary domain

**Risk:** `read`

```ts
await corsair.googleadmin.api.customers.get({ customerKey: 'my_customer' });
```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `customerKey` | `string` | Yes | The customer ID, or `my_customer` for the caller's own account |
