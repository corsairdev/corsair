---
title: "PDF.co database"
sidebarTitle: "Database"
description: "The PDF.co plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for PDF.co. To read its data, call the [API operations](/plugins/pdfco/api), which return what PDF.co has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
