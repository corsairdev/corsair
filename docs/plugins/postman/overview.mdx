Use **Postman** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 135 typed API operations
- 5 synced entities (`collection`, `environment`, `mock`, `monitor`, `workspace`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/postman
```
```bash yarn
yarn add corsair @corsair-dev/postman
```
```bash pnpm
pnpm install corsair @corsair-dev/postman
```
```bash bun
bun add corsair @corsair-dev/postman
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { postman } from '@corsair-dev/postman';

export const corsair = createCorsair({
	plugins: [
		postman(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
postman()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'postman',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List collections**

```ts
const tenant = corsair.withTenant('acme');
await tenant.postman.api.collections.list({});
```


**Create a collection**

```ts
const tenant = corsair.withTenant('acme');
await tenant.postman.api.collections.create({
	workspace: '1f0df51a-8658-4ee8-a2a1-d2567dfa09a9',
	collection: {
		info: { name: 'Corsair API', schema: 'https://schema.postman.com/json/collection/v2.1.0/collection.json' },
		item: [],
	},
});
```


See the full list on the [API](/plugins/postman/api) page.

## Query synced data

These tables exist, but Postman calls don't fill them yet. This returns only rows you have written yourself.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.postman.db.collection.search({
	data: {},
	limit: 50,
});
```

Synced entities: `collection`, `environment`, `mock`, `monitor`, `workspace`. See [Database](/plugins/postman/database) for filters and operators.
