**What you get:**

- 36 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/findymail better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/findymail better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/findymail better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/findymail better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { findymail } from '@corsair-dev/findymail';

export const corsair = createCorsair({
	plugins: [
		findymail({
			authType: 'api_key',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Configure a Findymail API key before making a request, either on the plugin,
through `FINDYMAIL_API_KEY`, or for the tenant. A missing key causes an
`AuthMissingError`; Corsair does not prompt for it during the request.

```ts
findymail({
	authType: 'api_key',
})
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'findymail',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`contacts.list`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.findymail.api.contacts.list({ id: 0 });
```


**`excludedDomains.add`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.findymail.api.excludedDomains.add({ domains: ['example.com'] });
```


See the full list on the [API](/plugins/findymail/api) page.

Findymail accepts `webhook_url` for outbound callbacks on supported searches and
monitors. This plugin does not handle inbound callbacks. Requests are not
retried automatically; a 429 response can indicate a concurrency limit.
