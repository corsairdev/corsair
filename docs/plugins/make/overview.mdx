Use **Make** through Corsair: one client, typed API calls.

Configure your organization’s Make zone and an API token with the required scopes. Scenario runs and replays can trigger external actions and consume credits. The client does not retry failed requests automatically, including quota-related 429 responses.

**What you get:**

- 24 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/make better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/make better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/make better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/make better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { make } from '@corsair-dev/make';

export const corsair = createCorsair({
	plugins: [
		make({
			zone: 'eu1',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Make API key before the first call: `pnpm corsair setup --plugin=make --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

Select the Make zone for your organization; for example, `eu1`.

```ts
make({
	zone: 'eu1',
})
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'make',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List scenarios for a team**

```ts
const tenant = corsair.withTenant('acme');
await tenant.make.api.scenarios.list({ teamId: 123 });
```


**Rename a scenario**

```ts
const tenant = corsair.withTenant('acme');
await tenant.make.api.scenarios.update({
	scenarioId: 123,
	body: { name: 'Updated scenario' },
});
```


See the full list on the [API](/plugins/make/api) page.
