Use **Emailable** through Corsair: one client, typed API calls, local DB sync.

The key is the api_key query parameter, or a JSON field on batch create. Empty-key requests to account, verify, batch status, and batch create each returned HTTP 403. Owner email, names, and batch address lists are not stored. The authorize URL is built and not fetched.

**What you get:**

- 5 typed API operations
- 3 synced entities (`accounts`, `batches`, `verifications`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/emailable better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/emailable better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/emailable better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/emailable better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { emailable } from '@corsair-dev/emailable';

export const corsair = createCorsair({
	plugins: [
		emailable(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Emailable API key before the first call: `pnpm corsair setup --plugin=emailable --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
emailable()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'emailable',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read account credits**

```ts
const tenant = corsair.withTenant('acme');
await tenant.emailable.api.account.get({});
```


**`batches.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.emailable.api.batches.create({});
```


See the full list on the [API](/plugins/emailable/api) page.

## Query synced data

Synced entities support `tenant.emailable.db.<entity>.search()` and `.list()`: `accounts`, `batches`, `verifications`.

See [Database](/plugins/emailable/database) for filters and operators.
