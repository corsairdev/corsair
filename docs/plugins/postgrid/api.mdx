## Contacts

### create

`contacts.create`

Create a contact. PostGrid corrects and verifies the address, so the stored one may differ from the one sent

**Risk:** `write`

```ts
await corsair.postgrid.api.contacts.create({ addressLine1: '145 Mulberry St', city: 'New York', provinceOrState: 'NY', postalOrZip: '10013', countryCode: 'US', firstName: 'Kevin', lastName: 'Villena' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `addressLine1` | `string` | Yes | First line of the address. |
| `addressLine2` | `string` | No | — |
| `city` | `string` | No | — |
| `provinceOrState` | `string` | No | — |
| `postalOrZip` | `string` | No | — |
| `countryCode` | `string` | No | ISO 3166-1 alpha-2, such as `US`. |
| `firstName` | `string` | No | — |
| `lastName` | `string` | No | — |
| `companyName` | `string` | No | — |
| `jobTitle` | `string` | No | — |
| `email` | `string` | No | — |
| `phoneNumber` | `string` | No | — |
| `description` | `string` | No | — |
| `skipVerification` | `boolean` | No | Skip address correction and verification. |
| `forceVerifiedStatus` | `boolean` | No | Override the address verification status. |
| `secret` | `boolean` | No | Hide the details apart from the final print. |
| `metadata` | `Record<string, JsonValue>` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | The resource id, such as `contact_…` or `letter_…`. |
| `object` | `string \| null` | No | Always `contact`. |
| `live` | `boolean \| null` | No | — |
| `description` | `string \| null` | No | — |
| `firstName` | `string \| null` | No | — |
| `lastName` | `string \| null` | No | — |
| `companyName` | `string \| null` | No | — |
| `jobTitle` | `string \| null` | No | — |
| `addressLine1` | `string \| null` | No | — |
| `addressLine2` | `string \| null` | No | — |
| `city` | `string \| null` | No | — |
| `provinceOrState` | `string \| null` | No | — |
| `postalOrZip` | `string \| null` | No | — |
| `countryCode` | `string \| null` | No | — |
| `email` | `string \| null` | No | — |
| `phoneNumber` | `string \| null` | No | — |
| `addressStatus` | `string \| null` | No | `verified`, `corrected` or `failed`. |
| `skipVerification` | `boolean \| null` | No | — |
| `forceVerifiedStatus` | `boolean \| null` | No | — |
| `secret` | `boolean \| null` | No | — |
| `metadata` | `Record<string, JsonValue> \| null` | No | — |

### delete

`contacts.delete`

Delete a contact. Orders already created from it keep their own copy of the address

**Risk:** `destructive`

```ts
await corsair.postgrid.api.contacts.delete({ id: 'contact_nA8mdzveShFEmFraaChaDn' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The `contact_` id. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | The resource id, such as `contact_…` or `letter_…`. |
| `object` | `string \| null` | No | — |
| `deleted` | `boolean \| null` | No | — |
| `live` | `boolean \| null` | No | — |

### list

`contacts.list`

List contacts, optionally with a plain or structured search, paged by `skip` and `limit`

**Risk:** `read`

```ts
await corsair.postgrid.api.contacts.list({ limit: 10, skip: 0 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `skip` | `number` | No | How many documents to skip. Increment it by `limit` to page. |
| `limit` | `number` | No | How many documents to return. |
| `search` | `string` | No | A plain string, or a JSON object of structured queries such as &#123;"metadata.campaignID": "ABC"&#125;. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `object` | `string \| null` | No | Always `list`. |
| `limit` | `number \| null` | No | — |
| `skip` | `number \| null` | No | — |
| `totalCount` | `number` | Yes | Total documents including the skipped ones; page while skip &lt; totalCount. |
| `data` | `object[]` | Yes | — |

### create

`letters.create`

Print and mail a letter, which costs postage and cannot be recalled once it leaves `ready`. Pass `idempotencyKey` so a retry prints one letter, not two

**Risk:** `destructive`

```ts
await corsair.postgrid.api.letters.create({ to: { firstName: 'Kevin', addressLine1: '145 Mulberry St', city: 'New York', provinceOrState: 'NY', postalOrZip: '10013', countryCode: 'US' }, from: { companyName: 'Corsair', addressLine1: '1 Main St', city: 'New York', provinceOrState: 'NY', postalOrZip: '10001', countryCode: 'US' }, html: '<b>Hello</b>', color: true, doubleSided: true, size: 'us_letter', mailingClass: 'usps_first_class' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `to` | `string \| object` | Yes | The recipient: a contact id or the address fields. |
| `sendDate` | `string` | No | When to send it. Omit to send as soon as possible. |
| `mailingClass` | `first_class \| standard_class \| express \| certified \| certified_return_receipt \| registered \| usps_first_class \| usps_standard_class \| usps_eddm \| usps_express_2_day \| usps_express_3_day \| usps_first_class_certified \| usps_first_class_certified_return_receipt \| usps_first_class_registered \| usps_express_3_day_signature_confirmation \| usps_express_3_day_certified \| usps_express_3_day_certified_return_receipt \| usps_express_3_day_adult_signature_confirmation \| ca_post_lettermail \| ca_post_personalized \| ca_post_neighbourhood_mail \| ca_post_registered \| ca_post_expedited_with_signature \| ca_post_expedited \| ca_post_xpresspost_with_signature \| ca_post_xpresspost \| royal_mail_first_class \| royal_mail_standard_class \| royal_mail_second_class \| au_post_regular \| au_post_second_class \| ups_express_overnight \| ups_express_2_day \| ups_express_3_day \| ups_express_3_day_signature_confirmation \| ups_express_3_day_adult_signature_confirmation` | No | The carrier and service level. Defaults to first class or the fastest non-express postage in the destination country. |
| `description` | `string` | No | — |
| `idempotencyKey` | `string` | No | Reuse the same value to retry this order within 24 hours without creating a second one. |
| `mergeVariables` | `Record<string, JsonValue>` | No | — |
| `metadata` | `Record<string, JsonValue>` | No | — |
| `from` | `string \| object` | No | The sender: a contact id or the address fields. |
| `html` | `string` | No | The letter body. Supply this or a template. |
| `template` | `string` | No | A `template_` id to render instead of raw html. |
| `size` | `us_letter \| a4` | No | — |
| `color` | `boolean` | No | Print in colour. |
| `doubleSided` | `boolean` | No | — |
| `addressPlacement` | `top_first_page \| insert_blank_page` | No | — |
| `envelope` | `string` | No | A custom envelope id, or `standard` for the default envelope. Express postage is `mailingClass: express`. |
| `perforatedPage` | `1` | No | The page to perforate, for a tear-off return slip. PostGrid accepts only 1, the first page. |
| `returnEnvelope` | `string` | No | A `return_envelope_` id to include. |
