---
title: "PostGrid database"
sidebarTitle: "Database"
description: "The PostGrid plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for PostGrid. To read its data, call the [API operations](/plugins/postgrid/api), which return what PostGrid has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
