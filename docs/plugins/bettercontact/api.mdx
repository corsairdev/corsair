## Credits

### get

`credits.get`

Check remaining API credits balance

**Risk:** `read`

```ts
const tenant = corsair.withTenant('acme');
await tenant.bettercontact.api.credits.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |
| `credits_left` | `number` | Yes | — |
| `email` | `string` | No | — |

## Enrichment

### enrich

`enrichment.enrich`

**Risk:** `write`
