The Salesforce plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/salesforce/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `accountCreatedOrUpdated` (`accountCreatedOrUpdated`)
- `contactUpdated` (`contactUpdated`)
- `genericSObjectRecordUpdated` (`genericSObjectRecordUpdated`)
- `newContact` (`newContact`)
- `newLead` (`newLead`)
- `newOrUpdatedOpportunity` (`newOrUpdatedOpportunity`)
- `taskCreatedOrCompleted` (`taskCreatedOrCompleted`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Events

## Account Created Or Updated

### Account Created Or Updated

`accountCreatedOrUpdated`

Account created or updated

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ChangeEventHeader` | `object` | No | — |
| `Id` | `string` | No | — |
| `id` | `string` | No | — |
| `sobject` | `string` | No | — |
| `type` | `string` | No | — |
| `Status` | `string` | No | — |
| `LastModifiedDate` | `string` | No | — |
| `SystemModstamp` | `string` | No | — |
| `organization_id` | `string` | No | — |

<AccordionGroup>
<Accordion title="ChangeEventHeader full type">

```ts
{
  entityName?: string,
  changeType?: string,
  recordIds?: string[],
  commitTimestamp?: number,
  commitUser?: string
}
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  success: boolean
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
salesforce({
    webhookHooks: {
        accountCreatedOrUpdated: {
            before(ctx, args) {
                return { ctx, args };
            },
            after(ctx, response) {
            },
        },
    },
})
```
