The Salesforce plugin syncs data locally. Use `corsair.salesforce.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
