---
title: "tl;dv database"
sidebarTitle: "Database"
description: "The tl;dv plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for tl;dv. To read its data, call the [API operations](/plugins/tldv/api), which return what tl;dv has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
