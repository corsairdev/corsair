The tl;dv plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/tldv/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `meetings`
  - `meetingReady` (`meetings.meetingReady`)
- `transcripts`
  - `transcriptReady` (`transcripts.transcriptReady`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // Read the raw text, not `request.json()`.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body);
    // `result.response` is a plain object, not a Response. No match means no
    // plugin claimed the delivery, so answer 404 rather than 200.
    return Response.json(result.response ?? { success: false }, {
        status: !result.plugin ? 404 : result.response?.success === false ? 500 : 200,
    });
}
```

Three details decide whether a bad delivery is visible:

- **A rejected delivery must throw.** `processWebhook` ignores a handler's `statusCode` and answers `{ success: true }` for a returned `success: false`, keeping a failure only when the handler throws. The plugin's handlers throw when the shared secret does not match or the payload does not parse, so `success` is a reliable failure signal here.
- **tl;dv does not sign webhooks.** It publishes no signature scheme, so the plugin compares a shared secret you supply in `x-corsair-webhook-secret`. Enabling a webhook in the tl;dv app cannot attach headers, so a proxy has to add it, or leave the secret unset and accept unverified deliveries.
- **tl;dv waits 10 seconds** for a 2xx before retrying, so answer quickly. A `MeetingReady` delivery with `include.transcript` enabled can be several hundred KB.

## Events

## Meetings

### Meeting Ready

`meetings.meetingReady`

A meeting finished processing and its transcript and notes exist

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Webhook delivery id |
| `event` | `MeetingReady` | Yes | — |
| `data` | `object` | Yes | — |
| `executedAt` | `string` | Yes | ISO 8601 timestamp |

**`webhookHooks` example**

```ts
tldv({
    webhookHooks: {
        meetings: {
            meetingReady: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
