## Insights

### get

`insights.get`

Export project dashboard metrics for the past 1 to 3 days with optional dimension breakdowns

**Risk:** `read`

```ts
await corsair.microsoftclarity.api.insights.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `numOfDays` | `number` | Yes | — |
| `dimension1` | `string` | No | — |
| `dimension2` | `string` | No | — |
| `dimension3` | `string` | No | — |

Use `numOfDays` 1, 2, or 3 and up to three optional dimension values. Metric information fields vary with the metric and requested breakdown.



**Output:** `object[]`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  metricName: string,
  information: {
    totalSessionCount?: string,
    totalBotSessionCount?: string,
    distantUserCount?: string,
    PagesPerSessionPercentage?: number,
    OS?: string
  }[]
}[]
```
</Accordion>
</AccordionGroup>
