## Collections

### create

`collections.create`

Create a collection, such as one per customer of your SaaS, holding up to 500 templates

**Risk:** `write`

```ts
await corsair.placid.api.collections.create({ title: 'Acme onboarding', template_uuids: ['ospo24ysn'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `title` | `string` | Yes | — |
| `custom_data` | `string \| Record<string, any>` | No | — |
| `template_uuids` | `string[]` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `title` | `string \| null` | No | — |
| `custom_data` | `string \| Record<string, any> \| any[] \| null` | No | — |
| `templates` | `string[] \| null` | No | The UUIDs of the templates in this collection. |
| `template_uuids` | `string[] \| null` | No | Deprecated alias. The API returns `templates`. |

## Fonts

### create

`fonts.create`

Upload a ttf, otf, woff or woff2 font from a public URL. `terms_accepted` must be true. The returned `uuid` is the value to set as the `font` property on a text layer

**Risk:** `write`

```ts
await corsair.placid.api.fonts.create({ file_url: 'https://example.com/HelveticaNeue-Regular.ttf', title: 'Helvetica Neue', terms_accepted: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `file_url` | `string` | Yes | A publicly reachable ttf, otf, woff or woff2 file over HTTP(S). Private addresses are rejected, and the download is capped at 25 MB. |
| `title` | `string` | No | Display title. Defaults to the filename. |
| `terms_accepted` | `true` | Yes | You must confirm you own the font or hold a licence to use it. Placid rejects the upload without it. |
| `filename` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `uuid` | `string` | Yes | The font code. Use it as the `font` value on a text layer. |
| `title` | `string \| null` | No | — |
| `filename` | `string \| null` | No | — |
| `is_legacy` | `boolean \| null` | No | — |
| `created_at` | `string \| null` | No | — |



---

## Images

### create

`images.create`

Render a template to an image. The reply is usually `queued`: poll `images.get` with its `id` or set `webhook_success` to get the finished URL. One image costs one credit.

**Risk:** `write`

```ts
await corsair.placid.api.images.create({ template_uuid: 'ospo24ysn', layers: { title: { text: 'Meet Singh' } }, create_now: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `template_uuid` | `string` | Yes | The template to render, from the Templates tab of the project. |
| `layers` | `object` | No | — |
| `modifications` | `object` | No | Output sizing and format. Placid overrides the template default. |
| `transfer` | `object` | No | Copies the finished file to your own S3 bucket. Placid does not store the credentials. |
| `webhook_success` | `string` | No | Placid POSTs the finished image object to this URL. |
| `create_now` | `boolean` | No | render immediately instead of queueing. Placid allows 10 simultaneous calls this way; past that the call can fail. |
| `passthrough` | `string \| any[]` | No | Saved with the file and returned in the webhook and polling replies. At most 1024 characters. |

<AccordionGroup>
<Accordion title="layers full type">

```ts
Record<string, {
  hide?: boolean,
  opacity?: number,
  rotation?: number,
  position_x_absolute?: string,
  position_y_absolute?: string,
  position_x_relative?: string,
  position_y_relative?: string,
  width?: string,
  height?: string,
  link_target?: string,
  text?: string | string[],
  text_color?: string,
  font?: string,

  srt?: string
```

</Accordion>

**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | — |
| `status` | `queued \| finished \| error \| string` | Yes | `queued` in the queue, `finished` ready, `error` failed. Poll the matching `get` with `id` until it is not `queued`. |
| `polling_url` | `string \| null` | No | GET this until `status` settles. |
| `error_code` | `string \| null` | No | A render error code such as `INVALID_INPUT` or `MEDIA_DOWNLOAD_FAILED`. Null unless `status` is `error`. |
| `error_message` | `string \| null` | No | One sentence about the failure. Wording can change, so branch on `error_code`. |
| `image_url` | `string \| null` | No | — |
| `error_details` | `object[] \| null` | No | — |
| `errors` | `string[] \| null` | No | Deprecated. Use `error_code`, `error_message` and `error_details`. |
