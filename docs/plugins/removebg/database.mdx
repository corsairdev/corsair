---
title: "remove.bg database"
sidebarTitle: "Database"
description: "The remove.bg plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for remove.bg. To read its data, call the [API operations](/plugins/removebg/api), which return what remove.bg has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
