## Company

### get

`company.get`

Retrieve current company account profile and settings

**Risk:** `read`

```ts
await corsair.giftup.api.company.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |

| `onboardingCompleted` | `boolean \| null` | No | — |
| `canShowCheckout` | `boolean \| null` | No | — |
