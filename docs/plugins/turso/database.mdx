The Turso plugin syncs data locally. Use `corsair.turso.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Change Events

Path: `turso.db.changeEvents.search`

```ts
const rows = await corsair.turso.db.changeEvents.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `databaseUrl` | `string` | equals, contains, startsWith, endsWith, in |
| `table` | `string` | equals, contains, startsWith, endsWith, in |
| `action` | `string` | equals, contains, startsWith, endsWith, in |
| `receivedAt` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
