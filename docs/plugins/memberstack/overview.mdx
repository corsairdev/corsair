Use **Memberstack** through Corsair: one client, typed API calls.

Use a Memberstack secret key from Dev Tools as the API key. Keys are sent in the X-API-KEY header to https://admin.memberstack.com.

Member listing uses the numeric endCursor as after. Data record queries support offset and cursor pagination; cursor paging requires internalOrder ascending on every request. A missing member is returned as data: null. Member JSON updates replace the entire JSON value. Plan operations only support free plans. The provider limits the Admin API to 25 requests per second. Webhook verification is only available through Memberstack's Node admin package and is not included.

**What you get:**

- 14 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/memberstack better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/memberstack better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/memberstack better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/memberstack better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { memberstack } from '@corsair-dev/memberstack';

export const corsair = createCorsair({
	plugins: [
		memberstack({
			authType: 'api_key',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Memberstack API key before the first call: `pnpm corsair setup --plugin=memberstack --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
memberstack({
	authType: 'api_key',
})
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'memberstack',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List members**

```ts
const tenant = corsair.withTenant('acme');
await tenant.memberstack.api.members.list({ limit: 25 });
```


**Add a free plan**

```ts
const tenant = corsair.withTenant('acme');
await tenant.memberstack.api.members.addPlan({ id: 'mem_example', planId: 'pln_example' });
```


See the full list on the [API](/plugins/memberstack/api) page.
