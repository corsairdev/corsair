## Members

### addPlan

`members.addPlan`

Add a free plan to a member

**Risk:** `write`

```ts
await corsair.memberstack.api.members.addPlan({ id: 'mem_example', planId: 'pln_example' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `planId` | `string` | Yes | — |



**Output:** `void`
