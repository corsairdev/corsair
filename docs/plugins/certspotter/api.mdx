## Firehose

### list

`firehose.list`

Read the continuous stream of new issuances across every log; requires a Firehose subscription and a cursor to continue from

**Risk:** `read`

```ts
await corsair.certspotter.api.firehose.list({ after: '17433446883' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `after` | `string` | No | Return issuances discovered after this ID; omit to start from about an hour ago |
| `expand` | `(dns_names \| issuer \| issuer.website \| issuer.caa_domains \| issuer.operator \| issuer.pubkey_der \| issuer.name_der \| pubkey \| pubkey_der \| revocation \| problem_reporting \| cert_der)[]` | No | — |

Requires a Firehose subscription. Omit `after` to start from about the last hour; a `lagging_client` error means restart without it.



**Output:** `object[]`

## Issuances

### list

`issuances.list`

List the unexpired certificate issuances for a domain, newest last, with an `after` cursor for paging

**Risk:** `read`

```ts
await corsair.certspotter.api.issuances.list({ domain: 'example.com', include_subdomains: true, expand: ['dns_names', 'issuer', 'revocation'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `domain` | `string` | Yes | Registered domain or a name under it, e.g. "example.com" or "www.example.com"; a bare TLD is rejected |
| `include_subdomains` | `boolean` | No | Also return issuances valid for sub-domains; default false |
| `match_wildcards` | `boolean` | No | Also return wildcard matches, e.g. *.example.com; default false |
| `after` | `string` | No | Return issuances discovered after this ID; take `id` from the last result of the previous page |
| `expand` | `(dns_names \| issuer \| issuer.website \| issuer.caa_domains \| issuer.operator \| issuer.pubkey_der \| issuer.name_der \| pubkey \| pubkey_der \| revocation \| problem_reporting \| cert_der)[]` | No | Extra fields to include; repeated as one `expand` per value |

Take `id` from the last issuance and pass it as `after` to page. An empty array means the end, and its Retry-After header says when to ask again.



**Output:** `object[]`
