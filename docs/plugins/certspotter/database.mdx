---
title: "SSLMate Cert Spotter database"
sidebarTitle: "Database"
description: "The SSLMate Cert Spotter plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for SSLMate Cert Spotter. To read its data, call the [API operations](/plugins/certspotter/api), which return what SSLMate Cert Spotter has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
