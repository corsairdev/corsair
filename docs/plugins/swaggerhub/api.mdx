### cloneVersion

`apis.cloneVersion`

Create a version that starts as a copy of an existing one

**Risk:** `write`

```ts
await corsair.swaggerhub.api.apis.cloneVersion({ owner: 'your-org', api: 'petstore', version: '1.0.0', newVersion: '1.0.1' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `owner` | `string` | Yes | — |
| `api` | `string` | Yes | — |
| `version` | `string` | Yes | — |
| `newVersion` | `string` | Yes | — |
| `private` | `boolean` | No | — |

Creates `newVersion` as a copy of the version in the path. `private` decides the new version's visibility; without it the source setting is used.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `owner` | `string` | Yes | — |
| `api` | `string` | Yes | — |
| `sourceVersion` | `string` | Yes | — |
| `version` | `string` | Yes | — |
| `created` | `true` | Yes | — |

### compare

`apis.compare`

Compare a definition against the stored version and list the differences

**Risk:** `read`

```ts
await corsair.swaggerhub.api.apis.compare({ owner: 'your-org', api: 'petstore', version: '1.0.0', definition: 'openapi: 3.0.0\ninfo:\n  title: Petstore\n  version: 1.0.0\npaths: {}', method: 'FULL' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `owner` | `string` | Yes | — |
| `api` | `string` | Yes | — |
| `version` | `string` | Yes | — |
| `definition` | `string` | Yes | — |
| `format` | `yaml \| json` | No | — |
| `method` | `FULL \| LOGICAL \| STRUCTURAL` | No | Defaults to "FULL". |

Posts a definition and answers a **bare array** of differences between it and the stored version, so the plugin returns `{ owner, api, version, changes }`. `method` is a required query parameter on the route and takes `FULL`, `LOGICAL` or `STRUCTURAL`; the plugin sends `FULL` when you leave it out. A response that is not an array fails rather than reading as no changes.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `owner` | `string` | Yes | — |
| `api` | `string` | Yes | — |
| `version` | `string` | Yes | — |
| `changes` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="changes full type">

```ts
{
  description?: string | null,
  breaking?: boolean | null
}[]
```
</Accordion>
</AccordionGroup>

### save

`apis.save`

Save a definition to one API, creating the version or updating it. Answers 409 on a published version unless force is set

**Risk:** `write`

```ts
await corsair.swaggerhub.api.apis.save({ owner: 'your-org', api: 'petstore', definition: 'openapi: 3.0.0\ninfo:\n  title: Petstore\n  version: 1.0.0\npaths: {}' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `owner` | `string` | Yes | — |
| `api` | `string` | Yes | — |
| `definition` | `string` | Yes | — |
| `format` | `yaml \| json \| graphql` | No | — |
| `version` | `string` | No | — |
| `isPrivate` | `boolean` | No | — |
| `force` | `boolean` | No | — |
| `projectName` | `string` | No | — |
| `noReconcile` | `boolean` | No | — |

**The definition is the request body**, not a field inside an object. For OpenAPI and AsyncAPI the version comes from `info.version`; pass `version` for GraphQL and MCP. Use `format: 'graphql'` for GraphQL SDL, which is sent as `application/graphql`. `force` overwrites a published version instead of answering 409. The route replies with no body, so the result reports the owner, the name and the `version` you passed. When the version comes from the definition's `info.version` and you leave `version` out, the result has `version: null`. Core does not pass the status on, so whether the save created the version is not reported.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `owner` | `string` | Yes | — |
| `api` | `string` | Yes | — |
| `version` | `string \| null` | No | — |
| `saved` | `true` | Yes | — |
