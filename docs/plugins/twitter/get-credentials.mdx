This guide walks you through obtaining credentials for the X (Twitter) plugin.

## Authentication Methods

- **[`oauth_2`](/concepts/oauth)** (default): OAuth 2.0 Authorization Code with PKCE. Acts as the X user who signs in: posts, DMs, timelines, bookmarks, likes, lists.
- **`api_key`**: the app's Bearer token (app-only auth). Reaches public reads and the routes X only takes app-only: compliance jobs, `usage.get`, filtered-stream rules, full-archive counts. It can't act as a user.

## OAuth 2.0 Setup

### Step 1: Create an X app

1. Go to the [X Developer Console](https://console.x.com) and sign in with the account that will own the app.
2. Create a project and an app inside it. X bills API calls pay-per-use against the developer account's credits.

### Step 2: Turn on OAuth 2.0

1. In the app, open **User authentication settings** and click **Set up**.
2. Set **App permissions** to **Read and write and Direct message** (DMs need it).
3. Set **Type of App** to **Web App, Automated App or Bot** (a confidential client, with a client secret).
4. Add your **Callback URI**, for example `http://localhost:<port>` for the CLI flow, or your Corsair Hub callback.
5. Add your **Website URL** and click **Save**.

### Step 3: Get the client credentials

1. Open **Keys and tokens**.
2. Copy the **OAuth 2.0 Client ID** and **Client Secret** and store them securely.

**Storing credentials:**

```bash
pnpm corsair setup --plugin=twitter client_id=your-client-id client_secret=your-client-secret
pnpm corsair auth --plugin=twitter
```

The CLI prints an authorization URL (`https://x.com/i/oauth2/authorize`, with a PKCE challenge). Open it in a browser and approve; the access and refresh tokens are saved automatically.

Access tokens last 2 hours. X rotates the refresh token on every refresh and the old one stops working, so the plugin stores each new pair as it refreshes.

### Scopes

By default the plugin asks for `tweet.read tweet.write tweet.moderate.write users.read follows.read follows.write offline.access space.read mute.read mute.write like.read like.write list.read list.write block.read block.write bookmark.read bookmark.write dm.read dm.write media.write`. Live broadcasts, calls, the developer account and the media library need more (`X_EXTRA_SCOPES`):

```ts
import { twitter, X_DEFAULT_SCOPES, X_EXTRA_SCOPES } from '@corsair-dev/twitter';

twitter({ scopes: [...X_DEFAULT_SCOPES, ...X_EXTRA_SCOPES] });
```

## App-only Bearer token

1. In the app, open **Keys and tokens** and generate the **Bearer Token**.
2. Use the plugin with `authType: 'api_key'` and store the token as the API key:

```bash
pnpm corsair setup --plugin=twitter api_key=your-bearer-token
```

## Required Credentials Summary

| Credential | Required For | Where to Find |
|-----------|--------------|---------------|
| Client ID | OAuth 2.0 | Developer Console → Keys and tokens |
| Client Secret | OAuth 2.0 | Developer Console → Keys and tokens |
| Bearer Token | App-only auth (`api_key`) | Developer Console → Keys and tokens |
