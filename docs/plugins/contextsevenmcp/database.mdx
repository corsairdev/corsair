---
title: "Context7 database"
sidebarTitle: "Database"
description: "The Context7 plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Context7. To read its data, call the [API operations](/plugins/contextsevenmcp/api), which return what Context7 has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
