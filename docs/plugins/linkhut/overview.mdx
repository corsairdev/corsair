Use **Linkhut** through Corsair: one client, typed API calls.

Linkhut is an open-source social bookmarking service at ln.ht. Create a personal
access token in the web app under https://ln.ht/_/oauth/personal-token (log in
first; the token is shown once and you can revoke it on the same page), and store
it as the API key. The plugin sends it as an `Authorization: Bearer` header.

Things to know before you call:

- **Every method is a GET**, including `posts.delete` and `tags.delete`. That is
  how linkhut works, so a destructive call looks identical on the wire to a read.
  The plugin marks the deletes destructive and never replays them after a
  network failure or a 5xx.
- **Writes can fail at HTTP 200.** A write answers `{ "result_code": "done" }`.
  The documented failure is `{ "result_code": "something went wrong" }`, which
  can arrive with a 200 status. The plugin raises it as a `LinkhutAPIError`
  instead of returning it, so a failed write never looks like a success.
- **`posts.add` is an upsert keyed by url.** Existing bookmarks are replaced by
  default; pass `replace: 'no'` to leave one unchanged. A retried add converges,
  so the plugin allows the retry.
- **Etiquette.** The docs ask for at least one second between requests and an
  identifiable User-Agent; the plugin does both. A 500 or an HTTP 999 means you
  were throttled. The plugin retries reads with backoff; without a `Retry-After`
  header the first wait is one second.
- **Paging.** `posts.all` pages by offset: it takes `start` and `results`
  (default 1000, maximum 100000) and `fromdt`/`todt` bounds, and the plugin
  derives `nextStart`, null on the last page. `posts.recent` has no offset.
- **Webhooks.** The plugin does not receive webhooks; linkhut sends none.

- 11 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/linkhut better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/linkhut better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/linkhut better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/linkhut better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { linkhut } from '@corsair-dev/linkhut';

export const corsair = createCorsair({
	plugins: [
		linkhut(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Linkhut API key before the first call: `pnpm corsair setup --plugin=linkhut --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
linkhut()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'linkhut',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read the five most recent bookmarks**

```ts
const tenant = corsair.withTenant('acme');
await tenant.linkhut.api.posts.recent({ count: 5 });
```


**Save a bookmark with two tags**

```ts
const tenant = corsair.withTenant('acme');
await tenant.linkhut.api.posts.add({
	url: 'https://sourcehut.org/',
	description: 'sourcehut',
	tags: ['git', 'oss'],
});
```


See the full list on the [API](/plugins/linkhut/api) page.
