Use **Search1API** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 16 typed API operations
- 1 synced entity (`searchResults`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/search1api
```
```bash yarn
yarn add corsair @corsair-dev/search1api
```
```bash pnpm
pnpm install corsair @corsair-dev/search1api
```
```bash bun
bun add corsair @corsair-dev/search1api
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { search1api } from '@corsair-dev/search1api';

export const corsair = createCorsair({
	plugins: [
		search1api(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
search1api()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'search1api',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Search the web**

```ts
const tenant = corsair.withTenant('acme');
await tenant.search1api.api.web.search({ query: 'open source integration layer', max_results: 10 });
```


**Crawl a page**

```ts
const tenant = corsair.withTenant('acme');
await tenant.search1api.api.content.crawl({ url: 'https://example.com/docs' });
```


See the full list on the [API](/plugins/search1api/api) page.

## Query synced data

Search hits are cached by link when a database is configured, so repeated searches refresh rows instead of duplicating them.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.search1api.db.searchResults.search({
	data: { query: 'corsair' },
	limit: 50,
});
```

Synced entities: `searchResults`. See [Database](/plugins/search1api/database) for filters and operators.
