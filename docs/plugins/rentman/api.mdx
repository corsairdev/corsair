## Appointments

### get

`appointments.get`

Fetch one appointment with its start, end, location and recurrence settings

**Risk:** `read`

```ts
await corsair.rentman.api.appointments.get({ appointment_id: 55 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `appointment_id` | `number` | Yes | — |
| `fields` | `string[]` | No | Return only these fields. `id`, `created` and `modified` always come back. |
| `expand` | `string[]` | No | Inline these linked resources instead of returning a path string. Nested links use dot notation and go three levels deep at most. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `appointment` | `object` | Yes | — |

### list

`appointments.list`

List calendar appointments with start and end filters plus cursor paging

**Risk:** `read`

```ts
await corsair.rentman.api.appointments.list({ start: { gte: '2026-07-01' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | Records per page, 1 to 1500. Rentman uses 300 when omitted and carries the value into later pages. |
| `cursor` | `string` | No | The `next_cursor` from the previous page, used verbatim. Rentman warns against constructing or editing it. |
| `fields` | `string[]` | No | Return only these fields. `id`, `created` and `modified` always come back. |
| `expand` | `string[]` | No | Inline these linked resources instead of returning a path string. Nested links use dot notation and go three levels deep at most. |
| `sort` | `string` | No | A comma-separated sort, such as `+id,-firstname`: `+` ascending, `-` descending. |
| `start` | `object` | No | — |
| `end` | `object` | No | — |
| `modified` | `object` | No | — |

The date operators are `lt`, `gt`, `lte`, `gte` and `neq`.

## Contacts

### create

`contacts.create`

Create a company or person contact with its mailing, visit and invoice addresses

**Risk:** `write`

```ts
await corsair.rentman.api.contacts.create({ name: 'Acme Inc', type: 'company', email: 'info@acme.example', mailing_address: { street: 'Damrak', city: 'Amsterdam', country: 'nl' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `folder` | `string` | No | — |
| `type` | `private \| company` | No | `company` or `private` (a person); Rentman derives `displayname` from it. |
| `ext_name_line` | `string` | No | — |
| `name` | `string` | No | The company name. |
| `firstname` | `string` | No | — |
| `surname` | `string` | No | — |
| `surfix` | `string` | No | — |
| `gender` | `string` | No | — |
| `code` | `string` | No | — |
| `accounting_code` | `string` | No | — |
| `vendor_accounting_code` | `string` | No | — |
| `country` | `string` | No | The visit address country, a two-letter code such as `nl`. Same as `visit_address.country`. |
| `longitude` | `number` | No | — |
| `latitude` | `number` | No | — |
| `distance` | `number` | No | — |
| `travel_time` | `number` | No | — |
| `email` | `string` | No | The primary email address, stored as `email_1`. |
| `phone` | `string` | No | The primary phone number, stored as `phone_1`. |
| `mailing_address` | `object` | No | — |
| `visit_address` | `object` | No | — |
| `invoice_address` | `object` | No | — |

The three address blocks are folded into `mailing_`, `visit_` and `invoice_` prefixed fields; the visit address country is sent as `country`.
