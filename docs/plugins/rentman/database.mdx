---
title: "Rentman database"
sidebarTitle: "Database"
description: "The Rentman plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Rentman. To read its data, call the [API operations](/plugins/rentman/api), which return what Rentman has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
