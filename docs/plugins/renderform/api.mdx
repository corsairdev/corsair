## Pdf

### pdf

`pdf`

Capture a URL as a PDF in a chosen page format, optionally self-deleting after a set time; costs a credit

**Risk:** `write`

```ts
await corsair.renderform.api.pdf({ url: 'https://renderform.io', format: 'A4', expires: 3600 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | The page to capture. |
| `format` | `A5 \| A4 \| A3 \| LETTER \| LEGAL` | No | Defaults to A4. |
| `expires` | `number` | No | Delete the PDF after this many seconds, at most 604800 (7 days). |
| `waitTime` | `number` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `requestId` | `string \| null` | No | — |
| `href` | `string \| null` | No | — |
| `request` | `Record<string, JsonValue> \| null` | No | — |

## Render

### render

`render`

Render a template to an image, PDF or video, merging your data into its fields; costs a credit unless the answer is served from the cache, and a video render is asynchronous

**Risk:** `write`

```ts
await corsair.renderform.api.render({ template: 'template_1234', data: { 'my-text.text': 'John' }, fileName: 'welcome-card', version: 'welcome-john-v1' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `template` | `string` | Yes | The template identifier, such as template_1234. |
| `data` | `Record<string, JsonValue>` | No | Values keyed by the template's merge fields, such as &#123;"my-text.text": "John"&#125;. A component's own defaults fill anything omitted. |
| `fileName` | `string` | No | The output file name, without an extension. |
| `webhookUrl` | `string` | No | Called when the render finishes, which suits a video render. |
| `version` | `string` | No | The cache key. The same version with the same data returns the cached file and costs no credits. |
| `metadata` | `Record<string, JsonValue>` | No | Extra data passed through to the webhook. |
| `batchName` | `string` | No | Groups renders together, and can be filtered on in results.list. |
| `cache` | `boolean` | No | Defaults to true. False forces a fresh render and skips the cache, which costs credits. |
| `width` | `number` | No | Output width in pixels. Renderform crops the image to it from the top left corner. |
| `height` | `number` | No | Output height in pixels. Renderform crops the image to it from the top left corner. |
| `waitTime` | `number` | No | Milliseconds to wait before rendering. At most 5000. |
| `outputFormat` | `jpeg \| png \| webp \| pdf \| mp4 \| webm` | No | Overrides the template's format. A video format needs a template made in the Advanced Editor and always renders asynchronously. |
| `duration` | `number` | No | Video renders only: length in milliseconds. Every started second costs 5 credits. |
| `fps` | `24 \| 25 \| 30` | No | Video renders only, and sent as a string: 24, 25 or 30. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `requestId` | `string \| null` | No | Identifies the render, and is what results.get takes. |
| `href` | `string \| null` | No | The rendered file. Not usable yet when status is pending. |
| `status` | `string \| null` | No | pending, done or failed. Present only for an asynchronous video render. |
| `cached` | `boolean \| null` | No | True when the file came from the cache, which costs no credits. |
