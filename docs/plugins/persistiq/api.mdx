## Campaigns

### addLead

`campaigns.addLead`

Add a lead to a campaign

**Risk:** `write`

```ts
await corsair.persistiq.api.campaigns.addLead({ campaignId: "c_1", lead_id: "l_1" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | Campaign id |
| `lead_id` | `string` | Yes | Lead id to add |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string` | Yes | success |

### replyToMessage

`campaigns.replyToMessage`

Reply to an inbox message; the email goes out and cannot be recalled

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.persistiq.api.campaigns.replyToMessage({ campaignId: "c_1", lead_id: "l_1", message_id: "m_1", reply_message: "Thanks for the reply!" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | Campaign id |
| `lead_id` | `string` | Yes | Lead id the message belongs to |
| `message_id` | `string` | Yes | Inbox message id to reply to |
| `reply_message` | `string` | Yes | Reply body |

Sends the reply immediately; it cannot be recalled.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string` | Yes | success |
| `data` | `object[]` | Yes | The reply as sent |
| `page` | `object` | Yes | PersistIQ pagination |
