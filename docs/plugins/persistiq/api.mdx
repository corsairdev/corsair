## Campaigns

### addLead

`campaigns.addLead`

Add leads to a campaign; the campaign's automated emails start going to them

**Risk:** `destructive`

```ts
await corsair.persistiq.api.campaigns.addLead({ campaignId: "c_1", lead_id: "l_1" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | Campaign id |
| `lead_id` | `string` | No | Lead id to add |
| `leads` | `string[]` | No | Bulk add: up to 100 lead ids |
| `mailbox_id` | `string` | No | Mailbox to send from; defaults to the campaign owner's |
| `skip_if_exists` | `boolean` | No | Return the existing membership instead of an error |
| `override_lead_limit` | `boolean` | No | Add past the campaign's lead limit |

Starts the campaign's automated emails to the lead. Give lead_id, or up to 100 ids in leads.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string \| null` | No | success or error |
| `error` | `any \| null` | No | Error details, null on success |
| `campaign_lead` | `object \| null` | No | The membership created (single add) |

<AccordionGroup>
<Accordion title="campaign_lead full type">

```ts
{
  id: string,
  campaign_id?: string | null,
  mailbox_id?: string | null,
  lead?: {
    id: string,
    status?: string | null,
    data?: Record<string, any> | null,
    creator_id?: string | null,
    owner_id?: string | null,
    bounced?: boolean | null,
    optedout?: boolean | null,
    sent_count?: number | null,
    replied_count?: number | null,
    last_sent_at?: string | null
  } | null
} | null
```
</Accordion>
</AccordionGroup>

### replyToMessage

`campaigns.replyToMessage`

Reply to a message received in a campaign; the email goes out and cannot be recalled

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.persistiq.api.campaigns.replyToMessage({ campaignId: "c_1", inbox_message_id: "r_1", body: "<p>Thanks for the reply!</p>" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | Campaign id |
| `inbox_message_id` | `string` | Yes | Inbox message id to reply to (a reply id from listReplies) |
| `body` | `string` | Yes | HTML body of the reply |

Queues the reply email at once; it cannot be recalled. inbox_message_id is a reply id from listReplies.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string \| null` | No | queued once accepted |
| `message` | `string \| null` | No | What PersistIQ did |
