Use **PersistIQ** through Corsair: one client, typed API calls.

Authenticate with the API key from the PersistIQ integrations settings (Settings &gt; Integrations &gt; API Key); the plugin sends it in the x-api-key header. List operations answer &#123; status, errors, has_more, next_page &#125; plus a named array (leads, campaigns, campaign_leads, replies, events, ...). Pages are numbered: pass page: 2, 3, ... while has_more is true.
Lead attributes live in a `data` map keyed by the account's lead fields (read them with leadFields.list); leads.create takes them in `lead`. Adding a lead to a campaign (campaigns.addLead) starts the campaign's automated emails to that lead, so it asks for approval like a send.
PersistIQ delivers outbound webhooks through its webhook plugin; the plugin reads and updates those settings (webhooks.getSettings and webhooks.updateSettings). The delivery signature scheme is not documented, so this plugin does not receive the deliveries.
Every operation is described in the official OpenAPI spec: https://persistiq.com/api-docs/v1/swagger.json

**What you get:**

- 21 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/persistiq better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/persistiq better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/persistiq better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/persistiq better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { persistiq } from '@corsair-dev/persistiq';

export const corsair = createCorsair({
	plugins: [
		persistiq(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the PersistIQ API key before the first call: `pnpm corsair setup --plugin=persistiq --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
persistiq()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'persistiq',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read a lead**

```ts
const tenant = corsair.withTenant('acme');
await tenant.persistiq.api.leads.get({ id: 'l_1' });
```


**Create a lead**

```ts
const tenant = corsair.withTenant('acme');
await tenant.persistiq.api.leads.create({
	lead: { email: 'john@example.com', first_name: 'John' },
});
```
