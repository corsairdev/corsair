## Applications

### list

`applications.list`

List no-code applications

**Risk:** `read`

```ts
await corsair.writer.api.applications.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `before` | `string` | No | — |
| `after` | `string` | No | — |
| `limit` | `number` | No | — |
| `order` | `asc \| desc` | No | — |
| `search` | `string` | No | — |
| `status` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `has_more` | `boolean` | No | — |
| `first_id` | `string` | No | — |
| `last_id` | `string` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
}[]
```
</Accordion>
