## Account

### getAccountUsage

`account.getAccountUsage`

Read the account credit balance, rate-limit windows, plan and per-action pricing map. Free, but Lusha caps it at 5 requests per minute.

**Risk:** `read`

```ts
await corsair.lusha.api.account.getAccountUsage({});
```

**Input:** _empty object_

Free. Returns `credits` (`total`, `used`, `remaining`), `rateLimits` for the daily, hourly and minute windows (a window may be null), `plan` and a `pricing` map of action name to `{ credits, perQuantity }`. Lusha caps this endpoint at 5 requests per minute.

|------|------|----------|-------------|
| `credits` | `object \| null` | No | — |
| `rateLimits` | `object \| null` | No | — |
| `plan` | `object \| null` | No | — |
| `pricing` | `object \| null` | No | — |

## Company

### enrichCompanies

`company.enrichCompanies`

Reveal full firmographics for up to 100 company ids, including premium fields named in reveal (each charged separately per result). Omitting reveal returns base firmographics only. Metered, and every call re-charges.

**Risk:** `read`

```ts
await corsair.lusha.api.company.enrichCompanies({ ids: ['16303253'], reveal: ['employeesByDepartment', 'competitors'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ids` | `string[]` | Yes | 1 to 100 ids from a search result. |
| `reveal` | `(employeesByDepartment \| employeesByLocation \| employeesBySeniority \| competitors \| estimatedAnnualItSpend \| monthlyWebsiteTraffic \| openJobsTotal \| openJobsByDepartment \| openJobsByLocation \| openJobsBySeniority \| directParent \| ultimateParent)[]` | No | Premium fields to reveal, each charged separately per result: employeesByDepartment, employeesByLocation, employeesBySeniority, competitors, estimatedAnnualItSpend, monthlyWebsiteTraffic, openJobsTotal, openJobsByDepartment, openJobsByLocation, openJobsBySeniority, directParent, ultimateParent. Omitting reveal returns base firmographics only. |

Takes `ids` and optional `reveal` tokens (employeesByDepartment, employeesByLocation, employeesBySeniority, competitors, estimatedAnnualItSpend, monthlyWebsiteTraffic, openJobsTotal, openJobsByDepartment, openJobsByLocation, openJobsBySeniority, directParent, ultimateParent). ## Jobs

### getContactsEnrichJob

`jobs.getContactsEnrichJob`

Where a partial contacts enrich job stands: processing (poll again after retryAfter seconds), complete (contacts to merge by id plus creditsCharged), or the terminal expired and failed. Free.

**Risk:** `read`

```ts
await corsair.lusha.api.jobs.getContactsEnrichJob({ jobId: 'wf_3f2b9c1e-4a7d-4f3b-9c2e-1d6a5b8c7e90' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `jobId` | `string` | Yes | The job id from a partial enrichContacts response. |

Free. Takes the `jobId` from a partial enrich response. `processing` carries `retryAfter` (seconds) and `covers`; `complete` carries `contacts` and `creditsCharged`; `expired` and `failed` (with `reason`) are terminal and keep what enrich already returned.



**Output**

| `status` | `processing \| complete \| expired \| failed` | Yes | — |
| `requestId` | `string \| null` | No | — |
| `expiresAt` | `string \| null` | No | — |
| `retryAfter` | `number \| null` | No | — |
| `covers` | `object[] \| null` | No | — |
| `contacts` | `object[] \| null` | No | — |
| `creditsCharged` | `number \| null` | No | — |

## Person

### enrichContacts

`person.enrichContacts`

Reveal emails and phone numbers for up to 100 contact ids from search results. Metered: charged per revealed data point, and every call re-charges. May answer status partial with a job; follow it with jobs.getContactsEnrichJob until it reports complete, expired or failed.

**Risk:** `read`

```ts
await corsair.lusha.api.person.enrichContacts({ ids: ['4389064654'], reveal: ['emails', 'phones'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ids` | `string[]` | Yes | 1 to 100 ids from a search result. |
| `reveal` | `(emails \| phones)[]` | No | Data points to reveal, each charged per result: emails, phones. |
| `waterfallEnabled` | `boolean` | No | Allow the Data Waterfall to fall through to your enabled third-party providers when Lusha has no match. Defaults to true when the waterfall is enabled on your account; false means Lusha data only. |
| `tableId` | `string` | No | Also add these contacts to this table and fill its columns. |

Takes `ids` (1 to 100 from search results), optional `reveal` (`emails`, `phones`), `waterfallEnabled` and `tableId`. Returns enriched contacts with `emails` and `phones` arrays, plus `billing`. May answer `status: 'partial'` with a `job`: poll `jobs.getContactsEnrichJob` until it reports `complete`, `expired` or `failed`, and merge its `contacts` into the results by `id`. Metered per revealed data point.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `requestId` | `string \| null` | No | — |
| `results` | `object[]` | Yes | — |
| `tableWrite` | `object \| null` | No | — |
| `billing` | `object \| null` | No | — |
| `status` | `completed \| partial \| halted \| OUT_OF_CREDITS \| PARTIAL_OUT_OF_CREDITS \| null` | No | — |
| `statusDescription` | `string \| null` | No | — |
| `statusReason` | `WATERFALL_NOT_CONFIGURED \| WATERFALL_NOT_IN_PLAN \| WATERFALL_DISABLED \| null` | No | — |
| `job` | `object \| null` | No | — |
