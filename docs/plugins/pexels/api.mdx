## Collections

### list

`collections.list`

List the collections of the API key

**Risk:** `read`

```ts
await corsair.pexels.api.collections.list({ per_page: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | Page number |
| `per_page` | `number` | No | Results per page, at most 80 |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `collections` | `object[]` | Yes | Collections on this page |
| `page` | `number \| null` | No | Page returned |
| `per_page` | `number \| null` | No | Results per page |
| `total_results` | `number \| null` | No | Total collections |
| `next_page` | `string \| null` | No | URL of the next page |
| `prev_page` | `string \| null` | No | URL of the previous page |

<AccordionGroup>
<Accordion title="collections full type">

```ts
{
  id: string,
  title?: string | null,
  description?: string | null,
  private?: boolean | null,
  media_count?: number | null,
  photos_count?: number | null,
  videos_count?: number | null
}[]
```
</Accordion>
</AccordionGroup>

### listMedia

`collections.listMedia`

List the photos and videos of a collection, filtered by type

**Risk:** `read`

```ts
await corsair.pexels.api.collections.listMedia({ collectionId: "9nkrlyb", type: "photos", sort: "desc", per_page: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `collectionId` | `string` | Yes | Collection id |
| `type` | `photos \| videos` | No | Only photos or only videos; both when omitted |
| `sort` | `asc \| desc` | No | Order by when the item was added |
| `page` | `number` | No | Page number |
| `per_page` | `number` | No | Results per page, at most 80 |

Returns photos and videos together unless type is set; each item is a photo or video object with a type of Photo or Video.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `media` | `object[]` | Yes | Media items on this page |
| `page` | `number \| null` | No | Page returned |
| `per_page` | `number \| null` | No | Results per page |
| `total_results` | `number \| null` | No | Total media items |
| `next_page` | `string \| null` | No | URL of the next page |
| `prev_page` | `string \| null` | No | URL of the previous page |

### search

`photos.search`

Search photos by query, orientation, size and color

**Risk:** `read`

```ts
await corsair.pexels.api.photos.search({ query: "nature", orientation: "landscape", per_page: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | Search query |
| `orientation` | `landscape \| portrait \| square` | No | Aspect orientation filter |
| `size` | `large \| medium \| small` | No | Minimum size filter |
| `color` | `string` | No | Dominant color filter: a color name or a hex value |
| `locale` | `string` | No | Search locale, e.g. en-US, de-DE, ja-JP |
| `page` | `number` | No | Page number |
| `per_page` | `number` | No | Results per page, at most 80 |

color takes a color name or a hex value; src carries all rendition URLs, original included. per_page is capped at 80 results per page across every list endpoint.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `photos` | `object[]` | Yes | Photos on this page |
| `page` | `number \| null` | No | Page returned |
| `per_page` | `number \| null` | No | Results per page |
| `total_results` | `number \| null` | No | Total matching photos |
| `next_page` | `string \| null` | No | URL of the next page |
| `prev_page` | `string \| null` | No | URL of the previous page |
