Use **Pexels** through Corsair: one client, typed API calls.

Authenticate with the API key from the Pexels API keys page; the plugin sends it as the raw value of the Authorization header, without a Bearer prefix, as the API expects. Photos live under /v1, videos at the root, and the plugin handles both.
Every route is a GET and answers &#123; photos|videos|collections, page, per_page, total_results, next_page, prev_page &#125;; follow next_page for the next results page, or pass page and per_page (at most 80) yourself. The default monthly quota is 20,000 requests; limits.get is not part of the Pexels API, so watch the per-page X-Ratelimit-Remaining header if you need quota tracking.
Every operation is described in the official docs: https://www.pexels.com/api/documentation/

**What you get:**

- 10 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/pexels better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/pexels better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/pexels better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/pexels better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { pexels } from '@corsair-dev/pexels';

export const corsair = createCorsair({
	plugins: [
		pexels(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Pexels API key before the first call: `pnpm corsair setup --plugin=pexels --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
pexels()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'pexels',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Search photos**

```ts
const tenant = corsair.withTenant('acme');
await tenant.pexels.api.photos.search({ query: 'nature', orientation: 'landscape' });
```


**Search videos**

```ts
const tenant = corsair.withTenant('acme');
await tenant.pexels.api.videos.search({ query: 'waves' });
```
