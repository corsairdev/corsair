Use **ScrapeCreators** through Corsair: one client, typed API calls.

All 198 operations are reads. Most cost 1 ScrapeCreators credit; a few cost more (`tiktok.userAudience` 26, `creators.findSocialProfiles` and `creators.findEmails` up to 10, `download_media` 10, `google.companyAds` with `get_ad_details` 25, long AI transcripts 10 per started minute). Errors and `cache_max_age` cache hits cost 0, and some routes do not charge for an empty page. Every data response says what it cost in `credits_charged`. The `account.*` operations are free and read the account whose key you pass, so they are not available with managed pricing.

**What you get:**

- 198 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/scrapecreators better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/scrapecreators better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/scrapecreators better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/scrapecreators better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { scrapecreators } from '@corsair-dev/scrapecreators';

export const corsair = createCorsair({
	plugins: [
		scrapecreators(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the ScrapeCreators API key before the first call: `pnpm corsair setup --plugin=scrapecreators --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
scrapecreators()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'scrapecreators',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Look up a TikTok profile**

```ts
const tenant = corsair.withTenant('acme');
await tenant.scrapecreators.api.tiktok.profile({ handle: 'nasa' });
```


**Get a YouTube video transcript**

```ts
const tenant = corsair.withTenant('acme');
await tenant.scrapecreators.api.youtube.videoTranscript({ url: 'https://www.youtube.com/watch?v=_eeZQw9PBc0' });
```


See the full list on the [API](/plugins/scrapecreators/api) page.
