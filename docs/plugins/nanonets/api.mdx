## Files

### approve

`files.approve`

Approve a validated file from an approval stage, which can trigger exports

**Risk:** `write`

```ts
await corsair.nanonets.api.files.approve({ model_id: 'd4d3beec-1029-497a-8d4c-8a3e2de6e7f2', request_file_id: '68d2b0f6-af9c-4c71-9d3e-2f3a4b5c6d7e' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `model_id` | `string` | Yes | The Nanonets model ID. |
| `request_file_id` | `string` | Yes | The Nanonets file ID. |



**Output:** `Record<string, unknown>`


---

### assign

`files.assign`

Assign files to a team member by email for review

**Risk:** `write`

```ts
await corsair.nanonets.api.files.assign({ model_id: 'd4d3beec-1029-497a-8d4c-8a3e2de6e7f2', member: 'reviewer@example.com', file_ids: ['68d2b0f6-af9c-4c71-9d3e-2f3a4b5c6d7e'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `model_id` | `string` | Yes | The Nanonets model ID. |
| `member` | `string` | Yes | Team member email to assign to. |
| `file_ids` | `string[]` | Yes | File IDs to assign. |



**Output:** `Record<string, unknown>`

### updateFields

`files.updateFields`

Replace a file field set: unchanged boxes stay, new boxes need is_new, and any omitted field is deleted

**Risk:** `write`

```ts
await corsair.nanonets.api.files.updateFields({ model_id: 'd4d3beec-1029-497a-8d4c-8a3e2de6e7f2', moderated_boxes: [{ id: 'box-1', label: 'total_amount', xmin: 10, ymin: 20, xmax: 200, ymax: 40, ocr_text: '120.00' }] });
```

| `moderated_boxes` | `object[]` | Yes | The full field list: existing boxes unchanged, new boxes with is_new: true, and any field omitted from the array is deleted. |

## Integrations

### executeQuery

`integrations.executeQuery`

Run arbitrary SQL against a connected store; documented examples include UPDATE, which cannot be undone

**Risk:** `destructive`

```ts
await corsair.nanonets.api.integrations.executeQuery({ external_integration_id: 'a1b2c3d4-e5f6-7890-abcd-ef1234567890', query: 'select * from passports limit 10' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `external_integration_id` | `string` | Yes | The integration to query, from integrations.list. |
| `query` | `string` | Yes | SQL to run against the connected store; documented examples include UPDATE, which cannot be undone. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `rows` | `Record<string, unknown>[]` | Yes | — |

```ts
await corsair.nanonets.api.models.updateGuidelines({ model_id: 'd4d3beec-1029-497a-8d4c-8a3e2de6e7f2', field_instructions: 'Extract the invoice total and tax fields', table_instructions: 'Extract line items as a table', ai_guidelines: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `model_id` | `string` | Yes | The Nanonets model ID. |
| `field_instructions` | `string` | Yes | Natural-language extraction instructions for fields. |
| `table_instructions` | `string` | Yes | Natural-language extraction instructions for tables. |
| `ai_guidelines` | `true` | Yes | Must be true to apply the guidelines. |



**Output:** `Record<string, unknown>`

## Predictions

### createFromFile

`predictions.createFromFile`

Upload a base64 PNG or JPEG to an OCR model and extract fields synchronously or, with async, as a pollable request

**Risk:** `write`

```ts
await corsair.nanonets.api.predictions.createFromFile({ model_id: 'd4d3beec-1029-497a-8d4c-8a3e2de6e7f2', base64_data: '<base64 PNG or JPEG>', async: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `model_id` | `string` | Yes | The Nanonets model ID. |

| `request_metadata` | `string` | No | Your identifier for the request, returned with the result. |
| `pages_to_process` | `string` | No | Comma-separated page numbers to process, e.g. "1,2". |

| `async` | `boolean` | No | Process asynchronously: returns pending with a request_file_id to poll. Recommended above 3 pages. |
