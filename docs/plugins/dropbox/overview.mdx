Use **Dropbox** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 12 typed API operations
- 2 synced entities (`files`, `folders`) for fast `.search()` / `.list()`
- 1 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/dropbox
```
```bash yarn
yarn add corsair @corsair-dev/dropbox
```
```bash pnpm
pnpm install corsair @corsair-dev/dropbox
```
```bash bun
bun add corsair @corsair-dev/dropbox
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { dropbox } from '@corsair-dev/dropbox';

export const corsair = createCorsair({
	plugins: [
		dropbox({
			authType: 'managed',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="Managed OAuth (Recommended)">

No setup required. Corsair hosts the OAuth app for **Dropbox** — your tenants connect through Hub when they sign in.

Provider walkthrough: [Get Credentials](/plugins/dropbox/get-credentials).

```ts
dropbox({
	authType: 'managed',
})
```

More: [Managed OAuth](/concepts/auth#managed)

</Tab>
<Tab title="OAuth 2.0">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Dropbox OAuth app.

Provider walkthrough: [Get Credentials](/plugins/dropbox/get-credentials).

```ts
dropbox()
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'dropbox',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`files.download`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.dropbox.api.files.download({});
```


**`files.copy`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.dropbox.api.files.copy({});
```


See the full list on the [API](/plugins/dropbox/api) page.

## Query synced data

Synced entities support `tenant.dropbox.db.<entity>.search()` and `.list()`: `files`, `folders`.

See [Database](/plugins/dropbox/database) for filters and operators.

## Webhooks

This plugin registers **1** webhook event type. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/dropbox/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
