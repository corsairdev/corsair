Use **TwitterAPI.io** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 47 typed API operations
- 6 synced entities (`communities`, `lists`, `replies`, `trends`, `tweets`, `users`) for fast `.search()` / `.list()`
- 2 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/twitterapiio
```
```bash yarn
yarn add corsair @corsair-dev/twitterapiio
```
```bash pnpm
pnpm install corsair @corsair-dev/twitterapiio
```
```bash bun
bun add corsair @corsair-dev/twitterapiio
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { twitterapiio } from '@corsair-dev/twitterapiio';

export const corsair = createCorsair({
	plugins: [
		twitterapiio(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

Provider walkthrough: [Get Credentials](/plugins/twitterapiio/get-credentials).

```ts
twitterapiio()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'twitterapiio',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`api.webhooks.getRules`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.twitterapiio.api.api.webhooks.getRules({});
```


**`api.webhooks.addRule`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.twitterapiio.api.api.webhooks.addRule({});
```


See the full list on the [API](/plugins/twitterapiio/api) page.

## Query synced data

Synced entities support `tenant.twitterapiio.db.<entity>.search()` and `.list()`: `communities`, `lists`, `replies`, `trends`, `tweets`, `users`.

See [Database](/plugins/twitterapiio/database) for filters and operators.

## Webhooks

This plugin registers **2** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/twitterapiio/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
