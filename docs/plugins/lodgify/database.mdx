---
title: "Lodgify database"
sidebarTitle: "Database"
description: "The Lodgify plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Lodgify. To read its data, call the [API operations](/plugins/lodgify/api), which return what Lodgify has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
