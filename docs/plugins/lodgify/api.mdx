## Availability

### get

`availability.get`

Get availability calendar periods for a property

**Risk:** `read`

```ts
await corsair.lodgify.api.availability.get({ propertyId: 101, from: '2026-06-01', to: '2026-06-10' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `propertyId` | `number` | Yes | — |
| `from` | `string` | No | — |
| `to` | `string` | No | — |

Returns the calendar availability periods and booking states for the specified property over a date range.



**Output:** `object[]`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  start?: string | null,
  end?: string | null,
  is_available?: boolean,
  period_type?: string | null,
  room_type_id?: number | null
}[]
```
</Accordion>
</AccordionGroup>
