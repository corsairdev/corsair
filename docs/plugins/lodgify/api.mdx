## Availability

### get

`availability.get`

Get availability calendar periods for a property

**Risk:** `read`

```ts
await corsair.lodgify.api.availability.get({ propertyId: 101, from: '2026-06-01T00:00:00Z', to: '2026-06-10T00:00:00Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `propertyId` | `number` | Yes | — |
| `from` | `string` | Yes | — |
| `to` | `string` | Yes | — |
| `includeDetails` | `boolean` | No | — |

Reads all room-type calendars for one property. Input `from` and `to` map to the documented `start` and `end` query parameters; both are required.



**Output:** `object[]`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  user_id?: number,
  property_id?: number,
  room_type_id?: number,
  periods?: {
    start?: string,
    end?: string,
    available?: number,
    bookings?: {
      id: number,
      status?: string | null
    }[] | null,
    channel_calendars?: {
      id: number
    }[] | null,
    closed_period?: {
      id: number
    }
  }[] | null
}[]
```
</Accordion>
</AccordionGroup>

| `available` | `number` | Yes | — |

## Channels

### inventory

`channels.inventory`


| `name` | `string \| null` | No | — |
| `properties` | `object` | No | — |

### send

`messages.send`

Send a message to a guest or thread

**Risk:** `destructive`

```ts
await corsair.lodgify.api.messages.send({
	inboxType: 'booking',
	id: 501,
	message: 'Welcome to your stay!',
	type: 'Owner',
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `inboxType` | `booking \| enquiry` | Yes | — |
| `id` | `number` | Yes | — |
| `message` | `string` | Yes | — |
| `type` | `Owner \| Comment \| Renter` | Yes | — |
| `subject` | `string \| null` | No | — |
| `send_notification` | `boolean` | No | — |
| `message_id` | `string` | No | — |

Sends one v1 message to either a booking or an enquiry. The required `inboxType` selects the documented path; the request body is a one-element array. The API documents a 200 response without a body.



**Output:** `undefined`
