Use **Lodgify** through Corsair: one client, typed API calls.

Lodgify API endpoints require an account API key passed in the `X-ApiKey` header. API access is available on Lodgify Pro and Enterprise tiers. If a key is missing, Corsair throws `AuthMissingError` with a connect link for the caller to display. Guest records are embedded in booking and enquiry operations; Lodgify does not document a standalone guest collection. Webhook payloads are documented, but webhook support is outside this PR's requested scope.

**What you get:**

- 24 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/lodgify better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/lodgify better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/lodgify better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/lodgify better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { lodgify } from '@corsair-dev/lodgify';

export const corsair = createCorsair({
	plugins: [
		lodgify(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Lodgify API key before the first call: `pnpm corsair setup --plugin=lodgify --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
lodgify()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'lodgify',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List properties**

```ts
const tenant = corsair.withTenant('acme');
await tenant.lodgify.api.properties.list({ page: 1, size: 10 });
```


**Create a booking**

```ts
const tenant = corsair.withTenant('acme');
await tenant.lodgify.api.reservations.create({
	property_id: 101,
	arrival: '2026-06-01T00:00:00Z',
	departure: '2026-06-07T00:00:00Z',
	rooms: [{
		room_type_id: 201,
		guest_breakdown: { adults: 2 },
	}],
	guest: {
		guest_name: { first_name: 'Jane', last_name: 'Doe' },
		email: 'jane@example.com',
	},
});
```


See the full list on the [API](/plugins/lodgify/api) page.
