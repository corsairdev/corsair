### search

`attractions.search`

Search attractions (artists, teams, shows) by keyword, classification or source, with paging and sorting

**Risk:** `read`

```ts
await corsair.ticketmaster.api.attractions.search({ keyword: 'coachella', size: 5 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | No | — |
| `keyword` | `string` | No | — |
| `source` | `string` | No | Publishing source, such as 'ticketmaster', 'universe', 'frontgate' or 'tmr'. |
| `locale` | `string` | No | ISO locale, such as 'en-us'. Comma-separated values are allowed; '*' may end the list. |
| `includeTest` | `yes \| no \| only` | No | — |
| `includeFamily` | `yes \| no \| only` | No | — |
| `includeSpellcheck` | `yes \| no` | No | — |
| `classificationName` | `string[]` | No | — |
| `classificationId` | `string[]` | No | — |
| `segmentId` | `string[]` | No | — |
| `genreId` | `string[]` | No | — |
| `subGenreId` | `string[]` | No | — |
| `typeId` | `string[]` | No | — |
| `subTypeId` | `string[]` | No | — |
| `sort` | `string` | No | Field and direction, such as 'name,asc' or 'relevance,desc'. Ticketmaster defaults to relevance,desc. |
| `preferredCountry` | `us \| ca` | No | — |
| `size` | `number` | No | Items per page. Ticketmaster defaults to 20. |
| `page` | `number` | No | 0-based page number. |
| `domain` | `string[]` | No | Only entities available on these domains, such as ticketmaster.com. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `attractions` | `object[]` | Yes | — |
| `page` | `object \| null` | No | — |
| `next_page` | `number \| null` | Yes | The next 0-based page, or null on the last one. Ticketmaster stops at the 1000th item, so this is also null once that limit is reached. |

### search

`venues.search`

Search venues by keyword, country, state or geo point, with paging and sorting

**Risk:** `read`

```ts
await corsair.ticketmaster.api.venues.search({ keyword: 'Madison Square Garden', countryCode: 'US', size: 5 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | No | — |
| `keyword` | `string` | No | — |
| `latlong` | `string` | No | 'latitude,longitude'. Deprecated by Ticketmaster in favour of geoPoint. |
| `geoPoint` | `string` | No | — |
| `radius` | `number` | No | — |
| `unit` | `miles \| km` | No | — |
| `source` | `string` | No | Publishing source, such as 'ticketmaster', 'universe', 'frontgate' or 'tmr'. |
| `locale` | `string` | No | ISO locale, such as 'en-us'. Comma-separated values are allowed; '*' may end the list. |
| `includeTest` | `yes \| no \| only` | No | — |
| `includeSpellcheck` | `yes \| no` | No | — |
| `countryCode` | `string` | No | — |
| `stateCode` | `string` | No | — |
| `sort` | `string` | No | Field and direction, such as 'name,asc' or 'distance,asc'. Ticketmaster defaults to relevance,desc. |
| `preferredCountry` | `us \| ca` | No | — |
| `size` | `number` | No | Items per page. Ticketmaster defaults to 20. |
| `page` | `number` | No | 0-based page number. |
