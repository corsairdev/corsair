Use **Castingwords** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 11 typed API operations
- 6 synced entities (`audiofiles`, `balances`, `invoices`, `orders`, `skus`, `webhooks`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/castingwords
```
```bash yarn
yarn add corsair @corsair-dev/castingwords
```
```bash pnpm
pnpm install corsair @corsair-dev/castingwords
```
```bash bun
bun add corsair @corsair-dev/castingwords
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { castingwords } from '@corsair-dev/castingwords';

export const corsair = createCorsair({
	multiTenancy: true,
	plugins: [
		castingwords(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
castingwords()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'castingwords',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`audiofile.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.castingwords.api.audiofile.get({});
```


**`order.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.castingwords.api.order.create({});
```


See the full list on the [API](/plugins/castingwords/api) page.

## Query synced data

Synced entities support `tenant.castingwords.db.<entity>.search()` and `.list()`: `audiofiles`, `balances`, `invoices`, `orders`, `skus`, `webhooks`.

See [Database](/plugins/castingwords/database) for filters and operators.
