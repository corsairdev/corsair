The Bookingmood plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/bookingmood/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `events`
  - `bookingCreated` (`events.bookingCreated`)
  - `bookingDeleted` (`events.bookingDeleted`)
  - `bookingUpdated` (`events.bookingUpdated`)
  - `productCreated` (`events.productCreated`)
  - `productUpdated` (`events.productUpdated`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    const body = await request.json();
    const result = await processWebhook(corsair, headers, body);
    return result.response;
}
```

## Events

## Events

### Booking Created

`events.bookingCreated`

Triggered when a booking is created

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `booking.created` | Yes | — |
| `created_at` | `string` | No | — |
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  id: string,
  product_id?: string,
  start_date?: string,
  end_date?: string,
  status?: string
}
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  type: booking.created,
  created_at?: string,
  data: {
    id: string,
    product_id?: string,
    start_date?: string,
    end_date?: string,
    status?: string
  }
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
bookingmood({
    webhookHooks: {
        events: {
            bookingCreated: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
