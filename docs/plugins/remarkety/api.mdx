## Campaigns

### create

`campaigns.create`

Create a campaign from a type and its actions, each an email or an api webhook with the rules that decide when it runs

**Risk:** `write`

```ts
await corsair.remarkety.api.campaigns.create({ storeId: 'AbC123xy', type: 'TRIGGER_CART_RECOVERY', mode: 'stop', actions: [{ type: 'email', subject: 'Your cart misses you', baseTemplate: '<html></html>', rules: [{ type: 'CART_FOLLOWUP_TIME', operator: 'is', value: '60' }] }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `storeId` | `string \| number` | Yes | The store ID from Settings &gt; API Keys (a short string such as AbC123xy), or the numeric store id. |
| `type` | `string` | Yes | A campaign type from campaigns.types. |
| `actions` | `object[]` | Yes | The action this campaign runs. This API version takes exactly one. |
| `mode` | `run \| test \| stop` | No | run starts it, test sends a sample to testEmail, stop halts it. Defaults to Remarkety's own choice. |
| `testEmail` | `string` | No | Where a test send goes, when mode is test. |

<AccordionGroup>
<Accordion title="actions full type">

```ts
{
  type: email | api,
  webhook?: string,
  subject?: string,
  baseTemplate?: string,
  rules: {
    type: string,
    operator: string,
    value: string
  }[]
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number \| null` | No | — |
| `type` | `string \| null` | No | — |
| `actions` | `Record<string, JsonValue>[] \| null` | No | — |
| `mode` | `string \| null` | No | run, test or stop. |
| `testEmail` | `string \| null` | No | — |

## Contacts

### create

`contacts.create`

Create or update a contact in a store; Remarkety emails a double opt-in request unless doubleOptin is false

**Risk:** `write`

```ts
await corsair.remarkety.api.contacts.create({ storeId: 'AbC123xy', email: 'jane@example.com', firstName: 'Jane', tags: ['vip'], allowedMarketing: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `storeId` | `string \| number` | Yes | The store ID from Settings &gt; API Keys (a short string such as AbC123xy), or the numeric store id. |
| `email` | `string` | Yes | — |
| `firstName` | `string` | No | — |
| `lastName` | `string` | No | — |
| `tags` | `string[]` | No | — |
| `properties` | `Record<string, JsonValue>` | No | Custom contact properties as one object, such as &#123; country: "US", city: "Austin", rewardsPoints: 100 &#125;. Remarkety refuses an array. |
| `doubleOptin` | `boolean` | No | Remarkety defaults this to true, which emails the contact a confirmation request before they can be marketed to. Pass false to add the contact without that email. |
| `allowedMarketing` | `boolean` | No | True marks the contact as marketing-allowed. |



**Output:** _empty object_


---

| `apiKey` | `string \| null` | No | The store's own sync key. |
