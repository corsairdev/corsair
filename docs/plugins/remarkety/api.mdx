## Campaigns

### create

`campaigns.create`

Create a campaign from a type and its actions, each an email or an api webhook with the rules that decide when it runs

**Risk:** `write`

```ts
await corsair.remarkety.api.campaigns.create({ storeId: 1, type: 'abandoned-cart', mode: 'stop', actions: [{ type: 'email', subject: 'Your cart misses you', baseTemplate: '<html></html>', rules: [{ type: 'delay', operator: 'eq', value: '1' }] }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `storeId` | `number` | Yes | The store ID, which the store routes are scoped to. |
| `type` | `string` | Yes | A campaign type from campaigns.types. |
| `actions` | `object[]` | Yes | The actions this campaign runs. This endpoint version expects exactly one. |
| `mode` | `run \| test \| stop` | No | run starts it, test sends a sample to testEmail, stop halts it. Defaults to Remarkety's own choice. |
| `testEmail` | `string` | No | Where a test send goes, when mode is test. |

<AccordionGroup>
<Accordion title="actions full type">

```ts
{
  type: email | api,
  webhook?: string,
  subject?: string,
  baseTemplate?: string,
  rules: {
    type: string,
    operator: string,
    value: string
  }[]
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number \| null` | No | — |
| `type` | `string \| null` | No | — |
| `actions` | `Record<string, JsonValue>[] \| null` | No | — |
| `mode` | `string \| null` | No | run, test or stop. |
| `testEmail` | `string \| null` | No | — |

## Contacts

### create

**Risk:** `write`

```ts

```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `storeId` | `number` | Yes | The store ID, which the store routes are scoped to. |
| `email` | `string` | Yes | — |
| `firstName` | `string` | No | — |
| `lastName` | `string` | No | — |
| `tags` | `string[]` | No | — |
| `properties` | `Record<string, JsonValue>[]` | No | Custom contact properties, as name/value objects. |
| `doubleOptin` | `boolean` | No | True sends the contact a confirmation email from Remarkety before they can be marketed to. |
| `allowedMarketing` | `boolean` | No | True marks the contact as marketing-allowed. |
