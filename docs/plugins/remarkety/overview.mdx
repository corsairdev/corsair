Use **Remarkety** through Corsair: one client, typed API calls.

The token comes from your Remarkety account and goes in the `X-Token` header. The API also accepts `token` as a query parameter, but the plugin never uses it: a key in a URL is logged by every proxy.

**`Accept: application/json` is load-bearing.** Sent without it, a failed call comes back as an HTML login page instead of the JSON error `{"message":"Missing or invalid API Key","status":"ERROR","guid":"…"}`. The plugin always sends it, and it keeps the `guid` on the error because that is what support asks for.

**Building a campaign takes three reads first:**

- **`rules.list`** gives every rule type with its `operators`, `possibleValues` and `defaultValue`. A campaign action's `rules` must use those exact operator strings.
- **`campaigns.types`** gives the campaign types the store supports and what each needs.
- **`emailTemplates.preview`** gives the data a template merges against — and passing a real `shopper` or `order` ID shows exactly what that customer's mail would contain.

Things worth knowing before a write:

- **`stores.create` and `stores.update` carry a *different* secret.** The `apiKey` there is the key Remarkety uses to sync that store; it is not the token this plugin authenticates with.
- **`stores.update` is `PUT /stores` with the id in the body**, not `PUT /stores/{id}`. The same is true of `campaigns.update`, which is `PUT /stores/{storeId}/campaigns`.
- **`mode` decides whether a campaign sends.** `run` starts it contacting shoppers, `test` sends a sample to `testEmail`, and `stop` halts it. Check the current mode with `campaigns.get` before updating, and remember a `stop` is the safe state to build in.
- **An email action needs a subject and a `baseTemplate`; an api action needs a `webhook`.** The plugin rejects either omission rather than creating a campaign Remarkety cannot run. This endpoint version expects exactly one action.
- **Stats report revenue twice.** `totalOrdersUSD` is normalised to dollars and `totalOrders` is in the store's own currency, so the numbers differ whenever the store is not priced in USD.
- **`stores.status` is the sync health check.** `syncLastError` is populated only when `syncStatus` is `ERROR`, so a nil error on any other status means nothing.
- **Deleting a store is destructive and final.** There is no archive state, and a store's campaigns and contacts go with it.

**What you get:**

- 23 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/remarkety better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/remarkety better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/remarkety better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/remarkety better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { remarkety } from '@corsair-dev/remarkety';

export const corsair = createCorsair({
	plugins: [
		remarkety(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
remarkety()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'remarkety',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read campaign performance**

```ts
const tenant = corsair.withTenant('acme');
await tenant.remarkety.api.campaigns.stats({ storeId: 1 });
```


**Create a contact with marketing permission**

```ts
const tenant = corsair.withTenant('acme');
await tenant.remarkety.api.contacts.create({
	storeId: 1,
	email: 'jane@example.com',
	firstName: 'Jane',
	allowedMarketing: true,
});
```


See the full list on the [API](/plugins/remarkety/api) page.
