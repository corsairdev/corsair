Use **Browse AI** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 10 typed API operations
- 6 synced entities (`bulkRun`, `monitor`, `robot`, `robotTask`, `systemStatus`, `webhook`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/browseai
```
```bash yarn
yarn add corsair @corsair-dev/browseai
```
```bash pnpm
pnpm install corsair @corsair-dev/browseai
```
```bash bun
bun add corsair @corsair-dev/browseai
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { browseai } from '@corsair-dev/browseai';

export const corsair = createCorsair({
	plugins: [
		browseai(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
browseai()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'browseai',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`robots.list`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.browseai.api.robots.list({});
```


**`monitors.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.browseai.api.monitors.create({});
```


See the full list on the [API](/plugins/browseai/api) page.

## Query synced data

Synced entities support `tenant.browseai.db.<entity>.search()` and `.list()`: `bulkRun`, `monitor`, `robot`, `robotTask`, `systemStatus`, `webhook`.

See [Database](/plugins/browseai/database) for filters and operators.
