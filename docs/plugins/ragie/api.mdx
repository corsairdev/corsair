## Connections

### create

`connections.create`

Create a non-OAuth connector such as S3, GCS, Freshdesk, Zendesk, Intercom or a web crawler, with its settings and credentials

**Risk:** `write`

```ts
await corsair.ragie.api.connections.create({ connection: { provider: 'gcs', data: { bucket: 'acme-docs' }, credentials: { service_account_json: '...' } } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `connection` | `object` | Yes | — |
| `partition_strategy` | `Record<string, unknown>` | No | How ingested files land in partitions. |
| `page_limit` | `number \| null` | No | Monthly page cap for this connection. |

The path is singular: POST /connection, while every other connection route is plural. Non-OAuth providers only.

### delete

`connections.delete`

Delete a connection. With keep_files false its documents are deleted too and cannot be recovered; with true the documents survive unlinked

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.ragie.api.connections.delete({ connection_id: 'f83f5c92-1fae-4a37-8f3e-23914e2b9c1d', keep_files: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `connection_id` | `string` | Yes | — |
| `keep_files` | `boolean` | Yes | Keep the ingested documents when the connection is removed. With false every document from this connection is deleted and cannot be recovered. |

A POST to /connections/&#123;id&#125;/delete, not a DELETE method. With keep_files false the documents are deleted irreversibly; deletion runs asynchronously, so files can linger briefly either way.



**Output:** `Record<string, string>`
