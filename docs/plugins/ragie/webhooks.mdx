The Ragie plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/ragie/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `connections`
  - `limitExceeded` (`connections.limitExceeded`)
  - `syncFinished` (`connections.syncFinished`)
  - `syncProgress` (`connections.syncProgress`)
  - `syncStarted` (`connections.syncStarted`)
- `documents`
  - `deleted` (`documents.deleted`)
  - `statusUpdated` (`documents.statusUpdated`)
- `entities`
  - `extracted` (`entities.extracted`)
- `partitions`
  - `limitExceeded` (`partitions.limitExceeded`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Events

## Connections

### Limit Exceeded

`connections.limitExceeded`

A connection reached its page limit and stopped syncing

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `connection_limit_exceeded` | Yes | — |
| `payload` | `object` | Yes | — |
| `nonce` | `string` | Yes | — |

<AccordionGroup>
<Accordion title="payload full type">

```ts
{
  connection_id: string,
  partition?: string | null,
  connection_metadata?: Record<string, any>
}
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  type: connection_limit_exceeded,
  payload: {
    connection_id: string,
    partition?: string | null,
    connection_metadata?: Record<string, any>
  },
  nonce: string
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
ragie({
    webhookHooks: {
        connections: {
            limitExceeded: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
