Use **AgentQL** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 4 typed API operations
- 4 synced entities (`accountUsage`, `browserSessions`, `documentQueryResults`, `queryResults`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/agentql
```
```bash yarn
yarn add corsair @corsair-dev/agentql
```
```bash pnpm
pnpm install corsair @corsair-dev/agentql
```
```bash bun
bun add corsair @corsair-dev/agentql
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { agentql } from '@corsair-dev/agentql';

export const corsair = createCorsair({
	plugins: [
		agentql(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
agentql()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'agentql',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`data.query`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.agentql.api.data.query({});
```


**`browserSessions.createRemoteBrowserSession`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.agentql.api.browserSessions.createRemoteBrowserSession({});
```


See the full list on the [API](/plugins/agentql/api) page.

## Query synced data

Synced entities support `tenant.agentql.db.<entity>.search()` and `.list()`: `accountUsage`, `browserSessions`, `documentQueryResults`, `queryResults`.

See [Database](/plugins/agentql/database) for filters and operators.
