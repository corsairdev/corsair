### delete

`contacts.delete`

Delete a contact (DEFAULT or GDPR); cannot be undone

**Risk:** `destructive`

```ts
await corsair.piggy.api.contacts.delete({ contactUuid: "1b7e3c4a-5f2d-4e8b-9a6c-0d2f4e6a8b1c", type: "GDPR" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contactUuid` | `string` | Yes | The contact UUID |
| `type` | `DEFAULT \| GDPR` | Yes | DEFAULT keeps a detailed log; GDPR removes personal data references |

Schedules the removal; DEFAULT keeps a detailed log and GDPR removes personal data references. Cannot be undone.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `null \| null` | No | Piggy answers with a null data value |
| `meta` | `any` | No | — |

### list

List contacts with paging, date and attribute filters

**Risk:** `read`

```ts

```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | Records per page (default 10, max 100) |
| `page` | `number` | No | Page number (default 1) |
| `sort` | `created_at \| -created_at` | No | Sort field; prefix - for descending |
| `createdAtGt` | `string` | No | created_at after this ISO 8601 value |
| `createdAtGte` | `string` | No | created_at at or after this ISO 8601 value |
| `createdAtLt` | `string` | No | created_at before this ISO 8601 value |
| `createdAtLte` | `string` | No | created_at at or before this ISO 8601 value |

Attribute filters ride through attributesQuery with Piggy bracketed parameter names, e.g. "attributes[visits][gte]": 10 or "attributes[likes_pizza]": true; a contact must match every filter.

### merge

`contacts.merge`

Merge a source contact into a destination contact; cannot be undone

**Risk:** `destructive`

```ts
await corsair.piggy.api.contacts.merge({ sourceContactUuid: "cd183615-d1cb-402a-b618-6472d5e13890", destinationContactUuid: "1b7e3c4a-5f2d-4e8b-9a6c-0d2f4e6a8b1c" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `sourceContactUuid` | `string` | Yes | UUID of the contact that ceases to exist |
| `destinationContactUuid` | `string` | Yes | UUID of the contact that remains |

The source contact ceases to exist and the merge cannot be undone; verify both emails belong to the same person first.



**Output:** _empty object_
