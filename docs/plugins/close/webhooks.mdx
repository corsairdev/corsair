The Close plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/close/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `activityNote`
  - `created` (`activityNote.created`)
- `contact`
  - `created` (`contact.created`)
- `lead`
  - `created` (`lead.created`)
  - `updated` (`lead.updated`)
- `opportunity`
  - `created` (`opportunity.created`)
- `task`
  - `created` (`task.created`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    const body = await request.json();
    const result = await processWebhook(corsair, headers, body);
    return result.response;
}
```

## Events

## Activity Note

### Created

`activityNote.created`

A note activity was created in Close CRM

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event_type` | `activity.note.created` | Yes | — |
| `organization_id` | `string` | No | — |
| `object_type` | `string` | No | — |
| `action` | `string` | No | — |
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  id: string,
  lead_id?: string,
  note?: string,
  user_id?: string | null,
  organization_id?: string,
  date_created?: string,
  date_updated?: string
}
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  event_type: activity.note.created,
  organization_id?: string,
  object_type?: string,
  action?: string,
  data: {
    id: string,
    lead_id?: string,
    note?: string,
    user_id?: string | null,
    organization_id?: string,
    date_created?: string,
    date_updated?: string
  }
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
close({
    webhookHooks: {
        activityNote: {
            created: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
