Use **Close** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 31 typed API operations
- 10 synced entities (`activityCall`, `activityEmail`, `activityNote`, `activitySms`, `contact`, `customField`, and 4 more) for fast `.search()` / `.list()`
- 6 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/close better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/close better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/close better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/close better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { close } from '@corsair-dev/close';

export const corsair = createCorsair({
	plugins: [
		close(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Close API key before the first call: `pnpm corsair setup --plugin=close --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
close()
```

More: [API Key](/concepts/api-key)

</Tab>
<Tab title="OAuth 2.0">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Close OAuth app.

```ts
close({
	authType: 'oauth_2',
})
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'close',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List leads**

```ts
const tenant = corsair.withTenant('acme');
await tenant.close.api.leads.list({});
```


**Create a lead**

```ts
const tenant = corsair.withTenant('acme');
await tenant.close.api.leads.create({ name: 'Acme Inc.' });
```


See the full list on the [API](/plugins/close/api) page.

## Query synced data

This table exists, but Close calls don't fill it yet. This returns only rows you have written yourself.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.close.db.lead.search({
	data: {},
	limit: 50,
});
```

Synced entities: `activityCall`, `activityEmail`, `activityNote`, `activitySms`, `contact`, `customField`, `lead`, `opportunity`, `task`, `user`. See [Database](/plugins/close/database) for filters and operators.

## Webhooks

Fires when a lead is created.

```ts
close({
    webhookHooks: {
        lead: {
            created: {
                after: async (ctx, result) => {
                    console.log('Close lead created:', result.data);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/close/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
