## Account

### getBalance

`account.getBalance`

Read the account's current Lob Credits balance

**Risk:** `read`

```ts
await corsair.lob.api.account.getBalance({});
```

**Input:** _empty object_

Returns the Lob Credits balance; it can be negative.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `balance` | `number` | Yes | The account's Lob Credits balance. |

## Addresses

### create

`addresses.create`

Create a US or international address in the Lob address book for reuse as a mail to or from address

**Risk:** `write`

```ts
await corsair.lob.api.addresses.create({ name: 'Jordan Lee', address_line1: '210 King St Ste 6100', address_city: 'San Francisco', address_state: 'CA', address_zip: '94107-1741' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | — |
| `company` | `string` | No | — |
| `phone` | `string` | No | — |
| `email` | `string` | No | — |
| `address_line1` | `string` | Yes | Street address. Up to 64 characters for US addresses. |
| `address_line2` | `string` | No | — |
| `address_city` | `string` | No | — |
| `address_state` | `string` | No | — |
| `address_zip` | `string` | No | — |
| `address_country` | `string` | No | Two-letter ISO country code. Omit or pass 'US' for a US address. |

Lob requires `name` or `company` (at least one). Omitting `address_country` means US, which requires the city, two-letter state and a US ZIP.

### delete

`addresses.delete`

Permanently delete an address book entry. Lob marks it deleted and does not restore it

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.lob.api.addresses.delete({ id: 'adr_d0c7d5ac3f7e6b4' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The address's ID, prefixed with adr_. |

Marks the entry deleted. Lob does not restore it, and mail already queued to that address still processes.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `deleted` | `boolean \| null` | No | — |

### list

Page through the address book with before/after cursors, optional metadata and date filters

**Risk:** `read`

```ts
await corsair.lob.api.addresses.list({ limit: 20, include: ['total_count'], after: 'adr_d0c7d5ac3f7e6b4' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | Rows per page, 1-100. Defaults to 10. |

| `date_created` | `object` | No | ISO 8601 bounds on the creation timestamp. |
| `metadata` | `Record<string, string>` | No | Only rows whose metadata carries every given key and value. |

Page with `before` or `after` (never both), up to 100 rows. `total_count` arrives only when you pass `include: ['total_count']`.

## Autocomplete

### usAutocomplete

`autocomplete.usAutocomplete`

Complete a partial US address into up to 10 suggestion lines, optionally restricted to deliverable addresses

**Risk:** `read`

```ts
await corsair.lob.api.autocomplete.usAutocomplete({ address_prefix: '185 Industrial P', valid_addresses: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `address_prefix` | `string` | Yes | Partial primary line to complete, such as '185 Industrial P'. |
| `city` | `string` | No | — |
| `state` | `string` | No | — |
| `zip_code` | `string` | No | — |
| `geo_ip_sort` | `boolean` | No | True to rank suggestions by distance to the caller IP; needs the X-Forwarded-For header Lob documents, which this plugin does not send. |
| `case` | `upper \| proper` | No | Casing of the returned address lines: 'upper' (default) or 'proper'. |
| `valid_addresses` | `boolean` | No | True to return only deliverable addresses. |

`geo_ip_sort` ranks by caller IP; the plugin does not send the `X-Forwarded-For` header Lob uses to pass the end user IP through.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `suggestions` | `object[]` | Yes | Up to 10 completed address lines. |
| `object` | `string \| null` | No | — |

<AccordionGroup>
<Accordion title="suggestions full type">

```ts
{
  primary_line: string,
  city: string,
  state: string,
  zip_code: string,
  object?: string | null
}[]
```

### send

`letters.send`

Send a real letter that Lob prints, stuffs and mails. Each piece is billed and cannot be recalled once in production; pass an idempotency_key so a replay returns the original instead of mailing twice

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.lob.api.letters.send({ to: 'adr_210a8d4b0b76d77b', from: 'adr_fa64eaa6b3f335', file: '<html>Invoice 1234 due Friday</html>', color: false, use_type: 'operational', idempotency_key: 'invoice-1234' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `to` | `string \| object` | Yes | Recipient: an address ID (adr_...) or an inline address. |
| `from` | `string \| object` | Yes | Return address: an address ID (adr_...) or an inline address. |
| `file` | `string \| string \| string` | Yes | HTML string (up to 10000 characters), tmpl_... template ID, or an https URL to an html, pdf, png or jpg file. |
| `color` | `boolean` | Yes | Print in color. Lob requires this field; it defaults to false when omitted server-side. |
| `extra_service` | `certified \| certified_return_receipt \| registered \| null` | No | Adds USPS tracking; certified and registered add fees. |
| `double_sided` | `boolean` | No | Print on both sides of the paper. Defaults to true. |
| `address_placement` | `top_first_page \| insert_blank_page \| bottom_first_page_center \| bottom_first_page` | No | Where the address window sits. Defaults to 'top_first_page'. |
| `size` | `us_letter \| us_legal` | No | Paper size. Defaults to 'us_letter'; only accepted with Lob-Version 2024-01-01 or newer. |
| `use_type` | `marketing \| operational \| null` | Yes | The send's purpose for Lob's mail-use tracking: 'marketing' or 'operational'. Pass null for personal correspondence. |
| `mail_type` | `usps_first_class \| usps_standard` | No | Postage class. Defaults to 'usps_first_class'. |
| `merge_variables` | `Record<string, any> \| null` | No | Per-mailpiece template variables, keyed by merge variable name. |
| `send_date` | `string` | No | ISO 8601 date (2026-01-01) or datetime; Lob schedules production after it, up to 180 days out. |
| `description` | `string` | No | — |
| `metadata` | `Record<string, string>` | No | — |
| `idempotency_key` | `string` | No | Deduplication key, at most 256 characters. Lob replays within 24 hours return the original mailpiece instead of creating a duplicate. |

Bills a physical mailpiece. `color` is required by Lob (defaults to false server-side). `extra_service` adds certified or registered tracking and its fees. With an `idempotency_key`, replays within 24 hours return the original piece.
