## Events

### conversion

`events.conversion`

Log a named conversion with optional revenue and metadata against a user, device or install id

**Risk:** `write`

```ts
await corsair.radar.api.events.conversion({ name: 'in_app_purchase', user_id: 'user-1', revenue: 499 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | A generic name, such as `in_app_purchase`. |
| `user_id` | `string` | No | — |
| `device_id` | `string` | No | — |
| `install_id` | `string` | No | — |
| `revenue` | `number` | No | — |
| `created_at` | `string` | No | — |
| `metadata` | `Record<string, string \| number \| boolean>` | No | — |

The name may only contain letters, digits and underscores, and one identifier is required.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event` | `object` | Yes | — |

## Geocode

### forward

`geocode.forward`

Turn an address into coordinates, returning every match with its layer and confidence

**Risk:** `read`

```ts
await corsair.radar.api.geocode.forward({ query: '20 Jay Street, Brooklyn', layers: ['address'], country: ['US'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | The address to geocode. |
| `layers` | `(place \| address \| postalCode \| locality \| county \| state \| country \| coarse \| fine)[]` | No | Layer filters, sent comma-separated. `coarse` covers every admin layer and `fine` the address and place layers. |
| `country` | `string[]` | No | Two-letter country codes to restrict the search to. |
| `lang` | `ar \| de \| en \| es \| fr \| it \| ja \| ko \| nl \| pt \| ru \| zh` | No | — |

Layers and countries are comma-separated on the wire; the confidence is `exact`, `interpolated` or `fallback`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `addresses` | `object[]` | Yes | — |

**Input**

| `metadata` | `Record<string, string \| number \| boolean>` | No | — |
