## Bookings

### create

`bookings.create`

Create a new resource schedule booking

**Risk:** `write`

```ts
await corsair.hubplanner.api.bookings.create({
	resource: '5ba09b645ff58f149a2c2222',
	project: '5ba09b645ff58f149a2cf521',
	start: '2026-12-01',
	end: '2026-12-05',
	title: 'Sprint Planning',
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `resource` | `string` | Yes | — |
| `project` | `string` | Yes | — |
| `start` | `string` | Yes | — |
| `end` | `string` | Yes | — |
| `state` | `string` | No | — |
| `stateValue` | `number` | No | — |
| `title` | `string` | No | — |
| `note` | `string` | No | — |
| `allDay` | `boolean` | No | — |
| `allowOverschedule` | `boolean` | No | — |
| `repeat` | `boolean` | No | — |
| `interval` | `string` | No | — |
| `repeatEndsAfterTimes` | `number` | No | — |
| `repeatEndsOnDate` | `string` | No | — |

Requires `resource`, `project`, `start`, and `end` dates (YYYY-MM-DD). Use `allowOverschedule: true` to bypass schedule warning thresholds.



**Output**

|------|------|----------|-------------|
| `_id` | `string` | Yes | — |
