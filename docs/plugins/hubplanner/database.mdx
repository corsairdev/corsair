---
title: "Hub Planner database"
sidebarTitle: "Database"
description: "The Hub Planner plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Hub Planner. To read its data, call the [API operations](/plugins/hubplanner/api), which return what Hub Planner has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
