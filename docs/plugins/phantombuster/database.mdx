---
title: "PhantomBuster database"
sidebarTitle: "Database"
description: "The PhantomBuster plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for PhantomBuster. To read its data, call the [API operations](/plugins/phantombuster/api), which return what PhantomBuster has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
