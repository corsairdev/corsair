Use **Epic Games** through Corsair: one client, typed API calls, optional local DB sync.

**What you get:**

- 28 typed API operations
- 1 database entity synced for fast `.search()` / `.list()` queries

## Setup

<Steps>

<Step title="Install">
```bash
pnpm install @corsair-dev/epicgames
```

</Step>

<Step title="Add the plugin">
<Tabs>
<Tab title="Solo">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { epicgames } from '@corsair-dev/epicgames';

export const corsair = createCorsair({
	// ... other config options,
	multiTenancy: false,
    plugins: [epicgames()],
});
```
</Tab>
<Tab title="Multi-Tenant">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { epicgames } from '@corsair-dev/epicgames';

export const corsair = createCorsair({
	// ... other config options,
    multiTenancy: true,
    plugins: [epicgames()],
});
```

See [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Tab>
</Tabs>

</Step>

<Step title="Get credentials">
Follow [Get Credentials](/plugins/epicgames/get-credentials) if you need help getting keys.

</Step>

<Step title="Store credentials">
<Tabs>
<Tab title="Solo">
```bash
pnpm corsair setup --plugin=epicgames
```

Use the key names documented in [Get Credentials](/plugins/epicgames/get-credentials) (for example `api_key=`, `bot_token=`, or OAuth client fields).
</Tab>
<Tab title="Multi-Tenant">
```bash
pnpm corsair setup --plugin=epicgames --tenant=<tenantId>
```

Store per-tenant secrets after you create the tenant record. See [Multi-tenancy](/concepts/multi-tenancy).
</Tab>
</Tabs>

</Step>

</Steps>

## Authentication

Each tab shows how to register the plugin for that authentication method. The default `authType` from the plugin does not need to appear in the factory call.

<Tabs>
<Tab title="OAuth 2.0 (Default)">

```ts corsair.ts
epicgames()
```

Store credentials with `pnpm corsair setup --plugin=epicgames` (see [Get Credentials](/plugins/epicgames/get-credentials) for field names). For OAuth, you typically store integration keys at the provider level and tokens per account or tenant.

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>


## Query synced data

Synced entities support `corsair.epicgames.db.<entity>.search()` and `.list()`. See [Database](/plugins/epicgames/database) for filters and operators.


## Example API calls

**Read-style (read):** `islands.get`

```ts
await corsair.epicgames.api.islands.get({});
```


**Write-style (write):** `remote.batch`

```ts
await corsair.epicgames.api.remote.batch({});
```


See the full list on the [API](/plugins/epicgames/api) page. Use `pnpm corsair list --plugin=epicgames` and `pnpm corsair schema <path>` locally to inspect schemas.
