## Islands

`islands.get`

Get metadata for a Fortnite island by code

**Risk:** `read`

```ts
await corsair.epicgames.api.islands.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `code` | `string` | Yes | — |



**Output:** `Record<string, any>`
