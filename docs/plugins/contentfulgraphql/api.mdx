## Get Cma Token

### getCmaToken

`getCmaToken`

Get the stored Contentful access token, space ID, and environment ID

**Risk:** `read`

```ts
await corsair.contentfulgraphql.api.getCmaToken({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `space_id` | `string` | Yes | — |
| `environment_id` | `string` | No | — |
