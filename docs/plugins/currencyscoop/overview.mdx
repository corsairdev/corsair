Use **CurrencyScoop** through Corsair: one client, typed API calls, local DB sync.

CurrencyScoop now answers on https://api.currencybeacon.com/v1. GET /v1/latest with an empty api_key returned HTTP 401, error_type "auth failed". The same 401 came back from api.currencyscoop.com. The key is a query parameter and is not written to the event. A conversion is returned and not stored.

**What you get:**

- 5 typed API operations
- 2 synced entities (`currencies`, `quotes`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/currencyscoop better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/currencyscoop better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/currencyscoop better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/currencyscoop better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { currencyscoop } from '@corsair-dev/currencyscoop';

export const corsair = createCorsair({
	plugins: [
		currencyscoop(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the CurrencyScoop API key before the first call: `pnpm corsair setup --plugin=currencyscoop --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
currencyscoop()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'currencyscoop',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Latest rates**

```ts
const tenant = corsair.withTenant('acme');
await tenant.currencyscoop.api.quotes.latest({ base: 'USD', symbols: 'EUR' });
```

_No write-style endpoint inferred; pick any operation from the [API](/plugins/currencyscoop/api) reference._

## Query synced data

Synced entities support `tenant.currencyscoop.db.<entity>.search()` and `.list()`: `currencies`, `quotes`.

See [Database](/plugins/currencyscoop/database) for filters and operators.
