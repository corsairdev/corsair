## Currencies

### list

`currencies.list`

List supported CurrencyBeacon currency codes.

**Risk:** `read`

```ts
await corsair.currencyscoop.api.currencies.list({});
```

**Input:** _empty object_

GET /currencies. A row is stored when short_code is present.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `currencies` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="currencies full type">

```ts
{
  id: string,
  name?: string,
  symbol?: string
}[]
```
</Accordion>
</AccordionGroup>

## Quotes

### convert

`quotes.convert`

Convert an amount between two currencies.

**Risk:** `read`

```ts
await corsair.currencyscoop.api.quotes.convert({ from: 'USD', to: 'EUR', amount: 1 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `from` | `string` | Yes | — |
| `to` | `string` | Yes | — |
| `amount` | `number` | Yes | — |
| `date` | `string` | No | — |

GET /convert. Returns from, to, amount, value, and date. Nothing is stored.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `from` | `string` | Yes | — |
| `to` | `string` | Yes | — |
| `amount` | `number` | Yes | — |
| `value` | `number` | Yes | — |
| `date` | `string` | Yes | — |

### historical

`quotes.historical`

Read mid-market rates for one date.

**Risk:** `read`

```ts
await corsair.currencyscoop.api.quotes.historical({ date: '2024-01-01', base: 'USD' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `base` | `string` | No | — |
| `symbols` | `string` | No | — |
| `date` | `string` | Yes | — |

GET /historical. date is required. The stored row matches latest.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `quotes` | `object[]` | Yes | — |

<Accordion title="quotes full type">

```ts
{

  base: string,
  code: string,
  rate: number
}[]
```
</Accordion>

### timeseries

`quotes.timeseries`

Read daily rates between two dates.

**Risk:** `read`

```ts
await corsair.currencyscoop.api.quotes.timeseries({ start_date: '2024-01-01', end_date: '2024-01-02', base: 'USD' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `base` | `string` | No | — |
| `symbols` | `string` | No | — |
| `start_date` | `string` | Yes | — |
| `end_date` | `string` | Yes | — |

GET /timeseries. The API lists rates by date under response with no base, so the stored base is the one you asked for (USD when omitted). Stores one quote per date and currency code.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `quotes` | `object[]` | Yes | — |

<Accordion title="quotes full type">

```ts

  base: string,
  code: string,
  rate: number
}[]
```
</Accordion>
</AccordionGroup>
