## Get your Ambient Weather keys

<Steps>

<Step title="Open your Ambient Weather account">
Go to [ambientweather.net](https://ambientweather.net) and sign in to your account.
</Step>

<Step title="Open Account Settings">
From your account menu, open **Account Settings**.
</Step>

<Step title="Find API Keys">
Scroll to the **API Keys** section.
</Step>

<Step title="Create an API key">
Create an API key. This is your `apiKey`.
</Step>

<Step title="Create an Application key">
Create an Application key. This is your `applicationKey`, and you need one per app you build.
</Step>

<Step title="Store in Corsair">
Use these credential field names with `pnpm corsair setup`:

```bash
pnpm corsair setup --plugin=ambientweather api_key=your-api-key application_key=your-application-key
```
</Step>

</Steps>

Both fields are required. Neither expires or needs refresh.
