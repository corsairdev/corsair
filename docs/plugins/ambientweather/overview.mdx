---

Use **Ambient Weather** through Corsair: one client, typed API calls, and no webhook surface.

**What you get:**

- 2 typed API operations
- 0 webhook event types
- No OAuth

## Setup

<Steps>

<Step title="Install">
```bash
pnpm install @corsair-dev/ambientweather
```
</Step>

<Step title="Add the plugin">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { ambientweather } from '@corsair-dev/ambientweather';

export const corsair = createCorsair({
	// ... other config options,
	plugins: [ambientweather()],
});
```
</Step>

<Step title="Store credentials">
```bash
pnpm corsair setup --plugin=ambientweather api_key=<your-ambient-api-key> application_key=<your-application-key>
```
</Step>

</Steps>

## Authentication

<Tabs>
<Tab title="API Key (Default)">

Ambient Weather uses API key auth, not OAuth. Corsair sends both `apiKey` and `applicationKey` as query parameters on every request. There is no redirect flow and no token refresh flow.

```ts corsair.ts
ambientweather()
```

</Tab>
</Tabs>

## Example API calls

**List stations**

```ts
const stations = await corsair.ambientweather.api.devices.list();
```

**Fetch station history**

```ts
const history = await corsair.ambientweather.api.devices.getData({
	macAddress: 'AA:BB:CC:DD:EE:FF',
	limit: 24,
});
```
