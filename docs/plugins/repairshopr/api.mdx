## Contacts

### list

`contacts.list`

List contact people, optionally for one customer

**Risk:** `read`

```ts
await corsair.repairshopr.api.contacts.list({ customer_id: 1 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | 1-based page number. |
| `customer_id` | `number` | No | — |
