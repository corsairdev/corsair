## Google

### ads

`google.ads`

List a company's Google ads from Google's Ad Transparency report by domain, filtered by media type and country, with a continuation token per page

**Risk:** `read`

```ts
await corsair.adyntel.api.google.ads({ company_domain: 'clay.com', country_code: 'FR' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `company_domain` | `string` | Yes | The bare domain, without `https://` or `www.`. |
| `media_type` | `text \| image \| video \| all` | No | Defaults to `all`. Anything unrecognised is also treated as `all` rather than rejected, so a typo silently widens the result. |
| `country_code` | `string` | No | One country per call; a list is rejected. Leave it out, or send `anywhere`, for worldwide results. Send the same code again with every `continuation_token`. |
| `continuation_token` | `string` | No | `continuation_token` from the previous response. |
| `extract_text` | `boolean` | No | Extracts the text inside each creative for one extra credit. The docs table spells it `extract-text`; the OpenAPI spec and this plugin use `extract_text`. |
| `all_ads` | `boolean` | No | Needs `webhook_url`. One credit per page and cannot be stopped. |
| `webhook_url` | `string` | No | Adyntel POSTs the results here when the scrape finishes, instead of returning them. You host and receive that POST; this plugin does not. |
| `data_provider` | `'rapidapi' \| 'apify'` | No | Which scraping backend runs the call. Leave it unset to use Adyntel's default. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string` | No | `job started` when a job was queued. |
| `jobId` | `string` | No | Track via `GET /track/jobs`. |
| `jobIds` | `string[]` | No | One ID per country, for the multi-country Meta form. |
| `failedCountries` | `string[]` | No | Countries that were never queued and were not charged. |
| `message` | `string` | No | — |
| `chunk_count` | `number` | No | Number of POSTs Adyntel made to `webhook_url`. |
| `continuation_token` | `string \| null` | No | Null on the last page. Send it back to read the next one. |
| `country_code` | `string` | No | `anywhere` when no filter was applied. |
| `total_ad_count` | `number` | No | — |
| `ads` | `object[]` | No | — |

### shopping

`google.shopping`

Start a Google Shopping ad lookup for a domain: synchronous ads when `shopping` is true, otherwise a task ID to poll with `google.shoppingStatus`

**Risk:** `read`

```ts
await corsair.adyntel.api.google.shopping({ company_domain: 'tesla.com', shopping: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `company_domain` | `string` | Yes | The bare domain, without `https://` or `www.`. |
| `shopping` | `boolean` | No | `true` runs the synchronous parser and returns the ads in this response. `false` (the default) queues a DataForSEO scrape and answers with an `id` to poll via `google.shoppingStatus`. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | No | Queued task ID. Poll it with `google.shoppingStatus`. |
| `status` | `string` | No | — |
| `message` | `string` | No | — |
| `ads` | `object[]` | No | — |

| `live_ads` | `boolean` | No | Only currently active ads. |
| `all_ads` | `boolean` | No | Needs `webhook_url`. One credit per page and cannot be stopped. |
| `continuation_token` | `string` | No | `continuation_token` from the previous response. |
| `webhook_url` | `string` | No | Adyntel POSTs the results here when the scrape finishes, instead of returning them. You host and receive that POST; this plugin does not. |
| `data_provider` | `'rapidapi' \| 'apify'` | No | Which scraping backend runs the call. Leave it unset to use Adyntel's default. |
