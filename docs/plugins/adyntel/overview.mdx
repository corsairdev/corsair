Use **Adyntel** through Corsair: one client, typed API calls.

Adyntel needs two things, not one: an API key and the email of the account that owns it. Both go in the JSON body of every call, and a key without its matching email is a 401. Copy the key from your Adyntel profile under Integrations, then store it as `api_key` and the account email as `email` in the account config. Sign up at app.adyntel.com/signup for 50 free credits.

Things to know before you call:

- **Every call costs credits.** One credit per scrape, one page = one credit. `google.shoppingStatus` is free. `extract_text` (Google and LinkedIn), `impression_data` (LinkedIn) and `influencer_ads` (TikTok) each add one credit on top. A 204 ("no ads found") is not charged.
- **A 204 is a real answer.** When a domain has no reachable ad library entry, or the page is not public, Adyntel answers 204 with no body and charges nothing. The plugin turns that into an empty result, not an error, so a missing `ads` field means "checked, nothing there".
- **`company_domain` is the bare domain.** Send `clay.com`, never `https://clay.com` or `www.clay.com`. Adyntel does not reject a URL; it finds nothing and answers 204.
- **Paging.** Every list endpoint returns a `continuation_token` that is `null` on the last page. Send it back on the next call. On Google, a country filter is scoped to one call: send `country_code` again with every token, because the token does not carry it.
- **`all_ads` is a one-way door.** It follows the token to the end, costs one credit per page, needs a `webhook_url`, and the docs state there is no way to stop it.
- **Webhooks are yours to receive.** Setting `webhook_url` makes Adyntel answer with a `jobId` and POST the results to that URL later. This plugin does not host that receiver; the response carries `jobId` or `jobIds` so you can tell a queued job from a result.
- **Two filters reject rather than ignore.** On Meta, an unrecognised `language` is a 422 before anything is scraped. On Google, an unrecognised `media_type` is silently treated as `all`, so a typo widens the result instead of failing it.
- **Country support differs per endpoint.** Meta accepts one code or an array of up to 20 (the array needs `webhook_url` and costs one credit per country). Google accepts one per call. TikTok's keyword search accepts European codes only, and `US` is not one of them.
- **TikTok wraps its answers.** `tiktok.keywordSearch` and `tiktok.adDetails` return `{ code, data }` and send a non-zero `code` with a 200. The plugin throws on a non-zero code so a failure cannot read as "no ads".

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/adyntel
```
```bash yarn
yarn add corsair @corsair-dev/adyntel
```
```bash pnpm
pnpm install corsair @corsair-dev/adyntel
```
```bash bun
bun add corsair @corsair-dev/adyntel
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { adyntel } from '@corsair-dev/adyntel';

export const corsair = createCorsair({
	plugins: [
		adyntel(),
	],
	multiTenancy: true,
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the key and the account email for each tenant. A call made without them throws `AuthMissingError`; its `connectUrl` (when present) sends the user to the Hub connect page.

Adyntel checks two account fields on every call: `api_key`, and the `email` of the account that owns it. Set both.

```ts
adyntel({
	key: process.env.ADYNTEL_API_KEY,
	email: process.env.ADYNTEL_EMAIL,
})
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'adyntel',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List a company's Google ads**

```ts
const tenant = corsair.withTenant('acme');
await tenant.adyntel.api.google.ads({ company_domain: 'clay.com' });
```


**Compare paid and organic keywords for a domain**

```ts
const tenant = corsair.withTenant('acme');
await tenant.adyntel.api.keywords.paidVsOrganic({ company_domain: 'lokalise.com' });
```


See the full list on the [API](/plugins/adyntel/api) page.
