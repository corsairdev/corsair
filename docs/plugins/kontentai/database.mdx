---
title: "Kontent.ai database"
sidebarTitle: "Database"
description: "The Kontent.ai plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Kontent.ai. To read its data, call the [API operations](/plugins/kontentai/api), which return what Kontent.ai has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
