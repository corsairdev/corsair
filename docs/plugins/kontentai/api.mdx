## Items

### get

`items.get`

One content item by codename, with its elements and, on request, its linked items

**Risk:** `read`

```ts
await corsair.kontentai.api.items.get({ codename: 'about_us', depth: 2 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `codename` | `string` | Yes | The item, type or taxonomy codename, such as `about_us`. |
| `depth` | `number` | No | How deep to resolve linked items: `0` returns no `modular_content`, `1` and `2` go deeper. Kontent clamps anything outside 0 to 2 without saying so. |
| `language` | `string` | No | — |
| `elements` | `string[]` | No | — |
| `preview` | `string` | No | A preview token, so unpublished content comes back. Only a call that asks for it sends one. |

A `preview` token returns unpublished content and is sent as a bearer header on that call alone.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `item` | `object` | Yes | — |
| `modular_content` | `Record<string, any> \| null` | No | — |

### list

`items.list`

Published content items by type, language, collection or filter, with `depth` deciding how far linked items resolve; `next_skip` gives the next page

**Risk:** `read`

```ts
await corsair.kontentai.api.items.list({ limit: 10, depth: 1, type: 'about_us', language: 'en-US', order: 'system.last_modified' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `skip` | `number` | No | Items to skip. Defaults to 0. |
| `limit` | `number` | No | Items per page. Defaults to 10, and 2000 is the maximum. |
| `order` | `string` | No | A sort, such as `system.last_modified` or `elements.price[asc]`. Prefix a field with `-` or suffix it with `[desc]` to reverse it. |
| `preview` | `string` | No | A preview token, so unpublished content comes back. Only a call that asks for it sends one. |
| `depth` | `number` | No | How deep to resolve linked items: `0` returns no `modular_content`, `1` and `2` go deeper. Kontent clamps anything outside 0 to 2 without saying so. |
| `type` | `string` | No | Only items of this content type codename. |
| `language` | `string` | No | Only this language codename, such as `en-US`. |
| `collection` | `string` | No | Only this collection. |
| `in_filter` | `string` | No | A filter expression, such as `elements.price[gt]=10`. Kontent’s own syntax, passed through. |
| `elements` | `string[]` | No | Return only these element codenames. |

`depth` is 0 to 2; Kontent silently clamps anything outside it, so the plugin rejects it instead. `next_skip` is the next page, and null on the last one.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `items` | `object[]` | Yes | — |
| `modular_content` | `Record<string, any> \| null` | No | — |
| `pagination` | `object \| null` | No | — |
| `next_skip` | `number \| null` | Yes | The `skip` for the next page; null on the last page. |

|------|------|----------|-------------|
