## Items

### get

`items.get`

One content item by codename, with its elements and, on request, its linked items

**Risk:** `read`

```ts
await corsair.kontentai.api.items.get({ codename: 'about_us', depth: 2 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `codename` | `string` | Yes | The item, type or taxonomy codename, such as `about_us`. |
| `depth` | `number` | No | How deep to resolve linked items: `0` returns no `modular_content`, `1` and `2` go deeper. Kontent clamps anything outside 0 to 2 without saying so. |
| `language` | `string` | No | Read the item in this language codename. An untranslated item falls back to another language; check `system.language` on the answer. |
| `elements` | `string[]` | No | Return only these element codenames. Sent as one comma-separated `elements` value. |
| `preview` | `boolean` | No | Read the latest version, including unpublished content, from the Preview API. Needs a Delivery API key with preview access stored on the account. |

`preview: true` reads the latest version, unpublished included, from the Preview API; it needs a stored `delivery_api_key` with preview access.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `item` | `object` | Yes | — |
| `modular_content` | `Record<string, any> \| null` | No | — |

### list

`items.list`

Published content items by type, language, collection or filter, with `depth` deciding how far linked items resolve; `next_skip` gives the next page

**Risk:** `read`

```ts
await corsair.kontentai.api.items.list({ limit: 10, depth: 1, type: 'article', language: 'en-US', order: 'elements.post_date[desc]', in_filter: 'elements.title[nempty]' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `skip` | `number` | No | Items to skip. Defaults to 0. |
| `limit` | `number` | No | Items per page, at most 2000. Without it Kontent returns everything from `skip` on in one answer. |
| `order` | `string` | No | A sort, such as `system.last_modified` or `elements.price[asc]`. Suffix the field with `[desc]` to reverse it; a `-` prefix is refused with a 400. |
| `preview` | `boolean` | No | Read the latest version, including unpublished content, from the Preview API. Needs a Delivery API key with preview access stored on the account. |
| `depth` | `number` | No | How deep to resolve linked items: `0` returns no `modular_content`, `1` and `2` go deeper. Kontent clamps anything outside 0 to 2 without saying so. |
| `type` | `string` | No | Only items of this content type codename, sent as `system.type`. |
| `language` | `string` | No | Read content in this language codename, such as `es-ES`. Items not translated into it fall back to another language; add `system.language=es-ES` to `in_filter` to drop them. |
| `collection` | `string` | No | Only this collection codename, sent as `system.collection`. |
| `in_filter` | `string` | No | Kontent filters, such as `elements.price[gt]=10` or `system.type[in]=article,coffee&elements.title[nempty]`. Each `&`-separated filter is sent as its own query parameter, and an item must match all of them. |
| `elements` | `string[]` | No | Return only these element codenames. Sent as one comma-separated `elements` value. |

`depth` is 0 to 2; Kontent silently clamps anything outside it, so the plugin rejects it instead. `next_skip` is the next page, and null on the last one.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `items` | `object[]` | Yes | — |
| `modular_content` | `Record<string, any> \| null` | No | — |
| `pagination` | `object \| null` | No | — |
| `next_skip` | `number \| null` | Yes | The `skip` for the next page; null on the last page. |

**Risk:** `read`

```ts
await corsair.kontentai.api.taxonomies.list({ limit: 10 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `skip` | `number` | No | Items to skip. Defaults to 0. |
| `limit` | `number` | No | Items per page, at most 2000. Without it Kontent returns everything from `skip` on in one answer. |
| `order` | `string` | No | A sort, such as `system.last_modified` or `elements.price[asc]`. Suffix the field with `[desc]` to reverse it; a `-` prefix is refused with a 400. |
