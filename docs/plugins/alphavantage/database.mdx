The Alpha Vantage plugin syncs data locally. Use `corsair.alphavantage.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Companies

Path: `alphavantage.db.companies.search`

```ts
const rows = await corsair.alphavantage.db.companies.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```
