## Single

### check

`single.check`

Verify an email address; verification may consume credits

**Risk:** `destructive`

```ts
await corsair.neverbounce.api.single.check({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | Email address to verify, including invalid addresses for syntax checking |
| `address_info` | `number` | No | Include address details (default 0) |
| `credits_info` | `number` | No | Include credit details (default 0) |
| `timeout` | `number` | No | Maximum verification time in seconds |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `success` | Yes | — |
| `result` | `string` | No | — |
| `flags` | `string[]` | No | — |
| `suggested_correction` | `string` | No | — |
| `address_info` | `object` | No | — |
| `credits_info` | `object` | No | — |
| `execution_time` | `number` | No | — |
