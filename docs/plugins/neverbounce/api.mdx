## Single

### check

`single.check`

Verify one email address as it comes in, such as a form signup (valid, invalid, disposable, catchall or unknown); uses one verification credit. NeverBounce may lock the account if this is looped over an existing list; lists belong in its bulk jobs

**Risk:** `read`

```ts
await corsair.neverbounce.api.single.check({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | Email address to verify, including invalid addresses for syntax checking |
| `address_info` | `number` | No | Include address details (default 0) |
| `credits_info` | `number` | No | Include credit details (default 0) |
| `timeout` | `number` | No | Maximum verification time in seconds |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `success` | Yes | — |
| `result` | `string \| null` | No | — |
| `flags` | `string[] \| null` | No | — |
| `suggested_correction` | `string \| null` | No | — |
| `address_info` | `object \| null` | No | — |
| `credits_info` | `object \| null` | No | — |
| `execution_time` | `number \| null` | No | — |
