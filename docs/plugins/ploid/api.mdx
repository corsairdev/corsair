## Account

### credits

Read the workspace ACU balance and API key budget state

**Risk:** `read`

```ts
await corsair.ploid.api.account.credits({});
```

**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |
| `meta` | `object` | Yes | — |

```ts
  acu?: {

    used: number,

}
```
</Accordion>

## Contacts

### enrich

`contacts.enrich`

Resolve contact fields (work_email 1, personal_email 3, phone 10 ACU per hit) from a person_id, LinkedIn URL, email, or name plus company domain

**Risk:** `write`

```ts
await corsair.ploid.api.contacts.enrich({
	identifier: { person_id: 'per_abc123' },
	fields: ['work_email', 'phone'],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `identifier` | `object` | Yes | — |
| `fields` | `work_email \| personal_email \| phone[]` | Yes | — |
| `response_format` | `standard` | No | — |

<AccordionGroup>
<Accordion title="identifier full type">

```ts
{
  linkedin_url: string
} | {
  person_id: string
} | {
  email: string
} | {
  name: string,
  company_domain: string
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |
| `meta` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  work_email?: {
    value?: string | null,
    status: found | not_found | unavailable,
    confidence?: guess | strong | verified | null,
    source?: contact_network | linked_profile | public_code | public_web | null,
    last_seen?: string | null
  },
  personal_email?: {
    value?: string | null,
    status: found | not_found | unavailable,
    confidence?: guess | strong | verified | null,
    source?: contact_network | linked_profile | public_code | public_web | null,
    last_seen?: string | null
  },
  phone?: {
    value?: string | null,
    status: found | not_found | unavailable,
    confidence?: guess | strong | verified | null,
    source?: contact_network | linked_profile | public_code | public_web | null,
    last_seen?: string | null
  }
}
```
</Accordion>

<Accordion title="meta full type">

```ts
{
  request_id: string
}
```
</Accordion>
</AccordionGroup>

### search

`search.search`

**Risk:** `write`


| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | No | — |
| `type` | `instant \| fast \| auto \| deep` | No | — |
| `category` | `people` | No | — |
| `num_results` | `number` | No | — |
| `criteria` | `string[]` | No | — |
| `async` | `boolean` | No | — |
| `webhook_url` | `string` | No | — |
| `filters` | `object` | No | — |
| `freshness` | `object` | No | — |
| `contents` | `object` | No | — |
