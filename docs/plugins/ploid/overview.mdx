Use **Ploid** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 9 typed API operations
- 1 synced entity (`people`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/ploid
```
```bash yarn
yarn add corsair @corsair-dev/ploid
```
```bash pnpm
pnpm install corsair @corsair-dev/ploid
```
```bash bun
bun add corsair @corsair-dev/ploid
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { ploid } from '@corsair-dev/ploid';

export const corsair = createCorsair({
	plugins: [
		ploid(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
ploid()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'ploid',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read the workspace ACU balance**

```ts
const tenant = corsair.withTenant('acme');
await tenant.ploid.api.account.credits({});
```


**Resolve a person to a permanent person_id**

```ts
const tenant = corsair.withTenant('acme');
await tenant.ploid.api.person.resolve({ name: 'Jane Doe', company: 'acme.com' });
```


See the full list on the [API](/plugins/ploid/api) page.

## Query synced data

Read a previously resolved or enriched person without calling the API.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.ploid.db.people.search({
	data: { personId: 'per_abc123', name: 'Jane Doe', company: 'Acme' },
	limit: 10,
});
```

Synced entities: `people`. See [Database](/plugins/ploid/database) for filters and operators.
