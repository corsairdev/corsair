The Ploid plugin syncs data locally. Use `corsair.ploid.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## People

Path: `ploid.db.people.search`

```ts
const rows = await corsair.ploid.db.people.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `personId` | `string` | equals, contains, startsWith, endsWith, in |
| `name` | `string` | equals, contains, startsWith, endsWith, in |
| `headline` | `string` | equals, contains, startsWith, endsWith, in |
| `company` | `string` | equals, contains, startsWith, endsWith, in |
| `location` | `string` | equals, contains, startsWith, endsWith, in |
| `linkedinUrl` | `string` | equals, contains, startsWith, endsWith, in |
| `profileUrl` | `string` | equals, contains, startsWith, endsWith, in |
| `githubUrl` | `string` | equals, contains, startsWith, endsWith, in |
| `xUrl` | `string` | equals, contains, startsWith, endsWith, in |
| `identityVerified` | `boolean` | equals |
| `confidence` | `number` | equals, gt, gte, lt, lte, in |
| `summary` | `string` | equals, contains, startsWith, endsWith, in |
| `updatedAt` | `date` | equals, before, after, between |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
