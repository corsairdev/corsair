---
title: "WebScraping.AI database"
sidebarTitle: "Database"
description: "The WebScraping.AI plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for WebScraping.AI. To read its data, call the [API operations](/plugins/webscrapingai/api), which return what WebScraping.AI has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
