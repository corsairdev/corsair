---
title: "Customer.io database"
sidebarTitle: "Database"
description: "The Customer.io plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Customer.io. To read its data, call the [API operations](/plugins/customerio/api), which return what Customer.io has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
