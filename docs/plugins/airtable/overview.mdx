Use **Airtable** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 9 typed API operations
- 2 synced entities (`bases`, `records`) for fast `.search()` / `.list()`
- 1 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/airtable
```
```bash yarn
yarn add corsair @corsair-dev/airtable
```
```bash pnpm
pnpm install corsair @corsair-dev/airtable
```
```bash bun
bun add corsair @corsair-dev/airtable
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { airtable } from '@corsair-dev/airtable';

export const corsair = createCorsair({
	plugins: [
		airtable(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_DEV_API_KEY!,
		signingSecret: process.env.CORSAIR_DEV_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

Provider walkthrough: [Get Credentials](/plugins/airtable/get-credentials).

```ts
airtable()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'airtable',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`bases.getMany`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.airtable.api.bases.getMany({});
```


**`records.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.airtable.api.records.create({});
```


See the full list on the [API](/plugins/airtable/api) page.

## Query synced data

Synced entities support `tenant.airtable.db.<entity>.search()` and `.list()`: `bases`, `records`.

See [Database](/plugins/airtable/database) for filters and operators.

## Webhooks

This plugin registers **1** webhook event type. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/airtable/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
