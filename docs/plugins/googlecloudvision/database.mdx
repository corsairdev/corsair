---
title: "Google Cloud Vision database"
sidebarTitle: "Database"
description: "The Google Cloud Vision plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Google Cloud Vision. To read its data, call the [API operations](/plugins/googlecloudvision/api), which return what Google Cloud Vision has at that moment.

</Info>
