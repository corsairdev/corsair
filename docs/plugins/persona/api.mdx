## Accounts

### addTag

`accounts.addTag`

Add a tag to an account

**Risk:** `write`

```ts
await corsair.persona.api.accounts.addTag({ accountId: "af2a1c3d-4e5f-6a7b-8c9d-0e1f2a3b4c72", tag: "vip" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `accountId` | `string` | Yes | Account id |
| `tag` | `string` | Yes | Tag name |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | Whether the tag change succeeded |
