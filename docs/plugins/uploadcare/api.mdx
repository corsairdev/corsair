**Risk:** `write`

```ts

```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `file_ids` | `string[]` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string` | No | — |
| `result` | `object[]` | No | — |
