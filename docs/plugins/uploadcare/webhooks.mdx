The Uploadcare plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/uploadcare/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `fileUploaded`
  - `fileUploaded` (`fileUploaded.fileUploaded`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    const body = await request.json();
    const result = await processWebhook(corsair, headers, body);
    return result.response;
}
```

## File Uploaded

### File Uploaded

`fileUploaded.fileUploaded`

File uploaded webhook event

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event` | `file.uploaded` | Yes | — |
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  uuid: string,
  original_filename?: string | null
}
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{

    original_filename?: string | null
  }
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
uploadcare({
    webhookHooks: {
        fileUploaded: {
            fileUploaded: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
