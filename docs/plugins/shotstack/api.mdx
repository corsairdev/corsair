## Assets

### delete

`assets.delete`

Permanently delete a hosted asset from Shotstack storage and its CDN; there is no undo.

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.shotstack.api.assets.delete({ id: 'a4482cbf-e321-42a2-ac8b-947d26886840' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The id the create call returned (a UUID). |



**Output:** _empty object_


---

### transfer

`assets.transfer`

Copy a hosted file to external destinations such as S3, Google Cloud Storage, Mux, Vimeo or Google Drive.

**Risk:** `write`

```ts
await corsair.shotstack.api.assets.transfer({ url: 'https://s3.amazonaws.com/my-bucket/video.mp4', id: '018e8937-5015-75ee-aab6-03f214981133', destinations: [{ provider: 'shotstack' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | The file URL to fetch and transfer. |
| `id` | `string` | Yes | Your identifier for the asset; it does not need to be unique. |
| `destinations` | `object[]` | Yes | Where to send the file, e.g. [&#123; provider: "shotstack" &#125;] or an s3 / mux / vimeo destination. |

<AccordionGroup>
<Accordion title="destinations full type">

```ts

  provider: string
```

</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `owner` | `string \| null` | No | — |
| `status` | `queued \| failed \| null` | No | — |
| `created` | `string \| null` | No | — |

## Generations

### create

`generations.create`

Generate an image, video or audio asset from a prompt with an AI model; spends generation credits. Follow it with generations.get until status is done or failed. Pass idempotencyKey to make retries safe.

**Risk:** `write`

```ts
await corsair.shotstack.api.generations.create({ asset: { type: 'image', prompt: 'A lighthouse on a rocky coast at sunset' }, idempotencyKey: 'my-job-42' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `asset` | `object` | Yes | — |
| `length` | `number` | No | Seconds of clip the asset fills; duration-generating models take their length from this. |
| `idempotencyKey` | `string` | No | Makes this create replay-safe: a retry with the same key returns the job it first created instead of generating and billing again. |

<AccordionGroup>
<Accordion title="asset full type">

```ts
{
  type: image | video | audio,
  prompt?: string,
  src?: string,
  model?: string,
  options?: Record<string, any>
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `status` | `queued \| processing \| done \| failed` | Yes | — |
| `url` | `string \| null` | No | — |
| `error` | `string \| null` | No | — |

## Renders

### create

`renders.create`

Queue a video, image, GIF or audio render of a JSON timeline; spends credits. Follow it with renders.get until status is done or failed.

**Risk:** `write`

```ts
await corsair.shotstack.api.renders.create({ timeline: { tracks: [{ clips: [{ asset: { type: 'title', text: 'Hello', color: '#ffffff' }, start: 0, length: 3 }] }] }, output: { format: 'mp4', resolution: 'sd' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `timeline` | `object` | Yes | The timeline: tracks, clips and optional soundtrack, background and fonts. See shotstack.io/docs/guide for the clip DSL. |
| `output` | `object` | Yes | — |
| `merge` | `object[]` | No | Placeholder replacements applied to the edit before rendering. |
| `callback` | `string` | No | Webhook URL that receives a notification when the render completes or fails. |
| `instance` | `s1 \| s2 \| a1` | No | Render instance: s1 (default), s2 (more resources) or a1 (accelerated). |

<AccordionGroup>
<Accordion title="timeline full type">

```ts
{
  tracks: {
    clips: Record<string, any>[]
  }[]
}
```
</Accordion>

<Accordion title="output full type">

```ts
{
  format: mp4 | gif | mp3 | jpg | png | bmp,
  resolution?: 1080 | preview | mobile | sd | hd | 4k,
  aspectRatio?: 16:9 | 9:16 | 1:1 | 4:5 | 4:3,
  size?: {
    width: number,
    height: number
  }
}
```
</Accordion>

<Accordion title="merge full type">

```ts
{
  find: string,
  replace: any
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | — |
| `message` | `string` | Yes | — |

```ts
  id: string
}
```
</Accordion>
</AccordionGroup>

### get

`renders.get`

Where a render stands. Once done it returns the temporary download URL, which expires after 24 hours; serve the asset from its CDN URL via assets.getByRenderId instead.

**Risk:** `read`

```ts
await corsair.shotstack.api.renders.get({ id: '2abd5c11-0f3d-4c6d-ba20-235fc9b8e8b7' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The id the create call returned (a UUID). |
| `data` | `boolean` | No | True to include the full timeline echo in response.data. Defaults to false, which the plugin always sends: the echo can be huge. |
| `merged` | `boolean` | No | True to include the merged edit; needs data: true. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | — |
| `message` | `string` | Yes | — |
| `response` | `object` | Yes | — |

<AccordionGroup>

```ts
{
  id: string,
  owner: string,
  status: queued | fetching | preprocessing | rendering | generating | saving | done | failed,
  plan?: string | null,
  error?: string | null,
  duration?: number | null,
  renderTime?: number | null,
  url?: string | null,
  poster?: string | null,
  thumbnail?: string | null,
  data?: Record<string, any> | null,
  created?: string | null,
  updated?: string | null
}
```
</Accordion>
</AccordionGroup>
