## Company

### get

`company.get`

Read the account's name, work hours, tracking window and timezone

**Risk:** `read`

```ts
await corsair.desktime.api.company.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string \| null` | No | — |
| `work_starts` | `string \| null` | No | — |
| `work_ends` | `string \| null` | No | — |
| `work_duration` | `string \| number \| null` | No | — |
| `working_days` | `number \| null` | No | — |
| `work_start_tracking` | `string \| null` | No | — |
| `work_stop_tracking` | `string \| null` | No | — |
| `timezone_identifier` | `string \| null` | No | — |
| `__request_time` | `string \| null` | No | — |

## Employee

### apps

`employee.apps`

| `date` | `string` | No | A day in YYYY-MM-DD form. |

| `onlineTime` | `number \| null` | No | — |
| `offlineTime` | `number \| null` | No | — |

## Employees

### list

`employees.list`

List every employee for a day, week or month with their arrival, tracked time and productivity, nested by date then employee id

**Risk:** `read`

```ts
await corsair.desktime.api.employees.list({ date: '2026-11-02', period: 'week' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `date` | `string` | No | A day in YYYY-MM-DD form. |
| `period` | `day \| week \| month` | No | The window to return, starting at `date` or today. `day` returns one bucket, `week` seven, `month` the calendar month. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `employees` | `object` | Yes | — |
| `buckets` | `object[]` | Yes | The same employees flattened out of the two-level map, newest date first, with the date kept on each entry so a multi-day response stays unambiguous. |
| `__request_time` | `string \| null` | No | — |

## Ping

### get

`ping.get`

Check that the DeskTime API answers. A configured key is still required, because the runtime resolves the account key before any endpoint runs

**Risk:** `read`

```ts
await corsair.desktime.api.ping.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `pong` | `string` | Yes | — |
| `__request_time` | `string \| null` | No | — |
