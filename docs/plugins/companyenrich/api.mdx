## Account

### me

`account.me`

Get the authenticated user, credit balance and plan capabilities. Free.

**Risk:** `read`

```ts
await corsair.companyenrich.api.account.me({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `userId` | `string` | Yes | — |
| `credits` | `object` | Yes | — |
| `capabilities` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="credits full type">

```ts

  used: number,
  total: number
}
```
</Accordion>

<Accordion title="capabilities full type">

```ts

  previews: boolean,

  peopleSearchLimit: number,
```

</Accordion>

### search

`companies.search`

Search companies by filters, a semantic query or lookalike seed domains, with cursor pagination. Costs 1 credit per company (2 semantic, 5 lookalike).

**Risk:** `read`

```ts
await corsair.companyenrich.api.companies.search({
	pageSize: 10,
	filter: { domain: 'acme.example', type: 'private' },
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `pageSize` | `number` | No | — |
| `cursor` | `string` | No | — |
| `expand` | `(financial \| keywords \| naicsCodes \| technologies \| workforce)[]` | No | — |
| `filter` | `object` | No | — |
| `semantic` | `object` | No | — |
| `lookalike` | `object` | No | — |
