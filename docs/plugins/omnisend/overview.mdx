Use **Omnisend** through Corsair: one client, typed API calls.

Create an API key in Omnisend under Store settings &gt; API keys and give it the scopes you need (contacts, campaigns, automations, products and so on). Things to know before you write:

- **Sending is final.** `campaigns.send` emails or texts the campaign's whole audience and `campaigns.selectAbTestWinner` sends the winning variant to the rest; both are `destructive`. `campaigns.sendTestEmail` and `automations.sendBlockTestEmail` send real mail to the addresses you give. `automations.enable` turns on a flow that messages contacts whenever its trigger fires.
- **Events trigger automations.** `events.send` records a customer event (placed order, custom events) and creates or updates the contact; it can start automations that email real customers and cannot be edited or deleted afterwards.
- **Tags replace.** `contacts.update`, `contacts.updateByEmail` and `contacts.upsert` replace a contact's tag list with the one you send. Use `contacts.addTags` / `contacts.removeTags` to change tags on up to 250 contacts or a whole segment (queued, 202).
- **Batches.** `batches.create` queues up to 100 contact, product, category or event writes; read progress with `batches.get` and per-item results with `batches.listItems`.
- **Paging.** Most lists page with `after` / `before` cursors from `paging.cursors` and stop when `paging.hasMore` is false; a few take `offset` and `limit`.

**What you get:**

- 108 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/omnisend better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/omnisend better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/omnisend better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/omnisend better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { omnisend } from '@corsair-dev/omnisend';

export const corsair = createCorsair({
	plugins: [
		omnisend(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Omnisend API key before the first call: `pnpm corsair setup --plugin=omnisend --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
omnisend()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'omnisend',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List contacts**

```ts
const tenant = corsair.withTenant('acme');
await tenant.omnisend.api.contacts.list({});
```


**Tag contacts**

```ts
const tenant = corsair.withTenant('acme');
await tenant.omnisend.api.contacts.addTags({
	emails: ['ada@example.com'],
	tags: ['vip'],
});
```


See the full list on the [API](/plugins/omnisend/api) page.
