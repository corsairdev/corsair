---
title: "Omnisend database"
sidebarTitle: "Database"
description: "The Omnisend plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Omnisend. To read its data, call the [API operations](/plugins/omnisend/api), which return what Omnisend has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
