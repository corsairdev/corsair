## Batches

### create

`batches.create`

Queue up to 100 contact, product, category or event writes that Omnisend applies one by one, and read the batch back with batches.get until it is finished or stopped

**Risk:** `write`

```ts
await corsair.omnisend.api.batches.create({ endpoint: 'contacts', method: 'POST', items: [{ identifiers: [{ id: 'jordan@acme.com', type: 'email' }] }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `endpoint` | `contacts \| products \| events \| categories` | Yes | The resource the batch writes. |
| `method` | `POST \| PUT` | Yes | The HTTP method applied to each item. |
| `items` | `Record<string, JsonValue>[]` | Yes | The payloads to apply, in order; up to 100 per batch. |
| `origin` | `string` | No | Marks the batch, such as your integration name. |

Up to 100 items per batch. Poll `batches.get` until `status` is `finished` or `stopped`; there is no cancel.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `batchID` | `string` | Yes | — |
| `totalCount` | `number \| null` | No | — |
