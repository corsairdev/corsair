## Account

### get

`account.get`

Read account usage and the hourly limit.

**Risk:** `read`

```ts
await corsair.searchapi.api.account.get({});
```

**Input:** _empty object_

GET /api/v1/me. Stores the usage numbers on id account.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `account` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="account full type">

```ts
{
  id: string,
  currentMonthUsage?: number,
  monthlyAllowance?: number,
  remainingCredits?: number,
  remainingSearches?: number,
  searchesThisHour?: number,
  hourlyRateLimit?: number,
  periodStart?: string,
  periodEnd?: string
}
```
</Accordion>
</AccordionGroup>

## Locations

### list

`locations.list`

Look up Google locations by name.

**Risk:** `read`

```ts
await corsair.searchapi.api.locations.list({ q: 'london' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | — |
| `limit` | `number` | No | — |

GET /api/v1/locations. Stores google_id, name, canonical name, country code, and target type.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `locations` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="locations full type">

```ts
{
  id: string,
  name?: string,
  canonicalName?: string,
  countryCode?: string,
  targetType?: string
}[]
```
</Accordion>
</AccordionGroup>

## Searches

### get

`searches.get`

Read a cached search by id. Result rows are not stored.

**Risk:** `read`

```ts
await corsair.searchapi.api.searches.get({ id: 'search_example' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |

GET /api/v1/searches/{id}. This is the json_url. Stores id, status, and engine.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `search` | `object` | Yes | — |
| `results` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="search full type">

```ts
{
  id: string,
  status?: string,
  engine?: string
}
```
</Accordion>

<Accordion title="results full type">

```ts
{
  position?: number,
  title?: string,
  link?: string
}[]
```
</Accordion>
</AccordionGroup>

### html

`searches.html`

Read cached search HTML by id. The HTML is not stored.

**Risk:** `read`

```ts
await corsair.searchapi.api.searches.html({ id: 'search_example' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |

GET /api/v1/searches/{id}.html. Returns the HTML and does not store it.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `html` | `string` | Yes | — |



---

### run

`searches.run`

Run a search. This spends a credit. Results are not stored.

**Risk:** `write`

```ts
await corsair.searchapi.api.searches.run({ engine: 'google', q: 'example' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `engine` | `string` | Yes | — |
| `q` | `string` | Yes | — |

GET /api/v1/search. Stores id, status, and engine. Returns title and link for organic results.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `search` | `object` | Yes | — |
| `results` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="search full type">

```ts
{
  id: string,
  status?: string,
  engine?: string
}
```
</Accordion>

<Accordion title="results full type">

```ts
{
  position?: number,
  title?: string,
  link?: string
}[]
```
</Accordion>
</AccordionGroup>
