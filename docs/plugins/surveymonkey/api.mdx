## Collectors

### create

`collectors.create`

Create a weblink or email collector for a survey, which is what gives it a public link

**Risk:** `write`

```ts
await corsair.surveymonkey.api.collectors.create({ survey_id: '1234', type: 'weblink', name: 'Website link' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `survey_id` | `string` | Yes | — |
| `type` | `weblink \| email` | No | — |
| `name` | `string` | No | — |
| `thank_you_message` | `string` | No | — |
| `disqualification_message` | `string` | No | — |
| `disqualification_url` | `string` | No | — |
| `close_date` | `string` | No | — |
| `closed_page_message` | `string` | No | — |
| `redirect_url` | `string` | No | — |
| `display_survey_results` | `boolean` | No | — |
| `edit_response_type` | `until_complete \| never \| always` | No | — |
| `anonymous_type` | `not_anonymous \| partially_anonymous \| fully_anonymous` | No | — |
| `allow_multiple_responses` | `boolean` | No | — |
| `sender_email` | `string` | No | — |
| `response_limit` | `number` | No | — |
| `redirect_type` | `url \| close \| loop` | No | — |
| `password` | `string` | No | — |
| `from_collector_id` | `string` | No | — |

Answers the created collector. `type` is `weblink` or `email`; `sms` exists in the API but cannot be created here. A weblink collector answers a public `url`, and an email collector needs messages and recipients before it sends anything.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `status` | `string \| null` | No | — |
| `type` | `string \| null` | No | — |
| `name` | `string \| null` | No | — |
| `thank_you_message` | `string \| null` | No | — |
| `disqualification_message` | `string \| null` | No | — |
| `disqualification_url` | `string \| null` | No | — |
| `close_date` | `string \| null` | No | — |
| `closed_page_message` | `string \| null` | No | — |
| `redirect_url` | `string \| null` | No | — |
| `display_survey_results` | `boolean \| null` | No | — |
| `edit_response_type` | `string \| null` | No | — |
| `anonymous_type` | `string \| null` | No | — |
| `allow_multiple_responses` | `boolean \| null` | No | — |
| `date_modified` | `string \| null` | No | — |
| `date_created` | `string \| null` | No | — |
| `url` | `string \| null` | No | — |
| `open` | `boolean \| null` | No | — |
| `password_enabled` | `boolean \| null` | No | — |

| `response_limit` | `number \| null` | No | — |
| `redirect_type` | `string \| null` | No | — |

### merge

`contactLists.merge`

Move every contact from this list into another. The source list is left empty, so this effectively undoes it

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.surveymonkey.api.contactLists.merge({ contact_list_id: '1234', list_id: '5678' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contact_list_id` | `string` | Yes | — |
| `list_id` | `string` | Yes | — |

Moves every contact from this list into `list_id` and answers 200 with no body, so the plugin reports `{ source_list_id, target_list_id, merged: true }`. **The source list is left empty**, and nothing moves it back.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `source_list_id` | `string` | Yes | — |
| `target_list_id` | `string` | Yes | — |
| `merged` | `true` | Yes | — |
