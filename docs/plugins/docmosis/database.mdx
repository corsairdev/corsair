The Docmosis plugin syncs data locally. Use `corsair.docmosis.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Batch Upload Jobs

Path: `docmosis.db.batchUploadJobs.search`

```ts
const rows = await corsair.docmosis.db.batchUploadJobs.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `isEnded` | `boolean` | equals |
| `status` | `string` | equals, contains, startsWith, endsWith, in |
| `type` | `string` | equals, contains, startsWith, endsWith, in |
| `processingMsg` | `string` | equals, contains, startsWith, endsWith, in |
| `startedTime` | `number` | equals, gt, gte, lt, lte, in |
| `finishedTime` | `number` | equals, gt, gte, lt, lte, in |
| `duration` | `number` | equals, gt, gte, lt, lte, in |
| `pctComplete` | `number` | equals, gt, gte, lt, lte, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
