Use **ClickMeeting** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 42 typed API operations
- 2 synced entities (`conferences`, `contacts`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/clickmeeting
```
```bash yarn
yarn add corsair @corsair-dev/clickmeeting
```
```bash pnpm
pnpm add corsair @corsair-dev/clickmeeting
```
```bash bun
bun add corsair @corsair-dev/clickmeeting
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { clickmeeting } from '@corsair-dev/clickmeeting';

export const corsair = createCorsair({
	plugins: [
		clickmeeting(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
clickmeeting()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'clickmeeting',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`chats.getChatDetails`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.clickmeeting.api.chats.getChatDetails({ chatId: 1 });
```


**`conferences.createConference`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.clickmeeting.api.conferences.createConference({ name: 'My Webinar' });
```


See the full list on the [API](/plugins/clickmeeting/api) page.

## Query synced data

Synced entities support `tenant.clickmeeting.db.<entity>.search()` and `.list()`: `conferences`, `contacts`.

See [Database](/plugins/clickmeeting/database) for filters and operators.
