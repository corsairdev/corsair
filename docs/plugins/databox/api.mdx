## Datasets

### create

`datasets.create`

Create a dataset in a data source with column definitions and an optional primary key that makes re-ingested records overwrite

**Risk:** `write`

```ts
await corsair.databox.api.datasets.create({ name: 'Transactions', dataSourceId: 1234567, primaryKey: ['transaction_id'], schema: [{ id: 'transaction_id', dataType: 'string' }, { id: 'amount', dataType: 'number' }, { id: 'occurred_at', dataType: 'datetime' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Display name, such as Transactions. |
| `dataSourceId` | `number` | Yes | The data source that holds the dataset. |
| `primaryKey` | `string[]` | No | Column identifiers that make a record unique; re-ingesting a matching record overwrites it instead of appending. |
| `schema` | `object[]` | Yes | Column definitions for the dataset. |
| `accountId` | `number` | No | Sent as x-account-id to act on one account of the organization instead of the organization tied to the key. Only for organizations with accounts enabled. |
| `idempotencyKey` | `string` | No | A UUID, sent as Idempotency-Key; Databox rejects any other value with a 400 and returns the original response for the same key within 24 hours. |

<Accordion title="schema full type">

{

</AccordionGroup>

| `dataset` | `object` | Yes | — |

### ingestData

`datasets.ingestData`

Submit up to 500 records for ingestion; the response carries an ingestionId to poll in datasets.getIngestion

**Risk:** `write`

```ts
await corsair.databox.api.datasets.ingestData({ id: 2345678, records: [{ transaction_id: 'T-10024', amount: 249, occurred_at: '2026-09-18T09:12:00+00:00' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | The dataset to ingest into. |
| `records` | `Record<string, string \| number \| boolean \| null>[]` | Yes | Records keyed by column ID; at most 500 rows per request. With a primaryKey, matching records overwrite. |
| `accountId` | `number` | No | Sent as x-account-id to act on one account of the organization instead of the organization tied to the key. Only for organizations with accounts enabled. |
| `idempotencyKey` | `string` | No | A UUID, sent as Idempotency-Key; Databox rejects any other value with a 400 and returns the original response for the same key within 24 hours. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ingestionId` | `string` | Yes | Pass with the dataset ID to datasets.getIngestion to poll. |
| `status` | `string \| null` | No | — |
| `message` | `string \| null` | No | — |

## Metrics

### getData

`metrics.getData`

Read a metric's values over a date range with granularity, dimension breakdowns and filters; may wait for a first sync (up to two minutes)

**Risk:** `read`

```ts

```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Metric ID, such as 'GoogleAnalytics4@sessions', from metrics.list. |
| `sourceId` | `number` | No | Restrict the metric to one data source or dataset. |
| `dateRange` | `object` | Yes | — |
| `dimensionIds` | `string[]` | No | Dimension IDs to break the values down by; from the metric. |
| `filters` | `object` | No | — |
| `accountId` | `number` | No | Sent as x-account-id to act on one account of the organization instead of the organization tied to the key. Only for organizations with accounts enabled. |
