### fields

**Risk:** `read`


|------|------|----------|-------------|

### list

`issues.list`

Query the issues in a project, with filters and paging

**Risk:** `read`

```ts
await corsair.leiga.api.issues.list({ projectId: 123456, statusTypes: [2, 3], pageSize: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `projectId` | `number` | Yes | Project to query |
| `pageNumber` | `number` | No | Page number, from 1 |
| `pageSize` | `number` | No | Page size |
| `summary` | `string` | No | Filter on summary text |
| `orderBy` | `createTime \| updateTime` | No | Field to sort by |
| `sort` | `ASC \| DESC` | No | Sort direction |
| `statusTypes` | `number[]` | No | Status types to include: 2 not started, 3 in progress, 4 done |

A POST with the filters in the body, answering `{ total, list }`. `statusTypes` filters by phase (2 not started, 3 in progress, 4 done); `orderBy` accepts `createTime` or `updateTime` and `sort` accepts `ASC` or `DESC`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `issues` | `object[]` | Yes | — |
| `total` | `number` | Yes | — |
