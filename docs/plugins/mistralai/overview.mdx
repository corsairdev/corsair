Use **Mistral AI** through Corsair: one client, typed API calls.

Each operation returns one JSON result: streaming is off for completions, responses, speech and transcription. Files and audio go in as base64; the fields differ per operation: `files.upload` takes `content_base64` and `filename`; `audio.transcribe` takes `content_base64` with `filename`, or `file_url` or `file_id` instead; `voices.create` takes `sample_audio` and an optional `sample_filename`; `ocr.process` takes no base64: pass a `document` URL, an image URL or the `file_id` of an uploaded file. `files.getSignedUrl` gives a download link for a file's content, such as a batch job's results.

A batch job runs on Mistral after `batch.create` returns. Follow it with `batch.get({ job_id })` until `status` is SUCCESS (read `output_file` with `files.getSignedUrl`), or FAILED, TIMEOUT_EXCEEDED or CANCELLED. QUEUED, RUNNING and CANCELLATION_REQUESTED mean it is still going.

`agents.*` other than `agents.complete` are Mistral beta endpoints. A 422 from Mistral names each rejected field in the error message, for example `body.messages.0.content: Field required`.

**What you get:**

- 52 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/mistralai better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/mistralai better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/mistralai better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/mistralai better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { mistralai } from '@corsair-dev/mistralai';

export const corsair = createCorsair({
	plugins: [
		mistralai(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
mistralai()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'mistralai',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List the models this key can use**

```ts
const tenant = corsair.withTenant('acme');
await tenant.mistralai.api.models.list({});
```


**Ask a model a question**

```ts
const tenant = corsair.withTenant('acme');
await tenant.mistralai.api.chat.complete({
	model: 'mistral-small-latest',
	messages: [{ role: 'user', content: 'In one sentence, what is retrieval-augmented generation?' }],
});
```


See the full list on the [API](/plugins/mistralai/api) page.
