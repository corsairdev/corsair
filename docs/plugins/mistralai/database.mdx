---
title: "Mistral AI database"
sidebarTitle: "Database"
description: "The Mistral AI plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Mistral AI. To read its data, call the [API operations](/plugins/mistralai/api), which return what Mistral AI has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
