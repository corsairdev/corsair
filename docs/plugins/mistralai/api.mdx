## Agents

### complete

`agents.complete`

Run an agent on a list of messages with the agent's instructions and tools; spends Mistral credits

**Risk:** `write`

```ts
await corsair.mistralai.api.agents.complete({ agent_id: '<agent id>', messages: [{ role: 'user', content: 'Summarize ticket #4521' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `agent_id` | `string` | Yes | Id of the agent to run. |
| `max_tokens` | `number` | No | — |
| `min_tokens` | `number` | No | — |
| `stop` | `string \| string[]` | No | — |
| `random_seed` | `number` | No | — |
| `metadata` | `Record<string, any>` | No | — |
| `messages` | `object[]` | Yes | Conversation so far: &#123; role: "system" \| "user" \| "assistant" \| "tool", content &#125;. |
| `response_format` | `object` | No | — |
| `tools` | `object[]` | No | — |
| `tool_choice` | `auto \| none \| any \| required \| object` | No | — |
| `presence_penalty` | `number` | No | — |
| `frequency_penalty` | `number` | No | — |
| `repetition_penalty` | `number` | No | — |
| `top_k` | `number` | No | — |
| `n` | `number` | No | — |
| `logprobs` | `boolean` | No | — |
| `top_logprobs` | `number` | No | — |
| `prediction` | `object` | No | — |
| `parallel_tool_calls` | `boolean` | No | — |
| `reasoning_effort` | `none \| minimal \| low \| medium \| high \| xhigh \| max` | No | — |
| `prompt_mode` | `reasoning` | No | — |
| `guardrails` | `object[]` | No | — |
| `prompt_cache_key` | `string` | No | — |
| `service_tier` | `auto \| standard_only` | No | — |
