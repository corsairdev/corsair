## Api Keys

### create

`apiKeys.create`

Create an API key. Create a project-scoped API key using a global (organization-scoped) API key. Supply projectId for an active project in the authenticated organization; scopeType must be project or omitted. Project-scoped API keys cannot create keys, and global keys cannot create other global keys. Mints a new API key.

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.steel.api.apiKeys.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | A human-readable label for the new key. Defaults to Default. |
| `projectId` | `string` | No | The active project to bind the new key to, belonging to the authenticated organization. Required when authenticating with a global API key. Dashboard users may omit it to use their default project. |
| `scopeType` | `project \| global` | No | Defaults to `project`. Global API keys may only create project-scoped keys. Only organization admins using dashboard authentication may create a `global` key; projectId is ignored for those keys. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `createdAt` | `string \| null` | No | — |
| `id` | `string \| null` | No | — |
| `key` | `string \| null` | No | The full secret on creation or rotation only. Metadata reads return a masked preview. Store a newly created secret securely; it cannot be retrieved later. |
| `name` | `string \| null` | No | — |
| `projectId` | `string \| null \| null` | No | The pinned project, or null for a global key, which binds to no project. |
| `scopeType` | `string \| null` | No | `project` pins the key to one project. `global` authorizes access across the organization and has no project binding. |
| `updatedAt` | `string \| null` | No | — |

## Credentials

### create

`credentials.create`

Stores credentials. Encrypts and stores credentials for an origin.

**Risk:** `write`

```ts
await corsair.steel.api.credentials.create({
	value: {},
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `additionalOrigins` | `string[]` | No | Canonical http(s) origins, besides `origin`, this credential may be filled on, such as its login host or identity provider (e.g. `https://login.example.com`). Only the credential's origin and these ever match a page, exactly; at most 20. |
| `label` | `string` | No | Label for the credential |
| `namespace` | `string` | No | The namespace the credential is stored against. Defaults to "default". |
| `origin` | `string` | No | Website origin the credential is for |
| `projectId` | `string` | No | Project to store the credential in. |
| `value` | `Record<string, string>` | Yes | Value for the credential |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `additionalOrigins` | `string[] \| null` | No | Canonical http(s) origins, besides `origin`, this credential may be filled on, such as its login host or identity provider (e.g. `https://login.example.com`). Only the credential's origin and these ever match a page, exactly; at most 20. |

### commands.run

`sessions.commands.run`

Run commands. Drives the session's browser with high-level commands such as snapshot, click, and fill. Commands run in order and stop at the first failure. Send a random Idempotency-Key header to make retries safe.

**Risk:** `write`

```ts
await corsair.steel.api.sessions.commands.run({
	sessionId: 'example',
	commands: { command: 'navigate', url: 'https://example.com' },
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `sessionId` | `string` | Yes | Session ID |
| `idempotency_key` | `string` | No | A random value. A retry with the same key returns the stored result. |
| `after` | `string` | No | The next value from your last response. A retry with the same after and commands runs only once. |
| `commands` | `object \| object[]` | Yes | One command, or an array of up to 50. They run in order and stop at the first failure. Commands that already ran are not undone. |
| `observe` | `object` | No | Returns a snapshot, or a diff against the last one, after the commands. |
