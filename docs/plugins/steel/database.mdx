---
title: "Steel database"
sidebarTitle: "Database"
description: "The Steel plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Steel. To read its data, call the [API operations](/plugins/steel/api), which return what Steel has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
