## Balance

### get

`balance.get`

Read the remaining API credits, the funding source and the wallet amount

**Risk:** `read`

```ts
await corsair.textcortex.api.balance.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `object` | `string \| null` | No | — |
| `currency` | `string \| null` | No | — |
| `remaining_credits` | `number \| null` | No | — |
| `api_credit_purchases_allowed` | `boolean \| null` | No | — |
| `billing_source` | `object \| null` | No | — |
| `wallet` | `object \| null` | No | — |

<AccordionGroup>

## Chat

### completions

`chat.completions`

Generate a chat completion from a conversation, which spends credits on every call

**Risk:** `write`

```ts
await corsair.textcortex.api.chat.completions({ model: 'gpt-6-luna', messages: [{ role: 'user', content: 'Hello' }], temperature: 0.7 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `model` | `string` | Yes | A model ID from `models.list`. Use the base ID and set `reasoning_effort` rather than a `-thinking` variant, which is deprecated. |
| `messages` | `object[]` | Yes | The conversation, oldest first. |
| `max_tokens` | `number` | No | Cap the tokens generated. |
| `temperature` | `number` | No | Sampling temperature, 0 to 2. |
| `top_p` | `number` | No | Nucleus sampling probability, 0 to 1. |
| `n` | `number` | No | How many completions to generate. |
| `stop` | `string \| string[]` | No | A stop sequence, or a list of them. |
| `presence_penalty` | `number` | No | — |
| `frequency_penalty` | `number` | No | — |
| `seed` | `number` | No | A seed for reproducible output. |
| `user` | `string` | No | A caller-side user identifier for abuse tracking. |
| `reasoning_effort` | `none \| low \| medium \| high` | No | How much reasoning the model should spend, for models that grade it. |
| `response_format` | `object` | No | Ask for a structured answer, e.g. `{ type: "json_object" }`. |

Spends credits; messages take a plain string content, and a temperature runs from 0 to 2.

<AccordionGroup>
<Accordion title="messages full type">

```ts
{
  role: system | user | assistant | tool,
  content: string,
  name?: string
}[]
```
</Accordion>

<Accordion title="response_format full type">

```ts
{
  type: string
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `object` | `string \| null` | No | — |
| `created` | `number \| null` | No | — |
| `model` | `string \| null` | No | — |
| `choices` | `object[]` | Yes | — |
| `usage` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="choices full type">

```ts
{
  index?: number | null,
  finish_reason?: string | null,
  message?: {
    role?: string | null,
    content?: string | null
  } | null
}[]
```
</Accordion>

<Accordion title="usage full type">

```ts
{
  completion_tokens?: number | null,
  prompt_tokens?: number | null,
  total_tokens?: number | null,
  prompt_tokens_details?: {
    cached_tokens?: number | null
  } | null
} | null
```
</Accordion>
</AccordionGroup>

## Images

### create

`images.create`

Generate images from a prompt, returning URLs or base64 JSON, and spend credits per image

**Risk:** `write`

```ts
await corsair.textcortex.api.images.create({ prompt: 'A red bicycle on a white background', size: '1024x1024' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `prompt` | `string` | Yes | What the image should show. |
| `model` | `string` | No | An image model ID. The API picks its default when omitted. |
| `n` | `number` | No | How many images to generate. |
| `size` | `string` | No | The output size as "WIDTHxHEIGHT", e.g. "1024x1024". |
| `response_format` | `url \| b64_json` | No | Whether to return a URL or base64 JSON. |

Spends credits per image; response_format is url or b64_json.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `created` | `number \| null` | No | — |
| `data` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  url?: string | null,
  b64_json?: string | null,
  revised_prompt?: string | null
}[]
```
</Accordion>
</AccordionGroup>

## Responses

### create

`responses.create`

Generate one response from a prompt and optional instructions, which spends credits

**Risk:** `write`

```ts
await corsair.textcortex.api.responses.create({ model: 'gpt-6-luna', input: 'Say hello', instructions: 'You are a friendly assistant.' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `model` | `string` | Yes | A model ID from `models.list`. Use the base ID and set `reasoning_effort` rather than a `-thinking` variant, which is deprecated. |
| `input` | `string` | Yes | The prompt or conversation text. |
| `instructions` | `string` | No | A system instruction that applies to the whole response. |
| `max_output_tokens` | `number` | No | — |
| `temperature` | `number` | No | — |
| `top_p` | `number` | No | — |
| `store` | `false` | No | TextCortex requires this to be false, since it stores no conversation. |

Spends credits; store is always sent as false and store: true is rejected.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `object` | `string \| null` | No | — |
| `created_at` | `number \| null` | No | — |
| `model` | `string \| null` | No | — |
| `status` | `string \| null` | No | — |
| `output` | `object[] \| null` | No | — |
| `output_text` | `string \| null` | No | — |
| `usage` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="output full type">

```ts
{
  type?: string | null,
  text?: string | null,
  id?: string | null,
  role?: string | null
}[] | null
```
</Accordion>

<Accordion title="usage full type">

```ts
{
  input_tokens?: number | null,
  output_tokens?: number | null,
  total_tokens?: number | null
} | null
```
</Accordion>
</AccordionGroup>

## Web

### search

`web.search`

Search the web and return matching sources, which is a paid call rather than a plain read

**Risk:** `write`

```ts
await corsair.textcortex.api.web.search({ query: 'textcortex api', max_results: 5 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | What to search for. |
| `max_results` | `number` | No | Cap the number of results. |

A paid call rather than a plain read.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `results` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="results full type">
