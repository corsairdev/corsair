Use **TextCortex** through Corsair: one client, typed API calls.

Create a key in your TextCortex account's API settings. The plugin sends it as `Authorization: Bearer <key>`. Keep it server-side.

Things to know before you call:

- **Every generation is paid.** `chat.completions`, `responses.create`, `images.create` and `web.search` each spend credits, so they are writes: a read-only caller cannot reach them. Check `balance.get` for what is left.
- **A 402 means the credits ran out.** Waiting does not help, so the plugin never retries a 402, and `TextCortexAPIError` exposes `isInsufficientCredits` so a caller can tell it apart from throttling.
- **The models route is the place to start.** `models.list` returns the IDs `chat.completions` and `responses.create` accept. Use the base ID and set `reasoning_effort` instead of a `-thinking` variant, which is deprecated.
- **Two request shapes.** `chat.completions` takes an OpenAI-style `messages` array. `responses.create` takes a single `input` string with optional `instructions`, and stores nothing: the plugin pins `store: false` and rejects `store: true`.
- **Text is the supported content.** `chat.completions` sends plain-text messages. Image inputs, tool calls and streaming are not modelled, so the plugin does not offer them rather than silently dropping a field.
- **Errors come in three shapes.** The chat route answers the OpenAI `{ error: { message, type } }` envelope, TextCortex's own routes answer `{ message, status }` or `{ detail }`, and a validation failure puts an array in `detail`. All three are parsed, and a validation array keeps each field's location.
- **No retried paid calls.** The plugin replays a 5xx only on a GET. A repeated completion can produce and bill a second answer, and TextCortex promises no idempotency key.

**What you get:**

- 7 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/textcortex better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/textcortex better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/textcortex better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/textcortex better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { textcortex } from '@corsair-dev/textcortex';

export const corsair = createCorsair({
	plugins: [
		textcortex(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the TextCortex API key before the first call: `pnpm corsair setup --plugin=textcortex --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
textcortex()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'textcortex',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List the available models**

```ts
const tenant = corsair.withTenant('acme');
await tenant.textcortex.api.models.list({});
```


**Ask a model a question**

```ts
const tenant = corsair.withTenant('acme');
await tenant.textcortex.api.chat.completions({
	model: 'gpt-6-luna',
	messages: [{ role: 'user', content: 'Hello' }],
});
```


See the full list on the [API](/plugins/textcortex/api) page.
