## Access Lists

### addCodes

`accessLists.addCodes`

Add access-list codes for a link exam.

**Risk:** `write`

```ts
await corsair.classmarker.api.accessLists.addCodes({
  access_list_id: 123456,
  access_codes: ['USER-001', 'USER-002'],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `access_list_id` | `number` | Yes | — |
| `access_codes` | `string[]` | Yes | — |
