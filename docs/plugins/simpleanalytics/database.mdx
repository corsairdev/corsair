---
title: "Simple Analytics database"
sidebarTitle: "Database"
description: "The Simple Analytics plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Simple Analytics. To read its data, call the [API operations](/plugins/simpleanalytics/api), which return what Simple Analytics has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
