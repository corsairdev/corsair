## Activities

### create

`activities.create`

Create a contact activity.

**Risk:** `write`

```ts
await corsair.givebutter.api.activities.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contact` | `string \| number` | Yes | — |
| `type` | `email \| meeting \| note \| phone_call \| sms \| completed_task \| volunteer_activity` | Yes | — |
| `note` | `string \| null` | No | — |
| `subject` | `string \| null` | No | — |
| `occurred_at` | `string \| null` | No | — |
| `timezone` | `string \| null` | No | — |



**Output**

|------|------|----------|-------------|
| `id` | `string \| number` | Yes | — |
