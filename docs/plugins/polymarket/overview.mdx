Use **Polymarket** through Corsair: one client, typed API calls.

Market data needs no key: Gamma (`gamma.*`: markets, events, tags,
series, sports, search), the Data API (`data.*`: positions, trades,
activity, holders, leaderboards, open interest), CLOB prices and books
(`clob.books.get`, `clob.prices.get`, `clob.pricesHistory.get` ...), Perps
market info (`perps.instruments`, `perps.book` ...) and the Bridge.

- **Trading on the CLOB** (`clob.orders.*`, balances, rewards,
notifications, `combos.*`) needs a CLOB API key set: connect with the API
key as the key and its `secret`, `passphrase` and wallet `address`. Make
one with `clob.apiKeys.create` or `clob.apiKeys.derive`, which take your
wallet's EIP-712 ClobAuth signature as `poly_address`, `poly_signature`,
`poly_timestamp` and `poly_nonce` (the plugin never holds a private
key). Each call is signed with the secret (HMAC-SHA256).
- **Orders are signed by your wallet.** `clob.orders.create` takes the
order your wallet signed (the TypeScript or Python SDK builds it);
Perps orders, withdrawals and transfers carry their own signature too.
- **Perps account reads** (`perps.account.*`) take the `perps` option
`{ proxy, secret }` from `perps.proxy.create`; **RFQ partner** routes the
`rfq` option `{ keyId, secret }`; the **Relayer** the `relayer` option (a
relayer API key, or builder credentials).
- **Risk.** Placing orders, withdrawals, transfers, leverage and margin
changes, quotes, submitting transactions and minting API keys are
`destructive`, as is every cancel and delete. Lookups sent as POST
(batch prices, books, midpoints) are `read`.
- Token ids are long decimal strings (keep them as strings);
condition ids and addresses are 0x hex.

**What you get:**

- 276 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/polymarket better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/polymarket better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/polymarket better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/polymarket better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { polymarket } from '@corsair-dev/polymarket';

export const corsair = createCorsair({
	plugins: [
		polymarket(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Polymarket API key before the first call: `pnpm corsair setup --plugin=polymarket --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
polymarket()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'polymarket',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`bridge.quote`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.polymarket.api.bridge.quote({});
```


**`bridge.deposit`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.polymarket.api.bridge.deposit({});
```
