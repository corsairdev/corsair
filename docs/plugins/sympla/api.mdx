## Events

### get

`events.get`

Get one event: dates, address, host, category and publication status.

**Risk:** `read`

```ts
await corsair.sympla.api.events.get({ event_id: 'abc123def456' });
```

| `timezone` | `string` | No | IANA timezone for dates in and out. Sympla default: America/Sao_Paulo. |
| `fields` | `string` | No | Comma-separated snake_case fields to return. Omit for all. |

### list

`events.list`

List the events of the Sympla organizer, with cursor pagination.

**Risk:** `read`

```ts
await corsair.sympla.api.events.list({ published: 'all', page_size: 50 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `published` | `published \| not_published \| all` | No | Publication filter. Sympla default: published. |
| `from` | `string` | No | Start of the date range, local ISO-8601, e.g. 2025-09-08T00:00:00. |
| `timezone` | `string` | No | IANA timezone for dates in and out. Sympla default: America/Sao_Paulo. |
| `sort` | `asc \| desc` | No | Sort direction. |
| `field_sort` | `start_date \| end_date \| name` | No | Sort field. Sympla default: start_date. |
| `page_size` | `number` | No | Items per page, 1 to 200. Sympla default 100. |
| `cursor` | `string` | No | pagination.next_cursor from the previous page. |
| `fields` | `string` | No | Comma-separated snake_case fields to return. Omit for all. |

`published` is published (Sympla default), not_published or all. Pass `pagination.next_cursor` as `cursor` for the next page.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `pagination` | `object` | No | — |
| `sort` | `object` | No | — |

### checkInByQrCode

`participants.checkInByQrCode`

Check a participant in with the fields of a scanned ticket QR code. The API has no way to undo a check-in.

**Risk:** `destructive`

```ts
await corsair.sympla.api.participants.checkInByQrCode({
	event_id: 'abc123def456',
	itemId: 'item-1',
	walletId: 'wallet-1',
	signature: '<130-132 character signature from the QR code>',
	timestamp: 1698770407738,
	version: 1,
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event_id` | `string` | Yes | Event id hash, the `id` from events.list. |
| `itemId` | `string` | Yes | itemId from the scanned QR code payload. |
| `walletId` | `string` | Yes | walletId from the scanned QR code payload. |
| `signature` | `string` | Yes | signature from the scanned QR code payload. |
| `timestamp` | `number` | Yes | timestamp from the scanned QR code payload. |
| `version` | `number` | Yes | version from the scanned QR code payload. |

Pass the fields of the decoded ticket QR code (`itemId`, `walletId`, `signature`, `timestamp`, `version`). An expired code answers HTTP 410.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  check_in?: boolean | null,
  check_in_date?: string | null,
  check_in_id?: string | number | null
}
```
</Accordion>
</AccordionGroup>
