## Events

### list

`events.list`

List events for the authenticated organizer.

**Risk:** `read`

```ts
await corsair.sympla.api.events.list({ page: 1 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | Page number. |
| `page_size` | `number` | No | Page size. |
| `published` | `boolean` | No | Limit the list to published events. |
| `from` | `string` | No | Start date filter. |
| `to` | `string` | No | End date filter. |
| `field_sort` | `string` | No | Field used to sort the list. |
| `sort` | `ASC \| DESC` | No | ASC or DESC. |

Page starts at 1 when you set it. sort is ASC or DESC. Omit a filter to take the service default.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `pagination` | `object` | Yes | — |
