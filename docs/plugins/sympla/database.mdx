---
title: "Sympla database"
sidebarTitle: "Database"
description: "The Sympla plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Sympla. To read its data, call the [API operations](/plugins/sympla/api), which return what Sympla has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
