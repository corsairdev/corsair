## Companies

### create

`companies.create`

Create a company, optionally with its first contact in the same call. The role decides what the client portal shows it

**Risk:** `write`

```ts
await corsair.suitedash.api.companies.create({ name: 'Microsoft', role: 'Client', website: 'https://www.microsoft.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `role` | `Lead \| Client \| Prospect` | Yes | — |
| `phone` | `string \| null` | No | — |
| `home_phone` | `string \| null` | No | — |
| `work_phone` | `string \| null` | No | — |
| `shop_phone` | `string \| null` | No | — |
| `website` | `string \| null` | No | — |
| `full_address` | `string \| null` | No | — |
| `address` | `object` | No | — |
| `tags` | `string[] \| null` | No | — |
| `background_info` | `string \| null` | No | — |
| `public_custom_fields` | `Record<string, any> \| null` | No | — |
| `private_custom_fields` | `Record<string, any> \| null` | No | — |
| `target_custom_fields` | `Record<string, any> \| null` | No | — |
| `primaryContact` | `object` | No | — |

Set primaryContact.create_primary_contact_if_not_exists to create the first contact in the same call; first_name, last_name and email are then required inside it.

### get

`companies.get`

Read one company by uid or exact name, with its category, address, primary contact and custom fields

**Risk:** `read`

```ts
await corsair.suitedash.api.companies.get({ identifier: 'Schowalter-Parisian', meta: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `identifier` | `string` | Yes | The company's uid or its exact name. SuiteDash decides which from the value, so send the name as the name. |
| `meta` | `boolean` | No | Include the meta block: the paging object plus this account's custom field definitions. |

The identifier is a uid or an exact name; SuiteDash decides which from the value. Set meta to true to also get the paging and custom field definitions.

### meta

`companies.meta`

Read the meta attributes of the company custom fields, which is where the uuid keys a write uses come from

**Risk:** `read`

```ts
await corsair.suitedash.api.companies.meta({});
```

**Input:** _empty object_

Read this before writing custom fields: the keys are uuids unique to the account, not field names.


**Output:** `object`
