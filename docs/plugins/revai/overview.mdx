Use **Rev AI** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 3 typed API operations
- 1 synced entity (`job`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/revai better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/revai better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/revai better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/revai better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { revai } from '@corsair-dev/revai';

export const corsair = createCorsair({
	plugins: [
		revai(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Rev AI API key before the first call: `pnpm corsair setup --plugin=revai --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
revai()
```

More: [API Key](/concepts/api-key)

</Tab>
<Tab title="OAuth 2.0">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Rev AI OAuth app.

```ts
revai({
	authType: 'oauth_2',
})
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'revai',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Get a transcription job**

```ts
const tenant = corsair.withTenant('acme');
await tenant.revai.api.jobs.getJob({ id: 'Umx5c6F7pH7r' });
```


**Submit a transcription job**

```ts
const tenant = corsair.withTenant('acme');
await tenant.revai.api.jobs.submitJob({ media_url: 'https://example.com/interview.mp3' });
```


See the full list on the [API](/plugins/revai/api) page.

## Query synced data

Search synced jobs without hitting Rev AI.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.revai.db.job.search({
	data: {},
	limit: 50,
});
```

Synced entities: `job`. See [Database](/plugins/revai/database) for filters and operators.
