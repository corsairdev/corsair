The RevAI plugin syncs data locally. Use `corsair.revai.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Job

Path: `revai.db.job.search`

```ts
const rows = await corsair.revai.db.job.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `status` | `string` | equals, contains, startsWith, endsWith, in |
| `created_on` | `date` | equals, before, after, between |
| `completed_on` | `date` | equals, before, after, between |
| `metadata` | `string` | equals, contains, startsWith, endsWith, in |
| `language` | `string` | equals, contains, startsWith, endsWith, in |
| `failure` | `string` | equals, contains, startsWith, endsWith, in |
| `duration_seconds` | `number` | equals, gt, gte, lt, lte, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
