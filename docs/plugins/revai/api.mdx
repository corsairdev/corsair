## Jobs

### getJob

`jobs.getJob`

**Risk:** `read`

```ts
await corsair.revai.api.jobs.getJob({});
```

### getTranscript

`jobs.getTranscript`

Get transcript of a job

**Risk:** `read`

```ts
await corsair.revai.api.jobs.getTranscript({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `accept` | `application/vnd.rev.transcript.v1.0+json \| text/plain` | Yes | — |



**Output:** `object`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  monologues: {
    speaker?: number,
    elements: {
      type: string,
      value: string,
      ts?: number | null,
      end_ts?: number | null,
      confidence?: number | null
    }[]
  }[]
} | string
```
</Accordion>
</AccordionGroup>
