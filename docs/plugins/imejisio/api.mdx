## Designs

### render

`designs.render`

Render an Imejis template design into image/PDF bytes or a stored URL

**Risk:** `write`

```ts
await corsair.imejisio.api.designs.render({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `designId` | `string` | Yes | The design render code from the design render URL |
| `format` | `png \| jpeg \| webp \| pdf` | No | Output format. Defaults to jpeg per the Imejis OpenAPI spec |
| `quality` | `number` | No | JPEG quality from 1 to 100 (only affects jpeg output) |
| `delivery` | `stream \| hosted \| signed` | No | Delivery mode: stream (raw bytes normalized to base64), hosted (public URL), or signed (expiring URL). Defaults to "stream". |
| `expiresIn` | `number` | No | Signed delivery only: link lifetime in minutes (default 60, maximum 7 days = 10080) |
| `overrides` | `Record<string, any>` | No | Key-value overrides for dynamic design template fields |



**Output:** `object`
