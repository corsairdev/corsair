Use **Imejis.io** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 1 typed API operations
- 1 synced entity (`renders`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/imejisio better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/imejisio better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/imejisio better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/imejisio better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { imejisio } from '@corsair-dev/imejisio';

export const corsair = createCorsair({
	plugins: [
		imejisio(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Imejis.io API key before the first call: `pnpm corsair setup --plugin=imejisio --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
imejisio()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'imejisio',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Render a design**

```ts
const tenant = corsair.withTenant('acme');
await tenant.imejisio.api.designs.render({ designId: 'design_123' });
```


**`designs.render`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.imejisio.api.designs.render({});
```


See the full list on the [API](/plugins/imejisio/api) page.

## Query synced data

Search synced renders without hitting Imejis.io.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.imejisio.db.renders.search({
	data: {},
	limit: 50,
});
```

Synced entities: `renders`. See [Database](/plugins/imejisio/database) for filters and operators.
