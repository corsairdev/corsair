## Boards

### copy

`boards.copy`

Copy an existing board, including its content, into a new board with its own name and team

**Risk:** `write`

```ts
await corsair.miro.api.boards.copy({ boardId: 'uXjVK1abcd=', name: 'Copy of roadmap' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `boardId` | `string` | Yes | The board to copy. |
| `name` | `string` | No | Name for the copy. |
| `description` | `string` | No | — |
| `teamId` | `string` | No | Team to put the copy in. |
| `projectId` | `string` | No | — |

The source board is a required `copy_from` query parameter on a PUT to the collection, which this operation fills from `boardId`.

**Risk:** `write`


| `teamId` | `string` | No | The team to create it in. |

### list

List the boards the token can reach, filtered by team, project, owner or name, with offset paging

**Risk:** `read`

```ts
await corsair.miro.api.boards.list({ limit: 10, sort: 'last_modified' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `teamId` | `string` | No | Only boards in this team. |
| `projectId` | `string` | No | Only boards in this project. |
| `query` | `string` | No | Only boards whose name contains this text. |
| `owner` | `string` | No | Only boards owned by this user id. |

| `limit` | `number` | No | Results per page, up to 50. Defaults to 20. |

### remove

`boards.remove`

Delete a board and everything on it; Miro moves it to Trash, where an owner can restore it in the Miro UI for 90 days, but there is no API call to do so

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.miro.api.boards.remove({ boardId: 'uXjVK1abcd=' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `boardId` | `string` | Yes | The board id, as shown in the board URL. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |
