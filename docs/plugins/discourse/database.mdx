---
title: "Discourse database"
sidebarTitle: "Database"
description: "The Discourse plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Discourse. To read its data, call the [API operations](/plugins/discourse/api), which return what Discourse has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
