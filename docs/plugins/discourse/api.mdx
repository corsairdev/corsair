### download

`backups.download`

**Risk:** `read`


**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `filename` | `string \| number` | Yes | — |

**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | Discourse accepted the call; it answered with no body. |

### grant

`badges.grant`

Grant a badge to a user. (POST /user_badges.json)

**Risk:** `destructive`

```ts
await corsair.discourse.api.badges.grant({ username: 'ada' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `username` | `string` | Yes | The username of the user to grant the badge to. |
| `badge_id` | `number` | No | The ID of the badge to grant. Either badge_id or badge_name is required. |
| `badge_name` | `string` | No | The name of the badge to grant. Either badge_id or badge_name is required. |
| `reason` | `string` | No | Optional URL of a post or topic associated with the grant. Cannot be used together with post_id. |
| `post_id` | `number` | No | Optional ID of a visible, non-deleted post associated with the grant. Cannot be used together with reason. |
| `suppress_notification` | `boolean` | No | Suppress the notification for this grant only. Omit or set to false to preserve normal notification behavior, including existing suppression rules. The badge is still granted and grant events still occur. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | Discourse accepted the call; it answered with no body. |
