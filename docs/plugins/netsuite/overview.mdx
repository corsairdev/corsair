Use **NetSuite** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 84 typed API operations
- 13 synced entities (`customerPayments`, `customers`, `employees`, `invoices`, `itemFulfillments`, `itemReceipts`, and 7 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/netsuite
```
```bash yarn
yarn add corsair @corsair-dev/netsuite
```
```bash pnpm
pnpm install corsair @corsair-dev/netsuite
```
```bash bun
bun add corsair @corsair-dev/netsuite
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { netsuite } from '@corsair-dev/netsuite';

export const corsair = createCorsair({
	plugins: [
		netsuite({
			accountId: 'TSTDRV123',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="OAuth 2.0 (Recommended)">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your NetSuite OAuth app.

NetSuite needs your account ID to build account-specific REST and OAuth URLs.

```ts
netsuite({
	accountId: 'TSTDRV123',
})
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'netsuite',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List customer records**

```ts
const tenant = corsair.withTenant('acme');
await tenant.netsuite.api.records.listRecords({ recordType: 'customer', limit: 10 });
```


**Create a customer**

```ts
const tenant = corsair.withTenant('acme');
await tenant.netsuite.api.customers.createCustomer({
	body: {
		entityId: 'ACME',
		companyName: 'Acme Inc.',
		isPerson: false,
		subsidiary: { id: '1' },
	},
});
```


See the full list on the [API](/plugins/netsuite/api) page.

## Query synced data

Synced entities support `tenant.netsuite.db.<entity>.search()` and `.list()`: `customerPayments`, `customers`, `employees`, `invoices`, `itemFulfillments`, `itemReceipts`, `items`, `journalEntries`, `purchaseOrders`, `salesOrders`, `vendorBills`, `vendorPayments`, `vendors`.

See [Database](/plugins/netsuite/database) for filters and operators.
