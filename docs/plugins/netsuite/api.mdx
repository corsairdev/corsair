### upsertRecordByExternalId

`upsertRecordByExternalId`

Upsert a NetSuite record by external ID

**Risk:** `write`

```ts
await corsair.netsuite.api.upsertRecordByExternalId({
	record_type: 'customer',
	external_id: 'EXT-CUST-100',
	body: { companyName: 'Acme Global' },
});
```
