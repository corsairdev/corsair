Use **Pinecone** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 48 typed API operations
- 9 synced entities (`assistantFiles`, `assistants`, `backups`, `collections`, `indexes`, `models`, and 3 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/pinecone
```
```bash yarn
yarn add corsair @corsair-dev/pinecone
```
```bash pnpm
pnpm install corsair @corsair-dev/pinecone
```
```bash bun
bun add corsair @corsair-dev/pinecone
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { pinecone } from '@corsair-dev/pinecone';

export const corsair = createCorsair({
	plugins: [
		pinecone(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
pinecone()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'pinecone',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`assistantChat.chat`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.pinecone.api.assistantChat.chat({});
```


**`assistantFiles.delete`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.pinecone.api.assistantFiles.delete({});
```


See the full list on the [API](/plugins/pinecone/api) page.

## Query synced data

Synced entities support `tenant.pinecone.db.<entity>.search()` and `.list()`: `assistantFiles`, `assistants`, `backups`, `collections`, `indexes`, `models`, `namespaces`, `restoreJobs`, `vectors`.

See [Database](/plugins/pinecone/database) for filters and operators.
