## Indicators

### adx

`indicators.adx`

Read the ADX technical indicator for a symbol over an interval

**Risk:** `read`

```ts
await corsair.twelvedata.api.indicators.adx({ symbol: 'AAPL', interval: '1day', time_period: 14 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `symbol` | `string` | Yes | — |
| `interval` | `1min \| 5min \| 15min \| 30min \| 45min \| 1h \| 2h \| 4h \| 1day \| 1week \| 1month` | Yes | Candle size |
| `time_period` | `number` | No | Look-back period; the provider default depends on the indicator |
| `series_type` | `close \| open \| high \| low` | No | Which price the indicator reads; default close |
| `outputsize` | `number` | No | — |
| `exchange` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `meta` | `object \| null` | No | — |
| `values` | `Record<string, string \| null>[] \| null` | No | — |
| `status` | `string \| null` | No | ok or error |
| `code` | `number \| null` | No | — |
| `message` | `string \| null` | No | — |

<AccordionGroup>
<Accordion title="meta full type">

```ts
{
  symbol?: string | null,
  interval?: string | null,
  indicator?: string | null
} | null
```
</Accordion>
</AccordionGroup>
