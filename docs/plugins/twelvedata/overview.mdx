Use **Twelve Data** through Corsair: one client, typed API calls.

Create a free API key at https://twelvedata.com/pricing, or copy it from your dashboard. The key travels as the `apikey` query parameter on every request.

Things to know:

- **A 200 can mean the lookup failed.** An unknown symbol answers HTTP 200 with `{ code: 400, status: 'error', message: ... }`. The plugin reads `status` on every answer and throws `TwelveDataAPIError` when it says `error`, so a resolved promise means the data arrived.
- **Every number is a string.** Twelve Data sends prices and volumes as decimal strings (`"211.66"`), and the plugin keeps that type. Convert with `Number(...)` where arithmetic is needed.
- **Plan limits are per endpoint.** A 403 names the plan the endpoint needs, so `earnings`, `splits`, `dividends` and `profile` are left out: they need a paid plan and are not part of this plugin.
- **Paging is `outputsize`.** A time series returns the newest candles by default; `outputsize` caps them and `start_date` / `end_date` set a window. The free plan caps the interval history at 8 requests a minute.
- **Indicators return one shape each.** `rsi` answers `values[].rsi`, `macd` answers `macd`, `macd_signal` and `macd_hist`, and so on. Each value is a decimal string, and the schema keeps them as an open record rather than a fixed field list per indicator.
- **Reference lists answer without a key.** `stocks`, `forex_pairs`, `cryptocurrencies`, `exchanges`, `etf`, `funds` and `bonds` are open, which is why their shapes are the best documented here.
- **Two envelopes.** `stocks`, `forex_pairs`, `cryptocurrencies`, `exchanges` and `etf` answer `{ data: [...] }`. `funds` and `bonds` answer `{ result: { count, list } }`, so their schemas differ.

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/twelvedata better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/twelvedata better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/twelvedata better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/twelvedata better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { twelvedata } from '@corsair-dev/twelvedata';

export const corsair = createCorsair({
	plugins: [
		twelvedata(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Twelve Data API key before the first call: `pnpm corsair setup --plugin=twelvedata --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
twelvedata()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'twelvedata',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read the latest quote for a symbol**

```ts
const tenant = corsair.withTenant('acme');
await tenant.twelvedata.api.market.quote({ symbol: 'AAPL' });
```


**Read the last few candles for a symbol**

```ts
const tenant = corsair.withTenant('acme');
await tenant.twelvedata.api.market.timeSeries({ symbol: 'AAPL', outputsize: 7 });
```


See the full list on the [API](/plugins/twelvedata/api) page.
