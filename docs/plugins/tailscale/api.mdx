## Device Invites

### accept

`deviceInvites.accept`

Accept a device share invite from another tailnet into this key's tailnet, by its invite URL or code. The shared device then appears in devices.list. Needs a user's API access token: a share belongs to a user, so an OAuth client can't accept one.

**Risk:** `write`

```ts
await corsair.tailscale.api.deviceInvites.accept({ invite: 'https://login.tailscale.com/admin/invite/12346abc' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `invite` | `string` | Yes | The URL of the invite (in the form `https://login.tailscale.com/admin/invite/{code}`) or the `{code}` component of the URL. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `device` | `object \| null` | No | Information about the device being shared. |
| `sharer` | `object \| null` | No | The user who create the device share invite. |
| `acceptedBy` | `object \| null` | No | The user accepting the device share invite. |

### create

`deviceInvites.create`

Share a device with people outside the tailnet. Each invite gives an invite URL to send; with email set, Tailscale emails the invite itself. allowExitNode lets the recipient use the device as an exit node; multiUse lets several people accept one link. deviceId is the device `id` or `nodeId` from devices.list.

**Risk:** `destructive`

```ts
await corsair.tailscale.api.deviceInvites.create({
	deviceId: 'nKLggijBzX11CNTRL',
	invites: [{ multiUse: false, allowExitNode: false }],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deviceId` | `string` | Yes | ID of the device. Using the device's `nodeId` is preferred, but its numeric `id` value can also be used. |
| `invites` | `object[]` | Yes | — |

## Devices

### authorize

`devices.authorize`

Approve (authorized: true) or revoke approval for (authorized: false) a device when the tailnet requires device approval. Revoking cuts the device's access until it is approved again. deviceId is the device `id` or `nodeId` from devices.list.

**Risk:** `write`

```ts
await corsair.tailscale.api.devices.authorize({ deviceId: 'nKLggijBzX11CNTRL', authorized: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deviceId` | `string` | Yes | ID of the device. Using the device's `nodeId` is preferred, but its numeric `id` value can also be used. |
| `authorized` | `boolean` | Yes | - If `true`, authorize a new device or re-authorize a previously deauthorized device. - If `false`, deauthorize an authorized device. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | Tailscale accepted the call; it answers with no body. |

### get

`devices.get`

Get one device. fields: "all" adds routes, posture and connectivity details. deviceId is the device `id` or `nodeId` from devices.list.

**Risk:** `read`

```ts
await corsair.tailscale.api.devices.get({ deviceId: 'nKLggijBzX11CNTRL', fields: 'all' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deviceId` | `string` | Yes | ID of the device. Using the device's `nodeId` is preferred, but its numeric `id` value can also be used. |
| `fields` | `all \| default` | No | Optionally controls whether the response returns **all** fields or only a predefined subset of fields. Currently, there are two supported options: - **`all`:** return all fields in the response - **`default`:** return the following fields - `addresses` - `id` - `nodeId` - `user` - `name` - `hostname` - `clientVersion` - `updateAvailable` - `os` - `created` - `connectedToControl` - `lastSeen` - `keyExpiryDisabled` - `expires` - `authorized` - `isExternal` - `machineKey` - `nodeKey` - `blocksIncomingConnections` - `tailnetLockKey` - `tailnetLockError` - `tags` - `isEphemeral` If the `fields` parameter is not supplied, then the default (limited fields) option is used. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `addresses` | `string[] \| null` | No | A list of Tailscale IP addresses for the device, including both IPv4 (formatted as 100.x.y.z) and IPv6 (formatted as fd7a:115c:a1e0:a:b:c:d:e) addresses. |
| `id` | `string \| null` | No | The legacy identifier for a device; you can supply this value wherever &#123;deviceId&#125; is indicated in the endpoint. Note that although "id" is still accepted, "nodeId" is preferred. |
| `nodeId` | `string \| null` | No | The preferred identifier for a device; supply this value wherever &#123;deviceId&#125; is indicated in the endpoint. |
| `user` | `string \| null` | No | The user who registered the node. For untagged nodes, this user is the device owner. |
| `name` | `string \| null` | No | The MagicDNS name of the device. Learn more about MagicDNS at https://tailscale.com/docs/features/magicdns. |
| `hostname` | `string \| null` | No | The machine name in the admin console. Learn more about machine names at https://tailscale.com/docs/concepts/machine-names. |
| `clientVersion` | `string \| null` | No | The version of the Tailscale client software; this is empty for external devices. |
| `updateAvailable` | `boolean \| null` | No | 'true' if a Tailscale client version upgrade is available. This value is empty for external devices. |
| `os` | `string \| null` | No | The operating system that the device is running. |
| `created` | `string \| null` | No | The date on which the device was added to the tailnet; this is empty for external devices. |
| `connectedToControl` | `boolean \| null` | No | Indicates if the device recently maintained a TCP connection to the Tailscale control server. |
| `lastSeen` | `string \| null` | No | When the device was last connected to the Tailscale control server. Omitted if the device has never been online or `connectedToControl` is true. |
| `keyExpiryDisabled` | `boolean \| null` | No | 'true' if the keys for the device will not expire. Learn more at https://tailscale.com/docs/features/access-control/key-expiry. |
| `expires` | `string \| null` | No | The expiration date of the device's auth key. Learn more about key expiry at https://tailscale.com/docs/features/access-control/key-expiry. |
| `authorized` | `boolean \| null` | No | 'true' if the device has been authorized to join the tailnet; otherwise, 'false'. Learn more about device authorization at https://tailscale.com/docs/features/access-control/device-management/device-approval. |
| `isExternal` | `boolean \| null` | No | 'true', indicates that a device is not a member of the tailnet, but is shared in to the tailnet; if 'false', the device is a member of the tailnet. Learn more about node sharing at https://tailscale.com/docs/features/sharing. |
| `multipleConnections` | `boolean \| null` | No | 'true', indicates that multiple devices are currently connected using the same node key, which is usually a sign of node state being copied between machines. If only one device is connected using this node's key, the field is omitted. If the number of live connections goes back to 0 or 1, this field is also omitted, meaning it's not sticky. In case an attacker steals node state from a legitimate node, they can mask their activities by not connecting concurrently with the legitimate node. |
| `machineKey` | `string \| null` | No | For internal use and is not required for any API operations. This value is empty for external devices. |
| `nodeKey` | `string \| null` | No | Mostly for internal use, required for select operations, such as adding a node to a locked tailnet. Learn about tailnet locks at https://tailscale.com/docs/features/tailnet-lock. |
| `blocksIncomingConnections` | `boolean \| null` | No | 'true' if the device is not allowed to accept any connections over Tailscale, including pings. Learn more in the "Allow incoming connections" section of https://tailscale.com/docs/features/client/manage-preferences. |
| `enabledRoutes` | `string[] \| null` | No | The subnet routes for this device that have been approved by a tailnet admin. Learn more about subnet routes at https://tailscale.com/docs/features/subnet-routers. |
| `advertisedRoutes` | `string[] \| null` | No | The subnets this device requests to expose. Learn more about subnet routes at https://tailscale.com/docs/features/subnet-routers. |
| `clientConnectivity` | `object \| null` | No | clientConnectivity provides a report on the device's current physical network conditions. |
| `tags` | `string[] \| null` | No | Lets you assign an identity to a device that is separate from human users, and use it as part of an ACL to restrict access. Learn more about tags at https://tailscale.com/docs/features/tags. |

| `tailnetLockKey` | `string \| null` | No | The node's tailnet lock key. Every node generates a tailnet lock key (so the value will be present) even if tailnet lock is not enabled. Learn more about tailnet lock at https://tailscale.com/docs/features/tailnet-lock. |

| `postureIdentity` | `object \| null` | No | Contains extra identifiers from the device when the tailnet it is connected to has device posture identification collection enabled. | `postureStatus` | `object \| null` | No | Reports the status of a single posture for a device. |
| `isEphemeral` | `boolean \| null` | No | 'true' if the device is ephemeral. Learn more about ephemeral nodes at https://tailscale.com/docs/features/ephemeral-nodes. |

### list

`devices.list`

List the devices in the tailnet: name, hostname, Tailscale IPs, owner, OS, client version, tags, last seen, key expiry, authorized. Pass fields: "all" to add advertised and enabled routes, posture and connectivity details. filters narrows the list on the server by exact match on top-level device fields, all of them required to match (for example &#123; tags: ["tag:prod"], isEphemeral: true &#125;).

**Risk:** `read`

```ts
await corsair.tailscale.api.devices.list({
	filters: {
		tags: ['tag:mcp'],
	},
	fields: 'all',
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `tailnet` | `string` | No | The tailnet ID (T1234CNTRL, from Settings → General) or "-", the tailnet the key belongs to. Defaults to the plugin's `tailnet` option, else "-". |
| `fields` | `all \| default` | No | Optionally controls whether the response returns **all** fields or only a predefined subset of fields. Currently, there are two supported options: - **`all`:** return all fields in the response - **`default`:** return the following fields - `addresses` - `id` - `nodeId` - `user` - `name` - `hostname` - `clientVersion` - `updateAvailable` - `os` - `created` - `connectedToControl` - `lastSeen` - `keyExpiryDisabled` - `expires` - `authorized` - `isExternal` - `machineKey` - `nodeKey` - `blocksIncomingConnections` - `tailnetLockKey` - `tailnetLockError` - `tags` - `isEphemeral` If the `fields` parameter is not supplied, then the default (limited fields) option is used. |
| `filters` | `Record<string, string \| number \| boolean \| string[]>` | No | Server-side filters: top-level device fields matched exactly, all of them together, for example &#123; "tags": ["tag:prod"], "isEphemeral": true, "hostname": "mcp-1" &#125;. A list value matches devices that have every item. Objects such as clientConnectivity cannot be filtered on. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `devices` | `object[] \| null` | No | — |

**Risk:** `destructive`

```ts
await corsair.tailscale.api.keys.create({

		devices: {
			create: {
				reusable: false,
				ephemeral: true,

				tags: ['tag:agent'],
			},
		},
	},
});
```

| `keyType` | `auth \| client \| federated` | No | The type of key to create. Defaults to "auth" if omitted. |
