Use **Productboard** through Corsair: one client, typed API calls.

Configure a Productboard personal access token in Corsair. Productboard requires `Authorization: Bearer <token>` and `Accept: application/json`; personal access tokens are available on Pro plans and above. This plugin supports API-token authentication only. OAuth login, token issuance, and refresh are unavailable because Productboard's detailed OAuth guide and v2 per-route OpenAPI security sections disagree on authorization/token URLs and scopes; OAuth access-token compatibility is not claimed.

Productboard uses opaque cursor pagination (`pageCursor`) with `links.next`; its documented default rate limit is 50 requests per second per token. On 429 responses the shared transport preserves `Retry-After` and the plugin avoids duplicate retries.

Entity and note field names and values are workspace-configurable. The plugin strictly validates operation-level inputs and accepts JSON for provider-native request envelopes, query structures, and dynamic field maps. PII may be redacted by Productboard without `members:pii:read`. The customer-score operation is beta. All four documented webhook subscription-management routes are available, but inbound webhook/action callback handlers are not included. Documents operations are intentionally excluded: first-party entity references establish opaque document IDs, route paths and PBFM semantics, but not complete standalone auth, request, and response contracts. OAuth routes remain excluded because Productboard's OAuth guides and v2 OpenAPI security definitions disagree on URLs and scopes.

**What you get:**

- 58 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/productboard better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/productboard better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/productboard better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/productboard better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { productboard } from '@corsair-dev/productboard';

export const corsair = createCorsair({
	plugins: [
		productboard(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Productboard API key before the first call: `pnpm corsair setup --plugin=productboard --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
productboard()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'productboard',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List workspace teams**

```ts
const tenant = corsair.withTenant('acme');
await tenant.productboard.api.teams.list({
	query: { name: 'Product Team' },
});
```


**Create a synthetic feedback note**

```ts
const tenant = corsair.withTenant('acme');
await tenant.productboard.api.notes.create({
	body: {
		data: {
			type: 'textNote',
			fields: { name: 'Synthetic feedback', content: 'A synthetic example note.' },
		},
	},
});
```


See the full list on the [API](/plugins/productboard/api) page.
