Use **Stormglass** through Corsair: one client, typed API calls, local DB sync.

The key is the Authorization header with no Bearer prefix. Missing-key requests to stations, elevation, weather, solar, and tide extremes returned HTTP 403 API key is invalid. A box of four comma-separated numbers returned HTTP 422. The same path with box 58.0,17.0:59.0,18.0 returned HTTP 403. Hourly source maps other than sg are not returned. Coordinates are not written to the event. Every call counts against the daily quota.

**What you get:**

- 6 typed API operations
- 4 synced entities (`extremes`, `points`, `quotas`, `stations`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/stormglass better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/stormglass better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/stormglass better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/stormglass better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { stormglass } from '@corsair-dev/stormglass';

export const corsair = createCorsair({
	plugins: [
		stormglass(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Stormglass API key before the first call: `pnpm corsair setup --plugin=stormglass --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
stormglass()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'stormglass',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List stations**

```ts
const tenant = corsair.withTenant('acme');
await tenant.stormglass.api.stations.list({});
```


**`elevation.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.stormglass.api.elevation.get({});
```


See the full list on the [API](/plugins/stormglass/api) page.

## Query synced data

Synced entities support `tenant.stormglass.db.<entity>.search()` and `.list()`: `extremes`, `points`, `quotas`, `stations`.

See [Database](/plugins/stormglass/database) for filters and operators.
