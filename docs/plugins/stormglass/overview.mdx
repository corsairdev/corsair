Use **Stormglass** through Corsair: one client, typed API calls, local DB sync.

The plugin covers the whole Stormglass v2 API: hourly weather and marine forecasts, historical weather back to 2014, tide extremes and hourly sea levels, tide stations, astronomy, solar, bio and elevation.
Get a key from the Stormglass dashboard; it is sent as the Authorization header with no Bearer prefix. Every call counts against the account's daily request quota (10 a day on the free plan); each response's `quota` shows the limit and how many requests were used today. A 402 means the quota is used up.
Hourly ops return `values` (one number per parameter: the first source you asked for, else Stormglass's own `sg` blend) and `sources` (every source's value). Times are UTC; `start` and `end` take UNIX seconds or ISO strings such as 2024-01-01 or 2024-01-01T06, and one call covers at most 10 days.
Tide data is astronomical tide from the nearest tide station; `station` in the result names it and its distance. Coordinates are not written to events.

**What you get:**

- 10 typed API operations
- 4 synced entities (`extremes`, `points`, `quotas`, `stations`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/stormglass better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/stormglass better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/stormglass better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/stormglass better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { stormglass } from '@corsair-dev/stormglass';

export const corsair = createCorsair({
	plugins: [
		stormglass(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Stormglass API key before the first call: `pnpm corsair setup --plugin=stormglass --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
stormglass()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'stormglass',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Get tomorrow's wind and waves**

```ts
const tenant = corsair.withTenant('acme');
await tenant.stormglass.api.weather.get({
	lat: 58.7984,
	lng: 17.8081,
	params: 'windSpeed,waveHeight',
	start: '2024-06-02',
	end: '2024-06-03',
});
```
