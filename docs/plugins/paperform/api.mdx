## Coupons

### create

`coupons.create`

Create a coupon code on a form, with a fixed amount or percentage off.

**Risk:** `write`

```ts
await corsair.paperform.api.coupons.create({ form: 'eqadkzns', code: 'WELCOME10', enabled: true, target: 'price', discountPercentage: 10 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `form` | `string` | Yes | Form slug, custom slug or id (from forms.list). |
| `code` | `string` | Yes | Coupon code. |
| `enabled` | `boolean` | No | — |
| `target` | `price \| subscription` | No | What the discount applies to. |
| `discountAmount` | `number` | No | — |
| `discountPercentage` | `number` | No | — |
| `expiresAt` | `string \| null` | No | ISO date-time the coupon stops working. null never expires. |

`POST /v1/forms/{slug_or_id}/coupons`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `coupon` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="coupon full type">

```ts
{
  code: string,
  enabled?: boolean,
  target?: string | null,
  discountAmount?: number | null,
  discountPercentage?: number | null,
  expiresAt?: string | null
}
```
</Accordion>
</AccordionGroup>

## Webhooks

### create

`webhooks.create`

Add a webhook that posts each new submission (and optionally partial submission) of a form to an https URL.

**Risk:** `write`

```ts
await corsair.paperform.api.webhooks.create({ form: 'eqadkzns', targetUrl: 'https://example.com/paperform', triggers: ['submission'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `form` | `string` | Yes | Form slug, custom slug or id (from forms.list). |
| `targetUrl` | `string` | Yes | HTTPS URL Paperform posts each submission to. |
| `triggers` | `(submission \| partial_submission)[]` | Yes | Events that fire the webhook. |

`POST /v1/forms/{slug_or_id}/webhooks`. Business API. The target URL stays out of events.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `webhook` | `object` | Yes | — |

### list

`webhooks.list`

List a form's webhooks.

**Risk:** `read`

```ts
await corsair.paperform.api.webhooks.list({ form: 'eqadkzns' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `form` | `string` | Yes | Form slug, custom slug or id (from forms.list). |
| `limit` | `number` | No | Results per page. Paperform defaults to 20. |
| `skip` | `number` | No | Results to skip. |
| `afterId` | `string` | No | Only results after this id. |
| `beforeId` | `string` | No | Only results before this id. |
| `afterDate` | `string` | No | Only results created after this date (YYYY-MM-DD or ISO). |
| `beforeDate` | `string` | No | Only results created before this date (YYYY-MM-DD or ISO). |
| `sort` | `ASC \| DESC` | No | Order by creation date. |

`GET /v1/forms/{slug_or_id}/webhooks`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `webhooks` | `object[]` | Yes | — |
| `page` | `object` | Yes | — |
