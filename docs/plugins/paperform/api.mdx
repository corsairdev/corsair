## Forms

### list

`forms.list`

List forms. Submission answers are not read.

**Risk:** `read`

```ts
await corsair.paperform.api.forms.list({});
```

**Input:** _empty object_

GET /v1/forms. Stores id, title, and slug.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `forms` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="forms full type">

```ts
{
  id: string,
  title?: string,
  slug?: string
}[]
```
</Accordion>
</AccordionGroup>

## Spaces

### forms

`spaces.forms`

List forms in one space.

**Risk:** `read`

```ts

```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |

GET /v1/spaces/{id}/forms.
