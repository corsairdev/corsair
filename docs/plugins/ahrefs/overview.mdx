Use **Ahrefs** through Corsair: one client, typed API calls, local DB sync.

Things to know before you call:

- **Most calls cost API units.** Search Console (`gsc.*`), Web Analytics (`webAnalytics.*`), Rank Tracker, `public.*` and `management.*` calls are free; each Site Audit (`siteAudit.*`) read costs 50 units; Site Explorer and Keywords Explorer reads cost units per row, and some fields cost more. `subscriptionInfo.limitsAndUsage` shows what is left. Queries on ahrefs.com, wordcount.com and the keyword "ahrefs" are free test queries.
- **Search Console and Site Audit need a project.** Pass the `project_id` of an Ahrefs project with Google Search Console connected (or a `portfolio_id` for `gsc.*`). `management.projects` and `siteAudit.projects` list them; they return the id as a string, so pass it back as a number.
- **Web Analytics counts arrive as strings.** `visitors`, `visits`, `pageviews`, `entries` and `exits` come back as numeric strings such as `"689"`; rates and durations are numbers.
- **Brand Radar needs the add-on for Ahrefs' prompts.** Without it, `brandRadar.*` reads only cover a report's custom prompts (`prompts: 'custom'`, free). The `*Entities` variants take brands and competitors as names or URL groups in a POST body. `management.updateBrandRadarReport` must include `prompts_frequency`. The API has no working call to delete a report yet; delete reports in the Ahrefs app.
- **Social media posting is a write.** `socialMedia.createPost` with `timing: 'publish_now'` posts to the connected channels straight away; use `draft` or `scheduled` to review first.
- **Tables take `select`, `where`, `order_by` and `limit`.** `select` picks the columns that come back, so rows only carry the fields you asked for. `where` is a JSON filter string; the Ahrefs API reference lists the fields each endpoint accepts.

**What you get:**

- 154 typed API operations
- 7 synced entities (`domainMetrics`, `keywords`, `pages`, `rankings`, `refdomains`, `serpPositions`, and 1 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/ahrefs better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/ahrefs better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/ahrefs better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/ahrefs better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { ahrefs } from '@corsair-dev/ahrefs';

export const corsair = createCorsair({
	plugins: [
		ahrefs(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Ahrefs API key before the first call: `pnpm corsair setup --plugin=ahrefs --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

Provider walkthrough: [Get Credentials](/plugins/ahrefs/get-credentials).

```ts
ahrefs()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'ahrefs',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List Search Console queries for a project**

```ts
const tenant = corsair.withTenant('acme');
await tenant.ahrefs.api.gsc.keywords({ project_id: 1234567, date_from: '2026-10-01', limit: 20 });
```


**Save keywords to a new Keywords Explorer list**

```ts
const tenant = corsair.withTenant('acme');
await tenant.ahrefs.api.management.createKeywordList({
	name: 'Launch keywords',
	location: 'us',
	keywords: ['mcp server', 'ai agent integrations'],
});
```


See the full list on the [API](/plugins/ahrefs/api) page.

## Query synced data

Synced entities support `tenant.ahrefs.db.<entity>.search()` and `.list()`: `domainMetrics`, `keywords`, `pages`, `rankings`, `refdomains`, `serpPositions`, `subscriptionUsage`.

See [Database](/plugins/ahrefs/database) for filters and operators.
