## Gsc

### anonymousQueries

`gsc.anonymousQueries`

Estimate the queries Search Console hides as anonymous for a project

**Risk:** `read`

```ts
await corsair.ahrefs.api.gsc.anonymousQueries({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `select` | `string` | Yes | A comma-separated list of columns to return. |
| `where` | `string` | No | Filter expression as a JSON string; see the Ahrefs API docs for the fields this endpoint accepts. |
| `order_by` | `string` | No | A comma-separated list of columns to order results by, with optional direction. |
| `limit` | `number` | No | The number of results to return. |
| `timeout` | `number` | No | A manual timeout duration in seconds. |
| `project_id` | `number` | Yes | Project ID |
| `date_from` | `string` | Yes | The start date of the historical period in YYYY-MM-DD format. |
| `country` | `string` | Yes | A two-letter country code (ISO 3166-1 alpha-2). |
| `output` | `json` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `keywords` | `object[]` | Yes | — |

<Accordion title="keywords full type">

```ts
{
```
