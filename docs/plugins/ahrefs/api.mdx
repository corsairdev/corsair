## Batch Analysis

### analyze

`batchAnalysis.analyze`

Get SEO metrics for up to 200 targets in one request

**Risk:** `read`

```ts
await corsair.ahrefs.api.batchAnalysis.analyze({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `select` | `string[]` | Yes | A list of fields to return. |
| `order_by` | `string[]` | No | A list of fields to order the results by, with optional direction. |
| `targets` | `object[]` | Yes | A list of targets to do batch analysis. |
| `volume_mode` | `monthly \| average` | No | The search volume calculation mode: monthly or average. |
| `country` | `string` | No | A two-letter country code (ISO 3166-1 alpha-2). |
| `top_countries` | `number` | No | The number of countries to return in the org_traffic_top_by_country field. |
| `output` | `json` | No | — |

<AccordionGroup>
<Accordion title="targets full type">

```ts
{
  url: string,
  mode: exact | prefix | domain | subdomains,
  protocol: both | http | https
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `targets` | `object[]` | Yes | — |

## Brand Radar

### aiResponses

`brandRadar.aiResponses`

Brand Radar: get AI assistant answers that mention the brand or competitors

**Risk:** `read`

```ts
await corsair.ahrefs.api.brandRadar.aiResponses({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `select` | `string` | Yes | A comma-separated list of fields to return. |
| `where` | `string` | No | Filter expression as a JSON string; see the Ahrefs API docs for the fields this endpoint accepts. |
| `report_id` | `string` | No | The ID of the report to use. |
| `brand` | `string` | No | A comma-separated list of brands to search for. |
| `competitors` | `string` | No | A comma-separated list of competitors of your brands. |
| `data_source` | `string` | Yes | Comma-separated chatbot models: chatgpt, google_ai_overviews, google_ai_mode, gemini, perplexity, copilot, claude (custom prompts only), grok, google_ai_overviews_keywords, google_ai_mode_keywords. |
| `country` | `string` | No | A comma-separated list of two-letter country codes (ISO 3166-1 alpha-2). |
| `prompts` | `ahrefs \| custom` | No | The type of prompts to use. |
| `limit` | `number` | No | The number of results to return. |
| `date` | `string` | No | The date to search for in YYYY-MM-DD format. |
| `date_compared` | `string` | No | A date to compare date with, in YYYY-MM-DD format. |
| `order_by` | `relevance \| volume` | No | A column to order the results by. |
| `output` | `json` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ai_responses` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="ai_responses full type">

```ts
{
  brand_sentiment?: any[] | null,
  country?: string | null,
  data_source?: string | null,
  funnel_stage?: string | null,
  intent?: string[] | null,
  last_updated?: string | null,
  links?: any[] | null,
  question?: string | null,
  response?: string | null,
  search_queries?: string[] | null,
  status?: string | null,
  tags?: string[] | null,
  volume?: number | null
```

</Accordion>

### aiResponsesEntities

`brandRadar.aiResponsesEntities`

Brand Radar: get AI assistant answers that mention the brand or competitors, with brands and competitors given as names or URL groups

**Risk:** `read`

```ts
await corsair.ahrefs.api.brandRadar.aiResponsesEntities({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `select` | `string[]` | Yes | A list of fields to return. |
| `where` | `Record<string, any>` | No | Filter expression as a JSON object; see the Ahrefs API docs for the fields this endpoint accepts. |
| `report_id` | `string` | No | The ID of the report to use. |
| `brands` | `object[]` | No | A list of brand names and websites to search for. |
| `competitors` | `object[]` | No | A list of competitor names and websites to search for. |
| `content_filter` | `object` | No | Optional phrases used to include or exclude results based on their content. |
| `data_source` | `(chatgpt \| google_ai_overviews \| google_ai_mode \| gemini \| perplexity \| copilot \| claude \| grok \| google_ai_overviews_keywords \| google_ai_mode_keywords)[]` | Yes | A list of chatbot models. |
| `country` | `string[]` | No | A list of two-letter country codes (ISO 3166-1 alpha-2). |
| `prompts` | `ahrefs \| custom` | No | The type of prompts to use. |
| `limit` | `number` | No | The number of results to return. |
| `date` | `string` | No | The date to search for in YYYY-MM-DD format. |
| `date_compared` | `string` | No | A date to compare date with, in YYYY-MM-DD format. |
| `order_by` | `relevance \| volume \| object` | No | How to order the results: a column, or how the responses talk about one brand, as the Sentiment page in Brand Radar can. |
| `tags_filter` | `Record<string, any>` | No | A filter expression for prompt tags. |
| `brand_filter` | `Record<string, any>` | No | A filter expression for your brand's visibility, mirroring the "Your brand" filter. |
| `volume_range` | `object` | No | The volume range to filter by. |
| `changes` | `object` | No | Requires date_compared. |
| `sentiment_filter` | `Record<string, any>` | No | A filter on how the responses talk about your brands and competitors, like the Sentiment filter in Brand Radar. |
| `opinions_first` | `boolean` | No | Puts the responses with a positive, negative or mixed mention of a tracked brand before the others, each group by relevance, as the Sentiment page in Brand Rada |
| `output` | `json` | No | — |

</Accordion>

```ts
}
```
</Accordion>
