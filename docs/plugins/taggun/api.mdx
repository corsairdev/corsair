## Campaigns

### create

`campaigns.create`

Store a new set of validation rules under a campaign ID you choose; rejected if that ID already exists

**Risk:** `write`

```ts
await corsair.taggun.api.campaigns.create({
	campaignId: 'coffee-june-2026',
	settings: {
		merchantNames: {
			allowList: ['Fresh Market'],
		},
		balanceOwing: { max: 0.01 },
	},
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | Campaign ID, your choice, maximum 50 characters. |
| `settings` | `object` | Yes | Validation rules for the campaign. At least one section should be present: a campaign with no sections checks nothing. |

The campaign ID is yours to choose, up to 50 characters. At least one rule section is needed, or the campaign validates nothing. `balanceOwing.max` must be above zero: Taggun skips the comparison when it is 0.

### delete

`campaigns.delete`

Remove a campaign's validation rules permanently; later submissions against that campaign cannot evaluate them

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.taggun.api.campaigns.delete({ campaignId: 'coffee-june-2026' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | Campaign ID, your choice, maximum 50 characters. |

Permanently removes the campaign rules. Submit nothing against that campaign afterwards, since the removed rules cannot be evaluated.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `result` | `string` | No | — |
| `statusCode` | `number` | No | — |

### get

**Risk:** `read`

### list

`campaigns.list`

List the campaign IDs that have validation settings stored on the account; needs the Campaign Validation feature

**Risk:** `read`

```ts
await corsair.taggun.api.campaigns.list({});
```

**Input:** _empty object_

Returns a bare array of campaign IDs. An account without Campaign Validation enabled gets a 400 naming the feature rather than an empty list.


**Output:** `string[]`

### update

`campaigns.update`

Replace a campaign's stored validation rules wholesale: every section left out is removed, so re-send the response from `campaigns.get` with your changes

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.taggun.api.campaigns.update({
	campaignId: 'coffee-june-2026',
	settings: {
		merchantNames: {
			allowList: ['Fresh Market', 'Corner Store'],
		},
	},
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | Campaign ID, your choice, maximum 50 characters. |
| `settings` | `object` | Yes | Replaces the stored settings wholesale: every section left out is removed from the campaign. |

Replaces the stored rules wholesale: every section left out is removed. Read the current rules with `campaigns.get` and re-send them with your changes.

### validateFile

`campaigns.validateFile`

Check an uploaded receipt against a campaign's stored rules and return pass/fail per rule; a failed rule is a successful call reporting `successful: false`

**Risk:** `write`

```ts
await corsair.taggun.api.campaigns.validateFile({ campaignId: 'coffee-june-2026', file: new File([bytes], 'receipt.jpg') });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | Campaign ID, your choice, maximum 50 characters. |
| `file` | `custom` | Yes | The receipt or invoice, under 20 MB: PDF, JPG, PNG, GIF or HEIC. A `File` carries its own name and type, so prefer it over a bare `Blob`. |
| `language` | `string` | No | Two-letter language hint; leave empty for auto-detection. Taggun documents en, es, fr, jp, he/iw, et, lv, lt, fi, el, zh, th, ar and kh, recommends it for ar, kh, th and he, and ignores a code it does not act on. |
| `near` | `string` | No | — |
| `ipAddress` | `string` | No | — |
| `incognito` | `boolean` | No | — |
| `userId` | `string` | No | Caller-supplied identifier, maximum 50 characters. |
| `subAccountId` | `string` | No | Caller-supplied identifier, maximum 50 characters. |
| `referenceId` | `string` | No | Caller-supplied identifier, maximum 50 characters. |

A failed rule is a successful call reporting `successful: false` with `failedValidations`, not an error. Each call is one billable scan.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `successful` | `boolean` | Yes | True only when every enabled check passed. A receipt that fails a rule is a successful call with `false` here, not an error. |
| `failedValidations` | `string[]` | No | Validation keys that failed. |
| `passedValidations` | `string[]` | No | Validation keys that passed. |
| `productLineItems` | `object[] \| object` | No | The value itself, or `{ data, valid, expected, confidenceLevel }` when Taggun returns it with its verdict. |
| `matchedProductLineItems` | `object[]` | No | Items matched by the campaign rules. |
| `date` | `string \| object` | No | The value itself, or `{ data, valid, expected, confidenceLevel }` when Taggun returns it with its verdict. |
| `merchantName` | `string \| object` | No | The value itself, or `{ data, valid, expected, confidenceLevel }` when Taggun returns it with its verdict. |
| `merchantAddress` | `string \| object` | No | The value itself, or `{ data, valid, expected, confidenceLevel }` when Taggun returns it with its verdict. |
| `merchantCity` | `string \| object` | No | The value itself, or `{ data, valid, expected, confidenceLevel }` when Taggun returns it with its verdict. |

## Receipt Validation

### file

`receiptValidation.file`

Check an uploaded receipt against rules sent with this request, storing nothing; a failed rule is a successful call reporting `successful: false`

**Risk:** `write`

```ts
await corsair.taggun.api.receiptValidation.file({ file: new File([bytes], 'receipt.jpg'), validation: { merchantName: { allowed: ['H-E-B'] } } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `file` | `custom` | Yes | The receipt or invoice, under 20 MB: PDF, JPG, PNG, GIF or HEIC. A `File` carries its own name and type, so prefer it over a bare `Blob`. |
| `validation` | `object` | Yes | Rules for this request; nothing is stored. |
| `additionalExtractionFields` | `modelNumber[]` | No | Extra fields to expose on extracted objects. Only `modelNumber` is supported. |
| `containerId` | `string` | No | Caller-supplied identifier, maximum 50 characters. |
| `incognito` | `boolean` | No | — |
| `ipAddress` | `string` | No | — |
| `near` | `string` | No | — |
