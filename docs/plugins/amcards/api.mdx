## Cards

### list

`cards.list`

List cards for the authenticated account

**Risk:** `read`

```ts
const tenant = corsair.withTenant('acme');
await tenant.amcards.api.cards.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `skip` | `number` | No | Rows to skip (sent as Tastypie/DRF `offset`) |
| `limit` | `number` | No | Page size |



**Output:** `object`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  id: number | string
}[] | {
  count?: number,
  next?: string | null,
  previous?: string | null,
  results?: {
    id: number | string
  }[],
  meta?: {
    limit?: number,
    next?: string | null,
    offset?: number,
    previous?: string | null,
    total_count?: number
  },
  objects?: {
    id: number | string
  }[]
}
```
</Accordion>
</AccordionGroup>

### list

`categories.list`

List card template categories ordered by priority

**Risk:** `read`

```ts
const tenant = corsair.withTenant('acme');

```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `parent__id` | `number` | No | Filter sub-categories by parent id |
| `title__icontains` | `string` | No | Case-insensitive title search |
| `parent__title__icontains` | `string` | No | Case-insensitive parent title search |
