## Answers

### get

`answers.get`

Search the web and return a written answer with its sources ($0.006; deep $0.055).

**Risk:** `read`

```ts
await corsair.linkup.api.answers.get({ q: 'What is the capital of Norway?' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | — |
| `depth` | `flash \| fast \| standard \| deep` | No | flash, fast and standard cost the same and get slower and broader in that order; deep runs several searches and costs 10x. Default fast. |
| `includeInlineCitations` | `boolean` | No | Put numbered citations inside the answer text. |
| `fromDate` | `string` | No | Only sources published on or after this date (YYYY-MM-DD). |
| `toDate` | `string` | No | Only sources published on or before this date (YYYY-MM-DD). |
| `includeDomains` | `string[]` | No | Only search these domains. |
| `excludeDomains` | `string[]` | No | Never return these domains. |

`POST /v1/search` with outputType sourcedAnswer. Source text is not stored.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `answer` | `string` | Yes | — |
| `sources` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="sources full type">

```ts
{
  name?: string,
  url: string,
  snippet?: string,
  favicon?: string | null,
  publishedAt?: string
}[]
```
</Accordion>
</AccordionGroup>

## Pages

### fetch

`pages.fetch`

Fetch one web page or PDF as markdown, optionally with typed data from a schema ($0.001 to $0.011).

**Risk:** `read`

```ts
await corsair.linkup.api.pages.fetch({ url: 'https://example.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | — |
| `mode` | `standard \| pro` | No | pro gets past harder pages and costs 5x. Default standard. |
| `renderJs` | `boolean` | No | Run the page's JavaScript before reading it (costs 5x). |
| `extractImages` | `boolean` | No | — |
| `includeRawContent` | `boolean` | No | Also return the page's raw text. |
| `schema` | `Record<string, any>` | No | JSON Schema for typed data to pull from the page. |
| `instructions` | `string` | No | What to pull from the page, used with schema. |

`POST /v1/fetch`. Returns markdown and does not store the page.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `markdown` | `string` | Yes | — |
| `data` | `Record<string, any>` | No | — |
| `rawContent` | `string` | No | — |
| `images` | `any[]` | No | — |
| `contentType` | `string` | No | — |

## Research

### create

`research.create`

Start a multi-step research task ($0.25 to $2.50 by reasoningDepth). Poll research.get for the result.

**Risk:** `destructive`

```ts
await corsair.linkup.api.research.create({ q: 'When did the Oslo Opera House open?', reasoningDepth: 'S' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | The research question. |
| `reasoningDepth` | `S \| M \| L \| XL` | No | How hard to work: S $0.25 (default here), M $0.50, L $1.50, XL $2.50 per task. |
| `mode` | `auto \| answer \| investigate \| research` | No | — |
| `outputType` | `sourcedAnswer \| structured` | No | — |
| `schema` | `Record<string, any>` | No | JSON Schema for structured output; needed when outputType is structured. |
| `fromDate` | `string` | No | Only sources published on or after this date (YYYY-MM-DD). |
| `toDate` | `string` | No | Only sources published on or before this date (YYYY-MM-DD). |
| `includeDomains` | `string[]` | No | Only search these domains. |
| `excludeDomains` | `string[]` | No | Never return these domains. |

`POST /v1/research`. Returns the task; poll research.get.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `task` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="task full type">

```ts
{
  id: string,

  status: string,
  createdAt?: string,
  updatedAt?: string,
  error?: string | null,

}
```
</Accordion>

## Responses

**Risk:** `destructive`


| Name | Type | Required | Description |

| `input` | `string` | Yes | — |
| `model` | `linkup-standard \| linkup-deep` | Yes | linkup-standard is faster; linkup-deep is more thorough. |

**Output**

| Name | Type | Required | Description |

## Search

### run

`search.run`

Search the web and return results with their text content ($0.005 a call; deep $0.05). Filter by date and domain.

**Risk:** `read`

```ts
await corsair.linkup.api.search.run({ q: 'Corsair integrations for AI agents', depth: 'fast', maxResults: 5, fromDate: '2026-01-01' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | What to search for, in plain language. |
| `depth` | `flash \| fast \| standard \| deep` | No | flash, fast and standard cost the same and get slower and broader in that order; deep runs several searches and costs 10x. Default fast. |
| `maxResults` | `number` | No | — |
| `includeImages` | `boolean` | No | Also return image results. |
| `fromDate` | `string` | No | Only sources published on or after this date (YYYY-MM-DD). |
| `toDate` | `string` | No | Only sources published on or before this date (YYYY-MM-DD). |
| `includeDomains` | `string[]` | No | Only search these domains. |
| `excludeDomains` | `string[]` | No | Never return these domains. |

`POST /v1/search` with outputType searchResults. Stores name, url, type, and date of each result.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `results` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="results full type">

```ts
{
  type?: string,
  name?: string,
  url: string,
  content?: string,
  favicon?: string | null,
  publishedAt?: string
}[]
```
</Accordion>
</AccordionGroup>

### structured

`search.structured`

Search the web and return JSON shaped by your JSON Schema, optionally with sources ($0.006; deep $0.055).

**Risk:** `read`

```ts
await corsair.linkup.api.search.structured({ q: 'Population of Oslo', schema: { type: 'object', properties: { city: { type: 'string' }, population: { type: 'number' } } }, includeSources: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | — |
| `schema` | `Record<string, any>` | Yes | JSON Schema (type: object) for the data to return. |
| `depth` | `flash \| fast \| standard \| deep` | No | flash, fast and standard cost the same and get slower and broader in that order; deep runs several searches and costs 10x. Default fast. |
| `includeSources` | `boolean` | No | Also return the sources the data came from. |
| `fromDate` | `string` | No | Only sources published on or after this date (YYYY-MM-DD). |
| `toDate` | `string` | No | Only sources published on or before this date (YYYY-MM-DD). |
| `includeDomains` | `string[]` | No | Only search these domains. |
| `excludeDomains` | `string[]` | No | Never return these domains. |

`POST /v1/search` with outputType structured. The schema is sent as a JSON string.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `any` | Yes | — |
| `sources` | `object[]` | No | — |

<AccordionGroup>
<Accordion title="sources full type">

```ts
{
  name?: string,
  url: string,
  snippet?: string,
  favicon?: string | null,
  publishedAt?: string
}[]
```
</Accordion>
</AccordionGroup>

## Tasks

### create

`tasks.create`

Queue up to 100 search, fetch or research calls to run in the background, each billed like the direct call. Poll tasks.get.

**Risk:** `destructive`

```ts
await corsair.linkup.api.tasks.create({ tasks: [{ type: 'fetch', input: { url: 'https://example.com' } }, { type: 'search', input: { q: 'Oslo weather', depth: 'fast', outputType: 'searchResults' } }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `tasks` | `object[]` | Yes | — |

`POST /v1/tasks` with an array of up to 100 search, fetch or research inputs.

<AccordionGroup>
<Accordion title="tasks full type">

```ts
(
```
