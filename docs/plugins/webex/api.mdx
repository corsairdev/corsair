## Messages

### create

`messages.create`

Post a message to a room or directly to a person, with text, markdown, html or file attachments

**Risk:** `write`

```ts
await corsair.webex.api.messages.create({ roomId: 'Y2lzY29zcGFyazovL3VzL1JPT00vYTJjNDY', text: 'Your order shipped.' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `roomId` | `string` | No | The room to post to. |
| `toPersonId` | `string` | No | A one-to-one message to this person id. |
| `toPersonEmail` | `string` | No | A one-to-one message to this address. |
| `text` | `string` | No | — |
| `markdown` | `string` | No | — |
| `html` | `string` | No | — |
| `files` | `string[]` | No | Public URLs of files to attach. |
| `parentId` | `string` | No | Post as a reply in this thread. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `roomId` | `string \| null` | No | — |
