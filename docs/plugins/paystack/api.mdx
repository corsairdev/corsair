## Customers

### create

`customers.create`

Create a customer

**Risk:** `write`

```ts
await corsair.paystack.api.customers.create({ email: "john.doe@example.com", first_name: "John", last_name: "Doe" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | Customer email address |
| `first_name` | `string` | No | Customer first name |
| `last_name` | `string` | No | Customer last name |
| `phone` | `string` | No | Customer phone number |
| `metadata` | `Record<string, any>` | No | Custom data stored with the customer |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `boolean` | Yes | — |
| `message` | `string` | Yes | — |
| `data` | `object` | Yes | A Paystack customer |

## Refunds

### create

`refunds.create`

Refund a transaction fully or partially; money leaves the account and refunds cannot be undone

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.paystack.api.refunds.create({ transaction: "7PVGX8MEk85tgeEpVDtD", amount: 5000, merchant_note: "damaged goods" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `transaction` | `string` | Yes | Transaction reference or id to refund |
| `amount` | `number` | No | Amount in the currency subunit; defaults to the full amount |
| `currency` | `string` | No | Refund currency |
| `customer_note` | `string` | No | Note shown to the customer |
| `merchant_note` | `string` | No | Note recorded for the merchant |
| `reference` | `string` | No | Your reference for the refund |

Amount defaults to the full transaction amount; reference must be 8-64 characters of letters, digits, underscores or hyphens.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `boolean` | Yes | — |
| `message` | `string` | Yes | — |
| `data` | `object` | Yes | A Paystack refund |

### initialize

`transactions.initialize`

Start a checkout and get the authorization_url to redirect the customer to

```ts
await corsair.paystack.api.transactions.initialize({ amount: "10000", email: "john.doe@example.com", callback_url: "https://example.com/callback" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `amount` | `string` | Yes | Amount in the currency subunit |
| `email` | `string` | Yes | Customer email address |

| `currency` | `string` | No | Currency the transaction is charged in |
| `reference` | `string` | No | Your unique transaction reference |
| `callback_url` | `string` | No | Where the checkout redirects after payment |
| `plan` | `string` | No | Plan code to charge the customer for |
| `metadata` | `Record<string, any>` | No | Custom data returned with the transaction |

The answer carries authorization_url (redirect the customer), access_code (inline JS) and reference. Amount is in the currency subunit.



**Output**

|------|------|----------|-------------|
