## Accounts

### create

`accounts.create`

Connect a sending account with its IMAP and SMTP login (Google and Microsoft OAuth connections are not covered by this plugin). The passwords are sent to Instantly and never logged

**Risk:** `write`

```ts
await corsair.instantly.api.accounts.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | Email address of the account |
| `first_name` | `string` | Yes | First name associated with the account |
| `last_name` | `string` | Yes | Last name associated with the account |
| `warmup` | `object` | No | Warmup configuration for the account |
| `daily_limit` | `number` | No | Daily email sending limit |
| `tracking_domain_name` | `string` | No | Tracking domain |
| `tracking_domain_status` | `string` | No | Tracking domain status |
| `enable_slow_ramp` | `boolean` | No | Whether to enable slow ramp up for sending limits |
| `inbox_placement_test_limit` | `number` | No | The limit for inbox placement tests |
| `provider_code` | `1 \| 2 \| 3 \| 4 \| 8 \| 11` | Yes | Provider code for the account. Please make sure to specify the right provider code, otherwise your account will not work.; 1 Custom IMAP/SMTP, 2 Google, 3 Microsoft, 4 AWS, 8 AirMail, 11 Airmail Instant |
| `sending_gap` | `number` | No | The gap between emails sent from this account in minutes (minimum wait time when used with multiple campaigns) |
| `signature` | `string` | No | Email signature for the account |
| `reply_to` | `string` | No | — |
| `imap_username` | `string` | Yes | — |
| `imap_password` | `string` | Yes | — |
| `imap_host` | `string` | Yes | — |
| `imap_port` | `number` | Yes | — |
| `smtp_username` | `string` | Yes | — |
| `smtp_password` | `string` | Yes | — |
| `smtp_host` | `string` | Yes | — |
| `smtp_port` | `number` | Yes | — |
| `warmup_custom_ftag` | `string` | No | — |
| `skip_cname_check` | `boolean` | No | — |

### getDailyAnalytics

`accounts.getDailyAnalytics`

Emails sent per day by each sending account. Pass emails or a short date range: on a large workspace Instantly answers 413 otherwise

**Risk:** `read`

```ts
await corsair.instantly.api.accounts.getDailyAnalytics({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `start_date` | `string` | No | Start date for the analytics period. Defaults to a 30-day window ending at end_date. The maximum range is 31 days. |
| `end_date` | `string` | No | End date for the analytics period. Defaults to the current date. |
| `emails` | `string[]` | No | Email accounts to include. This filter is required and accepts at most 200 unique accounts. |

### list

`accounts.list`

List sending accounts (mailboxes) with status, warmup status, daily limit and warmup score; filter by status, provider, tag or search

**Risk:** `read`

```ts
await corsair.instantly.api.accounts.list({ filter: 'ACC_FILTER_W_ACTIVE', limit: 50 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | Items per page, 1 to 100 |
| `starting_after` | `string` | No | Cursor: `next_starting_after` from the previous page |
| `search` | `string` | No | Match account emails |
| `status` | `1 \| 2 \| 3 \| -1 \| -2 \| -3` | No | 1 Active, 2 Paused, 3 Maintenance, -1 Connection error, -2 Soft bounce error, -3 Sending error |
| `provider_code` | `1 \| 2 \| 3 \| 4 \| 8 \| 11` | No | — |
| `filter` | `ACC_FILTER_PAUSED \| ACC_FILTER_ERROR \| ACC_FILTER_NO_CTD \| ACC_FILTER_PW_ACCOUNTS \| ACC_FILTER_DFY \| ACC_FILTER_DFY_SETUP_PENDING \| ACC_FILTER_W_ACTIVE \| ACC_FILTER_W_PAUSED \| ACC_FILTER_W_ERROR` | No | Paused, has errors, no custom tracking domain, pre-warmed, DFY, DFY setup pending, or warmup active / paused / erroring |
| `tag_ids` | `string[]` | No | Accounts with any of these tag IDs |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `items` | `object[]` | Yes | — |
| `next_starting_after` | `string` | No | Pass as starting_after to get the next page; absent on the last page |
