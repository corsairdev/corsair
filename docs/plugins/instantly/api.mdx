## Accounts

### disableWarmup

`accounts.disableWarmup`

Turn warmup off for up to 100 sending accounts (runs as a background job; returns the job)

**Risk:** `write`

```ts
await corsair.instantly.api.accounts.disableWarmup({ emails: ['sam@fieldkit-mail.com'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `emails` | `string[]` | Yes | Sending account emails, up to 100 |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `type` | `string` | No | — |
| `status` | `string` | No | pending, in-progress, success, failed, draining, paused or cancelled |
| `progress` | `number` | No | 0 to 100 |
| `workspace_id` | `string` | No | — |
| `created_at` | `string` | No | — |
| `updated_at` | `string` | No | — |

### create

`campaigns.create`

Create a campaign as a draft: schedule, one sequence of email steps with A/B variants, sending accounts, daily limit and stop rules (stop_on_reply, stop_for_company). Sends nothing until campaigns.activate

**Risk:** `write`

```ts
await corsair.instantly.api.campaigns.create({
  name: 'Northeast IT leads',
  campaign_schedule: {
    schedules: [{
      name: 'Weekdays',
      timing: { from: '09:00', to: '17:00' },
      days: { '1': true, '2': true, '3': true, '4': true, '5': true },
      timezone: 'America/Detroit',
    }],
  },
  sequences: [{
    steps: [
      { delay: 3, variants: [{ subject: 'Quick question, {{firstName}}', body: 'Hi {{firstName}},<br/><br/>{{personalization}}' }] },
      { delay: 0, variants: [{ subject: '', body: 'Following up, {{firstName}}.' }] },
    ],
  }],
  email_list: ['sam@fieldkit-mail.com'],
  daily_limit: 30,
  stop_on_reply: true,
  stop_for_company: true,
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `campaign_schedule` | `object` | Yes | — |
| `sequences` | `object[]` | No | Exactly one sequence holding every step: Instantly reads only the first element |
| `email_list` | `string[]` | No | Sending account emails to rotate through |
| `email_tag_list` | `string[]` | No | Account tag IDs whose accounts send for this campaign |
| `daily_limit` | `number` | No | Most emails the campaign sends per day |
| `daily_max_leads` | `number` | No | Most new leads contacted per day |
| `email_gap` | `number` | No | Minutes between emails |
| `random_wait_max` | `number` | No | Extra random wait, in minutes, up to this |
| `stop_on_reply` | `boolean` | No | Stop the sequence for a lead once they reply |
| `stop_on_auto_reply` | `boolean` | No | Also stop on auto-replies such as out-of-office |
| `stop_for_company` | `boolean` | No | Stop the sequence for every lead at the same company (domain) when one replies |
| `text_only` | `boolean` | No | Send every email as plain text |
| `first_email_text_only` | `boolean` | No | Send only the first email as plain text |
| `link_tracking` | `boolean` | No | — |
| `open_tracking` | `boolean` | No | — |
| `insert_unsubscribe_header` | `boolean` | No | — |
| `prioritize_new_leads` | `boolean` | No | — |
| `match_lead_esp` | `boolean` | No | Send from accounts on the lead's email provider |
| `allow_risky_contacts` | `boolean` | No | — |
| `disable_bounce_protect` | `boolean` | No | — |
| `is_evergreen` | `boolean` | No | — |
| `pl_value` | `number` | No | Value of each positive lead |
