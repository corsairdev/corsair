Use **Instantly** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

Create an API v2 key in Instantly under Settings, Integrations, API keys, with the scopes you need. Things to know before you send:

- **Real email.** `campaigns.activate` starts sending to the campaign's leads and `emails.reply` sends a reply straight away. Neither is ever retried automatically; only read operations are.
- **Lifetime contact limit.** Every lead uploaded counts toward the plan's lifetime contact limit (1,000 on Growth), including re-uploads and the same person in a second campaign. `leads.create` and `leads.addBulk` default `skip_if_in_workspace` to `true` for that reason. Re-adding or moving a lead who already replied restarts their sequence at step 1.
- **Stopping a lead.** A lead's `status` is read-only. To stop follow-ups (for example after they answered on LinkedIn), call `leads.updateInterestStatus`, which completes the lead in its campaign.
- **Replies without webhooks.** Webhooks need the Hypergrowth plan or higher. On Growth, poll `emails.list` with `email_type: 'received'`; it allows 20 requests a minute.
- **Time zones.** Campaign schedules take Instantly's own time zone list, not all of IANA: US Eastern is `America/Detroit`.

**Webhook verification.** Instantly does not sign deliveries, but each webhook can carry custom headers. Store a random secret with `corsair.instantly.keys.set_webhook_signature(secret)` (or pass `webhookSecret`); `webhooks.create` then sends it as the `x-corsair-webhook-secret` header and the plugin rejects any delivery without it. For a webhook made in the Instantly UI, add that header by hand. Deliveries route to a tenant by their `workspace` ID: store it with `keys.set_tenant_external_id(workspaceId)` (the ID `workspace.get` returns).

**What you get:**

- 38 typed API operations
- 4 synced entities (`accounts`, `campaigns`, `emails`, `leads`) for fast `.search()` / `.list()`
- 19 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/instantly
```
```bash yarn
yarn add corsair @corsair-dev/instantly
```
```bash pnpm
pnpm install corsair @corsair-dev/instantly
```
```bash bun
bun add corsair @corsair-dev/instantly
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { instantly } from '@corsair-dev/instantly';

export const corsair = createCorsair({
	plugins: [
		instantly(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Tabs>

instantly()

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'instantly',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read unread Unibox emails**

```ts
const tenant = corsair.withTenant('acme');
await tenant.instantly.api.emails.list({ is_unread: true, min_timestamp_created: '2026-10-28T00:00:00Z', limit: 20 });
```


**Add leads to a campaign**

```ts
const tenant = corsair.withTenant('acme');
await tenant.instantly.api.leads.addBulk({
	campaign_id: '01a181d1-c62c-745b-b842-870ce5b29862',
	leads: [{
		email: 'jordan@acme-logistics.com',
		first_name: 'Jordan',
		company_name: 'Acme Logistics',
		custom_variables: { pain_point: 'slow onboarding' },
	}],
});
```


See the full list on the [API](/plugins/instantly/api) page.

## Query synced data

Leads seen through leads.list and leads.get are kept locally.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.instantly.db.leads.search({
	data: { company_name: 'Acme Logistics' },
	limit: 10,
});
```

Synced entities: `accounts`, `campaigns`, `emails`, `leads`. See [Database](/plugins/instantly/database) for filters and operators.

## Webhooks

Stop the lead's other outreach the moment they reply.

```ts
instantly({
    webhookHooks: {
        emails: {
            replyReceived: {
                after: async (ctx, result) => {
                    console.log('Reply from', result.data?.lead_email, result.data?.reply_text_snippet);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/instantly/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
