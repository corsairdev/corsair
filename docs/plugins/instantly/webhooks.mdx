The Instantly plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/instantly/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `accounts`
  - `error` (`accounts.error`)
- `campaigns`
  - `completed` (`campaigns.completed`)
- `emails`
  - `autoReplyReceived` (`emails.autoReplyReceived`)
  - `bounced` (`emails.bounced`)
  - `linkClicked` (`emails.linkClicked`)
  - `opened` (`emails.opened`)
  - `replyReceived` (`emails.replyReceived`)
  - `sent` (`emails.sent`)
- `events`
  - `other` (`events.other`)
- `leads`
  - `closed` (`leads.closed`)
  - `interested` (`leads.interested`)
  - `meetingBooked` (`leads.meetingBooked`)
  - `meetingCompleted` (`leads.meetingCompleted`)
  - `neutral` (`leads.neutral`)
  - `noShow` (`leads.noShow`)
  - `notInterested` (`leads.notInterested`)
  - `outOfOffice` (`leads.outOfOffice`)
  - `unsubscribed` (`leads.unsubscribed`)
  - `wrongPerson` (`leads.wrongPerson`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    const body = await request.json();
    const result = await processWebhook(corsair, headers, body);
    return result.response;
}
```
