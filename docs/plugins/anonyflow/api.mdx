## Core

### anonymize

`core.anonymize`

Anonymize sensitive data in text

**Risk:** `write`

```ts
await corsair.anonyflow.api.core.anonymize({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `text` | `string` | Yes | The raw text to anonymize |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `anonymizedText` | `string` | Yes | — |
