## Channels

### delete

`channels.delete`

Close a channel permanently; its message history is gone

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.revolt.api.channels.delete({ channel_id: '01F8Z1A2B3C4D5E6F7G8H9J0K1' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `channel_id` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |

### list

`messages.list`

Read a channel’s messages with time cursors, already carrying their authors

**Risk:** `read`

```ts
await corsair.revolt.api.messages.list({ channel_id: '01F8Z1A2B3C4D5E6F7G8H9J0K1', limit: 50 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `channel_id` | `string` | Yes | — |
| `limit` | `number` | No | Messages to return, up to 100. |
| `before` | `string` | No | A message id, such as `01F8Z0T8Y4W4Z8X3K5M2N1P0Q9`. |
| `after` | `string` | No | A message id, such as `01F8Z0T8Y4W4Z8X3K5M2N1P0Q9`. |
| `nearby` | `string` | No | A message id, such as `01F8Z0T8Y4W4Z8X3K5M2N1P0Q9`. |
| `sort` | `Oldest \| Latest \| Relevance` | No | Only meaningful with `nearby`. |
| `include_users` | `boolean` | No | Return the authors as `users` and `members` beside the messages. Defaults to true. |

The response carries `users` and `members` beside the messages, so authors resolve without a second call.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `messages` | `object[]` | Yes | — |
| `users` | `object[] \| null` | No | — |
| `members` | `object[] \| null` | No | — |

### send

`messages.send`

Send a message to a channel, optionally replying or attaching files

**Risk:** `write`

```ts
await corsair.revolt.api.messages.send({ channel_id: '01F8Z1A2B3C4D5E6F7G8H9J0K1', content: 'Standup in five' });
```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `channel_id` | `string` | Yes | — |
| `content` | `string` | No | — |
| `nonce` | `string` | No | A client id that makes a retry idempotent. |
| `replies` | `object[]` | No | — |
| `attachments` | `string[]` | No | Ids returned from the autumn upload service. |

Provide `content` or an attachment id; `nonce` makes a retry idempotent.
