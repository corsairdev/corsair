**Risk:** `destructive`

```ts
await corsair.modelry.api.embeds.delete({});
```

**Input**

|------|------|----------|-------------|
| `product_id` | `string \| number` | Yes | — |
| `id` | `string \| number` | Yes | — |



**Output:** `void`
