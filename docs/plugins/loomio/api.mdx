## Comments

### create

`comments.create`

Post a comment, or a reply to a comment, on a discussion, in markdown or html

**Risk:** `write`

```ts
await corsair.loomio.api.comments.create({ discussion_id: 88, body: 'Sounds good to me.' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `discussion_id` | `number` | Yes | The discussion to comment on (its numeric discussion id). |
| `parent_id` | `number` | No | Reply to this comment id inside the discussion. |
| `body` | `string` | Yes | The comment text. Required. |
| `body_format` | `md \| html` | No | Format of `body`; `md` (default) or `html`. |

discussion_id is the numeric discussion id (not the topic id). Set parent_id to reply to a comment. body_format takes md (default) or html.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `comment` | `object` | Yes | — |

## Discussions

### create

`discussions.create`

Start a discussion in a group; can notify the whole group and email invitations to recipient addresses

**Risk:** `destructive`

```ts
await corsair.loomio.api.discussions.create({ group_id: 12, title: 'Spring palette', description: 'Pick three colours for the rebrand.' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `group_id` | `number` | Yes | The group to start the discussion in. |
| `title` | `string` | Yes | The discussion title. Required. |
| `description` | `string` | No | The discussion body. |
| `description_format` | `md \| html` | No | Format of `description`; `md` (default) or `html`. |
| `recipient_audience` | `string` | No | Notify an audience in the group about the new discussion. |
| `recipient_user_ids` | `number[]` | No | Notify these user ids about the new discussion. |
| `recipient_emails` | `string[]` | No | Invite these email addresses to the group with the discussion. |
| `recipient_message` | `string` | No | Message sent to the notified recipients. |

recipient_audience: group notifies the whole group and recipient_emails emails invitations, so this is destructive. A permission denial answers the same 403 body a bad key does.

## Polls

### create

`polls.create`

Create a poll in a group or on a discussion; can invite the group to vote and email invitations to recipient addresses

**Risk:** `destructive`

```ts
await corsair.loomio.api.polls.create({ discussion_id: 88, title: 'Which blue?', poll_type: 'poll', options: ['Sky blue', 'Navy'], closing_at: '2026-04-01T00:00:00.000Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `group_id` | `number` | No | Start the poll in this group. Provide this or `discussion_id`. |
| `discussion_id` | `number` | No | Start the poll on this discussion. Provide this or `group_id`. |
| `title` | `string` | Yes | The poll question. Required. |
| `details` | `string` | No | The poll body text. |
| `details_format` | `md \| html` | No | Format of `details`; `md` (default) or `html`. |
| `poll_type` | `proposal \| poll \| count \| score \| ranked_choice \| meeting \| dot_vote` | Yes | Voting style: proposal, poll, count, score, ranked_choice, meeting, or dot_vote. |
| `options` | `string[]` | No | Option texts. For a proposal, Loomio uses agree, disagree, abstain, and block when omitted. |
| `poll_options_attributes` | `object[]` | No | Options with per-option settings; an alternative to `options`. |
| `closing_at` | `string \| null` | No | ISO 8601 close time. Omit or send null to keep the poll a draft with voting disabled. |
| `specified_voters_only` | `boolean` | No | Restrict voting to invited voters. |
| `hide_results` | `off \| until_vote \| until_closed` | No | Hide results until a vote is cast or until the poll closes. |
| `anonymous` | `boolean` | No | Hide voter identities. Options freeze after the first ballot. |
| `shuffle_options` | `boolean` | No | Show options in random order. |
| `stance_reason_required` | `disabled \| optional \| required \| required_for_disagree_or_block \| required_for_block` | No | When a reason statement is required with a vote. |
| `reason_prompt` | `string` | No | Question shown when a reason is requested. |
| `notify_on_closing_soon` | `nobody \| author \| voters_uncast \| voters` | No | Who is reminded before the poll closes. |
| `recipient_audience` | `string` | No | Notify an audience in the group about the poll. |
| `recipient_user_ids` | `number[]` | No | Notify these user ids about the poll. |
| `recipient_emails` | `string[]` | No | Invite these email addresses to vote. |
| `recipient_message` | `string` | No | Message sent to the notified recipients. |
| `notify_recipients` | `boolean` | No | Send the invitation notification. |

Provide group_id or discussion_id. Omit closing_at (or send null) to keep the poll a draft with voting disabled. For proposals, options default to agree, disagree, abstain, and block. notify_recipients: true emails everyone invited.
