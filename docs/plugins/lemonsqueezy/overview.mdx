Use **Lemon Squeezy** through Corsair: one client, typed API calls.

Every call goes through `https://api.lemonsqueezy.com` with the key as a Bearer token. The API speaks JSON:API 1.0, so responses carry `data`, `links`, `meta` and `jsonapi`, and a write body is `{ data: { type, id?, attributes, relationships? } }`. Those envelopes are returned as they arrive: `data.attributes` holds the fields. Three operations answer with `meta` and no `data`: `subscriptionItems.usage` returns the period's usage in `meta`, and `orders.generateInvoice` and `subscriptionInvoices.generate` return the link in `meta.urls.download_invoice`.

Lists page with `pageNumber` and `pageSize`, capped at 100 per page, and `meta.page.lastPage` says when to stop. Filters are each operation's own camelCase fields, such as `storeId` or `userEmail`, and the plugin sends them as `filter[store_id]` and so on. A field the operation does not define, such as a snake_case `store_id`, is dropped before the request, so the list comes back unfiltered rather than failing: use the field names in the API reference.

Money is in cents and its currency is the store's. A refund takes an optional `amount`; omit it to refund in full. A partial refund cannot be undone through the API, which is why `orders.refund` and `subscriptionInvoices.refund` are destructive.

A webhook is registered per store through `webhooks.create` with its own `secret`, and Lemon Squeezy signs each delivery with it. Deliveries are not routed through this plugin; verify them where they arrive.

**What you get:**

- 57 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/lemonsqueezy better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/lemonsqueezy better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/lemonsqueezy better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/lemonsqueezy better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { lemonsqueezy } from '@corsair-dev/lemonsqueezy';

export const corsair = createCorsair({
	plugins: [
		lemonsqueezy(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Lemon Squeezy API key before the first call: `pnpm corsair setup --plugin=lemonsqueezy --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
lemonsqueezy()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'lemonsqueezy',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read the latest orders**

```ts
const tenant = corsair.withTenant('acme');
await tenant.lemonsqueezy.api.orders.list({ pageSize: 10 });
```


**Create a checkout link for a variant**

```ts
const tenant = corsair.withTenant('acme');
await tenant.lemonsqueezy.api.checkouts.create({ storeId: 1, variantId: 1 });
```
