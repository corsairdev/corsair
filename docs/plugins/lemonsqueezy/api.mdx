## Checkouts

### create

`checkouts.create`

Create a checkout link for a variant and return its URL, with optional prefilled data, custom pricing and appearance

**Risk:** `write`

```ts
await corsair.lemonsqueezy.api.checkouts.create({ storeId: 1, variantId: 1, checkoutData: { email: 'buyer@example.com' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `storeId` | `number` | Yes | The store the checkout belongs to. |
| `variantId` | `number` | Yes | The variant to sell. Other variants of its product appear alongside it. |
| `customPrice` | `number` | No | Override the variant price, in cents. Only valid for a pay-what-you-want product. |
| `productOptions` | `Record<string, JsonValue>` | No | Overrides such as `name`, `description`, `redirect_url`, `receipt_button_text`, `receipt_link_url`, `receipt_thank_you_note` and `enabled_variants`. |
| `checkoutOptions` | `Record<string, JsonValue>` | No | Appearance and behaviour such as `embed`, `media`, `logo`, `desc`, `discount`, `subscription_preview`, the `*_color` values and `locale`. |
| `checkoutData` | `Record<string, JsonValue>` | No | Prefill and custom data such as `email`, `name`, `billing_address`, `tax_number`, `discount_code`, `custom` and `variant_quantities`. |
| `expiresAt` | `string` | No | When the checkout link stops working, as an ISO 8601 date. |
| `preview` | `boolean` | No | Return a preview checkout that cannot take a payment. |
| `testMode` | `boolean` | No | Create a test-mode checkout. Defaults to the store mode. |

The answer's `data.attributes.url` is the page to send a buyer to. `customPrice` is only valid for a pay-what-you-want product.



**Output**

|------|------|----------|-------------|
| `data` | `object` | Yes | — |
| `links` | `object` | No | — |
