## Accounts

### create

`accounts.create`

Create a QuickBooks account in the company chart of accounts

**Risk:** `write`

```ts
await corsair.quickbooks.api.accounts.create({ realmId: '12345678', name: 'Operating Checking', accountType: 'Bank' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `realmId` | `string` | Yes | QuickBooks company realm ID returned in Intuit’s OAuth redirect |
| `name` | `string` | Yes | — |
| `accountType` | `Bank \| Accounts Receivable \| Other Current Asset \| Fixed Asset \| Other Asset \| Accounts Payable \| Credit Card \| Other Current Liability \| Long Term Liability \| Equity \| Income \| Cost of Goods Sold \| Expense \| Other Income \| Other Expense` | No | — |
| `accountSubType` | `string` | No | — |
| `acctNum` | `string` | No | — |
| `taxCodeRef` | `object` | No | — |

POST /v3/company/&#123;realmId&#125;/account. Name must be unique, at most 100 characters, and cannot contain a double quote or colon. Supply accountType or accountSubType. Source: https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/account

```ts
  value: string
}
```
</Accordion>

| `realmId` | `string` | Yes | QuickBooks company realm ID returned in Intuit’s OAuth redirect |

GET /v3/company/&#123;realmId&#125;/query with SELECT * FROM Account. Pagination uses STARTPOSITION and MAXRESULTS (1–1000; default 100). Source: https://static.developer.intuit.com/output_html/qbo/docs/learn/explore-the-quickbooks-online-api/data-queries.html
