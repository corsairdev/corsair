---
title: "QuickBooks database"
sidebarTitle: "Database"
description: "The QuickBooks plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for QuickBooks. To read its data, call the [API operations](/plugins/quickbooks/api), which return what QuickBooks has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
