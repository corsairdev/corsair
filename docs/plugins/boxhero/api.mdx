## Item Attributes

### get

`itemAttributes.get`

Get an item attribute spec

**Risk:** `read`

```ts
const tenant = corsair.withTenant('acme');
await tenant.boxhero.api.itemAttributes.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `attr_id` | `number` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `item` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="item full type">

```ts
{
  id: number,
  attr_type: text | date | number | barcode,
  attr_name: string,
  rank: number
}
```
</Accordion>
</AccordionGroup>
