## Monitor

### chatgpt

`monitor.chatgpt`

Ask ChatGPT a prompt as a user in a given country and get the structured answer, sources, and shopping cards

**Risk:** `write`

```ts
await corsair.cloro.api.monitor.chatgpt({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `prompt` | `string \| string[]` | Yes | — |
| `country` | `string` | Yes | ISO 3166-1 alpha-2 country code; see utility.countries |
| `state` | `string` | No | US state for state-level targeting (+2 credits); see utility.states |
| `include` | `object` | No | — |
| `legacy` | `boolean` | No | — |
| `disableWebSearch` | `boolean` | No | — |
