## Company

### get

`company.get`

Read the company record the key belongs to: name, address and creation date

**Risk:** `read`

```ts
await corsair.remoteretrieval.api.company.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `company_name` | `string \| null` | No | — |
| `company_email` | `string \| null` | No | — |
| `address_1` | `string \| null` | No | — |
| `address_2` | `string \| null` | No | — |
| `city` | `string \| null` | No | — |
| `state` | `string \| null` | No | — |
| `zip` | `string \| null` | No | — |
| `created_date` | `string \| null` | No | A date such as 24-Jun-2024, not ISO 8601. |

## Orders

### create

`orders.create`

Create one or more equipment-return orders. Each order is a real, paid shipment: Remote Retrieval mails a box to the named employee's home address and bills the account the per-device fee shown by prices

**Risk:** `write`

```ts
await corsair.remoteretrieval.api.orders.create({ orders: [{ type_of_equipment: 'Laptop', order_type: 'Return To Company', employee_info: { email: 'a@b.com', name: 'Kenneth Davis', address_line_1: '1734 Steele Street', address_city: 'Houston', address_state: 'TX', address_country: 'United States', address_zip: '77001', phone: '1231231234' }, company_info: { return_person_name: 'Dorothy Buchanan', return_company_name: 'BigCo', return_address_line_1: '4522 Hanover Street', return_address_city: 'San Antonio', return_address_state: 'TX', return_address_country: 'United States', return_address_zip: '78015', email: 'it-team@example.com', phone: '1231231234' } }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `orders` | `object[]` | Yes | — |

<Accordion title="orders full type">

```ts

  ins_amount?: number,
  custom_msg?: string,
  employee_info: {
    email: string,

    address_line_1: string,
    address_line_2?: string,
    address_city: string,
    address_state: string,
    address_country: string,
    address_zip: string,
    phone: string
  },
  company_info: {
    return_person_name: string,
    return_company_name: string,
    return_address_line_1: string,
    return_address_line_2?: string,
    return_address_city: string,
    return_address_state: string,

    email: string,

  },
  new_employee_info?: {
    first_name: string,
    last_name: string,
    phone: string,
    email: string,
    address_line_1: string,
    address_city: string,
    address_state: string,
    address_zip: string,
    address_country: string,
    newemp_msg?: string
  }
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `order` | `string \| null` | No | The created order reference, as a string. One id comes back for a batch. |
| `message` | `string \| null` | No | — |
| `status` | `string \| null` | No | Success. |
| `response_code` | `number \| null` | No | — |

### list

`orders.list`

List every order with its payment status and shipping status, paged by the response's own next link

**Risk:** `read`

```ts
await corsair.remoteretrieval.api.orders.list({ cursor: 'abc123' });
```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `cursor` | `string` | No | The previous response's next link, passed as it came back; the plugin reads the cursor out of it. A bare cursor value also works. |

|------|------|----------|-------------|

## Validate

### validate

`validate`

Check that the API key works and read the account email it belongs to

**Risk:** `read`

```ts
await corsair.remoteretrieval.api.validate({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `message` | `string \| null` | No | "Valid Key!" on success. |
| `email` | `string \| null` | No | The account the key belongs to. |
| `status` | `string \| null` | No | Success. |
| `response_code` | `number \| null` | No | — |
