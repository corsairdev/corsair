## Connections

### create

`connections.create`

Create a new connection

**Risk:** `write`

```ts
await corsair.hookdeck.api.connections.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `source_id` | `string` | No | — |
| `destination_id` | `string` | No | — |
| `rules` | `object[]` | No | — |

<AccordionGroup>
<Accordion title="rules full type">

```ts
{
  type: string,
  count?: number,
  interval?: number,
  strategy?: string
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `team_id` | `string` | Yes | — |
| `name` | `string` | No | — |
| `full_name` | `string` | Yes | — |
| `disabled_at` | `string` | No | — |
| `paused_at` | `string` | No | — |
| `created_at` | `string` | Yes | — |
| `updated_at` | `string` | Yes | — |
| `rules` | `object[]` | No | — |
