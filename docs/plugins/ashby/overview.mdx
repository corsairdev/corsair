Use **Ashby** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 52 typed API operations
- 8 synced entities (`applications`, `candidates`, `departments`, `jobPostings`, `jobs`, `locations`, and 2 more) for fast `.search()` / `.list()`
- 10 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/ashby better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/ashby better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/ashby better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/ashby better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { ashby } from '@corsair-dev/ashby';

export const corsair = createCorsair({
	plugins: [
		ashby(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Ashby API key before the first call: `pnpm corsair setup --plugin=ashby --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
ashby()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'ashby',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`apiKey.info`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.ashby.api.apiKey.info({});
```


**`application.changeStage`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.ashby.api.application.changeStage({});
```


See the full list on the [API](/plugins/ashby/api) page.

## Query synced data

Synced entities support `tenant.ashby.db.<entity>.search()` and `.list()`: `applications`, `candidates`, `departments`, `jobPostings`, `jobs`, `locations`, `offers`, `users`.

See [Database](/plugins/ashby/database) for filters and operators.

## Webhooks

This plugin registers **10** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/ashby/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
