---
title: "E2B database"
sidebarTitle: "Database"
description: "The E2B plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for E2B. To read its data, call the [API operations](/plugins/e2b/api), which return what E2B has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
