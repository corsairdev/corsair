## Envd

### getEnvironmentVariables

`envd.getEnvironmentVariables`

Environment variables

**Risk:** `read`

```ts
await corsair.e2b.api.envd.getEnvironmentVariables({"headers":{"e2bSandboxId":"test","e2bSandboxPort":49983,"e2bAccessToken":"test-sandbox-access-token"}});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `headers` | `object` | Yes | — |

Requires an E2B sandbox access token; the response contains environment values and should be handled as sensitive data.

<AccordionGroup>
<Accordion title="headers full type">

```ts
{
  e2bSandboxId: string,
  e2bSandboxPort: number,
  e2bAccessToken: string
}
```
</Accordion>
</AccordionGroup>



**Output:** _empty object_
