Use **Google Drive** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 22 typed API operations
- 3 synced entities (`files`, `folders`, `sharedDrives`) for fast `.search()` / `.list()`
- 1 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/googledrive
```
```bash yarn
yarn add corsair @corsair-dev/googledrive
```
```bash pnpm
pnpm install corsair @corsair-dev/googledrive
```
```bash bun
bun add corsair @corsair-dev/googledrive
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { googledrive } from '@corsair-dev/googledrive';

export const corsair = createCorsair({
	plugins: [
		googledrive(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_DEV_API_KEY!,
		signingSecret: process.env.CORSAIR_DEV_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

</Tab>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'googledrive',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List files**

```ts
const tenant = corsair.withTenant('acme');
await tenant.googledrive.api.files.list({});
```


**Create a file**

```ts
const tenant = corsair.withTenant('acme');
await tenant.googledrive.api.files.createFromText({ name: 'hello.txt', content: 'Hello from Corsair' });
```


See the full list on the [API](/plugins/googledrive/api) page.

## Query synced data

Search synced files without hitting Drive.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.googledrive.db.files.search({
	data: { trashed: false },
	limit: 50,
});
```

Synced entities: `files`, `folders`, `sharedDrives`. See [Database](/plugins/googledrive/database) for filters and operators.

## Webhooks

Fires when a file or folder is created, updated, or deleted.

```ts
googledrive({
    webhookHooks: {
        driveChanged: {
            after: async (ctx, result) => {
                console.log('Drive change:', result.data?.changeType, result.data?.fileId ?? result.data?.folderId);
            }
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/googledrive/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
