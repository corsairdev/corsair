## Batch

### create

`batch.create`

Create multiple Fireberry records in one request

**Risk:** `write`

```ts
await corsair.fireberry.api.batch.create({ objectCode: '1', data: [{ accountname: 'Example Company' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `objectCode` | `string` | Yes | — |
| `data` | `Record<string, string \| number \| boolean \| null \| (string \| number \| boolean \| null)[] \| Record<string, any>>[]` | Yes | — |

Batch create accepts an array of records under data. Invalid items may fail while valid records in the same request are still created.



**Output:** _empty object_


---

### delete

`batch.delete`

Delete up to 20 Fireberry records in one request

**Risk:** `destructive`

```ts
await corsair.fireberry.api.batch.delete({ objectCode: '1', ids: ['00000000-0000-0000-0000-000000000001'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `objectCode` | `string` | Yes | — |
| `ids` | `string[]` | Yes | — |

Deletion accepts at most 20 record GUIDs under data. Batch API availability depends on the Fireberry license.



**Output:** _empty object_


---

### update

`batch.update`

Update multiple Fireberry records in one request

**Risk:** `write`

```ts
await corsair.fireberry.api.batch.update({ objectCode: '1', data: [{ id: '00000000-0000-0000-0000-000000000001', record: { accountname: 'Updated Example Company' } }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `objectCode` | `string` | Yes | — |
| `data` | `object[]` | Yes | — |

Each batch update item requires an id and a record field map. Invalid items may fail while valid records continue.

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  id: string,
  record: Record<string, string | number | boolean | null | (string | number | boolean | null)[] | Record<string, any>>
}[]
```
</Accordion>
</AccordionGroup>



**Output:** _empty object_

### query

`records.query`

Filter, sort, group, and paginate Fireberry records

**Risk:** `read`

```ts
await corsair.fireberry.api.records.query({ objectType: 1, fields: [{ name: 'accountname' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `objectType` | `number` | Yes | — |
| `fields` | `object[]` | Yes | — |
| `filter` | `object[]` | No | — |
| `orderBy` | `object[]` | No | — |
| `groupBy` | `object[]` | No | — |
| `pageNumber` | `number` | No | — |
| `pageSize` | `number` | No | — |

Query v3 supports pageSize up to 500. Aggregation requires groupBy; consult the query guide for the full structured filter semantics.

<AccordionGroup>
<Accordion title="fields full type">

```ts
{
  name: string,
  alias?: string,
  aggrFunc?: SUM | COUNT | MIN | MAX
}[]
```
</Accordion>

<Accordion title="filter full type">

```ts
{
  type: AND | OR,
  conditions: {
    fieldName: string,
    operator: eq | ne | lt | gt | le | ge | start-with | not-start-with | is-null | is-not-null | eq-in | not-in | between | userid,
    value?: string | number | boolean | (string | number)[]
  }[]
}[]
```
</Accordion>

<Accordion title="orderBy full type">

```ts
{
  name: string,
  order?: asc | desc
}[]
```
</Accordion>

<Accordion title="groupBy full type">

  name: string,

</Accordion>
</AccordionGroup>
