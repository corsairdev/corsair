## Batch

### create

`batch.create`

Create multiple Fireberry records in one request

**Risk:** `write`

```ts
await corsair.fireberry.api.batch.create({ objectCode: '1', data: [{ accountname: 'Example Company' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `objectCode` | `account \| activitylog \| article \| accountproduct \| businessunit \| campaign \| competitor \| contact \| contract \| invoicecredit \| invoicedelivery \| invoicedraft \| invoiceno \| invoicereno \| activity \| note \| opportunity \| crmorder \| crmorderitem \| calllog \| product \| project \| invoicereceipt \| task \| cases \| string` | Yes | — |
| `data` | `Record<string, JsonValue>[]` | Yes | — |

Batch create accepts 1–20 records under data. Invalid items may fail while valid records in the same request are still created.



**Output:** _empty object_


---

### delete

`batch.delete`

Delete up to 20 Fireberry records in one request

**Risk:** `destructive`

```ts
await corsair.fireberry.api.batch.delete({ objectCode: '1', ids: ['00000000-0000-0000-0000-000000000001'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `objectCode` | `account \| activitylog \| article \| accountproduct \| businessunit \| campaign \| competitor \| contact \| contract \| activity \| note \| opportunity \| crmorderitem \| calllog \| product \| project \| task \| cases \| string` | Yes | — |
| `ids` | `string[]` | Yes | — |

Pass 1–20 record GUIDs in ids; the plugin sends them to Fireberry as data. Batch API availability depends on the Fireberry license.



**Output:** `object \| undefined \| ""`

```ts
} | undefined | ""
```

`files.create`

**Risk:** `write`

```ts
await corsair.fireberry.api.files.create({ objectId: '1', recordId: '00000000-0000-0000-0000-000000000001', fileName: 'readme.txt', fileBase64: 'SGVsbG8=' });
```

| `fileName` | `string` | Yes | — |
| `fileBase64` | `string` | Yes | — |

The input base64 string is converted to the provider-required multipart `file` field. Fireberry encodes uploaded filenames; use alphanumeric names to avoid encoded punctuation.
