### upload

`documents.upload`

Upload a document and start memory indexing

**Risk:** `destructive`

```ts
await corsair.langbase.api.documents.upload({
	memoryName: 'support-knowledge',
	documentName: 'support-guide.pdf',
	contentBase64: 'SGVsbG8=',
	contentType: 'application/pdf',
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `memoryName` | `string` | Yes | — |
| `documentName` | `string` | Yes | — |
| `contentBase64` | `string` | Yes | — |
| `contentType` | `application/pdf \| text/plain \| text/markdown \| text/csv` | Yes | — |
| `meta` | `Record<string, string>` | No | — |

Upload requires `memoryName`, `documentName`, base64 file contents, and a supported MIME type (`application/pdf`, `text/plain`, `text/markdown`, or `text/csv`). The content type should match the document name; code files use `text/plain`. The signed URL is created and consumed internally; the output contains only the upload status.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ok` | `boolean` | Yes | — |
| `status` | `number` | Yes | — |
| `statusText` | `string` | Yes | — |

### retrieve

`memory.retrieve`

Retrieve relevant text chunks from one or more memories

**Risk:** `read`

```ts
await corsair.langbase.api.memory.retrieve({
	query: 'How can I contact support?',

});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | — |
| `memory` | `object[]` | Yes | — |
| `topK` | `number` | No | — |

`topK` is optional and ranges from 1 to 100. Filters use Langbase's documented nested tuple format.

<Accordion title="memory full type">

```ts
  name: string,
  filters?: [
    string,
    Eq | NotEq | In | NotIn,
    string | string[]

    (recursive)[]
  ]
}[]
```
</Accordion>
</AccordionGroup>

```ts
});
```

| `messages` | `object[]` | Yes | — |
