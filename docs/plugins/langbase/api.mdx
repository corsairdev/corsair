## Memory

### create

`memory.create`

Create a new managed semantic memory set

**Risk:** `write`

```ts
await corsair.langbase.api.memory.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `description` | `string` | No | — |
| `embedding_model` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `memory` | `Record<string, any>` | Yes | — |
