---
title: "Zoho Bigin database"
sidebarTitle: "Database"
description: "The Zoho Bigin plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Zoho Bigin. To read its data, call the [API operations](/plugins/zohobigin/api), which return what Zoho Bigin has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
