## Clients

### get

`clients.get`

Get a paginated list of Coassemble clients

**Risk:** `read`

```ts
await corsair.coassemble.api.clients.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `length` | `number` | No | — |
| `page` | `number` | No | — |



**Output:** `object[]`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  clientIdentifier: string,
  userCount?: number | null,
  metadata?: {
  },
  created?: string | number | null,
  updated?: string | number | null
}[]
```
</Accordion>
</AccordionGroup>
