## Assistant

### answer

`assistant.answer`

Ask the workspace assistant a question

**Risk:** `write`

```ts
await corsair.saperly.api.assistant.answer({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
