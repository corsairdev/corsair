---
title: "Genderize database"
sidebarTitle: "Database"
description: "The Genderize plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Genderize. To read its data, call the [API operations](/plugins/genderize/api), which return what Genderize has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
