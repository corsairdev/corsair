The Attio plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/attio/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `record`
  - `created` (`record.created`)
  - `deleted` (`record.deleted`)
  - `updated` (`record.updated`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Events

## Record

### Created

`record.created`

Triggered when a record is created

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event_type` | `record.created` | Yes | — |
| `id` | `object` | Yes | — |
| `actor` | `any` | No | — |

<AccordionGroup>
<Accordion title="id full type">

```ts
{
  workspace_id: string,
  object_id?: string,
  record_id: string
}
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  event_type: record.created,
  id: {
    workspace_id: string,
    object_id?: string,
    record_id: string
  },
  actor?: any
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
attio({
    webhookHooks: {
        record: {
            created: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
