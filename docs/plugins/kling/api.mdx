## Image Generation

### create

`imageGeneration.create`

Create a text-to-image or image-to-image task

**Risk:** `write`

```ts
await corsair.kling.api.imageGeneration.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `model_name` | `kling-v2-1 \| kling-v3` | No | — |
| `prompt` | `string` | Yes | — |
| `negative_prompt` | `string` | No | — |
| `image` | `string` | No | — |
| `image_reference` | `subject \| face` | No | — |
| `image_fidelity` | `number` | No | — |
| `human_fidelity` | `number` | No | — |
| `element_list` | `object[]` | No | — |
| `resolution` | `1k \| 2k` | No | — |
| `n` | `number` | No | — |
| `aspect_ratio` | `16:9 \| 9:16 \| 1:1 \| 4:3 \| 3:4 \| 3:2 \| 2:3 \| 21:9` | No | — |
| `watermark_info` | `object` | No | — |
| `callback_url` | `string` | No | — |
| `external_task_id` | `string` | No | — |

</Accordion>
</AccordionGroup>



**Output**

| `code` | `number` | Yes | — |
| `message` | `string` | No | — |
| `request_id` | `string` | No | — |
| `data` | `object` | Yes | — |

<Accordion title="data full type">
