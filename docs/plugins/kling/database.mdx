---
title: "Kling database"
sidebarTitle: "Database"
description: "The Kling plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Kling. To read its data, call the [API operations](/plugins/kling/api), which return what Kling has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
