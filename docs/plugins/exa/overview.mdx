Use **Exa** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 14 typed API operations
- 6 synced entities (`events`, `imports`, `monitors`, `searchResults`, `webhookConfigs`, `websets`) for fast `.search()` / `.list()`
- 4 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/exa better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/exa better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/exa better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/exa better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { exa } from '@corsair-dev/exa';

export const corsair = createCorsair({
	plugins: [
		exa(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Exa API key before the first call: `pnpm corsair setup --plugin=exa --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

Provider walkthrough: [Get Credentials](/plugins/exa/get-credentials).

```ts
exa()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'exa',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`answer.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.exa.api.answer.get({});
```


**`imports.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.exa.api.imports.create({});
```


See the full list on the [API](/plugins/exa/api) page.

## Query synced data

Synced entities support `tenant.exa.db.<entity>.search()` and `.list()`: `events`, `imports`, `monitors`, `searchResults`, `webhookConfigs`, `websets`.

See [Database](/plugins/exa/database) for filters and operators.

## Webhooks

This plugin registers **4** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/exa/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
