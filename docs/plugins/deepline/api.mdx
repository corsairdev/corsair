### autoRecharge.update

`billing.autoRecharge.update`

Turn automatic recharge on or off or change its limits (lets Deepline charge the saved card automatically)

**Risk:** `destructive`

```ts
await corsair.deepline.api.billing.autoRecharge.update({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `enabled` | `boolean` | Yes | true turns automatic recharge on (the saved card is charged whenever the balance drops below threshold_credits); false turns it off. |
| `threshold_credits` | `number` | No | Required when enabled is true: recharge when the balance drops below this many credits. |
| `refill_to_credits` | `number` | No | Required when enabled is true: buy enough credits to bring the balance back to this amount. |
| `purchase_limit_credits` | `number \| null` | No | Only with enabled true: maximum credits bought automatically over a rolling 30 days; 0 stops purchases, null removes the cap. |
| `idempotencyKey` | `string` | Yes | Required caller-owned key, 1-200 printable ASCII characters with no surrounding whitespace (a UUID works). Persist it before calling. Retrying with the same key and the same input replays the original operation instead of charging again; never generate a fresh key to retry an uncertain call. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `org_id` | `string` | Yes | — |
| `enabled` | `boolean` | Yes | — |
| `available` | `boolean` | Yes | — |
| `reason` | `string \| null \| null` | No | — |
| `threshold_credits` | `number \| null \| null` | No | — |
| `refill_to_credits` | `number \| null \| null` | No | — |
| `rolling_limit_cents` | `number \| null \| null` | No | — |
| `purchase_limit_cents` | `number \| null \| null` | No | — |
| `purchase_limit_credits` | `number \| null \| null` | No | — |
