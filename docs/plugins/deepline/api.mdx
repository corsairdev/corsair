### get

`runs.get`

Get one Play run status

**Risk:** `read`

```ts
await corsair.deepline.api.runs.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `runId` | `string` | Yes | The runId returned by the related Deepline API call. |
| `full` | `boolean` | No | true selects the legacy detail wrapper: status and result are top-level, and the compact package is nested under package. |
| `include` | `string` | No | Optional comma-separated expansions: nodeStates, runInsights, configuration. |
