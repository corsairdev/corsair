The Accredible plugin syncs data locally. Use `corsair.accrediblecertificates.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Credentials

Path: `accrediblecertificates.db.credentials.search`

```ts
const rows = await corsair.accrediblecertificates.db.credentials.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `name` | `string` | equals, contains, startsWith, endsWith, in |
| `description` | `string` | equals, contains, startsWith, endsWith, in |
| `group_name` | `string` | equals, contains, startsWith, endsWith, in |
| `issued_on` | `string` | equals, contains, startsWith, endsWith, in |
| `expired_on` | `string` | equals, contains, startsWith, endsWith, in |
| `complete` | `boolean` | equals |
| `approve` | `boolean` | equals |
| `private` | `boolean` | equals |
| `url` | `string` | equals, contains, startsWith, endsWith, in |
| `encoded_id` | `string` | equals, contains, startsWith, endsWith, in |
| `course_link` | `string` | equals, contains, startsWith, endsWith, in |
| `seo_image` | `string` | equals, contains, startsWith, endsWith, in |
| `recipient_name` | `string` | equals, contains, startsWith, endsWith, in |
| `recipient_email` | `string` | equals, contains, startsWith, endsWith, in |
| `issuer_name` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
