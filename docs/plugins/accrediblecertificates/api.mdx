## Credentials

### get

`credentials.get`

Get an credential resource by ID

**Risk:** `read`

```ts
await corsair.accrediblecertificates.api.credentials.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| number` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `credential` | `object` | Yes | — |
