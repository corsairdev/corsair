## Apps

### create

`apps.create`

Get a Modal App by name, creating an empty one if it does not exist. Sandboxes and image builds run inside an App.

**Risk:** `write`

```ts
await corsair.modal.api.apps.create({ name: 'my-app' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Name of a Modal App (as deployed or as created by apps.create). |
| `environment` | `string` | No | Modal environment to run in. Defaults to the account environment, else the workspace default. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `appId` | `string` | Yes | — |
| `name` | `string` | No | — |
| `environmentName` | `string` | No | — |

### sandboxStats

`apps.sandboxStats`

Cost in USD of an App's sandboxes over a time range (at most 7 days, on UTC hour boundaries), optionally grouped by tag values.

**Risk:** `read`


## Classes

### call

`classes.call`

Run a method of a deployed class and wait for its result (billed for the compute it uses).

**Risk:** `destructive`

```ts
await corsair.modal.api.classes.call({
	appName: 'my-app',
	className: 'Model',
	method: 'predict',
	parameters: { size: 'small' },
	args: ['hi'],
	waitMs: 0,
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `environment` | `string` | No | Modal environment to run in. Defaults to the account environment, else the workspace default. |
| `appName` | `string` | Yes | Name of a Modal App (as deployed or as created by apps.create). |
| `className` | `string` | Yes | Name of the deployed class (modal.Cls). |
| `method` | `string` | Yes | Method to run. |
| `parameters` | `Record<string, any>` | No | Values for the class's modal.parameter() fields. |
| `version` | `number` | No | — |
| `args` | `any[]` | No | Positional arguments (JSON values, sent CBOR-encoded). Defaults to []. |
| `kwargs` | `Record<string, any>` | No | Keyword arguments. Defaults to &#123;&#125;. |
| `options` | `object` | No | Override the deployed resources and settings for these calls (creates a variant of the function). |
| `waitMs` | `number` | No | How long to wait for the result. If the call is still running then, the result has status "pending" and functionCalls.get fetches it later. Defaults to 120000. |

<AccordionGroup>
<Accordion title="options full type">

```ts
{
  cpu?: number,
  cpuLimit?: number,
  memoryMiB?: number,
  memoryLimitMiB?: number,
  gpu?: string,
  env?: Record<string, string>,
  secrets?: string[],
  retries?: number,
  maxContainers?: number,
  bufferContainers?: number,
  scaledownWindowMs?: number,
  timeoutMs?: number,
  routingRegion?: string
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `functionCallId` | `string` | Yes | — |
| `status` | `completed \| pending` | Yes | — |
| `result` | `any` | No | Return value (bytes as &#123; $bytes: base64 &#125;). |
