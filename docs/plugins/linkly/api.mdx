## Clicks

### getCounters

`clicks.getCounters`

Group a workspace’s clicks by one dimension, such as country or UTM campaign, ordered by count

**Risk:** `read`

```ts
await corsair.linkly.api.clicks.getCounters({ workspace_id: 42, counter: 'country', start: '2026-06-01', end: '2026-06-30' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspace_id` | `number` | Yes | The workspace that owns the links. Find IDs with workspaces.listWorkspaces. |
| `counter` | `country \| city \| region \| platform \| destination \| referer \| bot_name \| isp \| link_id \| remote_ip \| top_params \| ad_network \| utm_source \| utm_medium \| utm_campaign \| utm_content \| utm_term` | Yes | The dimension to group clicks by. |
| `link_id` | `string` | No | A link ID, e.g. "30". One ID also works in link_ids. |
| `link_ids` | `string` | No | Hyphen-separated link IDs, e.g. "24-25-26". |
| `start` | `string` | No | YYYY-MM-DD or YYYY-MM-DDTHH:MM:SSZ. |
| `end` | `string` | No | YYYY-MM-DD or YYYY-MM-DDTHH:MM:SSZ. |
| `country` | `string` | No | ISO 3166-1 alpha-2 code, e.g. US. |
| `bots` | `boolean` | No | Include bot clicks. Defaults to false. |
| `unique` | `boolean` | No | Count unique visitors only. |
| `format` | `json \| csv \| tsv` | No | Defaults to 'json'. This plugin parses the json shape. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `total` | `number` | Yes | Clicks across all groups, including groups beyond the top 10,000 returned. |
| `values` | `object[]` | Yes | Ordered by count, highest first. |

### getTimeSeries

`clicks.getTimeSeries`

Read click counts over time for a workspace, filtered by link, date range, country and device, optionally pivoted into a links-by-date matrix

**Risk:** `read`

```ts
await corsair.linkly.api.clicks.getTimeSeries({ workspace_id: 42, start: '2026-06-01', end: '2026-06-30' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspace_id` | `number` | Yes | The workspace that owns the links. Find IDs with workspaces.listWorkspaces. |
| `link_id` | `string` | No | A link ID, e.g. "30". One ID also works in link_ids. |
| `link_ids` | `string` | No | Hyphen-separated link IDs, e.g. "24-25-26". |
| `start` | `string` | No | YYYY-MM-DD or YYYY-MM-DDTHH:MM:SSZ. |
| `end` | `string` | No | YYYY-MM-DD or YYYY-MM-DDTHH:MM:SSZ. |
| `country` | `string` | No | ISO 3166-1 alpha-2 code, e.g. US. |
| `browser` | `string` | No | — |
| `platform` | `string` | No | — |
| `referer` | `string` | No | — |
| `isp` | `string` | No | — |
| `bots` | `boolean` | No | Include bot clicks. Defaults to false. |
| `unique` | `boolean` | No | Count unique visitors only. |
| `format` | `json \| csv \| tsv` | No | Defaults to 'json'. This plugin parses the json shape. |
| `pivot` | `link_id` | No | Return a matrix instead of a time series: dates as rows, links as columns. |
| `timezone` | `string` | No | IANA name for bucket boundaries, e.g. America/New_York. Data is stored in UTC. |
| `frequency` | `day \| hour` | No | Bucket size. Defaults to 'day'. |



**Output:** `object`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  traffic: {

  }[]
} | {
  links: {
    id: number,
    name?: string | null,
    full_url: string
  }[],
  data: {
    date: string,
    clicks: Record<string, number | null>
  }[]
}
```
</Accordion>
</AccordionGroup>

### delete

`links.delete`

Move a link to the trash: its short URL stops redirecting straight away. links.restore can undo this while the link is still in the trash, and deleting a trashed link again is a harmless no-op

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.linkly.api.links.delete({ workspace_id: 42, id: 41657524 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspace_id` | `number` | Yes | The workspace that owns the links. Find IDs with workspaces.listWorkspaces. |
| `id` | `number` | Yes | The link to move to the trash. |



**Output:** `string`

```ts
await corsair.linkly.api.webhooks.list({ workspace_id: 42 });
```

```ts
{
  id: string
}[]
```

### subscribe

`webhooks.subscribe`

Register a webhook URL on a workspace; Linkly then POSTs there for every click. Deliveries arrive at that URL, not to this plugin

**Risk:** `write`

```ts
await corsair.linkly.api.webhooks.subscribe({ workspace_id: 42, url: 'https://hooks.example.com/linkly' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspace_id` | `number` | Yes | The workspace that owns the links. Find IDs with workspaces.listWorkspaces. |
| `url` | `string` | Yes | Receives a POST for every click in the workspace. Respond 2xx quickly; delivery is fire-and-forget with no retries. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The webhook URL. Pass it to webhooks.unsubscribe. |



---

### unsubscribe

`webhooks.unsubscribe`

Remove a webhook registration from a workspace by its URL, so it stops receiving click events

**Risk:** `write`

```ts
await corsair.linkly.api.webhooks.unsubscribe({ workspace_id: 42, hook_id: 'https://hooks.example.com/linkly' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspace_id` | `number` | Yes | The workspace that owns the links. Find IDs with workspaces.listWorkspaces. |
| `hook_id` | `string` | Yes | The webhook URL, exactly as webhooks.list or webhooks.subscribe returned it. Encoded into the path for you. |



**Output:** `string`
