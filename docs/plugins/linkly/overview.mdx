Use **Linkly** through Corsair: one client, typed API calls.

Create an API key in Linkly under Settings, API Keys at app.linklyhq.com. The key is
available on every plan, including the free one. Every workspace-scoped call takes a
`workspace_id` input; `workspaces.listWorkspaces` lists the IDs your key can reach.

Things to know before you send:

- **Create and update share one endpoint.** `links.create` POSTs a new link; `links.update`
  is the same call with the link's `id`, updating it in place. A repeat of `links.update`
  can never create a duplicate, which is why it is safe to retry.
- **Deleting is soft.** `links.delete` moves a link to the trash and its short URL stops
  redirecting straight away. `links.restore` takes links back out; a restored link whose
  back-half is already taken on the domain is reported under `conflicts`. Deleting a link
  that is already in the trash is a harmless no-op.
- **Click analytics has its own quota.** The link API allows 20 requests per second, but
  analytics is limited to 50 requests per hour per workspace, and Linkly sends no
  `Retry-After` header. The plugin retries a 429 three times with backoff; an exhausted
  hourly quota will still fail after those attempts.
- **`links.list` paging.** The API defaults to 1000 rows per page, the largest page it
  serves; `page_number` and `total_pages` in the answer tell you where you are.
- **Webhooks.** `webhooks.subscribe` and `webhooks.unsubscribe` manage the URLs that
  Linkly POSTs a click event to. The deliveries arrive at that URL; this plugin does not
  receive them, so point the URL at your own server.
- **Export.** `links.export` returns every link in the workspace at once, unpaginated.

**What you get:**

- 14 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/linkly better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/linkly better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/linkly better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/linkly better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { linkly } from '@corsair-dev/linkly';

export const corsair = createCorsair({
	plugins: [
		linkly(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Linkly API key before the first call: `pnpm corsair setup --plugin=linkly --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
linkly()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'linkly',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List links in a workspace**

```ts
const tenant = corsair.withTenant('acme');
await tenant.linkly.api.links.list({ workspace_id: 42, page_size: 50 });
```


**Create a tracked short link**

```ts
const tenant = corsair.withTenant('acme');
await tenant.linkly.api.links.create({
	workspace_id: 42,
	url: 'https://www.example.com/summer-sale',
	name: 'Summer sale',
	utm_source: 'newsletter',
});
```


See the full list on the [API](/plugins/linkly/api) page.
