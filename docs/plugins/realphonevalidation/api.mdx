## Active

### active

`active`

Report whether a US phone number sits on a provider still in business, which is a different question from whether it is connected

**Risk:** `read`

```ts
await corsair.realphonevalidation.api.active({ phone: '7275555555' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `phone` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `RESPONSECODE` | `string \| null` | No | L active landline, C active cell, V active VoIP, N inactive. |
| `RESPONSEMSG` | `string \| Record<string, never> \| null` | No | An error string, or &#123;&#125; when there is no error. |

## Dnc Lookup

### dncLookup

`dncLookup`

Check a US phone number against the national, state and DMA Do-Not-Call lists and the known-litigator list, and report its line type. Needs a SAN number from the national registry

**Risk:** `read`

```ts
await corsair.realphonevalidation.api.dncLookup({ phone: '7275555555' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `phone` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `RESPONSECODE` | `string \| null` | No | OK, or -1, 102 or invalid-phone for a refusal. |
| `RESPONSEMSG` | `string \| Record<string, never> \| null` | No | An error string, or &#123;&#125; when there is no error. |
| `national_dnc` | `string \| null` | No | Y is on the list, N is not, ? means a timeout or an unchecked list. Treat ? as unknown, not as cleared. |
| `state_dnc` | `string \| null` | No | Y is on the list, N is not, ? means a timeout or an unchecked list. Treat ? as unknown, not as cleared. |
| `dma` | `string \| null` | No | Y is on the list, N is not, ? means a timeout or an unchecked list. Treat ? as unknown, not as cleared. |
| `litigator` | `string \| null` | No | Y, N or ? for a known TCPA litigator or serial plaintiff. |
| `iscell` | `string \| null` | No | Y cell, N landline, V VoIP. |
| `id` | `string \| null` | No | An internal identifier. |

## Email Verify

### emailVerify

`emailVerify`

Verify an email address for validity, whether it is connected to an active online network, and whether it is disposable

**Risk:** `read`

```ts
await corsair.realphonevalidation.api.emailVerify({ email: 'johnsmith@test.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | The address to verify. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `retval` | `string \| null` | No | "0" for a good answer, "-1" when the request failed. |
| `error_text` | `string \| Record<string, never> \| null` | No | An error string, or &#123;&#125; when there is no error. |
| `error_code` | `string \| Record<string, never> \| null` | No | An error string, or &#123;&#125; when there is no error. |

| `disposable` | `string \| null` | No | Y or N: a disposable email provider. |

## Reassigned

### reassigned

`reassigned`

Report whether a US phone number changed owner since the date consent to contact was given

**Risk:** `read`

```ts
await corsair.realphonevalidation.api.reassigned({ phone: '7275555555', contact_date: '2010-01-01' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `phone` | `string` | Yes | — |
| `contact_date` | `string` | Yes | YYYY-MM-DD, the date consent to contact was given. A number reassigned after it must not be contacted. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `RESPONSECODE` | `string \| null` | No | OK, or -1 for a problem. |
| `RESPONSEMSG` | `string \| Record<string, never> \| null` | No | An error string, or &#123;&#125; when there is no error. |
| `reassigned` | `string \| null` | No | yes, no, no_data or undetermined. no_data means the carriers recorded no change since 27 January 2021, not that the number is safe to call. |
| `id` | `string \| null` | No | -1 on an error. |
