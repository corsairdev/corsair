## Alerting

### contacts.create

`alerting.contacts.create`

Create an alerting contact with notification targets

**Risk:** `write`

```ts
await corsair.pingdom.api.alerting.contacts.create({ name: "John Doe", notificationTargets: [{ email: "john@example.com", severity: "H" }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Contact name |
| `paused` | `boolean` | No | Create the contact paused |
| `notificationTargets` | `object[]` | Yes | Notification targets; each takes email or number (+countryCode) and an optional severity |

notificationTargets each take email or number with countryCode, plus an optional severity (H, M or L).

## Checks

### create

`checks.create`

Create an uptime check of any documented type

**Risk:** `write`

```ts
await corsair.pingdom.api.checks.create({ name: "api", host: "example.com", type: "http", typeSettings: { url: "/health", encryption: true }, resolution: "5" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Check name |
| `host` | `string` | Yes | Target host |
| `type` | `http \| httpcustom \| tcp \| ping \| dns \| udp \| smtp \| pop3 \| imap` | Yes | Type of check |
| `typeSettings` | `Record<string, any>` | No | Type-specific settings as flat body fields, per the check type docs: http takes url/encryption/port/shouldcontain/shouldnotcontain/postdata/requestheaders/verify_certificate/ssl_down_days_before; tcp takes port/encryption/stringtoexpect; dns takes nameserver/expectedip; udp/smtp/pop3/imap take port/stringtoexpect |
| `paused` | `boolean` | No | Create or leave the check paused |
| `resolution` | `1 \| 5 \| 15 \| 30 \| 60` | Yes | Test interval in minutes (1, 5, 15, 30 or 60) |
| `userIds` | `number[]` | No | User ids to alert |
| `teamIds` | `number[]` | No | Team ids to alert |
| `integrationIds` | `number[]` | No | Integration ids to alert |
| `sendNotificationWhenDown` | `number` | No | Alert after this many consecutive failures |
| `notifyAgainEvery` | `number` | No | Re-notify every N failures |
| `notifyWhenBackup` | `boolean` | No | Send an alert when the check recovers |
| `tags` | `string` | No | Comma-separated tags for filtering |
| `probeFilters` | `Record<string, any>[]` | No | Probe region filters, e.g. [&#123;"region":"EU"&#125;] or [&#123;"region":"NA"&#125;] |
| `ipv6` | `boolean` | No | Test over IPv6 |
| `responseTimeThreshold` | `number` | No | Response time threshold in ms |
| `customMessage` | `string` | No | Custom alert message |

type is one of http, httpcustom, tcp, ping, dns, udp, smtp, pop3, imap; typeSettings carries the flat type-specific fields from the docs (http: url, encryption, port, shouldcontain, shouldnotcontain, postdata, requestheaders, verify_certificate, ssl_down_days_before; tcp: port, encryption, stringtoexpect; dns: nameserver, expectedip).



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `check` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="check full type">

```ts
{
  id?: number | null,
  name?: string | null
}
```
</Accordion>
</AccordionGroup>

## Maintenance

### create

`maintenance.create`

Create a maintenance window

**Risk:** `write`

```ts
await corsair.pingdom.api.maintenance.create({ description: "Deploy window", from: 1700000000, to: 1700003600, recurrence: "weekly", checks: [100] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `description` | `string` | Yes | Description |
| `from` | `number` | Yes | Window start, UNIX time; only future allowed (use 1 for now) |
| `to` | `number` | Yes | Window end, UNIX time; only future allowed (use 1 for now) |
| `recurrence` | `none \| daily \| weekly \| monthly` | Yes | Recurrence interval |
| `recurring` | `0 \| 1` | Yes | Whether the window recurs (1) or is one-off (0) |
| `effectiveTo` | `number` | No | When the recurrence stops, UNIX time (0 = never) |
| `checks` | `number[]` | No | Check ids the window covers |
| `teams` | `number[]` | No | Team ids the window covers |
| `contacts` | `number[]` | No | Contact ids the window covers |

recurrence is none, daily, weekly or monthly; from and to must be in the future (use 1 for now); effectiveTo 0 means the recurrence never stops.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `maintenance` | `object` | Yes | — |
