The Claid.ai plugin syncs data locally. Use `corsair.claidai.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Edited Images

Path: `claidai.db.editedImages.search`

```ts
const rows = await corsair.claidai.db.editedImages.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `ext` | `string` | equals, contains, startsWith, endsWith, in |
| `mps` | `number` | equals, gt, gte, lt, lte, in |
| `mime` | `string` | equals, contains, startsWith, endsWith, in |
| `format` | `string` | equals, contains, startsWith, endsWith, in |
| `width` | `number` | equals, gt, gte, lt, lte, in |
| `height` | `number` | equals, gt, gte, lt, lte, in |
| `tmp_url` | `string` | equals, contains, startsWith, endsWith, in |
| `object_key` | `string` | equals, contains, startsWith, endsWith, in |
| `object_bucket` | `string` | equals, contains, startsWith, endsWith, in |
| `object_uri` | `string` | equals, contains, startsWith, endsWith, in |
| `claid_storage_uri` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
