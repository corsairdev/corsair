Use **BigMailer** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 57 typed API operations
- 13 synced entities (`brandProperties`, `brands`, `bulkCampaigns`, `connections`, `contacts`, `fields`, and 7 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/bigmailer
```
```bash yarn
yarn add corsair @corsair-dev/bigmailer
```
```bash pnpm
pnpm install corsair @corsair-dev/bigmailer
```
```bash bun
bun add corsair @corsair-dev/bigmailer
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { bigmailer } from '@corsair-dev/bigmailer';

export const corsair = createCorsair({
	plugins: [
		bigmailer(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
bigmailer()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'bigmailer',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`auth.me`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.bigmailer.api.auth.me({});
```


**`brandProperties.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.bigmailer.api.brandProperties.create({});
```


See the full list on the [API](/plugins/bigmailer/api) page.

## Query synced data

Synced entities support `tenant.bigmailer.db.<entity>.search()` and `.list()`: `brandProperties`, `brands`, `bulkCampaigns`, `connections`, `contacts`, `fields`, `lists`, `messageTypes`, `segments`, `senders`, `suppressionLists`, `templates`, `transactionalCampaigns`.

See [Database](/plugins/bigmailer/database) for filters and operators.
