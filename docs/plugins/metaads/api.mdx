## Accounts

### get

Retrieve an ad account by ID

**Risk:** `read`

```ts
await corsair.metaads.api.accounts.get({ accountId: '1234567890' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `accountId` | `string` | Yes | — |
| `fields` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |

| `status` | `string \| null` | No | — |
| `configured_status` | `string \| null` | No | — |
| `effective_status` | `string \| null` | No | — |

### create

**Risk:** `destructive`

```ts

	accountId: '1234567890',

	name: 'Sample ad',
	creativeId: '120000000000004',
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `accountId` | `string` | Yes | — |
| `adSetId` | `string` | Yes | — |

| `creativeId` | `string` | Yes | — |
| `status` | `ACTIVE \| PAUSED` | No | — |
| `idempotencyKey` | `string` | No | — |

New ads enter review and can deliver after approval. This consequential write is destructive and isn't automatically retried.

## Ad Sets

### create

`adSets.create`

Create a targeted ad set with a budget and schedule

**Risk:** `destructive`

```ts
await corsair.metaads.api.adSets.create({
	accountId: '1234567890',
	campaignId: '120000000000001',
	name: 'Sample ad set',
	targeting: {
		geo_locations: {
			countries: ['US'],
		},
	},
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `accountId` | `string` | Yes | — |
| `campaignId` | `string` | Yes | — |
| `name` | `string` | Yes | — |
| `optimizationGoal` | `NONE \| APP_INSTALLS \| AD_RECALL_LIFT \| ENGAGED_USERS \| EVENT_RESPONSES \| IMPRESSIONS \| LEAD_GENERATION \| QUALITY_LEAD \| LINK_CLICKS \| OFFSITE_CONVERSIONS \| PAGE_LIKES \| POST_ENGAGEMENT \| QUALITY_CALL \| REACH \| LANDING_PAGE_VIEWS \| VISIT_INSTAGRAM_PROFILE \| ENGAGED_PAGE_VIEWS \| VALUE \| THRUPLAY \| DERIVED_EVENTS \| APP_INSTALLS_AND_OFFSITE_CONVERSIONS \| CONVERSATIONS \| IN_APP_VALUE \| MESSAGING_PURCHASE_CONVERSION \| MESSAGING_DEEP_CONVERSATION_AND_FOLLOW \| SUBSCRIBERS \| REMINDERS_SET \| MEANINGFUL_CALL_ATTEMPT \| PROFILE_VISIT \| PROFILE_AND_PAGE_ENGAGEMENT \| ADVERTISER_SILOED_VALUE \| AUTOMATIC_OBJECTIVE \| MESSAGING_APPOINTMENT_CONVERSION` | Yes | — |
| `billingEvent` | `APP_INSTALLS \| CLICKS \| IMPRESSIONS \| LINK_CLICKS \| NONE \| OFFER_CLAIMS \| PAGE_LIKES \| POST_ENGAGEMENT \| THRUPLAY \| PURCHASE \| LISTING_INTERACTION` | Yes | — |
| `targeting` | `Record<string, any>` | Yes | — |
| `status` | `ACTIVE \| PAUSED` | No | — |
| `dailyBudget` | `number` | No | — |
| `lifetimeBudget` | `number` | No | — |
| `startTime` | `string` | No | — |
| `endTime` | `string` | No | — |
| `idempotencyKey` | `string` | No | — |

This consequential write is destructive and isn't automatically retried. Budgets use integer smallest-currency units; initial status defaults to PAUSED.

|------|------|----------|-------------|
| `id` | `string` | No | — |
