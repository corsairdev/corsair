### activeAdRulesList

`accounts.activeAdRulesList`

List active rules for explicitly selected ad objects

**Risk:** `read`

```ts
await corsair.metaads.api.accounts.activeAdRulesList({
	accountId: '1234567890',
	selectedIds: ['120000000000001', '120000000000002'],
});
```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `accountId` | `string` | Yes | — |
| `selectedIds` | `string[]` | Yes | — |

Requires selectedIds and accepts an optional passEvaluation filter; it does not execute or change rules.

  hashes: ["f1904cf1a9d73a55fa5de0ac823c4403ded71afd4c3248d00bdcd0866552bb79"],
