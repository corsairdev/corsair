### adRulesLibraryCreate

`accounts.adRulesLibraryCreate`

Create a rule that can change ad delivery, budgets, or bids

**Risk:** `destructive`

```ts
await corsair.metaads.api.accounts.adRulesLibraryCreate({
  accountId: "1234567890",
  name: "Pause on spend limit",
  evaluationSpec: {
    evaluationType: "SCHEDULE",
    filters: [{ field: "spend", value: 100, operator: "GREATER_THAN" }],
  },
  executionSpec: { executionType: "PAUSE" },
  scheduleSpec: { scheduleType: "DAILY" },
  status: "DISABLED",
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `accountId` | `string` | Yes | — |
| `name` | `string` | Yes | — |
| `evaluationSpec` | `object` | Yes | — |
| `executionSpec` | `object` | Yes | — |
| `scheduleSpec` | `object` | No | — |
| `status` | `ENABLED \| DISABLED \| DELETED \| HAS_ISSUES` | No | — |

Creates a potentially consequential automation rule. New rules default to DISABLED; PING_ENDPOINT and NOTIFICATION execution types are excluded because outbound callback lifecycle is not supported.

<AccordionGroup>
<Accordion title="evaluationSpec full type">

```ts
{
  evaluationType: SCHEDULE | TRIGGER,
  filters: {
    field: string,
    value: string | number | boolean | (string | number | boolean)[] | Record<string, any>,
    operator: GREATER_THAN | LESS_THAN | EQUAL | NOT_EQUAL | IN_RANGE | NOT_IN_RANGE | IN | NOT_IN | CONTAIN | NOT_CONTAIN | ANY | ALL | NONE
  }[],
  trigger?: {
    type: METADATA_CREATION | METADATA_UPDATE | STATS_MILESTONE | STATS_CHANGE | DELIVERY_INSIGHTS_CHANGE,
    field?: string,
    value?: string | number | boolean | (string | number | boolean)[] | Record<string, any>,
    operator?: GREATER_THAN | LESS_THAN | EQUAL | NOT_EQUAL | IN_RANGE | NOT_IN_RANGE | IN | NOT_IN | CONTAIN | NOT_CONTAIN | ANY | ALL | NONE
  }
}
```
</Accordion>

<Accordion title="executionSpec full type">

```ts
{
  executionType: DCO | PAUSE | REBALANCE_BUDGET | CHANGE_BUDGET | CHANGE_BID | ROTATE | UNPAUSE | CHANGE_CAMPAIGN_BUDGET | ADD_INTEREST_RELAXATION | ADD_QUESTIONNAIRE_INTERESTS | INCREASE_RADIUS | UPDATE_CREATIVE | UPDATE_LAX_BUDGET | UPDATE_LAX_DURATION | AUDIENCE_CONSOLIDATION | AUDIENCE_CONSOLIDATION_ASK_FIRST | AD_RECOMMENDATION_APPLY,
  isOnceOff?: boolean,
  executionOptions?: {
    field: string,
    value: string | number | boolean | (string | number | boolean)[] | Record<string, any>,
    operator: EQUAL | IN
  }[]
}
```
</Accordion>

<Accordion title="scheduleSpec full type">

```ts
{
  scheduleType: DAILY | HOURLY | SEMI_HOURLY | CUSTOM,
  schedule?: {
    startMinute?: number,
    endMinute?: number,
    days?: number[]
  }[]
}
```
</Accordion>
</AccordionGroup>

| `id` | `string` | Yes | — |
