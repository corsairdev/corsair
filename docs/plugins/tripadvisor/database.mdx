---
title: Database
description: "Tripadvisor does not define local database entities."
---

The Tripadvisor plugin does not define local database entities or a sync job.
Tripadvisor location data is returned live by
`corsair.tripadvisor.api.catalog.locationsNearby`.

<Info>
Use the [API reference](/plugins/tripadvisor/api) for the supported catalog
operation. The plugin does not expose a `corsair.tripadvisor.db` namespace.
</Info>
