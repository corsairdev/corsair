## Catalog

### locationsNearby

`catalog.locationsNearby`

Search nearby Tripadvisor catalog locations by coordinates or location ID

**Risk:** `read`

```ts
await corsair.tripadvisor.api.catalog.locationsNearby({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `location_id` | `string` | No | — |
| `lat` | `number` | No | — |
| `lon` | `number` | No | — |
| `radius` | `number` | No | — |
| `unit` | `MI \| KM` | No | — |
| `sw_lat` | `number` | No | — |
| `sw_lon` | `number` | No | — |
| `ne_lat` | `number` | No | — |
| `ne_lon` | `number` | No | — |
| `category` | `RESTAURANT \| ATTRACTION \| HOTEL` | No | — |
| `min_rating` | `number` | No | — |
| `locale` | `string[]` | No | — |
| `page` | `number` | No | — |
| `size` | `number` | No | — |
| `sort` | `string[]` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `pagination` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts

    addresses?: {

      language?: string,
      postal_code?: string,

      street_address2?: string
    }[],
    coordinates?: {
      latitude: number,

    },
```
