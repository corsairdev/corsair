## Channels

### create

`channels.create`

Create a group channel from user IDs.

**Risk:** `write`

```ts
await corsair.sendbird.api.channels.create({
	user_ids: ['user-1'],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | — |
| `cover_url` | `string` | No | — |
| `custom_type` | `string` | No | — |
| `data` | `string` | No | — |
| `is_distinct` | `boolean` | No | — |
| `is_public` | `boolean` | No | — |
| `is_super` | `boolean` | No | — |
| `access_code` | `string` | No | — |
| `user_ids` | `string[]` | Yes | — |
