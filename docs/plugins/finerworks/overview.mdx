Use **FinerWorks** through Corsair: one client, typed API calls, local DB sync.

FinerWorks signs every request with two keys: the account's `web_api_key` and an `app_key` for the calling app (create one under Account > API in FinerWorks). Corsair stores the web API key as the tenant's API key and the app key as the account's `app_key` field; you can also pass `appKey` to `finerworks()` to use one app key for every tenant.

**What you get:**

- 33 typed API operations
- 3 synced entities (`images`, `orders`, `virtualInventoryProducts`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/finerworks better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/finerworks better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/finerworks better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/finerworks better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { finerworks } from '@corsair-dev/finerworks';

export const corsair = createCorsair({
	plugins: [
		finerworks(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the FinerWorks API key before the first call: `pnpm corsair setup --plugin=finerworks --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
finerworks()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'finerworks',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List images in the inventory library**

```ts
const tenant = corsair.withTenant('acme');
await tenant.finerworks.api.images.list({
	library: { name: 'inventory' },
	per_page: 20,
});
```


**Change a product's asking price**

```ts
const tenant = corsair.withTenant('acme');
await tenant.finerworks.api.inventory.update({
	virtual_inventory: [{ sku: 'AP1556P79511', asking_price: 200 }],
});
```


See the full list on the [API](/plugins/finerworks/api) page.

## Query synced data

`orders.fetchStatus` stores each order by `order_id`. `images.list`, `images.add` and `images.update` store images by `guid`, and `inventory.list` and `inventory.update` store products by `sku`.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.finerworks.db.orders.search({
	data: { order_status_label: 'In Production' },
	limit: 50,
});
```

Synced entities: `images`, `orders`, `virtualInventoryProducts`. See [Database](/plugins/finerworks/database) for filters and operators.
