## Deals

### create

`deals.create`

Create a deal

**Risk:** `write`

```ts
await corsair.pipelinecrm.api.deals.create({ name: "Acme renewal", value: 12000, dealStageId: 3, companyName: "Acme Corporation" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Deal name |
| `summary` | `string` | No | Deal description |
| `userId` | `number` | No | Owning user id |
| `status` | `number` | No | Deal status id |
| `expectedCloseDate` | `string` | No | Expected close date, YYYY-MM-DD |
| `value` | `number \| string` | No | Deal value; a number or numeric string |
| `primaryContactId` | `number` | No | Primary contact person id |
| `personIds` | `number[]` | No | Associated person ids |
| `sharedUserIds` | `number[]` | No | Collaborator user ids |
| `companyId` | `number` | No | Company id |
| `companyName` | `string` | No | Creates and links a company of this name when no id matches |
| `probability` | `number` | No | Win probability 0-100; 0 or 100 closes the deal |
| `dealStageId` | `number` | No | Deal stage id |
| `dealLossReasonId` | `number` | No | Loss reason id |
| `dealLossReasonNotes` | `string` | No | Loss reason notes |
| `dealWonReasonId` | `number` | No | Won reason id |
| `dealWonReasonNotes` | `string` | No | Won reason notes |
| `dealSource` | `number` | No | Lead source id |
| `tagIds` | `number[]` | No | Tag ids |
| `customFields` | `Record<string, any>` | No | Custom field values keyed by custom_label_&lt;id&gt; |
| `deliverAssignmentEmail` | `boolean` | No | Email the new owner when the deal is assigned to another user |

probability 0 or 100 closes the deal; setting 1-99 on a closed deal reopens it. companyName creates and links a company when no id matches.

| `closed_time` | `string \| null` | No | Actual close date |
| `is_archived` | `boolean \| null` | No | Archived flag |
| `value` | `string \| null` | No | Deal value as a decimal string |
| `primary_contact_id` | `number \| null` | No | Primary contact person id |
| `person_ids` | `number[] \| null` | No | Associated person ids |
| `shared_user_ids` | `number[] \| null` | No | Collaborator user ids |
| `company_id` | `number \| null` | No | Company id |
| `company_name` | `string \| null` | No | Company name |
| `probability` | `number \| null` | No | Win probability, 0-100 |
| `deal_stage_id` | `number \| null` | No | Deal stage id |
| `deal_stage_name` | `string \| null` | No | Deal stage name |
| `deal_loss_reason_id` | `number \| null` | No | Loss reason id |
| `deal_loss_reason_notes` | `string \| null` | No | Loss reason notes |
| `deal_won_reason_id` | `number \| null` | No | Won reason id |
