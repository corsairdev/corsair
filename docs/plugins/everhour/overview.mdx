Use **Everhour** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 48 typed API operations
- 13 synced entities (`clients`, `expenseCategories`, `expenses`, `invoices`, `platforms`, `projects`, and 7 more) for fast `.search()` / `.list()`
- 20 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/everhour
```
```bash yarn
yarn add corsair @corsair-dev/everhour
```
```bash pnpm
pnpm install corsair @corsair-dev/everhour
```
```bash bun
bun add corsair @corsair-dev/everhour
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { everhour } from '@corsair-dev/everhour';

export const corsair = createCorsair({
	plugins: [
		everhour(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
everhour()
```

More: [API Key](/concepts/api-key)

</Tab>
<Tab title="OAuth 2.0">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Everhour OAuth app.

```ts
everhour({
	authType: 'oauth_2',
})
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'everhour',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List projects**

```ts
const tenant = corsair.withTenant('acme');
await tenant.everhour.api.projects.listProjects({});
```


**Create a task**

```ts
const tenant = corsair.withTenant('acme');
await tenant.everhour.api.tasks.createTask({ projectId: 'ev:1234567890', name: 'Write the release notes' });
```


See the full list on the [API](/plugins/everhour/api) page.

## Query synced data

These tables exist, but Everhour calls don't fill them yet. This returns only rows you have written yourself.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.everhour.db.projects.search({
	data: {},
	limit: 50,
});
```

Synced entities: `clients`, `expenseCategories`, `expenses`, `invoices`, `platforms`, `projects`, `sections`, `tags`, `tasks`, `timecards`, `timeEntries`, `users`, `webhooks`. See [Database](/plugins/everhour/database) for filters and operators.

## Webhooks

Fires when a task is created.

```ts
everhour({
    webhookHooks: {
        task: {
            created: {
                after: async (ctx, result) => {
                    console.log('Everhour task created:', result.data);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/everhour/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
