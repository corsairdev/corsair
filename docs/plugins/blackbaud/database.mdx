The Blackbaud plugin syncs data locally. Use `corsair.blackbaud.db.<entity>.search({ entity_id?, data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Batch Gifts

Path: `blackbaud.db.batchGifts.search`

```ts
const rows = await corsair.blackbaud.db.batchGifts.search({
    entity_id: { equals: '<id>' }, // optional, top-level (not inside data)
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

`entity_id` (`string`; equals, contains, startsWith, endsWith, in) is a top-level `.search()` option. The fields below go inside `data`.

| Field | Type | Operators |
|-------|------|-----------|
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `constituent_id` | `string` | equals, contains, startsWith, endsWith, in |
| `batch_number` | `string` | equals, contains, startsWith, endsWith, in |
| `constituency` | `string` | equals, contains, startsWith, endsWith, in |
| `date` | `string` | equals, contains, startsWith, endsWith, in |
| `date_added` | `string` | equals, contains, startsWith, endsWith, in |
| `date_modified` | `string` | equals, contains, startsWith, endsWith, in |
| `gift_code` | `string` | equals, contains, startsWith, endsWith, in |
| `gift_status` | `string` | equals, contains, startsWith, endsWith, in |
| `is_anonymous` | `boolean` | equals |
| `lookup_id` | `string` | equals, contains, startsWith, endsWith, in |
| `origin` | `string` | equals, contains, startsWith, endsWith, in |
| `post_date` | `string` | equals, contains, startsWith, endsWith, in |
| `post_status` | `string` | equals, contains, startsWith, endsWith, in |
| `reference` | `string` | equals, contains, startsWith, endsWith, in |
| `subtype` | `string` | equals, contains, startsWith, endsWith, in |
| `type` | `string` | equals, contains, startsWith, endsWith, in |
| `batch_id` | `string` | equals, contains, startsWith, endsWith, in |
| `approved_gift_id` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
