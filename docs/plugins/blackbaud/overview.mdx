Use **Blackbaud** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 5 typed API operations
- 5 synced entities (`batchGifts`, `gifts`, `memberships`, `oneRosterKeys`, `paymentTransactions`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/blackbaud
```
```bash yarn
yarn add corsair @corsair-dev/blackbaud
```
```bash pnpm
pnpm install corsair @corsair-dev/blackbaud
```
```bash bun
bun add corsair @corsair-dev/blackbaud
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { blackbaud } from '@corsair-dev/blackbaud';

export const corsair = createCorsair({
	plugins: [
		blackbaud(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="OAuth 2.0 (Recommended)">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Blackbaud OAuth app.

```ts
blackbaud()
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'blackbaud',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`gifts.getGiftById`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.blackbaud.api.gifts.getGiftById({});
```


**`batch.addGiftsToBatch`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.blackbaud.api.batch.addGiftsToBatch({});
```


See the full list on the [API](/plugins/blackbaud/api) page.

## Query synced data

Synced entities support `tenant.blackbaud.db.<entity>.search()` and `.list()`: `batchGifts`, `gifts`, `memberships`, `oneRosterKeys`, `paymentTransactions`.

See [Database](/plugins/blackbaud/database) for filters and operators.
