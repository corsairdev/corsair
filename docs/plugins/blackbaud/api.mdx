## Batch

### addGiftsToBatch

`batch.addGiftsToBatch`

Add one or more gifts (donations) to an existing open gift batch in Blackbaud Raiser's Edge NXT. Returns the added gifts and any per-gift errors.

**Risk:** `write`

```ts
await corsair.blackbaud.api.batch.addGiftsToBatch({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `batch_id` | `string` | Yes | — |
| `gifts` | `object[]` | Yes | — |

## Membership

### getMembershipDetails

`membership.getMembershipDetails`

Retrieves membership details (program, category, dues, renewal dates) from Blackbaud Raiser's Edge NXT by member junction ID.

**Risk:** `read`

```ts
await corsair.blackbaud.api.membership.getMembershipDetails({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `member_junction_id` | `string` | Yes | Membership record ID for the constituent (the "id" returned by the constituent memberships list). |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `dues` | `number` | No | — |
| `category_name` | `string` | No | — |
| `program_name` | `string` | No | — |
| `sub_category_name` | `string` | No | — |
| `last_renewed_date` | `string` | No | — |
| `last_dropped_date` | `string` | No | — |
| `next_renewal_date` | `string` | No | — |
| `joined_date` | `string` | No | — |
| `total_years` | `number` | No | — |
| `times_renewed` | `number` | No | — |
| `consec_years` | `number` | No | — |
| `constituent_id` | `string` | No | — |
| `notes` | `string` | No | — |
| `type` | `Joined \| Renewal \| Rejoined \| Upgrade \| Downgrade \| Dropped` | No | — |
