---
title: "Follow Up Boss database"
sidebarTitle: "Database"
description: "The Follow Up Boss plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Follow Up Boss. To read its data, call the [API operations](/plugins/followupboss/api), which return what Follow Up Boss has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
