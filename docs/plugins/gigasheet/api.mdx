## Datasets

### delete

`datasets.delete`

Permanently delete a sheet or folder by handle, optionally deleting child files

**Risk:** `destructive`

```ts
await corsair.gigasheet.api.datasets.delete({ handle: '6030253a_ffd2_42b5_b1a2_fe914d4e7db7' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `handle` | `string` | Yes | — |
| `recursive` | `boolean` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `Success` | `boolean` | No | — |
| `Message` | `string` | No | — |



---

**Risk:** `destructive`

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `handle` | `string` | Yes | — |
| `filename` | `string` | No | — |
| `folderHandle` | `string` | No | — |
| `compressionType` | `zip \| gzip` | No | — |
| `decompress` | `boolean` | No | — |
| `recordsPerFile` | `number` | No | — |
| `row_limit_from_head` | `number` | No | — |
| `skipNotification` | `boolean` | No | — |
| `useClientState` | `boolean` | No | — |
| `clientState` | `Record<string, any>` | No | — |
| `gridState` | `Record<string, any>` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `handle` | `string` | Yes | — |
