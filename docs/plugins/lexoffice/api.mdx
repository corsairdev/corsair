## Contacts

### create

`contacts.create`

Create a new customer or vendor contact in Lexoffice

**Risk:** `write`

```ts
await corsair.lexoffice.api.contacts.create({
	version: 0,
	roles: {
		customer: {},
	},
	person: { lastName: 'Mustermann' },
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `version` | `number` | No | Defaults to 0. |
| `roles` | `object` | Yes | — |
| `person` | `object` | No | — |
| `company` | `object` | No | — |
| `addresses` | `object` | No | — |
| `emailAddresses` | `object` | No | — |
| `phoneNumbers` | `object` | No | — |
| `xRechnung` | `object` | No | — |
| `note` | `string` | No | — |

New contacts are created with version 0 when omitted and must have exactly one of person or company plus at least one role. Only one entry per address/contact list and one company contact person can be written. XRechnung contacts require both buyerReference and vendorNumberAtCustomer. Personal contact fields are never included in plugin event logs or propagated provider error details.

## Credit Notes

### create

`creditNotes.create`

Create a credit note, optionally finalizing or pursuing it

**Risk:** `destructive`

```ts
await corsair.lexoffice.api.creditNotes.create({ voucherDate: '2026-01-01', address: { name: 'Acme Corp', countryCode: 'DE' }, lineItems: [{ type: 'custom', name: 'Credit', quantity: 1, unitName: 'piece', unitPrice: { currency: 'EUR', netAmount: 50, taxRatePercentage: 19 } }], totalPrice: { currency: 'EUR' }, taxConditions: { taxType: 'net' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `finalize` | `boolean` | No | — |
| `precedingSalesVoucherId` | `string` | No | — |
| `voucherDate` | `string` | Yes | — |
| `language` | `de \| en` | No | — |
| `printLayoutId` | `string` | No | — |
| `address` | `object` | Yes | — |
| `lineItems` | `object[]` | Yes | — |
| `totalPrice` | `object` | Yes | — |
| `taxConditions` | `object` | Yes | — |
| `title` | `string` | No | — |
| `introduction` | `string` | No | — |
| `remark` | `string` | No | — |

Credit notes can be finalized or pursued from an existing sales voucher; finalize and precedingSalesVoucherId are query parameters. A finalized credit note related to an invoice is immediately paid off and reduces the invoice's open amount. Credit notes do not support payment conditions, shipping conditions, or per-line discounts. For custom, material, and service lines, name, quantity, unitName, and unitPrice are required; material/service lines also require id.
