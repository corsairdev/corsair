## Contacts

### create

`contacts.create`

Create a new customer or vendor contact in Lexoffice

**Risk:** `write`

```ts
await corsair.lexoffice.api.contacts.create({
	version: 0,
	roles: {
		customer: {},
	},
	person: { lastName: 'Mustermann' },
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `version` | `number` | No | Defaults to 0. |
| `roles` | `object` | Yes | — |
| `person` | `object` | No | — |
| `company` | `object` | No | — |
| `addresses` | `object` | No | — |
| `emailAddresses` | `object` | No | — |
| `phoneNumbers` | `object` | No | — |
| `note` | `string` | No | — |
| `archived` | `boolean` | No | — |

## Invoices

### create

`invoices.create`

Create an invoice in draft or finalized state

**Risk:** `write`

```ts
await corsair.lexoffice.api.invoices.create({ voucherDate: '2026-01-01', address: { name: 'Acme Corp' }, lineItems: [{ type: 'custom', name: 'Consulting', unitPrice: { currency: 'EUR', netAmount: 100, taxRatePercentage: 19 } }], totalPrice: { currency: 'EUR' }, taxConditions: { taxType: 'net' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `finalize` | `boolean` | No | — |
| `voucherDate` | `string` | Yes | — |
| `address` | `object` | Yes | — |
| `lineItems` | `object[]` | Yes | — |
| `totalPrice` | `object` | Yes | — |
| `taxConditions` | `object` | Yes | — |
| `title` | `string` | No | — |
| `introduction` | `string` | No | — |
| `remark` | `string` | No | — |
| `shippingConditions` | `object` | No | — |

Invoices cannot be updated or deleted once created via the API due to accounting compliance regulations (GoBD).
