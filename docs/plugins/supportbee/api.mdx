## Attachments

### create

`attachments.create`

Upload one file and get the id to attach to a reply, comment, draft or ticket

**Risk:** `write`

```ts
await corsair.supportbee.api.attachments.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `filename` | `string` | Yes | — |
| `content` | `string` | Yes | — |
| `content_type` | `string` | No | — |

Sends `multipart/form-data` with the file under `files[]`, which is the field name the route documents. `content` is base64, with or without a data URI prefix. The answer carries the `id` to pass in `content.attachment_ids` on a reply, comment, draft or ticket.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number \| null` | No | — |
| `created_at` | `string \| number \| null` | No | — |
| `filename` | `string \| null` | No | — |
| `content_type` | `string \| null` | No | — |
| `url` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="url full type">

```ts
{
  original?: string | null,
  thumb?: string | null
} | null
```
</Accordion>
</AccordionGroup>

**Risk:** `write`

```ts
await corsair.supportbee.api.emails.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|

### createConsequence

`filters.createConsequence`

Create the action half of a filter: archive, spam, trash, label or assign

**Risk:** `write`

```ts
await corsair.supportbee.api.filters.createConsequence({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `archive` | `boolean` | No | — |
| `spam` | `boolean` | No | — |
| `trash` | `boolean` | No | — |
| `label` | `string` | No | — |
| `assign_user` | `string` | No | — |
| `assign_team` | `string` | No | — |

Creates the action half and answers `{ consequence: { id } }`. It can archive, spam, trash, label or assign, and **a consequence assigns a user or a team, not both**, so the schema rejects that pair. `assign_user` and `assign_team` are strings, not numbers.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `consequence` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="consequence full type">

```ts
{
  id: string
}
```
</Accordion>
</AccordionGroup>
