## Repository

### compareCommits

`repository.compareCommits`

Compare two commits and list file diffs

**Risk:** `read`

```ts
await corsair.sourcegraph.api.repository.compareCommits({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `repo` | `string` | Yes | — |
| `base` | `string` | Yes | — |
| `head` | `string` | Yes | — |
| `first` | `number` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `repository` | `object` | No | — |

<AccordionGroup>
<Accordion title="repository full type">

```ts
{
  comparison?: {
    range?: {
      expr?: string
    } | null,
    fileDiffs?: {
      nodes?: {
        oldPath?: string | null,
        newPath?: string | null,
        stat?: {
          added?: number,
          changed?: number,
          deleted?: number
        }
      }[],
      totalCount?: number | null,
      pageInfo?: {
        hasNextPage?: boolean,
        endCursor?: string | null
      }
    }
  } | null
}
```
</Accordion>
</AccordionGroup>
