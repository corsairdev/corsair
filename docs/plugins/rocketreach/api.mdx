## Email

### verify

`email.verify`

Verify whether one address can receive mail, with per-check detail; charges a verification credit, refunded when the answer is unknown or the address is malformed

**Risk:** `write`

```ts
await corsair.rocketreach.api.email.verify({ email: 'johndoe@google.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | The address to verify. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string \| null` | No | The address, canonicalized. |
| `status` | `string \| null` | No | valid, invalid, catchall or unknown. invalid covers a malformed, disposable or risky address. |
| `credits_charged` | `number \| null` | No | 1, or 0 when the result was refunded. |
| `mx_record` | `string \| null` | No | The domain's primary MX host. Null when it publishes none, so it is not on its own evidence that mail cannot be delivered. |
| `checks` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="checks full type">

```ts
{
  format_valid?: boolean | null,
  domain_valid?: boolean | null,
  disposable?: boolean | null,
  catchall?: boolean | null
} | null
```
</Accordion>
</AccordionGroup>

## Person

### bulkLookup

`person.bulkLookup`

Start a bulk lookup of up to 100 people and return the RR-Request-ID to poll with person.checkStatus

**Risk:** `write`

```ts
await corsair.rocketreach.api.person.bulkLookup({ queries: [{ email: 'john.doe@example.com' }, { linkedin_url: 'www.linkedin.com/in/jamesgullbrand' }], profile_list: 'Q1 prospects' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `queries` | `object[]` | Yes | Between 1 and 100 people. |
| `profile_list` | `string` | No | Add the looked-up profiles to this list. Defaults to API Bulk Lookup. |
| `webhook_id` | `number` | No | — |

<AccordionGroup>
<Accordion title="queries full type">

```ts
{
  email?: string,
  id?: number | string,
  linkedin_url?: string,
  name?: string,
  current_employer?: string,
  title?: string,
  phone?: string,
  npi_number?: number | string,
  lookup_type?: standard | premium | premium (feeds disabled) | bulk | phone | enrich,
  return_cached_emails?: boolean
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `requestId` | `string \| null` | No | The RR-Request-ID header, to poll person.checkStatus or match a webhook delivery. |

### lookup

`person.lookup`

Look up one person by email, LinkedIn URL, ID, phone, NPI number or name and employer, spending a lookup credit; a status other than complete means poll person.checkStatus

**Risk:** `write`

```ts
await corsair.rocketreach.api.person.lookup({ email: 'john.doe@example.com', return_cached_emails: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | No | An email address. |
| `id` | `number \| string` | No | A RocketReach profile ID. |
| `linkedin_url` | `string` | No | Such as www.linkedin.com/in/jamesgullbrand. |
| `name` | `string` | No | Requires current_employer as well. |
| `current_employer` | `string` | No | Requires name as well. |
