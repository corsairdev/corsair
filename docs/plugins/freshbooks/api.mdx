### delete

`clients.delete`

Soft-delete a client by setting vis_state to 1. The record stays in FreshBooks; no documented call restores it

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.freshbooks.api.clients.delete({ accountId: 'LJArJ4', customerId: 238951 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `accountId` | `string` | Yes | The accounting system id, such as LJArJ4, from the `accountId` field of users.me. |
| `customerId` | `number` | Yes | The client to delete. |

Soft delete: `PUT` with `vis_state: 1` marks the client deleted while the record stays. Restoring by setting `vis_state: 0` is undocumented, so the plugin marks this irreversible.
