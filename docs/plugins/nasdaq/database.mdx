---
title: "Nasdaq Data Link database"
sidebarTitle: "Database"
description: "The Nasdaq Data Link plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Nasdaq Data Link. To read its data, call the [API operations](/plugins/nasdaq/api), which return what Nasdaq Data Link has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
