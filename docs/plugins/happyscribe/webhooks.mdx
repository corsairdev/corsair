The Happy Scribe plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/happyscribe/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `meetings`
  - `cancelled` (`meetings.cancelled`)
  - `failed` (`meetings.failed`)
  - `recordingCompleted` (`meetings.recordingCompleted`)
  - `recordingStarted` (`meetings.recordingStarted`)
  - `summaryReady` (`meetings.summaryReady`)
  - `transcriptReady` (`meetings.transcriptReady`)
- `other`
  - `other` (`other.other`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Events

## Meetings

### Cancelled

`meetings.cancelled`

The Meeting was cancelled before completion

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Event ID beginning with `evt_`; deduplicate retries on it. |
| `type` | `string` | Yes | Event type, e.g. `meeting.summary_ready`. |
| `created_at` | `string \| null` | No | — |
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  object: Record<string, any>
}
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  id: string,
  type: string,
  created_at?: string | null,
  data: {
    object: Record<string, any>
  }
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
happyscribe({
    webhookHooks: {
        meetings: {
            cancelled: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
