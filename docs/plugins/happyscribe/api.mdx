### create

`orders.create`

Create a human transcription or subtitling order for media at a URL. It stays incomplete and unpaid until orders.confirm or an explicit confirm flag

**Risk:** `write`

```ts
await corsair.happyscribe.api.orders.create({ url: 'https://example.com/media.mp3', language: 'es', service: 'pro', organizationId: 123 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | Public URL of the media to transcribe or subtitle. |
| `language` | `string` | Yes | Spoken language code of the media. |
| `service` | `pro \| standard` | No | Human service tier; omit for the default. |
| `confirm` | `boolean` | No | Confirm and pay immediately instead of leaving the order incomplete. |
| `organizationId` | `number` | Yes | Numeric ID of the organization to act on. |
| `folderId` | `number` | No | Folder ID for the result. |
| `folder` | `string` | No | Folder path for the result, e.g. `my_project`. |
| `name` | `string` | No | Name of the ordered transcription. |
| `tags` | `string[]` | No | Tags to attach. |
| `boost` | `boolean` | No | Pay for faster delivery. |
| `isSubtitle` | `boolean` | No | Order subtitling instead of transcription. |
| `webhookUrl` | `string` | No | URL notified when the order finishes. |
| `glossaryIds` | `number[]` | No | Glossaries the human translators use. |
| `styleGuideId` | `number` | No | Style guide the human translators use. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `folder_id` | `number \| null` | No | — |
| `state` | `string \| null` | No | — |
| `operations` | `Record<string, unknown>[] \| null` | No | — |
