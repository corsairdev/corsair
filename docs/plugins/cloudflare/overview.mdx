Use **Cloudflare** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 24 typed API operations
- 5 synced entities (`dnsRecords`, `rulesets`, `workerRoutes`, `workerScripts`, `zones`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/cloudflare
```
```bash yarn
yarn add corsair @corsair-dev/cloudflare
```
```bash pnpm
pnpm install corsair @corsair-dev/cloudflare
```
```bash bun
bun add corsair @corsair-dev/cloudflare
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { cloudflare } from '@corsair-dev/cloudflare';

export const corsair = createCorsair({
	plugins: [
		cloudflare(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

Provider walkthrough: [Get Credentials](/plugins/cloudflare/get-credentials).

```ts
cloudflare()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'cloudflare',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`dns.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.cloudflare.api.dns.get({});
```


**`dns.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.cloudflare.api.dns.create({});
```


See the full list on the [API](/plugins/cloudflare/api) page.

## Query synced data

Synced entities support `tenant.cloudflare.db.<entity>.search()` and `.list()`: `dnsRecords`, `rulesets`, `workerRoutes`, `workerScripts`, `zones`.

See [Database](/plugins/cloudflare/database) for filters and operators.
