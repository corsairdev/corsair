## Attachments

### attachToItem

`attachments.attachToItem`

Upload a file and attach it to a work item

**Risk:** `write`

```ts
await corsair.onedesk.api.attachments.attachToItem({ externalId: '0abb5fgh-0000-0000-0000-c75df7969bad', fileName: 'invoice.pdf', contentBase64: '<base64 bytes>' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string` | Yes | Filename to record, including its extension. |
| `contentType` | `string` | No | MIME type, for example application/pdf. |
| `contentBase64` | `string` | Yes | The file contents, base64 encoded. |
| `externalId` | `string` | Yes | External id of the item, project, portfolio or organization. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `code` | `string \| null` | No | — |
| `data` | `string \| null` | No | — |

### upload

`attachments.upload`

Upload a file to the account and get its external id for attaching later

**Risk:** `write`

```ts
await corsair.onedesk.api.attachments.upload({ fileName: 'invoice.pdf', contentType: 'application/pdf', contentBase64: '<base64 bytes>' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string` | Yes | Filename to record, including its extension. |
| `contentType` | `string` | No | MIME type, for example application/pdf. |
| `contentBase64` | `string` | Yes | The file contents, base64 encoded. |

OneDesk takes multipart uploads, so the file is passed as base64 bytes with a filename. There is no import-from-URL endpoint.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `code` | `string \| null` | No | — |
| `data` | `string \| null` | No | — |
