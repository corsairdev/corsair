Use **OneDesk** through Corsair: one client, typed API calls.

OneDesk merges help desk and project management, so one account holds
tickets, tasks, projects, timesheets and invoices together.

Two things shape this plugin. First, OneDesk has no single "list" endpoint:
each resource is queried through a POST filter body, and the details variant
is what returns full records rather than ids. Second, a failure can arrive
with **HTTP 200** and a `code` of `ERROR_*`, so the plugin treats that as a
failed call rather than returning it as data.

Item and user writes need names the organization defines. Read them first
with `organization.itemTypes`, `organization.userTypes` and
`organization.lifecycleStatus`. `items.filter` takes `itemType` as an array;
a bare string is rejected.

A white-label or self-hosted account sets the `host` option; it defaults to
https://app.onedesk.com.

The public API needs a OneDesk **enterprise** account, and each API key
consumes one user license.

**What you get:**

- 79 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/onedesk better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/onedesk better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/onedesk better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/onedesk better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { onedesk } from '@corsair-dev/onedesk';

export const corsair = createCorsair({
	plugins: [
		onedesk(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the OneDesk API key before the first call: `pnpm corsair setup --plugin=onedesk --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
onedesk()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'onedesk',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List work items with their details**

```ts
const tenant = corsair.withTenant('acme');
await tenant.onedesk.api.items.filterDetails({
	itemType: ['Problem'],
	limit: 10,
});
```


**Create a ticket**

```ts
const tenant = corsair.withTenant('acme');
await tenant.onedesk.api.items.create({ name: 'The blue button does not work', type: 'Ticket' });
```


See the full list on the [API](/plugins/onedesk/api) page.
