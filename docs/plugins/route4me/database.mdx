---
title: "Route4Me database"
sidebarTitle: "Database"
description: "The Route4Me plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Route4Me. To read its data, call the [API operations](/plugins/route4me/api), which return what Route4Me has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
