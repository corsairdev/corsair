## Addresses

### create

`addresses.create`

Add a contact to the address book; the coordinates are required alongside the street address

**Risk:** `write`

```ts
await corsair.route4me.api.addresses.create({ address_1: 'Prinsengracht 100', address_city: 'Amsterdam', cached_lat: 52.373066, cached_lng: 4.886445 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `address_1` | `string` | Yes | The street address. |
| `address_2` | `string` | No | — |
| `address_alias` | `string` | No | — |
| `address_city` | `string` | No | — |
| `address_state_id` | `string` | No | — |
| `address_country_id` | `string` | No | — |
| `address_zip` | `string` | No | — |
| `cached_lat` | `number` | Yes | — |
| `cached_lng` | `number` | Yes | — |
| `curbside_lat` | `number` | No | — |
| `curbside_lng` | `number` | No | — |
| `address_group` | `string` | No | — |
| `first_name` | `string` | No | — |
| `last_name` | `string` | No | — |
| `address_email` | `string` | No | The contact email. Route4Me names it `address_email`, not `email`. |
| `address_phone_number` | `string` | No | — |
| `service_time` | `number` | No | — |
| `address_weight` | `number` | No | — |
| `address_cube` | `number` | No | — |
| `address_pieces` | `number` | No | — |
| `address_revenue` | `number` | No | — |
| `address_priority` | `number` | No | — |
| `address_reference_no` | `string` | No | — |
| `address_stop_type` | `DELIVERY \| PICKUP \| BREAK \| MEETUP \| SERVICE \| VISIT` | No | — |
| `eligible_pickup` | `boolean` | No | — |
| `eligible_depot` | `boolean` | No | — |
| `customer_id` | `string` | No | — |
| `address_custom_data` | `Record<string, string>` | No | — |

Coordinates are required; Route4Me will not geocode on write.



**Output**

### list

`addresses.list`

List address book contacts with a display filter, a search phrase and limit/offset paging

**Risk:** `read`

```ts
await corsair.route4me.api.addresses.list({ display: 'unrouted', limit: 100, offset: 0 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `display` | `all \| routed \| unrouted` | No | Which contacts to return. Route4Me defaults to `all`. |
| `display_list` | `(routed \| unrouted)[]` | No | Sent as a repeated parameter. |
| `query` | `string` | No | — |
| `fields` | `string[]` | No | A projection: only these fields come back. |
| `limit` | `number` | No | Records to return, up to 10000. Route4Me defaults to the maximum. |
| `offset` | `number` | No | Records to skip, for offset paging. |

Pages by limit/offset; next_offset is null on a short page.

|------|------|----------|-------------|

| `total` | `number \| null` | No | Total matching contacts, before `limit` and `offset`. |
| `offset` | `number \| null` | Yes | — |
| `limit` | `number \| null` | Yes | — |
| `next_offset` | `number \| null` | Yes | — |

## Optimizations

### create

`optimizations.create`

Submit addresses for optimization; the solver runs in the background and returns a problem id and state

**Risk:** `write`

```ts
await corsair.route4me.api.optimizations.create({ addresses: [{ lat: 52.373066, lng: 4.856445 }, { address: 'Damrak 1, Amsterdam' }], route_max_duration: 1800, algorithm_type: 'TSP' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `addresses` | `object[]` | Yes | The stops to sequence into routes. |
| `route_max_duration` | `number` | No | The longest a single route may take, in seconds. |
| `route_max_distance` | `number` | No | — |
| `vehicle_capacity` | `number` | No | — |
| `route_name` | `string` | No | — |
| `algorithm_type` | `TSP \| VRP \| CVRP \| MDVRP` | No | TSP for one vehicle, VRP for several, CVRP with capacity, MDVRP with multiple depots. |
| `distance_unit` | `mi \| km` | No | — |
| `optimize` | `Distance \| Time \| time \| distance` | No | What the optimizer minimises. |
| `travel_mode` | `Driving \| Walking \| Trucking \| Cycling` | No | — |
| `shared_publicly` | `boolean` | No | — |

Asynchronous: poll optimizations.get until state is 4 (Optimized).

### list

`optimizations.list`

List optimization problems by state and date range, or read exactly one when an id is given

**Risk:** `read`

```ts
await corsair.route4me.api.optimizations.list({ state: 4, limit: 10, offset: 0 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `optimization_problem_id` | `string` | No | Read this optimization instead of listing; v4 then answers a single object rather than a list. |
| `state` | `number` | No | 0 New, 1 Initial, 2 MatrixProcessing, 3 Optimizing, 4 Optimized, 5 Error, 6 ComputingDirections. |
| `limit` | `number` | No | — |
| `offset` | `number` | No | — |
| `start_date` | `string` | No | Only optimizations created on or after this date. |
| `end_date` | `string` | No | Only optimizations created on or before this date. |

Passing optimization_problem_id makes v4 answer one object; both forms are normalised into optimizations.

| `total_records` | `number \| null` | Yes | Route4Me's `totalRecords`, renamed to snake case. |
| `next_offset` | `number \| null` | Yes | The offset to request next, or null on the last page. |

### list

`routes.list`

List routes with search, facility and id filters plus page paging, from the v5 API

**Risk:** `read`

```ts
await corsair.route4me.api.routes.list({ page: 1, per_page: 100, timezone: 'Europe/Amsterdam' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | No | A free-text search phrase. |
| `search_query` | `string` | No | A second search field. |
| `exclude_ids` | `string[]` | No | Route ids to leave out of the result. |
| `facility_ids` | `string[]` | No | — |
| `route_id` | `string \| string[]` | No | One route id, or several, to read instead of listing all. |
| `timezone` | `string` | No | An IANA timezone, used for the date fields in the result. |
| `group_by` | `string` | No | — |
| `page` | `number` | No | 1-based page number. |
| `per_page` | `number` | No | Items per page, 1 to 500. Route4Me's own default applies when omitted. |
| `order_by` | `object` | No | — |

A POST with no side effect; the plugin marks it replayable so a 5xx is retried.
