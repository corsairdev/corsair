The Vaquill plugin syncs data locally. Use `corsair.vaquill.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Search Results

Path: `vaquill.db.searchResults.search`

```ts
const rows = await corsair.vaquill.db.searchResults.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `actId` | `string` | equals, contains, startsWith, endsWith, in |
| `citation` | `string` | equals, contains, startsWith, endsWith, in |
| `title` | `string` | equals, contains, startsWith, endsWith, in |
| `corpusType` | `string` | equals, contains, startsWith, endsWith, in |
| `state` | `string` | equals, contains, startsWith, endsWith, in |
| `excerpt` | `string` | equals, contains, startsWith, endsWith, in |
| `body` | `string` | equals, contains, startsWith, endsWith, in |
| `actStatus` | `string` | equals, contains, startsWith, endsWith, in |
| `goodLawStatus` | `string` | equals, contains, startsWith, endsWith, in |
| `query` | `string` | equals, contains, startsWith, endsWith, in |
| `createdAt` | `date` | equals, before, after, between |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
