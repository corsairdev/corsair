---
title: "Ghost database"
sidebarTitle: "Database"
description: "The Ghost plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Ghost. To read its data, call the [API operations](/plugins/ghost/api), which return what Ghost has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
