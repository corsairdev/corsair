## Ac States

### list

`acStates.list`

List the current and recent AC states of a pod, newest first.

**Risk:** `read`

```ts

```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deviceId` | `string` | Yes | Pod (device) id from devices.list. |
| `limit` | `number` | No | How many recent states to return (1 to 20). |



**Output**

### setProperty

`acStates.setProperty`

Change one property of the AC state of a pod, such as on or targetTemperature.

**Risk:** `write`

```ts
await corsair.sensibo.api.acStates.setProperty({ deviceId: 'abc123', property: 'targetTemperature', newValue: 23 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deviceId` | `string` | Yes | Pod (device) id from devices.list. |
| `property` | `on \| mode \| fanLevel \| targetTemperature \| temperatureUnit \| swing \| horizontalSwing \| light` | Yes | The one AC state property to change. |
| `newValue` | `string \| number \| boolean` | Yes | The new value, e.g. true for on, 22 for targetTemperature. |
| `currentAcState` | `object` | No | The current AC state, which Sensibo uses to fill in the other properties. |

`property` names one field of the AC state. Sensibo fills in the rest from `currentAcState` when you pass it.

## Climate React

### configure

`climateReact.configure`

Set the Climate React thresholds and the AC states it applies; replaces the current Climate React settings.

**Risk:** `write`

```ts
await corsair.sensibo.api.climateReact.configure({
	deviceId: 'abc123',
	enabled: true,
	lowTemperatureThreshold: 22,
	lowTemperatureState: { on: false },
	highTemperatureThreshold: 25,
	highTemperatureState: { on: true, mode: 'cool' },
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deviceId` | `string` | Yes | Pod (device) id from devices.list. |
| `enabled` | `boolean` | Yes | Whether Climate React runs. |
| `type` | `string` | No | What the thresholds measure, e.g. temperature, humidity, feelsLike. |
| `lowTemperatureThreshold` | `number` | Yes | Low threshold that triggers lowTemperatureState. |
| `lowTemperatureState` | `object` | Yes | AC state applied when the reading drops below the low threshold. |
| `highTemperatureThreshold` | `number` | Yes | High threshold that triggers highTemperatureState. |
| `highTemperatureState` | `object` | Yes | AC state applied when the reading rises above the high threshold. |

## Schedules

### create

`schedules.create`

Create a schedule that applies an AC state at a local time, once or on chosen weekdays.

**Risk:** `write`

```ts
await corsair.sensibo.api.schedules.create({
	deviceId: 'abc123',
	targetTimeLocal: '22:15',
	timezone: 'Europe/Oslo',
	acState: {
		on: false,
		mode: 'cool',
		fanLevel: 'auto',
		targetTemperature: 24,
	},
	recurOnDaysOfWeek: ['sunday', 'tuesday'],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deviceId` | `string` | Yes | Pod (device) id from devices.list. |
| `targetTimeLocal` | `string` | Yes | Local time in 24-hour HH:MM, e.g. 22:15. |
| `timezone` | `string` | Yes | IANA timezone the time is in, e.g. Europe/Oslo. |
| `acState` | `object` | Yes | AC state applied at that time (on, mode, fanLevel and targetTemperature required). |
| `recurOnDaysOfWeek` | `(sunday \| monday \| tuesday \| wednesday \| thursday \| friday \| saturday)[]` | Yes | Days the schedule repeats on; an empty list runs it once. |

`acState` must include `on`, `mode`, `fanLevel` and `targetTemperature`. `recurOnDaysOfWeek` takes lowercase weekday names. An empty list runs the schedule once at the next `targetTimeLocal`.

### set

`timer.set`

Set a timer that applies an AC state a number of minutes from now; replaces any current timer.

**Risk:** `write`

```ts
await corsair.sensibo.api.timer.set({
	deviceId: 'abc123',
	minutesFromNow: 30,
	acState: {
		on: false,
		mode: 'cool',
		fanLevel: 'auto',
		targetTemperature: 24,
	},
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `deviceId` | `string` | Yes | Pod (device) id from devices.list. |
| `minutesFromNow` | `number` | Yes | Minutes from now when the timer fires. |
| `acState` | `object` | Yes | AC state applied when the timer fires (on, mode, fanLevel and targetTemperature required). |

`acState` must include `on`, `mode`, `fanLevel` and `targetTemperature`.
