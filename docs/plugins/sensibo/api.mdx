## Devices

### list

`devices.list`

List every Sensibo pod on the authenticated account.

**Risk:** `read`

```ts
await corsair.sensibo.api.devices.list({ fields: 'id,room' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fields` | `string` | No | Comma-separated pod fields to return. |

Pass a comma-separated field list when you want a smaller pod object. Omit it to take the service default.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string` | Yes | — |
| `result` | `object[]` | Yes | — |
