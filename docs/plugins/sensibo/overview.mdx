Use **Sensibo** through Corsair: one client, typed API calls, local DB sync.

Things to know before you call:

- **The key goes in the query string.** Sensibo takes the API key as the `apiKey` query parameter; the client sends no bearer token. Create a key at home.sensibo.com/me/api. With no key stored, Corsair raises `AuthMissingError` before any request; a key Sensibo rejects comes back as HTTP 403.
- **Ask for the fields you need.** `devices.list` returns only pod ids unless you pass `fields` (`*` for everything, or a list such as `id,room,acState,measurements`).
- **AC values come from the pod's remote.** Valid `mode`, `fanLevel`, `swing` and `light` values are in the pod's `remoteCapabilities` (`devices.get` with `fields: '*'`). An AC state can be partial, such as `{ on: false }`.
- **Writes change a real air conditioner.** `acStates.set`, timers, schedules and Climate React act on the physical unit. `timer.set` and `climateReact.configure` replace the current timer or Climate React settings.
- **Unknown ids are 404.** A pod or sensor that is not on the account answers 404 "No such device or device is not associated with user".

**What you get:**

- 19 typed API operations
- 1 synced entity (`pods`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/sensibo better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/sensibo better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/sensibo better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/sensibo better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { sensibo } from '@corsair-dev/sensibo';

export const corsair = createCorsair({
	plugins: [
		sensibo(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Sensibo API key before the first call: `pnpm corsair setup --plugin=sensibo --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
sensibo()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'sensibo',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List Sensibo pods with their rooms and AC state**

```ts
const tenant = corsair.withTenant('acme');
await tenant.sensibo.api.devices.list({ fields: 'id,room,acState' });
```


**Turn the AC on in cool mode at 22 degrees**

```ts
const tenant = corsair.withTenant('acme');
await tenant.sensibo.api.acStates.set({
	deviceId: 'abc123',
	acState: { on: true, mode: 'cool', targetTemperature: 22 },
});
```


See the full list on the [API](/plugins/sensibo/api) page.
