## Agent Actions

### generate

`agentActions.generate`

Have Sanity's AI write content into a document's fields from an instruction, following the schema. Writes to the draft unless forcePublishedWrite; noWrite returns it without saving. Costs one Sanity AI credit.

**Risk:** `write`

```ts
await corsair.sanity.api.agentActions.generate({ schemaId: '_.schemas.default', targetDocument: { operation: 'create', _type: 'post' }, instruction: 'Write a short post about $topic', instructionParams: { topic: 'GROQ joins' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `schemaId` | `string` | Yes | The deployed schema the action reads, for example _.schemas.default. List them with schemas.list; a project deploys one with 'sanity schema deploy'. |
| `noWrite` | `boolean` | No | Return the result without saving anything. Not with async. |
| `async` | `boolean` | No | Start the action and return the target document id at once; the write lands later. For long generations. |
| `forcePublishedWrite` | `boolean` | No | Write to the published document instead of its draft, so the change is live at once. Default false. |
| `temperature` | `number` | No | — |
| `localeSettings` | `object` | No | Needed for the action to write date and datetime fields: &#123; locale: 'en-US', timeZone: 'Europe/Oslo' &#125;. |
| `conditionalPaths` | `Record<string, any>` | No | — |
| `dataset` | `string` | No | The dataset to use. Left out: the connection's dataset, else production. |
| `instruction` | `string` | Yes | What to write, for example "Write an SEO description of $title under 160 characters". |
| `instructionParams` | `Record<string, string \| Record<string, any>>` | No | Values for $names in the instruction: a string, &#123; type: 'constant', value &#125;, &#123; type: 'field', path, documentId? &#125;, &#123; type: 'document', documentId? &#125; or &#123; type: 'groq', query, params? &#125;. |
| `documentId` | `string` | No | An existing document to write into. Or give targetDocument. |
| `targetDocument` | `object` | No | Where the result goes: &#123; operation: 'create', _type: 'post' &#125; writes a new document, &#123; operation: 'edit', _id &#125; an existing one. Writes go to the draft unless forcePublishedWrite. |
| `target` | `Record<string, any> \| Record<string, any>[]` | No | Which fields to write, for example &#123; path: 'title' &#125; or [&#123; path: ['body'] &#125;, &#123; path: 'description', operation: 'set' &#125;]. Left out, every field the action can write. |

Give `documentId` to write into an existing document, or `targetDocument` to create one. `target` limits which fields it writes. It can't write file fields or fields the schema marks hidden or read-only, and it writes date fields only with `localeSettings`. Long generations can outlast a Corsair script, so pass `async: true` and read the document later.

<AccordionGroup>
<Accordion title="localeSettings full type">

```ts
{
  locale: string,
  timeZone: string
}
```
</Accordion>

<Accordion title="targetDocument full type">

```ts
{
  operation: edit | create | createIfNotExists | createOrReplace,
  _id?: string,
  _type?: string,
  initialValues?: Record<string, any>
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `document` | `object` | Yes | The document as the action left it; with async, only its _id, since the write happens later. |

<AccordionGroup>
<Accordion title="document full type">

```ts
{
  _id: string,
  _type?: string,
  _rev?: string | null,
  _createdAt?: string | null,
  _updatedAt?: string | null
}
```
</Accordion>
</AccordionGroup>

### prompt

`agentActions.prompt`

Ask Sanity's AI a question, optionally about documents passed as params, and get text or JSON back. Writes nothing. Costs one Sanity AI credit.

**Risk:** `read`

```ts
await corsair.sanity.api.agentActions.prompt({ instruction: 'Suggest three titles for $doc as json', instructionParams: { doc: { type: 'document', documentId: '<id>' } }, format: 'json' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `instruction` | `string` | Yes | — |
| `instructionParams` | `Record<string, string \| Record<string, any>>` | No | Values for $names in the instruction: a string, &#123; type: 'constant', value &#125;, &#123; type: 'field', path, documentId? &#125;, &#123; type: 'document', documentId? &#125; or &#123; type: 'groq', query, params? &#125;. |
| `format` | `string \| json` | No | string (default): text. json: a JSON value, and the instruction must contain the word 'json'. |
| `temperature` | `number` | No | — |
| `dataset` | `string` | No | The dataset to use. Left out: the connection's dataset, else production. |

Writes nothing. With `format: 'json'`, the instruction must contain the word json.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `text` | `string \| null` | No | The answer, when format is 'string'. |
| `json` | `any` | No | The answer, when format is 'json'. |

## Assets

### upload

`assets.upload`

Upload an image or file (base64, up to 25 MB) as a Sanity asset and get its asset document and CDN URL, ready to reference from a document.

**Risk:** `write`

```ts
await corsair.sanity.api.assets.upload({ kind: 'image', contentBase64: '<base64 bytes>', contentType: 'image/png', filename: 'cover.png' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `kind` | `image \| file` | Yes | image: a picture Sanity can crop and resize (JPEG, PNG, WebP, GIF, SVG, AVIF, TIFF). file: anything else (PDF, audio, video...). |
| `contentBase64` | `string` | Yes | The file as base64, up to 25 MB decoded. |
| `contentType` | `string` | Yes | The MIME type, for example image/png or application/pdf. |
| `filename` | `string` | No | — |
| `title` | `string` | No | — |
| `description` | `string` | No | — |
| `label` | `string` | No | — |
| `imageMetadata` | `(exif \| location \| lqip \| palette \| blurhash)[]` | No | Images only: metadata to extract. Sanity always extracts dimensions; lqip, palette and blurhash are on by default. |
| `dataset` | `string` | No | The dataset to use. Left out: the connection's dataset, else production. |

Up to 25 MB as base64. Uploading the same bytes again returns the existing asset. Reference an image from a document as `{ _type: 'image', asset: { _type: 'reference', _ref: asset._id } }`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `asset` | `object` | Yes | The asset document. Reference it from a document: &#123; _type: 'image', asset: &#123; _type: 'reference', _ref: asset._id &#125; &#125;. Uploading the same bytes again returns the existing asset. |

<AccordionGroup>
<Accordion title="asset full type">

```ts
{
  _id: string,
  _type: string,
  _rev?: string | null,
  _createdAt?: string | null,
  _updatedAt?: string | null,
  url?: string | null,
  originalFilename?: string | null,
  mimeType?: string | null,
  size?: number | null,
  sha1hash?: string | null
}
```
</Accordion>
</AccordionGroup>

## Documents

### create

`documents.create`

Create a document as a draft (default) or, with publish: true, publish it at once. Returns its id and draft id.

**Risk:** `write`

```ts
await corsair.sanity.api.documents.create({ document: { _type: 'post', title: 'Hello world' }, publish: false });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `document` | `object` | Yes | The new document's fields: &#123; _type: 'post', title: '...', slug: &#123; _type: 'slug', current: '...' &#125; &#125;. Objects in arrays need a unique _key. Read the dataset's schema or an existing document of the type for its fields. |
| `publish` | `boolean` | No | false (default): the document is created as a draft, which nothing reading published content sees until documents.publish. true: created and published at once. |
| `ifExists` | `fail \| ignore` | No | When a draft with this id already exists: fail (default) errors, ignore leaves it and returns. Only the draft is checked: with an _id of a published document, a new draft is made over it. |
| `dryRun` | `boolean` | No | Check the change without making it. |
| `dataset` | `string` | No | The dataset to use. Left out: the connection's dataset, else production. |

Uses the Actions API, the same one the Studio uses. `ifExists` only checks the draft. With the `_id` of a published document, a new draft is made over it.

<AccordionGroup>
<Accordion title="document full type">

```ts
{
  _type: string,
  _id?: string
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `transactionId` | `string \| null` | No | The transaction that made the change. Missing when there was nothing to change. |
| `id` | `string` | Yes | The published id. Pass it to documents.publish, documents.edit and the rest. |
| `draftId` | `string` | Yes | The draft, drafts.&lt;id&gt;. |
| `published` | `boolean` | Yes | Whether the change was also published in this call. |

### delete

`documents.delete`

Delete up to 100 documents, published and draft together. Documents that reference them must drop the references first. With purge, they also leave the history.

**Risk:** `destructive`

```ts
await corsair.sanity.api.documents.delete({ ids: ['<id>'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ids` | `string[]` | Yes | Documents to delete, up to 100, published and draft together. |
| `purge` | `boolean` | No | Also remove it from the document history. Default false, so documents.history can still read it. |
| `dryRun` | `boolean` | No | — |
| `dataset` | `string` | No | The dataset to use. Left out: the connection's dataset, else production. |

Deletes each published document together with its draft. Documents with strong references to them block the delete until the references go. Ids that don't exist are skipped.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `transactionId` | `string \| null` | No | The transaction that made the change. Missing when there was nothing to change. |
| `ids` | `string[]` | Yes | — |

| `dryRun` | `boolean` | No | — |

The published version stays. Discarding a draft that doesn't exist is a 404.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `transactionId` | `string \| null` | No | The transaction that made the change. Missing when there was nothing to change. |
| `id` | `string` | Yes | — |
| `draftId` | `string` | Yes | — |

### edit

`documents.edit`

Change a document the way the Studio does: the patch goes to its draft, made from the published version if needed, and nothing goes live until documents.publish (or publish: true).

**Risk:** `write`

```ts
await corsair.sanity.api.documents.edit({ id: '<id>', set: { title: 'A better title' }, setIfMissing: { tags: [] }, insert: { after: 'tags[-1]', items: ['news'] } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The document id. A drafts. prefix is accepted and dropped: drafts and the published document share this id. |
| `set` | `Record<string, any>` | No | Fields to set, by path: &#123; title: 'New title', 'seo.description': '...', 'body[_key=="a1"].text': '...' &#125;. |
| `setIfMissing` | `Record<string, any>` | No | Fields to set only where they have no value yet. Use it before inserting into an array that may not exist: &#123; tags: [] &#125;. |
| `unset` | `string[]` | No | Paths to remove, for example ['subtitle', 'tags[0]']. |
| `inc` | `Record<string, number>` | No | Numbers to add to, by path. |
| `dec` | `Record<string, number>` | No | Numbers to subtract from, by path. |
| `insert` | `object` | No | Insert items into an array at a path: &#123; after: 'tags[-1]', items: ['news'] &#125; appends. Objects in an array need a unique _key. |
| `diffMatchPatch` | `Record<string, string>` | No | diff-match-patch strings to apply to text fields, by path. |
| `publish` | `boolean` | No | false (default): the edit stays in the draft until documents.publish. true: published in the same transaction. |
| `dryRun` | `boolean` | No | — |
| `dataset` | `string` | No | The dataset to use. Left out: the connection's dataset, else production. |

Patches the draft and makes one from the published version first when there is none. The edit action takes no revision check. Use `documents.patch` with `ifRevisionId` when two writers might collide.

### history

`documents.history`

A document as it stood at a revision or a point in time. How far back depends on the plan's history retention.

**Risk:** `read`

```ts
await corsair.sanity.api.documents.history({ id: '<id>', time: '2026-11-01T00:00:00Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The exact document id, drafts.&lt;id&gt; for a draft. |
| `revision` | `string` | No | A _rev, from a document or documents.transactions. |
| `time` | `string` | No | An ISO time: the document as it stood then. |
| `lastRevision` | `boolean` | No | The last version it had, including just before it was deleted. The way to recover a deleted document. |
| `dataset` | `string` | No | The dataset to use. Left out: the connection's dataset, else production. |

`lastRevision: true` reads a deleted document as it was just before the delete, which is how you recover one. How far back history goes depends on the plan.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
