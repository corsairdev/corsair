## Events

### get

`events.get`

Read one queued event by ID to see whether an add or delete finished, failed, or is still running

**Risk:** `read`

```ts
await corsair.mem0.api.events.get({ event_id: '2c4d1f44-4f7b-4b2f-9f6e-7b5b4f5a1234' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event_id` | `string` | Yes | The event_id returned by memories.add or memories.deleteAll. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `event_type` | `string \| null` | No | ADD, SEARCH, DELETE_ALL and so on. |
| `status` | `string \| null` | No | PENDING, RUNNING, FAILED or SUCCEEDED. |
| `payload` | `Record<string, any> \| null` | No | — |
| `metadata` | `Record<string, any> \| null` | No | — |
| `results` | `any[] \| Record<string, any> \| null` | No | An array for ADD, SEARCH and GET_ALL, one object for UPDATE, and null for a delete. |
| `created_at` | `string \| null` | No | — |
| `updated_at` | `string \| null` | No | — |
| `started_at` | `string \| null` | No | — |
| `completed_at` | `string \| null` | No | — |
| `latency` | `number \| null` | No | Processing time in milliseconds. |
| `graph_status` | `string \| null` | No | — |
| `error` | `string \| null` | No | — |

## Memories

### add

`memories.add`

Extract memories from conversation messages and store them for a user, agent, app or run; processing is queued and returns an event_id to poll

**Risk:** `write`

```ts
await corsair.mem0.api.memories.add({ user_id: 'alice', messages: [{ role: 'user', content: 'I moved to Austin last month.' }], metadata: { source: 'onboarding_form' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `messages` | `object[]` | Yes | Conversation turns for Mem0 to extract memories from. |
| `user_id` | `string` | No | Scope memories to this user. |
| `agent_id` | `string` | No | Scope memories to this agent. |
| `app_id` | `string` | No | Scope memories to this app. |
| `run_id` | `string` | No | Scope memories to this run. |
| `metadata` | `Record<string, any>` | No | Custom key/value metadata attached to each memory. |
| `infer` | `boolean` | No | Defaults to true, which runs extraction. Set false to store each message verbatim, which also makes the response synchronous. |
| `expiration_date` | `string` | No | Date through which the memory is visible. Expired memories are hidden unless `show_expired` is passed. |
| `immutable` | `boolean` | No | Defaults to false. Immutable memories are excluded from later update and consolidation. |
| `includes` | `string` | No | Free-text hint of what to include during extraction. |
| `excludes` | `string` | No | Free-text hint of what to exclude during extraction. |
| `enable_graph` | `boolean` | No | Enable graph memory extraction for this call. |
| `timestamp` | `number` | No | Unix epoch seconds used as the created_at of stored memories. |

<AccordionGroup>
<Accordion title="messages full type">

```ts
{
  role: user | assistant | system,
  content: string
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event_id` | `string \| null` | No | Poll this with events.get. |
| `status` | `string \| null` | No | PENDING when extraction is queued, SUCCEEDED when `infer` was false. |
| `message` | `string \| null` | No | — |
| `results` | `object[] \| null` | No | — |

<AccordionGroup>
<Accordion title="results full type">

```ts
{
  id?: string | null,
  data?: Record<string, any> | null,
  event?: string | null
}[] | null
```
</Accordion>
</AccordionGroup>

### deleteAll

`memories.deleteAll`

Delete every memory matching a filter, or every memory for an entity when the filter is "*"; Mem0 queues the deletion and answers immediately

**Risk:** `destructive`

```ts
await corsair.mem0.api.memories.deleteAll({ user_id: 'alice' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `user_id` | `string` | No | Delete this user's memories. Pass "*" for every user. |
| `agent_id` | `string` | No | Delete this agent's memories. Pass "*" for every agent. |
| `app_id` | `string` | No | Delete this app's memories. Pass "*" for every app. |
| `run_id` | `string` | No | Delete this run's memories. Pass "*" for every run. |
| `org_id` | `string` | No | Only memories in this organization. |
| `project_id` | `string` | No | Only memories in this project. |
| `metadata` | `Record<string, any>` | No | Only memories whose metadata matches these keys. Values must be strings, numbers or booleans, because null and undefined reach the wire as no key at all. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `true` | Yes | — |
| `message` | `string \| null` | No | — |
| `event_id` | `string \| null` | No | Mem0 queues the deletion and answers immediately. |

### list

List stored memories page by page, filtered by entity, date range or category; entity IDs go inside `filters`

**Risk:** `read`


**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `filters` | `Record<string, any>` | Yes | Entity and metadata filters. Must include at least one of user_id, agent_id, app_id or run_id, at the top level or inside AND/OR/NOT. Supports AND, OR, NOT and the operators in, gte, lte, gt, lt, ne, icontains, and * as a wildcard. |
| `page` | `number` | No | 1-based page. Defaults to 1. |
| `page_size` | `number` | No | Results per page. Defaults to 100. |
| `show_expired` | `boolean` | No | Defaults to false. Include memories past their expiration_date. |

| `categories` | `string[]` | No | Only memories tagged with any of these categories. |
| `fields` | `string[]` | No | Only these fields come back per memory. A memory without them is absent from the result, not null. |
| `keywords` | `string` | No | Free-text keyword filter applied on top of `filters`. |

### search

`memories.search`

Rank stored memories by relevance to a query with hybrid semantic, keyword and entity matching; entity IDs go inside `filters`

**Risk:** `read`

```ts
await corsair.mem0.api.memories.search({ query: 'Where does the user live?', filters: { user_id: 'alice' }, top_k: 5 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | Natural-language search query. |
| `filters` | `Record<string, any>` | Yes | Entity and metadata filters. Must include at least one of user_id, agent_id, app_id or run_id, at the top level or inside AND/OR/NOT. Supports AND, OR, NOT and the operators in, gte, lte, gt, lt, ne, icontains, and * as a wildcard. |
| `top_k` | `number` | No | Number of results. Defaults to 10. |
| `threshold` | `number` | No | Minimum relevance score. Defaults to 0.1. Pass 0 to disable filtering. |
| `rerank` | `boolean` | No | Defaults to false. Apply the managed reranker, which adds latency. |
| `show_expired` | `boolean` | No | Defaults to false. Include memories past their expiration_date. |
| `reference_date` | `number \| string` | No | Date to simulate the search from. Accepts a Unix epoch, YYYY-MM-DD, or an ISO datetime. |
| `fields` | `string[]` | No | Only these fields come back per memory. A memory without them is absent from the result, not null. |
| `categories` | `string[]` | No | Only memories tagged with any of these categories. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `results` | `object[]` | Yes | — |

## Webhooks

### create

`webhooks.create`

Register a URL to receive Mem0 events for a project, subscribing it to memory add, update, delete or categorize and the ingest job events

**Risk:** `write`

```ts
await corsair.mem0.api.webhooks.create({ project_id: 'proj_123', name: 'Memory Logger', url: 'https://your-app.com/webhook', event_types: ['memory_add', 'memory_categorize'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project_id` | `string` | Yes | The project to register the webhook on. |
| `name` | `string` | Yes | A label for the webhook. |
| `url` | `string` | Yes | The HTTPS endpoint Mem0 posts events to. |
| `event_types` | `(memory_add \| memory_update \| memory_delete \| memory_categorize \| ingest_job_completed \| ingest_job_partially_completed \| ingest_job_failed \| ingest_job_cancelled)[]` | Yes | Events to subscribe to. Mem0 requires this: omitting it does not fall back to a default. |
| `is_active` | `boolean` | No | Defaults to true on Mem0 side. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `webhook_id` | `string` | Yes | — |
| `name` | `string \| null` | No | — |
| `url` | `string \| null` | No | — |
| `event_types` | `string[] \| null` | No | — |
| `owner` | `string \| null` | No | Username of the account that created the webhook. |
| `is_active` | `boolean \| null` | No | — |
| `project` | `string \| null` | No | Name of the project the webhook belongs to. |
| `created_at` | `string \| null` | No | — |
| `updated_at` | `string \| null` | No | — |
