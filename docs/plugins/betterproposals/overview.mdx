Use **Better Proposals** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 23 typed API operations
- 10 synced entities (`brands`, `companies`, `covers`, `currencies`, `documentTypes`, `mergeTags`, and 4 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/betterproposals
```
```bash yarn
yarn add corsair @corsair-dev/betterproposals
```
```bash pnpm
pnpm install corsair @corsair-dev/betterproposals
```
```bash bun
bun add corsair @corsair-dev/betterproposals
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { betterproposals } from '@corsair-dev/betterproposals';

export const corsair = createCorsair({
	plugins: [
		betterproposals(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
betterproposals()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'betterproposals',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`companies.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.betterproposals.api.companies.get({});
```


**`companies.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.betterproposals.api.companies.create({});
```


See the full list on the [API](/plugins/betterproposals/api) page.

## Query synced data

Synced entities support `tenant.betterproposals.db.<entity>.search()` and `.list()`: `brands`, `companies`, `covers`, `currencies`, `documentTypes`, `mergeTags`, `proposals`, `quotes`, `settings`, `templates`.

See [Database](/plugins/betterproposals/database) for filters and operators.
