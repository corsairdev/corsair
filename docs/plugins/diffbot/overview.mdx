Use **Diffbot** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 35 typed API operations
- 14 synced entities (`accounts`, `articles`, `bulkJobs`, `crawlJobs`, `customApis`, `discussions`, and 8 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/diffbot better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/diffbot better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/diffbot better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/diffbot better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { diffbot } from '@corsair-dev/diffbot';

export const corsair = createCorsair({
	plugins: [
		diffbot(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Diffbot API key before the first call: `pnpm corsair setup --plugin=diffbot --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
diffbot()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'diffbot',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`account.getAccount`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.diffbot.api.account.getAccount({});
```


**`bulk.createBulk`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.diffbot.api.bulk.createBulk({});
```


See the full list on the [API](/plugins/diffbot/api) page.

## Query synced data

Synced entities support `tenant.diffbot.db.<entity>.search()` and `.list()`: `accounts`, `articles`, `bulkJobs`, `crawlJobs`, `customApis`, `discussions`, `events`, `images`, `jobs`, `lists`, `organizations`, `people`, `products`, `videos`.

See [Database](/plugins/diffbot/database) for filters and operators.
