## Indicators

### cities

`indicators.cities`

List cities by INSEE code, zipcode, name, label, slug or polygon, with paging

**Risk:** `read`

```ts
await corsair.melo.api.indicators.cities({ insee: '75056' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `excludeGroupedCities` | `boolean` | No | Set to true to exclude cities that have grouped cities under them. The API defaults to false. |
| `insee` | `string \| string[]` | No | Filter by INSEE code. A string is sent as `insee`, an array as `insee[]`. |
| `polygon` | `object[]` | No | Filter by cities inside a polygon of GPS points. Sent as `polygon[0][lat]`, `polygon[0][lon]`, and so on. The spec types this as a string; its example uses this indexed form. |
| `libelle` | `string` | No | Filter by city label. |
| `name` | `string` | No | Filter by city name. |
| `order` | `object` | No | — |
| `page` | `number` | No | The collection page number. Defaults to 1. |
| `slug` | `string` | No | Filter by city slug. |
| `zipcode` | `string \| string[]` | No | Filter by zipcode. A string is sent as `zipcode`, an array as `zipcode[]`. |

### locations

**Risk:** `read`


### pricePerMeter

`indicators.pricePerMeter`

Average, median and time series of the price per meter for properties matching the same filters as properties.list

**Risk:** `read`

```ts
await corsair.melo.api.indicators.pricePerMeter({ includedDepartments: ['/departments/77'], propertyTypes: [0], transactionType: 0, aggregationInterval: 'year' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `advertPriceMin` | `number` | No | Minimum price of advert. Filters properties based on any non expired adverts prices. |
| `advertPriceMax` | `number` | No | Maximum price of advert. Filters properties based on any non expired adverts prices. |
| `bedroomMin` | `number` | No | Minimum number of bedrooms in the property. |
| `bedroomMax` | `number` | No | Maximum number of bedrooms in the property. |
| `budgetMin` | `number` | No | Minimum budget for the property. |
| `budgetMax` | `number` | No | Maximum budget for the property. |
| `condominiumFeesMin` | `number` | No | Minimum condominium fees for the property. |
| `condominiumFeesMax` | `number` | No | Maximum condominium fees for the property. |
| `constructionYearMin` | `number` | No | Minimum construction year of the property. |
| `constructionYearMax` | `number` | No | Maximum construction year of the property. |
| `energyCategories` | `(A \| B \| C \| D \| E \| F \| G)[]` | No | The energy efficiency categories of the property. |
| `energyValueMin` | `number` | No | Minimum energy value of the property. |
| `energyValueMax` | `number` | No | Maximum energy value of the property. |
| `eventPriceVariationFromCreatedAt` | `string` | No | Date from which an event of type price is created — inclusive. |
| `eventPriceVariationToCreatedAt` | `string` | No | Date before which an event of type price is created — inclusive. |
| `eventPriceVariationMin` | `number` | No | Minimum percent variation of an event of type price. |
| `eventPriceVariationMax` | `number` | No | Maximum percent variation of an event of type price. |
| `eventSurfaceVariationFromCreatedAt` | `string` | No | Date from which an event of type surface is created — inclusive. |
| `eventSurfaceVariationToCreatedAt` | `string` | No | Date before which an event of type surface is created — inclusive. |
| `eventSurfaceVariationMin` | `number` | No | Minimum percent variation of an event of type surface. |
| `eventSurfaceVariationMax` | `number` | No | Maximum percent variation of an event of type surface. |
| `excludedCities` | `string[]` | No | Cities to be excluded. |
| `excludedInseeCodes` | `string[]` | No | Insee codes to be excluded. |
| `excludedProperties` | `string[]` | No | Properties to be excluded. |
| `excludedZipcodes` | `string[]` | No | Zipcodes to be excluded. |
| `expressions` | `object[]` | No | Full-text rules on the title or description of the property: an array of OR groups, each an array of AND terms `{ word, options: { includes, strict } }`. Sent as `expressions[group][term][word]` and `expressions[group][term][options][includes\|strict]`. |
| `feesPercentageMin` | `number` | No | Minimum percentage of fees. |
| `feesPercentageMax` | `number` | No | Maximum percentage of fees. |
| `feesResponsibility` | `0 \| 1` | No | Responsibility for fees. `0` for seller, `1` for buyer. |
| `floorQuantityMin` | `number` | No | Minimum number of floors in the property. |
| `floorQuantityMax` | `number` | No | Maximum number of floors in the property. |
| `fromDate` | `string` | No | Date from which the property is created — inclusive. |
| `toDate` | `string` | No | Date until which the property is created — inclusive. |
| `fromUpdatedAt` | `string` | No | Date from which the property is updated — inclusive. |
| `toUpdatedAt` | `string` | No | Date until which the property is updated — inclusive. |
| `furnished` | `boolean` | No | Filter for furnished properties. |
| `geoAccuracy` | `(1 \| 2)[]` | No | Filters properties by geocoding confidence level: `1` (house-number level), `2` (neighborhood level). |
| `geoShapes` | `[number, number][][]` | No | Geographic areas to filter on: an array of polygons, each an array of `[lon, lat]` points. Sent as `geoShapes[polygon][point][0\|1]`. |
| `greenHouseGasCategories` | `(A \| B \| C \| D \| E \| F \| G)[]` | No | Green house gas performance letter array of the property. |
| `greenHouseGasValueMin` | `number` | No | Minimum value of green house gas of the property. |
| `greenHouseGasValueMax` | `number` | No | Maximum value of green house gas of the property. |
| `includedCities` | `string[]` | No | Located in given cities. Use `indicators.locations` to get the city IRIs, for example `/cities/30953`. |
| `includedDepartments` | `string[]` | No | Located in given departments. Use `indicators.locations` to get the department IRIs, for example `/departments/77`. |
| `includedInseeCodes` | `string[]` | No | Located in given insee codes. |
| `includedZipcodes` | `string[]` | No | Located in given zipcodes. |
| `inventoryPriceMin` | `number` | No | Greater than or equal to given inventory price. |
| `inventoryPriceMax` | `number` | No | Lower than or equal to given inventory price. |
| `lat` | `number` | No | Latitude. Will work if latitude exists in the property. |
| `lon` | `number` | No | Longitude. Will work if longitude exists in the property. |
| `radius` | `number` | No | Distance expressed in kilometers. Will work if latitude & longitude parameters are also set. |
| `lotCountMin` | `number` | No | Greater than or equal to given lot count. |
| `lotCountMax` | `number` | No | Lower than or equal to given lot count. |
| `priceExcludingFeesMin` | `number` | No | Greater than or equal to given price excluding fees. |
| `priceExcludingFeesMax` | `number` | No | Lower than or equal to given price excluding fees. |
| `pricePerMeterMin` | `number` | No | Greater than or equal to given price per meter. |
| `pricePerMeterMax` | `number` | No | Lower than or equal to given price per meter. |
| `propertyTypes` | `(0 \| 1 \| 2 \| 3 \| 4 \| 5 \| 6)[]` | No | Type of property. Apartment `0`, House `1`, Building `2`, Parking `3`, Office `4`, Land `5`, Shop `6`. |
| `publisherTypes` | `(0 \| 1)[]` | No | Type of publisher. Individual `0`, Professional `1`. |
| `rentalChargesMin` | `number` | No | Greater than or equal to given rental charges amount. |
| `rentalChargesMax` | `number` | No | Lower than or equal to given rental charges amount. |
| `rentalPledgeMin` | `number` | No | Greater than or equal to given rental pledge amount. |
| `rentalPledgeMax` | `number` | No | Lower than or equal to given rental pledge amount. |
| `renterFeesMin` | `number` | No | Greater than or equal to given renter fees. |
| `renterFeesMax` | `number` | No | Lower than or equal to given renter fees. |
| `roomMin` | `number` | No | Minimum rooms of the property. |
| `roomMax` | `number` | No | Maximum rooms of the property. |
| `sortMode` | `property \| advert` | No | Whether to sort results by properties or by adverts. If `property`, `fromDate`/`toDate` apply to the property root object; if `advert`, they apply to the nested adverts. |
| `surfaceMin` | `number` | No | Greater than or equal to given surface. |
| `surfaceMax` | `number` | No | Lower than or equal to given surface. |
| `transactionType` | `0 \| 1` | No | Type of transaction. Sell `0`, Rent `1`. |
| `withCoherentPrice` | `boolean \| null` | No | Price coherence filter. `true` returns properties whose price passes our coherence checks; `false` returns properties flagged as incoherent — both also include properties whose price has not been assessed. Set to `null` (or send an empty value) to disable filtering. If omitted, defaults to `true`. |
| `withLocation` | `boolean` | No | Having a latitude and longitude. |
| `withVirtualTour` | `boolean` | No | Having a virtual tour video link. |
| `expired` | `boolean` | No | Whether to show properties that are expired. A property is considered expired when all its adverts are expired. Default is `null` which returns all properties no matter if they're expired or not. |
| `aggregationInterval` | `month \| year` | No | Date histogram granularity for the time series. Defaults to `month`. |
| `order` | `object` | No | — |
| `page` | `number` | No | The collection page number. Defaults to 1. |
| `itemsPerPage` | `number` | No | The number of items per page. Max is 30; defaults to 30. `0` returns only `hydra:totalItems` (capped at 10 000 on properties.list). |

```ts
await corsair.melo.api.properties.list({ includedDepartments: ['/departments/77'], propertyTypes: [1], transactionType: 0, budgetMax: 450000, itemsPerPage: 20 });
```

| `bedroomMin` | `number` | No | Minimum number of bedrooms in the property. |
| `bedroomMax` | `number` | No | Maximum number of bedrooms in the property. |
| `budgetMin` | `number` | No | Minimum budget for the property. |
| `budgetMax` | `number` | No | Maximum budget for the property. |
| `condominiumFeesMin` | `number` | No | Minimum condominium fees for the property. |
| `condominiumFeesMax` | `number` | No | Maximum condominium fees for the property. |
