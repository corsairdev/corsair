---
title: "TwentyOne Risk database"
sidebarTitle: "Database"
description: "The TwentyOne Risk plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for TwentyOne Risk. To read its data, call the [API operations](/plugins/twentyonerisk/api), which return what TwentyOne Risk has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
