## Customers

### create

`customers.create`

Create a Zoho Invoice customer

**Risk:** `write`

```ts
await corsair.zohoinvoice.api.customers.create({ body: { contact_name: 'Acme Corp', company_name: 'Acme Corp' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `organizationId` | `string` | No | Zoho Invoice organization id. Leave out to use the one saved at connection, or the only organization the account has. organizations.list lists them. |
| `body` | `Record<string, any>` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contact` | `object` | Yes | — |
