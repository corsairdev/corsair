The API2PDF plugin syncs data locally. Use `corsair.api2pdf.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Pdf Jobs

Path: `api2pdf.db.pdfJobs.search`

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.api2pdf.db.pdfJobs.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `operation` | `string` | equals, contains, startsWith, endsWith, in |
| `responseId` | `string` | equals, contains, startsWith, endsWith, in |
| `fileUrl` | `string` | equals, contains, startsWith, endsWith, in |
| `success` | `boolean` | equals |
| `cost` | `number` | equals, gt, gte, lt, lte, in |
| `mbOut` | `number` | equals, gt, gte, lt, lte, in |
| `seconds` | `number` | equals, gt, gte, lt, lte, in |
| `updatedAt` | `date` | equals, before, after, between |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
