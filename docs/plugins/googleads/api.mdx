## Reporting

### mutate

`reporting.mutate`

Mutate any entity in one call: each entry names its own operation, and removing is permanent for that entity

**Risk:** `write`

```ts
await corsair.googleads.api.reporting.mutate({ customerId: '1234567890', mutateOperations: [{ campaignOperation: { update: { resourceName: 'customers/1234567890/campaigns/111', status: 'PAUSED' }, updateMask: 'status' } }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `customerId` | `string` | Yes | The account's customer ID, e.g. `1234567890`. A hyphenated `123-456-7890` is accepted and the hyphens are removed, which is what the docs ask |
| `mutateOperations` | `Record<string, any>[]` | Yes | One entry per entity, each naming its operation, e.g. `{ campaignOperation: { update: { resourceName, name }, updateMask: "name" } }` |
| `partialFailure` | `boolean \| null` | No | Let the request succeed for the operations that can, reporting the rest in partialFailureError. Off by default, which makes the batch all-or-nothing |
| `validateOnly` | `boolean \| null` | No | Validate the request without applying it: Google returns only errors, never results |
| `responseContentType` | `UNSPECIFIED \| RESOURCE_NAME_ONLY \| MUTABLE_RESOURCE \| null` | No | `MUTABLE_RESOURCE` returns the changed resource; the default returns only the resource name |

Each entry names its own entity operation, e.g. `{ campaignOperation: { remove } }`. `partialFailure` lets the good entries land.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `results` | `object[] \| null` | No | One result per operation, in order, each naming the resource |
| `partialFailureError` | `object \| null` | No | Present when partialFailure was set and some operations failed |

### search

`reporting.search`

Run a Google Ads Query Language statement and read its rows, 10,000 at a time

**Risk:** `read`

```ts
await corsair.googleads.api.reporting.search({ customerId: '1234567890', query: "SELECT campaign.id, campaign.name FROM campaign LIMIT 10" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `customerId` | `string` | Yes | The account's customer ID, e.g. `1234567890`. A hyphenated `123-456-7890` is accepted and the hyphens are removed, which is what the docs ask |
| `query` | `string` | Yes | A Google Ads Query Language statement, e.g. `SELECT campaign.id, campaign.name FROM campaign WHERE campaign.status = 'ENABLED'` |
| `pageSize` | `number \| null` | No | 1 to 10,000 rows. Omitted, Google chooses |
| `pageToken` | `string \| null` | No | nextPageToken from a previous page of the same query |
| `validateOnly` | `boolean \| null` | No | Validate the request without applying it: Google returns only errors, never results |

Pages at 10,000 rows; pass `nextPageToken` back as `pageToken`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `results` | `Record<string, any>[] \| null` | No | Absent when the query matched nothing |
| `nextPageToken` | `string \| null` | No | Pass back as pageToken. Absent on the last page |
| `totalResultsCount` | `string \| null` | No | int64 as a string, and only counted when the query asks for the total |
| `fieldMask` | `string \| null` | No | Comma-separated fields the response carries |
| `queryResourceConsumption` | `string \| null` | No | int64 as a string: the quota cost this query used |
