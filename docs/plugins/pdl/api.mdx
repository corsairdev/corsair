## Autocomplete

### suggest

`autocomplete.suggest`

Get value suggestions for a PDL field prefix

**Risk:** `read`

```ts
await corsair.pdl.api.autocomplete.suggest({ field: 'job_title', text: 'soft', size: 10 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `field` | `string` | Yes | — |
| `text` | `string` | Yes | — |
| `size` | `number` | No | — |
| `titlecase` | `boolean` | No | — |
| `pretty` | `boolean` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fields` | `string[]` | Yes | — |
| `data` | `object[]` | Yes | — |
| `status` | `number` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  count: number,
  name: string,
  meta?: {
  }
}[]
```
</Accordion>
</AccordionGroup>
