## Account

### createSite

`account.createSite`

Create and provision a new site for tracking in GoSquared

**Risk:** `write`

```ts
await corsair.gosquared.api.account.createSite({ domain_name: 'example.com', name: 'Example Site' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `domain_name` | `string` | Yes | — |
| `name` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `site_token` | `string` | Yes | — |
| `name` | `string \| null` | No | — |
| `domain_name` | `string` | No | — |
| `timezone` | `string` | No | — |
| `created` | `string` | No | — |
| `user_id` | `number \| string` | No | — |
| `plan_name` | `string` | No | — |
