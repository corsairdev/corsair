## Connect

### apiKey

`connect.apiKey`

Resolve the tenant host using the stored API key (Connect is free)

**Risk:** `read`

```ts
await corsair.formdesk.api.connect.apiKey({ domain: 'apitest' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `domain` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `apikey` | `string` | Yes | — |
| `host` | `string` | Yes | — |



---

### credentials

`connect.credentials`

Resolve the tenant host and API key from Formdesk credentials (free)

**Risk:** `read`

```ts
await corsair.formdesk.api.connect.credentials({ domain: 'apitest', username: 'automation-user', password: 'not-a-real-password' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `domain` | `string` | Yes | — |
| `username` | `string` | Yes | — |
| `password` | `string` | Yes | — |

This call sends Formdesk username/password credentials and returns an API key; treat its output as a secret. Connect is exempt from the API credit charge.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `apikey` | `string` | Yes | — |
| `host` | `string` | Yes | — |

## Files

### content

`files.content`

Download file content (1 API credit per call)

**Risk:** `read`

```ts
await corsair.formdesk.api.files.content({ host: 'fd7.formdesk.com', domain: 'apitest', fileId: 8702600 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `host` | `string` | Yes | — |
| `domain` | `string` | Yes | — |
| `fileId` | `number \| string` | Yes | — |

Returns binary data as `{ kind: 'binary', contentType, base64, filename?, byteLength }`. Responses over 25 MiB are rejected by this plugin.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `kind` | `binary` | Yes | — |
| `contentType` | `string` | Yes | — |
| `base64` | `string` | Yes | — |
| `filename` | `string` | No | — |
| `byteLength` | `number` | Yes | — |

| `data` | `Record<string, JsonValue> \| Record<string, JsonValue>[]` | Yes | — |
