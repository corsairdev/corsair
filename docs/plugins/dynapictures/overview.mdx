Use **Dynapictures** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 7 typed API operations
- 4 synced entities (`media`, `templates`, `webhooks`, `workspaces`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/dynapictures
```
```bash yarn
yarn add corsair @corsair-dev/dynapictures
```
```bash pnpm
pnpm install corsair @corsair-dev/dynapictures
```
```bash bun
bun add corsair @corsair-dev/dynapictures
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { dynapictures } from '@corsair-dev/dynapictures';

export const corsair = createCorsair({
	plugins: [
		dynapictures(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
dynapictures()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'dynapictures',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`templates.list`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.dynapictures.api.templates.list({});
```


**`media.upload`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.dynapictures.api.media.upload({});
```


See the full list on the [API](/plugins/dynapictures/api) page.

## Query synced data

Synced entities support `tenant.dynapictures.db.<entity>.search()` and `.list()`: `media`, `templates`, `webhooks`, `workspaces`.

See [Database](/plugins/dynapictures/database) for filters and operators.
