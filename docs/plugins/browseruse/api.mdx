## Browsers

### create

`browsers.create`

POST /browsers — start a cloud browser; returns cdpUrl for Playwright/Puppeteer and a liveUrl

**Risk:** `write`

```ts
await corsair.browseruse.api.browsers.create({ proxyCountryCode: 'us', timeout: 15 });
```

|------|------|----------|-------------|
| `profileId` | `string` | No | — |
