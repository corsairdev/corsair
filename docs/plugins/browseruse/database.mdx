The Browser Use plugin syncs data locally. Use `corsair.browseruse.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Browsers

Path: `browseruse.db.browsers.search`

```ts
const rows = await corsair.browseruse.db.browsers.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `liveUrl` | `string` | equals, contains, startsWith, endsWith, in |
| `cdpUrl` | `string` | equals, contains, startsWith, endsWith, in |
| `timeoutAt` | `string` | equals, contains, startsWith, endsWith, in |
| `startedAt` | `string` | equals, contains, startsWith, endsWith, in |
| `finishedAt` | `string` | equals, contains, startsWith, endsWith, in |
| `proxyUsedMb` | `string` | equals, contains, startsWith, endsWith, in |
| `proxyCost` | `string` | equals, contains, startsWith, endsWith, in |
| `browserCost` | `string` | equals, contains, startsWith, endsWith, in |
| `agentSessionId` | `string` | equals, contains, startsWith, endsWith, in |
| `recordingUrl` | `string` | equals, contains, startsWith, endsWith, in |
| `recordingAvailable` | `boolean` | equals |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
