Use **Browser Use** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 7 typed API operations
- 2 synced entities (`browsers`, `runs`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/browseruse
```
```bash yarn
yarn add corsair @corsair-dev/browseruse
```
```bash pnpm
pnpm install corsair @corsair-dev/browseruse
```
```bash bun
bun add corsair @corsair-dev/browseruse
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { browseruse } from '@corsair-dev/browseruse';

export const corsair = createCorsair({
	plugins: [
		browseruse(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
browseruse()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'browseruse',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read an agent run result**

```ts
const tenant = corsair.withTenant('acme');
await tenant.browseruse.api.runs.get({ id: '00000000-0000-0000-0000-000000000000' });
```


**Start a cloud browser**

```ts
const tenant = corsair.withTenant('acme');
await tenant.browseruse.api.browsers.create({ proxyCountryCode: 'us', timeout: 15 });
```


See the full list on the [API](/plugins/browseruse/api) page.

## Query synced data

Runs are upserted by id on create, get and cancel, so polling a run updates one row.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.browseruse.db.runs.search({
	data: { model: 'gpt-6-luna' },
	limit: 50,
});
```

Synced entities: `browsers`, `runs`. See [Database](/plugins/browseruse/database) for filters and operators.
