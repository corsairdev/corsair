## Actions

### trigger

`actions.trigger`

Run a legacy action for a connection synchronously. Actions can write to the end customer's account.

**Risk:** `destructive`

```ts
await corsair.nango.api.actions.trigger({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `connection_id` | `string` | Yes | The connection ID. |
| `provider_config_key` | `string` | Yes | The integration ID (unique key) the connection belongs to. |
| `action_name` | `string` | Yes | — |
| `input` | `Record<string, any>` | No | — |



**Output:** `any`

### get

`connections.get`

Get one connection. Pass include_credentials: true to also return its live third-party credentials (access token, API key, password); they are dropped otherwise.

**Risk:** `read`

```ts
await corsair.nango.api.connections.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `connectionId` | `string` | Yes | The connection ID. |
| `provider_config_key` | `string` | Yes | The integration ID (unique key) the connection belongs to. |
| `include_credentials` | `boolean` | No | Return the connection credentials (access tokens, API keys, passwords). Off by default; the plugin drops them from the result unless this is true. |
| `force_refresh` | `boolean` | No | Refresh the access token even if it has not expired. |
| `refresh_token` | `boolean` | No | Also return the refresh token (needs include_credentials). |
| `refresh_github_app_jwt_token` | `boolean` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | — |
| `connection_id` | `string` | Yes | — |
| `provider_config_key` | `string` | Yes | — |
| `provider` | `string` | Yes | — |
| `errors` | `object[]` | No | — |
| `metadata` | `Record<string, any> \| null` | No | — |
| `connection_config` | `Record<string, any> \| null` | No | — |
| `tags` | `Record<string, string> \| null` | No | — |
| `created_at` | `string` | No | — |
| `updated_at` | `string` | No | — |
| `last_fetched_at` | `string \| null` | No | — |
| `webhook_url_override` | `string \| null` | No | — |
| `end_user` | `object \| null` | No | — |
| `credentials` | `object` | No | Only present when include_credentials is true. Holds live third-party secrets. |

## Proxy

### delete

`proxy.delete`

Send a DELETE through Nango's proxy to the end customer's API with the connection's credentials.

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.nango.api.proxy.delete({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `connection_id` | `string` | Yes | The connection ID. |
| `provider_config_key` | `string` | Yes | The integration ID (unique key) the connection belongs to. |
| `path` | `string` | Yes | Path on the end customer's API, relative to the provider's base URL, e.g. /v1/users. |
| `query` | `Record<string, string \| number \| boolean>` | No | — |
| `headers` | `Record<string, string>` | No | Headers passed on to the external API (sent as Nango-Proxy-&lt;name&gt;). |
| `retries` | `number` | No | Retries Nango makes on failure, with exponential back-off. |
| `body` | `any` | No | JSON body sent to the external API. |



**Output:** `any`
