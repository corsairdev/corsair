## Connections

### delete

`connections.delete`

Delete a connection

**Risk:** `destructive`

```ts
await corsair.nango.api.connections.delete({ connectionId: 'example', provider_config_key: 'example' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `connectionId` | `string` | Yes | — |
| `provider_config_key` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | No | — |

### get

**Risk:** `read`

```ts
await corsair.nango.api.connections.get({ connectionId: 'example', provider_config_key: 'example' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `connectionId` | `string` | Yes | — |
| `provider_config_key` | `string` | Yes | — |
| `force_refresh` | `boolean` | No | — |
| `refresh_token` | `boolean` | No | — |
| `refresh_github_app_jwt_token` | `boolean` | No | — |



**Output**

| `id` | `number` | Yes | — |
| `connection_id` | `string` | Yes | — |
| `provider_config_key` | `string` | Yes | — |

| `errors` | `object[]` | Yes | — |
| `metadata` | `Record<string, any> \| null` | Yes | — |
| `connection_config` | `Record<string, any>` | Yes | — |
| `tags` | `Record<string, string>` | Yes | — |
| `created_at` | `string` | Yes | — |
| `updated_at` | `string` | Yes | — |
| `last_fetched_at` | `string \| null` | Yes | — |
| `webhook_url_override` | `string \| null` | No | — |
| `credentials` | `object` | Yes | — |
| `end_user` | `object \| null` | No | — |

## Sessions

### create

`sessions.create`

Create a connect session

**Risk:** `write`

```ts
await corsair.nango.api.sessions.create({
	tags: { end_user_id: 'example' },
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `tags` | `Record<string, string>` | No | — |
| `end_user` | `object` | No | — |
| `organization` | `object` | No | — |
| `integrations_config_defaults` | `object` | No | — |
| `overrides` | `object` | No | — |
| `webhook_url_override` | `string` | No | — |
| `allowed_integrations` | `string[]` | No | — |

Either `tags` or `end_user` is required; Nango recommends using tags.

```ts
  tags?: Record<string, string>
```
