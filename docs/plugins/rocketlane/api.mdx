## Companies

### create

`companies.create`

Create a customer company with its account owner, url and description

**Risk:** `write`


| `visibility` | `EVERYONE \| MEMBERS` | No | — |

### list

`companies.list`

List customer companies with search and token paging

**Risk:** `read`

```ts
await corsair.rocketlane.api.companies.list({ company_name: { cn: 'acme' }, page_size: 50 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page_size` | `number` | No | Records per page, 1 to 100. Rocketlane uses 100 when this is omitted. |
| `page_token` | `string` | No | The `next_page_token` from the previous page. It is valid for 15 minutes, so paging must keep moving. |
| `include_fields` | `string[]` | No | — |
| `include_all_fields` | `boolean` | No | — |
| `sort_by` | `string` | No | — |
| `sort_order` | `ASC \| DESC` | No | — |
| `match` | `all \| any` | No | How several filters combine: `all` (every filter, the default) or `any` (at least one). |
| `company_name` | `object` | No | Search by company name, e.g. `{ cn: "acme" }`. |

### create

`projects.create`

Create a project from a customer and an owner, with its dates, visibility and financial details; Rocketlane emails an invite to each team member added

**Risk:** `write`

```ts
await corsair.rocketlane.api.projects.create({ project_name: 'Acme onboarding', customer: { company_id: 301 }, owner: { email_id: 'sam@example.com' }, start_date: '2026-11-01' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project_name` | `string` | Yes | The project title. |
| `customer` | `object` | Yes | — |
| `owner` | `object` | Yes | — |
| `start_date` | `string` | No | An ISO date. |
| `due_date` | `string` | No | An ISO date on or after `start_date`. |
| `visibility` | `EVERYONE \| MEMBERS` | No | `EVERYONE` lets every team member in the firm see the project; `MEMBERS` limits it to invited members. |
| `team_member_ids` | `number[]` | No | Users to add to the project. Rocketlane emails each of them an invite. |
| `currency` | `string` | No | A three-letter currency code. |
| `annualized_recurring_revenue` | `number` | No | — |
| `project_fee` | `number` | No | — |
| `budgeted_hours` | `number` | No | — |
| `external_reference_id` | `string` | No | — |
| `auto_create_company` | `boolean` | No | Create the customer company when it does not exist. |
| `assign_project_owner` | `boolean` | No | — |
| `fields` | `object[]` | No | — |

The customer and owner blocks each need an id or a name.
