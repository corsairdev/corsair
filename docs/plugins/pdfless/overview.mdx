Use **PDFLess** through Corsair: one client, typed API calls, local DB sync.

Auth is the apikey header on https://api.pdfless.com. With no key stored, Corsair raises AuthMissingError before any request; a key PDFLess rejects comes back as HTTP 401 ("No API key found in request" when the header is empty). pdfs.generate renders one document against the workspace quota (workspace.get shows remainingQuota), so it is destructive; its download_url expires at `expires`. Template data and PDF passwords are kept out of errors and events. The workspace model has no id, so a workspace row is stored only when name is present. A template row is stored only when id is present.

**What you get:**

- 3 typed API operations
- 2 synced entities (`templates`, `workspaces`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/pdfless better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/pdfless better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/pdfless better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/pdfless better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { pdfless } from '@corsair-dev/pdfless';

export const corsair = createCorsair({
	plugins: [
		pdfless(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the PDFLess API key before the first call: `pnpm corsair setup --plugin=pdfless --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
pdfless()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'pdfless',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List document templates**

```ts
const tenant = corsair.withTenant('acme');
await tenant.pdfless.api.templates.list({ page: 1, pageSize: 25 });
```


**Render an invoice PDF from a template**

```ts
const tenant = corsair.withTenant('acme');
await tenant.pdfless.api.pdfs.generate({
	template_id: '3fa85f64-5717-4562-b3fc-2c963f66afa6',
	reference_id: 'invoice-42',
	payload: {
		customer: { name: 'Ada Lovelace' },
		total: 42,
	},
});
```


See the full list on the [API](/plugins/pdfless/api) page.

## Query synced data

Synced entities support `tenant.pdfless.db.<entity>.search()` and `.list()`: `templates`, `workspaces`.

See [Database](/plugins/pdfless/database) for filters and operators.
