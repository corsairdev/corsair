### lookup

`brands.lookup`

Look up a brand profile (name, description, colors, socials, logo) by domain, ticker, ISIN, crypto symbol or name. 5 API credits.

**Risk:** `read`

```ts
await corsair.logodev.api.brands.lookup({ domain: 'stripe.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `domain` | `string` | No | Company domain, such as stripe.com. |
| `ticker` | `string` | No | Stock ticker, such as AAPL. |
| `isin` | `string` | No | ISIN, such as US0378331005. |
| `crypto` | `string` | No | Crypto symbol, such as BTC. |
| `name` | `string` | No | Brand name. Logo.dev uses the top search match. |
| `noSubscribe` | `boolean` | No | true skips the automatic subscription to this brand. Only matters when webhooks are on for the account. |

Send exactly one of `domain`, `ticker`, `isin`, `crypto` or `name`. On accounts with webhooks, a lookup also subscribes to the brand unless `noSubscribe` is true. A ready brand is saved to the `brands` table under its domain.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |
| `metadata` | `object` | Yes | — |

### search

`brands.search`

Search brands by name and get each match with its domain and logo URL. Billed at 1 API credit per 1,000 searches.

**Risk:** `read`

```ts
await corsair.logodev.api.brands.search({ q: 'shopify', limit: 5 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | Brand name to search for. |
| `method` | `match \| typeahead` | No | match for full names, typeahead for a prefix. Default match. |
| `limit` | `number` | No | How many brands to return, from 1 to 25. Default 10. |

Returns `data` (each match's name, domain and logo URL) and `metadata`. The logo URL comes back without its `token` query.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `metadata` | `object` | Yes | — |

**Risk:** `read`

## Webhook Endpoints

### create

`webhookEndpoints.create`

Register a URL to receive brand.updated and brand.indexed events (paid plans).

**Risk:** `write`

```ts
await corsair.logodev.api.webhookEndpoints.create({ url: 'https://hooks.example.com/logo-dev', filter_types: ['brand.updated'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | HTTPS URL that receives the events. |
| `description` | `string` | No | — |
| `filter_types` | `(brand.updated \| brand.indexed)[]` | No | Event types to send. Omit or send [] for all of them. |
| `disabled` | `boolean` | No | true creates the endpoint switched off. |

`filter_types` takes `brand.updated` and `brand.indexed`; omit it for both. `409` means the plan's endpoint limit is reached.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |
| `metadata` | `object` | Yes | — |

  id: string,
  url?: string,
