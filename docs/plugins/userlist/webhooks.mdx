The Userlist plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/userlist/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `companyCreated` (`companyCreated`)
- `companyUpdated` (`companyUpdated`)
- `formSubmitted` (`formSubmitted`)
- `messageBounced` (`messageBounced`)
- `messageClicked` (`messageClicked`)
- `messageEnqueued` (`messageEnqueued`)
- `messageOpened` (`messageOpened`)
- `messageReported` (`messageReported`)
- `relationshipCreated` (`relationshipCreated`)
- `relationshipUpdated` (`relationshipUpdated`)
- `userCreated` (`userCreated`)
- `userSubscribed` (`userSubscribed`)
- `userUnsubscribed` (`userUnsubscribed`)
- `userUpdated` (`userUpdated`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    const body = await request.json();
    const result = await processWebhook(corsair, headers, body);
    return result.response;
}
```

## Company Created

### Company Created

`companyCreated`

**Payload:** `unknown`


**`webhookHooks` example**

```ts
userlist({
    webhookHooks: {
        companyCreated: {
            before(ctx, args) {
                return { ctx, args };
            },
            after(ctx, response) {
            },
        },
    },
})
```
