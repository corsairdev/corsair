---
title: "Userlist database"
sidebarTitle: "Database"
description: "The Userlist plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Userlist. To read its data, call the [API operations](/plugins/userlist/api), which return what Userlist has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
