## Account

### usage

`account.usage`

Get amount of credits left in the api key, these reset on the 1st of each month (needs a DefiLlama Pro key)

**Risk:** `read`

```ts
await corsair.defillama.api.account.usage({});
```

**Input:** _empty object_


**Output:** `any`

## Bridges

### dayStats

`bridges.dayStats`

Get a 24hr token and address volume breakdown for a bridge (needs a DefiLlama Pro key)

**Risk:** `read`

```ts
await corsair.defillama.api.bridges.dayStats({ timestamp: 1764547200, chain: 'Ethereum' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `timestamp` | `number` | Yes | Unix timestamp. Data returned will be for the 24hr period starting at 00:00 UTC that the timestamp lands in. |
| `chain` | `string` | Yes | chain slug, you can get these from /chains. |
| `id` | `number` | No | bridge ID, you can get these from /bridges |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `date` | `number \| null` | No | Date timestamp |
| `totalTokensDeposited` | `object \| null` | No | Total tokens deposited with their details |
| `totalTokensWithdrawn` | `object \| null` | No | Total tokens withdrawn with their details |
| `totalAddressDeposited` | `object \| null` | No | Total addresses that deposited with their details |
| `totalAddressWithdrawn` | `object \| null` | No | Total addresses that withdrew with their details |
