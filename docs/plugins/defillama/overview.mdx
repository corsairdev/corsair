Use **DefiLlama** through Corsair: one client, typed API calls.

73 routes are free and need no key: TVL (`tvl.*`, except
`tvl.chainAssets`, `tvl.inflows` and `tvl.tokenProtocols`), coin prices
(`coins.*`), stablecoins, yield pools (`yields.pools`,
`yields.poolChart`), DEX, options and fees overviews, oracles, forks,
hacks and more. They go to DefiLlama's free hosts (api.llama.fi,
coins.llama.fi, stablecoins.llama.fi, yields.llama.fi).

- **Pro** (defillama.com/subscription): connect with the Pro API key and
every call goes to pro-api.llama.fi with higher limits. The other 63
routes need it: yields earn, borrow, loops, LST and funding rates,
unlocks, bridges, equities, ETFs, RWA, pre-IPO, digital-asset
treasuries, raises, categories, entities, derivatives, token liquidity,
inflows and `account.usage` (credits left). Without a key they raise a
"needs a DefiLlama Pro API key" error before anything is sent; each
description says which routes are Pro-only.
- **Coins** are `chain:address` or `coingecko:<id>`, comma-separated
(`ethereum:0xdac17f958d2ee523a2206206994597c13d831ec7,coingecko:bitcoin`).
- **Protocols** are DefiLlama slugs (`aave`, `uniswap`); chains are names
(`Ethereum`, `Arbitrum`); timestamps are Unix seconds.
- Every operation only reads (`read`).

**What you get:**

- 136 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/defillama better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/defillama better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/defillama better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/defillama better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { defillama } from '@corsair-dev/defillama';

export const corsair = createCorsair({
	plugins: [
		defillama(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the DefiLlama API key before the first call: `pnpm corsair setup --plugin=defillama --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
defillama()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'defillama',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>
