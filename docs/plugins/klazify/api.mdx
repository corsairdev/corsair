## Categories

### iab

`categories.iab`

Classify a URL into IAB v1 and v3 taxonomy categories

**Risk:** `read`

```ts
await corsair.klazify.api.categories.iab({ url: 'https://cbsnews.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | No | The URL to classify, e.g. `https://apple.com`. Give this or `email`. |
| `email` | `string` | No | An email address to classify by its domain. Give this or `url`. |
| `refresh` | `boolean` | No | Force a live crawl instead of returning the cached result. Slower, and the docs offer it on every paid plan including Starter. Omit it to reuse the cached classification. |

Each category carries dynamic `IAB*` keys beside `name`, mapping IAB v1 and v3 ids to their labels.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | False when the classification failed. |
| `domain` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="domain full type">

```ts
{
  categories?: {
    name: string,
    confidence?: number | null
  }[] | null,
  domain_url?: string | null,
  updated_at?: string | null
}
```
</Accordion>
</AccordionGroup>

### listV1

`categories.listV1`

List the 620 categories in the Klazify v1 taxonomy

**Risk:** `read`

```ts
await corsair.klazify.api.categories.listV1({});
```

**Input:** _empty object_

The 620-category v1 taxonomy. Counts as one API call.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | False when the classification failed. |
| `version` | `string` | Yes | `v1` or `v2`, matching the taxonomy. |
| `count` | `number` | Yes | 620 for v1, 1091 for v2. |
| `categories` | `string[]` | Yes | Full category paths, each starting with `/`. |

## Discovery

### search

`discovery.search`

Search Klazify's domain database by rank, category, country, technology and company size

**Risk:** `read`

```ts
await corsair.klazify.api.discovery.search({ filters: { category: 'Shopping', country: 'US', tech: 'shopify' }, page: 1 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `top_n` | `number` | No | Only domains with a global rank at or below this are searched. Unranked domains are excluded when it is set. |
| `filters` | `object` | No | — |
| `q` | `string` | No | Free-text search across domain, company and category. |
| `sort` | `global_rank \| domain \| company_name \| monthly_visits_latest` | No | — |
| `sort_dir` | `asc \| desc` | No | — |
| `page` | `number` | No | Page number. Each page holds 100 results. |

Searches the whole Klazify database. `page` runs 1 to 1000 with 100 results each. A `tld` filter can set `total_is_lower_bound` when its candidate scan runs out.

<AccordionGroup>
<Accordion title="filters full type">

```ts
{
  category?: string,
  country?: string,
  tech?: string,
  employees?: 1-10 | 11-50 | 51-250 | 251-1K | 1K-5K | 5K-10K | 10K-50K | 50K-100K | 100K+,
  has_company?: boolean,
  tld?: string
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `total` | `number` | Yes | — |
| `total_pages` | `number` | Yes | — |
| `total_is_lower_bound` | `boolean` | No | — |
| `results` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="results full type">

```ts
{
  domain?: string | null,
  company_name?: string | null,
  company_country?: string | null,
  company_employees?: string | null,
  company_revenue?: string | null,
  primary_category?: string | null,
  primary_iab?: string | null,
  global_rank?: number | null,
  monthly_visits_latest?: number | null
}[]
```
</Accordion>
</AccordionGroup>
