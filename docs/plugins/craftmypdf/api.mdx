## Editor

### createSession

`editor.createSession`

Create a signed URL that lets its bearer edit a template in the embedded designer; the URL is a credential

**Risk:** `write`

```ts
await corsair.craftmypdf.api.editor.createSession({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `template_id` | `string` | Yes | Template the session edits. |
| `expiration` | `number` | Yes | Minutes until the session expires, for example 1440 for a day. |
| `canSave` | `boolean` | No | Allow saving changes. |
| `canCreatePDF` | `boolean` | No | Allow generating a PDF. |
| `canViewSettings` | `boolean` | No | Show the settings panel. |
| `canPreview` | `boolean` | No | Allow the preview. |
| `canEditJSON` | `boolean` | No | Allow editing the JSON data. |
| `canShowHeader` | `boolean` | No | Show the CraftMyPDF header. |
| `canShowLayers` | `boolean` | No | Show the layers panel. |
| `canShowPropertyPanel` | `boolean` | No | Show the property panel. |
| `canShowHelp` | `boolean` | No | Show the help tab. |
| `canShowData` | `boolean` | No | Show the data tab. |
| `canShowExpressionDoc` | `boolean` | No | Show the expression documentation tab. |
| `canShowPropertyBinding` | `boolean` | No | Show property binding for elements. |
| `canShowBackURL` | `boolean` | No | Show the back button. |
| `jsonMode` | `1 \| 2` | No | 1 makes the JSON editor editable, 2 makes it read-only. |
| `backURL` | `string` | No | Where the back button goes. |

The returned URL is a signed token that lets its bearer edit the template, so treat it as a credential and deactivate it when done.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string \| null` | No | — |
| `url` | `string \| null` | No | — |
| `expire_after_unix_timestamp` | `number \| string \| null` | No | — |
| `expire_after` | `string \| number \| null` | No | — |
| `token_uuid` | `string \| null` | No | — |

### create

`pdf.create`

Generate a PDF from a template and JSON data, synchronously; consumes one credit per PDF

**Risk:** `write`

```ts
await corsair.craftmypdf.api.pdf.create({
  template_id: '05f77b2b18ad809a',
  data: { invoice_number: 'INV38379', total_amount: 82542.56 },
  expiration: 60,
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `template_id` | `string` | Yes | Template to generate from. Several comma-separated IDs generate one PDF per template. |
| `data` | `string \| Record<string, JsonValue>` | No | Template JSON data, either an object or a stringified JSON string. |
| `load_data_from` | `string` | No | URL to fetch the template JSON from. CraftMyPDF overwrites data with this content, so data can be omitted. |
| `version` | `string \| number` | No | Template version. Omit to use the latest version of the template. |
| `expiration` | `number` | No | Minutes the generated file stays on the CDN. 1 to 10080; CraftMyPDF defaults to 5. |
| `output_file` | `string` | No | Name of the generated file, for example output.pdf. |
| `image_resample_res` | `number` | No | Downsamples images in the PDF to this resolution in DPI to shrink the file. Suggested values are 1200, 600, 300, 150 and 72. |
| `cloud_storage` | `number` | No | 1 to keep the generated file on the CraftMyPDF CDN, 0 to skip it (for example when S3 post actions are configured). Defaults to 1. |
| `postaction_s3_filekey` | `string` | No | File name for the S3 post action, without an extension. It must be unique, and / works as a folder separator. |
| `postaction_s3_bucket` | `string` | No | Overrides the configured AWS bucket for the S3 post action. |
| `password_protected` | `boolean` | No | Encrypt the generated PDF with password. |
| `password` | `string` | No | Password for the generated PDF. |
| `paging` | `continuous \| reset` | No | Page numbering when several templates are combined. continuous keeps counting across documents; reset restarts at 1 for each. |

A synchronous call can take up to 100 seconds, so the plugin waits 120 seconds before timing out. Each call spends one credit.

| `anchors` | `object[] \| null` | No | — |
| `total_pages` | `number \| null` | No | — |
| `file_size` | `number \| null` | No | — |
| `template_id` | `string \| null` | No | — |

### createAsync

`pdf.createAsync`

Queue a PDF generation and return at once with a transaction reference, delivering the file to a webhook URL; consumes one credit per PDF

**Risk:** `write`

```ts
await corsair.craftmypdf.api.pdf.createAsync({
  template_id: '05f77b2b18ad809a',
  data: { invoice_number: 'INV38379' },
  webhook_url: 'https://example.com/pdf-handler',
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `template_id` | `string` | Yes | Template to generate from. |
| `data` | `string \| Record<string, JsonValue>` | No | Template JSON data, either an object or a stringified JSON string. |
| `version` | `string \| number` | No | Template version. Omit to use the latest version of the template. |
| `expiration` | `number` | No | Minutes the generated file stays on the CDN. 1 to 10080; CraftMyPDF defaults to 5. |
| `webhook_url` | `string` | No | CraftMyPDF calls this URL with a GET once the PDF is ready, adding file, transaction_ref, status, message and details as query parameters. Without it the result is only recorded in transactions.list. |
| `image_resample_res` | `number` | No | Downsamples images in the PDF to this resolution in DPI to shrink the file. Suggested values are 1200, 600, 300, 150 and 72. |
| `cloud_storage` | `number` | No | 1 to keep the generated file on the CraftMyPDF CDN, 0 to skip it (for example when S3 post actions are configured). Defaults to 1. |
| `postaction_s3_filekey` | `string` | No | File name for the S3 post action, without an extension. It must be unique, and / works as a folder separator. |
| `postaction_s3_bucket` | `string` | No | Overrides the configured AWS bucket for the S3 post action. |

CraftMyPDF calls `webhook_url` with a GET once the file is ready, appending file, transaction_ref, status, message and details as query parameters. Without that URL the result only appears in `transactions.list`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string \| null` | No | — |
| `transaction_ref` | `string \| null` | No | — |
| `is_async` | `boolean \| null` | No | — |
