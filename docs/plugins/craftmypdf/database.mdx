---
title: "CraftMyPDF database"
sidebarTitle: "Database"
description: "The CraftMyPDF plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for CraftMyPDF. To read its data, call the [API operations](/plugins/craftmypdf/api), which return what CraftMyPDF has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
