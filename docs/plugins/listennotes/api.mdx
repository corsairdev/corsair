## Playlists

### addItem

`playlists.addItem`

Add an episode or podcast to a playlist

**Risk:** `write`

```ts
await corsair.listennotes.api.playlists.addItem({ id: 'm1pe7z60bsw', episode_id: '0123456789abcdef0123456789abcdef' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | 11-character playlist ID |
| `episode_id` | `string` | No | Episode ID (mutually exclusive with podcast_id) |
| `podcast_id` | `string` | No | Podcast ID (mutually exclusive with episode_id) |
| `notes` | `string` | No | — |

Supply exactly one 32-character episode ID or podcast ID. Existing active items are reused; the operation can restore deleted items.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | — |
| `type` | `episode \| custom_audio \| podcast` | Yes | — |
| `notes` | `string` | No | — |
| `added_at_ms` | `number` | No | — |
| `data` | `Record<string, any>` | No | — |
