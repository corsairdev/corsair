## Curated

### get

`curated.get`

Fetch a curated list of podcasts by ID

**Risk:** `read`

```ts
await corsair.listennotes.api.curated.get({ id: 'e4a6865261f945aeb78f2ebcb3fd46fb' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Curated list ID |



**Output**

## Search

### search

`search.search`

Full-text search for podcast episodes, channels, or curated lists

**Risk:** `read`

```ts
await corsair.listennotes.api.search.search({ q: 'startup' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | Search term |
| `sort_by_date` | `number` | No | 0 for relevance, 1 for date |
| `type` | `episode \| podcast \| curated` | No | Type of search results |
| `offset` | `number` | No | Pagination offset |
| `len_min` | `number` | No | Minimum audio length in minutes |
| `len_max` | `number` | No | Maximum audio length in minutes |
| `episode_count_min` | `number` | No | Minimum number of episodes |
| `episode_count_max` | `number` | No | Maximum number of episodes |
| `update_freq_min` | `number` | No | Minimum update frequency in hours |
| `update_freq_max` | `number` | No | Maximum update frequency in hours |
| `genre_ids` | `string` | No | Comma-delimited genre IDs |
| `published_before` | `number` | No | Published before epoch ms |
| `published_after` | `number` | No | Published after epoch ms |
| `only_in` | `string` | No | Search only in title, description, author, or audio |
| `language` | `string` | No | Filter by language |
| `region` | `string` | No | Filter by region |
| `ocid` | `string` | No | Comma-delimited podcast IDs to restrict search to |
| `ncid` | `string` | No | Comma-delimited podcast IDs to exclude from search |
| `safe_mode` | `number` | No | 1 to restrict explicit content, 0 otherwise |
| `unique_podcasts` | `number` | No | 1 to return unique podcasts |
| `page_size` | `number` | No | Number of results per page |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `count` | `number` | Yes | — |
| `next_offset` | `number` | No | — |
| `total` | `number` | Yes | — |
| `took` | `number` | No | — |
| `results` | `Record<string, any>[]` | Yes | — |
