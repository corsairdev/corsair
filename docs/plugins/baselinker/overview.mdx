Use **BaseLinker** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 106 typed API operations
- 16 synced entities (`categories`, `connectIntegrations`, `couriers`, `externalStorages`, `inventories`, `inventoryExtraFields`, and 10 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/baselinker better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/baselinker better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/baselinker better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/baselinker better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { baselinker } from '@corsair-dev/baselinker';

export const corsair = createCorsair({
	plugins: [
		baselinker(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the BaseLinker API key before the first call: `pnpm corsair setup --plugin=baselinker --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
baselinker()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'baselinker',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`connect.getConnectIntegrationContractors`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.baselinker.api.connect.getConnectIntegrationContractors({});
```


**`couriers.createPackageManual`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.baselinker.api.couriers.createPackageManual({});
```


See the full list on the [API](/plugins/baselinker/api) page.

## Query synced data

Synced entities support `tenant.baselinker.db.<entity>.search()` and `.list()`: `categories`, `connectIntegrations`, `couriers`, `externalStorages`, `inventories`, `inventoryExtraFields`, `manufacturers`, `orderStatuses`, `payers`, `priceGroups`, `returnProductStatuses`, `returnReasons`, `returnStatuses`, `suppliers`, `tags`, `warehouses`.

See [Database](/plugins/baselinker/database) for filters and operators.
