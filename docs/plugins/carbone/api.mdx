## Render

### get

`render.get`

Get download URL for a rendered document

**Risk:** `read`

```ts
await corsair.carbone.api.render.get({
  renderId: 'rnd_123',
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `renderId` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `renderId` | `string` | Yes | — |
| `downloadUrl` | `string` | Yes | — |
