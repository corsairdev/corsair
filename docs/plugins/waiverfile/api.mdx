## Event Categories

### create

`eventCategories.create`

Create an event category, active or not

**Risk:** `write`

```ts
await corsair.waiverfile.api.eventCategories.create({ name: 'Open jump', active: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `active` | `boolean` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ID` | `string \| null` | No | — |
| `SiteID` | `string \| null` | No | — |
| `Name` | `string \| null` | No | — |
| `Status` | `number \| null` | No | 0 = active, 1 = disabled, 2 = deleted. |
| `OrderNum` | `number \| null` | No | — |

## Webhooks

### subscribe

`webhooks.subscribe`

Subscribe a URL to one WaiverFile trigger, such as newwaiver or newevent, so it is posted to on each occurrence

**Risk:** `write`

```ts
await corsair.waiverfile.api.webhooks.subscribe({ trigger: 'newwaiver', targetUrl: 'https://acme.example/hooks/waiverfile' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `trigger` | `newwaiver \| newevent \| newcheckin \| newqrscan \| newbookingcheckin \| bookingcheckinundone \| bookingcheckedin \| newmembercheckin \| membercheckinundone \| editwaiver \| editevent \| editcheckin` | Yes | The trigger whose events will be posted to `targetUrl`. |
| `targetUrl` | `string` | Yes | The URL WaiverFile will POST to. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `Success` | `boolean` | Yes | — |
| `Message` | `string \| null` | No | — |
