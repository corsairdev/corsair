## Projects

### ioSchema

`projects.ioSchema`

Inspect a project version input and output schema.

**Risk:** `read`

```ts
await corsair.stackai.api.projects.ioSchema({ project_id: 'example-project', version: 'latest' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project_id` | `string` | Yes | — |
| `version` | `latest \| draft \| number` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `response_code` | `string \| null` | No | — |
| `meta` | `Record<string, any>` | No | — |
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  input_kind: start_node | legacy_input_nodes,
  inputs: {
    id: string,
    name: string
  }[],
  outputs: {
    id: string,
    name: string
  }[]
}
```
</Accordion>
</AccordionGroup>
