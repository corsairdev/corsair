## Account

### credits

`account.credits`

Get the workspace data credit and action balances

**Risk:** `read`

```ts
await corsair.clay.api.account.credits({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `balance` | `number` | Yes | — |
| `action_execution_balance` | `number` | No | — |



---

### me

```ts
await corsair.clay.api.account.me({});
```

**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `user` | `object` | Yes | — |
| `workspace` | `object` | Yes | — |

</Accordion>

```ts
{

```
</Accordion>

## Routines

### getResults

`routines.getResults`

Get progress, or the paginated per-item results, of a routine run

**Risk:** `read`

```ts
await corsair.clay.api.routines.getResults({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `routine_run_id` | `string` | Yes | — |
| `cursor` | `string` | No | — |
| `limit` | `number` | No | — |



**Output:** `object`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  routine_run_id: string,
  status: in_progress,
  total: number,
  finished: number
} | {
  routine_run_id: string,
  status: string,
  total: number,
  finished: number,
  data: {
    id: string,
    status: complete | failed,
    result?: {
    },
    error?: {
      message: string
    }
  }[],
  cursor?: string
}
```
</Accordion>
</AccordionGroup>

### run

`routines.run`

Run a Clay-managed or custom function routine on 1-100 items; spends credits and returns a routine_run_id

**Risk:** `write`

```ts
await corsair.clay.api.routines.run({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `routine_id` | `string` | Yes | Routine id, for example function:t_abc123 |
| `items` | `object[]` | Yes | — |
| `webhook_id` | `string` | No | — |

<AccordionGroup>
<Accordion title="items full type">

```ts
{
  id: string,
  inputs: {
  }
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `routine_run_id` | `string` | Yes | — |
| `status` | `in_progress` | Yes | — |

## Search

### create

`search.create`

Create a people or company search over Clay's GTM database from a Clay search query

**Risk:** `write`

```ts
await corsair.clay.api.search.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | Clay advanced search query; see search.reference |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `search_id` | `string` | Yes | — |
| `source_type` | `people \| companies` | Yes | — |



---

### reference

`search.reference`

Get the Clay search query language reference used by search.create

**Risk:** `read`

```ts
await corsair.clay.api.search.reference({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `reference` | `string` | Yes | — |
