Use **Wix** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 143 typed API operations
- 19 synced entities (`bookingCategories`, `brands`, `campaigns`, `contacts`, `coupons`, `currencies`, and 13 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/wix better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/wix better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/wix better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/wix better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { wix } from '@corsair-dev/wix';

export const corsair = createCorsair({
	plugins: [
		wix(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="OAuth 2.0 (Recommended)">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Wix OAuth app.

```ts
wix()
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
<Tab title="API Key">

Store the Wix API key before the first call: `pnpm corsair setup --plugin=wix --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
wix({
	authType: 'api_key',
})
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'wix',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List contacts**

```ts
const tenant = corsair.withTenant('acme');
await tenant.wix.api.contacts.list({});
```


**Add labels to a contact**

```ts
const tenant = corsair.withTenant('acme');
await tenant.wix.api.contacts.addLabels({
	contactId: '11111111-2222-3333-4444-555555555555',
	labelKeys: ['custom.vip'],
});
```


See the full list on the [API](/plugins/wix/api) page.

## Query synced data

This table exists, but Wix calls don't fill it yet. This returns only rows you have written yourself.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.wix.db.contacts.search({
	data: {},
	limit: 50,
});
```

Synced entities: `bookingCategories`, `brands`, `campaigns`, `contacts`, `coupons`, `currencies`, `customFields`, `extendedBookings`, `forms`, `formSubmissions`, `groupRequests`, `inventoryItems`, `locations`, `manualTaxMappings`, `moderationRules`, `orders`, `products`, `siteFolders`, `taxGroups`. See [Database](/plugins/wix/database) for filters and operators.
