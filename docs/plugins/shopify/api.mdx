## Collections

### addProducts

`collections.addProducts`

Add products to a collection; the whole call fails if any is already present

**Risk:** `write`

```ts
await corsair.shopify.api.collections.addProducts({ id: 'gid://shopify/Collection/1', productIds: ['gid://shopify/Product/108828309'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Collection GID. |
| `productIds` | `string[]` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `collection` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="collection full type">

```ts
{
  id: string,
  title: string,
  handle: string,
  descriptionHtml?: string | null,
  updatedAt: string,
```

## Inventory

### adjust

`inventory.adjust`

Adjust available stock by a signed delta at one location, with a reason

**Risk:** `write`

```ts
await corsair.shopify.api.inventory.adjust({ inventoryItemId: 'gid://shopify/InventoryItem/1', locationId: 'gid://shopify/Location/1', delta: 5, reason: 'correction' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `inventoryItemId` | `string` | Yes | — |
| `locationId` | `string` | Yes | — |
| `delta` | `number` | Yes | Signed change: positive adds stock, negative removes it. |
| `reason` | `string` | Yes | Inventory change reason, e.g. "correction" or "received". |

Adjusts the available quantity by a signed delta at one location. A positive delta adds stock and a negative one removes it.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `inventoryAdjustmentGroup` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="inventoryAdjustmentGroup full type">

```ts
{
  createdAt?: string | null,
  reason?: string | null,
  changes?: {
    name: string,
    delta: number
  }[] | null
} | null
```
</Accordion>
</AccordionGroup>

## Orders

### cancel

`orders.cancel`

Cancel an order, optionally restocking and notifying the customer; does not refund

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.shopify.api.orders.cancel({ id: 'gid://shopify/Order/1', reason: 'CUSTOMER', restock: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `reason` | `CUSTOMER \| DECLINED \| FRAUD \| INVENTORY \| OTHER \| STAFF` | No | — |
| `restock` | `boolean` | No | Restock the order items. |
| `notifyCustomer` | `boolean` | No | Email the customer about the cancellation. |

Cancels the order without refunding. Cancelling and refunding are separate decisions, so the deprecated refund flag is not used and no money moves on a cancel.
