## Account

### getCompressionCount

`account.getCompressionCount`

Get the number of compressions made this calendar month

**Risk:** `read`

```ts
await corsair.tinypng.api.account.getCompressionCount({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `compressionCount` | `number` | Yes | — |

## Images

### compressAndStoreInAzure

`images.compressAndStoreInAzure`

Compress an image and upload the result to Azure Blob Storage through a SAS URL

**Risk:** `write`

```ts
await corsair.tinypng.api.images.compressAndStoreInAzure({
	source: { url: 'https://tinypng.com/images/panda-happy.png' },
	blobUrl: 'https://myaccount.blob.core.windows.net/images/panda.png?sv=2022-11-02&sig=REDACTED',
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `source` | `object` | Yes | — |
| `blobUrl` | `string` | Yes | Full blob URL with a SAS token granting create/write, e.g. https://acct.blob.core.windows.net/container/name.png?sv=... |
| `cacheControl` | `string` | No | — |
| `resize` | `object` | No | — |
| `convert` | `object` | No | Several types return the smallest result |
| `transform` | `object` | No | — |
| `preserve` | `copyright \| creation \| location[]` | No | — |

### transform

`images.transform`

Resize, convert, fill the background of, or preserve metadata on a compressed image, optionally storing it on S3 or GCS

**Risk:** `write`

```ts
await corsair.tinypng.api.images.transform({
	imageId: '2xnsp7jn34e5',
	resize: { method: 'fit', width: 150, height: 100 },
	convert: { type: 'image/webp' },
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `imageId` | `string` | Yes | — |
| `resize` | `object` | No | — |
| `convert` | `object` | No | Several types return the smallest result |
| `transform` | `object` | No | — |
| `preserve` | `copyright \| creation \| location[]` | No | — |
| `store` | `object` | No | Upload the result to S3 or GCS instead of returning the bytes |
