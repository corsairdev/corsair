---
title: "Gender API database"
sidebarTitle: "Database"
description: "The Gender API plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Gender API. To read its data, call the [API operations](/plugins/genderapi/api), which return what Gender API has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
