## Market

### convertCrypto

`market.convertCrypto`

Convert an amount between two cryptocurrencies

**Risk:** `read`

```ts
await corsair.finage.api.market.convertCrypto({ from: 'BTC', to: 'ETH', amount: 1 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `from` | `string` | Yes | — |
| `to` | `string` | Yes | — |
| `amount` | `number` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `from` | `string` | Yes | — |
| `to` | `string` | Yes | — |
| `amount` | `number` | Yes | — |
| `value` | `number` | Yes | — |
| `timestamp` | `number` | Yes | — |
