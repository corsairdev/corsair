Use **BenchmarkEmail** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 298 typed API operations
- 3 synced entities (`campaigns`, `contactLists`, `contacts`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/benchmarkemail
```
```bash yarn
yarn add corsair @corsair-dev/benchmarkemail
```
```bash pnpm
pnpm install corsair @corsair-dev/benchmarkemail
```
```bash bun
bun add corsair @corsair-dev/benchmarkemail
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { benchmarkemail } from '@corsair-dev/benchmarkemail';

export const corsair = createCorsair({
	plugins: [
		benchmarkemail(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_DEV_API_KEY!,
		signingSecret: process.env.CORSAIR_DEV_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
benchmarkemail()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'benchmarkemail',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`account.checkIfResponsive`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.benchmarkemail.api.account.checkIfResponsive({});
```


**`account.addRemoveInboxTestsFromSubAccount`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.benchmarkemail.api.account.addRemoveInboxTestsFromSubAccount({});
```


See the full list on the [API](/plugins/benchmarkemail/api) page.

## Query synced data

Synced entities support `tenant.benchmarkemail.db.<entity>.search()` and `.list()`: `campaigns`, `contactLists`, `contacts`.

See [Database](/plugins/benchmarkemail/database) for filters and operators.
