## Users

### current

`users.current`

Get the current WakaTime user

**Risk:** `read`

```ts
await corsair.wakatime.api.users.current({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  id: string,
  username?: string,
  display_name?: string,
  email?: string
}
```
</Accordion>
</AccordionGroup>
