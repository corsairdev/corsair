## Balance

### get

`balance.get`

Get the API key balance (free, not billed)

**Risk:** `read`

```ts
await corsair.twittrapi.api.balance.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `user_id` | `number` | No | — |
| `balance` | `number` | No | — |
| `price_per_call` | `number` | No | — |
| `is_active` | `boolean` | No | — |
