---
title: "DeployHQ database"
sidebarTitle: "Database"
description: "The DeployHQ plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for DeployHQ. To read its data, call the [API operations](/plugins/deployhq/api), which return what DeployHQ has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
