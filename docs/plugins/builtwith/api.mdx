## Create Domain List File

### createDomainListFile

`createDomainListFile`

Build a deduplicated TXT or ZIP domain list file locally for bulk lookups

**Risk:** `read`

```ts
await corsair.builtwith.api.createDomainListFile({
	domains: ['builtwith.com', 'shopify.com'],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `domains` | `string[]` | Yes | — |
| `fileName` | `string` | No | — |
| `format` | `txt \| zip` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string` | Yes | — |
| `format` | `txt \| zip` | Yes | — |
| `content` | `string` | Yes | — |
| `encoding` | `utf8 \| base64` | Yes | — |
| `domainCount` | `number` | Yes | — |
| `domains` | `string[]` | Yes | — |
