Use **BuiltWith** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 11 typed API operations
- 11 synced entities (`companyFinancials`, `domainCoverage`, `domains`, `domainTechnologies`, `listSites`, `mcpServers`, and 5 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/builtwith better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/builtwith better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/builtwith better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/builtwith better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { builtwith } from '@corsair-dev/builtwith';

export const corsair = createCorsair({
	plugins: [
		builtwith(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the BuiltWith API key before the first call: `pnpm corsair setup --plugin=builtwith --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
builtwith()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'builtwith',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Look up a domain's technology stack**

```ts
const tenant = corsair.withTenant('acme');
await tenant.builtwith.api.domain.lookup({ lookup: 'builtwith.com' });
```


**`createDomainListFile`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.builtwith.api.createDomainListFile({});
```


See the full list on the [API](/plugins/builtwith/api) page.

## Query synced data

Synced entities support `tenant.builtwith.db.<entity>.search()` and `.list()`: `companyFinancials`, `domainCoverage`, `domains`, `domainTechnologies`, `listSites`, `mcpServers`, `products`, `recommendations`, `redirects`, `socialLinks`, `technologies`.

See [Database](/plugins/builtwith/database) for filters and operators.
