The BuiltWith plugin syncs data locally. Use `corsair.builtwith.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Company Financials

Path: `builtwith.db.companyFinancials.search`

```ts
const rows = await corsair.builtwith.db.companyFinancials.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `domain` | `string` | equals, contains, startsWith, endsWith, in |
| `companyName` | `string` | equals, contains, startsWith, endsWith, in |
| `employees` | `number` | equals, gt, gte, lt, lte, in |
| `followers` | `number` | equals, gt, gte, lt, lte, in |
| `products` | `number` | equals, gt, gte, lt, lte, in |
| `spend` | `number` | equals, gt, gte, lt, lte, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
