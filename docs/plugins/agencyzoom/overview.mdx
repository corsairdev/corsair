Use **AgencyZoom** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 99 typed API operations
- 3 synced entities (`customers`, `leads`, `tasks`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/agencyzoom
```
```bash yarn
yarn add corsair @corsair-dev/agencyzoom
```
```bash pnpm
pnpm install corsair @corsair-dev/agencyzoom
```
```bash bun
bun add corsair @corsair-dev/agencyzoom
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { agencyzoom } from '@corsair-dev/agencyzoom';

export const corsair = createCorsair({
	plugins: [
		agencyzoom(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
agencyzoom()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'agencyzoom',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`customers.getAmsPoliciesForACustomer`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.agencyzoom.api.customers.getAmsPoliciesForACustomer({});
```


**`auth.logTheUserIn`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.agencyzoom.api.auth.logTheUserIn({});
```


See the full list on the [API](/plugins/agencyzoom/api) page.

## Query synced data

Synced entities support `tenant.agencyzoom.db.<entity>.search()` and `.list()`: `customers`, `leads`, `tasks`.

See [Database](/plugins/agencyzoom/database) for filters and operators.
