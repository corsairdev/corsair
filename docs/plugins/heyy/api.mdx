## Api Webhooks

### create

`apiWebhooks.create`

Register an HTTPS endpoint for message events on the channels named in each event; Heyy then POSTs every matching message, with its content and sender, to that URL

**Risk:** `write`

```ts
await corsair.heyy.api.apiWebhooks.create({ url: 'https://example.com/heyy/events', events: [{ type: 'message.received', scopes: [{ type: 'channel', ids: ['b1a2c3d4-0000-4000-8000-000000000000'] }] }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | HTTPS URL that receives the webhook POSTs. |
| `events` | `object[]` | Yes | The events to deliver to this URL. |

The URL must be https. Events are `message.received`, `message.sent`, `message.updated`, `whatsapp_message_received` or `whatsapp_message_status`, each scoped to at least one channel id from `channels.search`. Heyy then POSTs every matching message, with its content and sender, to that URL.

<AccordionGroup>
<Accordion title="events full type">

```ts

  type: whatsapp_message_received | whatsapp_message_status | message.received | message.sent | message.updated,
  scopes: {
    type: channel,
    ids: string[]
  }[]
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `webhook` | `object` | Yes | — |
| `success` | `true` | Yes | — |

<AccordionGroup>
<Accordion title="webhook full type">

```ts

  createdAt: string,

  url: string,
  status: string,
  events?: {
    type: string,

      type: string,

    }[] | null
  }[] | null
}
```
</Accordion>

`contacts.search`

Search contacts with a structured filter, free-text search, sorting and paging; returns the matched contacts with their labels and attribute values

**Risk:** `read`

```ts
await corsair.heyy.api.contacts.search({ query: "contains(firstName, 'Jordan')", pagination: { page: 0, limit: 25 } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `sortBy` | `string` | No | Sort expression, such as "desc(createdAt)" or "asc(name)", with an optional null placement like "desc(updatedAt, 'nulls last')". Chain keys with sort(...). |
| `search` | `string` | No | Free-text search over the resource's searchable fields. `query` is the field for structured filters; the two can be combined. |
| `pagination` | `object` | No | Paging. Defaults to page 0, limit 10. |
| `query` | `string` | No | Structured filter, such as "equals(email, 'jordan@acme.com')". Filterable fields: id, createdAt, updatedAt, firstName, lastName, isSubscribed, labels, notes, groups, phoneNumber, email; custom attributes through getBy('attributes', 'name', 'plan'). Combine with and(), or(), not(); see the query syntax reference. Can be combined with `search`. Omit for no filter. |
