Use **DocuPost** through Corsair: one client, typed API calls.

**What you get:**

- 3 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/docupost better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/docupost better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/docupost better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/docupost better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { docupost } from '@corsair-dev/docupost';

export const corsair = createCorsair({
	plugins: [
		docupost(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the DocuPost API key before the first call: `pnpm corsair setup --plugin=docupost --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
docupost()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'docupost',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Check the account balance**

```ts
const tenant = corsair.withTenant('acme');
await tenant.docupost.api.account.balance({});
```


**Send a postcard**

```ts
const tenant = corsair.withTenant('acme');
await tenant.docupost.api.send.postcard({
	to_name: 'Ada Lovelace',
	to_address: '123 Main St',
	to_city: 'Austin',
	to_state: 'TX',
	to_zip: '78701',
	from_name: 'Corsair',
	from_address: '456 Market St',
	from_city: 'San Francisco',
	from_state: 'CA',
	from_zip: '94105',
	front_image_url: 'https://example.com/front.png',
	back_image_url: 'https://example.com/back.png',
});
```


See the full list on the [API](/plugins/docupost/api) page.
