## Account

### balance

`account.balance`

Fetch the remaining DocuPost account balance

**Risk:** `read`

```ts
await corsair.docupost.api.account.balance({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `balance` | `any` | No | — |

### letter

Send a physical letter through DocuPost

**Risk:** `write`

```ts

```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
