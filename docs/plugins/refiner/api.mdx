await corsair.refiner.api.reporting.get({ type: 'nps', form_uuids: ['3894dc20-8fe9-11ea-892e-d13af52e06ae'], date_range_start: '2024-12-12', date_range_end: '2025-04-18' });

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `nps \| csat \| ratings \| distribution \| count` | Yes | Which report to compute. |

| `form_uuids` | `string[]` | No | — |

| `contact_data` | `Record<string, string \| number \| boolean>` | No | Contact traits to match, keyed by trait slug. |
| `account_data` | `Record<string, string \| number \| boolean>` | No | Account traits to match, keyed by trait slug. |

| Name | Type | Required | Description |
|------|------|----------|-------------|

### store

`responses.store`

Store a survey response for a user on an existing survey, to import history or feed a custom survey UI. Answers go in as top-level keys named by question identifier, such as &#123; id: 'user-1', form_uuid, nps: 9, feedback: 'Fast setup' &#125;

**Risk:** `write`

```ts
await corsair.refiner.api.responses.store({ id: 'user-1', form_uuid: '3894dc20-8fe9-11ea-892e-d13af52e06ae', nps_question: 9, date: '2024-01-15T10:30:00Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | No | Your user ID. |
| `email` | `string` | No | Instead of an id. |
| `uuid` | `string` | No | A Refiner contact UUID. |
| `form_uuid` | `string` | Yes | The survey the response belongs to. It may be empty and unpublished, as long as it exists. |
| `date` | `string` | No | ISO 8601, when the response was recorded. Defaults to now, so set it on a historical import. |
| `prevent_duplicates` | `boolean` | No | Refiner detects duplicates by default; false turns that off. |
| `tags` | `string[]` | No | Up to 20 tags for the response. |
| `account` | `Record<string, string \| number \| boolean>` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `message` | `string \| null` | No | — |
| `uuid` | `string \| null` | No | The new response UUID. |

## Users

### identify

`users.identify`

Identify a user by ID or email, creating the contact on first sight. Every other top-level key is saved as a trait, such as &#123; id: 'user-1', plan: 'pro', signed_up_at: '2024-01-15' &#125;

**Risk:** `write`

```ts
await corsair.refiner.api.users.identify({ id: 'user-1', email: 'jane@example.com', some_attribute: 'Manager', created_at: '2020-08-20T14:48:00.000Z', account: { id: 'acme-1', name: 'Acme Inc.' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | No | Your user ID. One of id, email is required. |
| `email` | `string` | No | Instead of an id. |
| `account` | `Record<string, string \| number \| boolean>` | No | A nested account object, with at least an id, to group users under one account. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `message` | `string \| null` | No | — |
| `contact_uuid` | `string \| null` | No | — |
