## Access

### get

`access.get`

**Risk:** `read`

| Name | Type | Required | Description |

## Students

### create

`students.create`

Create a course or gallery student with an access record

**Risk:** `write`

```ts
await corsair.spotlightr.api.students.create({ email: 'jane@acme.com', password: 'hunter2hunter2', course_id: 42, never: true, unlocks: 0, time: 0, expires: '0000-00-00' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `email` | `string` | Yes | Student's email address |
| `password` | `string` | Yes | Student's password |
| `course_id` | `number` | Yes | Course or gallery ID |
| `never` | `boolean` | Yes | true never expires; `expires` is then ignored |
| `unlocks` | `number` | Yes | 0 for unlimited |
| `time` | `number` | Yes | 0 for unlimited |
| `expires` | `string \| 0000-00-00` | Yes | YYYY-MM-DD, or the literal "0000-00-00" the reference uses when `never` is true |

`expires` takes a date or the literal "0000-00-00" when `never` is true.



**Output:** `string \| number \| object \| object[] \| null \| undefined`

<AccordionGroup>
<Accordion title="Output full type">

```ts
string | number | {
} | {
}[] | null | undefined
```
</Accordion>

## Videos

### create

`videos.create`

Create a video from a hosted link or an uploaded file, optionally copying player settings from another video

**Risk:** `write`

```ts
await corsair.spotlightr.api.videos.create({ name: 'Product tour', url: 'https://youtu.be/abc123' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Name of the video |
| `url` | `string` | No | Any hosted video link (YouTube, Vimeo, Drive); wins over `file` |
| `file` | `custom` | No | Video file to upload, used when `url` is absent |
| `custom_s3` | `number` | No | 0, or the ID of a custom storage integration |
| `hls` | `boolean` | No | Encode to HLS (true) or leave the source unsecured (false) |
| `video_group` | `number` | No | Project to file it under |
| `create` | `boolean` | No | true confirms the write; false is a dry run |
| `player_settings` | `number \| string` | No | Another of your videos' numeric ID to copy player settings from |

Pass either `url` or `file`. `url` wins when both are given, and `hls` asks for HLS encoding.



**Output:** `string \| number \| object \| object[] \| null \| undefined`

<AccordionGroup>
<Accordion title="Output full type">

```ts
string | number | {
} | {
}[] | null | undefined
```
</Accordion>
</AccordionGroup>

### list

`videos.list`

List videos (1000 a page), or one video by numeric ID, optionally narrowed to a project

**Risk:** `read`

```ts
await corsair.spotlightr.api.videos.list({ video_group: 42 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `video_id` | `number \| string` | No | Only this video (numeric ID) |
| `video_group` | `number` | No | Only videos in this project |
| `page` | `number` | No | Page number, from 1; see last_page in the answer |

Pass `video_id` for one video or `video_group` to narrow to a project. Video IDs are the numeric IDs this route returns, not the base64 form in a watch URL. The answer is a page object under `videos` (1000 videos a page); pass `page` for the next one.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `videos` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="videos full type">

```ts
{
  total?: number | null,
  per_page?: number | string | null,
  current_page?: number | null,
  last_page?: number | null,
  from?: number | null,
  to?: number | null,
  next_page_url?: string | null,
  prev_page_url?: string | null,
  data: {
    id?: number | string | null,
    name?: string | null,
    videoGroup?: number | string | null
  }[]
}
```

</Accordion>

### views

`videos.views`

List a video views (30 a page), optionally for one known viewer or only those past one percent watched

**Risk:** `read`

```ts
await corsair.spotlightr.api.videos.views({ video_id: '1357835', only_watched: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `video_id` | `number \| string` | Yes | Numeric video ID, as videos.list returns it (the base64 ID in a watch URL is its encoded form and is not accepted) |
| `custom_viewer_id` | `string` | No | ID or email of a known viewer |
| `only_watched` | `boolean` | No | Only views past 1% watched |
| `all_views` | `boolean` | No | Skip pagination |
| `page` | `number` | No | Page number, from 1; 30 views a page |

The answer is a page object with `data`, `summary` and 30 views a page; pass `page` for the next one.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `total` | `number \| null` | No | — |
| `per_page` | `number \| string \| null` | No | — |
| `current_page` | `number \| null` | No | — |
| `last_page` | `number \| null` | No | — |
| `from` | `number \| null` | No | — |
| `to` | `number \| null` | No | — |
| `next_page_url` | `string \| null` | No | — |
| `prev_page_url` | `string \| null` | No | — |
| `data` | `object[]` | Yes | — |
| `summary` | `object \| null` | No | — |

<AccordionGroup>
