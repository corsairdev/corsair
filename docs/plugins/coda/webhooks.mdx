The Coda plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/coda/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `docs`
  - `created` (`docs.created`)
  - `deleted` (`docs.deleted`)
- `pages`
  - `created` (`pages.created`)
  - `updated` (`pages.updated`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    const body = await request.json();
    const result = await processWebhook(corsair, headers, body);
    return result.response;
}
```

## Docs

### Created

`docs.created`

A doc was created or copied in the organization

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `events` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="events full type">

```ts
{
  eventId: string,
  timestamp: number,
  action: string,
  result: string,
  organizationId: string,
  user: {
    type: user,
    id: number,
    email: string
  },
  userContext: {
    source: string
  },
  eventDetails?: Record<string, string | number | boolean | null | object | array>,
  entity: {
    type: string
  }
}[]
```
</Accordion>
</AccordionGroup>



<AccordionGroup>

**`webhookHooks` example**

```ts
coda({
    webhookHooks: {
        docs: {
            created: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
