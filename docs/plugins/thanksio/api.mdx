## Creatives

### get

`creatives.get`

Get a saved creative.

**Risk:** `read`

```ts
await corsair.thanksio.api.creatives.get({ creativeId: 501 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `creativeId` | `number` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  id?: number,
  name?: string,
  mailer_type?: string | null,
  postcard_size?: string | null,
  sub_account_id?: number | null,
  source?: string | null,
  hidden?: boolean,
  default?: boolean,
  preview_image_url?: string | null,
  thumbnail_url?: string | null,
  share_url?: string | null,
  is_complete?: boolean,
  needs?: string[],
  image_template?: Record<string, any> | null,
  message_template?: Record<string, any> | null,
  back_background?: Record<string, any> | null,
  created_at?: string,
  updated_at?: string
}
```
</Accordion>
</AccordionGroup>
