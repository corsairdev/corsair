---
title: "Brave Search database"
sidebarTitle: "Database"
description: "The Brave Search plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Brave Search. To read its data, call the [API operations](/plugins/bravesearch/api), which return what Brave Search has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
