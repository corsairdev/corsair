## Admin

### listAdminKeys

**Risk:** `read`


| `page` | `string` | No | next_page from the previous response. |



**Output**

| `data` | `object[]` | Yes | — |
| `has_more` | `boolean` | No | — |

### usage

`admin.usage`

Get API usage in time buckets by key, endpoint or plan

**Risk:** `read`

```ts
await corsair.bravesearch.api.admin.usage({
	starting_at: '2026-11-01T00:00:00Z',
	bucket_width: '1d',
	group_by: ['endpoint'],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `starting_at` | `string` | Yes | ISO 8601 start with an offset, e.g. 2026-11-01T00:00:00Z. Up to 12 months back. |
| `ending_at` | `string` | No | ISO 8601 end with an offset (default now). |
| `bucket_width` | `1h \| 1d \| 1mo` | No | Bucket size (default 1d). 1mo buckets are the billed totals. |
| `group_by` | `(api_key_id \| endpoint \| plan_id)[]` | No | Split each bucket by these. |
| `api_key_ids` | `string[]` | No | Only these search keys (key_...). |
| `endpoints` | `string[]` | No | Only these endpoints: web, news, images, videos, llm_context, answers, ... |
| `plan_ids` | `string[]` | No | Only these plans (plan_...). |
| `limit` | `number` | No | Buckets per page (1h: 168, 1d: 31, 1mo: 12 at most). |
| `page` | `string` | No | next_page from the previous response. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `object` | `string` | No | — |
| `data` | `object[]` | Yes | — |
| `api_keys` | `object` | No | — |
| `plans` | `object` | No | — |
| `has_more` | `boolean` | No | — |
| `next_page` | `string \| null` | No | — |
| `data_refreshed_at` | `string \| null` | No | — |

<AccordionGroup>

```ts
    queries?: number | null,
```

## Answers

### create

`answers.create`

Answer a question from one web search, with optional inline citations (Answers plan)

**Risk:** `read`

```ts
await corsair.bravesearch.api.answers.create({
	messages: [{ role: 'user', content: 'What is the second highest mountain?' }],
	enable_citations: true,
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `messages` | `object[]` | Yes | Exactly one user message: [&#123; "role": "user", "content": "your question" &#125;]. |
| `model` | `brave-pro \| brave` | No | brave-pro (default) or brave. |
| `max_completion_tokens` | `number` | No | Cap on answer tokens. |
| `country` | `string` | No | Country for the searches behind the answer (default us). |
| `language` | `string` | No | Answer language (default: the question's language). |
| `safesearch` | `off \| moderate \| strict` | No | Adult content filter (default moderate). |
| `web_search_options` | `object` | No | OpenAI-style search options: context size and approximate user location. |
| `enable_citations` | `boolean` | No | Collect inline citations into `citations` (start/end offsets into the answer, url, snippet). |
| `enable_entities` | `boolean` | No | Collect inline entity tags into `tags`. |

<AccordionGroup>
<Accordion title="messages full type">

```ts
{
  role?: user,
  content: string
```

```ts
    }
  }
}
```
</Accordion>
</AccordionGroup>

## Llm

### context

`llm.context`

Search the web and get extracted page text, token-budgeted, for grounding an LLM

**Risk:** `read`

```ts
await corsair.bravesearch.api.llm.context({ q: 'tallest mountains in the world', count: 5, maximum_number_of_tokens: 2048 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | The search query. Up to 600 characters; Brave search operators (site:, "quotes", -term) work unless operators is false. |
| `country` | `string` | No | Two-letter country code the results come from (US, GB, DE, ...), or ALL for worldwide. Default US. |
| `search_lang` | `string` | No | Language of the results: en, de, fr, pt-br, zh-hans, ... Default en. |
| `count` | `number` | No | Search results considered when picking context, 1-50 (default 20). |
| `safesearch` | `off \| moderate \| strict` | No | Adult content filter. Default: none. |
| `spellcheck` | `boolean` | No | Spell-correct the query (default true). |
| `operators` | `boolean` | No | Apply search operators (default true). |
| `operators_fallback` | `boolean` | No | Relaxed operator matching first, then the original results (default true). |
| `maximum_number_of_urls` | `number` | No | Most distinct URLs in the context. |
| `maximum_number_of_tokens` | `number` | No | Approximate token budget for the whole context, 1024-32768 (default 8192). |
| `maximum_number_of_tokens_per_url` | `number` | No | Token budget per URL, 512-8192 (default 4096). |
| `context_threshold_mode` | `disabled \| strict \| lenient \| balanced` | No | How strictly content must match the query to be included. |
| `goggles` | `string \| string[]` | No | Goggles re-rank results: the URL of a hosted Goggle or a Goggle definition, or a list of up to 3. |
| `freshness` | `string` | No | Page age filter: pd (24 hours), pw (7 days), pm (31 days), py (365 days), or a range YYYY-MM-DDtoYYYY-MM-DD. |
| `enable_local` | `boolean` | No | Local (POI and map) context. Default: on when a location is given. |
| `enable_source_metadata` | `boolean` | No | Add site_name, favicon, thumbnail and description to each source. |
| `location` | `object` | No | — |
| `api_version` | `string` | No | Pin the response format to an API version (Api-Version header, YYYY-MM-DD). Default latest. |
| `no_cache` | `boolean` | No | Ask Brave not to serve cached results (Cache-Control: no-cache, best effort). |
| `user_agent` | `string` | No | The end user's browser User-Agent, for device-specific results. |
