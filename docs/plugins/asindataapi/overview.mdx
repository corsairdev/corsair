Use **AsinData API** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 22 typed API operations
- 4 synced entities (`collections`, `destinations`, `requests`, `resultSets`) for fast `.search()` / `.list()`
- 1 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/asindataapi better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/asindataapi better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/asindataapi better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/asindataapi better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { asindataapi } from '@corsair-dev/asindataapi';

export const corsair = createCorsair({
	plugins: [
		asindataapi(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the AsinData API API key before the first call: `pnpm corsair setup --plugin=asindataapi --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
asindataapi()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'asindataapi',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`categories.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.asindataapi.api.categories.get({});
```


**`collections.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.asindataapi.api.collections.create({});
```


See the full list on the [API](/plugins/asindataapi/api) page.

## Query synced data

Synced entities support `tenant.asindataapi.db.<entity>.search()` and `.list()`: `collections`, `destinations`, `requests`, `resultSets`.

See [Database](/plugins/asindataapi/database) for filters and operators.

## Webhooks

This plugin registers **1** webhook event type. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/asindataapi/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
