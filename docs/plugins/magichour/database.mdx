---
title: "Magic Hour database"
sidebarTitle: "Database"
description: "The Magic Hour plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Magic Hour. To read its data, call the [API operations](/plugins/magichour/api), which return what Magic Hour has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
