## Account

### get

`account.get`

Get the account's credit balance and subscription details

**Risk:** `read`

```ts
await corsair.magichour.api.account.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `email` | `string` | No | — |
| `tier` | `free \| creator \| pro \| business` | Yes | — |
| `credits` | `number` | Yes | — |
| `subscription` | `object` | No | — |

<AccordionGroup>
<Accordion title="subscription full type">

```ts
{
  name?: string | null,
  status: active | past_due,
  price: {
    amount: number,
    currency: string
  },
  discount?: {
    percent_off?: number | null,
    amount_off?: number | null
  } | null,
  billing_interval?: month | year | | null,
  current_period_end?: string | null,
  cancel_at_period_end: boolean
}
```
</Accordion>
</AccordionGroup>
