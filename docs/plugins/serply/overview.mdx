Use **Serply** through Corsair: one client, typed API calls, local DB sync.

Empty-key GET requests to /v1/image, /v1/maps/search/test, and /v1/scholar each returned HTTP 401 with detail "API key missing". A successful uncached search spends one credit. The query is not written to the event. Phone numbers and author names are not stored.

**What you get:**

- 3 typed API operations
- 3 synced entities (`articles`, `images`, `places`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/serply better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/serply better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/serply better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/serply better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { serply } from '@corsair-dev/serply';

export const corsair = createCorsair({
	plugins: [
		serply(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Serply API key before the first call: `pnpm corsair setup --plugin=serply --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
serply()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'serply',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Search images**

```ts
const tenant = corsair.withTenant('acme');
await tenant.serply.api.images.search({ q: 'bicycle', num: 5 });
```


**`articles.search`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.serply.api.articles.search({});
```


See the full list on the [API](/plugins/serply/api) page.

## Query synced data

Synced entities support `tenant.serply.db.<entity>.search()` and `.list()`: `articles`, `images`, `places`.

See [Database](/plugins/serply/database) for filters and operators.
