## Articles

### search

`articles.search`

Search Google Scholar articles and store them. Each uncached call spends Serply credits.

**Risk:** `read`

```ts
await corsair.serply.api.articles.search({ q: 'large language model agents' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | — |
| `num` | `number` | No | Results per page, up to 200 |
| `start` | `number` | No | Zero-based offset for the next page |

GET /v1/scholar?q=. Pages with `num` (up to 200) and `start`. A row is stored when id is present. Author names are not stored.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `articles` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="articles full type">

```ts
{
  id: string,
  title?: string,
  link?: string
}[]
```
</Accordion>
</AccordionGroup>

## News

### search

`news.search`

Search Google News, optionally resolving links to the publisher URL. Each uncached call spends Serply credits.

**Risk:** `read`

```ts
await corsair.serply.api.news.search({ q: 'open source ai agents', ceid: 'US:en' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `q` | `string` | Yes | — |
| `ceid` | `string` | No | Country and language edition, e.g. US:en or GB:en |
| `resolve_links` | `boolean` | No | Replace Google News redirect links with the publisher URL (2-3 s slower) |
| `proxy_location` | `EU \| CA \| US \| IE \| GB \| FR \| DE \| SE \| IN \| JP \| KR \| SG \| AU \| BR` | No | Region the search runs from (X-Proxy-Location) |
| `device` | `desktop \| mobile` | No | Device Google sees (X-User-Agent); desktop by default |

`ceid` picks the edition (US:en, GB:en, DE:de). `resolve_links: true` swaps Google News redirect links for the publisher URL and takes 2-3 s longer.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `feed` | `object \| null` | No | — |
| `entries` | `object[] \| null` | No | — |

<AccordionGroup>
<Accordion title="feed full type">

```ts
{
} | null
```
</Accordion>

<Accordion title="entries full type">

```ts
{
  title?: string | null,

}[] | null
```
</Accordion>
</AccordionGroup>
