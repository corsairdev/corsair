## Coupons

### batch

`coupons.batch`

Create, update and delete up to 100 coupons in one call

**Risk:** `destructive`

```ts
await corsair.woocommerce.api.coupons.batch({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `create` | `Record<string, any>[]` | No | Records to create, each with the same fields as the create operation. |
| `update` | `Record<string, any>[]` | No | Records to update, each with its `id` (settings: `id` and `value`) and the fields to change. |
| `delete` | `number[]` | No | Ids of records to delete (permanently). |



**Output:** `unknown`


---

### create

`coupons.create`

Create a coupon

**Risk:** `write`

```ts
await corsair.woocommerce.api.coupons.create({ code: 'SPRING10', discount_type: 'percent', amount: '10' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `code` | `string` | Yes | Coupon code. |
| `amount` | `number \| string` | No | The amount of discount. Should always be numeric, even if setting a percentage. |
| `status` | `string` | No | The status of the coupon. Should always be draft, published, or pending review |
| `discount_type` | `percent \| fixed_cart \| fixed_product` | No | Determines the type of discount that will be applied. |
| `description` | `string` | No | Coupon description. |
| `date_expires` | `string \| null` | No | The date the coupon expires, in the site's timezone. |
| `date_expires_gmt` | `string \| null` | No | The date the coupon expires, as GMT. |
| `individual_use` | `boolean` | No | If true, the coupon can only be used individually. Other applied coupons will be removed from the cart. |
| `product_ids` | `number[]` | No | List of product IDs the coupon can be used on. |
| `excluded_product_ids` | `number[]` | No | List of product IDs the coupon cannot be used on. |
| `usage_limit` | `number` | No | How many times the coupon can be used in total. |
| `usage_limit_per_user` | `number` | No | How many times the coupon can be used per customer. |
| `limit_usage_to_x_items` | `number` | No | Max number of items in the cart the coupon can be applied to. |
| `free_shipping` | `boolean` | No | If true and if the free shipping method requires a coupon, this coupon will enable free shipping. |
| `product_categories` | `number[]` | No | List of category IDs the coupon applies to. |
| `excluded_product_categories` | `number[]` | No | List of category IDs the coupon does not apply to. |
| `exclude_sale_items` | `boolean` | No | If true, this coupon will not be applied to items that have sale prices. |
| `minimum_amount` | `number \| string` | No | Minimum order amount that needs to be in the cart before coupon applies. |
| `maximum_amount` | `number \| string` | No | Maximum order amount allowed when using the coupon. |
| `email_restrictions` | `string[]` | No | List of email addresses that can use this coupon. |
| `meta_data` | `object[]` | No | Meta data. |

}[]

### create

`orders.create`

Create an order with line items, billing and shipping addresses, shipping lines, fees, coupons and a status (no payment is taken; set_paid marks it paid)

**Risk:** `write`

```ts
await corsair.woocommerce.api.orders.create({
	payment_method: 'bacs',
	set_paid: false,
	billing: { first_name: 'Ada', last_name: 'Lovelace', email: 'ada@example.com' },
	line_items: [{ product_id: 42, quantity: 2 }],
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `parent_id` | `number` | No | Parent order ID. |
| `created_via` | `string` | No | Shows where the order was created. |
| `status` | `auto-draft \| pending \| processing \| on-hold \| completed \| cancelled \| refunded \| failed \| checkout-draft` | No | Order status. |
| `currency` | `AED \| AFN \| ALL \| AMD \| ANG \| AOA \| ARS \| AUD \| AWG \| AZN \| BAM \| BBD \| BDT \| BGN \| BHD \| BIF \| BMD \| BND \| BOB \| BRL \| BSD \| BTC \| BTN \| BWP \| BYR \| BYN \| BZD \| CAD \| CDF \| CHF \| CHW \| CLP \| CNY \| COP \| CRC \| CUC \| CUP \| CVE \| CZK \| DJF \| DKK \| DOP \| DZD \| EGP \| ERN \| ETB \| EUR \| FJD \| FKP \| GBP \| GEL \| GGP \| GHS \| GIP \| GMD \| GNF \| GTQ \| GYD \| HKD \| HNL \| HRK \| HTG \| HUF \| IDR \| ILS \| IMP \| INR \| IQD \| IRR \| IRT \| ISK \| JEP \| JMD \| JOD \| JPY \| KES \| KGS \| KHR \| KMF \| KPW \| KRW \| KWD \| KYD \| KZT \| LAK \| LBP \| LKR \| LRD \| LSL \| LYD \| MAD \| MDL \| MGA \| MKD \| MMK \| MNT \| MOP \| MRU \| MUR \| MVR \| MWK \| MXN \| MYR \| MZN \| NAD \| NGN \| NIO \| NOK \| NPR \| NZD \| OMR \| PAB \| PEN \| PGK \| PHP \| PKR \| PLN \| PRB \| PYG \| QAR \| RON \| RSD \| RUB \| RWF \| SAR \| SBD \| SCR \| SDG \| SEK \| SGD \| SHP \| SLL \| SOS \| SRD \| SSP \| STN \| SYP \| SZL \| THB \| TJS \| TMT \| TND \| TOP \| TRY \| TTD \| TWD \| TZS \| UAH \| UGX \| USD \| UYU \| UZS \| VEF \| VES \| VND \| VUV \| WST \| XAF \| XCD \| XOF \| XPF \| YER \| ZAR \| ZMW` | No | Currency the order was created with, in ISO format. |
| `customer_id` | `number` | No | User ID who owns the order. 0 for guests. |

| `billing` | `object` | No | Billing address. |
