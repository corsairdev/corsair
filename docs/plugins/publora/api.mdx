## Accounts

### getContext

`accounts.getContext`

The plan, features, monthly and scheduled post quotas, latest allowed schedule date and allowed networks of the key's account. Check it before a batch of posts.

**Risk:** `read`

```ts
await corsair.publora.api.accounts.getContext({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `scheduledTime` | `string` | No | ISO 8601 date-time of a planned batch; selects its monthly quota period. Omit for the current period. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | No | — |
| `context` | `object` | Yes | — |

<AccordionGroup>

## Webhooks

### create

`webhooks.create`

Subscribe an HTTPS URL to post.scheduled, post.published, post.failed and post.demoted events (up to 10 per account; needs a paid plan). The reply is the only time the signing secret is shown.

**Risk:** `write`

```ts
await corsair.publora.api.webhooks.create({ name: 'Production', url: 'https://example.com/publora-events', events: ['post.published', 'post.failed'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | A name to recognise the subscription by |
| `url` | `string` | Yes | Public HTTPS URL that receives the events |
| `events` | `(post.scheduled \| post.published \| post.failed \| post.demoted \| token.expiring)[]` | Yes | post.scheduled, post.published, post.failed, post.demoted (token.expiring is accepted but not sent yet) |
