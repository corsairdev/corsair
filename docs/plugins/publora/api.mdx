## Accounts

### getContext

`accounts.getContext`

The plan, features, monthly and scheduled post quotas, latest allowed schedule date and allowed networks of the key's account. Check it before a batch of posts.

**Risk:** `read`

```ts
await corsair.publora.api.accounts.getContext({});
```

| Name | Type | Required | Description |

### createUpload

`media.createUpload`

Get a pre-signed URL (valid for an hour) to PUT an image, video or PDF to, attached to a draft or scheduled post group. Use this for files that are not at a public URL.

**Risk:** `write`

```ts
await corsair.publora.api.media.createUpload({ postGroupId: 'POST_GROUP_ID', fileName: 'launch.png', contentType: 'image/png' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `postGroupId` | `string` | Yes | Post group to attach the file to (create a draft first) |
| `fileName` | `string` | Yes | File name, e.g. "photo.jpg" |
| `contentType` | `string` | Yes | MIME type: image/*, video/* or application/pdf |
| `type` | `image \| video \| document` | No | Media type; inferred from contentType when omitted |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | No | — |
| `uploadUrl` | `string` | Yes | — |
| `fileUrl` | `string \| null` | No | — |
| `mediaId` | `string` | Yes | — |

## Posts

### create

`posts.create`

Create one post for one or more connected accounts, with text, media URLs, per-network settings and first comments. Without scheduledTime or publishNow it is saved as a draft; with scheduledTime it is scheduled; publishNow publishes it right away and it cannot be recalled once live. An idempotencyKey makes a retry return the original post.

**Risk:** `destructive`

```ts
await corsair.publora.api.posts.create({ content: 'Launching today', platforms: ['linkedin-ABC123'], mediaUrls: ['https://example.com/launch.png'], scheduledTime: '2026-12-01T15:00:00Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `content` | `string` | No | Post text. Required unless the only target is a LinkedIn repost. |
| `platforms` | `string[]` | Yes | Connection ids from accounts.list (platformId, e.g. "linkedin-ABC123"), each at most once |
| `scheduledTime` | `string` | No | ISO 8601 UTC date-time to publish at. Omit (and leave publishNow off) to save a draft. |
| `publishNow` | `boolean` | No | Publish immediately. Cannot be combined with a future scheduledTime. |
| `platformSettings` | `Record<string, Record<string, any>>` | No | Per-network settings keyed by platform, e.g. &#123; youtube: &#123; title, privacy &#125;, tiktok: &#123; viewerSetting &#125;, instagram: &#123; videoType: "REELS" &#125; &#125;. See https://docs.publora.com/endpoints/create-post |
| `firstComments` | `object[]` | No | Up to three comments Publora posts under the published post (LinkedIn, X, Threads, Bluesky, Mastodon) |
| `mediaUrls` | `string[]` | No | Public https image or video URLs that Publora downloads (images 25 MB, videos 150 MB, 300 MB in total). Instagram, TikTok and YouTube need media. |
| `idempotencyKey` | `string` | No | Sent as the Idempotency-Key header. A repeat with the same key and body within 24 hours returns the first result instead of acting twice; the same key with another body is rejected with 422. |

<AccordionGroup>
<Accordion title="firstComments full type">

```ts

}[]
```
</Accordion>
</AccordionGroup>

| `success` | `boolean` | No | — |
| `postGroupId` | `string` | Yes | — |
| `scheduledTime` | `string \| null` | No | — |
| `warnings` | `object[]` | No | — |

<AccordionGroup>

### update

`posts.update`

Change a draft or scheduled post: text, targets (the list is replaced), publish time, status, settings, first comments or extra media. publishNow publishes it immediately.

**Risk:** `destructive`

```ts

```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `postGroupId` | `string` | Yes | Post group id (postGroupId) from posts.create or posts.list |
| `content` | `string` | No | Replacement post text |
| `platforms` | `string[]` | No | Replacement target list (not merged). Send the complete final list of connection ids. |
| `status` | `draft \| scheduled` | No | Move the post back to draft or schedule it |
| `scheduledTime` | `string` | No | New ISO 8601 UTC publish time |
| `publishNow` | `boolean` | No | Publish this draft or scheduled post immediately |
| `platformSettings` | `Record<string, Record<string, any>>` | No | Per-network settings keyed by platform, e.g. &#123; youtube: &#123; title, privacy &#125;, tiktok: &#123; viewerSetting &#125;, instagram: &#123; videoType: "REELS" &#125; &#125;. See https://docs.publora.com/endpoints/create-post |
| `firstComments` | `object[] \| null` | No | Replace the comments; null or [] removes them |
| `mediaUrls` | `string[]` | No | Public https media URLs appended to the existing media |
| `idempotencyKey` | `string` | No | Sent as the Idempotency-Key header. A repeat with the same key and body within 24 hours returns the first result instead of acting twice; the same key with another body is rejected with 422. |

## Webhooks

### create

`webhooks.create`

Subscribe an HTTPS URL to post.scheduled, post.published, post.failed and post.demoted events (up to 10 per account; needs a paid plan). The reply is the only time the signing secret is shown.

**Risk:** `write`

```ts
await corsair.publora.api.webhooks.create({ name: 'Production', url: 'https://example.com/publora-events', events: ['post.published', 'post.failed'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | A name to recognise the subscription by |
| `url` | `string` | Yes | Public HTTPS URL that receives the events |
| `events` | `(post.scheduled \| post.published \| post.failed \| post.demoted \| token.expiring)[]` | Yes | post.scheduled, post.published, post.failed, post.demoted (token.expiring is accepted but not sent yet) |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | No | — |
| `webhook` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="webhook full type">

{
  _id: string,

  events?: string[] | null,

  updatedAt?: string | null,

</Accordion>
