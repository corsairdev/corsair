Use **Callingly** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 29 typed API operations
- 8 synced entities (`calls`, `clients`, `leads`, `schedules`, `teams`, `teamUsers`, and 2 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/callingly better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/callingly better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/callingly better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/callingly better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { callingly } from '@corsair-dev/callingly';

export const corsair = createCorsair({
	plugins: [
		callingly(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Callingly API key before the first call: `pnpm corsair setup --plugin=callingly --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
callingly()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'callingly',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List leads**

```ts
const tenant = corsair.withTenant('acme');
await tenant.callingly.api.leads.list({});
```


**Create a call**

```ts
const tenant = corsair.withTenant('acme');
await tenant.callingly.api.calls.create({ team_id: 123, phone_number: '+15555550123', first_name: 'Octo' });
```


See the full list on the [API](/plugins/callingly/api) page.

## Query synced data

Search synced leads without hitting Callingly.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.callingly.db.leads.search({
	data: {},
	limit: 50,
});
```

Synced entities: `calls`, `clients`, `leads`, `schedules`, `teams`, `teamUsers`, `users`, `webhooks`. See [Database](/plugins/callingly/database) for filters and operators.
