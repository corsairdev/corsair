## Addons

### get

`addons.get`

Read one add-on record with its operator credentials

**Risk:** `read`

```ts
await corsair.storeganise.api.addons.get({ addonId: '5bf540e8d986a91cd713affe' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `addonId` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `customFields` | `Record<string, unknown> \| null` | No | — |

### update

`unitRentals.update`

Set custom fields on a unit rental, such as access codes

**Risk:** `write`

```ts
await corsair.storeganise.api.unitRentals.update({
	unitRentalId: '5bf540e8d986a91cd713affe',
	customFields: { myAC_accessCode: '482913' },
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `unitRentalId` | `string` | Yes | — |
| `customFields` | `Record<string, unknown>` | Yes | — |

The only documented write. Sets custom fields on one rental, which is how access-control integrations store access codes and overlock flags under prefixed keys such as myAC_accessCode or myAC_overlocked.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `unit` | `object \| null` | No | — |
| `owner` | `object \| null` | No | — |
| `customFields` | `Record<string, unknown> \| null` | No | — |

<AccordionGroup>
<Accordion title="unit full type">

```ts
{
  id: string,
  siteId?: string | null,
  typeId?: string | null,
  name?: string | null,
  length?: number | null,
  width?: number | null,
  height?: number | null,
  measure?: string | null,
  floor?: string | null,
  defaultDeposit?: number | null,
  defaultPrice?: number | null
} | null
```
</Accordion>

<Accordion title="owner full type">

```ts

  id: string,
  email?: string | null
} | null
```
</Accordion>
