Use **Dropbox Sign** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 56 typed API operations
- 7 synced entities (`account`, `apiApp`, `bulkSendJob`, `fax`, `signatureRequest`, `team`, and 1 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/dropboxsign
```
```bash yarn
yarn add corsair @corsair-dev/dropboxsign
```
```bash pnpm
pnpm install corsair @corsair-dev/dropboxsign
```
```bash bun
bun add corsair @corsair-dev/dropboxsign
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { dropboxsign } from '@corsair-dev/dropboxsign';

export const corsair = createCorsair({
	plugins: [
		dropboxsign(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
dropboxsign()
```

More: [API Key](/concepts/api-key)

</Tab>
<Tab title="OAuth 2.0">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Dropbox Sign OAuth app.

```ts
dropboxsign({
	authType: 'oauth_2',
})
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'dropboxsign',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`account.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.dropboxsign.api.account.get({});
```


**`account.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.dropboxsign.api.account.create({});
```


See the full list on the [API](/plugins/dropboxsign/api) page.

## Query synced data

Synced entities support `tenant.dropboxsign.db.<entity>.search()` and `.list()`: `account`, `apiApp`, `bulkSendJob`, `fax`, `signatureRequest`, `team`, `template`.

See [Database](/plugins/dropboxsign/database) for filters and operators.
