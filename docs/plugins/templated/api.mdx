## Renders

### create

`renders.create`

Render a template to an image, PDF or video, spending an API credit; layer overrides fill the template

**Risk:** `destructive`

```ts
await corsair.templated.api.renders.create({ template: '306c724a-d138-486a-a601-0b2a9ced52be', format: 'pdf', layers: { 'text-1': { text: 'Hello' } } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `template` | `string` | No | The template to render. Required unless `templates` is sent. |
| `templates` | `string[]` | No | Batch render several templates. When present, `template` is ignored and not required. |
| `layers` | `Record<string, Record<string, any>>` | No | Layer overrides keyed by layer name, each a map of property to value, e.g. `{ "text-1": { "text": "Hello" } }`. |
| `format` | `jpg \| png \| webp \| pdf \| mp4 \| html` | No | The output format. The API defaults it to jpg. |
| `width` | `number` | No | Custom width in pixels, 100 to 5000. |
| `height` | `number` | No | Custom height in pixels, 100 to 5000. |
| `scale` | `number` | No | Scale factor for the final render, 0.1 to 2.0. Defaults to 1. |
| `transparent` | `boolean` | No | A transparent background, for png only. |
| `duration` | `number` | No | Video duration in milliseconds, for mp4, up to 90000. |
| `fps` | `number` | No | Frames per second, for mp4, 1 to 60. |
| `flatten` | `boolean` | No | Flatten the PDF, for print. |
| `cmyk` | `boolean` | No | Use CMYK colour, for print. |
| `name` | `string` | No | A name for the render. |
| `background` | `string` | No | A hex background colour. |
| `external_id` | `string` | No | Your own identifier for this render. |
| `async` | `boolean` | No | Render asynchronously and return while it is still PENDING. Defaults to false. |
| `webhook_url` | `string` | No | A URL Templated posts the finished render to. |

Spends one credit per render; send template, or templates for a batch which answers an array; width and height run from 100 to 5000 and format defaults to jpg.



**Output:** `object \| object[]`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  id: string,
  url?: string | null,
  storage_url?: string | null,

  format?: string | null,
  templateId?: string | null,
  templateName?: string | null,
  name?: string | null,
  createdAt?: string | null,
  externalId?: string | null
} | {
  id: string,
  url?: string | null,
  storage_url?: string | null,
  width?: number | null,
  height?: number | null,
  status?: string | null,
  format?: string | null,
  templateId?: string | null,

  name?: string | null,
  createdAt?: string | null,
  externalId?: string | null
}[]
```
</Accordion>

### merge

`renders.merge`

Merge several renders, plus external PDFs when given, into one PDF and return its hosted URL

**Risk:** `destructive`

```ts
await corsair.templated.api.renders.merge({ ids: ['ce424057-6b54-41bb-afec-adc35a2b9175', 'aa112233-4455-6677-8899-aabbccddeeff'], name: 'packet' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ids` | `string[]` | Yes | The renders to merge. |
| `urls` | `string[]` | No | External PDF URLs to merge after the renders, in order. |
| `name` | `string` | No | A name for the merged PDF. |
| `host` | `true` | No | Host the merged PDF and return its URL. Always on. |

Always asked to host the merged PDF, because the direct-download form answers the file rather than JSON.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | — |

## Uploads

### create

`uploads.create`

Upload an image, up to 2 MB, for use as a template layer

**Risk:** `write`

```ts
await corsair.templated.api.uploads.create({ fileName: 'logo.png', fileBase64: 'iVBORw0KGgo=', contentType: 'image/png', tags: ['brand'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileName` | `string` | Yes | The file name, with its extension: jpg, png, webp or svg. |
| `fileBase64` | `string` | Yes | The image bytes, base64 encoded. Maximum 2 MB. |
| `contentType` | `string` | No | The image media type, e.g. "image/png". Inferred from the name when omitted. |
| `tags` | `string[]` | No | Tags to organise the upload. |
| `externalId` | `string` | No | Your own reference for the upload. |

The route takes multipart file bytes up to 2 MB; pass fileName and fileBase64, and contentType when the extension is ambiguous.
