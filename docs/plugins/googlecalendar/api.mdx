## Calendar

### getAvailability

`calendar.getAvailability`

Busy time ranges only, no event details; use events.getMany to see the events

**Risk:** `read`

```ts
await corsair.googlecalendar.api.calendar.getAvailability({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `timeMin` | `string` | Yes | RFC 3339 with a time zone offset, e.g. "2025-06-03T00:00:00-07:00". |
| `timeMax` | `string` | Yes | RFC 3339 with a time zone offset, e.g. "2025-06-04T00:00:00-07:00". |
| `timeZone` | `string` | No | — |
| `groupExpansionMax` | `number` | No | — |
| `calendarExpansionMax` | `number` | No | — |
| `items` | `object[]` | No | Calendars to check, by calendar id (usually an email address). |

<AccordionGroup>
<Accordion title="items full type">

```ts
{
  id: string
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `kind` | `string` | No | — |
| `calendars` | `object` | No | — |
| `groups` | `object` | No | — |
| `timeMin` | `string` | No | — |
| `timeMax` | `string` | No | — |

### getMany

`events.getMany`

List events in a time window. Set singleEvents true or recurring events appear once; page with pageToken until nextPageToken is empty

**Risk:** `read`

```ts
await corsair.googlecalendar.api.events.getMany({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `calendarId` | `string` | No | Calendar ID. Defaults to "primary". |
| `timeMin` | `string` | No | RFC 3339 with a time zone offset, e.g. "2025-06-03T00:00:00-07:00" or "2025-06-03T00:00:00Z"; a plain date is rejected. Lower bound on event end time, exclusive. |
| `timeMax` | `string` | No | RFC 3339 with a time zone offset, e.g. "2025-06-04T00:00:00-07:00" or "2025-06-04T00:00:00Z"; a plain date is rejected. Upper bound on event start time, exclusive. |
| `timeZone` | `string` | No | — |
| `updatedMin` | `string` | No | — |
| `singleEvents` | `boolean` | No | Defaults to false, which returns a recurring event once instead of its occurrences. Set true to expand occurrences; orderBy "startTime" needs it. |
| `maxResults` | `number` | No | Page size, default 250. A page can be short or empty while more remain; follow nextPageToken. |
| `pageToken` | `string` | No | nextPageToken from the previous response. |
| `q` | `string` | No | — |
| `orderBy` | `startTime \| updated` | No | — |
| `iCalUID` | `string` | No | — |
| `showDeleted` | `boolean` | No | — |
| `showHiddenInvitations` | `boolean` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `kind` | `string` | No | — |
| `etag` | `string` | No | — |
| `summary` | `string` | No | — |
| `description` | `string` | No | — |
| `updated` | `string` | No | — |
| `timeZone` | `string` | No | — |
| `accessRole` | `string` | No | — |
| `defaultReminders` | `object[]` | No | — |
| `nextPageToken` | `string` | No | — |
| `nextSyncToken` | `string` | No | — |
| `items` | `object[]` | No | — |
