## Account

### get

`account.get`

Retrieve ClickSend account details and credit balance

**Risk:** `read`

```ts
await corsair.clicksend.api.account.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `user_id` | `number \| string` | Yes | — |
| `username` | `string` | Yes | — |
| `user_email` | `string` | Yes | — |
| `user_first_name` | `string` | No | — |
| `user_last_name` | `string` | No | — |
| `balance` | `number` | Yes | — |
| `currency` | `string` | No | — |
