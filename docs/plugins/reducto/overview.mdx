Use **Reducto** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 20 typed API operations
- 12 synced entities (`classifyOutputs`, `editFormFields`, `editOutputs`, `extractCitations`, `extractOutputs`, `extractRecords`, and 6 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/reducto
```
```bash yarn
yarn add corsair @corsair-dev/reducto
```
```bash pnpm
pnpm install corsair @corsair-dev/reducto
```
```bash bun
bun add corsair @corsair-dev/reducto
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { reducto } from '@corsair-dev/reducto';

export const corsair = createCorsair({
	plugins: [
		reducto(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
reducto()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'reducto',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`account.version`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.reducto.api.account.version({});
```


**`account.configureWebhook`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.reducto.api.account.configureWebhook({});
```


See the full list on the [API](/plugins/reducto/api) page.

## Query synced data

Synced entities support `tenant.reducto.db.<entity>.search()` and `.list()`: `classifyOutputs`, `editFormFields`, `editOutputs`, `extractCitations`, `extractOutputs`, `extractRecords`, `jobs`, `parseBlocks`, `parseChunks`, `parseOcrItems`, `pipelineOutputs`, `splitSegments`.

See [Database](/plugins/reducto/database) for filters and operators.
