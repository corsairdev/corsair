### list

`changes.list`

Data changes detected across workflows in a date window, with the changed fields and counts; `exclude` drops the large arrays

**Risk:** `read`

```ts
await corsair.kadoa.api.changes.list({ startDate: '2026-11-01', endDate: '2026-11-12', exclude: ['differences'], limit: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workflowIds` | `string[]` | No | Only changes in these workflows, sent comma-separated. Omit for every ACTIVE workflow. |
| `startDate` | `string` | No | Earliest change, as an ISO date or date-time. |
| `endDate` | `string` | No | Latest change, as an ISO date or date-time. A date alone covers that whole day. |
| `skip` | `number` | No | Changes to skip. |
| `limit` | `number` | No | Changes to return, at most 100. Defaults to 25. |
| `exclude` | `(data \| differences)[]` | No | Drop these large fields from each change. The counts stay available. |

`exclude` drops the large arrays; `differencesCounts` still arrives.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `timestamp` | `string \| null` | No | — |
| `changesCount` | `number \| null` | No | — |
| `changes` | `object[]` | Yes | — |
| `pagination` | `object \| null` | No | — |
| `nextSkip` | `number \| null` | Yes | The `skip` for the next page while this one came back full; null otherwise. |

## Variables

### create

`variables.create`

Create a string, number, object or array variable, or a secret held by Kadoa or read from your Google Secret Manager

**Risk:** `write`

```ts
await corsair.kadoa.api.variables.create({ key: 'region', value: 'eu-west', dataType: 'STRING' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `key` | `string` | Yes | Unique within the team. |
| `value` | `string` | No | The value. For OBJECT and ARRAY, a JSON string. May be empty, except for a Kadoa-managed secret. Omit only for a CUSTOMER_MANAGED secret. |
| `dataType` | `STRING \| OBJECT \| ARRAY \| NUMBER \| SECRET` | No | Defaults to STRING. |
| `managementMode` | `KADOA_MANAGED \| CUSTOMER_MANAGED` | No | SECRET only. Defaults to KADOA_MANAGED. |
| `providerConnectionId` | `string` | No | SECRET with CUSTOMER_MANAGED: the Google Secret Manager connection. |
| `resourceReference` | `string` | No | SECRET with CUSTOMER_MANAGED: the secret resource to read. |

A `SECRET` with a value is Kadoa-managed. `CUSTOMER_MANAGED` needs `providerConnectionId` and `resourceReference` and takes no value.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `variable` | `object \| null` | No | — |

### create

`workflows.create`

Create a workflow from a prompt, an existing schema, inline entity and fields, or a template; every URL must belong to one website. Spends Kadoa credits once it runs

**Risk:** `destructive`

```ts
await corsair.kadoa.api.workflows.create({ urls: ['https://acme.example/products'], name: 'Product Catalog', userPrompt: 'Collect every product name, price and stock status from the listing.', interval: 'DAILY' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `urls` | `string[]` | Yes | Sources. Several URLs must belong to one website: subdomains and country domains of the same name count as one, and a request spanning two sites is rejected. |
| `name` | `string` | No | Human-readable workflow name. |
| `description` | `string` | No | What the workflow does, at most 500 characters. |
| `tags` | `string[]` | No | Tags for grouping. Each is at least two characters. |
| `limit` | `number \| null` | No | Maximum records per run. Omit or send null for no limit. |
| `interval` | `ONLY_ONCE \| EVERY_10_MINUTES \| EVERY_20_MINUTES \| HALF_HOURLY \| HOURLY \| TWO_HOURLY \| THREE_HOURLY \| FOUR_HOURLY \| SIX_HOURLY \| TWELVE_HOURLY \| EIGHTEEN_HOURLY \| DAILY \| TWO_DAY \| THREE_DAY \| WEEKLY \| BIWEEKLY \| TRIWEEKLY \| FOUR_WEEKS \| MONTHLY \| CUSTOM` | No | How often the workflow runs. Defaults to Kadoa’s choice for the workflow type. |
| `schedules` | `string[]` | No | Cron expressions. Overrides `interval`. |
| `timezone` | `string` | No | IANA timezone for `schedules`, such as `America/New_York`. Defaults to UTC. |
| `location` | `object` | No | — |
| `userPrompt` | `string` | No | What to extract and how to navigate the site. Required unless the workflow is built from `schemaId`, `entity` with `fields`, or `templateId`. |
| `schemaId` | `string` | No | Build from an existing schema instead of inline fields. |
| `entity` | `string` | No | Entity name for inline extraction, such as `Product`. Needs `fields` unless `userPrompt` is set. |
| `fields` | `object[]` | No | Inline extraction fields. Need `entity` unless `userPrompt` is set. |
| `templateId` | `string` | No | Build from a published template. |
| `templateVersion` | `number` | No | Pin a template version. Omit for the latest published one. |
| `bypassPreview` | `boolean` | No | Skip preview and validation and deploy at once. Only for a configuration you are sure of. |

Exactly one build source: `userPrompt`, `schemaId`, `entity` with `fields`, or `templateId`. Every URL must belong to one website, or Kadoa answers 422.
