## Cases

### bulkFetch

`cases.bulkFetch`

Fetch many cases by ID in one call, optionally limited to specific fields and properties

**Risk:** `read`

```ts
await corsair.commcare.api.cases.bulkFetch({ username: 'jdoe@my-project.commcarehq.org', domain: 'my-project', caseIds: ['abc123', 'def456'], fields: ['case_id'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `username` | `string` | Yes | CommCare username the API key belongs to, e.g. `me@my-project.commcarehq.org`. |
| `domain` | `string` | Yes | CommCare project domain (HQ domain), e.g. `my-project`. |
| `caseIds` | `string[]` | Yes | Case IDs to fetch in one call; an id that is not found comes back as a stub with `error: "not found"`. |
| `fields` | `string[]` | No | Top-level case fields to include, e.g. `case_id`. |
| `fieldsProperties` | `string[]` | No | Case properties to include, e.g. `dob`. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `matching_records` | `number \| null` | No | — |
| `missing_records` | `number \| null` | No | — |
| `cases` | `object[]` | Yes | — |
| `next` | `string \| null` | No | — |
| `nextCursor` | `string \| null` | No | — |

### list

`cases.list`

List cases (Case Data API v2) with cursor paging and filters for case type, owner, name, closed state and indices

**Risk:** `read`

```ts
await corsair.commcare.api.cases.list({ username: 'jdoe@my-project.commcarehq.org', domain: 'my-project', caseType: 'patient', closed: false });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `username` | `string` | Yes | CommCare username the API key belongs to, e.g. `me@my-project.commcarehq.org`. |
| `domain` | `string` | Yes | CommCare project domain (HQ domain), e.g. `my-project`. |
| `cursor` | `string` | No | `nextCursor` from the previous page; omit for the oldest page. The cursor carries the first page's filters, so filters sent with it are ignored. |
| `limit` | `number` | No | Page size, up to 5000; the default is 20. |
| `caseType` | `string` | No | Only cases of this case type. |
| `ownerId` | `string` | No | Only cases owned by this user or group id. |
| `caseName` | `string` | No | Only cases with this name. |
| `closed` | `boolean` | No | true lists closed cases, false open ones. |
| `externalId` | `string` | No | Only the case with this external id. |
| `indicesParent` | `string` | No | Only child cases whose parent index points to this case id. |
| `indicesHost` | `string` | No | Only cases whose host index points to this case id. |

## Forms

### bulkAction

`forms.bulkAction`

Archive, unarchive, or permanently delete up to 5000 forms in one background job (delete needs the forms archived first); follow with forms.bulkActionStatus until status is complete or failed

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.commcare.api.forms.bulkAction({ username: 'jdoe@my-project.commcarehq.org', domain: 'my-project', action: 'archive', formIds: ['3a1b...', '9c4d...'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `username` | `string` | Yes | CommCare username the API key belongs to, e.g. `me@my-project.commcarehq.org`. |
| `domain` | `string` | Yes | CommCare project domain (HQ domain), e.g. `my-project`. |
| `action` | `archive \| unarchive \| delete` | Yes | What to do to the listed forms; delete is permanent. |
| `formIds` | `string[]` | Yes | Up to 5000 form IDs per request; duplicate ids are collapsed. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `action` | `string \| null` | No | — |
| `status` | `string \| null` | No | — |
