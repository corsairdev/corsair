Use **CommCare** through Corsair: one client, typed API calls.

Generate an API key in CommCare HQ under Account Settings, API Keys (the key belongs to your CommCare username). Because ApiKey auth is user-scoped, every operation takes the project `domain` and that `username` as inputs. Things to know before you call:

- **API access needs a plan.** The JSON APIs require a Standard plan or above; on a free project they answer 401 "Your current subscription does not have access to this feature" (or 403). `ota.restore` is the exception: it works on a free project.
- **Every endpoint is scoped to one project.** All requests go to `https://www.commcarehq.org/a/{domain}/...`. There is no plugin-level `domain` or `username` option: pass both on every call.
- **Two pagination styles.** Most listings use `limit` and `offset` with a `meta.total_count`; `cases.list` pages oldest-to-newest by cursor: pass the `nextCursor` it answers as `cursor` until `nextCursor` is absent.
- **Async bulk actions.** `forms.bulkAction` accepts up to 5000 form ids for archive, unarchive or permanent delete, and answers a job id; follow with `forms.bulkActionStatus` until status is `complete` or `failed`. `complete` does not mean every form succeeded: compare `succeeded` with `requested` and read `skipped`. A form must be archived before it can be deleted.
- **Writes.** `submissions.submit` posts OpenRosa XForm XML to the receiver. HQ answers 201 even when it could not process the form; the call fails in that case (nature `submit_error` or `processing_failure`) and otherwise returns the `message` and its `nature`. `users.create` provisions a worker account with an initial password.
- **Delete is permanent.** `users.delete` removes a worker account, and `forms.bulkAction` with action `delete` permanently removes forms.
- **OTA restore auth.** `ota.restore` pulls the full case-restore XML. The docs show worker Basic credentials, but HQ also accepts the ApiKey header and restores the account that owns the key, so a web user's key returns that user's restore, not a mobile worker's. HQ puts the owner's password hash in the restore's registration block; the plugin replaces it with `[removed]` before returning the XML.

**What you get:**

- 32 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/commcare better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/commcare better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/commcare better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/commcare better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { commcare } from '@corsair-dev/commcare';

export const corsair = createCorsair({
	plugins: [
		commcare(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the CommCare API key before the first call: `pnpm corsair setup --plugin=commcare --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
commcare()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'commcare',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List open cases of a type**

```ts
const tenant = corsair.withTenant('acme');
await tenant.commcare.api.cases.list({
	username: 'jdoe@my-project.commcarehq.org',
	domain: 'my-project',
	caseType: 'patient',
	closed: false,
});
```


**Add a mobile worker**

```ts
const tenant = corsair.withTenant('acme');
await tenant.commcare.api.users.create({
	username: 'jdoe@my-project.commcarehq.org',
	domain: 'my-project',
	workerUsername: 'new.worker@my-project.commcarehq.org',
	password: 'change-me-1',
	firstName: 'Jordan',
	lastName: 'Lee',
});
```


See the full list on the [API](/plugins/commcare/api) page.
