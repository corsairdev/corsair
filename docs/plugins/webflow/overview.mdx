Use **Webflow** through Corsair: one client, typed API calls, optional local DB sync.

Webflow exposes site, CMS collection, asset, page, ecommerce, and webhook workflows for the no-code website platform. Use Corsair permissions for destructive actions such as deleting collections, items, assets, or webhooks, and for refunding orders.

**What you get:**

- 52 typed API operations
- 8 database entities synced for fast `.search()` / `.list()` queries

## Setup

<Steps>

<Step title="Install">
```bash
pnpm install @corsair-dev/webflow
```

</Step>

<Step title="Add the plugin">
<Tabs>
<Tab title="Solo">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { webflow } from '@corsair-dev/webflow';

export const corsair = createCorsair({
	// ... other config options,
	multiTenancy: false,
    plugins: [webflow()],
});
```
</Tab>
<Tab title="Multi-Tenant">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { webflow } from '@corsair-dev/webflow';

export const corsair = createCorsair({
	// ... other config options,
    multiTenancy: true,
    plugins: [webflow()],
});
```

See [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Tab>
</Tabs>

</Step>

<Step title="Get credentials">
Follow [Get Credentials](/plugins/webflow/get-credentials) if you need help getting keys.

</Step>

<Step title="Store credentials">
<Tabs>
<Tab title="Solo">
```bash
pnpm corsair setup --plugin=webflow
```

Use the key names documented in [Get Credentials](/plugins/webflow/get-credentials) (for example `api_key=`, `bot_token=`, or OAuth client fields).
</Tab>
<Tab title="Multi-Tenant">
```bash
pnpm corsair setup --plugin=webflow --tenant=<tenantId>
```

Store per-tenant secrets after you create the tenant record. See [Multi-tenancy](/concepts/multi-tenancy).
</Tab>
</Tabs>

</Step>

</Steps>

## Authentication

Each tab shows how to register the plugin for that authentication method. The default `authType` from the plugin does not need to appear in the factory call.

<Tabs>
<Tab title="API Key (Default)">

```ts corsair.ts
webflow()
```

Store credentials with `pnpm corsair setup --plugin=webflow` (see [Get Credentials](/plugins/webflow/get-credentials) for field names). For OAuth, you typically store integration keys at the provider level and tokens per account or tenant.

More: [API Key](/concepts/api-key)

</Tab>
<Tab title="OAuth 2.0">

```ts corsair.ts
webflow({
    authType: 'oauth_2',
})
```

Store credentials with `pnpm corsair setup --plugin=webflow` (see [Get Credentials](/plugins/webflow/get-credentials) for field names). For OAuth, you typically store integration keys at the provider level and tokens per account or tenant.

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>


## Query synced data

Synced entities support `corsair.webflow.db.<entity>.search()` and `.list()`. See [Database](/plugins/webflow/database) for filters and operators.


## Example API calls

**Read-style (read):** `assets.getAsset`

```ts
await corsair.webflow.api.assets.getAsset({});
```


**Write-style (write):** `assets.createAssetFolder`

```ts
await corsair.webflow.api.assets.createAssetFolder({});
```


See the full list on the [API](/plugins/webflow/api) page. Use `pnpm corsair list --plugin=webflow` and `pnpm corsair schema <path>` locally to inspect schemas.
