---
title: Get credentials
description: 'How to get Webflow credentials for the Corsair Webflow plugin'
---

## API key (site token)

Use a Webflow site token for single-site setups.

1. Open your site settings in Webflow.
2. Go to **Apps & Integrations** -> **API access**.
3. Generate a new API token and select the permissions you need.
4. Store it as `api_key`.

```bash
pnpm corsair setup --webflow api_key=<webflow_site_token>
```

Site tokens are scoped to one site. The permissions you select when generating the token control which operations succeed.

## OAuth 2.0

Use OAuth when your app needs access to sites across workspaces.

1. Register a Webflow App in your workspace settings under **Apps & Integrations** -> **App development**.
2. Set your redirect URI and select the scopes your app needs.
3. Store the client credentials:

```bash
pnpm corsair setup --webflow client_id=<client_id> client_secret=<client_secret>
```

Webflow access tokens do not expire and no refresh token is issued, but users can revoke them from their workspace settings at any time.
