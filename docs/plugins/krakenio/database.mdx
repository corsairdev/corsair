---
title: "Kraken.io database"
sidebarTitle: "Database"
description: "The Kraken.io plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Kraken.io. To read its data, call the [API operations](/plugins/krakenio/api), which return what Kraken.io has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
