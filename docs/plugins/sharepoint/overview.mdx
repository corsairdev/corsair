Use **SharePoint** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 86 typed API operations
- 6 synced entities (`files`, `folders`, `items`, `lists`, `sites`, `users`) for fast `.search()` / `.list()`
- 1 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/sharepoint
```
```bash yarn
yarn add corsair @corsair-dev/sharepoint
```
```bash pnpm
pnpm install corsair @corsair-dev/sharepoint
```
```bash bun
bun add corsair @corsair-dev/sharepoint
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { sharepoint } from '@corsair-dev/sharepoint';

export const corsair = createCorsair({
	plugins: [
		sharepoint({
			authType: 'managed',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="Managed OAuth (Recommended)">

No setup required. Corsair hosts the OAuth app for **SharePoint** — your tenants connect through Hub when they sign in.

```ts
sharepoint({
	authType: 'managed',
})
```

More: [Managed OAuth](/concepts/auth#managed)

</Tab>
<Tab title="OAuth 2.0">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your SharePoint OAuth app.

```ts
sharepoint()
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'sharepoint',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`contentTypes.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.sharepoint.api.contentTypes.get({});
```


**`contentTypes.addFieldLink`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.sharepoint.api.contentTypes.addFieldLink({});
```


See the full list on the [API](/plugins/sharepoint/api) page.

## Query synced data

Synced entities support `tenant.sharepoint.db.<entity>.search()` and `.list()`: `files`, `folders`, `items`, `lists`, `sites`, `users`.

See [Database](/plugins/sharepoint/database) for filters and operators.

## Webhooks

This plugin registers **1** webhook event type. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/sharepoint/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
