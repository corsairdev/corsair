### create

`browser.create`

Acquire a browser session with optional guardrails: https://developers.cloudflare.com/api/resources/browser_rendering/subresources/devtools/subresources/browser/methods/create/.

**Risk:** `destructive`

```ts
await corsair.cloudflarebrowserrendering.api.browser.create({
	accountId: 'acct-123',
	keepAlive: 60000,
	lab: true,
	liveViewUrlExpiresInMs: 120000,
	recording: true,
	targets: true,
	guardrails: {
		allowedDomains: ['example.com'],
	},
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `accountId` | `string` | Yes | — |
| `keepAlive` | `number` | No | — |
| `lab` | `boolean` | No | — |
| `liveViewUrlExpiresInMs` | `number` | No | — |
| `recording` | `boolean` | No | — |
| `targets` | `boolean` | No | — |
| `guardrails` | `object` | No | — |

<AccordionGroup>
<Accordion title="guardrails full type">

```ts
{
  allowedDomains?: string[],
  allowedDomainSets?: string[]
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `sessionId` | `string` | Yes | — |
| `webSocketDebuggerUrl` | `string` | No | — |
