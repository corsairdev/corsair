## Destinations

### create

`destinations.create`

Create a Destination from a catalog metadata id, a source id and its settings; it starts receiving data once enabled

**Risk:** `write`

```ts
await corsair.segment.api.destinations.create({ sourceId: 'qQEHquLrjRDN9j1ByrChyn', metadataId: '5gPpjD6ikn', settings: {} });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `sourceId` | `string` | Yes | The Source to connect this Destination to. |
| `metadataId` | `string` | Yes | Id of the Destination metadata, from `catalog.listDestinations`. |
| `enabled` | `boolean` | No | Defaults to true. |
| `name` | `string` | No | Display name. |

## Regulations

### create

`regulations.create`

Start a deletion or suppression run that permanently removes the named users data from Segment and downstream systems; cannot be cancelled or undone

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.segment.api.regulations.create({ regulationType: 'DELETE_ONLY', subjectType: 'USER_ID', subjectIds: ['user_123'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
