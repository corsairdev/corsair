## Generations

### createVideo

`generations.createVideo`

Transform a static image into a video using AI motion generation (consumes AI credits)

**Risk:** `destructive`

```ts
await corsair.imgix.api.generations.createVideo({ url: 'https://your-subdomain.imgix.net/mountain.jpg', prompt: 'Slow cinematic pan across a mountain vista' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | — |
| `model` | `auto \| klingai \| veo3.1 \| veo3.1-fast` | No | — |
| `prompt` | `string` | No | — |
| `duration` | `number` | No | — |
| `aspect_ratio` | `16:9 \| 9:16` | No | — |

Asynchronously transforms an image into a video using AI motion generation. The image must be on an imgix Source with Image to Video enabled. Poll generations.getVideoJob with the returned data.id every 5 to 10 seconds until data.attributes.status is ready (video at data.attributes.result.url) or errored.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="data full type">

{

  attributes: {
    status: string,
    created_at?: number | null,
    updated_at?: number | null,
    result?: {
      url?: string | null
    } | null,
