## Annotations

### create

`annotations.create`

Create a chart annotation marking an event on a date

**Risk:** `write`

```ts
await corsair.mixpanel.api.annotations.create({ date: '2026-04-01 09:00:00', description: 'Pricing page launched' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `date` | `string` | Yes | When, as "YYYY-MM-DD HH:mm:ss" in the project timezone. |
| `description` | `string` | Yes | — |
| `tags` | `number[]` | No | Annotation tag ids. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string \| null` | No | — |
| `results` | `object \| null` | No | — |

<AccordionGroup>

  id?: number | null,

cannot double-count. With the default `strict: '1'` a 400 lists the
rejected events in `failed_records`; the error quotes the first message.
