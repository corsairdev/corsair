Use **Mixpanel** through Corsair: one client, typed API calls.

Create a service account in Mixpanel under Organization settings, Service
Accounts (or Project settings, Service Accounts), with a role that can read
the project; importing events needs the Owner or Admin role. The account
stores three things: the service account username, the service account
secret, and the project id, which every service-account request must carry.
The region option switches hosts for EU (`eu`) and India (`in`) data
residency projects; it defaults to `us`.

- **Requests authenticate with HTTP Basic** using the plain `username:secret`
  pair, exactly as Mixpanel's docs show. A missing project id fails before
  anything is sent, because the API would answer 401 and read like a bad
  secret.
- **events.import is the server-side ingestion call.** It replaces `/track`,
  which this plugin does not wrap: `/track` authenticates with the project
  token meant for untrusted clients, while `/import` takes the service
  account and accepts events older than five days. Every event needs `time`,
  `distinct_id` and `$insert_id`; Mixpanel deduplicates on the three plus the
  event name, so a retried batch cannot double-count. With the default
  `strict: '1'`, a 400 body lists each rejected event in `failed_records`.
- **Profile updates are not wrapped.** The ingestion `/engage` property
  setters authenticate with the project token, not a service account, so this
  plugin reads profiles (`profiles.query`) but does not write them.
- **profiles.query pages by session.** Take `session_id` and `page` from one
  response, keep the `where` expression unchanged, and stop when `next_page`
  comes back null.
- **Funnels and Segmentation queries are in maintenance mode** per
  Mixpanel's docs, so this plugin wraps only `funnels.list` (saved funnels)
  and the Insights query for report data. Raw events come from
  `export.events`, one request per date range with an optional `limit`.
- **Rate limits.** The query API allows 60 queries per hour and 5 concurrent;
  the export API allows 60 per hour and 3 per second; ingestion allows about
  30k events per second or 2 GB per minute. The plugin retries 429, 502 and
  503 with exponential backoff (honouring Retry-After when sent) and never
  retries 400 validation failures.

**What you get:**

- 7 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/mixpanel better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/mixpanel better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/mixpanel better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/mixpanel better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { mixpanel } from '@corsair-dev/mixpanel';

export const corsair = createCorsair({
	plugins: [
		mixpanel(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Create a service account in Mixpanel (Organization settings, Service Accounts; importing events needs the Owner or Admin role) and store three fields on the account: `service_account_username`, `service_account_secret` and `project_id`. For EU or India residency projects, also set the `region` option to `eu` or `in`.

```sh
pnpm corsair setup --plugin=mixpanel --tenant=acme service_account_username=<username> service_account_secret=<secret> project_id=<project-id>
```

Or pass them as plugin options (`serviceAccountUsername`, `serviceAccountSecret`, `projectId`, `region`). Requests authenticate with HTTP Basic using the plain `username:secret` pair. See [API key auth](/concepts/api-key).

```ts
mixpanel({ region: 'eu' })
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'mixpanel',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List saved cohorts**

```ts
const tenant = corsair.withTenant('acme');
await tenant.mixpanel.api.cohorts.list({});
```


**Import a signed-up event**

```ts
const tenant = corsair.withTenant('acme');
await tenant.mixpanel.api.events.import({
	events: [{
		event: 'Signed up',
		properties: {
			time: 1618716477000,
			distinct_id: '91304156-cafc-4673-a237-623d1129c801',
			$insert_id: '29fc2962-6d9c-455d-95ad-95b84f09b9e4',
			Referred by: 'Friend',
		},
	}],
});
```
