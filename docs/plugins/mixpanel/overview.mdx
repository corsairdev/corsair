Use **Mixpanel** through Corsair: one client, typed API calls.

Create a service account in Mixpanel (Project Settings, Service Accounts)
with a role that fits what the agent should do: Consumer to read, Admin or
Owner to import events and manage annotations, Lexicon, flags and
experiments. Connect with:

- **api_key**: the service account secret.
- **service_account_username**: its username (`name.xxxxxx.mp-service-account`).
- **project_id**: the project id (Project Settings, Overview).
- **region**: `us` (default), `eu` or `in`, matching the project's data
  residency. Every API switches to that region's hosts.
- **project_token** (optional): needed for `events.track`, profile and group
  updates, identity calls and GDPR, which authenticate with the token.
- **gdpr_token** (optional): the GDPR API OAuth token from Personal Settings,
  Data & Privacy. A service account gets 401 on the GDPR API.

Plan limits seen on a free project (11-24): the Query API reports
(insights, funnels, retention, segmentation, event counts, activity stream,
cohorts, JQL) answer 402 `plan_restricted`; `profiles.query` and raw export
work. Data Pipelines is a paid add-on (401), and the Platform API data
definitions answer 404 until Mixpanel enables them for the project.
Organization-level service account calls need an organization admin or
owner service account (403 otherwise).

- **Rate limits.** The Query API allows 60 queries per hour and 5 at once;
  raw export 60 per hour and 3 per second. Core retries a 429 using
  Retry-After; nothing else is retried.
- **Errors** come back as core `ApiError`s with Mixpanel's message and
  `error_code`. Request bodies (tokens, profiles, events) are stripped from
  the error, and secrets Mixpanel echoes are redacted.

**What you get:**

- 119 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/mixpanel better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/mixpanel better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/mixpanel better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/mixpanel better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { mixpanel } from '@corsair-dev/mixpanel';

export const corsair = createCorsair({
	plugins: [
		mixpanel(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Mixpanel API key before the first call: `pnpm corsair setup --plugin=mixpanel --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
mixpanel()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'mixpanel',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Find profiles on a plan**

```ts
const tenant = corsair.withTenant('acme');
await tenant.mixpanel.api.profiles.query({
	where: 'properties["plan"] == "pro"',
	output_properties: ['$email', 'plan'],
});
```


**Import a signed-up event**

```ts
const tenant = corsair.withTenant('acme');
await tenant.mixpanel.api.events.import({
	events: [{
		event: 'Signed up',
		properties: {
			time: 1618716477000,
			distinct_id: '91304156-cafc-4673-a237-623d1129c801',
			$insert_id: '29fc2962-6d9c-455d-95ad-95b84f09b9e4',
			referrer: 'friend',
		},
	}],
});
```
