Use **Gemini** through Corsair: one client, typed API calls, optional local DB sync.

**What you get:**

- 8 typed API operations

## Setup

<Steps>

<Step title="Install">
```bash
pnpm install @corsair-dev/gemini
```

</Step>

<Step title="Add the plugin">
<Tabs>
<Tab title="Solo">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { gemini } from '@corsair-dev/gemini';

export const corsair = createCorsair({
	// ... other config options,
	multiTenancy: false,
    plugins: [gemini()],
});
```
</Tab>
<Tab title="Multi-Tenant">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { gemini } from '@corsair-dev/gemini';

export const corsair = createCorsair({
	// ... other config options,
    multiTenancy: true,
    plugins: [gemini()],
});
```

See [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Tab>
</Tabs>

</Step>

<Step title="Get credentials">
Follow [Get Credentials](/plugins/gemini/get-credentials) if you need help getting keys.

</Step>

<Step title="Store credentials">
<Tabs>
<Tab title="Solo">
```bash
pnpm corsair setup --plugin=gemini
```

Use the key names documented in [Get Credentials](/plugins/gemini/get-credentials) (for example `api_key=`, `bot_token=`, or OAuth client fields).
</Tab>
<Tab title="Multi-Tenant">
```bash
pnpm corsair setup --plugin=gemini --tenant=<tenantId>
```

Store per-tenant secrets after you create the tenant record. See [Multi-tenancy](/concepts/multi-tenancy).
</Tab>
</Tabs>

</Step>

</Steps>

## Authentication

Each tab shows how to register the plugin for that authentication method. The default `authType` from the plugin does not need to appear in the factory call.

<Tabs>
<Tab title="API Key (Default)">

```ts corsair.ts
gemini()
```

Store credentials with `pnpm corsair setup --plugin=gemini` (see [Get Credentials](/plugins/gemini/get-credentials) for field names). For OAuth, you typically store integration keys at the provider level and tokens per account or tenant.

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>



## Example API calls

**Read-style (read):** `content.countTokens`

```ts
await corsair.gemini.api.content.countTokens({
    model: 'example',
    contents: [],
});
```


**Write-style (write):** `images.generateImage`



```ts
await corsair.gemini.api.images.generateImage({
    model: 'example',
    prompt: 'example',
});
```


See the full list on the [API](/plugins/gemini/api) page. Use `pnpm corsair list --plugin=gemini` and `pnpm corsair schema <path>` locally to inspect schemas.
