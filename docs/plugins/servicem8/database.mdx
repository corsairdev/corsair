---
title: "ServiceM8 database"
sidebarTitle: "Database"
description: "The ServiceM8 plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for ServiceM8. To read its data, call the [API operations](/plugins/servicem8/api), which return what ServiceM8 has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
