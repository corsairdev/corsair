---
title: "Google Photos database"
sidebarTitle: "Database"
description: "The Google Photos plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Google Photos. To read its data, call the [API operations](/plugins/googlephotos/api), which return what Google Photos has at that moment.

</Info>
