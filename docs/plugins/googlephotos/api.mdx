## Albums

### addEnrichment

`albums.addEnrichment`

Add a text note or a location to an app-created album, at a chosen position

**Risk:** `write`

```ts
await corsair.googlephotos.api.albums.addEnrichment({ albumId: 'ABcDeFgHiJkLmNoP', text: 'Day one' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `albumId` | `string` | Yes | An album id from albums.create or albums.list |
| `text` | `string \| null` | No | A text note to add |
| `location` | `object \| null` | No | — |
| `position` | `object` | No | — |

<AccordionGroup>
<Accordion title="location full type">

```ts
{
  locationName?: string | null,
  latlng?: {
    latitude: number,
    longitude: number
  } | null
} | null
```
</Accordion>

<Accordion title="position full type">

```ts
{
  position: POSITION_TYPE_UNSPECIFIED | FIRST_IN_ALBUM | LAST_IN_ALBUM | AFTER_MEDIA_ITEM | AFTER_ENRICHMENT_ITEM,
  relativeMediaItemId?: string | null,
  relativeEnrichmentItemId?: string | null
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `enrichmentItem` | `object \| null` | No | The new enrichment, named by its id |

<AccordionGroup>
<Accordion title="enrichmentItem full type">

```ts
{
  id?: string | null
} | null
```
</Accordion>
</AccordionGroup>

`albums.batchAddMediaItems`

Add up to 50 media items to an app-created album

**Risk:** `write`

```ts
await corsair.googlephotos.api.albums.batchAddMediaItems({ albumId: 'ABcDeFgHiJkLmNoP', mediaItemIds: ['AbCdEf123'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `albumId` | `string` | Yes | An album id from albums.create or albums.list |
| `mediaItemIds` | `string[]` | Yes | 1 to 50 ids per call |



**Output:** _empty object_

| `mediaItemIds` | `string[]` | Yes | 1 to 50 ids per call |

### list

`albums.list`

List the account's albums. Without a scope Google removed in 2025, only app-created albums are readable

**Risk:** `read`

```ts
await corsair.googlephotos.api.albums.list({ pageSize: 20 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `pageSize` | `number \| null` | No | 1 to 50. The API default is 20 |
| `pageToken` | `string \| null` | No | nextPageToken from a previous page of the same call |
| `excludeNonAppCreatedData` | `boolean \| null` | No | Leave out albums the app did not create. Reads of the user's whole library need a scope Google removed in April 2025, so this is effectively the only data a current scope can see |

Only albums this app created are readable; the wide-read scope was removed in 2025.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `albums` | `object[] \| null` | No | Absent when the account has no albums |
| `nextPageToken` | `string \| null` | No | — |

### create

`mediaItems.create`

Upload bytes and create up to 50 media items, optionally in an album; uploads count toward the user's Google storage past 25MB

**Risk:** `write`

```ts
await corsair.googlephotos.api.mediaItems.create({ newMediaItems: [{ fileName: 'beach.jpg', contentType: 'image/jpeg', bytes: '<base64>' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `newMediaItems` | `object[]` | Yes | 1 to 50 items per call; the API refuses more |
| `albumId` | `string \| null` | No | Also add the items to this album, which must be app-created |
| `albumPosition` | `object \| null` | No | — |

Bytes are base64. The endpoint uploads them, then creates up to 50 items from the returned tokens.

### search

`mediaItems.search`

Search the library with date, content, feature and media-type filters, or list one album

**Risk:** `read`

```ts
await corsair.googlephotos.api.mediaItems.search({ albumId: 'ABcDeFgHiJkLmNoP', pageSize: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `albumId` | `string \| null` | No | Search inside one album. Cannot be combined with filters |
| `filters` | `object \| null` | No | — |
| `orderBy` | `MediaMetadata.creation_time desc \| MediaMetadata.creation_time \| null` | No | Only usable with a date filter. `desc` is newest first, which is also the default |
| `pageSize` | `number \| null` | No | 1 to 100. The API default is 25 |
| `pageToken` | `string \| null` | No | nextPageToken from a previous page of the same call |

Send `albumId` or `filters`, never both; the API answers 400 for that combination.
