---
title: "Zoho CRM database"
sidebarTitle: "Database"
description: "The Zoho CRM plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Zoho CRM. To read its data, call the [API operations](/plugins/zohocrm/api), which return what Zoho CRM has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
