## Apps

### limits

`apps.limits`

Get the monthly message limit and remaining quota

**Risk:** `read`

```ts
await corsair.pushover.api.apps.limits({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `1` | Yes | — |
| `request` | `string` | Yes | — |
| `limit` | `number` | Yes | — |
| `remaining` | `number` | Yes | — |
| `reset` | `number` | Yes | — |
