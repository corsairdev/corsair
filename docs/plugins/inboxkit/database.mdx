The InboxKit plugin syncs data locally. Use `corsair.inboxkit.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Domains

Path: `inboxkit.db.domains.search`

```ts
const rows = await corsair.inboxkit.db.domains.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `name` | `string` | equals, contains, startsWith, endsWith, in |
| `status` | `string` | equals, contains, startsWith, endsWith, in |
| `workspace_uid` | `string` | equals, contains, startsWith, endsWith, in |
| `connection_type` | `string` | equals, contains, startsWith, endsWith, in |
| `dns_propagation_status` | `string` | equals, contains, startsWith, endsWith, in |
| `nameserver_match_status` | `string` | equals, contains, startsWith, endsWith, in |
| `forwarding_url` | `string` | equals, contains, startsWith, endsWith, in |
| `renewal_date` | `string` | equals, contains, startsWith, endsWith, in |
| `renewal_status` | `string` | equals, contains, startsWith, endsWith, in |
| `assigned_mailboxes` | `number` | equals, gt, gte, lt, lte, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
