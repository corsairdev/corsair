## Billing

### addCredits

`billing.addCredits`

SPENDS MONEY. Buy wallet credits. With direct_charge the saved card is charged at once; otherwise this returns a hosted checkout link.

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.inboxkit.api.billing.addCredits({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `credits` | `number` | Yes | Amount in USD to add to the wallet. $1 = 1 credit. |
| `direct_charge` | `boolean` | No | When `true`, charges the team's default payment method immediately (off-session) and applies credits synchronously. Returns Stripe decline details with HTTP 402 on failure. |
| `guest_mode` | `boolean` | No | When `true`, returns a white-label Checkout link suitable for sharing with an end user. The team's email is hidden on the Checkout page and the payer's card is not saved. Requires `success_url`. Default false. |
| `success_url` | `string` | No | Required when `guest_mode` is `true`. Full URL the payer is redirected to after successful payment. Ignored in other modes. |
| `cancel_url` | `string` | No | Full URL the payer is redirected to if they cancel the Checkout. Defaults to `success_url` when omitted. Only used in `guest_mode`. |
| `redirect_url` | `string` | No | Internal redirect path appended to the default hosted-checkout return URL. Hosted-checkout mode only; ignored in `guest_mode` and `direct_charge`. |

Spends money. With `direct_charge: true` the saved card is charged at once and the credits are there when this returns. Otherwise it returns a hosted checkout link; follow it with `billing.getPaymentStatus`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `error` | `boolean \| null` | No | Always `false` on success. |
| `message` | `string \| null` | No | — |
| `payment_link` | `string \| null` | No | Stripe Checkout URL. Valid for 24 hours. |
| `session_id` | `string \| null` | No | Stripe Checkout session ID. Pass to `GET /v1/api/billing/wallet/status` to poll payment status. |

### initiate

`clientIdRequests.initiate`

Authorize an app's client ID on a domain, as a trusted app or with domain-wide delegation on Google, or tenant-wide consent on Microsoft. This can give the app access to every mailbox on the domain. The domain needs an admin mailbox.

**Risk:** `destructive`

```ts
await corsair.inboxkit.api.clientIdRequests.initiate({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `workspaceId` | `string` | No | Which workspace, as a uid from workspaces.list. Leave out to use the plugin's workspaceId option or, failing that, the team's only workspace. |
| `domain` | `string` | Yes | Domain name the client ID is authorized on. Must exist in your workspace and have an admin mailbox. |
| `client_id` | `string` | Yes | The app to authorize. On GOOGLE, the OAuth 2.0 client ID (numeric, or ending in .apps.googleusercontent.com). On MICROSOFT/AZURE, the Entra application id, which is a GUID. |
| `request_data` | `Record<string, any>` | No | Optional metadata or additional data for the request |
| `delegated` | `boolean` | No | GOOGLE only. When false (default) the client ID is marked as a trusted app in Google Admin; when true it is registered under domain-wide delegation with the scopes given. |
| `scopes` | `string[]` | No | Delegated OAuth scopes to grant - permissions that apply when a signed-in user acts through the app. |
| `platform` | `GOOGLE \| MICROSOFT \| AZURE` | No | Which platform this client ID is for. Only needed when the domain has admin mailboxes on more than one platform - otherwise the platform is read from the domain's admin mailbox and a value that contradicts it is… |
| `app_roles` | `string[]` | No | MICROSOFT/AZURE only. Application permissions to grant, assigned as appRoleAssignments so the app can act as itself with a client-credentials (app-only) token. |

A Microsoft application role such as `Mail.Read` can reach every mailbox in the tenant. Check the client ID, scopes and roles before you call this.



**Output**

|------|------|----------|-------------|
| `error` | `boolean \| null` | No | Indicates if there was an error |
| `message` | `string \| null` | No | Success message |
| `data` | `object \| null` | No | — |

### create

**Risk:** `write`
