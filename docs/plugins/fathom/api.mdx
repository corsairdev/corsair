## Account

### get

`account.get`

Retrieve information about the account that owns the API key

**Risk:** `read`

```ts
await corsair.fathom.api.account.get({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number \| string` | Yes | — |
| `object` | `account` | Yes | — |
| `name` | `string` | Yes | — |
| `email` | `string` | Yes | — |



---

## Reports

### aggregation

`reports.aggregation`

Generate custom aggregation reports across pageviews or events

**Risk:** `read`

```ts
await corsair.fathom.api.reports.aggregation({ entity: 'pageview', entity_id: 'CDBUGS', aggregates: 'pageviews,visits,uniques' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `entity` | `pageview \| event` | Yes | — |
| `entity_id` | `string` | No | — |
| `site_id` | `string` | No | — |
| `entity_name` | `string` | No | — |
| `aggregates` | `string` | Yes | — |
| `date_grouping` | `hour \| day \| month \| year` | No | — |
| `field_grouping` | `string` | No | — |
| `sort_by` | `string` | No | — |
| `date_from` | `string` | No | — |
| `date_to` | `string` | No | — |
| `timezone` | `string` | No | — |
| `limit` | `number` | No | — |
| `filters` | `string \| object[]` | No | — |

<AccordionGroup>
<Accordion title="filters full type">

```ts
string | {
  property: string,
  operator: is | is not | is like | is not like | matching | not matching,
  value: string
}[]
```
</Accordion>
</AccordionGroup>



**Output:** `Record<string, string \| number \| null>[]`


**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `site_id` | `string` | Yes | — |
| `detailed` | `boolean` | No | — |



**Output:** `object`

<AccordionGroup>

```ts
  total: number,
  content?: {
    hostname: string,
    pathname: string,
    total: number
  }[],
  referrers?: {
    referrer_hostname: string,
    referrer_pathname: string,
```
