Use **JumpCloud** through Corsair: one client, typed API calls.

JumpCloud needs an administrator's API key: in the admin console open the profile menu, then **My API Key**. If it says you don't have permission, turn on **Enable API access** for that administrator under Settings → Administrators first.

Two optional settings are stored with the connected account next to the key, or passed to the factory:

```ts
jumpcloud({ key: process.env.JUMPCLOUD_API_KEY, region: 'eu', orgId: '5f0c1b2a3d4e5f6a7b8c9d0e' })
```

- **Region** (`region` account field). `us` (console.jumpcloud.com, the default), `eu` (console.eu.jumpcloud.com) or `in` (console.in.jumpcloud.com). A key only works in its organization's region; a pasted console host is read as its region, and any other value is rejected.
- **Organization** (`org_id` account field). Multi-tenant (MSP) administrators set the 24-character organization ID each call acts on; it is sent as the `x-org-id` header. Leave it empty for a single-organization key.
- **Calls that email or lock out people.** `users.create` emails the new user a welcome or activation link unless `state` is `STAGED`, and `users.update` does the same when it activates a staged user. `users.setPassword`, `expirePassword`, `resetMfa` and `enforceMfa` change how a person signs in. These are all marked destructive.
- **Commands.** `commands.create` needs `user` (the system user to run as) for linux and mac commands; `000000000000000000000000` runs as root. `commands.run` runs the command on every bound system right away.
- **No local data.** Every call returns live data from JumpCloud.

**What you get:**

- 48 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/jumpcloud better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/jumpcloud better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/jumpcloud better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/jumpcloud better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { jumpcloud } from '@corsair-dev/jumpcloud';

export const corsair = createCorsair({
	plugins: [
		jumpcloud(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the JumpCloud API key before the first call: `pnpm corsair setup --plugin=jumpcloud --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
jumpcloud()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'jumpcloud',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`applications.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.jumpcloud.api.applications.get({});
```


**`commands.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.jumpcloud.api.commands.create({});
```


See the full list on the [API](/plugins/jumpcloud/api) page.
