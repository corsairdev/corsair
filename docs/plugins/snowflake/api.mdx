## Statements

### cancel

`statements.cancel`

Cancel a running SQL statement.

**Risk:** `write`

```ts
await corsair.snowflake.api.statements.cancel({ statementHandle: '019c06a4-0000-df4f-0000-00100006589e' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `statementHandle` | `string` | Yes | UUID-shaped handle (8-4-4-4-12 hex). |
| `requestId` | `string` | No | UUID-shaped request ID (8-4-4-4-12 hex). |
| `retry` | `boolean` | No | Requires `requestId`. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `code` | `string` | No | — |
| `sqlState` | `string` | No | — |
| `message` | `string` | No | — |
| `statementHandle` | `string` | Yes | — |
| `statementStatusUrl` | `string` | No | — |
| `createdOn` | `number` | No | — |

### get

`statements.get`

Fetch the status of a statement and one partition of its result.

**Risk:** `read`

```ts
await corsair.snowflake.api.statements.get({ statementHandle: '019c06a4-0000-df4f-0000-00100006589e', partition: 0 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `statementHandle` | `string` | Yes | UUID-shaped handle (8-4-4-4-12 hex). |
| `requestId` | `string` | No | UUID-shaped request ID (8-4-4-4-12 hex). |
| `partition` | `number` | No | Partition index, starting at 0. |
| `retry` | `boolean` | No | Requires `requestId`. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `code` | `string` | No | — |
| `sqlState` | `string` | No | — |
| `message` | `string` | No | — |
| `statementHandle` | `string` | Yes | — |
| `statementHandles` | `string[]` | No | — |
| `createdOn` | `number` | No | — |
| `statementStatusUrl` | `string` | No | — |
| `resultSetMetaData` | `object` | No | — |
| `data` | `(string \| null)[][]` | No | Rows. Each cell is a string or null. |
| `stats` | `object` | No | — |

### submit

`statements.submit`

Submit SQL for execution. Returns rows, a handle while the statement is still running, or DML stats.

**Risk:** `destructive`

```ts
await corsair.snowflake.api.statements.submit({ statement: 'SELECT 1', timeout: 10, warehouse: 'COMPUTE_WH' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `requestId` | `string` | No | UUID-shaped request ID (8-4-4-4-12 hex). |
| `async` | `boolean` | No | Return the handle immediately when true. |
| `nullable` | `boolean` | No | `false` returns SQL NULL as the string `"null"`. |
| `retry` | `boolean` | No | Requires `requestId`. Set `true` with the `requestId` of the original request to resubmit it; Snowflake does not run it twice. A new `requestId` runs the statement again. |
| `statement` | `string` | Yes | — |
| `timeout` | `number` | No | — |
| `database` | `string` | No | — |
| `schema` | `string` | No | — |
| `warehouse` | `string` | No | — |
| `role` | `string` | No | — |
| `bindings` | `object` | No | — |
| `parameters` | `object` | No | — |

`parameters.client_result_chunk_size` is in megabytes, from 16 to 160.
