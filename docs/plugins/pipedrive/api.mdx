## Deals

### create

`deals.create`

Create a deal

**Risk:** `write`

```ts
await corsair.pipedrive.api.deals.create({ title: 'Sample opportunity' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `title` | `string` | Yes | — |
| `owner_id` | `number` | No | — |
| `person_id` | `number \| null` | No | — |
| `org_id` | `number \| null` | No | — |
| `pipeline_id` | `number` | No | — |
| `stage_id` | `number` | No | — |
| `value` | `number` | No | — |
| `currency` | `string` | No | — |
| `is_archived` | `boolean` | No | — |
| `archive_time` | `string \| null` | No | — |
| `status` | `string` | No | — |
| `probability` | `number` | No | — |
| `lost_reason` | `string` | No | — |
| `visible_to` | `number` | No | — |
| `close_time` | `string` | No | — |
| `won_time` | `string` | No | — |
| `lost_time` | `string` | No | — |
| `expected_close_date` | `string` | No | — |
| `label_ids` | `number[]` | No | — |
| `channel` | `number \| null` | No | — |
| `channel_id` | `string \| null` | No | — |
| `origin_id` | `string \| null` | No | — |
| `custom_fields` | `Record<string, any>` | No | — |

API-token authentication is sent using Pipedrive's documented x-api-token header. OAuth 2.0 uses a Bearer access token and requires deals:full. The documented API token cost is 5 tokens.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | No | — |
| `data` | `object` | No | — |

### list

`deals.list`

List deals with cursor pagination and filters

**Risk:** `read`

```ts
await corsair.pipedrive.api.deals.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `filter_id` | `number` | No | — |
| `ids` | `number[]` | No | — |
| `owner_id` | `number` | No | — |
| `person_id` | `number` | No | — |
| `org_id` | `number` | No | — |
| `pipeline_id` | `number` | No | — |
| `stage_id` | `number` | No | — |
| `status` | `(open \| won \| lost \| deleted)[]` | No | — |
| `updated_since` | `string` | No | — |
| `updated_until` | `string` | No | — |
| `sort_by` | `id \| update_time \| add_time` | No | — |
| `sort_direction` | `asc \| desc` | No | — |
| `include_fields` | `(next_activity_id \| last_activity_id \| first_won_time \| products_count \| files_count \| notes_count \| followers_count \| email_messages_count \| activities_count \| done_activities_count \| undone_activities_count \| participants_count \| last_incoming_mail_time \| last_outgoing_mail_time \| smart_bcc_email \| source_lead_id)[]` | No | — |
| `custom_fields` | `string[]` | No | — |
| `include_option_labels` | `boolean` | No | — |
| `include_labels` | `boolean` | No | — |
| `limit` | `number` | No | — |
| `cursor` | `string` | No | — |

The list operation forwards Pipedrive's opaque cursor and returns additional_data.next_cursor; pass that value as cursor to request the next page. List array query parameters are serialized as comma-separated values as required by the OpenAPI form/explode=false contract. Its documented API token cost is 10 tokens.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | No | — |
| `data` | `object[]` | No | — |
| `additional_data` | `object` | No | — |
