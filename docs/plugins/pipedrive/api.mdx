## Activities

### create

`activities.create`

Create a calendar activity

**Risk:** `write`

```ts
await corsair.pipedrive.api.activities.create({ subject: 'Follow up', type: 'call' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `subject` | `string` | No | — |
| `type` | `string` | No | — |
| `owner_id` | `number` | No | — |
| `deal_id` | `number` | No | — |
| `lead_id` | `string` | No | — |
| `org_id` | `number` | No | — |
| `project_id` | `number` | No | — |
| `due_date` | `string` | No | — |
| `due_time` | `string` | No | — |
| `duration` | `string` | No | — |
| `busy` | `boolean` | No | — |
| `done` | `boolean` | No | — |
| `location` | `object` | No | — |
| `participants` | `object[]` | No | — |
| `attendees` | `object[]` | No | — |
| `public_description` | `string` | No | — |
| `priority` | `number` | No | — |
| `outcome` | `number \| null` | No | — |
| `note` | `string` | No | — |

OAuth requires activities:full. All request properties are optional in the v2 schema. Use participants to set the person; the response data is an activity object. The documented API token cost is 5 tokens.
