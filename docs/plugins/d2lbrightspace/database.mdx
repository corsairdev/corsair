---
title: "D2L Brightspace database"
sidebarTitle: "Database"
description: "The D2L Brightspace plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for D2L Brightspace. To read its data, call the [API operations](/plugins/d2lbrightspace/api), which return what D2L Brightspace has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
