### updateXml

`artifactConfigurations.updateXml`

Replace an artifact configuration's XML; SignPath does not merge it, and existing signing requests keep the version they captured

**Risk:** `write`

```ts
await corsair.signpath.api.artifactConfigurations.updateXml({ projectSlug: 'my-app', artifactConfigurationSlug: 'default', artifactConfigurationXml: '<artifact-configuration xmlns="http://signpath.io/artifact-configuration"><pe-file><file-path>app.exe</file-path></pe-file></artifact-configuration>' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `projectSlug` | `string` | Yes | — |
| `artifactConfigurationSlug` | `string` | Yes | — |
| `artifactConfigurationXml` | `string` | Yes | The complete replacement document. SignPath does not merge it. |

The whole document is replaced. Existing signing requests keep the configuration they captured when they were submitted.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `projectSlug` | `string` | Yes | — |
| `artifactConfigurationSlug` | `string` | Yes | — |
| `success` | `true` | Yes | — |

### create

`projects.create`

Create a project with an artifact configuration; the project starts inactive, so activate it before submitting signing requests

**Risk:** `write`

```ts
await corsair.signpath.api.projects.create({ name: 'My App', slug: 'my-app', artifactConfigurationXml: '<artifact-configuration xmlns="http://signpath.io/artifact-configuration"><pe-file id="app"><file-path>app.exe</file-path></pe-file></artifact-configuration>' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `slug` | `string` | Yes | Unique within the organization; used in every project path. |
| `description` | `string` | No | — |
| `readerIds` | `string[]` | No | Interactive users, CI users or groups allowed to read the project. |
| `configuratorIds` | `string[]` | No | Participants allowed to change the project. |
| `repositoryUrls` | `string[]` | No | — |
| `artifactConfigurationXml` | `string` | Yes | The artifact configuration itself, as XML. A project needs one. |

artifactConfigurationXml is required. SignPath rejects a project without one, so send the configuration you want on day one.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `slug` | `string` | Yes | — |
| `created` | `true` | Yes | — |
| `artifactConfigurationXml` | `string` | Yes | Echoed back from the input. |
