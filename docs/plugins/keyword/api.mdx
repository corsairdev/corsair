## Keywords

### add

`keywords.add`

Add keywords to a project, each with its domain, region and language. Adding a keyword already tracked returns the existing one

**Risk:** `write`

```ts
await corsair.keyword.api.keywords.add({ projectName: 'Disney', keywords: [{ kw: 'Jungle Book', url: 'disney.com', region: 'google.com', language: 'en', url_tracking_method: 'broad' }] });
```

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `projectName` | `string` | Yes | The project (group) name, such as `Disney`. A subproject is written `Parent[sub]Child`. |
| `keywords` | `object[]` | Yes | — |

Adding a keyword the project already tracks returns the existing one rather than an error.

### refresh

`keywords.refresh`

Queue keywords for an on-demand rank check; spends the plan’s daily refresh quota. The whole request is refused if the quota would be exceeded

**Risk:** `destructive`

```ts
await corsair.keyword.api.keywords.refresh({ keywordIds: ['267540882', '267540883'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `keywordIds` | `(string \| number)[]` | Yes | Queued for an on-demand check. The whole request is refused if it would exceed the plan’s daily refresh quota. |

Spends the plan’s daily on-demand refresh quota. The whole request is refused when it would be exceeded.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `message` | `string` | Yes | How many refreshes the plan has left. |
