Use **ERPNext** through Corsair: one client, typed API calls, local DB sync.

Authenticate with a Frappe token pair: `Authorization: token <api_key>:<api_secret>`, created per user under Settings > My Settings > API Access. Every ERPNext deployment is its own site, so a token only works on the site that issued it. When credentials are configured explicitly, set the matching `baseUrl` beside them. When credentials come from a connected account, that account must also store its matching `base_url`; requests do not fall back to the plugin option.

This plugin implements the requested 51 operations over the generic Frappe REST surface. Inbound webhooks are not included.

**What you get:**

- 51 typed API operations
- 1 synced entity (`documents`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/erpnext better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/erpnext better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/erpnext better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/erpnext better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { erpnext } from '@corsair-dev/erpnext';

export const corsair = createCorsair({
	plugins: [
		erpnext({
			baseUrl: 'https://yourcompany.frappe.cloud',
		}),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

Use `baseUrl` only with explicitly configured credentials for that same site. Connected accounts require their own `base_url` alongside the stored API key and secret.

```ts
erpnext({
	baseUrl: 'https://yourcompany.frappe.cloud',
})
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'erpnext',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Search customers**

```ts
const tenant = corsair.withTenant('acme');
await tenant.erpnext.api.desk.searchGlobal({ doctype: 'Customer', txt: 'Acme', page_length: 10 });
```


**Add a customer comment**

```ts
const tenant = corsair.withTenant('acme');
await tenant.erpnext.api.desk.addComment({
	body: {
		reference_doctype: 'Customer',
		reference_name: 'CUST-0001',
		content: 'Follow-up scheduled for Friday.',
		comment_email: 'agent@example.com',
		comment_by: 'Corsair Agent',
	},
});
```


See the full list on the [API](/plugins/erpnext/api) page.
