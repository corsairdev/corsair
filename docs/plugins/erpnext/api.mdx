### searchGlobal

`desk.searchGlobal`

Search a DocType by text across its searchable fields, with optional custom search method, filters, and result limit

**Risk:** `read`

```ts
await corsair.erpnext.api.desk.searchGlobal({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `doctype` | `string` | Yes | — |
| `txt` | `string` | Yes | — |
| `query` | `string` | No | Name of a whitelisted method implementing a custom search for the DocType; defaults to the standard search |
| `filters` | `string` | No | JSON string filter expression in Frappe list format, for example [["customer_type","=","Company"]], passed verbatim |
| `page_length` | `number` | No | Maximum number of result rows to return |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `message` | `any[]` | Yes | — |
