Use **Uniswap** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 8 typed API operations
- 5 synced entities (`approval`, `gaslessOrder`, `quote`, `swapStatus`, `token`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/uniswapapi
```
```bash yarn
yarn add corsair @corsair-dev/uniswapapi
```
```bash pnpm
pnpm install corsair @corsair-dev/uniswapapi
```
```bash bun
bun add corsair @corsair-dev/uniswapapi
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { uniswapapi } from '@corsair-dev/uniswapapi';

export const corsair = createCorsair({
	plugins: [
		uniswapapi(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
uniswapapi()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'uniswapapi',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`approval.check`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.uniswapapi.api.approval.check({});
```


**`swap.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.uniswapapi.api.swap.create({});
```


See the full list on the [API](/plugins/uniswapapi/api) page.

## Query synced data

Synced entities support `tenant.uniswapapi.db.<entity>.search()` and `.list()`: `approval`, `gaslessOrder`, `quote`, `swapStatus`, `token`.

See [Database](/plugins/uniswapapi/database) for filters and operators.
