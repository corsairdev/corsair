Use **NeuronWriter** through Corsair: one client, typed API calls, local DB sync.

The key is the X-API-KEY header. An invalid key on import content returned HTTP 401. The HTML and the source URL are not stored.

**What you get:**

- 1 typed API operations
- 1 synced entity (`imports`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/neuronwriter better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/neuronwriter better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/neuronwriter better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/neuronwriter better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { neuronwriter } from '@corsair-dev/neuronwriter';

export const corsair = createCorsair({
	plugins: [
		neuronwriter(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the NeuronWriter API key before the first call: `pnpm corsair setup --plugin=neuronwriter --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
neuronwriter()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'neuronwriter',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Import HTML**

```ts
const tenant = corsair.withTenant('acme');
await tenant.neuronwriter.api.content.import({ query: 'abc123', html: '<p>Hello</p>' });
```


**`content.import`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.neuronwriter.api.content.import({});
```


See the full list on the [API](/plugins/neuronwriter/api) page.

## Query synced data

Synced entities support `tenant.neuronwriter.db.<entity>.search()` and `.list()`: `imports`.

See [Database](/plugins/neuronwriter/database) for filters and operators.
