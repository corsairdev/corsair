## Content

### import

`content.import`

Import HTML or a page into a query. The content is not stored.

**Risk:** `write`

```ts
await corsair.neuronwriter.api.content.import({ query: 'abc123', html: '<p>Hello</p>' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | — |
| `html` | `string` | No | — |
| `url` | `string` | No | — |

POST /neuron-api/0.5/writer/import-content. Stores the query id, status, and content score.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `imported` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="imported full type">

```ts
{
  id: string,
  status?: string,
  contentScore?: number
}
```
</Accordion>
</AccordionGroup>
