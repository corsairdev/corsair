## Analysis

### get

`analysis.get`

Poll one analysis: the status alone while it runs, then the target word count, terms, questions and SERP competitors

**Risk:** `read`

```ts
await corsair.neuronwriter.api.analysis.get({ query: '32dee2a89374a722' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | The query id, from analysis.start. |

Answers only a status until it is ready; the metrics, terms, ideas and competitors appear only then.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string` | Yes | — |
| `metrics` | `object \| null` | No | — |
| `terms` | `object \| null` | No | — |
| `terms_txt` | `object \| null` | No | — |
| `ideas` | `object \| null` | No | — |
| `competitors` | `object[] \| null` | No | — |

### start

`analysis.start`

Queue a content analysis for a keyword, spending one Content Writer analysis from the monthly limit; poll analysis.get for the recommendations

**Risk:** `write`

```ts
await corsair.neuronwriter.api.analysis.start({ project: 'c2fe46bce8019bff', keyword: 'trail running shoes', engine: 'google.co.uk', language: 'English', competitors_mode: 'top10' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project` | `string` | Yes | The project id, from the project's URL: app.neuronwriter.com/project/view/&#123;id&#125;. |
| `keyword` | `string` | Yes | The keyword to analyse. |
| `engine` | `string` | Yes | The search engine, e.g. google.co.uk. |
| `language` | `string` | Yes | The content language, e.g. English. |
| `competitors_mode` | `top10 \| top30 \| top-intent` | No | Which competitors to analyse: top10 (the default), top30, or top-intent for up to ten pages matching the dominant intent. |

Spends one Content Writer analysis from the monthly limit, and answers before the recommendations exist.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | — |
| `query_url` | `string \| null` | No | — |
| `share_url` | `string \| null` | No | — |
| `readonly_url` | `string \| null` | No | — |

## Content

### evaluate

`content.evaluate`

Score content against its analysis without saving a revision, so a draft can be checked before it is written back

**Risk:** `read`

```ts
await corsair.neuronwriter.api.content.evaluate({ query: '32dee2a89374a722', url: 'https://example.com/draft', id: 'main-content' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | The query id, from analysis.start. |
| `html` | `string` | No | The HTML to send. |
| `url` | `string` | No | A page to fetch and parse instead of sending HTML. |
| `title` | `string` | No | Overrides the title found in the HTML or page. |
| `description` | `string` | No | Overrides the meta description found in the HTML or page. |
| `id` | `string` | No | The element id holding the content, when importing from a url. |
| `class` | `string` | No | The element class holding the content, when importing from a url. |

Scores the content without saving a revision, so it costs no revision history.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string \| null` | No | — |
| `error` | `string \| null` | No | The reason an import or evaluation failed, when one did. |

### get

`content.get`

Read a query's last saved content revision, or the latest autosave as well

**Risk:** `read`

```ts
await corsair.neuronwriter.api.content.get({ query: '32dee2a89374a722', revision_type: 'all' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | The query id, from analysis.start. |
| `revision_type` | `manual \| all` | No | manual for the last saved revision, all to include autosaves. NetHunt defaults to manual. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `content` | `string \| null` | No | — |
| `title` | `string \| null` | No | — |
| `description` | `string \| null` | No | — |
| `created` | `string \| null` | No | — |
| `type` | `string \| null` | No | — |

### import

`content.import`

Replace the editor content from HTML or a fetched URL, saving it as a new revision

**Risk:** `write`

```ts
await corsair.neuronwriter.api.content.import({ query: '32dee2a89374a722', html: '<h1>Best Trail Running Shoes</h1><p>...</p>' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | The query id, from analysis.start. |
| `html` | `string` | No | The HTML to send. |
| `url` | `string` | No | A page to fetch and parse instead of sending HTML. |
| `title` | `string` | No | Overrides the title found in the HTML or page. |
| `description` | `string` | No | Overrides the meta description found in the HTML or page. |
| `id` | `string` | No | The element id holding the content, when importing from a url. |
| `class` | `string` | No | The element class holding the content, when importing from a url. |

Saves a new revision. Takes html or url, never both.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string \| null` | No | — |
| `error` | `string \| null` | No | The reason an import or evaluation failed, when one did. |

## Queries

### list

`queries.list`

List the queries in a project, filterable by status, source, keyword, language, engine, dates and tags

**Risk:** `read`

```ts
await corsair.neuronwriter.api.queries.list({ project: 'c2fe46bce8019bff', status: 'ready', tags: ['Done'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project` | `string` | Yes | The project id, from the project's URL: app.neuronwriter.com/project/view/&#123;id&#125;. |
| `status` | `not found \| waiting \| in progress \| ready` | No | Only queries in this state. |
| `source` | `neuron \| neuron-api` | No | Only queries created in the app or through the API. |
| `created` | `string` | No | Only queries created at this instant. |
| `updated` | `string` | No | Only queries last updated at this instant. |
| `keyword` | `string` | No | — |
| `language` | `string` | No | — |
| `engine` | `string` | No | — |
| `tags` | `string \| string[]` | No | Only queries carrying these tags. Every tag must be present. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `queries` | `object[]` | Yes | — |

<Accordion title="queries full type">

{
