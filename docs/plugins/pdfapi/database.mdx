---
title: "PDF-API.io database"
sidebarTitle: "Database"
description: "The PDF-API.io plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for PDF-API.io. To read its data, call the [API operations](/plugins/pdfapi/api), which return what PDF-API.io has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
