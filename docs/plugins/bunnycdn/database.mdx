---
title: "bunny.net database"
sidebarTitle: "Database"
description: "The bunny.net plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for bunny.net. To read its data, call the [API operations](/plugins/bunnycdn/api), which return what bunny.net has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
