---
title: "Chaser database"
sidebarTitle: "Database"
description: "The Chaser plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Chaser. To read its data, call the [API operations](/plugins/chaser/api), which return what Chaser has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
