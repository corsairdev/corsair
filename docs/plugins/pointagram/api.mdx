## Players

### create

`players.create`

Create a player with a name and an email or external id; an online player is also invited. A player whose external id already exists is reported as a failure, not created twice

**Risk:** `destructive`

```ts
await corsair.pointagram.api.players.create({ player_name: 'Axl Rose', player_email: 'axl@pointagram.com', player_external_id: '121212', offline: '0' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `player_name` | `string` | Yes | The name shown in Pointagram. |
| `player_email` | `string` | No | Where the invitation goes. |
| `player_external_id` | `string` | No | Your own identifier, kept on the player. |
| `offline` | `boolean \| 0 \| 1 \| 0 \| 1` | No | 1 creates the player without sending an invitation; 0 invites them. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `profile_id` | `string \| number \| null` | No | — |

## Score Series

### addPoints

`scoreSeries.addPoints`

Score points for a player in a score series, optionally with a comment, tags and a transaction reference that makes a repeat call replace the earlier one

**Risk:** `destructive`

```ts
await corsair.pointagram.api.scoreSeries.addPoints({ player_email: 'harry@pointagram.com', scoreseries_id: 180, points: 120, tags: [{ name: 'North' }], source_score_id: 'order-991' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `player_id` | `string \| number` | No | — |
| `player_name` | `string` | No | — |
| `player_email` | `string` | No | — |
| `player_external_id` | `string` | No | — |
| `scoreseries_id` | `string \| number` | No | — |
| `scoreseries_name` | `string` | No | — |
| `points` | `number` | No | How many points to add. Supply this or pointtype_name. |
| `pointtype_name` | `string` | No | A point type scores a fixed number of points; the score series must define it. |
| `source_score_id` | `string` | No | Your transaction reference. Sending it again revokes the earlier transaction and adds a new one, so a retried call does not double-score. |
| `comment` | `string` | No | Shown with the point in the news feed. |
| `score_time` | `string` | No | When the points were scored, if not now. Sent unchanged, so include the offset. |
| `tags` | `object[]` | No | Tags to display with the scored point. |
| `create_player` | `boolean \| 0 \| 1 \| 0 \| 1` | No | 1 creates the player when no player with that id, name, email or external id exists. |
| `create_tags` | `boolean \| 0 \| 1 \| 0 \| 1` | No | 1 creates tags that do not exist yet. |
