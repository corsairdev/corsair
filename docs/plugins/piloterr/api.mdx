## Account

### getJob

`account.getJob`

Poll the status and result of an async job (free)

**Risk:** `read`

```ts
await corsair.piloterr.api.account.getJob({ id: "abc123" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The job_id returned by an endpoint called with is_async=true |

Free; status Queued, Running, CompletedJob, Error, NotFound or BadRequest, with the endpoint answer in result once completed.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | Job ID |
| `success` | `boolean \| null` | No | Whether the job succeeded |
| `status` | `Queued \| Running \| CompletedJob \| Error \| NotFound \| BadRequest \| null` | No | Job state; CompletedJob, Error, NotFound and BadRequest are terminal |
| `endpoint` | `string \| null` | No | Endpoint the job runs |
| `created_at` | `string \| null` | No | Creation timestamp |
| `started_at` | `string \| null` | No | Start timestamp |
| `completed_at` | `string \| null` | No | Completion timestamp |
| `duration_ms` | `number \| null` | No | Duration in milliseconds |
| `progress` | `number \| null` | No | Progress from 0 to 100 |
| `args` | `Record<string, any> \| null` | No | Arguments the job was started with |
| `result` | `any \| null` | No | The endpoint answer, once completed |

### usage

`account.usage`

Read remaining quota, packs, credits and rate limits (free)

**Risk:** `read`

```ts
await corsair.piloterr.api.account.usage({});
```

**Input:** _empty object_

Free; remaining spans subscription quota, one-time packs and credits.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `remaining` | `number` | Yes | Total still available across all balances |
| `total_used` | `number` | Yes | Total consumed across all balances |
| `renewal_date` | `string \| null` | No | Subscription renewal date (ISO 8601) |
| `period` | `object \| null` | No | Current billing period |
| `subscription` | `object \| null` | No | Combined subscription quota plus packs |
| `packs` | `any \| null` | No | One-time pack balances |
| `credits` | `object \| null` | No | Credit ledger balances |
| `rate_limit` | `Record<string, any> \| null` | No | Per-second and per-minute plan limits |
| `account` | `Record<string, any> \| null` | No | Account name and slug |
| `api_key` | `Record<string, any> \| null` | No | Key alias, active flag, category, expiry and quotas |

`web.crawler`

Fetch a public page with fast HTTP crawling, no JavaScript

**Risk:** `read`

```ts
await corsair.piloterr.api.web.crawler({ query: "https://example.com", returnPageSource: false });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | Public website URL to fetch; must include http:// or https:// |
| `allowRedirects` | `boolean` | No | Follow HTTP redirects (default true); set false to inspect the redirect chain |
| `returnPageSource` | `boolean` | No | Return the exact HTML source instead of processed content (default false) |
| `softFail` | `boolean` | No | Answer 200 even on errors, with the message in the error field; errors stay unbilled |
| `fields` | `string` | No | Comma-separated fields to keep, with dot notation for nested objects; unknown names are ignored |

Answers a JSON-encoded HTML string; start here for static pages and escalate to web.rendering (2 credits) or web.webunlocker (3 credits, whitelisted domains) when JavaScript or bot protection blocks you.



**Output:** `string`

### rendering

`web.rendering`

Render a JavaScript-heavy page in a headless browser

**Risk:** `read`

```ts
await corsair.piloterr.api.web.rendering({ query: "https://example.com", waitFor: "#content", timeout: 30 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | Public website URL to render in a headless browser; must include http:// or https:// |
| `waitInSeconds` | `number` | No | Seconds to wait after page load before returning |
| `waitFor` | `string` | No | CSS or XPath selector to wait for before returning the rendered HTML |
| `blockAds` | `boolean` | No | Block ad network requests during rendering |
| `timeout` | `number` | No | Maximum seconds to wait for the page to load |
| `returnPageSource` | `boolean` | No | Return &#123;"result": html&#125; instead of the raw HTML string |
| `softFail` | `boolean` | No | Answer 200 even on errors, with the message in the error field; errors stay unbilled |
| `fields` | `string` | No | Comma-separated fields to keep, with dot notation for nested objects; unknown names are ignored |



**Output:** `string`

### screenshot

`web.screenshot`

Capture a webpage as an image or PDF file

**Risk:** `read`

```ts
await corsair.piloterr.api.web.screenshot({ url: "https://example.com", format: "png", fullPage: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | The URL of the webpage to capture |
| `format` | `jpeg \| jpg \| pdf \| png \| webp` | No | Output format of the screenshot |
| `device` | `galaxy_fold4 \| galaxy_s23 \| galaxy_s23_ultra \| galaxy_s8 \| huawei_mate_50_pro \| huawei_p60_pro \| ipad \| iphone_12 \| iphone_13_mini \| iphone_13_pro_max \| iphone_14_pro \| iphone_14_pro_max \| iphone_x \| pixel_5 \| pixel_6a \| pixel_7_pro \| redmi_note_11 \| redmi_note_12_pro` | No | Device type to emulate |
| `fullPage` | `boolean` | No | Capture the entire page instead of the viewport |
| `fullPageScroll` | `boolean` | No | Scroll the page to load lazy elements before capturing |
| `fullPageScrollDuration` | `number` | No | Scroll duration in milliseconds before a full-page capture |
| `viewportWidth` | `number` | No | Viewport width in pixels |
| `viewportHeight` | `number` | No | Viewport height in pixels |
| `scaleFactor` | `number` | No | Scale factor for high-resolution screenshots |
| `imageQuality` | `string` | No | Custom image quality (jpeg and webp) |
| `selector` | `string` | No | Capture a specific element instead of the viewport |
| `cache` | `boolean` | No | Cache the response |
| `cacheTtl` | `number` | No | Cache TTL in seconds |
| `removeSelectors` | `string` | No | Comma-separated elements to hide before capturing |
| `removeCookieBanners` | `boolean` | No | Remove cookie banners before capturing |
| `removeAds` | `boolean` | No | Remove ads before capturing |
| `blockResources` | `string` | No | Comma-separated resource types to block, e.g. image,stylesheet,font |
| `blockUrls` | `string` | No | Comma-separated URL patterns to block |
| `delay` | `number` | No | Delay in seconds before capturing |
| `waitForSelector` | `string` | No | Element to wait for before capturing |
| `softFail` | `boolean` | No | Answer 200 even on errors, with the message in the error field; errors stay unbilled |
| `fields` | `string` | No | Comma-separated fields to keep, with dot notation for nested objects; unknown names are ignored |

Answers &#123; contentType, fileContent &#125; with the capture base64-encoded; format takes jpeg, jpg, pdf, png or webp and device one of the 19 documented emulations.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contentType` | `string \| null` | No | Image content type, e.g. image/png or application/pdf |
| `fileContent` | `string` | Yes | The captured file, base64-encoded |

### technology

`web.technology`

Detect the technology stack behind a website

**Risk:** `read`

```ts
await corsair.piloterr.api.web.technology({ query: "https://example.com", mode: "expert" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | Website URL to analyze; must include http:// or https:// |
| `mode` | `expert \| simple` | No | expert (default) adds confidence scores, versions and descriptions; simple keeps names and status codes |
| `softFail` | `boolean` | No | Answer 200 even on errors, with the message in the error field; errors stay unbilled |
| `fields` | `string` | No | Comma-separated fields to keep, with dot notation for nested objects; unknown names are ignored |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `cms` | `string \| null` | No | Detected CMS |
| `urls` | `Record<string, any> \| null` | No | Checked URLs with their status codes |
| `technologies` | `any[] \| null` | No | Detected technologies; names in simple mode |

### webunlocker

`web.webunlocker`

Unlock a bot-protected page on a whitelisted domain

**Risk:** `read`

```ts
await corsair.piloterr.api.web.webunlocker({ query: "https://www.example-whitelisted.com/page", allowRedirects: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | Public website URL to unlock; the target domain must be on the Piloterr whitelist |
| `allowRedirects` | `boolean` | No | Follow HTTP redirects (default true); set false to inspect the redirect chain |
| `returnPageSource` | `boolean` | No | Return the exact HTML source instead of processed content (default false) |
| `softFail` | `boolean` | No | Answer 200 even on errors, with the message in the error field; errors stay unbilled |
| `fields` | `string` | No | Comma-separated fields to keep, with dot notation for nested objects; unknown names are ignored |



**Output:** `string`
