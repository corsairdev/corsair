## Documents

### create

`documents.create`

Create a draft document from a template or from a public PDF URL

**Risk:** `write`

```ts
await corsair.pandadoc.api.documents.create({ template_uuid: "ustHNnVaPCD6MzuoNBbZ8L", name: "Contract for Acme Corp", recipients: [{ email: "jane@example.com", first_name: "Jane", last_name: "Roe", role: "Signer" }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `template_uuid` | `string` | No | Create from this template |
| `url` | `string` | No | Create from a publicly accessible HTTPS PDF |
| `name` | `string` | No | Document name; required when creating from a PDF URL |
| `recipients` | `object[]` | No | Recipients; required when creating from a template |
| `fields` | `Record<string, any>` | No | Prefilled fields, keyed by field name or uuid; values are strings, booleans or arrays |
| `tokens` | `object[]` | No | Token replacements |
| `metadata` | `Record<string, string>` | No | Arbitrary metadata key/value pairs, filterable on documents.list |
| `tags` | `string[]` | No | Tags for the document |
| `folder_uuid` | `string` | No | Place the document in this folder |
| `owner` | `object` | No | Create the document on a member’s behalf |
| `parse_form_fields` | `boolean` | No | Convert native PDF form fields into PandaDoc fields (PDF creation only) |
| `editable` | `boolean` | No | Let recipients edit the uploaded PDF (PDF creation only) |

Two creation bodies: from a template (template_uuid plus recipients) or from a public HTTPS PDF (url plus name). The answer is 201 with the document in document.create_pending while it renders.

### download

`documents.download`

Download a document as PDF, with optional watermarking

**Risk:** `read`

```ts
await corsair.pandadoc.api.documents.download({ id: "RsXrKarV524iCpjci9CMGa" });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | Document id |
| `watermark_color` | `string` | No | Watermark color, e.g. #FF0000 |
| `watermark_font_size` | `number` | No | Watermark font size |
| `watermark_opacity` | `number` | No | Watermark opacity, 0.0-1.0 |
| `watermark_text` | `string` | No | Watermark text |
| `separate_files` | `boolean` | No | Return a zip of per-recipient files instead of one PDF |

Answers a PDF; while the document is still rendering the API answers 202 and the operation reports pending: true instead of an empty file.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contentType` | `string` | Yes | Media type, for example application/pdf |
| `byteLength` | `number` | Yes | Size of the file in bytes |
| `contentBase64` | `string` | No | The PDF, base64-encoded; missing while the render is pending |
| `pending` | `boolean` | Yes | True when PandaDoc answered 202 and the file is still rendering |

### list

`documents.list`

List documents, filtered by status, folder, contact, dates or metadata

**Risk:** `read`

```ts
await corsair.pandadoc.api.documents.list({ status: 2, count: 25, page: 1 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `count` | `number` | No | Results per page; default 50, maximum 100 |
| `page` | `number` | No | Page number, starting at 1 |
| `status` | `number` | No | Filter by numeric status: 0 document.draft, 1 document.sent, 2 document.completed, 3 document.uploaded, 4 document.error, 5 document.viewed, 6 document.waiting_approval |
| `statusNe` | `number` | No | Exclude this numeric status (sent as status__ne) |
| `deleted` | `boolean` | No | Return only deleted documents |
| `q` | `string` | No | Filter by name or reference number |
| `id` | `string` | No | Search for a document by its id |
| `folderUuid` | `string` | No | Filter by folder (sent as folder_uuid) |
| `templateId` | `string` | No | Filter by template (sent as template_id) |
| `contactId` | `string` | No | Filter by contact (sent as contact_id) |
| `orderBy` | `name \| date_created \| date_status_changed \| date_of_last_action \| date_modified \| date_sent \| date_completed \| date_expiration \| date_declined \| status \| -name \| -date_created \| -date_status_changed \| -date_of_last_action \| -date_modified \| -date_sent \| -date_completed \| -date_expiration \| -date_declined \| -status` | No | Sort field (sent as order_by) |
| `createdFrom` | `string` | No | Created at or after (sent as created_from) |
| `createdTo` | `string` | No | Created at or before (sent as created_to) |
| `completedFrom` | `string` | No | Completed at or after (sent as completed_from) |
| `completedTo` | `string` | No | Completed at or before (sent as completed_to) |
| `modifiedFrom` | `string` | No | Modified at or after (sent as modified_from) |
| `modifiedTo` | `string` | No | Modified at or before (sent as modified_to) |
| `metadata` | `string[]` | No | Metadata filters, repeated once per entry |
| `tag` | `string` | No | Filter by tag |

Status filters are numeric codes (0 = document.draft, 1 = document.sent, 2 = document.completed, 3 = document.uploaded, 4 = document.error, 5 = document.viewed, 6 = document.waiting_approval). Metadata filters take the documented `metadata_key=value` format, one array entry per filter.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `results` | `object[]` | Yes | Documents on this page |


| `sender` | `object` | No | Send as another workspace member, by email or membership_id |
| `forwarding_settings` | `object` | No | Control whether recipients can forward the document |

Sends the document to its recipients by email (silent: true sends without emails or reminders; approval notifications still go out). This cannot be recalled.

## Webhooks

### createSubscription

`webhooks.createSubscription`

Create a webhook subscription for the events you choose

**Risk:** `write`

```ts
await corsair.pandadoc.api.webhooks.createSubscription({ name: "Deal desk deliveries", url: "https://example.com/webhooks/pandadoc", triggers: ["document_state_changed", "recipient_completed"] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Subscription name |
| `url` | `string` | Yes | Endpoint deliveries are posted to |
| `triggers` | `string[]` | Yes | Event names to subscribe to, e.g. document_state_changed, recipient_completed, document_deleted, document_updated, document_creation_failed, document_completed_pdf_ready, quote_updated, template_created, template_updated, template_deleted |
| `active` | `boolean` | No | Whether deliveries start active |
| `payload` | `(metadata \| fields \| products \| tokens \| pricing)[]` | No | Extra payload sections to include in every delivery |

The answer carries the subscription's shared_key: store it (keys.set_webhook_signature) so deliveries can be verified.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `uuid` | `string` | Yes | Subscription id |
| `name` | `string` | Yes | Subscription name |
| `url` | `string` | Yes | Endpoint deliveries are posted to |
| `active` | `boolean \| null` | No | Whether deliveries are active |
| `triggers` | `string[]` | Yes | Event names the subscription delivers |
| `payload` | `(metadata \| fields \| products \| tokens \| pricing)[] \| null` | No | Extra payload sections the subscription asks for |
| `workspace_id` | `string \| null` | No | Workspace the subscription belongs to |
| `shared_key` | `string \| null` | No | Key used to verify delivery signatures (HMAC-SHA256 over the raw body, hex, in the signature query parameter) |
| `status` | `ACTIVE \| INACTIVE \| DEACTIVATED \| null` | No | Subscription status |
