## Posts

### get

`posts.get`

Get Beamer posts

**Risk:** `read`

```ts
await corsair.beamer.api.posts.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number \| string` | No | — |
| `maxResults` | `number \| string` | No | — |
