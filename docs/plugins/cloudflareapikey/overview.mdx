Use **Cloudflare API Token** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 25 typed API operations
- 6 synced entities (`dnsRecords`, `dnssec`, `lockdowns`, `r2Objects`, `rulesets`, `zones`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/cloudflareapikey
```
```bash yarn
yarn add corsair @corsair-dev/cloudflareapikey
```
```bash pnpm
pnpm install corsair @corsair-dev/cloudflareapikey
```
```bash bun
bun add corsair @corsair-dev/cloudflareapikey
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { cloudflareapikey } from '@corsair-dev/cloudflareapikey';

export const corsair = createCorsair({
	plugins: [
		cloudflareapikey(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
cloudflareapikey()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'cloudflareapikey',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List zones**

```ts
const tenant = corsair.withTenant('acme');
await tenant.cloudflareapikey.api.zones.list({});
```


**Create a DNS record**

```ts
const tenant = corsair.withTenant('acme');
await tenant.cloudflareapikey.api.dns.create({
	zone_id: '023e105f4ecef8ad9ca31a8372d0c353',
	type: 'A',
	name: 'www.example.com',
	content: '203.0.113.10',
});
```


See the full list on the [API](/plugins/cloudflareapikey/api) page.

## Query synced data

Search synced zones without hitting Cloudflare.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.cloudflareapikey.db.zones.search({
	data: {},
	limit: 50,
});
```

Synced entities: `dnsRecords`, `dnssec`, `lockdowns`, `r2Objects`, `rulesets`, `zones`. See [Database](/plugins/cloudflareapikey/database) for filters and operators.
