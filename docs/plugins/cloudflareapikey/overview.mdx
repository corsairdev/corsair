Use **Cloudflare API token** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 25 typed API operations
- 6 synced entities (`dnsRecords`, `dnssec`, `lockdowns`, `r2Objects`, `rulesets`, `zones`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/cloudflareapikey
```
```bash yarn
yarn add corsair @corsair-dev/cloudflareapikey
```
```bash pnpm
pnpm install corsair @corsair-dev/cloudflareapikey
```
```bash bun
bun add corsair @corsair-dev/cloudflareapikey
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { cloudflareapikey } from '@corsair-dev/cloudflareapikey';

export const corsair = createCorsair({
	plugins: [
		cloudflareapikey(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
cloudflareapikey()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'cloudflareapikey',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`cache.getRegionalTieredCache`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.cloudflareapikey.api.cache.getRegionalTieredCache({});
```


**`dns.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.cloudflareapikey.api.dns.create({});
```


See the full list on the [API](/plugins/cloudflareapikey/api) page.

## Query synced data

Synced entities support `tenant.cloudflareapikey.db.<entity>.search()` and `.list()`: `dnsRecords`, `dnssec`, `lockdowns`, `r2Objects`, `rulesets`, `zones`.

See [Database](/plugins/cloudflareapikey/database) for filters and operators.
