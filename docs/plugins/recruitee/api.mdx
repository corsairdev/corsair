## Candidates

### create

`candidates.create`

Add a candidate manually and assign them to a published or internal offer at its default stage

**Risk:** `write`

```ts
await corsair.recruitee.api.candidates.create({ name: 'John Smith', emails: ['john@example.com'], offer_id: 42 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | The candidate name. |
| `emails` | `string[]` | No | — |
| `phones` | `string[]` | No | — |
| `social_links` | `string[]` | No | — |
| `links` | `string[]` | No | — |
| `cover_letter` | `string` | No | — |
| `sources` | `string[]` | No | — |
| `remote_cv_url` | `string` | No | A link to a CV hosted elsewhere, instead of an upload. |
| `offer_id` | `number` | No | The offer the candidate is assigned to at its default stage. Recruitee skips the assignment, without an error, when the offer is a draft. |

The record goes under `candidate` and the offer assignment beside it as `offers`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `candidate` | `object` | Yes | — |

### delete

`candidates.delete`

Delete a candidate. Recruitee keeps them restorable in its deleted list for 7 days, then removes them

**Risk:** `destructive`

```ts
await corsair.recruitee.api.candidates.delete({ candidate_id: 135145 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `candidate_id` | `number` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |
| `candidate_id` | `number` | Yes | — |

### list

`candidates.list`

Search candidates by text, offer, stage, status, department or location, a page at a time

**Risk:** `read`

```ts
await corsair.recruitee.api.candidates.list({ offer_id: 42, stage: 'Applied', limit: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | Records per page. Recruitee applies its own default when omitted. |
| `page` | `number` | No | The page to read, 1-based. Defaults to 1. |
| `query` | `string` | No | A free-text search over name, emails, phones, tags, sources, stage, cover letter and CV. |
| `offer_id` | `number` | No | Only candidates on this offer. |
| `stage` | `string` | No | Only candidates in a stage with this name, such as `Applied`. |
| `status` | `string` | No | The candidate status: `qualified`, `disqualified` or `new`. |
| `department_id` | `number` | No | Only candidates on offers in this department. |
| `location_id` | `number` | No | Only candidates on offers at this location. |
| `sort_by` | `string` | No | The column to sort on, such as `created_at`, `candidate_name` or `relevance`. |
| `sort_direction` | `asc \| desc` | No | Defaults to `desc` when `sort_by` is set. |

Calls /search/new/candidates and sends the filters as one filters_json array; page with `page` and `next_page`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `candidates` | `object[]` | Yes | — |
| `total` | `number \| null` | Yes | How many records match in total, when the route says. |
| `next_page` | `number \| null` | Yes | Pass as `page` to read the next page; null on the last. |

## Offers

### create

`offers.create`

Create an offer as a draft job or talent pool; publishing is done in Recruitee

**Risk:** `write`

```ts
await corsair.recruitee.api.offers.create({ title: 'Senior Backend Engineer', kind: 'job', description: '<p>Build the API.</p>', requirements: '<p>Five years of TypeScript.</p>', location_ids: [2] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `title` | `string` | Yes | — |
| `kind` | `job \| talent_pool` | No | — |
| `description` | `string` | No | The description, as HTML. |
| `requirements` | `string` | No | The requirements, as HTML. Recruitee requires them for a job. |
| `department_id` | `number` | No | — |
| `location_ids` | `number[]` | No | Location ids from `locations.list`. Recruitee requires at least one for a job. |

A new offer is created as a draft. A job needs description, requirements and location_ids.



**Output**

| Name | Type | Required | Description |

| `offer` | `object` | Yes | — |
