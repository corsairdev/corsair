## Candidates

### create

`candidates.create`

Add a candidate manually and assign them to an offer at its default stage

**Risk:** `write`

```ts
await corsair.recruitee.api.candidates.create({ name: 'John Smith', emails: ['john@example.com'], offer_id: 42 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | The candidate name. |
| `emails` | `string[]` | No | — |
| `phones` | `string[]` | No | — |
| `social_links` | `string[]` | No | — |
| `links` | `string[]` | No | — |
| `cover_letter` | `string` | No | — |
| `sources` | `string[]` | No | — |
| `remote_cv_url` | `string` | No | A link to a CV hosted elsewhere, instead of an upload. |
| `offer_id` | `number` | No | The offer the candidate is assigned to at its default stage. |

The record goes under `candidate` and the offer assignment beside it as `offers`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `candidate` | `object` | Yes | — |

### list

`candidates.list`

Search candidates with offer, stage, status and location filters, plus offset paging

**Risk:** `read`

```ts
await corsair.recruitee.api.candidates.list({ offer_id: 42, stage: 'Applied', limit: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number` | No | Records per page. Recruitee applies its own default when omitted. |
| `offset` | `number` | No | Records to skip, 0-based. |
| `query` | `string` | No | A free-text search. |
| `offer_id` | `number` | No | Only candidates on this offer. |
| `stage` | `string` | No | The pipeline stage name. |
| `status` | `string` | No | The candidate status. |
| `department_id` | `number` | No | — |
| `location_id` | `number` | No | — |
| `sort_by` | `string` | No | The column to sort on, such as `created_at`. |
| `sort_direction` | `asc \| desc` | No | — |

Filtering lives on /search/new/candidates; /candidates itself is the create route.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `candidates` | `object[]` | Yes | — |
| `meta` | `object \| null` | No | — |
| `next_offset` | `number \| null` | Yes | Pass as `offset` to read the next page; null on the last. |
