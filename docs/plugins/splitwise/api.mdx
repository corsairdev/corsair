## Expenses

### create

`expenses.create`

Record an expense, split either equally across a group or by an explicit paid and owed share per person

**Risk:** `destructive`

```ts
await corsair.splitwise.api.expenses.create({ description: 'Internet', cost: 60, group_id: 321, split_equally: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `description` | `string` | Yes | A short description of the expense |
| `cost` | `number` | Yes | Total cost of the expense, e.g. 25.5 |
| `details` | `string` | No | Free-text notes |
| `date` | `string` | No | ISO 8601 date and time the expense took place, e.g. "2026-05-02T13:00:00Z" |
| `currency_code` | `string` | No | Currency code from `currencies.list`; defaults to the group currency |
| `category_id` | `number` | No | A subcategory ID from `categories.list`; a parent category is rejected |
| `repeat_interval` | `never \| weekly \| fortnightly \| monthly \| yearly` | No | — |
| `split_equally` | `true` | No | Split equally between the group; requires `group_id` and no `users` |
| `group_id` | `number` | No | Group to put the expense in, or 0 for an expense outside a group |
| `users` | `object[]` | No | One entry per person, each with `paid_share` and `owed_share` |

Pass either `split_equally: true` with a `group_id`, or a `users` list whose paid and owed amounts add up to `cost`.

**Risk:** `destructive`

await corsair.splitwise.api.expenses.update({ expense_id: 51023, description: 'Brunch (updated)' });

| `group_id` | `number` | No | — |
| `users` | `object[]` | No | Replaces every share on the expense when supplied |
