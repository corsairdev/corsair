## Cache

### getPurgeStatus

`cache.getPurgeStatus`

Where a cache purge stands; status Pending or Completed

**Risk:** `read`

```ts
await corsair.imagekit.api.cache.getPurgeStatus({ requestId: '5d5b1a9b4c8c4c0001f3e4a2' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `requestId` | `string` | Yes | Request ID from a cache purge call. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string` | Yes | — |



---

### purge

`cache.purge`

Purge the CDN cache of one delivered file URL; follow with cache.getPurgeStatus until status is Completed

**Risk:** `write`

```ts
await corsair.imagekit.api.cache.purge({ url: 'https://ik.imagekit.io/your_id/photo.jpg' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | Full https URL of the delivered file whose CDN cache to purge. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `requestId` | `string` | Yes | — |

### list

`files.list`

List and search files and folders with paging (limit and skip), a folder path filter, file type and a searchQuery expression

**Risk:** `read`

```ts
await corsair.imagekit.api.files.list({ path: '/products/', limit: 25, skip: 25 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `file \| file-version \| folder \| all` | No | Asset kind to list; the default `file` lists only files. |
| `path` | `string` | No | Only assets inside this folder path, e.g. `/products/`. |
| `searchQuery` | `string` | No | Search filter expression over name, tags, type, size and createdAt, e.g. `name = "summer"`. |
| `fileType` | `all \| image \| non-image` | No | All files, images only, or non-image files (video and others). |
| `sort` | `ASC_NAME \| DESC_NAME \| ASC_CREATED \| DESC_CREATED \| ASC_UPDATED \| DESC_UPDATED \| ASC_HEIGHT \| DESC_HEIGHT \| ASC_WIDTH \| DESC_WIDTH \| ASC_SIZE \| DESC_SIZE \| ASC_RELEVANCE \| DESC_RELEVANCE` | No | Sort token, e.g. ASC_CREATED (the default) or DESC_SIZE. |
| `limit` | `number` | No | Page size, 1-1000; the default is 1000. |
| `skip` | `number` | No | Assets to skip before this page; combine with limit to page. |

### upload

`files.upload`

Upload a file from an https URL or base64 content into the media library, optionally into a folder and with tags

**Risk:** `write`

```ts
await corsair.imagekit.api.files.upload({ file: 'https://example.com/photo.jpg', fileName: 'photo.jpg', folder: '/products/', tags: ['summer'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `file` | `string` | Yes | The file to upload: an https URL ImageKit can fetch, or base64-encoded content. |
| `fileName` | `string` | Yes | Name the file gets in the media library, e.g. photo.jpg. |
| `folder` | `string` | No | Destination folder path, e.g. `/products/`. |
| `tags` | `string[]` | No | Tags to attach to the uploaded file; no commas inside a tag. |
| `isPrivateFile` | `boolean` | No | Mark the file private; it is then served only through a signed URL or a named transformation. |
| `isPublished` | `boolean` | No | Publish the file immediately. |
| `useUniqueFileName` | `boolean` | No | Add a random suffix to fileName when true (the default). |
| `overwriteFile` | `boolean` | No | Replace an existing file at the same path. |
| `overwriteTags` | `boolean` | No | When overwriting a file and no tags are sent, true (the default) removes its existing tags and false keeps them. Sent tags always replace them. |
| `overwriteAITags` | `boolean` | No | When overwriting a file, true (the default) removes its AI tags and false keeps them. |
| `overwriteCustomMetadata` | `boolean` | No | When overwriting a file and no customMetadata is sent, true (the default) removes its existing custom metadata and false keeps it. Sent customMetadata always replaces it. |
| `customMetadata` | `Record<string, any>` | No | Custom metadata to set, keyed by field label, identifier or UUID. |
| `description` | `string` | No | Short human-readable description stored with the file. |
