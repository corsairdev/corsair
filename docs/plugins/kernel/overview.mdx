Use **Kernel** through Corsair: one client, typed API calls.

A browser bills per second while active and holds a concurrency slot until it is deleted: call `browsers.delete` when done. `headless: true` costs about 8x less than headful but has no live view. `browsers.playwright.execute` acts on a page in one call. Screenshots, file reads, replays and archives come back as files. Kernel's event streams (SSE) are left out; poll the matching `get` instead.

**What you get:**

- 183 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/kernel better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/kernel better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/kernel better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/kernel better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { kernel } from '@corsair-dev/kernel';

export const corsair = createCorsair({
	plugins: [
		kernel(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Kernel API key before the first call: `pnpm corsair setup --plugin=kernel --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
kernel()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'kernel',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List running browsers**

```ts
const tenant = corsair.withTenant('acme');
await tenant.kernel.api.browsers.list({ status: 'active', limit: 20 });
```


**Open a page and read its title**

```ts
const tenant = corsair.withTenant('acme');
await tenant.kernel.api.browsers.playwright.execute({ id_or_name: 'htzv5orfit78e1m2biiifpbv', code: 'await page.goto(\'https://example.com\'); return await page.title();', timeout_sec: 60 });
```


See the full list on the [API](/plugins/kernel/api) page.
