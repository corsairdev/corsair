Use **Scale AI** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 40 typed API operations
- 6 synced entities (`batches`, `batchStatuses`, `files`, `projects`, `tasks`, `teammates`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/scaleai
```
```bash yarn
yarn add corsair @corsair-dev/scaleai
```
```bash pnpm
pnpm install corsair @corsair-dev/scaleai
```
```bash bun
bun add corsair @corsair-dev/scaleai
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { scaleai } from '@corsair-dev/scaleai';

export const corsair = createCorsair({
	multiTenancy: true,
	plugins: [
		scaleai(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
scaleai()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'scaleai',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`audits.getFixlessAudits`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.scaleai.api.audits.getFixlessAudits({});
```


**`batches.createBatch`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.scaleai.api.batches.createBatch({});
```


See the full list on the [API](/plugins/scaleai/api) page.

## Query synced data

Synced entities support `tenant.scaleai.db.<entity>.search()` and `.list()`: `batches`, `batchStatuses`, `files`, `projects`, `tasks`, `teammates`.

See [Database](/plugins/scaleai/database) for filters and operators.
