The Fathom AI Notetaker plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/fathomai/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `meetings`
  - `contentReady` (`meetings.contentReady`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Events

## Meetings

### Content Ready

`meetings.contentReady`

A recorded meeting finished processing; carries the meeting with the transcript, summary, action items and CRM matches the webhook was set to include

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `title` | `string` | Yes | — |
| `meeting_title` | `string \| null` | Yes | — |
| `meeting_type` | `string \| null` | Yes | — |
| `recording_id` | `number` | Yes | — |
| `url` | `string` | Yes | — |
| `meeting_url` | `string \| null` | No | — |
| `share_url` | `string` | Yes | — |
| `created_at` | `string` | Yes | — |
| `scheduled_start_time` | `string` | Yes | — |
| `scheduled_end_time` | `string` | Yes | — |
| `recording_start_time` | `string` | Yes | — |
| `recording_end_time` | `string` | Yes | — |
| `calendar_invitees_domains_type` | `only_internal \| one_or_more_external \| string` | Yes | — |
| `shared_with` | `no_teams \| single_team \| multiple_teams \| all_teams \| string` | Yes | — |
| `transcript_language` | `string` | Yes | — |
| `transcript` | `object[] \| null` | No | — |
| `default_summary` | `object \| null` | No | — |
| `action_items` | `object[] \| null` | No | — |
| `highlights` | `object[] \| null` | No | — |
| `calendar_invitees` | `object[]` | Yes | — |
| `recorded_by` | `object` | Yes | — |
| `crm_matches` | `object \| null` | No | — |

```ts
fathomai({

        meetings: {
            contentReady: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
