## Meetings

### list

`meetings.list`

List recorded meetings with filters, optionally including transcript, summary, action items, highlights and CRM matches

**Risk:** `read`

```ts
await corsair.fathomai.api.meetings.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `cursor` | `string` | No | — |
| `created_after` | `string` | No | — |
| `created_before` | `string` | No | — |
| `calendar_invitees_domains` | `string[]` | No | — |
| `calendar_invitees_domains_type` | `all \| only_internal \| one_or_more_external` | No | — |
| `meeting_type` | `string` | No | — |
| `recorded_by` | `string[]` | No | — |
| `teams` | `string[]` | No | — |
| `include_action_items` | `boolean` | No | — |
| `include_crm_matches` | `boolean` | No | — |
| `include_highlights` | `boolean` | No | — |
| `include_summary` | `boolean` | No | — |
| `include_transcript` | `boolean` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `number \| null` | Yes | — |
| `next_cursor` | `string \| null` | Yes | — |
| `items` | `object[]` | Yes | — |

### getSummary

`recordings.getSummary`

Get the AI summary of a recording, or have Fathom POST it to a destination_url

**Risk:** `read`

```ts
await corsair.fathomai.api.recordings.getSummary({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `recording_id` | `number` | Yes | — |
| `destination_url` | `string` | No | — |

**Output:** `object`

    markdown_formatted: string | null

</Accordion>
</AccordionGroup>

## Webhooks

### create

`webhooks.create`

Register a webhook that fires when new meeting content is ready; returns its signing secret once

**Risk:** `write`

```ts
await corsair.fathomai.api.webhooks.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `destination_url` | `string` | Yes | — |
| `triggered_for` | `(my_recordings \| shared_external_recordings \| my_shared_with_team_recordings \| shared_team_recordings)[]` | Yes | — |
| `include_action_items` | `boolean` | No | — |
| `include_crm_matches` | `boolean` | No | — |
| `include_summary` | `boolean` | No | — |
| `include_transcript` | `boolean` | No | — |

Set at least one of include_transcript, include_summary, include_action_items or include_crm_matches to true; Fathom rejects a webhook that includes nothing, and the input check does too.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `url` | `string` | Yes | — |
| `secret` | `string` | Yes | — |
| `created_at` | `string` | Yes | — |
| `include_transcript` | `boolean` | Yes | — |
| `include_crm_matches` | `boolean` | Yes | — |
| `include_summary` | `boolean` | Yes | — |
| `include_action_items` | `boolean` | Yes | — |
| `triggered_for` | `(my_recordings \| shared_external_recordings \| my_shared_with_team_recordings \| shared_team_recordings \| string)[]` | Yes | — |
