---
title: Database
description: "Veo does not sync a local database. Read generated videos through operations."
---

Veo has no local database collections. The plugin declares no entities and does not store generated videos in Corsair, so there is no `corsair.veo.db.<entity>.search()`.

Start a generation, then fetch the result with `corsair.veo.api.operations.get` or `corsair.veo.api.operations.wait`.

</Info>
