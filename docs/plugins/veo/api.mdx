## Extend

### create

`extend.create`

Extend a Veo video stored in Cloud Storage.

**Risk:** `write`

```ts
await corsair.veo.api.extend.create({ model: 'veo-3.1-generate-001', prompt: 'a butterfly flies in and lands on the flower', video: { gcsUri: 'gs://cloud-samples-data/generative-ai/video/flower.mp4', mimeType: 'video/mp4' }, resolution: '720p' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `projectId` | `string` | No | Google Cloud project id. Falls back to veo(&#123; projectId &#125;) or the stored projectId account field. |
| `location` | `string` | No | API location. Defaults to us-central1, the region in the Veo REST samples. Pass global for the global host. |
| `aspectRatio` | `16:9 \| 9:16` | No | Defaults to 16:9 when omitted. |
| `negativePrompt` | `string` | No | — |
| `personGeneration` | `allow_adult \| disallow` | No | Defaults to allow_adult when omitted. |
| `resolution` | `720p \| 1080p \| 4k` | No | Veo 3 models. Defaults to 720p. 4k is documented for Veo 3.1. |
| `sampleCount` | `number` | No | Number of videos to generate, from 1 to 4. |
| `seed` | `number` | No | — |
| `storageUri` | `string` | No | Cloud Storage prefix for output. When omitted, the API returns video bytes in the operation response. |
| `durationSeconds` | `4 \| 6 \| 8` | No | Video length in seconds. Defaults to 8 when omitted. |
| `model` | `veo-3.1-generate-001 \| veo-3.1-fast-generate-001 \| veo-3.1-lite-generate-001` | Yes | — |
| `prompt` | `string` | Yes | — |
| `video` | `object` | Yes | — |

```ts

  mimeType: video/mp4
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `done` | `boolean` | No | — |
| `metadata` | `any` | No | — |
| `error` | `object` | No | — |
| `response` | `object` | No | — |

<AccordionGroup>
<Accordion title="error full type">

```ts

  code?: number,

  status?: string
```

### wait

`operations.wait`

Poll a Veo operation until it finishes, fails, or the timeout is reached.

**Risk:** `read`

```ts
await corsair.veo.api.operations.wait({ operationName: 'projects/my-proj/locations/us-central1/publishers/google/models/veo-3.1-generate-001/operations/op-1' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `operationName` | `string` | Yes | Full operation name returned by predictLongRunning, projects/.../operations/... |
