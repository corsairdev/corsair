## Api Keys

### create

`apiKeys.create`

Mint an API key; the token is returned once in this response and never again, so it must be stored now

**Risk:** `write`

```ts
await corsair.ngrok.api.apiKeys.create({ description: 'CI deploy' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `description` | `string` | No | — |
| `metadata` | `string` | No | — |
| `owner_id` | `string` | No | Create the key for this user instead of the caller. |

The token appears only in this response and never on a later read, so store it now.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `uri` | `string \| null` | No | — |
| `description` | `string \| null` | No | — |
| `metadata` | `string \| null` | No | — |
| `created_at` | `string \| null` | No | — |
| `token` | `string \| null` | No | — |
| `owner_id` | `string \| null` | No | — |

## Domains

### create

`domains.create`

Reserve a hostname and return the CNAME target to point DNS at; certificate issuance starts once it resolves

**Risk:** `write`

```ts
await corsair.ngrok.api.domains.create({ domain: 'acme.example.com', description: 'Acme production' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `domain` | `string` | Yes | The hostname to reserve, e.g. app.example.com. |
| `region` | `string` | No | — |
| `description` | `string` | No | — |
| `metadata` | `string` | No | — |
| `certificate_id` | `string` | No | Attach an uploaded certificate instead of an automatic one. |
| `certificate_management_policy` | `object` | No | Automatic certificate issuance and renewal; an empty object takes the defaults. |
| `resolves_to` | `object[]` | No | Only serve the domain from these points of presence, e.g. [&#123; value: 'us-cal-1' &#125;, &#123; value: 'eu' &#125;]. |

Reserving returns a cname_target to point DNS at; certificate issuance starts once the record resolves.

## Endpoints

### create

`endpoints.create`

Create a cloud endpoint at a URL you own (e.g. your ngrok dev domain); its required Traffic Policy decides what happens to requests, and it serves immediately

**Risk:** `write`

```ts
await corsair.ngrok.api.endpoints.create({ url: 'https://acme.ngrok-free.dev', type: 'cloud', traffic_policy: '{"on_http_request":[{"actions":[{"type":"forward-internal","config":{"url":"https://api.internal"}}]}]}', description: 'Acme API' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | The endpoint's own address, the URL clients connect to, e.g. https://your-domain.ngrok-free.dev. Where traffic goes is set in traffic_policy. |
| `type` | `string` | No | The endpoint type. Only 'cloud' is supported; defaults to it. |
| `traffic_policy` | `string` | Yes | The Traffic Policy, as YAML or JSON text. Required for a cloud endpoint, and it must end in a terminal action such as forward-internal, redirect or custom-response. |
| `description` | `string` | No | — |
| `metadata` | `string` | No | — |
| `bindings` | `string[]` | No | — |

The endpoint starts forwarding on its public URL as soon as it exists.

| `updated_at` | `string \| null` | No | — |
