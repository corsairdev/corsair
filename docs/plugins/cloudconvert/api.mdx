## Formats

### listSupported

`formats.listSupported`

List supported conversion formats, engines, options and engine versions through CloudConvert GET /operations. Docs: https://cloudconvert.com/docs/api-reference/operations#list-operations

await corsair.cloudconvert.api.formats.listSupported({});

## Jobs

### create

`jobs.create`

Create an asynchronous job from a task graph. CloudConvert limits job task names to alphanumeric characters, hyphens and underscores, with at most 2000 tasks. Docs: https://cloudconvert.com/docs/api-reference/jobs#create-job

**Risk:** `destructive`

```ts
await corsair.cloudconvert.api.jobs.create({
	tasks: {
		import_file: { operation: 'import/url', url: 'https://example.test/input.docx' },
		convert: { operation: 'convert', input: 'import_file', output_format: 'pdf' },
		export_file: { operation: 'export/url', input: 'convert' },
	},
	tag: 'request-123',
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `tasks` | `object` | Yes | — |
| `tag` | `string` | No | — |

This example includes an `export/url` task so the completed job has a downloadable file. Read `result.files[].url` from the finished export task; use `jobs.get` for status polling on long jobs. The generic task schema rejects credential fields such as `private_key` and `secret_access_key`. Response `status` values are the string literals `"waiting"`, `"processing"`, `"finished"`, and `"error"`.

### createAndWait

`jobs.createAndWait`

Create a job and wait for completion on CloudConvert’s synchronous API. Prefer jobs.create for long-running work because clients and network stacks may time out. redirect=true is rejected because it returns raw file bytes unsupported by this JSON endpoint. Docs: https://cloudconvert.com/docs/api-reference/jobs#create-job-and-wait

**Risk:** `destructive`

```ts
await corsair.cloudconvert.api.jobs.createAndWait({
	tasks: {
		import_file: { operation: 'import/url', url: 'https://example.test/input.docx' },
		convert: { operation: 'convert', input: 'import_file', output_format: 'pdf' },
		export_file: { operation: 'export/url', input: 'convert' },
	},
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `tasks` | `object` | Yes | — |
| `tag` | `string` | No | — |
| `redirect` | `false` | No | Only false or omitted is supported. true redirects to raw file content, which this JSON endpoint cannot represent. |

This example includes an `export/url` task. Read `result.files[].url` from the completed export task. Synchronous calls are bounded by `syncTimeoutMs` (5 minutes by default, up to 10 minutes); use async jobs for long work. Response `status` values are the string literals `"waiting"`, `"processing"`, `"finished"`, and `"error"`.
