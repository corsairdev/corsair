## Lists

### create

`lists.create`

Create an empty mailing list

**Risk:** `write`

```ts
await corsair.moosend.api.lists.create({ name: 'Newsletter' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | The name of the mailing list. |
| `confirmationPage` | `string` | No | Shown at the end of the subscription process. |
| `redirectAfterUnsubscribePage` | `string` | No | Where subscribers land after unsubscribing. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `mailingList` | `object` | Yes | — |

### list

`lists.list`

List every active mailing list in the account, with subscriber statistics and custom fields

**Risk:** `read`

```ts
await corsair.moosend.api.lists.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `withStatistics` | `boolean` | No | Omit to receive statistics by default. |
| `shortBy` | `string` | No | The property to sort by; defaults to CreatedOn. |
| `sortMethod` | `ASC \| DESC` | No | — |

`GET /lists.json` returns every active list with subscriber counts and the
custom field definitions; `lists.listPaged` takes page and pageSize and
also returns the paging info.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|

### subscribe

`subscribers.subscribe`

Add a subscriber, updating the existing entry when the email is already on the list

**Risk:** `write`

```ts
await corsair.moosend.api.subscribers.subscribe({ mailingListId: '8c4f9a52-3f3e-4f29-a497-1f4c30f10be9', email: 'jana.berger@beachy.example', name: 'Jana Berger', customFields: { Country: 'NL' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `mailingListId` | `string` | Yes | — |
| `email` | `string` | Yes | The subscriber email address. |
| `name` | `string` | No | — |
| `customFields` | `Record<string, unknown>` | No | — |

`POST /subscribers/{mailingListId}/subscribe.json` with an upsert: an
existing email is updated instead of rejected. `customFields` are
name-value pairs matched against the list's custom field definitions.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `subscriber` | `object` | Yes | — |

### unsubscribe

`subscribers.unsubscribe`

Unsubscribe an email from one mailing list, moving it to the suppression list; subscribe adds it back

**Risk:** `write`

```ts
await corsair.moosend.api.subscribers.unsubscribe({ mailingListId: '8c4f9a52-3f3e-4f29-a497-1f4c30f10be9', email: 'jana.berger@beachy.example' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `mailingListId` | `string` | Yes | — |
| `email` | `string` | Yes | The subscriber email address. |

`POST /subscribers/{mailingListId}/unsubscribe.json` moves the email to
the suppression list; `subscribers.remove` deletes it permanently without
the suppression list.



**Output:** _empty object_
