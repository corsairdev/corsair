### create

`campaigns.create`

Create a draft campaign (regular or A/B); nothing is sent

**Risk:** `write`

```ts
await corsair.moosend.api.campaigns.create({ name: 'November newsletter', subject: 'News', senderEmail: 'news@example.com', htmlContent: '<p>Hello</p>', mailingLists: [{ mailingListId: '15c677cb-e8b2-438f-b338-1dc393caf0f3' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | Campaign name |
| `subject` | `string` | Yes | Subject line |
| `senderEmail` | `string` | Yes | Email of one of the account senders |
| `replyToEmail` | `string` | No | Reply-to address; must be one of the account senders (sender when omitted) |
| `confirmationToEmail` | `string` | No | Where Moosend sends its "campaign sent" confirmation (sender when omitted) |
| `htmlContent` | `string` | No | Full HTML body |
| `webLocation` | `string` | No | URL Moosend fetches the HTML body from |
| `mailingLists` | `object[]` | No | Lists (and optional segments) the campaign goes to |
| `trackInGoogleAnalytics` | `boolean` | No | — |
| `isAB` | `boolean` | No | Create an A/B split campaign (false when omitted) |
| `abCampaignType` | `Subjectline \| Content \| Sender` | No | — |
| `subjectB` | `string` | No | — |
| `htmlContentB` | `string` | No | — |
| `webLocationB` | `string` | No | — |
| `senderEmailB` | `string` | No | — |
| `hoursToTest` | `number` | No | — |
| `listPercentage` | `number` | No | — |
| `abWinnerSelectionType` | `OpenRate \| TotalUniqueClicks` | No | — |

<Accordion title="mailingLists full type">

```ts
{
  mailingListId: string,

}[]
```
</Accordion>
</AccordionGroup>

|------|------|----------|-------------|
| `campaignId` | `string` | Yes | — |

### list

`campaigns.list`

List campaigns (drafts, scheduled and sent) with their totals, optionally by page and page size

**Risk:** `read`

```ts
await corsair.moosend.api.campaigns.list({ page: 1, pageSize: 20, sortBy: 'CreatedOn', sortMethod: 'DESC' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | Page number, starting at 1 |
| `pageSize` | `number` | No | Results per page (needs page) |
| `sortBy` | `string` | No | Sort by this campaign property (needs pageSize) |
| `sortMethod` | `ASC \| DESC` | No | Sort direction |

No paging input calls `GET /campaigns.json`; `page` alone calls
`/campaigns/{page}.json`; `pageSize` calls `/campaigns/{page}/{pageSize}.json`
(page 1 when omitted) with the sort options.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `Paging` | `object \| null` | No | — |
| `Campaigns` | `object[]` | Yes | — |
