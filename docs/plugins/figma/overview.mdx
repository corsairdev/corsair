Use **Figma** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 50 typed API operations
- 5 synced entities (`comments`, `components`, `fileMetadata`, `versions`, `webhookConfigs`) for fast `.search()` / `.list()`
- 6 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/figma
```
```bash yarn
yarn add corsair @corsair-dev/figma
```
```bash pnpm
pnpm install corsair @corsair-dev/figma
```
```bash bun
bun add corsair @corsair-dev/figma
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { figma } from '@corsair-dev/figma';

export const corsair = createCorsair({
	plugins: [
		figma(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

Provider walkthrough: [Get Credentials](/plugins/figma/get-credentials).

```ts
figma()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'figma',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`activityLogs.list`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.figma.api.activityLogs.list({});
```


**`comments.add`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.figma.api.comments.add({});
```


See the full list on the [API](/plugins/figma/api) page.

## Query synced data

Synced entities support `tenant.figma.db.<entity>.search()` and `.list()`: `comments`, `components`, `fileMetadata`, `versions`, `webhookConfigs`.

See [Database](/plugins/figma/database) for filters and operators.

## Webhooks

This plugin registers **6** webhook event types. Configure the provider to POST to your Corsair HTTP handler, then use `webhookHooks` on the plugin factory.

See [Webhooks](/plugins/figma/webhooks) for every event path and payload shape, and [Webhooks concept](/concepts/webhooks) for routing.
