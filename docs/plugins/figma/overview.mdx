Use **Figma** through Corsair: one client, typed API calls, local DB sync, and incoming webhooks.

**What you get:**

- 50 typed API operations
- 5 synced entities (`comments`, `components`, `fileMetadata`, `versions`, `webhookConfigs`) for fast `.search()` / `.list()`
- 6 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/figma better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/figma better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/figma better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/figma better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { figma } from '@corsair-dev/figma';

export const corsair = createCorsair({
	plugins: [
		figma(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Figma API key before the first call: `pnpm corsair setup --plugin=figma --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

Provider walkthrough: [Get Credentials](/plugins/figma/get-credentials).

```ts
figma()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'figma',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Get file metadata**

```ts
const tenant = corsair.withTenant('acme');
await tenant.figma.api.files.getMetadata({ file_key: 'abcDEF123' });
```


**Add a comment**

```ts
const tenant = corsair.withTenant('acme');
await tenant.figma.api.comments.add({ file_key: 'abcDEF123', message: 'Hello from Corsair' });
```


See the full list on the [API](/plugins/figma/api) page.

## Query synced data

Search synced file metadata without hitting Figma.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.figma.db.fileMetadata.search({
	data: {},
	limit: 50,
});
```

Synced entities: `comments`, `components`, `fileMetadata`, `versions`, `webhookConfigs`. See [Database](/plugins/figma/database) for filters and operators.

## Webhooks

Fires when a Figma file is updated. Do not use ping.ping.

```ts
figma({
    webhookHooks: {
        files: {
            fileUpdate: {
                after: async (ctx, result) => {
                    console.log('Figma file updated:', result.data);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/figma/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
