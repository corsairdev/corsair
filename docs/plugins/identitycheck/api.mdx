## Verification

### create

`verification.create`

Start an individual verification; it uses plan credit, and with emailUser "Yes" StackGo emails the person an invitation

**Risk:** `destructive`

```ts
await corsair.identitycheck.api.verification.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `body` | `Record<string, any>` | Yes | Request body sent to StackGo as-is. StackGo has not published the field list; its quickstart uses firstName, lastName, email, emailUser ("Yes" emails the person an invitation), type (e.g. "kyc"), triggeredBy ("direct") and active (true). |



**Output:** `Record<string, any>`

### image

`verification.image`

Download a document or selfie image captured during a verification (needs the verification.image key scope)

**Risk:** `read`

```ts
await corsair.identitycheck.api.verification.image({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `verificationId` | `string` | Yes | ID of the verification the image belongs to |
| `imageId` | `string` | Yes | ID of the captured document or selfie image |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contentBase64` | `string` | No | The file, base64-encoded. Missing when the file came back as text or contentOmitted is set. |
| `text` | `string` | No | The file as text, in place of contentBase64, when it is a text file (CSV, JSON, Markdown, XML and the like) in UTF-8. |
| `contentType` | `string` | Yes | Media type of the file, for example application/pdf. |
| `byteLength` | `number` | Yes | Size of the file in bytes. |
| `filename` | `string` | No | The file name, when known. |
| `contentOmitted` | `not_requested \| over_limit` | No | Set when the content was left out: the caller did not ask for it, or the file was over the limit. |
| `fileId` | `string` | No | Where the host saved the file, in place of its content, when it was over the limit. On Corsair it is a Files id (fil_…): pass it to another app wherever that app takes a file URL, or read a text file or PDF with files.read_text. |
