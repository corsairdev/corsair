## Account

### getCredentials

`account.getCredentials`

Extract the OCR Web Service username from stored credentials

**Risk:** `read`

```ts
await corsair.ocrwebservice.api.account.getCredentials({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `user_name` | `string` | Yes | — |



---

### getInformation

`account.getInformation`

Retrieve remaining pages, subscription plan, and expiration date

**Risk:** `read`

```ts
await corsair.ocrwebservice.api.account.getInformation({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ErrorMessage` | `string \| null` | No | — |
| `AvailablePages` | `number \| null` | No | — |
| `MaxPages` | `number \| null` | No | — |
| `LastProcessingTime` | `string \| null` | No | — |
| `SubcriptionPlan` | `string \| null` | No | — |
| `ExpirationDate` | `string \| null` | No | — |



---

### log

```ts
await corsair.ocrwebservice.api.account.log({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `from_date` | `string` | Yes | — |
| `to_date` | `string` | Yes | — |
| `reserved` | `string[]` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `string` | Yes | — |

## Ocr

### recognize

`ocr.recognize`

OCR an image or document via REST processDocument. Takes the file as a public link, base64 or a Blob; on Corsair, pass a Files id.

**Risk:** `write`

```ts
await corsair.ocrwebservice.api.ocr.recognize({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `file` | `string \| object \| custom` | Yes | The image or document to OCR: a public URL, &#123;url, filename?, contentType?&#125;, or &#123;base64, filename?, contentType?&#125;; a Blob or File from TypeScript. On Corsair, pass a Files id (fil_…). |
| `language` | `string` | No | Defaults to "english". |
| `pagerange` | `string` | No | — |
| `tobw` | `boolean` | No | — |
| `zone` | `string` | No | — |
| `outputformat` | `string` | No | — |
| `gettext` | `boolean` | No | — |
| `getwords` | `boolean` | No | — |
| `newline` | `boolean` | No | — |
| `description` | `string` | No | — |

<AccordionGroup>
<Accordion title="file full type">

```ts
string | {
  url: string,
  filename?: string,
  contentType?: string
} | {
  base64: string,
  filename?: string,
  contentType?: string
} | custom
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ErrorMessage` | `string \| null` | No | — |
| `AvailablePages` | `number \| null` | No | — |
| `ProcessedPages` | `number \| null` | No | — |
| `OCRText` | `string[][] \| null` | No | — |
| `OutputFileUrl` | `string \| null` | No | — |
| `TaskDescription` | `string \| null` | No | — |
| `Reserved` | `any[] \| null` | No | — |
