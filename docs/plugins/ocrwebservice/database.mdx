The OCR Web Service plugin syncs data locally. Use `corsair.ocrwebservice.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Accounts

Path: `ocrwebservice.db.accounts.search`

```ts
const rows = await corsair.ocrwebservice.db.accounts.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `availablePages` | `number` | equals, gt, gte, lt, lte, in |
| `maxPages` | `number` | equals, gt, gte, lt, lte, in |
| `subscriptionPlan` | `string` | equals, contains, startsWith, endsWith, in |
| `expirationDate` | `string` | equals, contains, startsWith, endsWith, in |
| `lastProcessingTime` | `string` | equals, contains, startsWith, endsWith, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._

## Documents

Path: `ocrwebservice.db.documents.search`

```ts
const rows = await corsair.ocrwebservice.db.documents.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `outputFileUrl` | `string` | equals, contains, startsWith, endsWith, in |
| `processedPages` | `number` | equals, gt, gte, lt, lte, in |
| `availablePages` | `number` | equals, gt, gte, lt, lte, in |
| `taskDescription` | `string` | equals, contains, startsWith, endsWith, in |
