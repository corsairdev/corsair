---
title: "Storerocket database"
sidebarTitle: "Database"
description: "The Storerocket plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Storerocket. To read its data, call the [API operations](/plugins/storerocket/api), which return what Storerocket has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
