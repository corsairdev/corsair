---
title: "Linguapop database"
sidebarTitle: "Database"
description: "The Linguapop plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Linguapop. To read its data, call the [API operations](/plugins/linguapop/api), which return what Linguapop has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
