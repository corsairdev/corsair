## Alerts

### create

**Risk:** `write`


## Sessions

### list

`sessions.list`

List recorded sessions with page, size, visitor, email, timezone, and date filters

**Risk:** `read`

```ts
await corsair.livesession.api.sessions.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `page` | `number` | No | — |
| `size` | `number` | No | — |
| `email` | `string` | No | — |
| `visitor_id` | `string` | No | — |
| `tz` | `string` | No | — |
| `date_from` | `TODAY \| YESTERDAY \| BEGINNING_OF_WEEK \| BEGINNING_OF_MONTH \| BEGINNING_OF_PREV_MONTH \| TODAY-7DAYS \| TODAY-30DAYS \| string` | No | — |
| `date_to` | `TODAY \| YESTERDAY \| BEGINNING_OF_WEEK \| BEGINNING_OF_MONTH \| BEGINNING_OF_PREV_MONTH \| TODAY-7DAYS \| TODAY-30DAYS \| string` | No | — |

`date_from` and `date_to` take a relative value such as `TODAY-7DAYS` or an ISO 8601 datetime with a time part (`2026-01-31T00:00:00Z`); LiveSession ignores a date without a time. `tz` only applies together with a date filter. An empty result can come back as `sessions: null`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `total` | `number` | Yes | — |
| `page` | `object` | Yes | — |
| `sessions` | `object[] \| null` | Yes | — |
