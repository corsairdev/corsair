## Custom Fields

### create

`customFields.create`

Add a custom field to a product's checkout, optionally required

**Risk:** `write`

```ts
await corsair.gumroad.api.customFields.create({ product_id: 'A-m3CDDC5dlrSdKZp0RFhA==', name: 'Example' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `product_id` | `string` | Yes | Product id from products.list |
| `name` | `string` | Yes | — |
| `required` | `true \| false` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `success` | `boolean` | Yes | — |
| `custom_field` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="custom_field full type">

```ts
  name: string,
  required?: string | boolean | null
}
```
</Accordion>
</AccordionGroup>

## Emails

### create

`emails.create`

Create a draft audience email by subject, HTML body and audience, or send it immediately with publish=true

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.gumroad.api.emails.create({ subject: 'Welcome', body: 'Thanks for your purchase' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `subject` | `string` | Yes | — |
| `body` | `string` | Yes | HTML email body |
| `audience` | `all \| audience \| customers \| seller \| followers \| follower \| product` | No | Defaults to "audience". |
| `product_id` | `string` | No | Required when audience is "product" |
| `link_id` | `string` | No | Product permalink |
| `publish` | `true \| false` | No | "true" to send immediately |
| `draft` | `true \| false` | No | "false" to send immediately |
