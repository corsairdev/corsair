Use **Google Meet** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 18 typed API operations
- 6 synced entities (`conferenceRecords`, `participants`, `recordings`, `smartNotes`, `spaces`, `transcripts`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/googlemeet
```
```bash yarn
yarn add corsair @corsair-dev/googlemeet
```
```bash pnpm
pnpm install corsair @corsair-dev/googlemeet
```
```bash bun
bun add corsair @corsair-dev/googlemeet
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { googlemeet } from '@corsair-dev/googlemeet';

export const corsair = createCorsair({
	plugins: [
		googlemeet(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="OAuth 2.0 (Recommended)">

Open [hub.corsair.dev](https://hub.corsair.dev/dashboard), navigate to your project, and enter the **client ID** and **client secret** from your Google Meet OAuth app.

```ts
googlemeet()
```

More: [OAuth 2.0](/concepts/oauth)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'googlemeet',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`conferenceRecords.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.googlemeet.api.conferenceRecords.get({});
```


**`spaces.create`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.googlemeet.api.spaces.create({});
```


See the full list on the [API](/plugins/googlemeet/api) page.

## Query synced data

Synced entities support `tenant.googlemeet.db.<entity>.search()` and `.list()`: `conferenceRecords`, `participants`, `recordings`, `smartNotes`, `spaces`, `transcripts`.

See [Database](/plugins/googlemeet/database) for filters and operators.
