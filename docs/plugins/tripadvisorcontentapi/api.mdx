## Locations

### get

`locations.get`

Read one location. The address and description are not stored.

**Risk:** `read`

```ts
await corsair.tripadvisorcontentapi.api.locations.get({ locationId: '187147' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `locationId` | `string` | Yes | — |
| `language` | `string` | No | — |

GET /api/v1/location/{locationId}/details.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `location` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="location full type">

```ts
{
  id: string,
  name?: string,
  rating?: number,
  reviewCount?: number
}
```
</Accordion>
</AccordionGroup>

### nearby

`locations.nearby`

Search locations near a coordinate. The coordinate is not stored.

**Risk:** `read`

```ts
await corsair.tripadvisorcontentapi.api.locations.nearby({ latLong: '51.5072,-0.1276' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `latLong` | `string` | Yes | — |
| `language` | `string` | No | — |

GET /api/v1/location/nearby_search. latLong is latitude,longitude.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `locations` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="locations full type">

```ts
{
  id: string,
  name?: string,
  rating?: number,
  reviewCount?: number
}[]
```
</Accordion>
</AccordionGroup>

### search

`locations.search`

Search locations by name. The query is not stored.

**Risk:** `read`

```ts
await corsair.tripadvisorcontentapi.api.locations.search({ searchQuery: 'london' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `searchQuery` | `string` | Yes | — |
| `language` | `string` | No | — |

GET /api/v1/location/search. Stores location id, name, rating, and review count.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `locations` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="locations full type">

```ts
{
  id: string,

  rating?: number,
```

</Accordion>

| Name | Type | Required | Description |

GET /api/v1/location/{locationId}/photos. Stores id, width, and height.
