## Contracts

### addSigner

`contracts.addSigner`

Add a signer to a contract without sending a sign request; use contracts.resendToSigner to send one

**Risk:** `write`

```ts
await corsair.esignatures.api.contracts.addSigner({ contract_id: '1contr11-2222', signer: { name: 'Sam Signer', email: 'sam@tenants.com' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `contract_id` | `string` | Yes | The contract ID. |
| `signer` | `object` | Yes | The signer to add. No sign request email is sent; use `contracts.resendToSigner`. |

<AccordionGroup>
<Accordion title="signer full type">

```ts
{
  name?: string,
  email?: string,
  mobile?: string,
  company_name?: string,
  signing_order?: string,
  auto_sign?: yes | no,
  signature_request_delivery_methods?: (email | sms)[],
  signed_document_delivery_method?: email | sms | "",
  multi_factor_authentications?: (sms_verification_code | email_verification_code | photo_id)[],
  redirect_url?: string
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `string` | No | — |

### create

`contracts.create`

Create and send a contract from a template, filling placeholder fields; set save_as_draft to create without sending

**Risk:** `write`

```ts
await corsair.esignatures.api.contracts.create({ template_id: '4templ44-8888', signers: [{ name: 'Sam Signer', email: 'sam@tenants.com' }], placeholder_fields: [{ placeholder_key: 'tenant_name', replace_with_text: 'Sam Signer' }], test: 'yes' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `template_id` | `string` | Yes | The template ID. |
| `signers` | `object[]` | Yes | — |
| `title` | `string` | No | — |
| `locale` | `cz \| da \| de \| el \| en \| en-GB \| es \| fi \| fr \| hr \| hu \| id \| it \| ja \| nl \| no \| pl \| pt \| ro \| rs \| sk \| sl \| sv \| vi \| zh-CN \| zh-TW` | No | Language of the sign request emails and sign page. |
| `metadata` | `string` | No | Custom data attached to the contract, echoed by webhooks. |
| `expires_in_hours` | `string` | No | Hours before the sign request expires, such as "48". |
| `custom_webhook_url` | `string` | No | — |
| `assigned_user_email` | `string` | No | — |
| `labels` | `string[]` | No | — |
| `test` | `yes \| no` | No | When yes, the contract is a demo and no sending fees are charged. |
| `save_as_draft` | `yes \| no` | No | When yes, the contract is a draft until `contracts.sendDraft` sends it. |
| `placeholder_fields` | `object[]` | No | — |
| `signer_fields` | `object[]` | No | Pre-fills Signer fields the signer completes. |
| `emails` | `object` | No | Overrides for the sign request and signed-contract emails. |
| `custom_branding` | `object` | No | — |
