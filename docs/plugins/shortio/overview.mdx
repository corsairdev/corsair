Use **Short.io** through Corsair for typed link and domain API calls.

**What you get:**

- 13 typed API operations
- Entity schemas for `domains` and `links`; API calls do not automatically sync them locally.

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/shortio better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/shortio better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/shortio better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/shortio better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { shortio } from '@corsair-dev/shortio';

export const corsair = createCorsair({
	plugins: [
		shortio(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Save the tenant's secret key before making API calls, or supply a key when registering the plugin. A registration-level key takes precedence for every tenant, so use it only when all tenants should access the same Short.io account.

```ts
await corsair.withTenant('acme').shortio.keys.set_api_key(process.env.SHORTIO_API_KEY!);
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'shortio',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`domains.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.shortio.api.domains.get({ domainId: 123 });
```


**`links.archive`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.shortio.api.links.archive({ link_id: 'lnk_abc123_def456' });
```


See the full list on the [API](/plugins/shortio/api) page.

## Local data

The plugin declares `domains` and `links` entity schemas, but its API operations do not automatically populate the local database.

See [Database](/plugins/shortio/database) for filters and operators.
