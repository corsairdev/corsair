---
title: "Streamtime database"
sidebarTitle: "Database"
description: "The Streamtime plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Streamtime. To read its data, call the [API operations](/plugins/streamtime/api), which return what Streamtime has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
