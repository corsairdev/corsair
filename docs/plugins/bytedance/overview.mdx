Use **ByteDance** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 4 typed API operations
- 1 synced entity (`videoTasks`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/bytedance better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/bytedance better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/bytedance better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/bytedance better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { bytedance } from '@corsair-dev/bytedance';

export const corsair = createCorsair({
	plugins: [
		bytedance(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the ByteDance API key before the first call: `pnpm corsair setup --plugin=bytedance --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
bytedance()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'bytedance',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List video tasks**

```ts
const tenant = corsair.withTenant('acme');
await tenant.bytedance.api.tasks.list({});
```


**Start a video task**

```ts
const tenant = corsair.withTenant('acme');
await tenant.bytedance.api.video.create({
	model: 'seedance-1-0-pro-250528',
	content: [{ type: 'text', text: 'A paper boat drifting down a rainy street' }],
});
```


See the full list on the [API](/plugins/bytedance/api) page.

## Query synced data

Search synced video tasks without hitting ByteDance.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.bytedance.db.videoTasks.search({
	data: {},
	limit: 50,
});
```

Synced entities: `videoTasks`. See [Database](/plugins/bytedance/database) for filters and operators.
