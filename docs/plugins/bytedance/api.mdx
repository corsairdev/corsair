## Tasks

### delete

`tasks.delete`

Cancel a queued video task, or delete a finished task record

**Risk:** `destructive`

```ts
await corsair.bytedance.api.tasks.delete({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |



**Output:** _empty object_

### list

## Video

### create

`video.create`

Start a Seedance video generation task from text, frames, or reference media; returns a task id

**Risk:** `write`

```ts
await corsair.bytedance.api.video.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `model` | `string` | Yes | Model ID (dreamina-seedance-2-5-260628, dreamina-seedance-2-0-260128, dreamina-seedance-2-0-fast-260128, dreamina-seedance-2-0-mini-260615, seedance-1-5-pro-251215, seedance-1-0-pro-250528, seedance-1-0-pro-fast-251015) or an inference endpoint ID |
| `content` | `object[]` | Yes | — |
| `omni_reference_task_type` | `auto \| reference \| edit \| extend` | No | — |
| `resolution` | `480p \| 720p \| 1080p \| 4k` | No | — |
| `ratio` | `16:9 \| 4:3 \| 1:1 \| 3:4 \| 9:16 \| 21:9 \| adaptive` | No | — |
| `duration` | `-1 \| number` | No | — |
| `frames` | `number` | No | — |
| `generate_audio` | `boolean` | No | — |
| `watermark` | `boolean` | No | — |
| `output_format` | `mp4 \| mov` | No | — |
| `seed` | `number` | No | — |
| `camera_fixed` | `boolean` | No | — |
| `return_last_frame` | `boolean` | No | — |
| `draft` | `boolean` | No | — |
| `service_tier` | `default \| flex` | No | — |
| `callback_url` | `string` | No | — |
| `execution_expires_after` | `number` | No | — |
| `priority` | `number` | No | — |
| `safety_identifier` | `string` | No | — |

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
