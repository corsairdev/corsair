## Available Phone Numbers

### list

`availablePhoneNumbers.list`

Search the numbers available to buy in a country, filtered by area code, locality or type

**Risk:** `read`

```ts
await corsair.telnyx.api.availablePhoneNumbers.list({ countryCode: 'US', locality: 'Chicago', limit: 10 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `countryCode` | `string` | Yes | Two-letter country code to search in, e.g. "US". |
| `pageNumber` | `number` | No | Page of results, starting at 1. |
| `pageSize` | `number` | No | Results per page, from 1 to 250. |
| `locality` | `string` | No | A city to search in. |
| `administrativeArea` | `string` | No | A state or province to search in. |
| `nationalDestinationCode` | `string` | No | An area code to search in. |
| `phoneNumberType` | `local \| toll_free \| mobile \| national \| shared_cost` | No | — |
| `limit` | `number` | No | The maximum number of results, 1 to 250. |

countryCode is required; every other filter, limit included, travels as a filter[..] query key.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `object[]` | Yes | — |
| `meta` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  phone_number?: string | null,
  record_type?: string | null,
  region_information?: Record<string, string>[] | null,
  cost_information?: {
    upfront_cost?: string | null,
    monthly_cost?: string | null,
    currency?: string | null
  } | null,
  features?: {
    name?: string | null
  }[] | null
}[]
```
</Accordion>

<Accordion title="meta full type">

```ts
{
  total_pages?: number | null,
  total_results?: number | null,
  page_number?: number | null,
  page_size?: number | null
} | null
```
</Accordion>
</AccordionGroup>

## Calls

### create

`calls.create`

Place an outbound call through a call control application, which dials the number and bills per minute

**Risk:** `write`

```ts
await corsair.telnyx.api.calls.create({ connection_id: '1293384261075731500', to: '+13125550002', from: '+13125550001' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `connection_id` | `string` | Yes | The call control application that handles the call. |
| `to` | `string` | Yes | The number to dial, in E.164 format. |
| `from` | `string` | Yes | The number to dial from, in E.164 format. |
| `from_display_name` | `string` | No | — |
| `timeout_secs` | `number` | No | — |
| `time_limit_secs` | `number` | No | — |
| `webhook_url` | `string` | No | — |

| `client_state` | `string` | No | Base64 state returned on every webhook for this call. |
| `command_id` | `string` | No | — |

connection_id is the call control application ID, and the call bills per minute once answered.

### send

`messages.send`

Send an SMS or MMS from a Telnyx number, charging the account per part; text or at least one media URL is required

**Risk:** `write`

```ts
await corsair.telnyx.api.messages.send({ from: '+13125550001', to: '+13125550002', text: 'Hello from Telnyx' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `to` | `string` | Yes | The destination number in E.164 format, e.g. "+13125550001". |
| `from` | `string` | No | The sending number or alphanumeric sender ID. Required when sending from a phone number or sender ID; omit it when the number pool on `messaging_profile_id` picks the sender. |
| `text` | `string` | No | The message body. Required for SMS; required for MMS only with media. |
| `messaging_profile_id` | `string` | No | The messaging profile to send through. Required when sending via a number pool or from an alphanumeric sender ID. |
| `media_urls` | `string[]` | No | Media to attach, for MMS. Required for MMS. |
| `subject` | `string` | No | — |
| `webhook_url` | `string` | No | — |
| `use_profile_webhooks` | `boolean` | No | — |
| `type` | `SMS \| MMS` | No | The message type. Telnyx infers it when omitted. |
| `send_at` | `string` | No | An ISO 8601 timestamp to schedule the message. |

Charges the account per part; send from, or a messaging_profile_id so the number pool picks the sender; SMS needs text and MMS needs media_urls.



**Output**

| `data` | `object` | Yes | — |
