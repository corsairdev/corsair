---
title: "DocsBot AI database"
sidebarTitle: "Database"
description: "The DocsBot AI plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for DocsBot AI. To read its data, call the [API operations](/plugins/docsbotai/api), which return what DocsBot AI has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
