---
title: "Token Metrics database"
sidebarTitle: "Database"
description: "The Token Metrics plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Token Metrics. To read its data, call the [API operations](/plugins/tokenmetrics/api), which return what Token Metrics has at that moment.

**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
