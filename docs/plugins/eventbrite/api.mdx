### list

`attendees.list`

List an event's attendees with their ticket class, order, check-in state and barcodes. Private: requires access to the event

**Risk:** `read`

```ts
await corsair.eventbrite.api.attendees.list({ event_id: '2000937221092', status: 'attending' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event_id` | `string \| number` | Yes | The event whose attendees to list. |
| `status` | `attending \| not_attending \| unpaid` | No | Attendee status filter. |
| `changed_since` | `string` | No | Only attendees changed at or after this instant. |
| `last_item_seen` | `number` | No | With `changed_since`, only attendees with a later ID. |
| `attendee_ids` | `(string \| number)[]` | No | Only these attendee IDs. |
| `page_size` | `number` | No | Results per page. Eventbrite defaults to 50 and caps the value at 300. |
| `continuation` | `string` | No | Cursor from the previous response’s `pagination.continuation`. Pass it instead of `page` to walk the list. |
| `page` | `number` | No | Page number, starting at 1. Ignored when `continuation` is set. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `pagination` | `object \| null` | No | — |
| `attendees` | `object[]` | Yes | — |

### list

`discounts.list`

List an organization’s discounts for one scope (`event`, `multi_events` or `user`), optionally by code

**Risk:** `read`

```ts
await corsair.eventbrite.api.discounts.list({ organization_id: '154830740213', scope: 'event', event_id: '2000937221092' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `organization_id` | `string \| number` | Yes | The organization whose discounts to list. |
| `scope` | `event \| multi_events \| user` | Yes | Discount scope. Eventbrite requires it. |
| `event_id` | `string \| number` | No | Required when `scope` is `event`; rejected with `multi_events`. |
| `code_filter` | `string` | No | Approximate code or name match. |
| `code` | `string` | No | Exact code or name match. |
| `type` | `access \| coded \| hold \| public` | No | — |
| `ticket_group_id` | `string \| number` | No | — |
| `hold_ids` | `string[]` | No | — |
| `order_by` | `code_asc \| code_desc \| discount_type_asc \| discount_type_desc \| start_asc \| start_desc` | No | Sorting is only allowed together with exactly one of `code` and `code_filter`. |
| `page_size` | `number` | No | Results per page. Eventbrite defaults to 50 and caps the value at 300. |
| `continuation` | `string` | No | Cursor from the previous response’s `pagination.continuation`. Pass it instead of `page` to walk the list. |
| `page` | `number` | No | Page number, starting at 1. Ignored when `continuation` is set. |

`scope` is required, and `event` scope also requires `event_id`. Sorting needs exactly one of `code` and `code_filter`.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `discounts` | `object[]` | Yes | — |
