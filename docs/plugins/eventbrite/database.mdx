---
title: "Eventbrite database"
sidebarTitle: "Database"
description: "The Eventbrite plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Eventbrite. To read its data, call the [API operations](/plugins/eventbrite/api), which return what Eventbrite has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
