---
title: "Ko-fi database"
sidebarTitle: "Database"
description: "The Ko-fi plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Ko-fi. To read its data, call the [API operations](/plugins/kofi/api), which return what Ko-fi has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
