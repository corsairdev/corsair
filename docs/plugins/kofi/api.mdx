## Webhooks

### listEvents

`webhooks.listEvents`

List the payment types Ko-fi can deliver, from its webhook reference; makes no API call, because Ko-fi has no REST API

**Risk:** `read`

```ts
await corsair.kofi.api.webhooks.listEvents({});
```

**Input:** _empty object_

Returns the four documented payment types from Ko-fi’s webhook reference. Makes no API call, because Ko-fi has none.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `events` | `object[]` | Yes | — |
