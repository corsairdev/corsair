## Competitors

### fetch

`competitors.fetch`

Start the ranking-competitors lookup for a site; answers with an async_call receipt to follow with jobs.lookup. Spends mozscape quota

**Risk:** `read`

```ts
await corsair.moz.api.competitors.fetch({ target_query: { query: 'moz.com', scope: 'domain', locale: 'en-US' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `target_query` | `object` | Yes | — |

`data.site.competitor.fetch` is asynchronous: the answer is an
async_call receipt, and the competitors arrive through jobs.lookup once
the status is complete. It spends the mozscape quota bucket, so the
plugin never replays it after a failure.

<AccordionGroup>
<Accordion title="target_query full type">

```ts
{
  query: string,
  scope: domain | subdomain | subfolder,
  locale: en-US | en-GB | en-CA | en-AU
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `async_call` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="async_call full type">

```ts
{
  id: string,
  action: string,
  status: pending | processing | complete,
  ttl: number,
  result?: Record<string, unknown> | null,

    message: string,
    code: number,
    status: number,
    data?: {
      explanation?: string,
      issue?: string,
      key?: string,

}
```
</Accordion>
</AccordionGroup>

## Jobs

### lookup

`jobs.lookup`

Read an async_call by id: pending or processing means poll again, complete carries the result or the error. Free

**Risk:** `read`

```ts
await corsair.moz.api.jobs.lookup({ id: 'c3397e5a-ce31-42fb-8607-ed40487aea18' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | The async_call.id returned by the asynchronous action that started the request. |

`async.call.lookup` is free and safe to poll every five seconds. A
completed call carries exactly one of async_call.result and
async_call.error, and is only retained for twenty seconds.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `async_call` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="async_call full type">

```ts
{
  id: string,
  action: string,
  status: pending | processing | complete,
  ttl: number,
  result?: Record<string, unknown> | null,
  error?: {
    message: string,
    code: number,
    status: number,
    data?: {
      explanation?: string,
      issue?: string,
      key?: string,
      value?: unknown
    }
  } | null
}
```
</Accordion>
</AccordionGroup>

## Links

### intersect

`links.intersect`

Find sources that link to some targets but not others, a Venn diagram of link profiles (up to 6 targets)

**Risk:** `read`

```ts
await corsair.moz.api.links.intersect({ is_linking_to: [{ query: 'moz.com', scope: 'domain' }], not_linking_to: [{ query: 'ahrefs.com', scope: 'domain' }] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `is_linking_to` | `object[]` | Yes | Get sources that link to at least one of these sites, or more if minimum_matching_targets is set. |
| `not_linking_to` | `object[]` | No | Optionally, ensure that the returned sources do not link to any of these sites. |
| `options` | `object` | No | — |
| `offset` | `object` | No | — |

`data.site.link.intersect.fetch`. At least one target in
is_linking_to, at most six targets across both arrays, and it costs N
rows per result where N is the number of targets in the request.

## Locales

### list

`locales.list`

List every locale a search engine (google, bing or yahoo) supports; costs no rows

**Risk:** `read`

```ts
await corsair.moz.api.locales.list({ engine: 'google' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `engine` | `google \| bing \| yahoo` | Yes | The search engine to list supported locales for; each engine supports a different set. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `engine` | `google \| bing \| yahoo` | Yes | — |
| `locales` | `string[]` | Yes | Every locale the engine supports, e.g. en-US; some have a regional variant such as es-419-AR. |
