### manage

`agents.manage`

Full lifecycle management for monday platform agents — create, read, update, delete, change state, and run — using the Platform MCP.

**Risk:** `destructive`

```ts
await corsair.mondaymcp.api.agents.manage({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `action` | `create \| create_blank \| get \| update \| delete \| activate \| deactivate \| run` | Yes | One of create, create_blank, get, update, delete, activate, deactivate, run. |
| `agent_id` | `string` | No | Required for update, delete, activate, deactivate, run. Use with get to fetch a specific agent; omit it with get to list owned agents. |
| `prompt` | `string` | No | Required for create. Plain-language description of what the agent should do. |
| `agent_model` | `any` | No | Used with create or update. Omit unless the user explicitly names a valid monday-supported model. |
| `name` | `string` | No | Used with create_blank or update. Display name of the agent. |
| `role` | `string` | No | Used with create_blank or update. Short role title (e.g. "Customer Success Bot"). |
| `role_description` | `string` | No | Used with create_blank or update. Detailed description of the agent role. |
| `avatar_url` | `string` | No | Used with create_blank. HTTPS URL of the avatar. Prefer dapulse-res.cloudinary.com or cdn.monday.com. |
| `gender` | `male \| female` | No | Used with create_blank. male or female — a hint for the generated avatar/name when profile fields are omitted. |
| `background_color` | `string` | No | Used with create_blank. Lowercase hex, e.g. "#9450fd". |
| `user_prompt` | `string` | No | Used with create_blank. Stored as metadata; not used for AI generation. |
| `plan` | `string` | No | Used with update. New step-by-step execution plan in markdown. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `content` | `object[]` | Yes | — |
| `isError` | `boolean` | No | — |

```ts

  type?: string,
```

### getItemsPage

`boards.getItemsPage`

Retrieves items from a board with pagination, optional column values, filters, sorting, and sub-item support using the Platform MCP.

**Risk:** `read`

```ts
await corsair.mondaymcp.api.boards.getItemsPage({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|

| `itemIds` | `any[]` | No | Fetch specific items by their IDs (maximum 100). |
