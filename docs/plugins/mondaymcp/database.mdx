---
title: "Monday MCP database"
sidebarTitle: "Database"
description: "The Monday MCP plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Monday MCP. To read its data, call the [API operations](/plugins/mondaymcp/api), which return what Monday MCP has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
