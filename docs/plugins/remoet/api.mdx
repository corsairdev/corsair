## Companies

### get

`companies.get`

**Risk:** `read`

```ts
await corsair.remoet.api.companies.get({ slug: 'starburst' });
```

### search

`companies.search`

Search Remoet's tech companies by name, description, tech stack or seniority, or set starred to list the companies the user has starred. Paginated with page and pageSize (max 100)

**Risk:** `read`

```ts
await corsair.remoet.api.companies.search({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `starred` | `boolean` | No | Set true to list every starred company instead of searching; the other filters and paging are ignored. |
| `searchQuery` | `string` | No | Search keyword: matches company name, description and about text. |
| `techStack` | `string[]` | No | — |
| `techStackMatch` | `any \| all` | No | How techStack combines: "any" (at least one) or "all" (every one required). |
| `experienceLevel` | `junior \| mid \| senior[]` | No | — |
| `sortBy` | `stars \| jobCount \| name` | No | — |
| `page` | `number` | No | Page number, starting from 1. |
| `pageSize` | `number` | No | Results per page, max 100. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `listings` | `object[]` | Yes | — |
| `totalCount` | `number` | Yes | — |
| `page` | `number` | No | — |
| `pageSize` | `number` | No | — |
| `totalPages` | `number` | No | — |
| `hasNextPage` | `boolean` | No | — |
| `starred` | `boolean` | No | — |
| `hint` | `string` | No | — |
| `note` | `string` | No | — |

## Jobs

### search

`jobs.search`

Search Remoet's public tech job catalogue by keywords, tech stack, company, location, remote policy, seniority and salary floor. Each job's firstSeenAt is when Remoet first saw it, not when it was posted. Paginated with page and pageSize (max 50)

**Risk:** `read`

```ts
await corsair.remoet.api.jobs.search({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `searchQuery` | `string` | No | Free text, matched against the job title, summary and tech stack. Comma-separate keywords to require ALL of them. |
| `techStack` | `string[]` | No | Match roles carrying technologies from this list, e.g. ["React", "Go"]. |
| `techStackMatch` | `any \| all` | No | How techStack combines: "any" (at least one) or "all" (every one required). |
| `companySlug` | `string` | No | Restrict to one company by its Remoet slug, e.g. "stripe". |
| `remotePolicy` | `onsite \| hybrid \| remote \| remote-restricted[]` | No | — |
| `experienceLevel` | `junior \| mid \| senior[]` | No | — |
| `salaryMin` | `number` | No | Minimum salary. |
| `location` | `string[]` | No | Place names, e.g. ["Berlin"]. Each may itself contain a comma, e.g. "Portland, OR". |
| `sortBy` | `newest \| salary` | No | — |
| `sortOrder` | `asc \| desc` | No | — |
| `page` | `number` | No | Page number, starting from 1. |
| `pageSize` | `number` | No | Results per page, max 50. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `jobs` | `object[]` | Yes | — |
| `totalCount` | `number` | Yes | — |
| `page` | `number` | Yes | — |
| `pageSize` | `number` | Yes | — |
| `totalPages` | `number` | Yes | — |
| `hasNextPage` | `boolean` | Yes | — |

### update

`profile.update`

Update the user's Remoet profile: contact fields, name, avatarUrl, socials and summary (each may be set to null to clear it, 500 characters max, 5000 for summary), and visibility. Visibility controls who can see the profile in company candidate lists: NONE hides it from every company, STARRED shows it only to companies the user has starred, and ALL shows it to every company on Remoet

**Risk:** `write`

```ts
await corsair.remoet.api.profile.update({ location: 'Stockholm' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `phone` | `string \| null` | No | Phone number. Null clears it. |
| `url` | `string \| null` | No | Personal website URL. Null clears it. |
| `location` | `string \| null` | No | Location. Null clears it. |
| `githubUrl` | `string \| null` | No | GitHub profile URL. Null clears it. |
| `linkedinUrl` | `string \| null` | No | LinkedIn profile URL. Null clears it. |
| `name` | `string \| null` | No | Full name. Null clears it. |
| `avatarUrl` | `string \| null` | No | Avatar/photo URL. Null clears it. |
| `facebookUrl` | `string \| null` | No | Facebook profile URL. Null clears it. |
| `twitterUrl` | `string \| null` | No | Twitter/X profile URL. Null clears it. |
| `youtubeUrl` | `string \| null` | No | YouTube channel URL. Null clears it. |
| `summary` | `string \| null` | No | Brief professional summary or bio. Null clears it. |
| `visibility` | `NONE \| STARRED \| ALL` | No | Who can see the profile in company candidate lists. Not writable to null; leave it out to leave it unchanged. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `updated` | `string[]` | Yes | — |
