## Administrations

### list

`administrations.list`

List the administrations the token can access, with id, name, currency and access level

**Risk:** `read`

```ts
await corsair.moneybird.api.administrations.list({});
```

**Input:** _empty object_

`GET /api/v2/administrations.json`, the one resource above the
administration scope. Returns `{ administrations: [{ id, name, language,
currency, country, time_zone, access, suspended, ... }] }`.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `administrations` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="administrations full type">

```ts
{
  id: string,
  name?: string | null,
  language?: string | null,
  currency?: string | null,
  country?: string | null,
  time_zone?: string | null,
  access?: string | null,
  suspended?: boolean | null,
  period_locked_until?: string | null,
  period_start_date?: string | null
}[]
```
</Accordion>
</AccordionGroup>
