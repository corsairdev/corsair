## Image

### generate

`image.generate`

Generate or edit images with Qwen-Image 3.0 or Wan 2.7 Image; returns image URLs valid for 24 hours

**Risk:** `write`

```ts
await corsair.alibaba.api.image.generate({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `model` | `qwen-image-3.0-pro \| qwen-image-3.0 \| wan2.7-image-pro \| wan2.7-image` | Yes | — |
| `prompt` | `string` | Yes | — |
| `images` | `string[]` | No | — |
| `parameters` | `object` | No | — |

<AccordionGroup>
<Accordion title="parameters full type">

```ts
{
  size?: string,
  n?: number,
  seed?: number,
  watermark?: boolean,
  negative_prompt?: string,
  prompt_extend?: boolean,
  prompt_extend_mode?: direct | agent,
  enable_thinking?: boolean,
  thinking_mode?: boolean,
  enable_sequential?: boolean,
  bbox_list?: tuple[][],
  color_palette?: {
    hex: string,
    ratio: string
  }[]
}
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `output` | `object` | Yes | — |
| `usage` | `object` | No | — |
| `request_id` | `string` | Yes | — |

<AccordionGroup>
<Accordion title="output full type">

```ts
{
  rewrite_status?: string | null,
  choices: {
    finish_reason?: string | null,
    message: {
      role: string,
      content: {
        image: string
      }[]
    }
  }[]
}
```
</Accordion>

<Accordion title="usage full type">

```ts
{
  output_width?: number | null,
  output_height?: number | null,
  input_image_count?: number | null,
  output_image_count?: number | null,
  input_image_type?: string | null,
  output_image_type?: string | null,
  width?: number | null,
  height?: number | null,
  image_count?: number | null
}
```
</Accordion>
</AccordionGroup>

## Tasks

### get

`tasks.get`

Get a generation task status and, once it succeeds, the video URL (valid 24 hours)

**Risk:** `read`

```ts
await corsair.alibaba.api.tasks.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `task_id` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `output` | `object` | Yes | — |
| `usage` | `object` | No | — |
| `request_id` | `string` | Yes | — |

<AccordionGroup>
<Accordion title="output full type">

```ts
{
  task_id: string,
  task_status: PENDING | RUNNING | SUCCEEDED | FAILED | CANCELED | UNKNOWN,
  submit_time?: string | null,
  scheduled_time?: string | null,
  end_time?: string | null,
  video_url?: string | null,
  orig_prompt?: string | null,
  code?: string | null,
  message?: string | null
}
```
</Accordion>

<Accordion title="usage full type">

```ts
{
  duration?: number | null,

  output_video_duration?: number | null,
  SR?: number | null,

}
```
</Accordion>
</AccordionGroup>
