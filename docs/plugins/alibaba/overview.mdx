Use **Alibaba Cloud Model Studio** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 6 typed API operations
- 2 synced entities (`images`, `videoTasks`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/alibaba better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/alibaba better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/alibaba better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/alibaba better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { alibaba } from '@corsair-dev/alibaba';

export const corsair = createCorsair({
	plugins: [
		alibaba(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Alibaba Cloud Model Studio API key before the first call: `pnpm corsair setup --plugin=alibaba --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
alibaba()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'alibaba',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Check a task**

```ts
const tenant = corsair.withTenant('acme');
await tenant.alibaba.api.tasks.get({ task_id: '0385dc79-5ff8-4d82-bcb6-xxxxxxxxxxxx' });
```


**`image.generate`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.alibaba.api.image.generate({});
```


See the full list on the [API](/plugins/alibaba/api) page.

## Query synced data

Search synced images without hitting Alibaba Cloud.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.alibaba.db.images.search({
	data: {},
	limit: 50,
});
```

Synced entities: `images`, `videoTasks`. See [Database](/plugins/alibaba/database) for filters and operators.
