---
title: "EmailOctopus database"
sidebarTitle: "Database"
description: "The EmailOctopus plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for EmailOctopus. To read its data, call the [API operations](/plugins/emailoctopus/api), which return what EmailOctopus has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
