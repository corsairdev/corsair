### search

`contacts.search`

Search contacts by name, email or phone. Google warms this index per account, so the first call after authorizing can return nothing; retry.

**Risk:** `read`

```ts
await corsair.googlecontacts.api.contacts.search({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `query` | `string` | Yes | Prefix-matched against names, nicknames, emails and phones |
| `readMask` | `string[]` | No | Person fields to return, e.g. ["names","emailAddresses","phoneNumbers"]. Defaults to names, emailAddresses and phoneNumbers. |
| `pageSize` | `number` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `results` | `object[]` | No | — |

<AccordionGroup>
<Accordion title="results full type">

```ts
{
  person?: {
```
