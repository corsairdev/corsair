## Campaigns

### create

`campaigns.create`

Create a campaign in draft from a sequence graph; it contacts nobody until campaigns.update sets it active

**Risk:** `write`

```ts
await corsair.needle.api.campaigns.create({ name: 'EMEA logistics Q4', graph: { nodes: [{ id: 'start', kind: 'start' }, { id: 'end', kind: 'end' }], edges: [{ from: 'start', to: 'end' }] } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | Yes | — |
| `graph` | `object` | Yes | — |

The campaign starts in draft and contacts nobody until campaigns.update sets status active.

<AccordionGroup>
<Accordion title="graph full type">

```ts
{
  nodes: {
    id: string,
    kind: start | end | delay | action,
    label?: string,
    duration?: {
      days?: number,
      hours?: number,
      minutes?: number

    channel?: linkedin | instagram,
    connectedAccountId?: string,
    action?: linkedin_invitation | linkedin_cancel_invitation | linkedin_message | linkedin_inmail | linkedin_profile_view | linkedin_search | linkedin_comment | linkedin_reaction | linkedin_post_view | linkedin_company_view | linkedin_job_view | linkedin_conversation_view | linkedin_network_view | linkedin_invitation_list | linkedin_invitation_response | linkedin_search_parameter | linkedin_inmail_balance | linkedin_own_profile | instagram_message | instagram_profile_view | instagram_follow | instagram_unfollow | instagram_comment | instagram_reaction | instagram_post | instagram_post_view | instagram_conversation_view | instagram_network_view | instagram_own_profile,
```

### enroll

`campaigns.enroll`

Enroll up to 500 leads at once, with one result per lead so a batch can partly succeed; an enrolled lead can be contacted

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.needle.api.campaigns.enroll({ campaignId: '4d5e6f7a-8b9c-4d0e-9f1a-2b3c4d5e6f7a', leadIds: ['1a2b3c4d-5e6f-4a7b-8c9d-0e1f2a3b4c5d'] });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `campaignId` | `string` | Yes | — |
| `leadIds` | `string[]` | Yes | Leads to enroll, by id. Create them first. |

One result comes back per lead, so a batch can partly succeed; a skipped entry carries the reason.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `results` | `object[]` | Yes | — |

## Compose

### preview

`compose.preview`

Preview an AI-composed message for a lead without sending it, with the context sources it used

**Risk:** `read`

```ts
await corsair.needle.api.compose.preview({ channel: 'linkedin', connectedAccountId: '2f1c8d9e-3a5b-4c6d-8e9f-0a1b2c3d4e5f', identity: 'dana-okafor', prompt: 'Mention the Rotterdam hub and ask for a short call.' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `channel` | `linkedin \| instagram` | Yes | — |
| `connectedAccountId` | `string` | Yes | The connected account the message would be sent from. |
| `identity` | `string` | Yes | Who the message is for: a LinkedIn identifier, path, URL or user id, or an Instagram username, handle or URL. |
| `prompt` | `string` | Yes | What the message should say, in plain instructions. |
| `context` | `(profile \| posts \| conversation \| lead_properties)[]` | No | What the composer may read. Defaults at the provider to conversation only. |
| `maxChars` | `number` | No | An upper bound on the message length. |
| `leadProperties` | `Record<string, string>` | No | Facts about the lead the composer may use. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `text` | `string` | Yes | — |
| `meta` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="meta full type">

```ts
{
  contextUsed?: {
    source?: string | null,
    cached?: boolean | null
  }[] | null
} | null
```
</Accordion>
</AccordionGroup>
