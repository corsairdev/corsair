Use **Google Address Validation** through Corsair: one client, typed API calls, optional local DB sync.

**What you get:**

- 2 typed API operations

## Setup

<Steps>

<Step title="Install">
```bash
pnpm install @corsair-dev/googleaddressvalidation
```

</Step>

<Step title="Add the plugin">
<Tabs>
<Tab title="Solo">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { googleaddressvalidation } from '@corsair-dev/googleaddressvalidation';

export const corsair = createCorsair({
	// ... other config options,
	multiTenancy: false,
    plugins: [googleaddressvalidation()],
});
```
</Tab>
<Tab title="Multi-Tenant">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { googleaddressvalidation } from '@corsair-dev/googleaddressvalidation';

export const corsair = createCorsair({
	// ... other config options,
    multiTenancy: true,
    plugins: [googleaddressvalidation()],
});
```

See [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Tab>
</Tabs>

</Step>

<Step title="Get credentials">
Follow [Get Credentials](/plugins/googleaddressvalidation/get-credentials) if you need help getting keys.

</Step>

<Step title="Store credentials">
<Tabs>
<Tab title="Solo">
```bash
pnpm corsair setup --plugin=googleaddressvalidation
```

Use the key names documented in [Get Credentials](/plugins/googleaddressvalidation/get-credentials) (for example `api_key=`, `bot_token=`, or OAuth client fields).
</Tab>
<Tab title="Multi-Tenant">
```bash
pnpm corsair setup --plugin=googleaddressvalidation --tenant=<tenantId>
```

Store per-tenant secrets after you create the tenant record. See [Multi-tenancy](/concepts/multi-tenancy).
</Tab>
</Tabs>

</Step>

</Steps>

## Authentication

Each tab shows how to register the plugin for that authentication method. The default `authType` from the plugin does not need to appear in the factory call.

<Tabs>
<Tab title="API Key (Default)">

```ts corsair.ts
googleaddressvalidation()
```

Store credentials with `pnpm corsair setup --plugin=googleaddressvalidation` (see [Get Credentials](/plugins/googleaddressvalidation/get-credentials) for field names). For OAuth, you typically store integration keys at the provider level and tokens per account or tenant.

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>



## Example API calls

**Read-style (read):** `address.validate`

```ts
await corsair.googleaddressvalidation.api.address.validate({});
```


**Write-style (write):** `address.provideFeedback`

```ts
await corsair.googleaddressvalidation.api.address.provideFeedback({});
```


See the full list on the [API](/plugins/googleaddressvalidation/api) page. Use `pnpm corsair list --plugin=googleaddressvalidation` and `pnpm corsair schema <path>` locally to inspect schemas.
