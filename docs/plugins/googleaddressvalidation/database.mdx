---
title: "Google Address Validation database"
sidebarTitle: "Database"
description: "The Google Address Validation plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for Google Address Validation. To read its data, call the [API operations](/plugins/googleaddressvalidation/api), which return what Google Address Validation has at that moment.

</Info>
