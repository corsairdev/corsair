Use **Listclean** through Corsair: one client, typed API calls.

Create an API token at app.listclean.xyz under Integration/API &gt; API tokens, then Add. The token is sent in the `X-Auth-Token` header as a plain value, with no Bearer prefix.

Things to know before you call:

- **Every answer is one envelope.** `{ success, error_code, message, data }` where `success` is an integer: `1` on success, `0` on failure, even over a 2xx status. The plugin throws on `success: 0` and on non-JSON bodies, so a 404 HTML page never comes back as an empty result.
- **Billed calls.** `verify.verifyEmail` spends one credit per call, and `verify.startBatchVerification` spends one credit per address when the job runs. Both carry `replayable: false`, so a lost answer or a 5xx is never retried and may have already been charged. Check `account.getCredits` first; signup comes with 25 free credits.
- **Bulk verification is a job.** `verify.startBatchVerification` answers `list_id`. Poll `lists.getList`, whose `list.status` moves `SUBMITTED`, `INPROCESS`, `COMPLETED`. Listclean documents no failed status for this flow. Once `COMPLETED`, download rows with `lists.getListResults`, choosing `clean`, `dirty` or `unknown`.
- **Analytics shapes are undocumented.** Listclean's spec leaves `total_summary`, `datewise_summary` and `graph_summary` without inner fields, so those come back exactly as the API sends them rather than typed.
- **Deletes are permanent.** `lists.delete` cannot be undone and the results cannot be fetched afterwards.
- **Deferred for a later release.** The chunked CSV upload flow (`/uploads/`) and the account profile read/update are not in this plugin, and neither is the CSV download, which the JSON download covers.
- **Webhooks.** Listclean sends none, and the plugin does not receive any.

**What you get:**

- 9 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/listclean better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/listclean better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/listclean better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/listclean better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { listclean } from '@corsair-dev/listclean';

export const corsair = createCorsair({
	plugins: [
		listclean(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Listclean API key before the first call: `pnpm corsair setup --plugin=listclean --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
listclean()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'listclean',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Verify one address**

```ts
const tenant = corsair.withTenant('acme');
await tenant.listclean.api.verify.verifyEmail({ email: 'test@example.com' });
```


**Start a batch verification**

```ts
const tenant = corsair.withTenant('acme');
await tenant.listclean.api.verify.startBatchVerification({
	emails: ['user1@example.com', 'user2@example.com'],
});
```


See the full list on the [API](/plugins/listclean/api) page.
