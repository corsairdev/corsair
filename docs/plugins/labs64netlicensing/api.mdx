### transfer

`licensees.transfer`

Move every license of a source licensee (marked for transfer) to this licensee; NetLicensing then removes the source licensee.

**Risk:** `destructive`

```ts
await corsair.labs64netlicensing.api.licensees.transfer({ licenseeNumber: 'I002', sourceLicenseeNumber: 'I001' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `licenseeNumber` | `string` | Yes | Licensee that receives the licenses |
| `sourceLicenseeNumber` | `string` | Yes | Licensee whose licenses move; must be markedForTransfer |

The source licensee needs `markedForTransfer` set (licensees.update) and both licensees must belong to the same product. Validating the source clears the flag. After the move NetLicensing removes the source licensee.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `transferred` | `true` | Yes | — |
| `licenseeNumber` | `string` | Yes | — |
| `sourceLicenseeNumber` | `string` | Yes | — |

### validate

`licensees.validate`

Check which product modules a licensee may use; floating checkouts and pay-per-use counts change unless dryRun is true.

**Risk:** `destructive`

```ts
await corsair.labs64netlicensing.api.licensees.validate({ licenseeNumber: 'I001', dryRun: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `licenseeNumber` | `string` | Yes | Licensee number or alias |
| `productNumber` | `string` | No | Needed when the licensee does not exist yet and the product auto-creates licensees |
| `licenseeName` | `string` | No | — |
| `dryRun` | `boolean` | No | Validate without saving any change |
| `forOfflineUse` | `boolean` | No | — |
| `parameters` | `Record<string, string>` | No | Per-module parameters as NetLicensing names them, e.g. &#123; productModuleNumber: "M001", sessionId: "abc", action: "checkOut" &#125; |

Returns one entry per product module with its licensing model and validity, plus `ttl`, the time until which the result can be reused. Pass module parameters (sessionId and action for Floating, usedQuantity for PayPerUse, nodeSecret for NodeLocked) in `parameters`. A product with no active module answers 404.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `ttl` | `string` | No | Reuse this result until this time, then validate again |
| `validations` | `object[]` | Yes | — |

## License Templates

### create

`licenseTemplates.create`

Create a license template in a product module.

**Risk:** `write`

```ts
await corsair.labs64netlicensing.api.licenseTemplates.create({ productModuleNumber: 'M001', name: 'Monthly', licenseType: 'TIMEVOLUME', timeVolume: '1', timeVolumePeriod: 'MONTH', price: '9.99', currency: 'EUR' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `number` | `string` | No | Template number; generated when left out |
| `productModuleNumber` | `string` | Yes | — |
| `name` | `string` | Yes | — |
| `licenseType` | `FEATURE \| TIMEVOLUME \| FLOATING \| QUANTITY` | Yes | Must fit the module licensing model |
| `active` | `boolean` | No | — |
| `price` | `string` | No | Decimal price; above 0 needs currency |
| `currency` | `EUR \| USD` | No | — |
| `automatic` | `boolean` | No | Give every new licensee one license |
| `hidden` | `boolean` | No | — |
| `hideLicenses` | `boolean` | No | — |
| `timeVolume` | `string` | No | — |
| `timeVolumePeriod` | `DAY \| WEEK \| MONTH \| YEAR` | No | — |
| `maxSessions` | `string` | No | — |
| `quantity` | `string` | No | — |
| `gracePeriod` | `boolean` | No | — |
| `promoCode` | `string` | No | — |
| `discountType` | `PERCENT \| FIX` | No | — |
| `discountAmount` | `string` | No | — |
| `discountCurrency` | `string` | No | — |
| `minCartTotal` | `string` | No | — |
| `startDate` | `string` | No | — |
| `endDate` | `string` | No | — |
| `customProperties` | `Record<string, string>` | No | Extra fields NetLicensing stores as custom properties |

`licenseType` must fit the module model: FEATURE or TIMEVOLUME for TryAndBuy and Rental, TIMEVOLUME for Subscription, FLOATING for Floating, QUANTITY for PayPerUse, Quota and NodeLocked. A price above 0 needs `currency`.
