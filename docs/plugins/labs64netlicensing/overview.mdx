Use **Labs64 NetLicensing** through Corsair: one client, typed API calls, local DB sync.

Create an API key in the NetLicensing console under Settings &gt; API Access. Its role decides what the plugin can do: a Licensee key only validates and transfers its own licensee, Analytics reads everything, Operation also writes licensees and licenses, and Maintenance also writes products, modules and templates. The key is sent as HTTP Basic with the username `apiKey`.

Things to know:

- **How the pieces fit.** A product has product modules; each module has a licensing model (TryAndBuy, Subscription, Floating, PayPerUse, ...) and license templates. A licensee is one of your customers under a product, and a license is created for a licensee from a template.
- **Every value is a string.** NetLicensing returns each entity as a list of properties. `get`, `create` and `update` return `item` with `number`, `active` and `name` lifted out and every property, custom ones included, in `properties`; nested lists such as product discounts are in `lists`.
- **Custom properties.** Any field NetLicensing does not know is stored as a custom property: pass them in `customProperties`.
- **Paging.** List calls take `filter`, `;`-separated `key=value` pairs such as `page=0;items=50`, and return `page` (pageNumber, totalPages, totalItems, hasNext).
- **Validation changes state.** `licensees.validate` checks out floating sessions and uses up pay-per-use and quota amounts unless `dryRun` is true, so it is `destructive`; it also clears the licensee's `markedForTransfer` flag.
- **Deletes.** `forceCascade: true` also deletes what depends on the entity (a product's modules, templates, licensees and licenses). Deletes can't be undone.

**What you get:**

- 29 typed API operations
- 2 synced entities (`licenses`, `products`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/labs64netlicensing better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/labs64netlicensing better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/labs64netlicensing better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/labs64netlicensing better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { labs64netlicensing } from '@corsair-dev/labs64netlicensing';

export const corsair = createCorsair({
	plugins: [
		labs64netlicensing(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Labs64 NetLicensing API key before the first call: `pnpm corsair setup --plugin=labs64netlicensing --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
labs64netlicensing()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'labs64netlicensing',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List licensees**

```ts
const tenant = corsair.withTenant('acme');
await tenant.labs64netlicensing.api.licensees.list({ filter: 'page=0;items=20' });
```


**Create a licensee**

```ts
const tenant = corsair.withTenant('acme');
await tenant.labs64netlicensing.api.licensees.create({ productNumber: 'P001', name: 'Acme Corp' });
```


See the full list on the [API](/plugins/labs64netlicensing/api) page.

## Query synced data

Synced entities support `tenant.labs64netlicensing.db.<entity>.search()` and `.list()`: `licenses`, `products`.

See [Database](/plugins/labs64netlicensing/database) for filters and operators.
