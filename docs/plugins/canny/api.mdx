## Boards

### list

`boards.list`

List all boards for your company in Canny

**Risk:** `read`

```ts
await corsair.canny.api.boards.list({});
```

**Input:** _empty object_


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `boards` | `object[]` | Yes | — |
