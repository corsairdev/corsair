## Attendees

### checkin

`attendees.checkin`

Check an attendee in, or revert their check-in, by ticket barcode. Passing `eventcheckin: true` twice is harmless.

**Risk:** `write`

```ts
await corsair.eventzilla.api.attendees.checkin({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `barcode` | `string` | Yes | The `bar_code` from the attendee or ticket record. |
| `eventcheckin` | `boolean` | Yes | true to check in, false to revert a check-in. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `checkinstatus` | `object` | Yes | — |
| `checkedIn` | `boolean \| null` | Yes | True only when `checkinstatus.status` confirms a check-in this call asked for. False when the status reports a failure, an "already" state or a revert; null when the status text does not say. A revert (`eventcheckin: false`) therefore never answers true: read `checkinstatus.status` for its outcome. Eventzilla answers HTTP 200 even for a failed check-in, so read this rather than the status code. |

```ts
{
  firstname?: string | null,
  lastname?: string | null,
  eventtitle?: string | null,
  orderref?: string | null,
  email?: string | null,
  status?: string | null
}
```
</Accordion>
</AccordionGroup>

### list

`events.list`

The account's events, paged with offset. Filter by status (only "live" is accepted) or category, and page with the returned next_offset. An empty account answers HTTP 200 with &#123;"message":"No events found"&#125; rather than an array, which is read here as an empty page.

**Risk:** `read`

```ts
await corsair.eventzilla.api.events.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `status` | `live` | No | Only `live` is accepted. Every other value, including the capitalised spellings, is rejected by the API. |
| `category` | `string` | No | Only this category name. |
| `offset` | `number` | No | Records to skip. Defaults to 0. |
| `limit` | `number` | No | Records to return. Defaults to 20. |

Only status: live is accepted; every other value is rejected by the API. Set category to a name from categories.list.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `pagination` | `object[] \| null` | No | — |
| `events` | `object[]` | Yes | — |
| `next_offset` | `number \| null` | Yes | Offset of the next page, or null when this is the last one. Pass it back as `offset`. |
| `message` | `string` | No | — |
