Use **Eventzilla** through Corsair: one client, typed API calls.

Eventzilla authenticates with an `x-api-key` header. Create a key in your
Eventzilla account under **Settings > Developers > API Credentials**, then
save it for the `eventzilla` integration.

The checkout workflow runs in four steps and each one needs the event's
`dateid`, not its `id`: `checkout.prepare` (what is on sale, and the
`payment_id` to use), `checkout.create` (reserve, and get one
`ticket_price_id` per ticket), `checkout.fillOrder` (buyer and attendee
details), then `checkout.confirm` (record the payment). A reservation holds
inventory until it is confirmed or abandoned.

Eventzilla posts webhooks, but does not sign them and documents no secret to
verify one with, so this plugin registers no inbound webhook: a delivery
cannot be told apart from a forged request.

List operations page with `offset` and `limit`; each result carries
`next_offset`, which is null on the last page. `events.get`,
`attendees.get` and `users.get` answer an array, and an empty one for an
unknown id rather than a 404. `transactions.get` answers an array too, but
an unknown reference is a 404 error, not an empty result.

**What you get:**

- 20 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/eventzilla better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/eventzilla better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/eventzilla better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/eventzilla better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { eventzilla } from '@corsair-dev/eventzilla';

export const corsair = createCorsair({
	plugins: [
		eventzilla(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Eventzilla API key before the first call: `pnpm corsair setup --plugin=eventzilla --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
eventzilla()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'eventzilla',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List the account's live events**

```ts
const tenant = corsair.withTenant('acme');
await tenant.eventzilla.api.events.list({ limit: 10 });
```


**Check an attendee in by barcode**

```ts
const tenant = corsair.withTenant('acme');
await tenant.eventzilla.api.attendees.checkin({ barcode: 'EZ202605200001', eventcheckin: true });
```


See the full list on the [API](/plugins/eventzilla/api) page.
