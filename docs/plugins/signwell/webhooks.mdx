The SignWell plugin handles incoming webhooks. Point your provider’s subscription URL at your Corsair HTTP handler (see [Overview](/plugins/signwell/overview) for setup context and the exact URL shape).

<Info>
**New to Corsair?** See [webhooks](/concepts/webhooks) and [hooks](/concepts/hooks).
</Info>

## Webhook map

- `document`
  - `canceled` (`document.canceled`)
  - `completed` (`document.completed`)
  - `created` (`document.created`)
  - `declined` (`document.declined`)
  - `expired` (`document.expired`)
  - `inProgress` (`document.inProgress`)
  - `recipientsUpdated` (`document.recipientsUpdated`)
  - `sent` (`document.sent`)
  - `signed` (`document.signed`)
  - `viewed` (`document.viewed`)

## HTTP handler setup

```ts app/api/webhook/route.ts
import { processWebhook } from "corsair";
import { corsair } from "@/server/corsair";

export async function POST(request: Request) {
    const headers = Object.fromEntries(request.headers);
    // With multiTenancy, give each tenant its own URL (/api/webhook?tenantId=acme):
    // the query says whose account, secret and hooks handle the delivery.
    const query = Object.fromEntries(new URL(request.url).searchParams);
    // The raw text, not request.json(): signatures are checked over the exact bytes sent.
    const body = await request.text();
    const result = await processWebhook(corsair, headers, body, query);
    if (!result.plugin) {
        return Response.json({ success: false }, { status: 404 });
    }
    // A refusal (bad signature) carries no status and answers 400; a handler
    // that threw comes back with 500, so the sender retries it.
    const status =
        result.response?.success === false ? (result.response.statusCode ?? 400) : 200;
    return Response.json(result.response ?? { success: true }, {
        status,
        headers: result.responseHeaders,
    });
}
```

## Events

## Document

### Canceled

`document.canceled`

The sender canceled the document.

**Payload**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `event` | `object` | Yes | — |
| `data` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="event full type">

```ts
{
  hash: string,
  time: number,
  type: string,
  related_signer?: {
    email?: string | null,
    name?: string | null
  } | null
}
```
</Accordion>

<Accordion title="data full type">

```ts
{
  object: Record<string, any>
}
```
</Accordion>
</AccordionGroup>



<AccordionGroup>
<Accordion title="Response data full type">

```ts
{
  event: {
    hash: string,
    time: number,
    type: string,
    related_signer?: {
      email?: string | null,
      name?: string | null
    } | null
  },
  data: {
    object: Record<string, any>
  }
}
```
</Accordion>
</AccordionGroup>

**`webhookHooks` example**

```ts
signwell({
    webhookHooks: {
        document: {
            canceled: {
                before(ctx, args) {
                    return { ctx, args };
                },
                after(ctx, response) {
                },
            },
        },
    },
})
```
