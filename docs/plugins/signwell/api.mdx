### update

`account.update`

Change the account name, logo, time zone, date format or recipient language; only the fields you send are changed

**Risk:** `write`

```ts
await corsair.signwell.api.account.update({ name: 'Acme Logistics', date_format: 'DD/MM/YYYY' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | — |
| `logo` | `string` | No | A base64 PNG or JPG (a data URI works), or a public URL. The decoded image must be under 300 KB. |
| `time_zone` | `string` | No | An IANA name SignWell supports. A few newer aliases are rejected: send Europe/Kiev, not Europe/Kyiv. |
| `date_format` | `MM/DD/YYYY \| DD/MM/YYYY \| YYYY/MM/DD \| Month DD, YYYY \| MM/DD/YYYY hh:mm:ss a` | No | — |
| `recipient_language` | `string \| null` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `name` | `string` | Yes | — |
| `logo_url` | `string \| null` | No | — |
| `plan_tier` | `string` | Yes | — |
| `preferences` | `object` | Yes | — |

## Api Applications

### delete

**Input**

**Output**

## Bulk Sends

### create

`bulkSends.create`

Create a bulk send from a CSV of recipient rows against one or more templates; each row becomes a document and is sent

**Risk:** `destructive`

```ts
await corsair.signwell.api.bulkSends.create({ template_ids: ['d7315111-c671-4b15-8354-c9a19bbaefa0'], bulk_send_csv: 'bmFtZSxlbWFpbApUZXN0LHRlc3RAZXhhbXBsZS5jb20K' });
```

|------|------|----------|-------------|
| `template_ids` | `string[]` | Yes | — |

## Documents

### create

`documents.create`

Create a document from one or more files and send it for signature unless draft is true; this notifies real recipients

**Risk:** `destructive`

```ts
await corsair.signwell.api.documents.create({ files: [{ name: 'offer.pdf', file_url: 'https://acme.example/offer.pdf' }], recipients: [{ id: '1', name: 'Jordan Lee', email: 'jordan@acme-logistics.com' }], subject: 'Please sign the offer', draft: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `files` | `object[]` | Yes | — |
| `recipients` | `object[]` | Yes | — |
| `test_mode` | `boolean` | No | SignWell does not bill a test-mode document and it is not legally binding. Defaults to false. |
| `name` | `string` | No | The document name shown in the SignWell UI. |
| `subject` | `string` | No | Email subject. Applies to email notifications only. |
| `message` | `string` | No | Email body. Applies to email notifications only. |
| `draft` | `boolean` | No | When true the document is not sent. Defaults to false, which sends it immediately. |
| `expires_in` | `number` | No | Days before the request expires. |
| `reminders` | `boolean` | No | Send reminders on days 3, 6 and 9 to recipients who have not signed. |
| `apply_signing_order` | `boolean` | No | Recipients sign one at a time, in order. |
| `redirect_url` | `string` | No | Where recipients land after signing. |
| `decline_redirect_url` | `string` | No | Where recipients land after declining. |
| `allow_decline` | `boolean` | No | — |
| `allow_reassign` | `boolean` | No | — |
| `language` | `string` | No | A supported language code, such as en or fr. |
| `text_tags` | `boolean` | No | Place fields with text tags in the document instead of coordinates. |
| `metadata` | `Record<string, string>` | No | Your own key-value data, returned on every read. |
| `labels` | `object[]` | No | — |
| `attachment_requests` | `object[]` | No | — |
| `conditional_rules` | `object[]` | No | — |
| `api_application_id` | `string` | No | Use a specific API application's branding and settings. |
| `self_sign` | `boolean` | No | The creator signs without any field setup, using embedded_edit_url. Unavailable on 21 CFR Part 11 documents. |
| `with_signature_page` | `boolean` | No | Append a signature page and require every signer to sign there. |
| `embedded_signing` | `boolean` | No | — |
| `embedded_signing_notifications` | `boolean` | No | — |
| `fields` | `object[]` | No | Fields per file; one inner array for each entry in files. SignWell requires at least one field when draft is false and with_signature_page is not set. |
| `copied_contacts` | `object[]` | No | — |
| `sms_test_email` | `boolean` | No | On a test-mode document, send SMS notifications here instead. |

Set draft: true to create without notifying anyone. Without it SignWell sends the request immediately. Each file also needs file_url or file_base64, never both: the schema rejects a call that sends both or neither.
