---
title: Database
description: "Flutterwave currently does not sync entities into the local database."
---

The Flutterwave plugin currently has no synced entities in `FlutterwaveSchema.entities`, so `corsair.flutterwave.db.*` search operations are not available yet.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
