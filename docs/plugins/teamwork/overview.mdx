Use **Teamwork** through Corsair: one client, typed API calls.

Store each tenant's Teamwork site as site_name with its API key: acme for acme.teamwork.com, acme.eu for an EU site. The optional siteName plugin option is a global single-site override.

**What you get:**

- 220 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/teamwork better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/teamwork better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/teamwork better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/teamwork better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { teamwork } from '@corsair-dev/teamwork';

export const corsair = createCorsair({
	plugins: [
		teamwork(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Teamwork API key before the first call: `pnpm corsair setup --plugin=teamwork --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
teamwork()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'teamwork',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List a project's open tasks**

```ts
const tenant = corsair.withTenant('acme');
await tenant.teamwork.api.tasks.list({
	query: {
		projectIds: [1470497],
		includeCompletedTasks: false,
	},
});
```


**Create a task without emailing anyone**

```ts
const tenant = corsair.withTenant('acme');
await tenant.teamwork.api.tasks.create({
	path: { tasklistId: 4073104 },
	body: {
		task: { name: 'Draft the launch post' },
		taskOptions: { notify: false },
	},
});
```


See the full list on the [API](/plugins/teamwork/api) page.
