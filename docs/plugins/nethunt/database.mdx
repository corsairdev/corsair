---
title: "NetHunt CRM database"
sidebarTitle: "Database"
description: "The NetHunt CRM plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for NetHunt CRM. To read its data, call the [API operations](/plugins/nethunt/api), which return what NetHunt CRM has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
