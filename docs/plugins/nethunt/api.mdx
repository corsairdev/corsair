|------|------|----------|-------------|
| `user` | `object` | Yes | — |

### changes

`records.changes`

Read the audit trail for a folder: who changed which field, when, with before and after values, including deletes

**Risk:** `read`

```ts
await corsair.nethunt.api.records.changes({ folderId: '596f644b8f6d05e16c24b810', since: '2026-01-01T00:00:00.000Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `folderId` | `string` | Yes | The folder's id, from folders.list. |
| `recordId` | `string` | No | The record id. |
| `fieldNames` | `string[]` | No | — |
| `since` | `string` | No | An ISO 8601 instant, e.g. 2026-01-01T00:00:00.000Z. |
| `limit` | `number` | No | — |

This is the only route that reports a delete, and it carries before and after values per field.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `changes` | `object[]` | Yes | — |

### create

`records.create`

Create one record in a folder from a flat map of the folder’s field names, with the time zone NetHunt needs to read dates

**Risk:** `write`

```ts
await corsair.nethunt.api.records.create({ folderId: '596f644b8f6d05e16c24b810', timeZone: 'Europe/London', fields: { Name: 'John Doe', Country: 'GB' } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `folderId` | `string` | Yes | The folder's id, from folders.list. |
| `timeZone` | `string` | Yes | The user’s time zone, an IANA name such as Europe/London. NetHunt requires it on every create and uses it to interpret date fields. |
| `fields` | `Record<string, string \| number \| boolean \| null \| (string \| number \| boolean)[]>` | Yes | The folder’s field names mapped to their values. Names are per-folder and set by the user. |

The fields map uses the folder’s own field names, and timeZone is required so NetHunt can read date values.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `recordId` | `string \| null` | No | — |
| `createdAt` | `string \| null` | No | — |
| `fields` | `Record<string, string \| number \| boolean \| null \| (string \| number \| boolean)[]> \| null` | No | The folder’s field names mapped to their values. Names are per-folder and set by the user. |

### update

`records.update`

Update a record’s fields through per-field actions, each able to overwrite, remove or add values

**Risk:** `write`

```ts
await corsair.nethunt.api.records.update({ recordId: '596f644b8f6d05e16c24b830', fieldActions: { Salary: { remove: 100000, add: 200000 } } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `recordId` | `string` | Yes | The record id. |
| `overwrite` | `boolean` | No | The default for every field action. NetHunt defaults it to false. |
| `fieldActions` | `object` | Yes | Field name to the action to perform on it. |

Each field takes an action: overwrite clears it, remove takes values out, add puts values in. Do not combine overwrite with remove.

<AccordionGroup>
<Accordion title="fieldActions full type">

```ts
Record<string, {
  overwrite?: boolean,
  remove?: string | number | boolean | null | (string | number | boolean)[] | (string | number | boolean | null | (string | number | boolean)[])[],
  add?: string | number | boolean | null | (string | number | boolean)[] | (string | number | boolean | null | (string | number | boolean)[])[]
}>
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `recordId` | `string \| null` | No | — |

### updated

`records.updated`

List records updated in a folder after a timestamp, optionally only when named fields changed

**Risk:** `read`

```ts
await corsair.nethunt.api.records.updated({ folderId: '596f644b8f6d05e16c24b810', fieldNames: ['Primary Email Address'], since: '2026-01-01T00:00:00.000Z' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `folderId` | `string` | Yes | The folder's id, from folders.list. |
| `fieldNames` | `string[]` | No | Only report changes to these fields. Repeatable at the provider; several names are sent as separate parameters. |
| `since` | `string` | No | Only records updated after this instant. Defaults at NetHunt to 24 hours before the request. |
| `limit` | `number` | No | — |

fieldNames is sent as a repeated fieldName parameter, which NetHunt takes as a list.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `records` | `object[]` | Yes | — |

{
  id?: string | null,
  recordId?: string | null,
  createdAt?: string | null,
