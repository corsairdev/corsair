## Activities

### create

`activities.create`

Create a time entry on a project task for the authenticated user, in hours or seconds

**Risk:** `write`

```ts
await corsair.moco.api.activities.create({ date: '2026-04-09', project_id: 1234567, task_id: 7536, seconds: 1800, description: 'Kickoff call', billable: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `date` | `string` | No | — |
| `project_id` | `number` | No | — |
| `task_id` | `number` | No | — |
| `company_id` | `number` | No | — |
| `hours` | `number` | No | Tracked hours as a decimal; seconds are derived. |
| `seconds` | `number` | No | Tracked seconds; hours are derived. |
| `description` | `string` | No | — |
| `tag` | `string` | No | — |
| `billable` | `boolean` | No | — |
| `remote_service` | `trello \| jira \| asana \| basecamp \| wunderlist \| basecamp2 \| basecamp3 \| toggl \| mite \| github \| youtrack` | No | — |
| `remote_url` | `string` | No | — |
| `remote_id` | `string` | No | — |
| `stop_timer` | `boolean` | No | — |

`POST /activities`. The entry belongs to the authenticated user. The spec
marks no request field as required; Moco answers 422 with
`{ errors: { field: [messages] } }` for a missing one.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|

| `hours` | `number \| null` | No | — |
| `description` | `string \| null` | No | — |
| `billed` | `boolean \| null` | No | — |
| `billable` | `boolean \| null` | No | — |
| `invoice_id` | `number \| null` | No | — |
| `tag` | `string \| null` | No | — |
| `remote_service` | `string \| null` | No | — |
| `remote_id` | `string \| null` | No | — |
| `remote_url` | `string \| null` | No | — |
| `project` | `object \| null` | No | — |
| `task` | `object \| null` | No | — |

**Risk:** `read`

```ts

```

**Input**

|------|------|----------|-------------|
| `from` | `string` | No | Only activities on or after this date. |
| `to` | `string` | No | Only activities on or before this date. |
| `user_id` | `number` | No | — |
| `task_id` | `number` | No | — |
| `company_id` | `number` | No | — |

| `deal_id` | `number` | No | — |

| `billed` | `boolean` | No | — |
| `term` | `string` | No | Full-text search term. |
| `tag` | `string` | No | — |
| `remote_id` | `string` | No | — |
| `page` | `number` | No | 1-based page. Moco pages with 100 entries per default page; next_page is null once a page comes back short. |

`GET /activities` with from, to, user_id, task_id, company_id, project_id,
deal_id, billable, billed, term, tag and remote_id filters. The bare array
is returned as `{ items, next_page }`.
