Use **Moco** through Corsair: one client, typed API calls.

MOCO serves every account from its own subdomain, so the account stores two
things: the API key (a user key from profile &gt; Integrations, or an account
key from Settings &gt; Extensions &gt; API & Webhooks, read-only or full access)
and the subdomain of `{subdomain}.mocoapp.com`. Requests authenticate with
`Authorization: Token token=<key>`.

- **Lists are paginated in response headers**, which the client cannot
return, so every paginated list takes a 1-based `page` (and `per_page`, up
to 100) and returns `{ items, next_page }`: `next_page` is the next page
number while the page came back full and null once it is short.
- **Acting as another user.** Time entries and presences belong to the user
whose key is used. An account key with the Staff permission can act for
another user: set `impersonate_user_id` (sent as `X-IMPERSONATE-USER-ID`) on
the operations that take it.
- **Sends and money.** `invoices.sendEmail`, `offers.sendEmail` and
`invoiceReminders.sendEmail` email customers, bookkeeping exports can submit
to the accounting service, and `users.create` adds a billed seat and emails
a welcome message unless `welcome_email` is false: all are `destructive`, as
are deletes and `taggings.replace`.
- **PDFs** (invoices, timesheets, offers, offer confirmations, purchase
drafts) come back as files, saved to Files when Corsair runs with a file
store.
- **Archiving is reversible** by the matching unarchive call; deletes are
not. MOCO refuses to delete billed time entries and locked invoices.
- **Rate limits.** About 120 requests per 2 minutes (1200 on the unlimited
plan). Core retries a 429 three times; a 5xx is retried for reads only,
because MOCO has no idempotency keys for writes.
- Not wrapped: `POST /session`, which trades an email and password for an
API key (the plugin already holds one).

**What you get:**

- 290 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/moco better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/moco better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/moco better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/moco better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { moco } from '@corsair-dev/moco';

export const corsair = createCorsair({
	plugins: [
		moco(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Moco API key before the first call: `pnpm corsair setup --plugin=moco --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
moco()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'moco',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List active projects**

```ts
const tenant = corsair.withTenant('acme');
await tenant.moco.api.projects.list({});
```


**Track half an hour on a task**

```ts
const tenant = corsair.withTenant('acme');
await tenant.moco.api.activities.create({
	date: '2026-04-09',
	project_id: 1234567,
	task_id: 7536,
	seconds: 1800,
	description: 'Kickoff call',
	billable: true,
});
```


See the full list on the [API](/plugins/moco/api) page.
