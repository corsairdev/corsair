## Account Manager

### locales

`accountManager.locales`

List locales supported by DigiCert ONE Account Manager.

**Risk:** `read`

```ts
await corsair.digicert.api.accountManager.locales({});
```

**Input:** _empty object_

Uses the DigiCert ONE service-user token stored in `digicert_one_api_key`, sent as `x-api-key`.


**Output:** `object[]`

<AccordionGroup>
<Accordion title="Output full type">

```ts
{
  code?: de_DE | en_US | es_ES | fr_FR | it_IT | ja_JP | ko_KR | pt_PT | ru_RU | zh_CN | zh_TW,
  language?: Deutsch | English | Español | Français | Italiano | 日本語 | 한국어 | Português | Русский | 简体中文 | 繁體中文
}[]
```
</Accordion>
</AccordionGroup>
