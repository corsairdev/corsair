Use **DigiCert** through Corsair: one client, typed API calls.

This plugin currently covers only a small subset of DigiCert's official API surface. CertCentral and Report Library use `X-DC-DEVKEY`; DigiCert ONE product APIs use a separate service-user token in `x-api-key`; the documented public version and CSC info routes need no key. The combined plugin requires both API-key fields because Corsair requires each custom account field. DigiCert ONE also offers mTLS, which this plugin does not implement. Webhook operations are out of scope, five deprecated TLM routes are excluded, and the 14 CertCentral Discovery catalog operations were discontinued on October 1, 2026.

**What you get:**

- 17 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/digicert better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/digicert better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/digicert better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/digicert better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { digicert } from '@corsair-dev/digicert';

export const corsair = createCorsair({
	plugins: [
		digicert(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
digicert()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'digicert',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`accountManager.locales`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.digicert.api.accountManager.locales({});
```


**`trustLifecycle.addCertificateTags`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.digicert.api.trustLifecycle.addCertificateTags({});
```
