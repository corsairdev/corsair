---
title: "ClickUp database"
sidebarTitle: "Database"
description: "The ClickUp plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for ClickUp. To read its data, call the [API operations](/plugins/clickup/api), which return what ClickUp has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
