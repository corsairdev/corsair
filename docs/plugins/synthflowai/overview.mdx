Use **Synthflow AI** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 37 typed API operations
- 8 synced entities (`actions`, `assistants`, `calls`, `contacts`, `knowledgeBases`, `memoryStores`, and 2 more) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/synthflowai
```
```bash yarn
yarn add corsair @corsair-dev/synthflowai
```
```bash pnpm
pnpm install corsair @corsair-dev/synthflowai
```
```bash bun
bun add corsair @corsair-dev/synthflowai
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { synthflowai } from '@corsair-dev/synthflowai';

export const corsair = createCorsair({
	plugins: [
		synthflowai(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
synthflowai()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'synthflowai',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`actions.get`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.synthflowai.api.actions.get({});
```


**`actions.attach`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.synthflowai.api.actions.attach({});
```


See the full list on the [API](/plugins/synthflowai/api) page.

## Query synced data

Synced entities support `tenant.synthflowai.db.<entity>.search()` and `.list()`: `actions`, `assistants`, `calls`, `contacts`, `knowledgeBases`, `memoryStores`, `phoneBooks`, `voices`.

See [Database](/plugins/synthflowai/database) for filters and operators.
