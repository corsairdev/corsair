## Comments

### create

`comments.create`

Post a comment on an issue

**Risk:** `write`

```ts
await corsair.linear.api.comments.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `issueId` | `string` | Yes | — |
| `body` | `string` | Yes | — |
| `parentId` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `body` | `string` | Yes | — |
| `issue` | `object` | Yes | — |
| `user` | `object` | Yes | — |
| `parent` | `object \| null` | No | — |
| `editedAt` | `Date \| null` | No | — |
| `createdAt` | `Date \| null` | No | — |
| `updatedAt` | `Date \| null` | No | — |
| `archivedAt` | `Date \| null` | No | — |
