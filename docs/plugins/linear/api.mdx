## Comments

### create

`comments.create`

Post a comment on an issue

**Risk:** `write`

```ts
await corsair.linear.api.comments.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `issueId` | `string` | Yes | — |
| `body` | `string` | Yes | — |
| `parentId` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `body` | `string` | Yes | — |
| `issue` | `object` | Yes | — |
| `user` | `object` | Yes | — |
| `parent` | `object \| null` | No | — |
| `editedAt` | `Date \| null` | No | — |
| `createdAt` | `Date \| null` | No | — |
| `updatedAt` | `Date \| null` | No | — |
| `archivedAt` | `Date \| null` | No | — |

`comments.delete`

**Risk:** `destructive` · **Irreversible**

```ts
await corsair.linear.api.comments.delete({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |



**Output:** `boolean`

### list

`comments.list`

Comments on one issue; issueId is the UUID or an identifier such as "ENG-123".

**Risk:** `read`

```ts
await corsair.linear.api.comments.list({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `issueId` | `string` | Yes | Issue UUID or identifier such as "ENG-123". |
| `first` | `number` | No | — |
| `after` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `nodes` | `object[]` | Yes | — |
| `pageInfo` | `object` | Yes | — |
