## Addresses

### create

`addresses.create`

Create a reusable address. Only `country` is required, but buying a label needs a name and a street line

**Risk:** `write`

```ts
await corsair.shippo.api.addresses.create({ name: 'Shawn Ippotle', street1: '215 Clayton St.', city: 'San Francisco', state: 'CA', zip: '94117', country: 'US' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `name` | `string` | No | Required to buy a label, not to create the address. |
| `company` | `string` | No | — |
| `street1` | `string` | No | Required to buy a label. |
| `street2` | `string` | No | — |
| `street3` | `string` | No | USPS international, UPS domestic and UPS international only. |
| `street_no` | `string` | No | Separate street number, for DHL Germany only. |
| `city` | `string` | No | — |
| `state` | `string` | No | State or province code or name. |
| `zip` | `string` | No | — |
| `country` | `string` | Yes | ISO 3166-1 alpha-2 code. |
| `phone` | `string` | No | — |
| `email` | `string` | No | — |
| `is_residential` | `boolean` | No | — |
| `metadata` | `string` | No | — |
| `validate` | `boolean` | No | Validate the address as part of the create call. |
| `shippo_account_id` | `string` | No | Sent as `SHIPPO-ACCOUNT-ID`: the managed Shippo account to act on behalf of. Platform accounts only. |

Only `country` is required by the API, but buying a label needs `name` and a street line. An address with `is_complete: false` still gets rates.



**Output**

|------|------|----------|-------------|
| `object_id` | `string \| null` | No | — |
| `object_owner` | `string \| null` | No | — |
| `object_created` | `string \| null` | No | — |
| `object_updated` | `string \| null` | No | — |
| `name` | `string \| null` | No | — |
| `company` | `string \| null` | No | — |
| `street_no` | `string \| null` | No | — |
| `street1` | `string \| null` | No | — |
| `street2` | `string \| null` | No | — |
| `street3` | `string \| null` | No | — |
| `city` | `string \| null` | No | — |
| `state` | `string \| null` | No | — |
| `zip` | `string \| null` | No | — |
| `country` | `string \| null` | No | ISO 3166-1 alpha-2 code, e.g. `US`. |
| `phone` | `string \| null` | No | — |
| `email` | `string \| null` | No | — |
| `is_residential` | `boolean \| null` | No | — |
| `is_complete` | `boolean \| null` | No | False when a required value failed validation. Such an address still gets rates but cannot buy a label. |
| `metadata` | `string \| null` | No | — |
