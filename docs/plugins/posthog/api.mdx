## Actions

### create

`actions.create`

Create an action from event, URL or element steps

**Risk:** `write`

```ts
await corsair.posthog.api.actions.create({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project_id` | `string \| number` | No | — |
| `name` | `string` | Yes | — |
| `description` | `string` | No | — |
| `steps` | `object[]` | Yes | — |
| `tags` | `string[]` | No | — |

<AccordionGroup>
<Accordion title="steps full type">

```ts
{
  event?: string | null,
  url?: string | null,
  url_matching?: contains | regex | exact,
  selector?: string | null,
  text?: string | null,
  href?: string | null,
  properties?: Record<string, any>[]
}[]
```
</Accordion>
</AccordionGroup>



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `number` | Yes | — |
| `name` | `string \| null` | No | — |
| `description` | `string \| null` | No | — |
| `steps` | `any[]` | No | — |
| `tags` | `string[]` | No | — |
| `deleted` | `boolean` | No | — |
| `created_at` | `string \| null` | No | — |
| `created_by` | `object \| null` | No | — |

<AccordionGroup>
<Accordion title="created_by full type">

```ts
{
  id?: number,
  uuid?: string,
  distinct_id?: string | null,
  first_name?: string,
  last_name?: string,
  email?: string
} | null
```
</Accordion>
</AccordionGroup>
