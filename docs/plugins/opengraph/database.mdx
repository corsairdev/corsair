---
title: "OpenGraph.io database"
sidebarTitle: "Database"
description: "The OpenGraph.io plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for OpenGraph.io. To read its data, call the [API operations](/plugins/opengraph/api), which return what OpenGraph.io has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
