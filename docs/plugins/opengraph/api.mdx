## Brand

### analyze

`brand.analyze`

Analyze the brand behind a website: identity, products, audiences, positioning, messaging, voice, visual style and links

**Risk:** `read`

```ts
await corsair.opengraph.api.brand.analyze({ url: 'https://asana.com', sections: { visual: false } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | The target URL. It is percent-encoded into the request path. |
| `sections` | `Record<string, boolean>` | No | Set a section to false to skip it, e.g. &#123; visual: false &#125;. |
| `questions` | `object[]` | No | Up to 3 custom questions; answers come back under custom.&lt;key&gt;. |
| `include_meta` | `boolean` | No | Add a _meta object with the source pages behind each field. |
| `cache_ok` | `boolean` | No | Reuse a cached analysis up to 7 days old. Default true. |

## Extract

### run

`extract.run`

Extract chosen HTML elements as structured data plus concatenated clean text from a URL, ready for LLM pipelines

**Risk:** `read`

```ts
await corsair.opengraph.api.extract.run({ site: 'https://example.com', selectors: { heading: { selector: 'h1' }, links: { selector: 'a', multiple: true, type: 'attr', attr: 'href' } } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `site` | `string` | Yes | The URL to extract from. |
| `selectors` | `object` | No | CSS selectors to pull as structured data, keyed by your own names. |
| `html_elements` | `string` | No | Comma-separated tags behind concatenatedText. Default title,h1,h2,h3,h4,h5,p. |
| `wait_for_selector` | `string` | No | Wait for this CSS selector before capturing. Enables JavaScript rendering. |
| `scroll_to_bottom` | `boolean` | No | Scroll the page to trigger lazy-loaded content. Enables JavaScript rendering. |
| `load_more_selector` | `string` | No | A load-more button to click before capturing. Enables JavaScript rendering. |
| `load_more_clicks` | `number` | No | How many times to click the load-more button. Default 3. |
| `load_more_wait` | `number` | No | Milliseconds to wait after each click. Default 1500. |
| `cache_ok` | `boolean` | No | Allow a cached result. OpenGraph.io defaults this to true. |
| `max_cache_age` | `number` | No | Maximum age of an acceptable cached result, in seconds. |
| `full_render` | `boolean` | No | Render the page in a headless browser before extracting. |
| `use_proxy` | `boolean` | No | Fetch through the standard datacenter proxy (10 credits). |
| `use_premium` | `boolean` | No | Fetch through the residential proxy (20 credits). |
| `use_superior` | `boolean` | No | Fetch through the mobile proxy for heavily protected sites (30 credits). |
| `auto_proxy` | `boolean` | No | Let OpenGraph.io pick the proxy for the domain. v3.0 default: true. |
| `auto_render` | `boolean` | No | Let OpenGraph.io render JavaScript when the page needs it. v3.0 default: true. |
| `retry` | `boolean` | No | Retry a failed fetch with a stronger proxy tier. v3.0 default: true. |
| `ai_sanitize` | `boolean` | No | Scan the extracted text for prompt injection (1 extra credit). |
| `ai_sanitize_mode` | `sanitize \| warn \| block` | No | What to do on detected injection risk. Default sanitize. |

## Markdown

### get

`markdown.get`

Convert a URL to clean Markdown with optional heading-aware chunking, keyword passage search and structure extraction

**Risk:** `read`

```ts
await corsair.opengraph.api.markdown.get({ url: 'https://en.wikipedia.org/wiki/Web_scraping', chunking: true, chunk_size: 1200, query: 'legal issues' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | The target URL. It is percent-encoded into the request path. |
| `only_main_content` | `boolean` | No | Strip navigation, sidebars and footers. Default true. |
| `include_tags` | `string` | No | Comma-separated CSS selectors to keep, e.g. article,main. |
| `exclude_tags` | `string` | No | Comma-separated CSS selectors to drop, e.g. nav,.sidebar,footer. |
| `max_chars` | `number` | No | Cap the Markdown at this many characters. |
| `chunking` | `boolean` | No | Split the document into chunks sized for embedding. Default false. |
| `chunk_size` | `number` | No | Target chunk size in characters. Default 2000. |
| `chunk_overlap` | `number` | No | Characters repeated from the end of the previous chunk. Default 0. |
| `heading_aware` | `boolean` | No | Start a new chunk at each section heading. Default true. |
| `heading_aware_level` | `number` | No | Which heading level starts a new chunk. Default 2. |
| `max_chunks` | `number` | No | Most chunks to return. Default 500. |
| `query` | `string` | No | Return only passages matching these keywords, with relevance scores. Implies chunking. |
| `query_top_k` | `number` | No | How many matching passages to return. Default 5. |
| `include_markdown` | `boolean` | No | Include the document itself. Default true. |
| `include_metadata` | `boolean` | No | Include the page metadata block. Default true. |
| `include_chunks` | `boolean` | No | Include the chunk texts. Default true. |
| `include_headings` | `boolean` | No | Return the heading outline and table and code block counts. Default false. |
| `include_links` | `boolean` | No | Return every link from the main content as an absolute URL. Default false. |
| `include_images` | `boolean` | No | Return every image with its source and alt text. Default false. |
| `ai_sanitize` | `boolean` | No | Scan the page for prompt injection (1 extra credit). |
| `ai_sanitize_mode` | `sanitize \| warn \| block` | No | What to do on detected injection risk. Default sanitize. |
| `cache_ok` | `boolean` | No | Allow a cached result. OpenGraph.io defaults this to true. |
| `max_cache_age` | `number` | No | Maximum age of an acceptable cached result, in milliseconds. |
| `full_render` | `boolean` | No | Always render in a browser first. Adds 5-10 seconds and is billed. |
| `wait_for_selector` | `string` | No | Wait for this CSS selector before reading. Enables rendering. |
| `scroll_to_bottom` | `boolean` | No | Scroll the page to trigger lazy-loaded content. Enables rendering. |
| `load_more_selector` | `string` | No | A load-more button to click before reading. Enables rendering. |
| `use_proxy` | `boolean` | No | Fetch through the standard datacenter proxy (10 credits). |
| `use_premium` | `boolean` | No | Fetch through the residential proxy (20 credits). |
| `use_superior` | `boolean` | No | Fetch through the mobile proxy for heavily protected sites (30 credits). |
| `proxy_country` | `string` | No | Two-letter country code to fetch from, e.g. US. |
| `accept_lang` | `string` | No | Accept-Language header sent to the page, e.g. en-US. |
| `auto_render` | `boolean` | No | Let OpenGraph.io render JavaScript when the page needs it. v3.0 default: true. |
| `auto_proxy` | `boolean` | No | Let OpenGraph.io pick the proxy for the domain. v3.0 default: true. |
| `retry` | `boolean` | No | Retry a failed fetch with a stronger proxy tier. v3.0 default: true. |
