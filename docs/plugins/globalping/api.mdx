## Health

### get

`health.get`

Read the Globalping health check.

**Risk:** `read`

```ts
await corsair.globalping.api.health.get({});
```

**Input:** _empty object_

GET /health. Stores the text body.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `health` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="health full type">

```ts
{
  id: string,
  status: string
}
```
</Accordion>
</AccordionGroup>

## Limits

### get

`limits.get`

Read the current measurement rate limit.

**Risk:** `read`

```ts
await corsair.globalping.api.limits.get({});
```

**Input:** _empty object_

GET /v1/limits. Stores the measurements.create bucket.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `limit` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="limit full type">

```ts
{
  id: string,
  type?: string,
  limit?: number,
  remaining?: number,
  reset?: number
}
```
</Accordion>
</AccordionGroup>

## Measurements

### create

`measurements.create`

Create a network measurement. This spends credits.

**Risk:** `write`

```ts
await corsair.globalping.api.measurements.create({ type: 'ping', target: 'example.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `type` | `ping \| traceroute \| dns \| mtr \| http` | Yes | — |
| `target` | `string` | Yes | — |
| `limit` | `number` | No | — |

POST /v1/measurements. Stores id, probesCount, and type.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `measurement` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="measurement full type">

```ts
{
  id: string,
  probesCount?: number,
  type?: string,
  status?: string
}
```
</Accordion>
</AccordionGroup>



---

### get

`measurements.get`

Read a measurement by id. Results are not stored.

**Risk:** `read`

```ts
await corsair.globalping.api.measurements.get({ id: 'example' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |

GET /v1/measurements/{id}. Stores id, type, status, and probesCount.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `measurement` | `object` | Yes | — |

<AccordionGroup>
<Accordion title="measurement full type">

```ts
{
  id: string,
  probesCount?: number,
  type?: string,
  status?: string
}
```
</Accordion>
</AccordionGroup>

## Probes

### list

`probes.list`

List online Globalping probes. Probe rows are not stored.

**Risk:** `read`

```ts
await corsair.globalping.api.probes.list({});
```

**Input:** _empty object_

GET /v1/probes. Resolver addresses are not returned.


**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `probes` | `object[]` | Yes | — |

<AccordionGroup>
<Accordion title="probes full type">

```ts
{
  version?: string,
  continent?: string,
  region?: string,
  country?: string,
  city?: string,
  network?: string,
  asn?: number
}[]
```
</Accordion>
</AccordionGroup>
