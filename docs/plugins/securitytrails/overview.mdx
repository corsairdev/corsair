Use **SecurityTrails** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 12 typed API operations
- 5 synced entities (`certificates`, `companyIpRanges`, `domains`, `ips`, `projects`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/securitytrails
```
```bash yarn
yarn add corsair @corsair-dev/securitytrails
```
```bash pnpm
pnpm install corsair @corsair-dev/securitytrails
```
```bash bun
bun add corsair @corsair-dev/securitytrails
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { securitytrails } from '@corsair-dev/securitytrails';

export const corsair = createCorsair({
	plugins: [
		securitytrails(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
securitytrails()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'securitytrails',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**`account.ping`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.securitytrails.api.account.ping({});
```


**`projects.bulkStaticAssetRules`**

```ts
const tenant = corsair.withTenant('acme');
await tenant.securitytrails.api.projects.bulkStaticAssetRules({});
```


See the full list on the [API](/plugins/securitytrails/api) page.

## Query synced data

Synced entities support `tenant.securitytrails.db.<entity>.search()` and `.list()`: `certificates`, `companyIpRanges`, `domains`, `ips`, `projects`.

See [Database](/plugins/securitytrails/database) for filters and operators.
