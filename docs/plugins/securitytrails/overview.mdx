Use **Securitytrails** through Corsair: one client, typed API calls, optional local DB sync.

**What you get:**

- 12 typed API operations
- 5 database entities synced for fast `.search()` / `.list()` queries

## Setup

<Steps>

<Step title="Install">
```bash
pnpm install @corsair-dev/securitytrails
```

</Step>

<Step title="Add the plugin">
<Tabs>
<Tab title="Solo">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { securitytrails } from '@corsair-dev/securitytrails';

export const corsair = createCorsair({
	// ... other config options,
	multiTenancy: false,
    plugins: [securitytrails()],
});
```
</Tab>
<Tab title="Multi-Tenant">
```ts corsair.ts
import { createCorsair } from 'corsair';
import { securitytrails } from '@corsair-dev/securitytrails';

export const corsair = createCorsair({
	// ... other config options,
    multiTenancy: true,
    plugins: [securitytrails()],
});
```

See [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Tab>
</Tabs>

</Step>

<Step title="Get credentials">
Follow [Get Credentials](/plugins/securitytrails/get-credentials) if you need help getting keys.

</Step>

<Step title="Store credentials">
<Tabs>
<Tab title="Solo">
```bash
pnpm corsair setup --plugin=securitytrails
```

Use the key names documented in [Get Credentials](/plugins/securitytrails/get-credentials) (for example `api_key=`, `bot_token=`, or OAuth client fields).
</Tab>
<Tab title="Multi-Tenant">
```bash
pnpm corsair setup --plugin=securitytrails --tenant=<tenantId>
```

Store per-tenant secrets after you create the tenant record. See [Multi-tenancy](/concepts/multi-tenancy).
</Tab>
</Tabs>

</Step>

</Steps>

## Authentication

Each tab shows how to register the plugin for that authentication method. The default `authType` from the plugin does not need to appear in the factory call.

<Tabs>
<Tab title="API Key (Default)">

```ts corsair.ts
securitytrails()
```

Store credentials with `pnpm corsair setup --plugin=securitytrails` (see [Get Credentials](/plugins/securitytrails/get-credentials) for field names). For OAuth, you typically store integration keys at the provider level and tokens per account or tenant.

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>


## Query synced data

Synced entities support `corsair.securitytrails.db.<entity>.search()` and `.list()`. See [Database](/plugins/securitytrails/database) for filters and operators.


## Example API calls

**Read-style (read):** `account.ping`

```ts
await corsair.securitytrails.api.account.ping({});
```


**Write-style (write):** `projects.bulkStaticAssetRules`

```ts
await corsair.securitytrails.api.projects.bulkStaticAssetRules({});
```


See the full list on the [API](/plugins/securitytrails/api) page. Use `pnpm corsair list --plugin=securitytrails` and `pnpm corsair schema <path>` locally to inspect schemas.
