---
title: "U301 database"
sidebarTitle: "Database"
description: "The U301 plugin in Corsair returns live API data and stores no local entities, so there is nothing to search locally."
---

No local `.search()` operations are available for U301. To read its data, call the [API operations](/plugins/u301/api), which return what U301 has at that moment.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>
