## Analytics

### audience

`analytics.audience`

Read a top-N click breakdown by country, city, referrer, browser, OS or device

**Risk:** `read`

```ts
await corsair.u301.api.analytics.audience({ dimension: 'countries', range: '30d' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `dimension` | `countries \| cities \| referers \| browsers \| operating-systems \| device-types` | Yes | Which breakdown to read: countries, cities, referers, browsers, operating-systems or device-types. |
| `range` | `24h \| 1d \| 3d \| 7d \| 14d \| 30d \| 60d \| 1m` | Yes | The window to aggregate over. |
| `timezone` | `string` | No | An IANA timezone for the buckets. Defaults to UTC. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `datetimeRange` | `string[] \| null` | No | — |
| `range` | `string \| null` | No | — |
| `data` | `object[] \| null` | No | — |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  label?: string | null,
  click?: number | null,
  meta?: Record<string, any> | null
}[] | null
```
</Accordion>
</AccordionGroup>

### clicks

`analytics.clicks`

Read click counts over a time range at a chosen granularity, in a chosen timezone

**Risk:** `read`

```ts
await corsair.u301.api.analytics.clicks({ range: '7d', granularity: 'day', timezone: 'UTC' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `range` | `24h \| 1d \| 3d \| 7d \| 14d \| 30d \| 60d \| 1m` | Yes | The window to aggregate over. |
| `granularity` | `day \| hour` | Yes | The bucket size within that window. |
| `timezone` | `string` | No | An IANA timezone for the buckets. Defaults to UTC. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `start` | `string \| null` | No | ISO 8601 start of the window. |
| `end` | `string \| null` | No | ISO 8601 end of the window. |
| `data` | `object[] \| null` | No | One entry per bucket. |

<AccordionGroup>
<Accordion title="data full type">

```ts
{
  date?: string | null,
  click?: number | null
}[] | null
```
</Accordion>
</AccordionGroup>

## Domains

### active

`domains.active`

Check whether a domain's DNS verification has completed, which is the step to poll after adding the CNAME

**Risk:** `read`

```ts
await corsair.u301.api.domains.active({ domain: 'go.example.com' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `domain` | `string` | Yes | The domain for the link, such as u301.co or one of your own. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `actived` | `boolean \| null` | No | Whether the domain is active. |
| `message` | `string \| null` | No | — |

## Links

### create

`links.create`

Shorten a URL on u301.co or one of your domains, with an optional custom slug, password and comment; a new link spends one monthly allowance slot

**Risk:** `write`

```ts
await corsair.u301.api.links.create({ url: 'https://example.com/spring-sale', slug: 'spring', comment: 'spring campaign' });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `url` | `string` | Yes | The destination URL to shorten. |
| `domain` | `string` | No | The domain for the link, such as u301.co or one of your own. |
| `slug` | `string` | No | A custom path. A random one is generated when omitted. |
| `reuseExisting` | `boolean` | No | Reuse an existing short link when the same URL is already shortened, instead of creating a second one. |
| `password` | `string` | No | Require this password before the short link resolves. |
| `comment` | `string` | No | A note to attach to the link. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string \| null` | No | — |
| `url` | `string \| null` | No | The destination URL. |
| `slug` | `string \| null` | No | — |
| `isCustomSlug` | `boolean \| null` | No | — |
| `domain` | `string \| null` | No | — |
| `isReused` | `boolean \| null` | No | True when an existing link was returned and no new one was created. |
| `shortLink` | `string \| null` | No | The short link without a scheme, such as u301.co/jtyZ. |
| `comment` | `string \| null` | No | — |
