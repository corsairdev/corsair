Use **U301** through Corsair: one client, typed API calls.

U301 needs **two** credentials on every call: an API key in `Authorization: Bearer`, and a **workspace ID** that goes in the `workspaceId` query parameter. Find both in your U301 dashboard.

There is one key slot, so set the key to both values with a newline between them:

```text
<api key>
<workspace id>
```

Or pass them as the `apiKey` and `workspaceId` options, which is clearer. A key without a workspace is reported as a configuration error before any request goes out, rather than as a `401` that looks like a bad key.

Things worth knowing before you rely on an answer:

- **A new link spends one slot of the monthly allowance**, and free accounts get 100 a month. Reusing a link does not: pass `reuseExisting` to return the existing link for a URL instead of making a second one, and check `isReused` on the answer. An oversized bulk request answers `429` **without creating anything**, so a `429` here is the allowance, not a request rate — the plugin never retries it.
- **A link looks different on create than on read.** A create answers `shortLink`, `url` and `isReused`; a read answers `shortUrl`, `originalUrl` and `statsClicks`. The two shapes are modelled as they are rather than merged.
- **Links and domains are addressed by their own name, not an internal id.** `links.get` takes the short form, `u301.co/abc123`, and it is sent as a path with its slash rather than an encoded `%2F`. A `https://` prefix is stripped for you.
- **A custom domain is not live when it is created.** `domains.create` adds it, then you add the DNS CNAME and poll `domains.active` until `actived` is true — that is U301's own spelling of the field. A domain that is still verifying answers `actived: false` with a message such as "Challenge not ready".
- **The three domain settings share one PATCH** but are separate operations, so each sends exactly one field: `domains.pathLength` (`randomCodeLength`, 3 to 10), `domains.homeRedirect` and `domains.notFoundRedirect`.
- **Analytics separate range from granularity.** `range` is how far back (`1d`, `7d`, `30d`, `90d`, `1y`) and `granularity` is how the buckets are cut (`hour`, `day`, `week`, `month`); a year at hourly granularity is a very large answer. Give `timezone` when the day boundary matters.
- **The audience breakdown puts the dimension in the path.** `analytics.audience` takes `countries`, `cities`, `referrers`, `browsers`, `os` or `devices` and calls the matching `top-<dimension>` route.

**What you get:**

- 14 typed API operations

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/u301 better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/u301 better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/u301 better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/u301 better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { u301 } from '@corsair-dev/u301';

export const corsair = createCorsair({
	plugins: [
		u301(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
u301()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'u301',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**List short links with their click counts**

```ts
const tenant = corsair.withTenant('acme');
await tenant.u301.api.links.list({ page: 1, perPage: 20 });
```


**Shorten a URL on your own domain**

```ts
const tenant = corsair.withTenant('acme');
await tenant.u301.api.links.create({
	url: 'https://example.com/spring-sale',
	domain: 'go.example.com',
	slug: 'spring',
	reuseExisting: true,
});
```


See the full list on the [API](/plugins/u301/api) page.
