The Plate Recognizer plugin syncs data locally. Use `corsair.platerecognizer.db.<entity>.search({ data, limit?, offset? })` with the filters listed per entity.

<Info>
**New to Corsair?** See [database operations](/concepts/database), [data synchronization](/concepts/integrations), and [multi-tenancy](/concepts/multi-tenancy).
</Info>

## Usage

Path: `platerecognizer.db.usage.search`

```ts
const rows = await corsair.platerecognizer.db.usage.search({
    data: { /* filters below */ },
    limit: 100,
    offset: 0,
});
```

### Searchable filters

| Field | Type | Operators |
|-------|------|-----------|
| `entity_id` | `string` | equals, contains, startsWith, endsWith, in |
| `id` | `string` | equals, contains, startsWith, endsWith, in |
| `year` | `number` | equals, gt, gte, lt, lte, in |
| `month` | `number` | equals, gt, gte, lt, lte, in |
| `calls` | `number` | equals, gt, gte, lt, lte, in |
| `resetsOn` | `string` | equals, contains, startsWith, endsWith, in |
| `totalCalls` | `number` | equals, gt, gte, lt, lte, in |

_Every `.search()` also accepts `limit` and `offset` for pagination. `.list()` is available on the same path without the `.search` suffix in code — see [database operations](/concepts/database)._
