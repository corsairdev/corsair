Use **Plate Recognizer** through Corsair: one client, typed API calls, local DB sync.

Auth is `Authorization: Token <key>`, not Bearer; the key is on the Snapshot Cloud dashboard. A missing or wrong token returns HTTP 403. Each `plates.read` uses one Snapshot lookup and each `ocr.read` one OCR call from the plan's monthly allowance. Plate text is not stored, because a plate is not a stable id. Snapshot usage is stored per year and month.

OCR is a separate Plate Recognizer product: an account without it gets `403` from `ocr.read`.

**What you get:**

- 4 typed API operations
- 1 synced entity (`usage`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/platerecognizer better-sqlite3
npm install --save-dev @types/better-sqlite3
```
```bash yarn
yarn add corsair @corsair-dev/platerecognizer better-sqlite3
yarn add --dev @types/better-sqlite3
```
```bash pnpm
pnpm install corsair @corsair-dev/platerecognizer better-sqlite3
pnpm install --save-dev @types/better-sqlite3
```
```bash bun
bun add corsair @corsair-dev/platerecognizer better-sqlite3
bun add --dev @types/better-sqlite3
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { platerecognizer } from '@corsair-dev/platerecognizer';

export const corsair = createCorsair({
	plugins: [
		platerecognizer(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

Store the Plate Recognizer API key before the first call: `pnpm corsair setup --plugin=platerecognizer --tenant=acme api_key=<your-key>` (leave out `--tenant` without `multiTenancy`), or pass it as `key` in the plugin options. With Hub, each tenant enters their own key on the connect page. See [API key auth](/concepts/api-key).

```ts
platerecognizer()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'platerecognizer',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Read the plates in an image by URL**

```ts
const tenant = corsair.withTenant('acme');
await tenant.platerecognizer.api.plates.read({
	uploadUrl: 'https://app.platerecognizer.com/static/demo.jpg',
	regions: ['us-ca'],
});
```
