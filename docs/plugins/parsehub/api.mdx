## Projects

### get

`projects.get`

Get one project with its last run, last ready run and the 20 most recent runs.

**Risk:** `read`

```ts
await corsair.parsehub.api.projects.get({ project_token: 't-0WMEZ-Bc9sWGHAMsYvP7y4', include_options: true });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project_token` | `string` | Yes | Project token from projects.list (not the API key). |
| `offset` | `number` | No | Offset into run_list (the 20 most recent runs). Default 0. |
| `include_options` | `boolean` | No | Include options_json and related fields. Sent as 1 or 0. |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `token` | `string` | Yes | — |
| `title` | `string \| null` | No | — |
| `templates_json` | `string \| null` | No | — |
| `main_template` | `string \| null` | No | — |
| `main_site` | `string \| null` | No | — |
| `options_json` | `string \| null` | No | — |
| `webhook` | `string \| null` | No | — |
| `last_run` | `object \| null` | No | — |
| `last_ready_run` | `object \| null` | No | — |
| `run_list` | `object[] \| null` | No | — |

### getLastReadyData

Get the extracted data of the most recent run of a project that has data ready.

await corsair.parsehub.api.projects.getLastReadyData({ project_token: 't-0WMEZ-Bc9sWGHAMsYvP7y4' });

### list

`projects.list`

List the scraping projects on the ParseHub account, 20 at a time.

**Risk:** `read`

```ts
await corsair.parsehub.api.projects.list({ offset: 0, limit: 20 });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `offset` | `number` | No | Zero-based start index. Default 0. |
| `limit` | `number` | No | Page size, 1 to 20. Default 20. |
| `include_options` | `boolean` | No | Include options_json and related fields. Sent as 1 or 0. |

Omit offset, limit or include_options to take the service default. include_options is sent as 1 or 0.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `projects` | `object[]` | Yes | — |
| `total_projects` | `number` | No | — |

### run

`projects.run`

Start a run of a project on the ParseHub cloud. Returns the new run; poll runs.get until data_ready.

**Risk:** `destructive`

```ts
await corsair.parsehub.api.projects.run({
	project_token: 't-0WMEZ-Bc9sWGHAMsYvP7y4',
	start_url: 'https://www.example.com',
	start_value_override: { query: 'San Francisco' },
});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project_token` | `string` | Yes | Project token from projects.list (not the API key). |
| `start_url` | `string` | No | URL to start on. Defaults to the project start site. |
| `start_template` | `string` | No | Template to start with. Defaults to the project main template. |
| `start_value_override` | `Record<string, any>` | No | Starting global scope for the run, e.g. &#123; "query": "San Francisco" &#125;. Sent as a JSON string. |
| `send_email` | `boolean` | No | Email the account owner when the run completes or fails. Default false. |

`start_value_override` is sent as a JSON string. `send_email: true` emails the account owner when the run ends. The operation is `destructive` because it starts a cloud run against the plan's quota and can send that email.



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `project_token` | `string \| null` | No | — |
| `run_token` | `string` | Yes | — |
| `status` | `string \| null` | No | — |
| `data_ready` | `boolean \| number \| null` | No | — |
| `start_time` | `string \| null` | No | — |
| `end_time` | `string \| null` | No | — |
| `pages` | `number \| null` | No | — |
| `md5sum` | `string \| null` | No | — |
| `start_url` | `string \| null` | No | — |
| `start_template` | `string \| null` | No | — |
| `start_value` | `string \| null` | No | — |
