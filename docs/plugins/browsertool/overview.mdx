---
title: Overview
description: "Cloud browser automation tool that runs AI-driven browser tasks, polls and stops them, and returns session live URLs and task output files."
---

Use **Browser Tool** through Corsair: one client, typed API calls, local DB sync.

**What you get:**

- 5 typed API operations
- 2 synced entities (`executions`, `tasks`) for fast `.search()` / `.list()`

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/browsertool
```
```bash yarn
yarn add corsair @corsair-dev/browsertool
```
```bash pnpm
pnpm install corsair @corsair-dev/browsertool
```
```bash bun
bun add corsair @corsair-dev/browsertool
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { browsertool } from '@corsair-dev/browsertool';

export const corsair = createCorsair({
	plugins: [
		browsertool(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	multiTenancy: true,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

With `multiTenancy: true`, scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
browsertool()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'browsertool',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Get a session**

```ts
const tenant = corsair.withTenant('acme');
await tenant.browsertool.api.sessions.get({ sessionId: 'session_123' });
```


**Start a browser task**

```ts
const tenant = corsair.withTenant('acme');
await tenant.browsertool.api.tasks.create({ task: 'Open example.com and return the page title', startUrl: 'https://example.com' });
```


See the full list on the [API](/plugins/browsertool/api) page.

## Query synced data

These tables exist, but Browser Tool calls don't fill them yet. This returns only rows you have written yourself.

```ts
const tenant = corsair.withTenant('acme');
const rows = await tenant.browsertool.db.tasks.search({
	data: {},
	limit: 50,
});
```

Synced entities: `executions`, `tasks`. See [Database](/plugins/browsertool/database) for filters and operators.
