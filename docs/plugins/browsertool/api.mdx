## Files

### get

`files.get`

Get a download URL for a task output file

**Risk:** `read`

```ts
const tenant = corsair.withTenant('acme');
await tenant.browsertool.api.files.get({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `fileId` | `string` | Yes | — |
| `taskId` | `string` | Yes | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `data` | `any` | Yes | — |
| `error` | `string` | No | — |
| `successful` | `boolean` | Yes | — |
| `session_info` | `any` | No | — |
| `log_id` | `string` | No | — |
