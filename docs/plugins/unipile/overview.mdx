---

Use **Unipile** through Corsair: one client, typed API calls, and incoming webhooks.

Every LinkedIn call takes the `account_id` (acc_…) of a connected account; connect one with `accounts.createAuthLink` (credentials, cookies or the UniLogin extension). LinkedIn limits invitations to roughly 100-200 a week and profile views to about 80-100 a day, and Unipile does not pace sends for you. Sends (`relationRequests.create`, `chats.start`, `messages.send`) are never retried after a timeout or 5xx, so a lost answer cannot cause a duplicate.

Managing webhook endpoints needs a Unipile **Service API Key**; Account API Keys get `403 api/insufficient_permissions`. Deliveries are verified with the endpoint's signing secret (`unipile-signature` header, HMAC-SHA256 of the raw body), so pass the raw request body to Corsair and set `webhookSecret` (or store the webhook signature) to that secret. Only `webhookEndpoints.create` returns the secret, once; `list`, `get` and `update` report `secret_set` instead, so store it when you create the endpoint.

**What you get:**

- 27 typed API operations
- 13 incoming webhook event types

## Setup

<Steps>

<Step title="Install">
<CodeGroup>
```bash npm
npm install corsair @corsair-dev/unipile
```
```bash yarn
yarn add corsair @corsair-dev/unipile
```
```bash pnpm
pnpm install corsair @corsair-dev/unipile
```
```bash bun
bun add corsair @corsair-dev/unipile
```
</CodeGroup>

</Step>

<Step title="Add the plugin">
```ts corsair.ts
import Database from 'better-sqlite3';
import { createCorsair } from 'corsair';
import { unipile } from '@corsair-dev/unipile';

export const corsair = createCorsair({
	plugins: [
		unipile(),
	],
	database: new Database('corsair.db'),
	kek: process.env.CORSAIR_KEK!,
	hub: {
		projectApiKey: process.env.CORSAIR_API_KEY!,
		signingSecret: process.env.CORSAIR_SIGNING_SECRET!,
	},
});
```

Multi-tenancy is the default — scope calls with `corsair.withTenant(id)`. See [Quick start](/quick-start) for KEK + Hub keys, and [Multi-tenancy](/concepts/multi-tenancy) for account isolation.

</Step>

<Step title="Choose authentication">
<Tabs>
<Tab title="API Key (Recommended)">

No setup required yet. When you make your first request as a tenant, Corsair prompts for the API key.

```ts
unipile()
```

More: [API Key](/concepts/api-key)

</Tab>
</Tabs>

</Step>

<Step title="Connect a tenant">
Mint a connect link and send the tenant to it. Hub hosts the page and delivers the result to your app — see [Connect / OAuth](/management/connect).

```ts
const { connectUrl } = await corsair.manage.connect.createLink({
	plugin: 'unipile',
	tenantId: 'acme',
});
// redirect the user's browser to connectUrl
```

</Step>

</Steps>

## Example API calls

**Look up a LinkedIn profile**

```ts
const tenant = corsair.withTenant('acme');
await tenant.unipile.api.users.getProfile({ account_id: 'acc_9f2c1d7e', user_id: 'williamhgates' });
```


**Send a LinkedIn invitation**

```ts
const tenant = corsair.withTenant('acme');
await tenant.unipile.api.relationRequests.create({ account_id: 'acc_9f2c1d7e', user_id: 'ACoAAB1cDeFgHiJkLmNoPqRsTuVwXyZ0123456', message: 'Hi Maya, I enjoyed your post on field data.' });
```


See the full list on the [API](/plugins/unipile/api) page.

## Webhooks

Runs when an invitation is accepted. LinkedIn can report it up to 6 hours late.

```ts
unipile({
    webhookHooks: {
        relations: {
            new: {
                after: async (ctx, result) => {
                    console.log('New connection', result.data?.payload.user.display_name);
                }
            },
        },
    },
})
```

Mount your framework handler once (see [Frameworks](/frameworks/next)), then point the provider at that URL. Full event list: [Webhooks](/plugins/unipile/webhooks). Concepts: [Webhooks](/concepts/webhooks), [Hooks](/concepts/hooks).
