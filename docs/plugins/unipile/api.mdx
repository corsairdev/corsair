## Accounts

### createAuthLink

`accounts.createAuthLink`

Create a Hosted Auth link for a user to connect a LinkedIn (or other) account, or to reconnect one with account_id; LinkedIn sign-in can offer credentials, cookies or the UniLogin extension

**Risk:** `write`

```ts
await corsair.unipile.api.accounts.createAuthLink({ providers: 'linkedin', redirect_uri: 'https://app.example.com/linkedin/connected', state: 'user_123', config: { linkedin: { allow_methods: ['unilogin', 'credentials'] } } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `providers` | `* \| *:MESSAGING \| *:EMAILS \| *:CALENDAR \| *:SOCIAL \| linkedin \| mock \| whatsapp \| google \| outlook \| imap \| telegram \| instagram \| linkedin \| mock \| whatsapp \| google \| outlook \| imap \| telegram \| instagram[]` | No | Providers to offer when linking a new account, e.g. linkedin. Omit when reconnecting with account_id |
| `account_id` | `string` | No | Reconnect or reconfigure this existing account instead of linking a new one |
| `expires_on` | `string` | No | When the link stops working, ISO 8601 with a timezone. Defaults to one hour from now |
| `redirect_uri` | `string` | Yes | Where to send the user afterwards. On success Unipile adds account_id, provider and state to the query; on failure error_title |
| `state` | `string` | No | Your own ID for this user or session. Unipile returns it on the redirect and in the account.add / account.reconnect webhook |
| `account_scope_id` | `string` | No | Scope to assign the account to |
| `domain` | `string` | No | White-label Hosted Auth hostname already verified by Unipile |
| `config` | `object` | No | — |

<AccordionGroup>

### update

`accounts.update`

Update a connected account: its name, custom data, proxy settings or LinkedIn products

**Risk:** `write`

```ts
await corsair.unipile.api.accounts.update({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `account_id` | `string` | Yes | Unipile account ID (acc_…) of the connected account to act as, from accounts.list |
| `account_scope_id` | `string` | No | The Scope to permanently assign to an unscoped Account. This field requires a Service API Key, and the Scope cannot be removed or replaced after assignment. |
| `metadata` | `object` | No | Custom key-value data for the account. Replaces the account `metadata.custom_data` field; other metadata fields are not modified. Any fields not provided will be removed. |
| `auto_proxy_country` | `string` | No | The rotation country to use for Automatic Proxy Protection. Choose from the countries where Unipile offers automatic proxies. A proxy may be temporarily unavailable even in a country included in the offering. |
| `allow_country_fallback` | `boolean` | No | Whether Automatic Proxy Protection may use an available proxy from another country when none is available in the rotation country, during authentication and throughout the account lifetime. Defaults to true. |
| `proxy` | `object` | No | A new proxy configuration for the account. This will restart the account. Set to `null` to remove the proxy. Removing the proxy will revert the account to using Automatic Proxy Protection if required for the provider. |

| Name | Type | Required | Description |
|------|------|----------|-------------|

### getPicture

`chats.getPicture`

Download a chat's picture (Telegram only). Returns the type and size only, unless include_content is set (then base64, up to max_bytes)

**Risk:** `read`

```ts
await corsair.unipile.api.chats.getPicture({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `include_content` | `boolean` | No | Return the file itself as base64 in content_base64. Off by default: only the type and size come back |
| `max_bytes` | `number` | No | Largest file to return with include_content (default 5 MB); bigger files come back without content |
| `chat_id` | `string` | Yes | — |
| `account_id` | `string` | Yes | Unipile account ID (acc_…) of the connected account to act as, from accounts.list |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `content_type` | `string` | Yes | MIME type Unipile sent |
| `size_bytes` | `number` | Yes | Size of the file in bytes |
| `filename` | `string` | No | File name from Content-Disposition, when sent |
| `content_base64` | `string` | No | The file as base64, only with include_content |
| `content_omitted` | `string` | No | Why content_base64 is missing although include_content was set |

**Risk:** `read`

| `after` | `string` | No | Only chats with a last message after this date-time |
| `is_archived` | `boolean` | No | — |
| `is_unread` | `boolean` | No | — |
| `offset` | `number` | No | Offset pagination: add the previous limit to get the next page. Use `cursor` instead when the previous page returned next_cursor |
| `cursor` | `string` | No | next_cursor from the previous page. Send it alone, without offset |

### update

`chats.update`

Change a chat: mark it read or unread, archive, mute, rename (groups) or label (WhatsApp Business). Marking read does not mark its messages; Telegram cannot archive

**Risk:** `write`

```ts
await corsair.unipile.api.chats.update({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `chat_id` | `string` | Yes | ID of the Chat to update. |
| `account_id` | `string` | Yes | Unipile account ID (acc_…) of the connected account to act as, from accounts.list |
| `name` | `string` | No | A custom name for the chat. Some providers allow custom names only on groups. |
| `pin_status` | `boolean` | No | If supported, set to `true` to pin the chat at the top of the list, or `false` to unpin it. |
| `archive_status` | `boolean` | No | If supported, set to `true` to archive the chat, or `false` to move it back to the main inbox. |
| `label` | `string` | No | If supported, associate the chat with the given label. For Whatsapp, this is resolved by label name and created if missing. |
| `muted_until` | `boolean \| string` | No | If supported, the date until which the conversation should be muted. Else `true` to mute the chat for an indefinite time, else `false` to un-mute an already muted chat. |
| `read_status` | `boolean` | No | Set to `true` to mark the chat as read. This is useful when displaying the list of messages in your app. Set to `false` to mark the chat as unread. |

### replay

`webhookEvents.replay`

Queue another delivery of a stored event (evt_…) to every enabled endpoint that matches it, even if it was delivered before. Receivers must handle the duplicate. Needs a Service API Key

**Risk:** `write`

```ts
await corsair.unipile.api.webhookEvents.replay({});
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `id` | `string` | Yes | — |
| `endpoint_id` | `string` | No | — |



**Output**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `object` | `string` | Yes | — |
| `event_id` | `string` | Yes | — |
| `endpoint_ids` | `string[]` | Yes | — |
