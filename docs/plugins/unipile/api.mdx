## Accounts

### createAuthLink

`accounts.createAuthLink`

Create a Hosted Auth link for a user to connect a LinkedIn (or other) account, or to reconnect one with account_id; LinkedIn sign-in can offer credentials, cookies or the UniLogin extension

**Risk:** `write`

```ts
await corsair.unipile.api.accounts.createAuthLink({ providers: 'linkedin', redirect_uri: 'https://app.example.com/linkedin/connected', state: 'user_123', config: { linkedin: { allow_methods: ['unilogin', 'credentials'] } } });
```

**Input**

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `providers` | `* \| *:MESSAGING \| *:EMAILS \| *:CALENDAR \| *:SOCIAL \| linkedin \| mock \| whatsapp \| google \| outlook \| imap \| telegram \| instagram \| linkedin \| mock \| whatsapp \| google \| outlook \| imap \| telegram \| instagram[]` | No | Providers to offer when linking a new account, e.g. linkedin. Omit when reconnecting with account_id |
| `account_id` | `string` | No | Reconnect or reconfigure this existing account instead of linking a new one |
| `expires_on` | `string` | No | When the link stops working, ISO 8601 with a timezone. Defaults to one hour from now |
| `redirect_uri` | `string` | Yes | Where to send the user afterwards. On success Unipile adds account_id, provider and state to the query; on failure error_title |
| `state` | `string` | No | Your own ID for this user or session. Unipile returns it on the redirect and in the account.add / account.reconnect webhook |
| `account_scope_id` | `string` | No | Scope to assign the account to |
| `domain` | `string` | No | White-label Hosted Auth hostname already verified by Unipile |
| `config` | `object` | No | — |

<AccordionGroup>
<Accordion title="config full type">

```ts

    allow_methods?: credentials | cookies | unilogin[],
    products?: classic | company | recruiter | sales_navigator[],
    allow_product_selection?: boolean,
    auto_proxy_config?: {
      country?: string,
      ip?: string,
      allow_country_fallback?: boolean
    }
  },
  global?: {
    login_hint?: string,
    allow_user_proxy_override?: boolean,
    allow_user_country_override?: boolean
  }
}
```
</Accordion>
</AccordionGroup>

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `object` | `string` | No | — |
| `link` | `string` | Yes | Hosted Auth URL to send the user to |
