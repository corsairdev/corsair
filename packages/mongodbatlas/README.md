# @corsair-dev/mongodbatlas

MongoDB Atlas integration for Corsair: the Atlas Administration API v2 (489 operations): organizations, projects, clusters and flex clusters, database users and custom roles, IP access lists, backups, snapshots and restores, Atlas Search indexes and nodes, Stream Processing, Data Federation, online archive, private endpoints and peering, monitoring, logs, performance advisor, alerts and alert settings, teams, users, service accounts and API keys, invoices and more.

## Install

```bash
pnpm add @corsair-dev/mongodbatlas
```
