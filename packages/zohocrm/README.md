# @corsair-dev/zohocrm

Zoho CRM with the full v8 REST API: records in every module (leads, contacts, accounts, deals and custom modules), search and COQL, notes, attachments, tags, emails, bulk read and write, users, roles, profiles, territories, layouts, fields, pipelines, blueprints, workflow rules and other automation, webforms and org settings, in every Zoho data center (573 operations).

## Install

```bash
pnpm add @corsair-dev/zohocrm
```
