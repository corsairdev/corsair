# @corsair-dev/neuronwriter

NeuronWriter plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/neuronwriter
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `content.import` | `neuronwriter.api.content.import` | `write` | Import HTML or a page into a query. The content is not stored. |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/neuronwriter
