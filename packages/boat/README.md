# @corsair-dev/boat

Persistent Linux sandboxes for AI agents with Boat: create, stop, resume, fork and share sandboxes, run commands, read and write files, prompt integrated coding agents, expose ports, stream the desktop, save and share snapshots, and manage environments, credential profiles, API keys, webhooks, CI and telemetry (125 operations).

## Install

```bash
pnpm add @corsair-dev/boat
```
