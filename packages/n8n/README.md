# @corsair-dev/n8n

Manage a self-hosted or Cloud n8n instance: create, run, publish and archive workflows, read and retry executions, manage credentials, data tables and their rows, tags, variables, projects, folders, users, roles, AI agents, evaluations, source control, environment promotions and instance settings (202 operations).

## Install

```bash
pnpm add @corsair-dev/n8n
```
