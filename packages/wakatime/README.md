# @corsair-dev/wakatime

WakaTime plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/wakatime
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `users.current` | `wakatime.api.users.current` | `read` | Get the current WakaTime user |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/wakatime
