# @corsair-dev/youcom

You.com Web Search plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/youcom
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `yousearch.youSearch` | `youcom.api.yousearch.youSearch` | `read` | Search the web using You.com's search API. Returns LLM-ready web results and news articles. |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/youcom
