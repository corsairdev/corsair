# QuickBooks

## Status: blocked pending official API contract sources

This package is an intentionally empty scaffold. It exposes no QuickBooks API
operations, webhooks, authentication configuration, or request behavior. Do not
use it to make QuickBooks Online API calls.

The [Intuit QuickBooks Online Accounting API reference](https://developer.intuit.com/app/developer/qbo/docs/api/accounting/all-entities/account)
is the available starting point, but the reviewed pages render as a JavaScript
shell and no first-party OpenAPI or equivalent machine-readable contract source
was found. An authoritative source is needed to verify routes, authentication,
company realm handling, API version parameters, request and response schemas,
and webhook behavior before any of those are implemented.

No QuickBooks routes or operations are claimed by this package.
