# @corsair-dev/winstonai

Winston AI plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/winstonai
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `detect.aiText` | `winstonai.api.detect.aiText` | `read` | Score whether text was written by a human or generated by AI |
| `detect.plagiarism` | `winstonai.api.detect.plagiarism` | `read` | Scan text for matching sources on the web |
| `detect.aiImage` | `winstonai.api.detect.aiImage` | `read` | Score whether a public image URL was generated by AI |
| `text.compare` | `winstonai.api.text.compare` | `read` | Compare two texts and return similarity scores |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.
