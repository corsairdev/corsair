# @corsair-dev/boloforms

Boloforms plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/boloforms
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `documents.list` | `boloforms.api.documents.list` | `read` | Retrieve a list of documents from a Boloforms workspace, with optional filtering and pagination |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/boloforms
