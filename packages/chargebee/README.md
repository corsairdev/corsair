# @corsair-dev/chargebee

Subscription billing with Chargebee: customers, subscriptions, items and item prices, invoices, credit notes, payments and payment sources, coupons, quotes, estimates, hosted pages, usage, entitlements, exports and site settings, on Product Catalog 2.0 and 1.0 sites (546 operations).

## Install

```bash
pnpm add @corsair-dev/chargebee
```
