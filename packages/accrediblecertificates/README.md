# @corsair-dev/accrediblecertificates

AccredibleCertificates plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/accrediblecertificates
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `credentials.get` | `accrediblecertificates.api.credentials.get` | `read` | Get an credential resource by ID |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/accrediblecertificates
