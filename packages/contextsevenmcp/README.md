# @corsair-dev/contextsevenmcp

ContextSevenMcp plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/contextsevenmcp
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `context.get` | `contextsevenmcp.api.context.get` | `read` | Get documentation context for a library |
| `library.search` | `contextsevenmcp.api.library.search` | `read` | Search Context7 libraries by name |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/contextsevenmcp
