# @corsair-dev/baserow

Baserow, the open-source no-code database, on its cloud or a self-hosted server: rows (with batch create, update and delete), fields, tables, views with filters, sorts and groupings, imports and exports, webhooks, workspaces, members and invitations, applications, the builder, dashboards, automations, AI agents and admin settings (489 operations).

## Install

```bash
pnpm add @corsair-dev/baserow
```
