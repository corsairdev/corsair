# @corsair-dev/parsehub

ParseHub plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/parsehub
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `projects.list` | `parsehub.api.projects.list` | `read` | List projects for the authenticated ParseHub account. |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/parsehub
