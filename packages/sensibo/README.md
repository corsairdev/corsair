# @corsair-dev/sensibo

Sensibo plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/sensibo
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `devices.list` | `sensibo.api.devices.list` | `read` | List every Sensibo pod on the authenticated account. |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/sensibo
