# @corsair-dev/microsoftclarity

MicrosoftClarity plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/microsoftclarity
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `insights.get` | `microsoftclarity.api.insights.get` | `read` | Export project dashboard metrics for the past 1 to 3 days with optional dimension breakdowns |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/microsoftclarity
