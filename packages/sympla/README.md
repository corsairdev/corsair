# @corsair-dev/sympla

Sympla plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/sympla
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `events.list` | `sympla.api.events.list` | `read` | List events for the authenticated organizer. |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/sympla
