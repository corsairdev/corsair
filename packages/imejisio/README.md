# @corsair-dev/imejisio

Imejisio plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/imejisio
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `designs.render` | `imejisio.api.designs.render` | `write` | Render an Imejis template design into image/PDF bytes or a stored URL |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/imejisio
