# @corsair/plugin-typefully

This integration module links Corsair platform capabilities directly to the Typefully API.

## Configuration
To initialize the plugin provider layout, supply your Typefully Bearer credentials:
- `apiKey`: Your private API token generated from your Typefully developer profile dashboard settings.

## Supported Actions
- `createDraft`: Compiles, validates, and transmits text payloads to generate fresh draft threads.
