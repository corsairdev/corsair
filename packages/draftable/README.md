# @corsair-dev/draftable

Draftable plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/draftable
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `comparisons.list` | `draftable.api.comparisons.list` | `read` | Paginated list of document comparisons. |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/draftable
