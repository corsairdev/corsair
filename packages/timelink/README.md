# @corsair-dev/timelink

Timelink plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/timelink
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `deletePerson.delete` | `timelink.api.deletePerson.delete` | `destructive` | Delete a person record by their unique identifier. |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/timelink
