# @corsair-dev/segment

Twilio Segment customer data platform: send identify, track, page, screen, group and alias calls, and manage the workspace through the Public API: sources, destinations and their filters, warehouses, tracking plans, functions, transformations, catalog, deletion and suppression, users and groups, labels, usage, delivery overview, spaces, audiences, computed traits, Profiles Sync and Reverse ETL (207 operations).

## Install

```bash
pnpm add @corsair-dev/segment
```
