# @corsair-dev/beamer

Beamer plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/beamer
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `posts.get` | `beamer.api.posts.get` | `read` | Get Beamer posts |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/beamer
