# @corsair-dev/flexisign

Flexisign plugin for Corsair.

## Install

```bash
pnpm add @corsair-dev/flexisign
```

## Endpoints

| Operation | Operation ID | Risk | Description |
|-----------|--------------|------|-------------|
| `list.templates` | `flexisign.api.list.templates` | `read` | List all available document templates in FlexiSign |

## Auth

Auth: API key. Corsair prompts your tenant for credentials on first use.

## Webhooks

No webhooks.

## Reference

Full docs, types, and examples: https://docs.corsair.dev/plugins/flexisign
